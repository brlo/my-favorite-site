# 安息日
## 上帝祝圣了安息日
创造世界之后，上帝祝圣了第七日（安息日），但没有设立诫命：
> gen 2:3 :: !上帝赐福给第七日，定为圣日 :: !因为在这日上帝歇了他一切创造的工，就安息了
旁边有许多上帝赐下其他命令的地方：
> gen 1:28 :: !又对他们说
> gen 1:29 :: !上帝说
> gen 2:16-17 :: !耶和华上帝吩咐他说
然而，关于安息日没有赐下任何命令。创造诸日之后说到安息的是上帝，而不是人。上帝把人安置在伊甸园中是为了劳动：
> gen 2:5,8,15 :: !也没有人耕地 :: !把所造的人安置在那里 :: !使他修理看守
在那永恒的神圣安息中——上帝如今所处其中（[[gen 2:3]]）——人们将来才能进入。而且并非所有人，只有上帝亲自放进去的人：
> evr 4:3; ps 95:11; evr 3:11 :: !但我们已经相信的人得以进入那安息 :: !他们断不可进入我的安息
## 安息日停止劳作之诫命的出现
安息日停止劳作的诫命，是上帝在先知摩西的时代、与以色列民立约的时候首次设立的：
> ish 20:8-10 :: !当记念安息日，守为圣日 :: !六日要劳碌作你一切的工 :: !但第七日 :: !无论何工都不可作 ~~ 并见 [[vtor 5:12-15]]；[[lev 19:3]]；[[lev 19:30]]。
## 设立安息日诫命的原因
诫命的原因就在诫命的话语之后说明了。这一原因：以色列民出埃及的出走。
> vtor 5:14-15 :: !你也要记念你在埃及地作过奴仆 :: !将你从那里领出来 :: !因此，耶和华你的上帝吩咐你守安息日
赐给他们「安息日」，即赐给他们先前没有的东西：
> iez 20:10-12 :: !我就使他们出埃及地 :: !将我的律例赐给他们 :: !又将我的安息日赐给他们
> vtor 5:2-3 :: !耶和华我们的上帝在何烈山与我们立约 :: !乃是与我们今日在这里存活之人立的
也有另一种解释，指出上帝对第七日的祝圣：
> ish 20:11; gen 2:3 :: !因为六日之内，耶和华造天、地、海和其中的万物 :: !所以耶和华赐福与安息日，定为圣日
然而，这一解释虽指出了联系，但这里说明的是祝圣安息日的原因：「所以耶和华赐福」（[[ish 20:11]]），而不是诫命的原因。而在另一节经文中，则最明确地给出了诫命本身的原因：「你也要记念你在埃及地作过奴仆……将你从那里领出来……因此，耶和华你的上帝吩咐你守安息日」（[[vtor 5:14-15]]）。
这样，安息日的停止劳作是因以色列民脱离埃及奴役的出走而设立的，虽然也指出了它与神圣安息的联系。
## 诫命之律已被废除
律法是在基督来临之前、为一段时期而赐下的：
> gal 3:19 :: !原是为过犯添上的 :: !等候那蒙应许的子孙来到
诫命之律已被基督的教导废除：
> ef 2:14-16 :: !拆毁了中间隔断的墙 :: !以自己的身体废掉冤仇 :: !就是那记在律法上的规条
基督徒已从律法中释放：
> rim 7:6 :: !现今就脱离了律法 :: !要按着心灵的新样，不按着仪文的旧样
摩西律法废除的详细解释：[[ru:Библия-Закон-Моисея-отмена|摩西律法的废除]]。
## 基督保护使徒免受干犯安息日的指控
法利赛人指摘主和使徒们干犯安息日。基督称使徒们无罪：
> mf 12:2,7 :: !看哪，你的门徒作安息日不可作的事了 :: !就不将无罪的当作有罪的了
## 使徒禁止因不守安息日而论断基督徒
> kol 2:16 :: !所以不拘在饮食上，或节期、月朔、安息日，都不可让人论断你们
# 主日
## 主显现的日子
1. 主耶稣基督在七日的第一日——主日——复活了，并向没有多马的门徒们显现（[[in 20:19]]）。
1. 在主日，他向持香的妇女们显现（[[mf 28:1,9]]）、向抹大拉的马利亚显现（[[mk 16:9]]）、向使徒彼得显现（[[lk 24:34]]）、向使徒革流巴和路加显现（[[lk 24:13-32]]）。
1. 为多马的缘故，救主恰好过了一周再次显现，又是在主日（[[in 20:26]]）。
## 聚会与举行圣餐礼的日子
使徒们在特罗亚住了七天，而在七天之中，他们不是在安息日、而是在主日聚会举行事奉圣礼并擘饼：
> act 20:6-11 :: !在那里住了七天 ~~ 在特罗亚住了整整七天。 :: !七日的第一日，我们聚会擘饼的时候 ~~ 有七天，但擘饼聚会正是在主日。 :: !我们聚会的那座楼上，有好些灯烛 ~~ 隆重的聚会。
使徒请求在主日（聚会之日）抽出钱来，帮助有缺乏的人：
> 1kor 16:2 :: !每逢七日的第一日，各人要照自己的进项抽出来留着
# 批评
某些脱离教会的团体（主要是基督复临安息日会教派），违背诫命（[[kol 2:16]]），不但指摘教会不守安息日，还指摘教会更隆重地庆祝主日，说主日不应当庆祝。
在东正教会中，人在一生所有的日子都蒙召行善，而在特别的日子（安息日，尤其是主日），不但以个人的善行、更以**共同的事业**（源自希腊文 λειτουργία——事奉圣礼）来庆祝，也就是以共同的聚会举行事奉圣礼来庆祝主日。其余的日子也举行事奉圣礼，但在安息日、尤其是在主日举行特别的、更隆重的事奉圣礼。
对基督徒来说，最重要的事件是基督的复活——主耶稣基督从死人中复活。这一日被称为诸庆节之庆节、诸凯旋之凯旋，因为：
> 1kor 15:14,17 :: !若基督没有复活，我们所传的便是枉然 :: !你们的信便是徒然，你们仍在罪里
如上所示，使徒们正是在主日举行事奉圣礼。这一日成了与复活之主相会的喜乐之日。最早的基督徒也是如此：[[ru:Евхаристия_в_воскресенье|主日的圣餐礼]]
还有人指摘君士坦丁皇帝（四世纪），说他似乎把休息日从安息日改到了主日（[[act 20:6-11]]）。然而，君士坦丁皇帝设立了每周第一个休息日——主日，没有对安息日作任何指示（[[ru:Воскресенье_выходной_Указ_императора_Константина|详见]]）。在这一敕令之前，罗马帝国没有普遍的每周休息日。
这样，这种批评至少可以说是不成立的。
