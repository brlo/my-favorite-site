正教基督徒被指控拜偶像：圣像被称为偶像，敬礼圣像被称为拜偶像。本文按圣经考察圣像敬礼的问题，回应这些指控。
先给出简短的回答，然后较详细地考察批评，最后给出最详细的、逐句依据圣经的回答。
# 敬礼圣像最简短的辩护
在上帝道成肉身之前的时代，上帝为旧约的以色列设立律法时，没有显明自己的像，并禁止制造假神（偶像）的像、禁止敬拜它们（[[ish 20:4-5]]；[[vtor 5:8-9]]；[[vtor 4:15-19]]）；但他命令描绘自己的圣洁仆人（[[ish 25:1]]；[[ish 26:1]]；[[ish 25:18-20]]），而先知们在有像的圣物前叩拜（[[nav 7:6]]；[[ps 5:7]]）。正教徒对带有像的圣物的敬礼，与先知的做法完全一样。
此外，按上帝的构想，圣殿本身就是天的圣像（[[ish 25:8-9,40]]；[[evr 9:24]]；[[act 7:44]]）。上帝命令敬重圣殿（[[lev 19:30]]；[[lev 26:2]]）；圣殿受敬礼，人们在它面前叩拜（[[ps 5:7]]；[[ps 99:5]]；[[ps 132:7]]）。这正是正教的敬礼：敬礼像，就是敬礼原型。
任何人想用来为先知对带有像的圣物的敬礼辩护的理由，都适用于正教的敬礼（因为这是同一件事）；任何人想用来指责正教敬礼的定罪，也同样落在先知的敬礼上。
问题完全不在像及其敬礼。既然偶像是对上帝的任何虚假观念，那么问题在于：1）像本身、2）敬礼者赋予它的意义内容，与真理是什么关系。如果两者中哪怕一个在原则上虚假，那就是拜偶像——它把人从真理引开。这才是问题所在：偶像不引人归向上帝，对上帝的虚假观念不引人归向真上帝，因为谎言不引向真理，而使人离开真理。
在与反对圣像者的对话中简要检验这一论断：
**反圣像者**：向物件叩拜——是拜偶像。
**正教徒**：那么上帝的先知们在圣殿和有像的约柜前叩拜，就成了拜偶像的了？
**反对者**：上帝只说了描绘，没有说敬礼或叩拜。
**正教徒**：那么先知们作了不该作的、没有记载的、没有被命令的事，就是说陷入了拜偶像？
**反对者**：先知叩拜的不是圣殿或约柜本身，而是把这敬礼归于上帝。
**正教徒**：正是如此。正教徒叩拜的也不是木头和颜料，而是像中所描绘的位格——教导中正是这样说：藉着像敬礼原型，如同先知。没有任何差别。
如此等等。这条规则永远有效，因为先知的敬礼与正教的敬礼之间没有任何差别。现在更详细地考察这一问题。
# 反圣像者说：“上帝的话明明说：不可作像，你们却作”
**回答**：这是摩西律法中只针对描绘上帝的旧约禁令，从上下文可见：
- 前四条诫命正是**关于上帝**的（[[ish 20:4-5]]；[[vtor 5:8-9]]）；
- 设立禁令时，上帝指出它的缘由：在律法设立时上帝没有显明自己的**像**（[[vtor 4:15-19]]）：既然没有见过上帝，就不要描绘。
这样，禁令针对的正是描绘上帝；而对自己的圣洁仆人，上帝不但没有禁止，反而命令描绘（[[ish 25:1]]；[[ish 26:1]]），义人们向圣殿和带这些像的圣物叩拜（[[nav 7:6]]；[[ps 5:7]]；[[ps 99:5]]；[[ps 132:7]]）。
旧约的教会里有圣像，它们受敬礼。首先，**旧约的圣殿本身就是圣像**。作为地上的场所，它按上帝起初的构想应当成为天上所发生之事的描绘。上帝命令先知摩西建造圣殿，不是因为他需要殿（上帝不需要，[[is 66:1]]；[[ps 49:13]]；[[is 1:11]]），而是命令把殿造为天的圣像、造为向先知所显示的天上实体之像（[[ish 25:8-9,40]]；[[evr 9:24]]；[[act 7:44]]）。上帝命令敬礼这一圣像（[[lev 19:30]]；[[lev 26:2]]）。先知大卫向它叩拜（[[ps 5:7]]；[[ps 99:5]]；[[ps 132:7]]）。当不虔的王在圣殿里设立异教偶像时（[[4ts 21:3-7]]）——即损坏了天上实体的像——上帝就弃绝了圣殿（[[4ts 23:27]]）。
正因为圣殿是天的圣像，在新约里它经历了改变（内部构造、像），因为天上实体也改变了。在旧约里，天上实体中以属灵-可见方式存在的**只有天使**。而上帝完全不可见、非物质，人也还没有达到天上的生命（详见[[ru:9VFT_До_жертвы_Христовой_ветхозаветные_праведники_сходили_в_ад|详见]]）。
在新约里——更准确地说，随着主耶稣基督的来临——发生了巨大的变化：
1. **上帝按人性成为可见的**（[[in 1:18]]；[[1in 1:1-2]]）；
2. **上帝有形地在天上登基**（[[ef 1:20-21]]；[[otkr 3:21]]）；
3. **天上出现了人**——他们获得了与主耶稣基督同活的可能（[[otkr 6:9-11]]；[[otkr 14:1,3-5]]）；
4. **上帝订立新约**（[[ier 31:31]]；[[evr 8:8]]；[[lk 22:20]]；[[1kor 11:25]]）。**旧约与摩西的律法一同终结**（[[rim 7:6]]；[[gal 3:21-25]]；[[ef 2:14-16]]）。描绘上帝的禁令失效，因为它曾是摩西律法的一部分，而摩西律法已随基督的来临被废除（详见[[ru:Библия-Закон-Моисея-отмена|详见]]）。
这样，旧约的圣殿是旧约天上实体的像，而这实体在新约里改变了。先前的已不存在。既然圣殿按上帝起初的构想就是天上实体的像，那么在这实体改变之后，描绘旧的就已没有意义。因此基督徒从最古老的年代起描绘新的天上实体，把在天空明显登基的耶稣基督（上帝）的像立在最前面，周围——描绘他圣洁的仆人们：如今已不只是天使，还有人。
标志性的事件是基督的祭献之后耶路撒冷圣殿的损坏：
> mf 27:51-53 :: !殿里的幔子从上到下裂为两半 :: !地也震动，磐石也崩裂 :: !坟墓也开了 :: !到耶稣复活以后 :: !进了圣城，向许多人显现
而在70年代，圣殿被罗马人完全毁灭，在随后的一切千百年里，把位置让给了新的天上实体之像——正教圣殿。
更多古圣像见：[[ru:древние-иконы|古圣像]]
过时的不只是旧约天上实体的像，还有旧约本身——摩西的律法是它不可分的部分，如今律法已失去意义。除描绘上帝的禁令外，还有许多规定在新约里已不再有效：
> lev 24:16 :: !那亵渎耶和华名的，必被治死 :: !他亵渎耶和华名的时候，必被治死
亵渎上帝的名——是违背**第三诫**的罪。按摩西律法的刑罚——死（[[lev 24:16]]）。据我们所知，反对圣像的人并不教导为亵渎上帝而杀人。他们要求遵守旧约关于不可描绘上帝的禁令，引用带有“这是上帝的话”字样的引文；但关于处死亵渎者的诫命也是上帝的话，也写得同样明白，但他们并不这样行。为什么？因为摩西律法被废除了。
**第四诫**设立安息日的安息——停止作工（[[ish 20:8-10]]；[[vtor 5:12-15]]；[[lev 19:3]]；[[lev 19:30]]）。按摩西律法的刑罚——死。这也是上帝的话，也写得同样明白；但反对圣像的人不教导为破坏安息日的安息而杀人，他们大多数连安息日的安息自己也不守。为什么？因为摩西律法被废除了。
这样，禁止描绘道成肉身的上帝意味着：
1. **犹太化**：继续按摩西律法生活（顺便说，什一奉献也是按同样的理由收取的，见[[ru:ozcY_О_десятине|什一奉献]]）；
2. **间接否认上帝道成肉身**：或者否认基督是上帝，或者否认他是可见的。
现在我们把问题考察得更详细。
# 摩西律法的第二诫
反对圣像的人认为圣像违反了[[ru:10-заповедей|摩西律法]]的第二诫：
1. “**不可为自己雕刻偶像；也不可作什么形像**仿佛上天、下地，和地底下、水中的百物。**不可跪拜那些像**；也不可事奉它”（[[ish 20:4-5]]；[[vtor 5:8-9]]）；
摩西的十诫分为两部分（两块法版）：
- 四条关于爱上帝的诫命；
- 六条关于爱邻人的诫命。
第二诫属于爱上帝的表现，它并不禁止一切的像和叩拜，而是禁止制造物件、把它们当作神来敬拜以代替独一的真上帝。换言之，**这条诫命禁止敬拜假神**。正因为如此，我们在圣经里既看到像、也看到不违反这条诫命的叩拜。详见下文。
## “不可作像”
### 上帝命令在他自己的圣殿里制作像
虽然第二诫禁止作像，但赐下这条诫命的同一上帝，如今命令在他的殿（会幕）里制作像：在会幕的板壁上、在通入至圣所的幔子上描绘基路伯的像，并在约柜的施恩座上制作基路伯的金像：
> ish 26:1 :: !你要用十幅幔子作帐幕 :: !并用巧匠的手工绣上基路伯
> ish 36:8 :: !并用巧匠的手工绣上基路伯
> ish 25:18-20 :: !要用金子锤出两个基路伯来 :: !安在施恩座的两头
在较晚的、所罗门建造的圣殿里，有更多的各种像和雕像：
> 2par 3:14 :: !织幔子 :: !在其上绣出基路伯来
> 2par 3:10 :: !在至圣所按造像的法子造两个基路伯
> 3ts 6:23 :: !他用橄榄木作两个基路伯
圣殿构造的详情：[[ru:иерусалимский-храм|耶路撒冷圣殿]]
为制作殿内的器皿，上帝把圣灵的恩赐赐给了工匠们：
> ish 31:1-5 :: !我已经提他的名召他 :: !我也以我的灵充满了他 :: !能想出巧工，用金、银、铜制造各物
### 上帝命令制作蛇的像
上帝还命令制作铜蛇，使望它的人奇妙地脱离蛇咬的死亡：
> chis 21:8-9 :: !你制造一条火蛇 :: !凡被咬的，一望这蛇，就必得活 :: !摩西便制造一条铜蛇 :: !凡被蛇咬的，一望这铜蛇，就活了
非常重要的是：这蛇是耶稣基督的像，应当指向他在十字架上将来的苦难：
> in 3:14-15 :: !摩西在旷野怎样举蛇 :: !人子也必照样被举起来 :: !叫一切信他的都得永生
这蛇后来被希西家王毁掉，因为以色列人开始把蛇本身当作神，给它起了自己虚假的名字（尼忽士但）——这名字与真上帝没有任何关系。他们离弃了真上帝，违反了第二诫：
> 4ts 18:4 :: !打碎摩西所造的铜蛇 :: !以色列人仍向铜蛇烧香 :: !希西家叫铜蛇为铜块
## “不可跪拜那些像”
虽然禁止敬拜像（圣像），但义人们经常向人、向各种物件、向天使下拜；别人也向先知下拜。没有人因拜偶像而定他们的罪，因为这些叩拜不是向假神（偶像）行的。
### 向以天使形像显现的上帝叩拜
亚伯拉罕向以三个男人形像显现的上帝叩拜：
> gen 18:1-2 :: !向亚伯拉罕显现出来 :: !见有三个人在对面站着 :: !俯伏在地
为什么上帝以像显现？——因为上帝在本性上不可见，从来没有人见过他（[[1tim 6:16]]；[[in 1:18]]）。
### 向天使叩拜
先要指出：天使是灵（[[evr 1:13-14]]），而灵没有骨和肉（[[lk 24:39]]）；就是说，天使也是以人的形像向人显现的。所以，向天使叩拜，就是向看不见的灵（天使）的看得见之像叩拜：
> nav 5:14 :: !约书亚就俯伏在地下拜
### 向先知叩拜
> 4ts 2:15 :: !在他面前俯伏于地
### 向圣殿叩拜
大卫向圣殿叩拜——这殿本身就是天的圣像（[[lev 19:30]]；[[lev 26:2]]），并且殿中布满圣天使的像（[[ish 25:1]]；[[ish 26:1]]）：
> ps 5:7 :: !向你的圣殿下拜
同时，上帝命令敬重圣殿（[[lev 19:30]]；[[lev 26:2]]）。
### 向上帝的脚凳（圣殿）叩拜
> ps 99:5 :: !在他脚凳前下拜
> ps 132:7 :: !我们要进他的居所，在他脚凳前下拜
### 向约柜叩拜
> nav 7:6 :: !俯伏在地，直到晚上
### 向杖叩拜
经上记着“以色列在床头上敬拜”（[[gen 47:31]]），而在七十士译本里是“在杖头上”（[[evr 11:21]]）。
更多例子：[[ru:поклоны|叩拜]]
## 异教对偶像的信仰违反第二诫
### 异教的神
> ish 20:4-5 :: !不可为自己雕刻偶像 :: !不可跪拜那些像
### 正教会所信的上帝
> in 17:3 :: !认识你独一的真上帝 :: !并且认识你所差来的耶稣基督
## 设立第二诫的缘由
> vtor 4:15-19 :: !你们没有看见什么形像 :: !惟恐你们败坏自己，雕刻偶像 :: !又恐怕你向天举目观看 :: !自己便被勾引敬拜事奉它
# 随着基督的来临，发生了改变
## 1. 旧约与摩西的律法终结了
> rim 7:6 :: !但我们既然在捆我们的律法上死了 :: !叫我们服事主 :: !要按着心灵的新样，不按着仪文的旧样
> gal 3:21-25 :: !这样，律法是与上帝的应许反对吗 :: !律法是我们训蒙的师傅，引我们到基督那里 :: !但这因信得救的理既然来到，我们从此就不在师傅的手下了
> ef 2:14-16 :: !拆毁了中间隔断的墙 :: !而且以自己的身体废掉冤仇 :: !便藉这十字架使两下归为一体
基督订立新约，以此终结旧约和摩西的律法（[[rim 7:6]]；[[gal 3:21-25]]；[[ef 2:14-16]]）。描绘上帝的禁令曾是摩西律法的一部分，摩西律法已随基督的来临被废除（详见[[ru:Библия-Закон-Моисея-отмена|详见]]）。上帝藉摩西所赐的诫命失去其字面的意义：我们不守安息日的安息（也不杀安息日作工的人），不献牲畜为祭，不受割礼，不过犹太的节日，不献什一奉献；摩西律法的许多别的命令我们也不遵守。旧约和摩西的律法作为整体被废除了，而新约的信徒被召作执事的，不是按仪文的旧样，而是按心灵的新样（[[2kor 3:6]]）——即理解上帝各种设立的缘由，领会其意义，遵守诫命的实质。
第二诫的字面意义禁止描绘的只是上帝，而不是他的圣洁仆人（[[ish 25:1]]；[[ish 26:1]]）。
第二诫的实质——不可敬拜假神。
相应地，正教会描绘圣人们，因为这从来没有被禁止，反而命令描绘他们（[[ish 25:1]]；[[ish 26:1]]），而义人们在像前叩拜（[[nav 7:6]]；[[ps 5:7]]）。至于描绘上帝，则只在旧约里被摩西律法所禁止，因为那时没有人见过上帝。而既然摩西律法被废除，那么描绘上帝的禁令作为摩西律法的一部分也被废除了。
## 2. 上帝成为可见的，取了人性（道成肉身）
> in 1:18 :: !从来没有人看见上帝 :: !只有在父怀里的独生子将他表明出来
> 1in 1:1-2 :: !就是我们所听见、所看见、亲眼看过、亲手摸过的
天上实体改变了。先前的已不存在。耶路撒冷的圣殿成了过去的天上实体之像，而不是现在的。因此基督徒从最古老的年代起描绘新的天上实体，把在天空明显登基的耶稣基督（上帝）的像立在最前面，周围——描绘他圣洁的仆人们，如今已不只是天使，还有人。
标志性的事件是基督的祭献之后耶路撒冷圣殿的损坏：
> mf 27:51-53 :: !殿里的幔子从上到下裂为两半 :: !到耶稣复活以后 :: !进了圣城，向许多人显现
而在70年代，圣殿被罗马人完全毁灭，在随后的一切千百年里，把位置让给了新的天上实体之像——正教圣殿。
# 上帝亲自制作自己的圣像
从来没有人见过上帝：
> in 1:18 :: !从来没有人看见上帝
但上帝多次以像（圣像）的样式显现：
## 上帝以三位天使的样式向亚伯拉罕显现
三位天使不是上帝的本相、不是他在创世之前所是的；就是说，这是上帝的像（希腊文 εἰκόνα——圣像），而亚伯拉罕拜的是上帝的圣像：
> gen 18:1-2 :: !向亚伯拉罕显现出来 :: !见有三个人在对面站着 :: !俯伏在地
亚伯拉罕拜了三位天使样式的上帝之像之后，他事奉的是上帝，还是上帝的像？显然，是上帝。
## 上帝明显与雅各较力
> gen 32:24,28,30 :: !只剩下雅各一人 :: !因为你与上帝与人较力，都得了胜 :: !我面对面见了上帝，我的性命仍得保全
## 上帝经由像与先知摩西交谈
> chis 12:6-8 :: !我耶和华必在异象中向他显现 :: !我的仆人摩西不是这样 :: !我要与他面对面说话 :: !并且他必见我的形像
## 上帝以鸽子的样式降在耶稣基督身上
> lk 3:22 :: !圣灵降临在他身上，形状仿佛鸽子 :: !又有声音从天上来
同样见：[[mf 3:16]]；[[mk 1:10]]；[[in 1:32]]
## 人——是上帝的圣像

### 难道除了基督还有谁能救人吗？
无论使徒还是夫妻，都不是主耶稣基督意义上的救主——他是唯一的救赎者，把人类从死亡和阴间中救出、赐复活和与上帝同在的永生。但如上所见，“我要救”这样的说法是使徒们所用的。我们正确地理解这些话的意义——人可以促进得救：“因为我们是与上帝同工的”（[[1kor 3:9]]）。
圣像也是这样：拯救的不是圣像，而是上帝；上帝经由物件赐下恩典。在圣经里我们可以找到许多这样的例子，详见下文。
# 关于“圣像——通向属灵世界的窗户”的说法
圣像是一种通向属灵世界的窗户。这一说法没有任何神秘的意义，是形象化的表达。它只是说：观看圣像时，我们仿佛透过窗户看向看不见的属灵世界。
属灵的事物是不可见的，而圣像画家把不可见的以可见的方式、藉着象征描绘在圣像上。例如，上帝的恩典住在圣人里面，以他们头上的光环描绘；没有影子意味着住在上帝的光中（这光不是寻常的光，不投下影子）；意义包含在手上所示的姿势、衣着的颜色、衣服上的特别标记（上帝之母衣服上的三颗星）、周围的物件、建筑、空间之中。观看这一切，我们认识到关于看不见的属灵世界的某些事。正因为如此，有时才使用这样的说法：圣像仿佛是通向属灵世界的窗户（详见[[ru:ikony-okno|圣像——窗户]]）。
为什么这需要特别说明？因为经常不得不遇到：反对正教会的人为了编造自己的指控，干脆凭空捏造指控，灌输给自己的追随者，在他们心里培植对正教会的仇恨。例如，为把正教徒描绘成可憎的巫师，教会的反对者捏造说：正教徒仿佛经由圣像与上帝建立联系，如同经由某种能量门户，因此需要圣像来与上帝相交。这一切纯属虚构。
正教会召呼信徒随处祈祷，无论有没有圣像。圣像只是帮助教育和祈祷的辅助手段。祈祷时，圣像帮助集中思想：不涣散、不分心。圣像也是表达对像中所描绘之位格的敬意的手段。各种物件，包括圣像，可以成为上帝向人赐下自己恩典的途径——详见下一节。

# 正教会关于敬礼圣像的教训
## 367位圣教父关于敬礼圣像的信经——第七次大公会议，尼西亚（787年）
“我们完整地保守教会的一切传统，无论是书面的还是非书面的。其中一个传统命令制作圣像彩绘；因为它与福音宣讲的历史相合，证实上帝的道真实地、而非虚幻地成了肉身，并且对我们有益：因为彼此互相说明的事物，无疑也彼此互相证实。我们循着王道、追随我们圣教父的圣训和公教会的圣传行进——因为我们知道，圣灵住在她里面——以一切的谨慎和明察确定：可敬的圣像应被陈设（供敬礼），如同生命给予者的十字架之像一样，无论它们由颜色、或由（马赛克）小块、或由任何别的材料制成，只要是以合宜的方式制成；无论它们在上帝的圣堂里、在神圣的器皿和衣袍上、在墙壁和木板上，或在家里和路旁；无论这是我们的主上帝救主耶稣基督的像，或我们至洁的圣母、上帝之母的像，或可敬的天使及一切圣人和义人的像。——藉圣像他们越常被我们默观，观看这些像的人就越被激励记念原型，对他们获得更多的爱，并受到更多的激励向他们献上亲吻、敬意和叩拜；但这绝不是那按我们的信仰只归于上帝本性的真正事奉。他们被激励向圣像献香、为它们点灯，如同为主基督之像、为圣天使们那样，如同古时按虔诚的心意习惯所行的那样：因为向圣像所献的敬意归于它的原型；敬拜圣像的人，敬拜的是像中所描绘者的位格。这样的教导保存在我们的圣教父们那里，即在公教会的传统中，在其中福音代代相传。”
（[俄文](https://azbyka.ru/otechnik/7_Vselenskij_Sobor)第七次大公会议，决议7）
## 君士坦丁堡牧首耶利米（1576年）
“至于第二十一篇——也是论及敬礼圣人、并说纪念圣徒有益于坚固我们的信仰——的最后一章，如果我们想到他们如何藉信心领受了上帝的恩典和帮助，我们说：呼求主要地只与上帝一位相宜，并且首先和本然地归于他；而对圣人们所行的呼求，不是在本然的意义上，仿佛偶然地、按恩典而归于他们。因为听那些呼求他们的，不是彼得或保罗，而是他们所具有的恩典——照主的话：‘我就常与你们同在，直到世界的末了’（太 28:20）。
神圣的使徒保罗写信给罗马人，论呼求上帝说：‘人未曾信他，怎能求他呢？’（罗 10:14）——由此表明：只应当呼求我们所信的那独一者，即上帝。而我们把呼求本然地归于独一的上帝，由我们在神圣的奥迹中呼求‘我们在天上的父’等，可以看见。在另一处：‘万军之主啊，求你与我们同在；除你以外，我们没有别的患难中的帮助者。’又说：‘除你以外，我们没有认识别的上帝。’我们使一切圣徒作中保，而首先是主之母，与她一起的还有天使和圣人的团契；我们以圣殿、奉献、呼求、神圣的圣像相对地（而非事奉地）尊敬他们。因为我们知道，事奉只应首先献给独一的上帝，除他以外不应承认别人为上帝，不可敬拜‘别神’（诗 80:10）。我们宁可自己不愿成为圣人，也不愿因相对的敬礼而陷入把圣人们神化。断乎不可：因为不相对地敬拜圣像，是不虔的、与基督的教会和她的儿女相违的，因为对它们的尊敬归于原型，如瓦西里所说：我们承认一切圣徒都是我们的中保和代求者，并且说，不但在今世，且在未来的世代里都会有某种代求：因为天使和圣人们将为某些人恳求，而世界的主母也不少于他们；但绝不是为一切人，也绝不为人任何死在罪中的——断然不；因为上帝对这样的人完全关闭了自己的怜悯，为此他启示了以下的事：‘他们中间虽有挪亚、但以理、约伯，也不能因他们的义救自己的儿女’（结 14:14,18）。只有为那些——他们的恳求易于蒙垂听的——人，即以悔改先于自己生命之终、却还未能洗净罪之污秽的人，教会才向上帝恳求；并且只是在审判还在进行的时候。这景象结束后，当每个人被带到指定的刑罚之地，代求就不可能，也就没有代求了。这代求如今也在教会中宣告：我们向圣徒们呼求，也向我们的主母，向圣天使们呼求。向我们的主母——如此：‘至圣圣母上帝之母，为我们罪人祈祷’；向圣天使们如此：‘天上诸品圣天使总领天使们，为我们罪人祈祷’——同样向主的先驱施洗者先知、向光荣的使徒、先知、殉道者、修士、牧者们、普世的教师们和其余一切圣人。我们也求圣妇们的团契为我们罪人祈祷；我们求上帝，愿他按自己的恩典和十字架不可战胜、不可测度的神圣能力，怜悯我们这些事奉他、居于宣信和忏悔之中、求我们心灵之眼得蒙光照的人，好叫我们不至于在罪中睡着而死亡，叫仇敌不能在我们身上得逞。这样，藉我们所说的这一切人的代求，我们求上帝怜悯我们，把我们从恶者的网罗中救出。”

# 对批评的回应
## “你们删去了上帝十诫中的一诫”
你们守**第四**条关于安息日安息的诫命吗？安息日里你们什么工都不作吗？你们把安息日作工的弟兄姊妹杀了吗？你们为亵渎或拜偶像杀人吗？如果你们不作这些，那是为什么？难道你们没有删去上帝的诫命？为什么忽略了这一点：你们自己不守第四诫，却要求遵守第二诫？
摩西的律法被废除了。基督徒跟随基督。第二诫显然不禁止像及其敬礼，因为上帝命令在自己的殿里制作像，命令敬重圣殿，而先知们在带像的圣物前叩拜。诫命禁止的是描绘上帝，以及禁止拜偶像（敬礼并事奉假神）。
## “你们向圣像献香，如以色列人向尼忽士但献香”
以色列人的错误不在于献香（献香是上帝自己设立的），而在于他们虚构了一个假神，称它为尼忽士但，并且不再事奉上帝，而是事奉他们所虚构的尼忽士但——显然是把物件本身当作神明，以色列人中一向如此（详见[[ru:поклоны-Нехуштан|详见]]）。被虚构的不只是名字，还有讨尼忽士但喜悦的方式，随之而来的是它的虚构意志（诫命）。这就是拜偶像，即事奉假神。它使人离开上帝和按他旨意的生活，把人引向按尼忽士但（其作者）意志的生活。
正教徒描绘的是真上帝，称他的本名，遵守他的诫命，不把物件（圣像）当作神；他们叩拜和献香不是向圣像，而是向上帝。这不是拜偶像，因为这里连假神都没有，也没有对假神的事奉——不像尼忽士但的仆役们那样。
## “上帝说了描绘，但没有说敬礼”
不是这样。在圣经里可以看到：上帝既命令制作像，也命令敬礼它们。圣经里有敬礼像的实践。
上帝命令敬礼圣殿——而圣殿按上帝自己的构想，就是天上实体的像（圣像）。先知大卫向带像的圣殿叩拜；先知约书亚向带像的约柜叩拜。这样，敬礼像是上帝命令的，先知们也敬礼了带像的圣物，在它们面前叩拜。毫无疑问，先知们把这敬礼归于上帝：就是说，敬礼像，就是敬礼原型。正教基督徒所作的正是同样的事。
## “以防万一，还是把圣像撤掉吧”
听了我们的解释之后，反对敬礼圣像的人常会同意我们的圣像敬礼是允许的；但他们说，不是我们所有人都足够好地认识教会的教训，仍有人把圣像当偶像对待；所以——他们说——最好把圣像撤掉，以免绊倒。
我们不同意，因为圣像是需要的，而对它们的错误态度应当藉教育、藉解释正确的信仰来消除。
有些人错误地理解圣经；然而这并不迫使我们为了避免绊倒而拒绝圣经。这只会使我们必须进行教育、正确地解释圣经的话语。

# 结论
这样，我们认为，那些把敬礼圣像与敬拜假神（偶像）混为一谈的人是错误的；指控正教徒拜偶像，是对信徒的不公正的指控，是对正教信仰的歪曲观念。
圣像只是关于上帝、人、事件的正确的解释和提醒；它既不被当作上帝敬礼，也不被当作代替上帝的东西敬礼。我们对与上帝相关之物表现出基本的敬意：如同人们尊敬国旗，不是为那特别的布料，而是为尊敬国家本身；尊敬总统的画像，不是为纸张和颜料的质量，而是为总统本人；尊敬十字架和福音书，不是为名贵的木料和书的材料，而是因为上帝在十字架上为我们的得救被钉，而书里写着他救恩的话语。
圣像被召帮助人对上帝、他的母亲和他的朋友们表达敬意。圣像可以帮助人在祈祷中集中注意力，把思想引向上帝。
有时，完全不是出于我们的意愿，上帝亲自藉圣像和其他物件显明奇迹和医治；这自然使我们想到对这物件特别的敬意——但不是代替上帝，而是为了上帝：如同上帝有一次对先知摩西说到必须敬重圣地那样：
> ish 3:5 :: !你所站之地是圣地
先知大卫也对圣物心存敬畏，向圣物叩拜：
> ps 99:5 :: !在他脚凳前下拜
而对那些没有这种敬畏的人，上帝赐下致死的刑罚：
| 反而**自高自大，抵抗上天的大主，命人将他殿宇的器皿给你拿来**，供你和你的大臣并你的妻妾用来饮酒，并且你赞美那些不能看，不能听，不能知的金、银、铜、铁、木、石制的神像，却不知尊崇那掌握你的气息，注定你一切命途的天主。**当夜加色丁王贝耳沙匝即为人所杀。** ||| sb dan 5:23,30
这样，简单地说：当敬礼的是假神或指向假神之物时，这就是拜偶像，即敬礼并叩拜假神（偶像）。对这样的人、物件和像的宗教性敬礼，正教会不教导，并且谴责。
对真上帝的敬礼引向对一切与他相关之物的敬礼。上帝被当作上帝敬礼，而他的朋友们和忠心的仆人们——被当作他的朋友和忠心仆人敬礼，而不是被当作上帝。王被尊敬为王，而他的近臣——被尊敬为近臣，而不是王。在这样的敬礼里没有假神。正教会教导的正是这样的信仰。
