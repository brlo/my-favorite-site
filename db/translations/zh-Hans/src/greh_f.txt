# 异端的定义
**异端**（古希腊文 <a href="https://bibleox.com/ru/words/%CE%B1%CE%B9%CF%81%CE%B5%CF%83%CE%B9%CF%82">αἵρεσις</a> ——派别、学说、学派、选择）——是后来产生的、在先前学说之观念上形成的独立学说，通常与之相对立。异端的追随者认为他们所由分出的那个学说是错误的，也同样遭到对方的回敬。
在圣经的语境中，任何对信理的重大歪曲都被称为异端：
- **法利赛人**——关于救恩的错误学说。在很大程度上，他们把救恩仅仅归结为严格遵守外在的规条；
- **撒都该人**——关于属灵现实的错误学说。他们否认属灵的现实：灵魂在身体死后的生命、神灵和天使的存在、死人的复活；
- **许米乃和腓理徒的学说**——关于复活的错误学说。他们教导说复活已经在过去完成了；
- **尼哥拉一党人**——关于道德生活的错误学说。他们容许肉体的淫乱。
这些异端都不直接涉及关于上帝的教义，而是涉及信理的某些其他方面，然而它们仍然是异端。

# 反对耶稣基督的人曾把他的教导视为异端之一
控告基督使徒的人称基督的教导为拿撒勒异端（基督在拿撒勒长大——[[in 1:45-46]]）：
> act 24:5 :: !拿撒勒教党
使徒们确认，法利赛人和撒都该人把他们的教导视为异端：
> act 24:14 :: !他们所称为异端的道
在公会中，基督的教导被视为众多派别之一。法利赛人迦玛列列举了新派别的例子：
> act 5:34-37 :: !从前丢大起来 :: !又有加利利的犹大起来
另见：[[lk 23:2]]、[[in 7:12]]。
## 为什么基督的教导不是异端？
简言之，因为他是上帝（[[ru:Христос-Бог|引文]]）、是真理（[[in 14:6]]）、是立法者（「你们听见有吩咐古人的话说：&lt;…&gt;只是我告诉你们」——[[mf 5:21-22]]）。
只有那些不承认耶稣是基督、是上帝，不相信他就是那位与亚伯拉罕、以撒和雅各说话的上帝和立法者（[[ish 3:15]]；[[in 8:25]]）、就是那位赐给以色列律法（[[gal 3:19]]）、差遣先知到以色列的上帝（[[mf 23:34]]）的人，才把基督的教导视为虚假的、独立的。由于耶稣基督是上帝，作为立法者，他来更改了他自己所立的秩序，把他自己的葡萄园转给别人（[[lk 20:16]]；[[mk 12:9]]）。
因此，只有不信基督的人才把基督的教导称为异端；信基督的人则认为他的教导是唯一真实的（[[2in 1:9]]；[[in 3:36]]）。然而，基督和使徒们曾警告说，在他们之后会出现虚假的教导，但必须持守那一次传给教会的：
> iud 1:3 :: !要为从前一次交付圣徒的真道竭力的争辩
## 凡讲到耶稣基督的教导，都因为它讲到基督而是真实的吗？
使徒们警告说，别人可能传讲另一个耶稣、另一个福音，并给人另一个灵：
> 2kor 11:3-4 :: !假如有人来另传一个耶稣，不是我们所传过的 :: !或者你们另受一个灵，不是你们所受过的 :: !或者另得一个福音，不是你们所得过的

## 假师傅的手法
### 动听的学说
假师傅们将要编出动听的学说，正是因为他们的听众将寻求悦耳的学说，忍受不了纯正的教导：
> 2tim 4:3 :: !耳朵发痒，就随从自己的情欲，增添好些师傅
> 1tim 4:1-2 :: !必有人离弃真道，听从那引诱人的邪灵和鬼魔的道理
### 虚假的敬虔
> 2tim 3:1-2,5,7-8 :: !末世必有危险的日子来到 :: !有敬虔的外貌，却背了敬虔的实意 :: !这等人也怎样敌挡真道
> mf 7:15 :: !你们要防备假先知。他们到你们这里来，外面披着羊皮，里面却是残暴的狼
### 奇迹
使徒们和古代基督徒被赐予丰富的行异能之力，不是为了作秀，而是为了益处：
> 1kor 12:7 :: !圣灵显在各人身上，是叫人得益处
一小群渔夫需要很大的帮助，才能在短短一生中把传道传遍全世界。使徒们曾警告说，这些恩赐将要止息：
> 1kor 13:8 :: !先知讲道之能，终必归于无有；说方言之能，终必停止
基督自己也斥责寻求奇迹：
> mf 12:39 :: !一个邪恶、淫乱的世代求看神迹
在末后的时代，假先知将恰恰以奇迹引诱人：
> mf 24:24; mk 13:22 :: !因为假基督、假先知将要起来，显大神迹、大奇事
结果，在审判时，许多信徒将确信自己得救正是因为他们奉基督的名行异能、说预言、赶鬼。但他们受了欺骗，被教导行不法之事，基督不认识他们，把他们从自己面前赶走：
> mf 7:22-23 :: !奉你的名行许多异能吗 :: !我从来不认识你们，你们这些作恶的人，离开我去吧
# 一世纪异端的例子
## 法利赛人
使徒们称法利赛人的教导为异端（独立的、错误的学说）：
> act 15:5 :: !惟有几个信徒是法利赛教门的人
从法利赛人中出来的信徒认为，外邦人要得救，必须受割礼并遵守摩西的律法。
传道者马太也指出法利赛人和撒都该人教导的危险：
> mf 16:6,11-12 :: !防备法利赛人和撒都该人的酵 :: !乃是防备法利赛人和撒都该人的教训
## 撒都该人
使徒们称撒都该人的教导为异端（独立的、错误的学说）：
> act 5:17 :: !撒都该教门的人
撒都该人的教导否认死人复活、灵魂的死后生命、天使和神灵的存在：
> mk 12:18,24,26-27 :: !撒都该人常说没有复活的事 :: !你们所以错了，岂不是因为不明白圣经，不晓得上帝的大能吗 :: !论到死人复活，你们没有念过摩西的书 :: !上帝不是死人的上帝，乃是活人的上帝
> act 23:8 :: !因为撒都该人说没有复活，也没有天使和鬼魂
法利赛人与撒都该人相争：
> act 23:6-8 :: !保罗看出大众一半是撒都该人，一半是法利赛人 :: !法利赛人和撒都该人就争论起来，会众分为两党
## 许米乃和腓理徒的学说
背离真理的许米乃和腓理徒的学说。他们既然背离了真理，就是说他们以前曾是基督徒。如今他们错误地教导复活，这显然是即将传播的异端，必须远离：
> 2tim 2:16-19 :: !他们的话如同毒疮，越烂越大 :: !其中有许米乃和腓理徒 :: !他们偏离了真道，说复活的事已过 :: !凡称呼主名的人总要离开不义
## 尼哥拉一党人
主耶稣基督憎恶尼哥拉一党人的教导，也就是说，他们的教导显然是异端：
> otkr 2:15 :: !你那里也有人照样服从了尼哥拉一党人的教训
> otkr 2:6 :: !你恨恶尼哥拉一党人的行为，这也是我所恨恶的
# 二世纪异端的例子
圣殉道者护教者查士丁（约100-165）写道，有些人虽然自称基督徒、承认被钉十字架的耶稣是主和基督，却传讲谎言之灵的教导，即独立的虚假学说（异端）：
<blockquote><p>有些人<strong>自称是基督徒，承认被钉十字架的耶稣是主和基督，却传讲谎言之灵的教导，而不是他的教导</strong>……我们不与他们中的任何一位相通。</p></blockquote>
（<a href="https://bibleox.com/ru/ru/w/Иустин_Философ-разговор_с_Трифоном_иудеем">《与特来弗对话录》</a>）
里昂的圣依勒内（约130-202）也写到无数的基督教异端。例如，他写到护教者查士丁的门徒塔提安：在查士丁殉道之前，塔提安未曾说过异端，而在那之后却编造了自己的学说：
<blockquote><p>1. 从上述的（假师傅们）已经分出了许多异端的许多支派，因为<strong>许多人，甚至所有人，都愿意自己做师傅，离开他们原先所持守的异端。他们从另一套意见体系编造出学说，然后又由此编出另一种，力图教导新的东西，把自己当作所编学说的发明者</strong>。例如：所谓的克己派（Encratites），出自撒土尼努和马吉安，<strong>宣讲独身</strong>，拒绝上帝起初的创造，间接指摘那位为人的生育造了男性和女性的那一位；他们又<strong>戒绝食用动物</strong>，对造万物的上帝忘恩负义。他们<strong>还否认太初之人得救</strong>；不过这意见是他们中间很晚才发明的。首先提出这一亵渎的是塔提安：他作查士丁的门徒时，与他在一起，从未说过这样的话；但在查士丁殉道之后，他离开了教会，因想作高人一等的师傅而受此思想激动，编造了自己独特的学说体系。他像华伦提努派一样杜撰某些不可见的艾翁，又像马吉安和撒土尼努一样宣称婚姻是玷污和奸淫，并且凭自己否认亚当得救。</p><p>2. 另一些人相反，追随巴西理德和卡波克拉特，引入了不法同居、多妻制和对祭偶像之物的随意取用，声称上帝并不怎么在意这些。但何必再往下说呢？<strong>无法一一列举那些以这种或那种方式脱离真理的人</strong>。</p></blockquote>
（<a href="https://bibleox.com/ru/ru/w/Ириней_Лионский-Против_ересей#HH-Глава-XXVIII-Учение-Татиана-энкратитов-и-других">《驳异端》第28章</a>）

# 批评
## 你们不羡慕奇迹吗
异端的拥护者常常试图用奇迹、医治和赶鬼把自己的团体拉人。为此他们引用这样的话：
> 1kor 14:1 :: !你们要追求爱，也要切慕属灵的恩赐
他们也用这节经文指摘教会不羡慕，因此教会里没有大规模的奇迹展示。
然而，使徒们和古代基督徒被赐予丰富的行异能之力，不是为了作秀，而是为了益处：
> 1kor 12:7 :: !圣灵显在各人身上，是叫人得益处
一小群渔夫需要很大的帮助，才能在短短一生中把传道传遍全世界。使徒们曾警告说，这些恩赐将要止息：
> 1kor 13:8 :: !先知讲道之能，终必归于无有；说方言之能，终必停止
基督自己也斥责寻求奇迹：
> mf 12:39 :: !一个邪恶、淫乱的世代求看神迹
在末后的时代，假先知将恰恰以奇迹引诱人：
> mf 24:24; mk 13:22 :: !因为假基督、假先知将要起来，显大神迹、大奇事
结果，在审判时，许多信徒将确信自己得救正是因为他们奉基督的名行异能、说预言、赶鬼。但他们受了欺骗，被教导行不法之事，基督不认识他们，把他们从自己面前赶走：
> mf 7:22-23 :: !奉你的名行许多异能吗 :: !我从来不认识你们，你们这些作恶的人，离开我去吧
## 你们没有爱心
在与脱离教会的团体拥护者交谈时，常常出现这样的防卫反应：避开所讨论的话题，试图转到讨论对方的为人及其品质。这通常发生在出现难以回答的问题之后。无论你多么有分寸、有礼貌，你仍然可能被指控：
- 论断人；
- 骄傲；
- 没有爱心。
**说论断人**——因为你说在异端中不能得救。然而，说这话的是使徒（[[gal 5:20]]）和从一世纪起的圣教父（[[ru:7Ut6v4xr_Спасение_возможно_только_в_Церкви|引文]]）。主赐了不要定人罪的诫命（[[lk 6:37]]），但另一方面也说要按公义判断（[[in 7:24]]）。
**说骄傲**——因为你说[[ru:X7l9DcTY_Спасение_возможно_только_в_Церкви|只有基督的教会才能得救]]，教会是唯一的、有形的、合一的（[[ru:Церковь|引文]]）。然而圣经中也这样说：基督是身体的（教会的）救主（[[ef 5:23]]），离了基督没有人能得救（[[ru:Иисус_Христос-единственный-спаситель-человечества|引文]]）。圣教父们说的也是同样的话（[[ru:7Ut6v4xr_Спасение_возможно_только_в_Церкви|引文]]）。
至于**爱心**。毫无疑问，基督徒应当温良、谦卑、始终出于爱心行事。但爱可以而且应当是什么样的呢？我们不能指摘主耶稣基督和使徒们缺乏爱心。同时，我们在圣经中遇到这样的教导：
> pr 3:11-12 :: !因为耶和华所爱的，他必责备
> evr 12:6 :: !因为主所爱的，他必管教
> otkr 3:19 :: !凡我所疼爱的，我就责备管教他
> iov 5:17-18 :: !上帝所惩治的人是有福的 :: !他打破，又缠裹
因此必须记得：如果我们把一切指摘都当作仇恨的表现，那就等于指摘上帝和使徒们有仇恨——他们不仅自己指摘谎言，还召人这样做：
> ef 5:11 :: !倒要责备行这事的人
指出某种学说的虚假，可能不只是仇恨的表现（有些人确实出于骄傲和仇恨这样做），也可以是爱心的表现、对近人的关怀、愿他得救的意愿：
> iak 5:19-20 :: !你们中间若有失迷真道的 :: !便是救一个灵魂不死，并且遮盖许多的罪
应当努力永不羞辱任何人，也不要让谈话转入对个人的讨论——在那里往往开始彼此定罪。应当谈学说，而不是谈人的品质。
