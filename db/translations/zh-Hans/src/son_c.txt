# 前言
首先要说明：“基督就是天使长米迦勒”的说法存在于“耶和华见证人”这一极端教派中。耶和华见证人为论证自己的教导，制造了自己歪曲甚多的圣经译本（专家对该派《新世界》译本的评述见 <a href="https://azbyka.ru/otechnik/sekty/rassuzhdaja-so-svideteljami-iegovy-pri-pomoshhi-pisanija/4_7">azbyka.ru</a>）。此外，基督复临安息日会也有人认为，旧约中以天使长米迦勒身份出现的那一位似乎就是上帝之子耶稣基督。
# “天使”一词的两个含义
在圣经中，“天使”一词有两种理解：职能与本性。
天使的**职能**是奉差遣，因为这个词在古希腊文中字面上正是这个意思：ἄγγελος（天使罗思）——使者、报信者；希伯来文 מלאך——使者。
天使的**本性**是无形体的灵。天使是被上帝所造的灵体，没有身体（无形的），换言之就是灵。这些灵在被造之先于人类，被赋予了自由与理性。他们中有一部分不愿顺服上帝，从他堕落了，但仍然被称为天使（[[mf 25:41]]）。也就是说，本性独立于活动：无论是否奉差遣，都是天使。本性就是如此。因此，一个由人所生的、完全具体的人——先知施洗约翰——也被称为天使（[[mal 3:1]]；[[mf 11:10]]；[[mk 1:2]]；[[lk 7:27]]）。同样含义下，基督自己也被称为新约的使者（[[mal 3:1]]）。这个说清楚了。现在来看引文。
# 所有天使都是服役的灵，而基督坐在宝座上
使徒保罗称上帝之子是远比天使更尊贵的存在（[[evr 1:4]]），因为上帝从不以对待自己儿子的方式对天使说话（[[evr 1:5]]），上帝的儿子要受所有天使的敬拜（[[evr 1:6]]）；他指出上帝论到天使和论到上帝之子的话语各不相同：前者是服役的灵，后者是坐在宝座上的主宰（[[evr 1:7-8]] 与 [[evr 1:13]]）；并指出一切受造之物的短暂，但创造了万有的上帝之子自己永不废去（[[evr 1:10-12]]）。最后，圣经直说：所有天使无一例外都是服役的灵，但子是与父同坐在宝座上的：
> evr 1:13-14 :: 坐在我的右边 :: 服役的灵
儿子受服役，而子与父一同作王。
# 上帝要受人敬拜，基督受一切受造物的敬拜
上帝说，万膝必向他跪拜（[[rim 14:11]]）；而基督受一切受造物的敬拜——不只是人（[[fil 2:10]]），包括天使（[[evr 1:6]]）。
# 世界交给了基督，不是交给天使
> evr 2:5 :: 上帝原没有交给天使管辖
同时，世界交给了基督：
> 1kor 15:27 :: 上帝叫万物都服在他的脚下
> ef 1:22 :: 又将万有服在他的脚下
> evr 2:8 :: 叫万物都服在他的脚下
# 全能者、万王之王、万主之主
先知称**上帝**为万主之主（[[ps 136:2-3]]）。使徒称**上帝**为万主之主、万王之王（[[1tim 6:15-16]]）。使徒称**耶稣基督**为万主之主、万王之王（[[otkr 17:14]]；[[otkr 19:16]]），为全能者（[[otkr 1:8]]）。万王之王之上没有别的王。万主之主之上没有别的主。全能者之上没有任何存在能托住全能者，因为他自己以自己的能力托住万有。天使长米迦勒是天使军团的君长。基督却是世上一切——包括天使和天使长米迦勒本身——的元首。
# 上帝（耶和华）亲自差遣先知，而基督说，正是他差遣了他们
应当指出：基督指明，他就是那位向以色列差遣了许多先知的（[[mf 23:34]]）。而圣经告诉我们，正是上帝亲自（而非借天使）向先知说话，并亲自把他们差往以色列（[[ish 3:12]]；[[mal 4:1]]、[[mal 4:5]]；[[sud 6:8]]；[[2par 25:15]]；[[1ts 15:1]]；[[2ts 12:1]]；[[2ts 12:7]]）。也就是说，基督就是耶和华上帝。在上帝与先知的交往中，没有中间人。
# 上帝之子由父所生，他创造了天使
基督是一切看得见与看不见之物的创造者，包括天使（[[kol 1:13-17]]）。也就是说，他要成为天使，就得先造出他自己。
# “米迦勒”之名的词源
米迦勒是希伯来名字，源自 מי כמו אלוהים（米·克莫·埃洛希姆，缩略为“米·卡·埃尔”），字面意思是“谁能像上帝”。也就是说——没有谁与上帝同等，没有谁能与他相比。但基督并不认为自己与上帝同等是强夺的（[[fil 2:6]]）。
# 旧约借天使赐下，新约由主亲自宣讲
使徒保罗指出新约与旧约的区别：旧约借天使传的（[[evr 2:2]]），而新约由主自己亲自宣讲（[[evr 2:3]]）。也就是说，至少不是借天使。
# 上帝成为人，向天使显现
> 1tim 3:16 :: 上帝在肉身显现 :: 被天使看见
从来没有人看见上帝（[[in 1:18]]），他住在人不能靠近的光里，人不可能看见上帝（[[1tim 6:16]]）；然而，上帝一旦真正成为人（[[in 1:14]]），就在基督里成为人人可见的。人不能凭肉眼看见灵界（天使）的居民，但基督却说自己看见了从天坠落的撒但（[[lk 10:18]]）。
# 结语
基督不是天使长米迦勒，而是上帝。他多次被直接称为上帝。圣经对此直言不讳：[[ru:Христос-Бог|基督是上帝]]
> ps 50:7 :: 我的民哪！你们当听我的话 :: 我是上帝，是你的上帝
