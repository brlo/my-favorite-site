# 七十士译本（LXX）——是什么？
**七十士译本**（拉丁文 Septuaginta——“七十”，简称 LXX）——旧约书卷的译本，于公元前III-II世纪由七十位（72位）犹太释经者从希伯来文译成古希腊文。
除这个希腊文本外，还有希伯来文的文本——马所拉文本。
**马所拉文本**——旧约圣经的希伯来文本，公元VII-X世纪在其上加上了元音符号。什么是元音符号？简单地说，就是词上面的各种小点和勾勾，它们指出词中缺失的元音和读音的特点，使人能正确读出这个词。这些符号叫作区别符号。因为希伯来文本只由辅音字母组成，所以只有知道诵读传统（圣传）的人才能正确诵读。加上元音符号，是为了使文本的读法成为唯一的。
七十士译本之所以重要，是因为它是犹太人自己的文本，而且是在犹太民族拒绝耶稣为基督、为上帝**之前**就完成的。也就是说，那时还没有必要把圣经解释成让主耶稣基督在其中越来越没有位置。另外还要考虑到，任何翻译都同时是一种解释。在这里，七十士译本是由通晓语言和传统的人所作的解释-翻译：从难以诵读的希伯来文译成许多人易懂的希腊文。
# 童女还是少女
福音史家马太引用以赛亚关于基督由童女而生的预言：
> mf 1:23 :: !必有童女怀孕生子
这里“童女”在希腊文里是 παρθένος。

> is 7:14 :: !必有童女怀孕生子
而按马所拉文本，基督由未出嫁的少女而生：希伯来文 עַלְמָ֗ה [al-maw']。

# “使瞎眼的得看见”还是“被囚的出监牢”

在七十士译本里，此处有“使瞎眼的得看见”一语（希腊文 τυφλοῖς ἀνάβλεψιν）：
| Πνεῦμα κυρίου ἐπ᾿ ἐμέ, οὗ εἵνεκεν ἔχρισέν με· εὐαγγελίσασθαι πτωχοῖς ἀπέσταλκέν με, ἰάσασθαι τοὺς συντετριμμένους τῇ καρδίᾳ, κηρύξαι αἰχμαλώτοις ἄφεσιν **καὶ τυφλοῖς ἀνάβλεψιν**, καλέσαι ἐνιαυτὸν κυρίου δεκτὸν καὶ ἡμέραν ἀνταποδόσεως, παρακαλέσαι πάντας τοὺς πενθοῦντας ||| gr is 61:1-2

# 手脚被扎了，还是被狮子撕裂？
七十士译本里有关于基督的预言：
> ps 22:16 :: !他们扎了我的手、我的脚
晚出的马所拉文本在[[ps 22:16]]（诗 22:16）里没有关于扎手扎脚的话，那里是“狮子”一词。文本里根本没有“撕裂”的动词，而且狮子的动作与手脚有什么关系也不清楚。
然而，正确的仍然是“扎了”。库姆兰古卷 4Q88 证实手脚被扎（详见[[ru:пророчества-о-Христе|关于基督的预言]]）。
此外，还有一个关于“扎”的预言。它在这里被引用：
> in 19:37 :: !他们要仰望自己所扎的人
所引的出处：
> zah 12:10 :: !他们所扎的
希伯来原文：“וְהִבִּיטוּ אֵלַי אֵת אֲשֶׁר־**דָּקָרוּ**”（[希伯来文原典](https://bibleox.com/zh-Hans/heb-osm/zah/12/#L10)，亚 12:10）
דָּקָר——扎、刺穿；被刺穿、被扎透。
库姆兰卷 4Q80 也证实是“扎”。
