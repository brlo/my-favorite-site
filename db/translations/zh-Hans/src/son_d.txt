# 耶稣基督降生在伯利恒
> mf 2:1; lk 2:4-7 :: 生在犹太的伯利恒
<em>这应验了预言：[[mf 2:5]]；[[in 7:42]]；[[mih 5:2]]。</em>
# 逃往埃及
降生以后，约瑟和童贞女马利亚为躲避希律王的追杀，把婴孩耶稣带到埃及去了几年（[[mf 2:16]]）：
> mf 2:14-15 :: 往埃及去 :: 住在那里，直到希律死了
<em>这应验了主借先知所说的话：[[mf 2:15]]；[[os 11:1]]。</em>
# 返回拿撒勒
然后他们回到约瑟在拿撒勒的家（[[lk 2:4]]）：
> mf 2:20-23 :: 把小孩子和他母亲带到以色列地去 :: 加利利境内 :: 拿撒勒
<em>这应验了预言：[[mf 2:23]]；可能还有 [[sud 13:5]]。</em>
# 每年上耶路撒冷
每年，耶稣基督都与父母、亲属和熟人一起上耶路撒冷的圣殿守节（[[lk 2:43-44]]）：
> lk 2:41-42 :: 每年到逾越节，他父母就上耶路撒冷去 :: 当他十二岁的时候
到十二岁时，孩童耶稣已具有令耶路撒冷圣殿中的教师惊讶的智慧：
> lk 2:41-42,46-47 :: 当他十二岁的时候 :: 在殿里，坐在教师中间 :: 凡听见他的，都希奇他的聪明和他的应对
十二岁以后，基督也住在拿撒勒，顺从父母：
> lk 2:51 :: 回到拿撒勒．并且顺从他们
# 从拿撒勒迁往迦百农：传道的开始
满了三十岁、在先知约翰那里受洗之后，基督才离开拿撒勒，迁往迦百农，开始宣讲：
> mf 4:12-13 :: 后又离开拿撒勒，往迦百农去，就住在那里
<em>这应验了预言：[[mf 4:14-16]]；[[is 9:1-2]]。</em>
# 若干细节
## 加利利人都熟悉耶稣是木匠的儿子
在加利利传道时，人们都熟悉耶稣基督，知道他是普通的木匠、木匠的儿子：
> mk 6:3 :: 这不是那木匠吗
> mf 13:55 :: 这不是木匠的儿子吗
## 为守律法而常上圣殿
为遵守律法，基督每年要三次上耶路撒冷的圣殿：
> ish 23:17 :: 一切的男丁，要一年三次朝见主耶和华
> ish 34:23 :: 一切男丁，要一年三次
> vtor 16:16 :: 一切的男丁 :: 除酵节、七七节、住棚节，一年三次
## 基督遵行了律法
> mf 5:17 :: 律法 :: 不是要废掉，乃是要成全
> mf 3:15 :: 我们理当这样尽诸般的义
> mf 26:24; mk 14:21 :: 人子必要去世，正如经上指着他所写的
> lk 24:44 :: 摩西的律法 :: 先知的书 :: 诗篇
> gal 4:4 :: 为女子所生 :: 生在律法以下
## 等候满龄才开始传道
基督直到三十岁才传道行神迹，因为按上帝的定规和既成的传统，公共事奉从三十岁开始（[[chis 4:3]]）。因此，来不是要废掉律法、乃是要成全的基督（[[mf 5:17]]），等候到三十岁才出来传道：
> lk 3:23 :: 开头传道，年纪约有三十岁
