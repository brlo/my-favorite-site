# 题词
> ps 50:7 :: 我是上帝，是你的上帝
# 使徒在众人面前称基督为上帝，基督认可了他的信仰（[[in 20:28-29]]）
这是最无可争辩的一段。这里具备一切必要的条件，使人确信使徒是把他当作真上帝来信的：在场没有一个使徒反驳他，连基督自己也认可了这信仰。这里的「θεὸς」（上帝）一词甚至带有冠词「ὁ」——这就排除了反对方的一切异议。这节经文让人看到，基督所被称为的，正是最高意义上的那同一位上帝：
> in 20:28-29 :: 我的主！我的上帝！ :: 你因看见了我才信
| Ὁ κύριός μου καὶ ὁ θεός μου. λέγει αὐτῷ ὁ Ἰησοῦς, Ὅτι ἑώρακάς με πεπίστευκας; μακάριοι οἱ μὴ ἰδόντες καὶ πιστεύσαντες ||| gr in 20:28-29
对此，基督神性教导的反对者只会用一句缺乏说服力的话来搪塞，说：「使徒不过是太激动，因惊讶而喊叫」。但这与经文相矛盾，因为经文直说，多马是对着基督本人说的：「**对他说**」，也就是说，「我的主！我的上帝！」这句话按文本正是对基督的称呼。
使徒这样称呼基督，没有一个人纠正他，而基督自己也认可了他的信仰，说：「你因看见了我才信」。显然，他所信的是基督的复活；但得了这信仰，他随即表明他所信的是什么：信基督是上帝。这里满足批评者的一切语法要求：话是使徒说的，是在基督与众使徒面前说的，无人反对，基督还加以认可。如果这都不能说服不信的人，那还有什么能说服他们呢？
# 基督是在万有之上、永远可称颂的上帝（[[rim 9:3-5]]）
使徒在最高意义上称基督为上帝：
> rim 9:3-5 :: 基督 :: 在万有之上，永远可称颂的上帝
| ὁ Χριστὸς τὸ κατὰ σάρκα· ὁ ὢν ἐπὶ πάντων θεὸς εὐλογητὸς εἰς τοὺς αἰῶνας, ἀμήν ||| gr rim 9:5
基督神性教导的反对者会反驳说，这里「θεὸς」（上帝）一词缺少冠词，所以基督在这里似乎不是在最高意义上被称为上帝（仿佛这不是他自己的属性），或者说「上帝」一词根本不属于基督。
对此有不同见解。有理由认为，冠在这一切描述同一位人物的定语之前的共同指涉冠词已经足够：「ὁ ὢν ἐπὶ πάντων θεὸς」（在万有之上、永远可称颂的上帝）。何况「上帝」一词带冠词而属于基督的例子，我们一开始已经举过（[[in 20:28-29]]）。如果这里缺少冠词，那么那里还缺少什么，才能叫人相信呢？
# 基督是真上帝（[[1in 5:20]]）
> 1in 5:20 :: 耶稣基督里面。这是真神
| καὶ ἐσμὲν ἐν τῷ ἀληθινῷ, ἐν τῷ υἱῷ αὐτοῦ Ἰησοῦ Χριστῷ. οὗτός ἐστιν ὁ ἀληθινὸς θεὸς καὶ ζωὴ αἰώνιος ||| gr 1in 5:20
使徒约翰写「这是」（οὗτός ἐστιν）的时候，这个代词所指的是紧接在前面一句中的「耶稣基督」（Ἰησοῦ Χριστῷ）之名。这是最近的先行词。「θεὸς」前的冠词「ὁ」强调，这是刚刚所谈论之人的确定的属性，即耶稣基督的属性。语法上和逻辑上，这里说的是：「这位【耶稣基督】是真上帝，是永生。」
# 上帝用自己的血买来了教会（[[act 20:28]]）
这节经文指明基督的神性，因为这里被称为上帝的，正是用自己的血买来教会的那一位。神性没有血；血只有成了肉身的儿子才有。这里被称为上帝、用自己的血买来教会的，正是儿子：
> act 20:28 :: 上帝的教会 :: 用自己血所买来的
| ποιμαίνειν τὴν ἐκκλησίαν τοῦ θεοῦ, ἣν περιεποιήσατο διὰ τοῦ αἵματος τοῦ ἰδίου ||| gr act 20:28
# 从前无人看见的上帝，在肉身显现，将自己表明出来（[[1tim 3:15-16]]）
「上帝在肉身显现」这句话是俄文公会译本如此译的，但希腊文原文这里没有「上帝」一词，代替它的是一个代词「那一位」。然而这个代词指的是上帝，因为紧接着前面说的是上帝：「在上帝的家中当怎样行；这家就是永生上帝的教会」。随后又清楚表明，在这里被称为上帝的正是耶稣基督：因为不是父，而是儿子——即耶稣基督——「在肉身显现」，从而「被天使看见」（父作为上帝仍然不能看见），儿子也在荣耀里被接升天：
> 1tim 3:15-16 :: 在上帝的家中 :: 永生上帝的教会 :: 上帝在肉身显现 :: 被天使看见 :: 被接在荣耀里
| Ὃς ἐφανερώθη ἐν σαρκί, ἐδικαιώθη ἐν πνεύματι, ὤφθη ἀγγέλοις, ἐκηρύχθη ἐν ἔθνεσιν, ἐπιστεύθη ἐν κόσμῳ, ἀνηλήμφθη ἐν δόξῃ ||| gr 1tim 3:16
# 上帝与主耶稣基督（[[2tim 4:1]]、[[2pet 1:1]]）
在这节经文里，耶稣被称为上帝，又被称为基督（「基督」一词译自希腊文，意为「受膏者」，这是对世人所等候的救主的称号，[[act 2:36]]）。俄文公会译本作：「在上帝和我们的主耶稣基督面前」，但希腊文写法略有不同，直译是：「在上帝和基督耶稣面前」（τοῦ θεοῦ καὶ Χριστοῦ Ἰησοῦ）。
有人会反驳说，这里说的是两位：上帝，以及耶稣基督。这种反驳不能成立，因为两个词共用一个冠词「τοῦ」（属格的指涉冠词），也就是说，两个词都指同一个被描述的人物——耶稣。此外，下文的「τοῦ μέλλοντος」（将要审判的）是单数，这进一步表明前文所说的是一个人物：
> 2tim 4:1 :: 上帝面前，并在将来审判活人死人的基督耶稣面前
| Διαμαρτύρομαι ἐνώπιον τοῦ θεοῦ καὶ Χριστοῦ Ἰησοῦ, τοῦ μέλλοντος κρίνειν ζῶντας καὶ νεκρούς ||| gr 2tim 4:1
下面是一个使用同一共同冠词的类似语法结构：
> 1pet 1:3 :: 父上帝
| Εὐλογητὸς ὁ θεὸς καὶ πατὴρ τοῦ κυρίου ἡμῶν Ἰησοῦ Χριστοῦ ||| gr 1pet 1:3
这里「上帝与父」两个词共用一个冠词「ὁ」（主格的指涉冠词），因此两个词描述的是同一位，而不是两位。
以下这处称基督为上帝的结构，也服从同一条规则：
> 2pet 1:1 :: 上帝和救主耶稣基督
| ἐν δικαιοσύνῃ τοῦ θεοῦ ἡμῶν καὶ σωτῆρος Ἰησοῦ Χριστοῦ ||| gr 2pet 1:1
# 福音书作者路加称基督为上帝（[[lk 8:39]]）
来看福音书作者路加所记的一节。引文的前半是耶稣基督的话，后半是叙述者——福音书作者路加——自己的话。基督吩咐痊愈的人去传讲上帝为他所作的事，而福音书作者路加记下，痊愈的人传扬的是耶稣为他所作的事。也就是说，在福音书作者路加的理解中，耶稣与上帝在这里是一回事：
> lk 8:39 :: 上帝为你作了何等大的事 :: 耶稣为他作了何等大的事
| διηγοῦ ὅσα σοι ἐποίησεν ὁ θεός … κηρύσσων ὅσα ἐποίησεν αὐτῷ ὁ Ἰησοῦς ||| gr lk 8:39
如果基督神性的反对者反驳说，福音书作者只是描述了痊愈者的行为，说耶稣吩咐他传讲上帝所作的事，而痊愈者误解了，没有传讲上帝所作的事，反倒传讲耶稣所作的事——那么要明白：反对基督神性的人也认为福音书作者路加是否认基督神性的，仿佛路加也不认为基督是上帝。那样的话，福音书作者必定会以某种方式指出痊愈者的错误——他做的完全不是耶稣吩咐他做的事。这至少会表现为用「但是」「然而」之类的转折词：「耶稣说，要回去传讲上帝所作的事，**但是**他却去传扬耶稣所作的事」；更有可能的是，他会直说痊愈者误把耶稣当作上帝，所以传讲的不是上帝，而是耶稣。这不是小事，而是信仰的根基。
但福音书作者没有作任何对比。他使用的是同一结构的重复：「上帝为你作了……耶稣为他作了……」。这是福音书作者相信基督神性的有力明证。

# 上帝道成肉身（[[in 1:1-18]]）
使徒约翰称道为上帝，随后指出道成了肉身。施洗约翰所指向的正是这道成了肉身的道，而他指的是耶稣基督：
> in 1:1-18 :: 道就是上帝 :: 道成了肉身
使徒在这里称基督不仅是父的儿子，而是独生子，意思是：再没有谁像基督那样是父的儿子。他不是长子（最先出生的），而是独生子（独一的儿子）。没有别的儿子。
基督神性教导的反对者会反驳说，在另外两处，基督也被称为长子：
> rim 8:29 :: 在许多弟兄中作长子
> evr 1:6 :: 长子
对此应当说：他被称为长子，是因为他首先从死里复活：他的复活不是复活之后又要死（先知们从前的复活是那样），而是以胜过死亡的改变形象的复活（[[rim 6:9]]），要活到永远，并在荣耀里升天，要作王直到永远——在他以前没有人这样复活过。他首先这样复活，也就是成为长子，或者说从死里的首生者：
> kol 1:18 :: 从死里首先复生的
> otkr 1:5 :: 从死里首先复活
> act 26:23 :: 因从死里复活

# 诗篇论及上帝的话，是论及子说的（[[evr 1:8-12]]）
使徒保罗把先知的诗篇用在基督身上。他说，那些话是论及子说的：
1. 子是上帝。
2. 子立了地的根基，造了天。
3. 子——上帝——受了上帝的膏（希腊文 Χριστός 意为「受膏者」）。
> evr 1:8-12 :: !论到子 :: 上帝啊，你的宝座是永永远远的 :: 上帝，就是你的上帝，用喜乐油膏你 :: !你起初立了地的根基，天也是你手所造的
基督神性教导的反对者会反驳说，这里称上帝用的只是犹太人通用的词 Elohim，这个词既用于真上帝，也用于假神。他们将期待上帝被冠以四字圣名——四个希伯来字母 **יְהוָֽה（YHWH，音「雅威」）**。而使徒所引的诗篇（[[ps 102:25-27]]）恰好满足他们的要求。整篇诗——是向**上帝（יְהוָֽה，YHWH）**的祷告，他在 [[ps 102:20]] 和 [[ps 102:23]] 被称为 **יְהוָֽה**。诗篇的标题是：「困苦人的祷告，他消沉地在**耶和华（יְהוָֽה，YHWH）**面前倾吐苦情」。也就是说，整篇诗——包括使徒所引用的诗句——都是向上帝的祷告，而上帝在其中的称呼正如他们所期待的——耶和华。使徒却说，这是论子说的，也就是说，耶和华——就是子，耶稣基督。

# 耶稣就是旧约里的那同一位上帝（[[mf 23:34]]、[[ier 7:21,25]]）
当人向基督神性的反对者指出，使徒们直呼基督为上帝时，他们反驳说：「仅被称为上帝还不够」——瞧，先知摩西也曾被称为神：
> ish 7:1 :: 我使你在法老面前代替上帝
| Ἰδοὺ δέδωκά σε θεὸν Φαραω, καὶ Ααρων ὁ ἀδελφός σου ἔσται σου προφήτης ||| gr ish 7:1
首先，这里没有满足批评者自己先前提出的要求：上帝一词要带冠词。这里没有冠词。而且从文本可以清楚看到，先知摩西得到的只是相对于法老的一种授予的职能。这里没有任何地方表明摩西按本性就是神，拥有神性作为自己固有的恒常属性。此外，批评者对我们的论证所要求的第二条，在这里也没有满足：希伯来文原文中用的也是通用的「אֱלֹהִ֖ים」（Elohim），而不是四字圣名 YHWH，也就是说，这里说的不是最高意义上的真上帝。
其次，可以完全确信：耶稣基督就是那位真上帝——创造者、耶和华、祖宗的上帝（亚伯拉罕、以撒、雅各的上帝）。例如，基督自己说他曾向以色列差遣先知，而旧约说，向以色列差遣众先知的是上帝耶和华。由此也直接可见：基督就是道成肉身的上帝耶和华。后面还有别的例子。

上帝亲自（不借中间人）向先知说话，并差遣他们：

> 2par 25:15 :: 差一个先知
> 1ts 15:1 :: 耶和华差遣我

> 2ts 12:24-25 :: 藉先知拿单

# 古代抄本
1. 现今的 **[[iud 1:5]]** 作：「我想提醒你们，你们虽然知道这事，主救了他的百姓出埃及地，其后就把不信的灭绝了。」但在保存犹大书信的最古老的蒲草抄本 [[https://en.wikipedia.org/wiki/Papyrus_72|p72]]（三世纪）中，这段文字是这样：「我想提醒你们，你们虽然万事都知道，**上帝基督**（Theos Christos）曾一次救了他的百姓出埃及地，其后就把不信的灭绝了。」
2. 现今文本的 **[[kol 2:2]]** 结尾作：「得以知道上帝和基督的奥秘」。而在保存保罗书信的最古老蒲草抄本 [[https://en.wikipedia.org/wiki/Papyrus_46|p46]]（二世纪末）中，写的是：「得以知道**上帝基督**的奥秘」（tou Theou Hristou）。
3. 在我们手头的文本中，**[[2pet 1:2]]** 作：「愿恩惠、平安因你们认识上帝和我们主耶稣多多地加给你们」。而该书信最古老的抄本作：「愿恩惠、平安因你们认识**上帝耶稣**（tou Theou Iesou），我们的主，多多地加给你们」。
4. 现今的 **[[in 1:18]]** 作：「父怀里的独生子」。而在约翰福音最早的书册——蒲草抄本 [[https://en.wikipedia.org/wiki/Papyrus_75|p75]]（三世纪中叶）和 [[https://en.wikipedia.org/wiki/Papyrus_66|p66]]（二世纪末）中，读到的是：「父怀里的**独一上帝**」。圣里昂的伊里奈乌引用这处时，也是这样。
# 基督——两个世界的居住者：上帝与人
没有能把一只手放在上帝身上、另一只手放在人身上的中保，因为这两个世界互不相触，没有任何东西、任何存在把它们连在一起：
> iov 9:33 :: 我们中间没有听讼的人
而耶稣基督（非受造的上帝与受造的人）自己就联结了这两个世界：
> 1tim 2:5 :: 在上帝和人中间，只有一位中保
