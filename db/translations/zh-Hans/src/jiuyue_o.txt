# 本文论什么
本文以新旧约圣经文本为例，分析希腊词「артос」与「азима」在圣餐礼问题上的用法。
**Артос**（希腊文 ἄρτος）——只是饼，不指明其性质。
**Азима**（希腊文 ἄζυμα）——无酵饼（无酵的饼）。
**Артос азима**（希腊文 ἄρτος ἄζυμα）——无酵的饼。「артос」一词的加添，通常发生在列举不同种类的无酵饼时（无酵的饼、无酵的薄饼）。
对这些希腊词的引用，在历史争论中被用作论据。
# 争论的对象
在关于[[ru:Евхаристия|圣餐礼]]（东正教会的主要圣奥秘）的历史讨论中，一直有争论：主耶稣基督递给使徒们、称之为自己身体时，所用的**饼**是什么。
争论分为两种意见：
- **有酵的饼**（发面的）——东正教会；
- **无酵的饼**（无酵饼）——天主教（起初也用有酵的饼）和新教（有不同做法）。
东正教会——罗马教会直到十一世纪也属于其中——从一开始就在各地使用有酵的饼。当罗马教会脱离正教时，在罗马的诸多新做法中，也考虑到罗马放弃以有酵之饼行圣礼、转用无酵之饼的问题。后来这一问题在与新教各派别的论战中再次成为焦点。
支持在圣餐礼上使用有酵之饼的论据有一系列，其一是「артос」一词。四位传道者（马太、马可、路加、约翰）都用希腊词「**артос**」称呼圣餐的饼，这有理由认为饼是有酵的，因为逾越节晚餐的无酵饼在圣经中总是（无一例外）用希腊词「**азимос**」称呼。而且凡说到无酵饼，几乎总是直接指明它是无酵的。

# 圣经中的「азимос」或「артос азимос」
在圣经中，「артос」通常指有酵的饼，而「азимос」指无酵饼。凡说到逾越节的无酵饼，圣经总是直接说明：或只说**азимос**（无酵饼），或说**артос азимос**（无酵的饼）（通常在列举不同种类无酵饼时）。这对遵行律法是重要的：要指明饼是无酵的。
比如，我们今天称白面包为「面包」，而称黑面包为「黑面包」——这区别对我们未必重要，但对犹太人在律法方面却原则性地重要：饼是不是无酵的。
这样，可以只说「азимос」（无酵的），也可以说「артос азимос」（无酵的饼），但无酵饼从不被只称为「артос」而不提及这饼的无酵性。最常见的是用一个词「азимос」称呼无酵饼。
「артос азимос」（无酵的饼）这一表达出现得少得多。加添其他词是在说到不同种类的无酵饼的时候——形状和做法不同的无酵饼。于是，加 油 做成的饼状无酵饼被称为「артос азимос」（无酵的饼），而薄饼状、抹了油的无酵饼被称为「лагана азима」（无酵的薄饼）。因此在少数情形下会出现这样的组合：
- 无酵的饼；
- 无酵的薄饼。
如果没有列举不同种类的无酵饼，那么几乎总是用一个词称呼：**азимос**。
# 总的画面
## 旧约
逾越节的饼总是被称为无酵的。使用的是：「азима」或「артос азимос」。
## 新约
圣餐的饼从不被称为无酵的。传道者们总是用「артос」一词，完全不提及晚餐上有「азимос」。
# 那么，артос 或许也可以是无酵饼？
东正教会的反对者想证明圣经中任何饼——包括无酵饼——都可称为 артос，举出极罕见的情形（[[ish 29:2]]和[[ish 29:23]]）：那里说的是无酵饼，却只称为「артос」。这正是说到两种不同无酵饼的情形：饼（артос）和薄饼（лагана）。
在详细考察这几节之前，可以先指出：即便在这里，也毫不含糊地指明所说的是无酵的饼：
1. 在[[ish 29:2]]一章的开头，这些饼（饼和薄饼）被称为：无酵的饼和无酵的薄饼。
1. 在[[ish 29:23]]一章的中部，较简短地重复：一个饼和一个薄饼，并立刻指明：「从装无酵饼的筐子中」，即无酵的。
现在详细考察。这些词是希腊文的，因此直接查考七十士译本（LXX）的希腊文本——它是在耶稣基督诞生前两个世纪由七十二位犹太译者译成的。取 LXX 的希腊文文本（附翻译）：
<blockquote><p>καὶ［而］<strong>ἄρτους</strong>［饼］<strong>ἀζύμους</strong>［无酵的］πεφυραμένους［调合了］ἐν［用］ἐλαίῳ［油］καὶ［和］<strong>λάγανα</strong>［薄饼］<strong>ἄζυμα</strong>［无酵的］κεχρισμένα［抹了］ἐν - ἐλαίῳ［油］；σεμίδαλιν［细面］ἐκ［用］πυρῶν［小麦］ποιήσεις［你要作］αὐτά［它们］。（[[ish 29:2]]）</p></blockquote>
这里出现的是：1）**无酵的饼**（ἄρτους ἀζύμους）用油调合（πεφυραμένους ἐν ἐλαίῳ）；2）**无酵的薄饼**（λάγανα ἄζυμα）抹了油（κεχρισμένα ἐν ἐλαίῳ）。七十士译本只提到这两种无酵饼（马所拉文本——三种无酵饼）。随后上帝吩咐要用小麦的细面作成。再看下一节：
<blockquote><p>καὶ［和］<strong>ἄρτον</strong>［饼］ἕνα［一个］ἐξ［从］ἐλαίου［油的］καὶ［和］<strong>λάγανον</strong>［薄饼］ἓν［一个］ἀπὸ［从］τοῦ - κανοῦ［筐子］τῶν - <strong>ἀζύμων</strong>［无酵的］τῶν - προτεθειμένων［摆着的］ἔναντι［在］κυρίου［主］面前。</p></blockquote>
这里提到的仍是第二节中那两个饼：
- 「一个调油的饼」；
- 「一个薄饼」。
并且立刻说明：它们是从装有无酵饼的筐子中取的。况且，在这一章（第2节）已经说过这饼是无酵的。
也就是说，即便在「артос」与「азимос」连用的情形中，每次也都指明饼是无酵的。但此处给「азимос」加添其他词也有原因：这里描述的是不同的无酵饼（饼和薄饼）。如果不用附加的词来描述做法，就成了「取一个无酵饼和无酵饼」，看起来相当奇怪。
由于饼彼此不同，就需要附加的词：
- ἄρτους ἀζύμους（无酵的饼）；
- λάγανα ἄζυμα（无酵的薄饼）。
第二次：
- ἄρτον（饼）；
- λάγανον（薄饼）；
- 从装无酵饼的筐子中（ἀζύμων）。

# 麦基洗德——圣餐礼的预像
先知和使徒们称上帝之子为按麦基洗德等次的祭司：
> evr 5:10; evr 5:6; evr 6:20; evr 7:11; evr 7:17; evr 7:21 :: !照着麦基洗德的等次 ~~ 并见 [[ps 110:4]]（俄文本编号为 Пс 109:4）。
回忆麦基洗德。族长亚伯拉罕遇见了至高上帝的神秘祭司（那时祭司职分还未设立）——撒冷王麦基洗德。麦基洗德拿普通的饼（артос）和酒出来迎接亚伯拉罕，而亚伯拉罕把十分之一献给他（那时什一奉献还未设立）：
> gen 14:18 :: !带着饼和酒
麦基洗德用的只是 артос。
# 吗哪——圣餐礼的预像
旧约中在旷野里赐给犹太人以维持生命的吗哪，是圣餐礼的预像，主耶稣基督亲自指明了这一点。在旧约中，上帝称吗哪为从天降下的饼（ἄρτος）：
> ish 16:4 :: !我要将粮食从天降给你们
饼在这一章中提到7次，7次都称为 артос：
> ish 16:15 :: !这就是耶和华给你们吃的食物
天上的饼（吗哪）被称为 артос。
# 上帝在幔利橡树旁向亚伯拉罕显现——圣餐礼的预像
亚伯拉罕为上帝（以三位天使的形像显现）预备了普通饼（ἄρτος）和宰杀的「又嫩又好」的牛犊（基督祭献的预像）的筵席：
> gen 18:5 :: !我再拿一点饼来，你们可以加添心力
亚伯拉罕在预像圣餐礼的筵席上用的只是 артос。

在箴言书中，说到圣餐礼时，讲的是普通的饼（артос）：

在关于圣餐礼的预言文本中，指明的是 артос。
# 五旬节——教会的诞生日
在旧约的五旬节（在新约中，五旬节是教会的诞生日），主直接命令给他献上**新的**祭——**有酵的（ἐζυμωμένοι）饼（ἄρτοι）**和七只无残疾的羊羔：
> lev 23:16-17 :: !又要将新素祭献给耶和华 :: !加酵，烤成两个摇祭的饼 :: !当作初熟之物献给耶和华
旧约的五旬节明确地使用有酵的 артос。
# 感恩的平安祭
旧约中有两种平安祭：
- 赞美的祭（תודה，тода）；
- 感恩的祭（或救恩的祭）（шеламим 或 נדר，недер）。
平安祭包含饼的供物和牲畜的祭献。**赞美**的平安祭用无酵的饼献上，而若在其之外还献**感恩**的平安祭，则用有酵的饼献上：
> lev 7:13 :: !要用有酵的饼和为感谢献的平安祭
这样，在旧约中，感恩（救恩）的祭用有酵的饼献上。在新约中，向上帝献上饼的圣奥秘被称为**「感恩礼」（Евхаристия，源自希腊文——感恩）**，因为基督自己在把饼递给门徒之前，先**祝谢了**上帝并祝福了饼（[[lk 22:19]]；[[1kor 11:23-24]]）。
也就是说，在东正教会的感恩礼中，今天所做的正是：
- 取有酵的饼；
- 只是不与之同献祭牲，因为祭物、羔羊、逾越节——就是被钉十字架并复活的基督（[[1kor 5:7]]）。
应当注意：无酵饼被称为困苦饼（「ἄζυμα, ἄρτον κακώσεως」，[[vtor 16:3]]），而用有酵之饼的平安祭称为感恩的祭，或救恩的祭（תֹּודַ֥ת——感恩，σωτηρίου——救恩，[[lev 7:13]]）。
*注：祭肉的肉允许在当天吃掉、不留到早晨（如同逾越节），或吃两天，但严格禁止留到第三天。若没有在第三天之前吃完，剩下的就应当烧掉，否则祭物被上帝拒绝，发生玷污和罪。这把我们引向救主的复活——第三天坟墓就空了。也就是说，在这里，有酵的饼同样指向新约——救主的复活。

# 酵——罪的预像？
有时会遇到把旧酵的比喻用作邪恶和诡诈之酵的说法。使徒保罗正是使用**旧**酵的比喻，指出必须除掉它：
> 1kor 5:7-8 :: !应当把旧酵除净 :: !也不可用恶毒、邪恶的酵 :: !只用诚实真正的无酵饼
然而，基督自己以另一种方式使用酵的比喻，把它比作天国：
> mf 13:33 :: !天国好像面酵 :: !直等全团都发起来 ~~ 并见 [[lk 13:21]]。
也就是说，酵是不同的。它表明小小的东西可以影响巨大的东西：酵使**全**团发起来。类似地，救主也用盐的比喻：盐很少，却影响整个环境。可以注意，旧约中既献无酵的饼为祭，也献有酵的饼为祭。有酵之饼所献上的，是把我们引向新约的东西——感恩的平安祭（[[lev 7:13]]）和五旬节的祭（[[lev 23:16-17]]）。而无酵饼则被称为困苦饼（[[vtor 16:3]]），是对埃及奴役的记念。无酵的、无味的、坚硬的、配苦菜的饼，应当提醒犹太民族那些主救他们脱离的苦难。而有酵的饼则相反——应当把心思转向蒙福的时光、脱离苦难的解脱、上帝祝福的时光。
# 关于 LXX 与马所拉文本的说明
俄文正教译本（司祭宗教译本）按马所拉文本译成（该文本在基督被钉十字架之后编成），而 LXX（在基督前两个世纪编成）只在教义上有意义的地方加以参照。东正教会诵读按 LXX 编成的教会斯拉夫语文本。这一切都很重要，因为希伯来文的马所拉文本在本主题所关注的地方与同样是犹太人所编、但以希腊文写成的 LXX 略有不同。例如在（[[ish 29:2]]）：马所拉文本提到三种不同的饼（虽然都是无酵的），LXX 只提到两种饼（也都是无酵的）。往后也是如此。
