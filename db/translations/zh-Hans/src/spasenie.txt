# 对异议的回应
## “信徒不受审判”
> in 5:24 :: 不至于定罪
简要地说：这里所说的是，真实的信徒和遵行救主话语的人（[[lk 6:47-49]]；[[1in 2:17]]）不会被判罪受刑罚；但谁是这些信徒和遵行的人，要由基督自己在审判时决定（[[1kor 4:3-5]]），因为如上所示，普世的审判正是从教会开始（[[1pet 4:17-18]]），而人人都要受审判。
我们更详细地看这一点。
这节经文应当按照圣经全部的教导来理解。圣经里既说到得救必须遵行诫命（[[lk 6:47-49]]；[[1in 2:17]]），也说到必须受洗（[[in 3:5]]）、领受圣餐（[[in 6:53-54]]），以及许多别的。不能只看一些经文，而对其他经文视而不见。
既然不能排除得救所需的其他条件，那么这里所说的是指那些藉洗礼进入教会、藉参与圣餐活在教会（基督的身体）里、遵行诫命、认识上帝的旨意并照着生活的信徒。如果这样行，就不会来到审判台前被判罪。但谁是这样行的人？唯有审判者基督知道。所以，首先所有人都要来到审判台前，这在其他经文里有直接的说明。
人人都要受审判：
> 2kor 5:10 :: 我们众人必要在基督台前显露出来 :: 所行的 :: 或善或恶
这里所说的正是**信徒**：
> rim 14:10 :: 论断弟兄 :: 轻看弟兄 :: 我们都要站在上帝的台前
> ekl 12:14 :: <<因为人所作的事 :: 人所作的事 :: 上帝都必审问 :: 无论是善是恶
但仅仅说人人都要受审判还不够。而且，审判正是从教会开始，也就是从信徒开始：
> 1pet 4:17-18 :: !审判要从上帝的家起首 :: !先从我们起首
总之，信徒并且遵行的人（至于是谁——由基督作为审判者决定）不会来到审判台前被判罪。
这些**许多信徒**显然以为自己已经得救、不必受审判，然而他们虽然信了，却要被定罪为作恶的人：
> mf 7:22-23 :: 许多 :: 奉你的名传道 :: 奉你的名赶鬼 :: 奉你的名行许多异能 :: 我从来不认识你们，你们这些作恶的人，离开我去吧
总之，基督要审判所有人，在审判中把人彼此分开：
> mf 25:31-32 :: !万民 :: !他要把他们分别出来 :: !绵羊山羊
## “人称义不是因行律法”
> gal 2:16 :: 人称义不是因行 :: !律法 :: 乃是因信耶稣基督 :: 不因行 :: !律法 :: 称义，因为凡有血气的，没有一人因行 :: !律法 :: 称义
这里所说的是摩西律法的行为，人不能靠它称义。在加拉太书中这是全书的主题，起因是关于外邦人是否需要受割礼的争论。受割礼并不需要，因为我们得救不是靠摩西律法的行为，而是靠对基督的信心和这信心的行为（参见上文“不只信心，行为也是得救所必需的”一节）。
## “你们得救是本乎恩，也因着信”
> ef 2:5,8-9 :: 你们得救是本乎恩 :: 你们得救是本乎恩，也因着信 :: 乃是上帝所赐的 :: 也不是出于行为
这里所说的不是每个人个人的得救，而是得救的可能性临到世界（即这可能性得以开启）。
### 1. 得救可能性的开启——是恩赐
在基督以前，人没有得救的可能。基督以后，得救成为可能，得救的途径也被建立。人作了什么，使得救成为可能？什么也没有作，人类的罪反而越来越多。救恩之路的建立，是上帝赐给人的**恩赐**。这恩赐不是罪恶的人类挣来的：
> rim 5:6-9 :: 因我们还软弱的时候，基督就按所定的日期为罪人死 :: !惟有基督在我们还作罪人的时候为我们死，上帝的爱就在此向我们显明了
### 2. 救恩的途径——是恩赐
同样，要走上得救之路并获得救恩的途径，对具体的人来说，需要的正是信心。他被引入教会，在洗礼中重生，在圣膏中领受圣灵的恩赐，在圣餐礼中与基督联合——这一切都是**因信心而白白领受的恩赐**。不要求人先挣得这个恩赐。
### 3. 走过得救之路——一生之中，靠上帝的帮助（[[1kor 15:10]]）以人的行为（[[rim 2:5-8]]）来成就（[[otkr 2:10]]）
接下来说到在基督里受生的目的——就是善行：
> ef 2:10 :: !行善
若没有这些善行，如圣经其他地方所说，人就不能得救，因为没有行为的信心是死的（[[iak 2:20]]），人称义是因着行为，不是单因着信（[[iak 2:24]]），人人都要受审判（[[2kor 5:10]]），而审判必按行为进行（[[2kor 5:10]]；[[ef 6:7-8]]）。
因此，曾向人类开启的救恩，不仅要以信心、也要以行为去领受；而如上所示，这是一个过程，而且是艰难的过程，它的终点许多人达不到：
> lk 13:24; mf 7:14; mf 7:13 :: <<你们要努力进窄门 :: !许多人想要进去，却是不能
## 悔改的强盗只来得及相信，没有作过任何行为吗？
悔改的强盗得救，是作为旧约以色列的一部分，与上帝立有旧约，凭着对救主的信心，并且来得及作了一些事。
为什么说在旧约里？因为经上记着，基督要用圣灵施洗（[[lk 3:16]]；[[mf 3:11]]；[[mk 1:8]]），而基督应许在升天之后才差遣圣灵来（[[in 16:7]]；[[in 14:16]]；[[in 14:26]]；[[in 7:38-39]]），也就是在五旬节。经上没有写强盗被传讲悔改和受洗，也没有写圣灵降在强盗身上（不同于后来其他古代基督徒的情形）。这样，悔改的强盗还在旧约之内、教会建立之前得救，没有经过洗礼和圣餐礼这两个圣奥秘。
然而，强盗也作了一件事——谦卑地领受了所加给他的刑罚，承认这是自己应得的，结出了与悔改的心相称的果子（[[mf 3:8]]）。
> lk 23:41 :: 我们是应该的，因我们所受的与我们所作的相称
谦卑地忍受苦难，不发怨言责怪上帝，不在别人身上寻找罪魁，也不定别人的罪——这是基督徒的行为（[[pr 3:11]]）。我们的始祖堕落之后，不是责备自己，而是责备别人，甚至多少责怪上帝：
> gen 3:12-13 :: <<你所赐给我 :: 你所赐给我、与我同居的女人，她把那树上的果子给我，我就吃了 :: 那蛇引诱我，我就吃了
而强盗责备的是自己，并且甘心领受刑罚。这是行为，而且极配得上基督徒的心志。
他虽是强盗，并没有被高举为伟人之一，也没有得着救主右边或左边所预备的座位（[[mk 10:40]]）；但他是因信心得救的，并且还有他来得及作成的那件小行为。所以，强盗到底还是有行为，而不只有信心。
还要注意的是，并不是强盗自己宣称得救，而是基督对他作出审判。强盗的话里看不出任何对得救的确信；相反，他明白自己不会与上帝同享永生，所以只怀着对怜悯的谨慎盼望，求基督在他进入自己国的时候记念他（照强盗自己的想法，那时他不会在那个国里）。
## “凡求告主名的，就必得救”
> rim 10:13 :: 凡求告主名的，就必得救
> act 2:21 :: 凡求告主名的，就必得救
有人可能产生疑问：难道只要求告主，无论怎样求告、无论行什么，就都必得救？其实，这里的“凡”是说，能得救的不仅是犹太人，而是任何民族的人。
这些话使徒只是引用。最初是旧约中对犹太人所说的预言。使徒在此提醒这些话，并指出它们应验的时候已经到了。旧约中说这话的是先知约珥：
> iol 2:32 :: 凡求告耶和华名的就必得救
先知的话是对以色列民说的，以色列民坚信上帝只拯救以色列人。于是给以色列民一个预言：时候将到，得救的不再只是以色列人，而是任何求告上帝的民族。
总之，这话出自旧约——上帝只与以色列民立旧约；新约则是与教会立的，教会召聚了万民，因为在教会里民族已不再有意义（[[kol 3:11]]）。这里说的正是这一点，从上下文可以直接看出：民族对得救没有意义：
> rim 10:11-13 :: 凡信他的人，必不至于羞愧 :: !犹太人和希利尼人并没有分别 :: !凡求告主名的，就必得救
圣经其余的部分，并不因此失去必要性。
怎样得救？遵守诫命——主说：
> mf 19:17 :: <<你若要进入永生 :: 当遵守诫命
求告上帝的话把这废除了吗？当然没有。
经上说，不从水和圣灵生的，就不能见上帝的国，也不能进上帝的国。这同样没有废除：
> in 3:3,5 :: 不能见上帝的国 :: 不能进上帝的国
关于圣餐礼的话也没有废除。没有它，人就不能在自己里面有生命，也不能在末日复活（为与上帝同活）：
> in 6:53-54 :: <<你们若不吃 :: 你们若不吃人子的肉，不喝人子的血，就没有生命在你们里面 :: 在末日我要叫他复活
尼哥拉一党人和许多异端也求告上帝，然而他们作为异端和分裂教会者，被判失去上帝的国：
> gal 5:19-21 :: 情欲的事都是显而易见的 :: !结党、纷争 :: !异端 :: !行这样事的人必不能承受上帝的国 ~~ *“结党、纷争”（διχοστασίαι）——分裂、分派。
总之，“凡”是指任何民族的人，而不只是犹太人。关于教会，使徒这样说：
> kol 3:8,10-11 :: <<但现在你们要弃绝 :: !希利尼人、犹太人 :: !化外人、西古提人
## “代赎的祭”
有些主张救恩只凭信心（不凭行为）的人，讲到一种称为“代赎的祭”的救赎理论，其含义如下：正如以撒被献为祭时有羊羔代替，使以撒得以存活；同样，基督代替罪人被献为祭，使罪人得以存活。这样，既然上帝父把他的怒气倾倒在儿子身上，他就不再向信主的罪人发怒。于是信主的罪人与上帝同活就不再有拦阻。
代赎之祭的理论看来并不符合真理。它出自一个错误的前提：问题在于上帝（他向罪人发怒）。为了“纠正”上帝（这念头本身就何等僭妄），儿子必须死。而人自己完全不必悔改，因为上帝将向儿子发怒，于是（仿佛在上帝那边的）问题就解决了。这样的理论不能被当作真理，因为它违背常识。显然，问题不在于上帝。与上帝同在的永生之中，任何不洁净的都不能进入：
> otkr 21:23,27 :: 凡不洁净的，并那行可憎与虚谎之事的，总不得进那城
