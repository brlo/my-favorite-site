圣经的经文虽然是在上帝之灵的感动下写成的（即上帝所默示的），却不是上帝口述的笔录，书写者也不是上帝手中铅笔那样没有个性的工具。牧人出身的先知用朴素的语言写作，宫廷出身的先知则以饱学之士的笔法写作；两人都采用与自己生活方式相称的比喻。例如，论到使徒保罗，别的使徒写道，他的书信中有难以理解的地方：
> 2pet 3:16 :: 有些难明白的 :: >>难明白的
而使徒保罗自己也说，他在言语上是粗俗的，在知识上却不是：
> 2kor 11:6 :: 我的言语虽然粗俗 :: >>却不粗俗
也就是说，他尽力而写，但在知识上并无亏损。事实上，使徒保罗作为受过教育的法利赛人，确实运用了复杂的意义结构。更进一步，使徒们有时明确宣告，所写的是自己的意见：
> 1kor 7:25 :: 我没有主的命令 :: 自己的意见告诉
更准确地说，圣经乃是上帝与人的共同工作（协作，συνεργία）：
> 1kor 3:9 :: 与上帝同工的 ~~ συνεργοί，直译为「与上帝同工者」
