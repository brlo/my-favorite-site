# 新约中的圣物
## 圣洁的圣殿
耶路撒冷圣殿是真圣所的像：
> evr 9:24 :: !基督并不是进了人手所造的圣所（这不过是真圣所的影像）
> in 2:13-16 :: !看见殿里有卖牛、羊、鸽子的 :: !把牛羊都赶出殿去 :: !不要将我父的殿当作买卖的地方
> lk 24:53 :: !常在殿里称颂上帝
> act 2:46 :: !他们天天同心合意恒切的在殿里
使徒在圣殿里祈祷，基督在那里于异象中向他显现：
> act 22:17 :: !在殿里祷告的时候 :: !魂游象外
敌基督（大罪人）要坐在上帝的殿里（显然，要坐在上帝的殿里，那殿必须是：不是宙斯的殿、不是雷神的殿，而是上帝的殿）：
> 2sol 2:3-4 :: !并有那大罪人 :: !抵挡主，高抬自己 :: !甚至坐在上帝的殿里自称是上帝
## 圣地
在圣地，听的人必须看见什么：
> mf 24:15 :: !那行毁坏可憎的 :: !站在圣地

## 圣物
圣膏——是圣物。圣殿和一切以圣膏膏抹的殿内器皿——是圣物。在人中间，只有亚伦的后裔可以用它膏抹，使他们成为司祭：
> ish 30:23-33 :: !按作香之法，调和作成圣膏油 :: !要用这膏油抹会幕和法柜 :: !要使这些物成为圣，好成为至圣，凡挨着的都成为圣 :: !要膏亚伦和他的儿子 :: !这膏油是圣的，你们也要以为圣 :: !这人要从民中剪除
祭坛——至圣的圣物：
> ish 40:9-10 :: !使坛成圣，就都成为至圣
> ish 29:37 :: !坛就成为至圣，凡挨着坛的都成为圣
香的配方（在祭坛上焚烧的香料）——至圣的圣物：
> ish 30:34-38 :: !作成清净圣洁的香 :: !你们要以这香为至圣 :: !要以这香为圣，归耶和华 :: !这人要从民中剪除

# 对异议的回应
## “上帝不住人手所造的殿”
反对圣殿的教会批评者引用一节经文：
> act 7:46-49 :: !其实，至高者并不住人手所造的 :: !你们要为我造何等的殿宇
然而这丝毫不能证明反对圣殿，因为当大卫想为上帝建造殿宇时，上帝早已命令先知摩西建造会幕、祝圣它、在其中设立司祭、遵守规程、拥有圣物（约柜）、并设立了违反上帝所立秩序的死刑。这节经文只是说明：上帝无处不在，而不只在圣殿里。同时，圣殿——是上帝自己的设立，而不是人的设立，更不是仿佛从异教借来的东西。
