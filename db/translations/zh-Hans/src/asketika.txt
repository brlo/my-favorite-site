# 圣经论隐修生活
## 选择上帝所喜悦之事的太监
上帝特别举出那些不结婚、特别关心遵守上帝诫命的人。他们仿佛被高举在其余的“儿女”之上：
> is 56:4-5 :: !持守我约的太监 :: !我必使他们在我殿中，在我墙内有记念、有名号，比有儿女的更美
| **不生育的男人，手若不作非法的行为，心不思念相反上主的恶事，是有福的；天主见他忠贞，必赐给他特赏，在上主的圣殿中，赐给他更称心的一份。** ||| sb prs 3:14
## 高于遵守诫命的成全之路
寻求救恩之道的富少年从救主得到确认：为此必须遵守诫命。然而，因为少年问起更多的事，主就向他指出更高的：不仅要得救，还要成为完全的。为此主呼召少年变卖自己的一切所有，来跟从他：
> mf 19:21 :: !你若愿意作完全人 :: !可去变卖你所有的，分给穷人 :: !你还要来跟从我
## 为天国的缘故自阉的人
隐修士舍弃一切地上的财富和依恋，一生专心寻求上帝并事奉他。隐修士——为天国的缘故自阉、甘受剥夺的人：
> mf 19:10-12 :: !倒不如不娶 :: !这话不是人都能领受的，惟独赐给谁，谁才能领受 :: !有为天国的缘故自阉的 :: !这话谁能领受，就可以领受
这些关于阉人的话，是基督在使徒们听到他禁止休妻之后说的。使徒们以为那样倒不如不娶。主没有与这个结论争辩，只指出：不是人人都能选择这条路。谁能，谁就选择。就是说，这是苦修者的特殊道路。
## 使徒的劝告
使徒明确地重复关于独身的思想：
> 1kor 7:1 :: !男不近女倒好
使徒保罗没有妻子，他劝告独身者和寡妇（正是劝告）不要寻求新的丈夫，像他自己一样：
> 1kor 7:8 :: !若他们常像我就好
使徒解释这样劝告的原因：
> 1kor 7:28-40 :: !我愿你们无所挂虑 :: !没有娶妻的，是为主的事挂虑，想怎样叫主喜悦 :: !娶了妻的，是为世上的事挂虑，想怎样叫妻子喜悦 :: !没有出嫁的，是为主的事挂虑，要身体、灵魂都圣洁 :: !已经出嫁的，是为世上的事挂虑，想怎样叫丈夫喜悦 :: !若常守节更有福气
在自己的一生中度贞洁生活的基督徒，在天上无论羔羊往哪里去都跟随他：
> otkr 14:1-5 :: 羔羊 :: 十四万四千人 :: 仿佛是新歌 :: !除了从地上买来的那十四万四千人以外，没有人能学这歌 :: !这些人未曾沾染妇女，他们原是童身 :: !羔羊无论往那里去，他们都跟随他

# 隐修生活的榜样
## 主耶稣基督
- 没有结婚；
- 没有自己的房子（[[mf 8:20]]；[[lk 9:58]]；[[mf 19:21]]）；
- 没有个人的钱袋（[[mk 12:15]]；[[mf 17:24-27]]；[[mf 19:21]]）；
- 常常独自整夜祈祷（[[lk 6:12]]；[[mf 6:6]]；[[mf 14:23,25]]；[[mk 14:32,35,37,39-41]]）；
- 有门徒（[[lk 6:13]]；[[lk 10:1]]）；
- 教导祈祷，给门徒祈祷的范本（[[mf 6:9]]）；
- 安慰、责备、教导、训诲来到他面前的人（[[mk 6:31]]）。
## 童贞女马利亚——上帝之母
- 立了独身的愿，形式上处于婚姻中，没有夫妻关系（“我不认识丈夫”——详见[[ru:Богородица#HH-Богородица-была-и-остаётся-девой|上帝之母]]）；
- 没有财产，自幼被送到圣殿抚养，后许配给约瑟，后被主交托给使徒约翰（[[in 19:27]]）。
## 先知施洗约翰
- 没有结婚；
- 住在旷野，没有自己的房子（[[lk 1:80]]）；
- 穿粗陋的自制衣服（[[mf 3:4]]）；
- 吃在旷野找到的极简单的食物（[[mf 3:4]]）；
- 自制的衣服和找到的食物表明他没有钱；
- 教导祈祷，给出祈祷的范本（[[lk 11:1]]）；
- 有门徒（[[mf 11:2]]；[[in 1:35]]；[[in 3:25]]）；
- 安慰、责备、教导、训诲来到他面前的人（[[lk 3:18]]；[[lk 3:10-20]]；[[mk 6:31]]）。
## 先知以利亚
- 没有结婚；
- 常常生活在荒野、旷野和洞穴里（[[3ts 17:3-7]]；[[3ts 19:9]]；[[3ts 19:4]]）；
- 穿动物毛织的简朴衣服，束皮带（[[4ts 1:8]]）；
- 吃乌鸦叼来的简朴食物（[[3ts 17:6]]）；
- 有门徒（[[3ts 19:19-21]]）；
- 奉上帝的命令责备人的不虔（[[3ts 18:17-40]]）。
## 先知但以理
- 没有结婚；
- 吃简朴的食物，拒绝王的膳食（[[dan 1:12]]）；
- 常常祈祷（[[dan 6:10]]）；
- 责备不虔（[[dan 5:17-28]]）。
## 先知耶利米
- 奉上帝的命令没有结婚（[[ier 16:2]]）；
- 独居，常被囚禁或流放（[[ier 37:15-16]]）；
- 教导并责备万民（[[ier 1:9-10]]）。
