# 前言
首先要指出的是：圣经里没有任何一个建立自己“教会”、自立为牧人的例子，也没有任何这样的依据。基督建立了一个看得见的教会，并表达了关于她合一的旨意。
# 基督和使徒关于教会看得见之合一的旨意
> in 17:20-21 :: !祈求 :: !使他们都合而为一 :: !使他们也在我们里面 :: !叫世人可以信你差了我来
> 1kor 1:10-13 :: !劝你们 :: !都说一样的话 :: !不可分党 :: !一心一意 :: !彼此相合 :: 你们中间有纷争 :: 基督是分开的吗
> 1kor 3:4 :: !这岂不是你们和世人一样吗
上帝安置身体（教会）的肢体，为使身体没有分裂，而是彼此相顾，同受苦，同快乐：
> 1kor 12:13-14,21-26 :: 都从一位圣灵受洗，成了一个身体 :: !身子原不是一个肢体，乃是许多肢体 :: !眼不能对手说 :: !上帝配搭这身子 :: !免得身上分门别类 :: !总要肢体彼此相顾 :: !若一个肢体受苦，所有的肢体就一同受苦
这些不同的肢体是什么？——就是教会里各种不同的事奉和恩赐：
> 1kor 12:12,14,27-30 :: 就如身子是一个，却有许多肢体 :: !身子原不是一个肢体，乃是许多肢体 :: !你们就是基督的身子 :: !上帝在教会所设立的 :: 使徒 :: 先知 :: 教师 :: 行异能的 :: 医病的 :: 说方言的 :: 繙方言的
这样，上帝安置这一切的事奉和恩赐，为使身体没有分裂；使徒在书信开头就防止了分裂（[[1kor 1:10-13]]）。也就是说，上帝不但愿意合一（[[in 17:20-21]]），而且亲自照顾这合一。看，使徒被上帝立为仆人，维护看得见的合一，禁止哥林多人制造看得见的分裂。
既然合一是基督的旨意，就要明白：得救的是遵行上帝旨意的人（[[mf 7:21]]）。

# 教会起初看得见的合一
## 外人——另立一旁
教会在起初就有完全确定的看得见的边界：
> act 5:13 :: 其余的人
## 共同的财物
教会当时是一个一体的团体：
> act 4:32 :: 一心一意 :: 都是大家公用
## 共同解决有争议的问题
教会有共同的问题，并且一同解决，聚集在完全确定的、看得见的会议上：
> act 15:6,22 :: 使徒和长老，聚会商议这事 :: 使徒和长老并全教会定意
## 共同的规矩
教会有确定的、大家共同的规矩：
> act 16:4-5 :: 经过各城 :: 把耶路撒冷使徒和长老所定的条规交给门徒遵守
## 禁止分门别类
在教会里，任何分裂的企图都被制止：
> 1kor 1:10-13 :: !劝你们 :: !都说一样的话 :: !不可分党 :: !一心一意 :: !彼此相合
## 一个信仰和圣奥秘
在教会里只有一个确定的、大家共同的信仰：
> ef 4:5 :: 一信
> 2in 1:9 :: 越过 :: !基督的教训 :: 不常守着的，就没有上帝 :: 常守这教训的
如救主所说：这信仰是按使徒的话：
> in 17:20 :: 因他们的话
教会知道，将来会出现想离开这唯一信仰的人。这些人不能被称为教会：
> iud 1:18-19 :: 引人结党
## 一个司祭的等次
> act 20:17-18,28 :: <<请教会的长老来 :: !圣灵立你们作全群的监督 :: 牧养上帝的教会
关于司祭职，详见[[ru:Таинство-Священства|司祭圣奥秘]]。

这样，教会是一个完全确定的看得见的团体（机体），有唯一一个共同的使徒信仰，有大家共同的规矩，有使徒所立的、在一切事上合一的带领者；教会的肢体之间没有任何阻隔。
# 教会的边界与圣餐礼
旧约的教会不像新约的教会那样被称为基督的身体。新约的教会是一个奥秘的神人机体，是[[ru:Церковь|基督的身体]]。所以，教会的边界就在身体的边界。人的身体的边界在哪里？血液流通的地方就是身体；不流通的地方就不是身体。人身体的部分没有血就没有生命。被切下来的手已经不是身体的一部分。很快，得不到血的供应，它就会腐烂。哪里有真实的领受圣体，哪里就有身体，也就是教会：
> 1kor 10:16-17 :: 同领基督的血 :: 同领基督的身体 :: 我们虽多，仍是一个饼、一个身体，因为我们都是分受这一个饼
> 1kor 12:27 :: 你们就是基督的身子
> ef 2:13 :: !靠着他的血，已经得亲近了
所以，救恩只在教会里，因为基督是[[ru:Церковь|身体的救主，也就是教会的救主]]：
> ef 5:23 :: 基督是教会的头 :: 教会全体的救主
关于圣餐礼，详见[[ru:Евхаристия|圣餐礼]]。
**圣殉道者、安提阿主教伊格那丢（一世纪）**，《致士每拿人书》（[俄文](https://azbyka.ru/otechnik/Ignatij_Antiohijskij/poslanie-k-smirnjanam/)）：
“第八章。凡属于教会的事，一概不要不经主教而行。……**只有主教所举行的圣餐，或他所准许的人所举行的，才当视为确实有效**。”
