# 基督复活后天上现实的改变
要确信在基督之前，死去的义人灵魂并未达到与上帝在天上同活的生命，可以把基督之前的天上现实与基督复活之后的天上现实作一比较。
在基督之前，天上的现实曾被指示给先知摩西看——在山上，为要使先知按所看见的样式在地上建造圣殿（会幕、圣所）：
> ish 25:8-9,40 :: !又当为我造圣所 :: !都要照我所指示你的样式 :: !都要照着在山上指示你的样式
> evr 9:24 :: !人手所造的圣所 :: !这不过是真圣所的影像
观察旧约圣殿的[[ru:иерусалимский-храм|构造]]和图像，我们看到：在基督的祭献之前，天上只有上帝（不可见地）临在和圣洁的天使（[[3ts 6:29]]）。
在基督复活和升天之后，按人性可见的上帝坐在于天上（[[ef 1:20-21]]；[[otkr 3:21]]），天使仍然临在于那里（[[otkr 8:3]]；[[otkr 15:6]]），同时义人的灵魂也出现了（[[otkr 6:9-11]]；[[otkr 14:1,3-5]]）。我们在神学家约翰的启示录中看到这一新的天上现实。
这样，在新的天上现实中，除了上帝和天使之外，还出现了义人的灵魂；在基督复活之前，那里并没有他们。
## 旧约——圣殿中只有上帝和天使
在基督的祭献之前，旧约中，上帝在山上把圣殿指示给先知摩西看，吩咐他在地上照所指示的样式制造一切（[[ish 25:8-9,40]]；[[evr 9:24]]）。最终，摩西建造了圣殿：其中上帝完全不被描绘，而在上帝显现之处（约柜的施恩座）周围，安放着天使的像；同样，所有的墙壁和幔子上都有天使的图像。
### 不可见的上帝
在奉上帝之命建造的旧约圣殿中，没有上帝的像，因为上帝是不可见的。在最主要的地方只立着约柜（柜子），里面放着圣物；在柜盖上、两个革鲁宾之间，上帝显现并说话：
> ish 25:22 :: !我要在那里与你相会，又要从法柜施恩座上，二基路伯中间
### 圣洁的天使
圣殿到处充满了天使（革鲁宾）的图像：
> ish 25:18-20 :: !要用金子锤出两个基路伯来，安在施恩座的两头
> 3ts 6:23,27 :: !他用橄榄木作两个基路伯，各高十肘，安在内殿 :: !他将两个基路伯安在内殿里
> 2par 3:14 :: !幔子 :: !在其上绣出基路伯来

## 新约——圣殿中有上帝、天使和义人的灵魂
在上帝之子降生成人并战胜死亡之后，我们看到另一种天上现实。神学家约翰在启示录一书中描述了它。首先，上帝成为可见的，坐在宝座上。其次，在天上事奉他的不再只有天使，还有众多圣义者的灵魂。

> ef 1:20-21 :: !叫他在天上坐在自己的右边
> otkr 3:21 :: !在我宝座上 :: !在我父的宝座上与他同坐

# 「你必不将我的灵魂撇在阴间」——不是指大卫
大卫王在圣咏中说的预言（[[ps 16:10]]）——灵魂不被撇在阴间、肉身不见朽坏——不是指大卫，而是指基督。因此，大卫王的**肉身**见了朽坏，**灵魂**则被留在阴间，直到基督下到阴间。
> act 2:27,29,31,34 :: !因你必不将我的灵魂撇在阴间 :: !弟兄们，先祖大卫的事，我可以明明地对你们说，他死了，也葬埋了 :: !讲论基督复活说 :: !他的灵魂不撇在阴间；他的肉身也不见朽坏 :: !大卫并没有升到天上
