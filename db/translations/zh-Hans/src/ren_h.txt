# 定义
地狱可以有几种理解。
1. 地狱——死者灵魂在普遍复活和最后审判之前的居所。
1. 地狱——在荣耀的第二次降临、普遍复活和最后审判之后，被定罪的罪人复活后（即灵魂与身体一起）的居所。最后审判之后，这一命运已无法改变。被定罪者的痛苦与义人的真福将同样永远持续。
# 地狱、欣嫩谷、火湖、永火、外面的黑暗、监狱——受苦之处
在圣经中，「地狱」最常指某种受苦之处。这地方可以用不同的词来称呼，但这并不改变其实质：它始终是受苦之处。在地狱里受苦的有：
> mf 8:12 :: !惟有本国的子民，竟被赶到外边黑暗里去
> mf 22:13 :: !把他丢在外边的黑暗里
> mf 25:30 :: !把这无用的仆人丢在外面黑暗里
是基督自己——作为审判者——决定谁往哪里去：
> mf 25:41 :: !你们这被咒诅的人，离开我，进入那为魔鬼和他的使者所预备的永火里去
> mf 10:17,28,33-34,38 :: !你们要防备人 :: !惟有能把身体和灵魂都灭在地狱里的，正要怕他 :: !我在我天上的父面前也必不认他 :: !乃是叫地上动刀兵 :: !不背着他的十字架跟从我的，也不配作我的门徒
人死后要进入新的居所。这一事件值得哀哭：
> ekl 12:5 :: !因为人归他永远的家
人死后有审判等待着他：
> evr 9:27 :: !人人都有一死，死后且有审判
地狱中，其中的居民有知觉地存在。巴比伦王受到地狱一切居民的迎接：
> is 14:4,9-10 :: !你下到阴间，阴间就因你震动，来迎接你 :: !你也变为软弱像我们一样吗？你也成了我们的样子吗
主在身体死后下到阴间，向那些从世界洪水时代起就在那里的神魂宣讲：
> 1pet 3:18-20 :: !按着肉体说，他被治死；按着灵性说，他复活了 :: !他藉这灵曾去传道给那些在监狱里的灵听 :: !挪亚预备方舟、上帝容忍等待的时候
> ef 4:8-9 :: !既说升上，岂不是先降在地下吗
基督的灵魂没有被撇在阴间。不是**身体**没有被撇在坟墓（土）里，而是**灵魂**没有被撇在阴间：
> act 2:31 :: !他的灵魂不撇在阴间
死人被看见，死人受审判，阴间交出死人：
> otkr 20:12-13 :: !我又看见死了的人 :: !死了的人都凭着这些案卷所记载的，照他们所行的受审判 :: !死亡和阴间也交出其中的死人
