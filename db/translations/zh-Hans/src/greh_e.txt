# 杀人是罪
> ish 20:13; vtor 5:17 :: !不可杀人
> mf 19:18; mf 5:21; mk 10:19; lk 18:20; rim 13:9 :: !不可杀人
无论是尚在母腹中、还是已经出生的婴儿，都是人。杀人是罪。
在古老的基督教文献（《十二宗徒训言》）中直截了当地说到这一点：
<blockquote><p>「<strong>不可堕杀胎中的婴儿</strong>，也不可在出生后杀死他。」</p></blockquote>（<a href="https://azbyka.ru/otechnik/pravila/didahe_rus/">《十二宗徒训言》</a>）
# 婴儿也是人。无论在母腹内，还是在母腹外
圣经把远早于预产期（怀孕三四个月）出生的人也称为婴孩：
| 甫满周岁的婴孩要用声音说话；怀孕的妇人要在三四个月时生下不足月的婴孩，他们要存活，并且健壮。 ||| ru 3ezd 6:21
赞美那些拒绝杀死刚出生婴儿的收生婆：
> ish 1:17,20-21 :: !收生婆敬畏上帝 :: !竟存留男孩的性命
先知施洗约翰在母腹中、在出生之前，就已被圣灵充满。也就是说，并不是什么「将来会成为人的东西」，而是先知约翰自己，还在母腹中时，就成了上帝之灵的殿：
> lk 1:15 :: !从母腹里就被圣灵充满了
上帝在母腹中所造的，不是什么「后来才成为人」的东西，而是人本身；这个人后来只是从母腹中出来，也就是出生。上帝在人出生之前就使他成圣：
> ier 1:5 :: !我未将你造在腹中 :: !你未出母胎，我已分别你为圣
忍受苦难的先知约伯也这样说。上帝在母腹中造的是我们，而不是什么「后来会成为人」的东西：
> iov 31:15 :: !造我在腹中的 :: !将他与我抟在腹中的岂不是一位吗
人在母腹中的发育过程被描述为上帝自己的创造行动。这被描述为：人已经存在，却像穿衣服一样穿上肉体，为要出来到世界上。约伯所说的不是某种后来才成为约伯的质料；他直接把这胚胎说成是他自己：难道不是你给我穿上肉体的吗？
> iov 10:8-12 :: !你不是倒出我来好像奶，使我凝结如同奶饼吗？你以皮和肉为衣给我穿上，用骨与筋把我全体联络
先知大卫也描述说：
> ps 139:13,15-16 :: !我在母腹中，你已覆庇我 :: !我在暗中受造，在地的深处被联络 :: !我未成形的体质，你的眼早已看见了 ~~ 俄文本编号为 Пс 138:13,15-16（圣咏编号相差一）。
