## 没有空虚的多言
上面已经说到，需要恒常的祈祷、在祈祷中的坚持和忍耐（[[lk 18:1-7]]）。但上帝不是被话语重复的频度安抚的。祈祷必须与上面列举的一切结合：信心、公义、蒙上帝喜悦的行为、远离罪恶、清洁的心、饶恕委屈、与邻人和睦等等。而外邦人**不改变自己**和自己的生活，指望喊叫到他们的神那里；那些神仿佛在睡觉，所以仿佛需要更大声、更频繁地喊叫（见[[3ts 18:26-28]]）。

# 前言
为亡者祈求某种怜悯，这是爱心之举，即被对上帝和对邻人的爱所引导之人的举动。我们不知道主对于某一个为亡者所发的祈求会怎样决定，然而我们有盼望的依据，也有促使我们关怀的爱。这依据是什么？依据——是上帝的启示，我们从其中得知：上帝是全能的，他掌握着死亡和阴间的「钥匙」；有些罪甚至在未来的世代也不会被赦免（由此可以明白，还有别的罪）；上帝曾呼召我们以各种不同的祈求来到他面前。我们也知道，罪人所受的刑罚不是[[ru:bib_Неодинаковая_мера_воздаяния:_мучения_и_блаженства|一样的尺度]]，义人的福乐也不是一样的程度；所以即使一个人不能得救，我们也盼望他的命运得到减轻。在旧约里人们就关怀亡者（见[[ru:молитвы-за-умерших#HH-Ветхий-Завет-Забота-о-прощении-грехов-умерших|下文]]），最早的基督徒也关怀他们（详见[[ru:91USaqiJ_молитвы_за_умерших|为亡者的祈祷]]）。
促使这一切的，是那“永不止息”的爱（[[1kor 13:8]]）。

# 罪可以藉教会的祈祷得赦免
这就是说，罪得到赦免不仅是在人自己悔改、自己求赦免的时候，也是在别人为人求赦免的时候：
> iak 5:14-15 :: !该请教会的长老来 :: !他若犯了罪，也必蒙赦免
瘫痪者的朋友们费了很大的力气才把朋友带到基督面前。主因他们的信心赦免了瘫痪者的罪，并医治了他：
> mk 2:5 :: !耶稣见他们的信心 :: !小子，你的罪赦了

| 事后，犹大率领兵马，到了阿杜蓝城；因为已到第七日，他们就在那里照例自洁，过了安息日。第二天，由于事不宜迟，犹大的部队便出去收殓阵亡的尸体，好把他们安葬在祖坟里，与亲族在一起。当时在每个死者的内衣下，发现都有雅木尼雅偶像的符箓，这原是法律禁止佩带的；众人便都明白这正是他们阵亡的原因。于是众人称赞秉公审判及揭示隐密的上主，同心哀祷，**求使所犯过恶，得以完全赦免**。随后，英勇的犹大劝勉民众避免犯罪，因为人都亲眼看见这些阵亡者因罪所受的罚。于是大众募集了二千银“达玛”，送到耶路撒冷作赎罪祭的献仪：**他作的是一件很美妙高超的事，因为他想念着复活**；如果他不希望那些死过的人还要复活，**为亡者祈祷，便是一种多余而糊涂的事**。何况，他还想到为那些善终的人保留下的超等报酬：这实在是一个圣善而虔诚的思想。**为此，他为亡者献赎罪祭，是为叫他们获得罪赦**。 ||| sb 2mak 12:38-45

# 按范本祈祷
旧约里有一部伟大的、受上帝默感的祈祷书——诗篇。它由先知兼君王大卫写成。它曾在圣殿中使用，诗篇是人们在登上台阶时唱的。
当使徒们求主教他们祈祷时，他们所依据的是：先知施洗约翰已经教导过自己的门徒祈祷：
> lk 11:1 :: !求主教导我们祷告 :: !像约翰教导他的门徒
之后基督赐下祈祷的范本——用他自己的话：
> lk 11:2-4; mf 6:9-13 :: !你们祷告的时候，要说 :: !赦免我们的罪
就是说，给出祈祷文、按范本（规矩）祈祷——这是完全正常的，是圣经的实践。

在讲了关于恒常和坚持祈祷的比喻之后，主又讲了那个税吏的短祷蒙他喜悦的比喻；不过如福音史家所说明，这个比喻讲的是那些自以为义的人。最终，基督直接指出税吏蒙上帝喜悦之处：对自己和自己的义看得很低：
> lk 18:9-14 :: !仗着自己是义人，藐视别人的 :: !那税吏远远的站着，连举目望天也不敢 :: !上帝啊，开恩可怜我这个罪人 :: !凡自高的，必降为卑；自卑的，必升为高
# 对异议的回应
## 不可用许多重复话
在马太福音里，“我们在天上的父”祈祷之前记着基督的话：祈祷中不必说多余的话：
> mf 6:7-8 :: !用许多重复话 :: !你们不可效法他们
主耶稣基督自己常常整夜祈祷，有时也重复自己的话：
> mk 14:39 :: !说的话还是与先前一样
