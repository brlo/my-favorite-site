# 定义
**婚姻**——教会七个圣奥秘之一，在其中求上帝祝福自愿的夫妻联合——它建立在夫妻彼此相爱之上，按基督和他的教会之属灵联合的样式。
# 圣经引文
在婚姻中举行上帝所行做的圣奥秘：
> gen 2:18,22,24 :: !那人独居不好 :: !耶和华上帝就用那人身上所取的肋骨造成一个女人 :: !人要离开父母，与妻子连合，二人成为一体
> mk 10:2-9 :: !既然如此，夫妻不再是两个人，乃是一体的了 :: !上帝配合的，人不可分开
> 1kor 6:15-16 :: !与娼妓联合的，便是与她成为一体吗 :: !二人要成为一体
> ef 5:28,31-33 :: !丈夫也当照样爱妻子 :: !这是极大的奥祕 :: !但我是指着基督和教会说的 :: !妻子也当敬重他的丈夫
# 一世纪教会婚姻祝福
## 圣伊格那提·怀上帝者（约37-107）
“凡娶妻嫁人的，**必须与主教的同意联合**，好叫婚姻在主里面，而不是出于情欲”
（[[ru:ИгнАн_Пк|致波利卡普书]] 第28节）

# 旧约中的认罪
在旧约的教会里，上帝亲自设立了在圣殿里、在司祭面前的告解，并藉司祭洁净罪：
> lev 5:5-6 :: !就要承认所犯的罪 :: !祭司要为他赎了
> pr 28:13 :: !承认离弃罪过的，必蒙怜恤
# 新约中的认罪
## 司祭职有权赦罪
上帝更换了司祭职（详见[[ru:Таинство-Священства|司祭圣奥秘]]）：
> evr 7:12 :: !祭司的职任既已更改，律法也必须更改
把赦罪之权赐给新的司祭职：
> mf 16:19 :: !凡你在地上所释放的，在天上也要释放
> mf 18:18 :: !凡你们在地上所释放的，在天上也要释放
> in 20:22-23 :: !你们赦免谁的罪，谁的罪就赦免了 :: !你们留下谁的罪，谁的罪就留下了
因司祭职的祈祷，罪得赦免：
> iak 5:14-15 :: !该请教会的长老来 :: !用油抹他 :: !他若犯了罪，也必蒙赦免
司祭职被立为教会的守护者：
> act 20:17-18,28 :: !请教会的长老来 :: !圣灵立你们作全群的监督 :: !牧养上帝的教会
## 告解在教会里得以保存
在新旧约交界处，人们来到先知施洗约翰面前，也认自己的罪：
> mk 1:4-5 :: !传悔改的洗礼，使罪得赦 :: !承认他们的罪
告解在教会里得以保存：
> act 19:18 :: !承认诉说自己所行的事
## 信徒在得着真信仰之后，后来仍需要新的罪的赦免
真信徒能使邻人从迷路上转回，并以此遮盖自己的许多罪：
> iak 5:19-20 :: !有人使他回转 :: !叫一个罪人从迷路上转回 :: !遮盖许多的罪
> iak 5:14-15 :: !该请教会的长老来 :: !用油抹他 :: !他若犯了罪，也必蒙赦免
# 主不拒绝悔改的人
上帝总是预备接纳罪人的悔改，无论他犯了多重的罪
> ps 51:17 :: !忧伤痛悔的心，你必不轻看
> in 6:37 :: !到我这里来的，我总不丢弃他
