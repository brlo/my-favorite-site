# 圣奥秘中是救主真实的体和血
## 饼——基督将为世人的生命而舍去的肉
在圣餐中，信徒领受耶稣基督真实的（真正的）体和真实的血——他为世人的生命而舍弃它们，把自己作为祭物献在十字架上：
> in 6:48-51 :: !我所要赐的粮就是我的肉，为世人之生命所赐的
这里主直接宣告：这从天降下的粮就是他的肉——这肉他**现在**就有，并且**将来**要为世人的生命而舍去。这里只是应许。此刻他还没有舍这肉。教导他已经赐下，而在将来，他要交付于死刑的不是教导、不是象征、不是纪念，而是他真实的肉。正是他的肉才是那从天降下的粮——他在圣餐圣奥秘中以饼和酒的形式分给门徒吃。

## 逾越节的羔羊
无残疾的（一岁的、没有缺陷的）公羔羊应当真实地**死**，为人的罪；然后真实地被**吃掉**，全部吃完。基督是羔羊，字面地应验了这一预表的两部分：
- 他真实地（不是象征地）为人的罪而死；

## 吗哪
旷野中的吗哪，它供养以色列民从埃及的奴役走向应许之地的路上的力量。吗哪在旷野里是真实地被吃的。它真实地保护人不至死亡、赐人生命（旷野里没有别的食物）：
> ish 16:4,31 :: !我要将粮食从天降给你们 :: !每天收每天的分 :: !以色列家叫吗哪
> chis 11:9 :: !吗哪也随着降下
因为吗哪只是预像、是将来之事的影子，而不是实物本身，所以它没有赐下永恒的生命，只是延长地上的生命、使人免于饿死；最终那些犹太人还是死了，正如人都死一样。但基督说，吃他的必永远活着：
> in 6:31-33,35,48-50 :: !我们的祖宗在旷野吃过吗哪 :: !乃是我父将天上来的真粮赐给你们 :: !上帝的粮就是那从天上降下来赐生命给世界的 :: !我就是生命的粮 :: !你们的祖宗在旷野吃过吗哪，还是死了 :: !叫人吃了就不死
> in 6:54-55,57-58 :: !吃我肉、喝我血的人就有永生 :: !吃我肉的人也要因我活着 :: !不像你们的祖宗吃过吗哪还是死了
再者，如果把犹太人从埃及的奴役到应许之地的整个路程看作基督徒从罪的奴役到天国的路程，那么吗哪在这里也字面地指向圣餐：
- 真实的埃及奴役——真实的罪的奴役。
- 真实地走海床脱离奴役——真实的洗礼（[[1kor 10:2]]）。
- 真实的四十年旷野漂泊——教会中真实的今生。
- 真实的吗哪和水——上帝所赐救主真实的体和血。
- 真实地应许给犹太人的土地——真实的国，只是如今不是地上的，而是天上的。

## 吃树上的果子
人类真实地吃了树上的果子而远离上帝（[[gen 3:6]]）；人类也照样藉吃十字架之树的果子归向上帝。人藉不顺服之树远离上帝，又藉十字架顺服之树归回（[[fil 2:8]]；[[mf 16:24]]）。那树上的果子夺去生命，而这树上的果子使人归回生命。人从哪扇门出去，就从哪扇门进来。那时主说：“不可吃”（[[gen 2:17]]）——他们吃了。如今他说“拿着吃”（[[mf 26:26]]）——许多人犯着从前同样的错误，只是反过来——不吃。虽然那时和现在，遵守这诫命都不难：
> gen 3:3 :: !你们不可吃，也不可摸，免得你们死
> gen 2:17 :: !你不可吃，因为你吃的日子必定死
> mf 26:26 :: !你们拿着吃，这是我的身体
> in 6:58 :: !吃这粮的人，就永远活着
## 感恩的平安祭
旧约里有两类平安祭：
- **赞美**祭（תודה，todah）；
- **感恩**祭（或救恩祭）（שלמים shelamim 或 נדר neder）。
平安祭包括献饼和牲祭。**赞美**的平安祭用无酵饼献上，而若另外还献**感恩**的平安祭，则用有酵饼献上：
> lev 7:13 :: !要用有酵的饼和为感谢献的平安祭
在新约里，向上帝献饼的圣奥秘称为**“圣餐礼”（感恩祭，希腊文——感恩）**，因为基督自己在分给门徒之前**祝谢了**上帝并祝福了饼（[[lk 22:19]]；[[1kor 11:23-24]]）。
就是说，在正教会的圣餐礼中，今天字面地行的正是这些：
- 取有酵的饼；
- 献上感恩；
- 只是不与它一同献上祭牲，因为祭物、羔羊、逾越节——是被钉死又复活的基督。
要注意，无酵饼称为困苦饼（“ἄζυμα, ἄρτον κακώσεως”，[[vtor 16:3]]），而有酵饼的平安祭称为感恩祭或救恩祭（תֹּודַ֥ת——感恩，σωτηρίου——救恩，[[lev 7:13]]）。
*注：* *祭牲的肉或者当天吃掉、不留到早晨（如逾越节），或者可以吃两天，但严格禁止留到第三天。若没有在第三天之前吃完，剩余的就要用火焚烧，否则祭物就被上帝拒绝，成为玷污和罪。这把我们引向救主的复活——第三天坟墓空了。就是说，在这里有酵饼属于新约——救主的复活。*

# 对饼和酒的祝福
那位非物质的上帝——他从前从无中创造了宇宙，安排了普世的洪水，使太阳停住，在任何地方奇妙地赐下不同的食物和水，分开江河和海洋，多次改变物件的本质（杖、水），他自己成为物质的（道成肉身），以自己的祝福使饼和鱼增多（[[mf 14:15-21]]；[[mf 15:32-38]]；[[mk 6:35-44]]；[[mk 8:1-9]]；[[lk 9:12-17]]；[[in 6:5-13]]），为生来瞎眼的造了眼睛，使腐烂的肉身复原——在与门徒的逾越节晚餐上，不只是分了饼和酒，而是祈祷之后**祝福了它们**，称它们为自己的体和血：
> mf 26:26-28 :: !祝福，就擘开递给门徒 :: !你们拿着吃，这是我的身体 :: !又拿起杯来，祝谢了
不能把这祝福理解为无足轻重的空话。

# 对异议的回应
## “基督把自己比作门，是比喻？”
与民众交谈时，基督把自己比作羊圈的门：
> in 10:7 :: !我就是羊的门
既然基督在这里比喻地称自己为门，那么是否意味着圣餐中关于体和血的话也应当比喻地理解？完全不是。在与门比较之前，救主讲了牧人从门进羊圈、而贼从别处爬进去的比喻。把自己比作门，救主只是结束这个比喻，向民众解释它。基督对民众总是用比喻讲话，而与门徒单独在一起时则解释一切：
> mf 13:10-11 :: !对众人讲话为什么用比喻呢 :: !因为天国的奥祕，只叫你们知道，不叫他们知道
> mf 13:13 :: !所以我用比喻对他们讲
> mk 4:11 :: !若是对外人讲，凡事就用比喻
> mk 4:33-34 :: !若不用比喻，就不对他们讲 :: !没有人的时候，就把一切的道讲给门徒听
在锡安的楼房里**与门徒单独在一起**讲圣餐时，基督没有附加任何比喻，更没有关于体和血的比喻——就是说，基督是按字面讲的，而不是比喻。与民众交谈时，基督在讲圣餐的话上也没有附加任何比喻。他从关于旧约吗哪的谈话出发。这不是比喻，而是现实。犹太人真实地吃了吗哪，为了真实地不死。为了向听众指明吗哪只是预像，主才说：他们虽然吃了吗哪，吗哪只救他们免于饥饿，最终他们还是死了（正如人人都死），而吃他的人必不死（因为这已经不是预像，而是预像所指之物——赐永恒生命的真正从天降下的粮）：
> in 6:57-58 :: !吃我肉的人也要因我活着 :: !不像你们的祖宗吃过吗哪还是死了
## “我不再喝葡萄汁”
有人反对在圣餐中对体和血作实在的理解，引用基督在最后晚餐上关于葡萄汁的话。
三位福音史家——马太、马可和路加——都讲到葡萄汁（[[mf 26:29]]；[[mk 14:25]]；[[lk 22:18]]）。路加福音史家与马可和马太不同，更详细地描述了晚餐，提到喝过的几杯：
### 第一杯
> lk 22:15-18 :: !我很愿意在受害以先和你们吃这逾越节的筵席 :: !耶稣接过杯来，祝谢了 :: !你们拿这个，大家分着喝 :: !从今以后，我不再喝这葡萄汁
基督吩咐把杯中的东西分给门徒。这杯被分了。到这里还没有圣餐，没有关于体和血的话；有的只是逾越节的晚餐。在这杯酒之后，基督立刻说了那句关于他不再喝葡萄汁的话：
> lk 22:18 :: !从今以后，我不再喝这葡萄汁
而只有**饭后**（[[lk 22:20]]；[[1kor 11:25]]）基督才举行圣餐：拿起饼，又拿起杯（这已是另一杯，因为第一杯已经喝了），递给门徒，只是现在才说到自己的体和血：
### 第二杯
> lk 22:19-20 :: !这是我的身体，为你们舍的 :: !饭后也照样拿起杯来 :: !这杯是用我血所立的新约
这样，在前一部分举行的只是犹太人传统的逾越节晚餐，按习俗必喝**四杯酒**（掺水的）并感谢上帝。圣经里没有喝这四杯酒的命令。这只是犹太人的习俗。犹太逾越节晚餐的习俗在犹太的米示拿中有详细描述：
“米示拿第一篇
（ א ）在逾越节前夕，从晚祭之前起，人不可吃到天黑。即使在以色列中最穷的人也不可以不侧身而食。并且**不可少给他四杯酒**，即使是从施济处领的。”
（[俄文](https://toldot.com/articles/articles_30013.html)《米示拿·应户约》第10篇）
第一次基督只是行了这习俗：拿起杯，祝谢，递给自己的门徒，一句关于这是他的血的话也没有说，只说叫他们彼此分着喝——他们显然也这样做了。杯喝了。第一次完全没提饼。饭后才说到饼，又再说到杯，并且只是这时才出现关于基督的体和血的话。所以关于葡萄汁的话属于第一杯——葡萄的酒；而关于基督的血的话属于第二杯——在其中奥秘地递给门徒的已经不是酒，而是基督真实的血，这正是我们所信的。
## “叫人活着的乃是灵，肉体是无益的”（不带来益处）
教会圣餐教训的反对者宣称，基督只是象征性地讲到吃他的肉。他们引用下面的话：
> in 6:63 :: !肉体是无益的
象征论的拥护者这样解释这些话：仿佛吃基督的肉不带来任何益处。
我们则表明，“肉体无益”的话说的是肉体式的思维——它不带来益处。这是说那些只按地上的方式思想的人，粗糙地、按世俗的方式：只用他们在自己生活中习惯见到的方式，不能把思想提升到属灵的奥秘。
在圣经里我们可以遇到许多别的地方，这样的话被用于只按地上方式思想的人：
> mf 16:17 :: !这不是属血肉的指示你的
> gal 1:16 :: !我就没有与属血气的人商量
> gal 3:3 :: !你们既靠圣灵入门，如今还靠肉身成全吗
> ier 17:5 :: !倚靠人血肉的膀臂
这些人以为他们面前只是一个普通人、约瑟的儿子。一个普通人怎么能把自己的肉给他们吃？——只能像所有人那样：从自己身上撕下来给他们吃。这样的思维没有带给他们任何益处。他们大大地忧愁，说：“**这话甚难，谁能听呢？**”（[[in 6:60]]），就离开了。
然而基督不是普通人，而是全能的上帝。他设立圣奥秘：在其中他赐生命的体和血以奥秘的方式、藉上帝的能力、以饼和酒的形式被分予。为此需要属灵地思想，为那理智并不总能明白的奥秘性举行留下位置，为基督话语的超越地上秩序的超性成就留下位置：
> in 6:53 :: !你们若不吃人子的肉，不喝人子的血，就没有生命在你们里面
## 为什么要“吃上帝”？
这样的问题多是穆斯林问的。新教徒也向教会提这个问题，只是形式稍有不同，实质相同。
对这个问题的回答可以很长，但这里只给出总的想法：领圣体使人进入与上帝基督最亲密的相通：不仅是属灵的，也是身体的——因为上帝造人不仅用灵魂，也用身体。
实际上，除了亚当和夏娃，每个人从出现在这个世界上的最初时刻起，就是以另一个人的身体——自己母亲的身体——为食的。如果他不是这样，就不能有生命，不能成长发育，必定灭亡——当胎儿（胚胎）不能着床时，事情正是如此。
婴儿出生时，他的身体是由母亲的身体构成的。母亲的身体交出自己，把生命给了婴儿，这样两者（母亲和婴儿）处于身体的相通之中。即使出生之后，婴儿还要长时间以母亲的身体为食，因为婴儿所喝的奶是在母亲的身体里由她的血造成的。所以，在这个意义上，奶——就是母亲的血。
两个过程（生育和圣餐）的设立都是上帝的。
认识了上帝所造的人性及其诞生和滋养的过程，在圣餐中承认类似的过程就不足为奇了——在圣餐中我们吃的已不是母亲的身体，而是基督上帝的身体；这样我们与上帝进入的不仅是属灵的，也是身体的相通——与基督完全的相通，灵与体：
