# 与亚玛力人的争战
耶稣基督在十字架上救赎性祭献的预像，是旧约中的一件事：以色列民与亚玛力人的争战。先知摩西在山上祈祷，他举手时以色列人就得胜（[[ish 17:11]]）；他因疲乏垂手时，民众就开始败退。以色列民与亚玛力人争战时在山上的先知摩西。亚伦与户珥扶着他的手（[[ish 17:11-12]]）。争战持续了一整天，摩西不能一直举着手，所以亚伦与户珥帮助摩西，搬石头来放在他以下让他坐下，从两边扶着他的手：亚伦扶一只手，户珥扶另一只（可以说，如同钉子固定着基督的手）。摩西就以这样的姿势在山上（如同基督的十字架在山上）直到日落（[[ish 17:12]]）（如同基督一样）。情形如下：
- 约书亚（以色列民的统帅）的军队［如同基督军队——教会的元首］
- 借着十字架战胜了亚玛力人［如同基督借十字架得了胜利（[[ef 2:16]]）］，
- 十字架由摩西在山上摆出［如同基督的十字架在各各他山上］，
- 摩西被人在这样的姿势中扶持着［如同基督在十字架上被固定着］
- 直到一天结束［如同基督一样］。

上帝规定了以色列各支派营阵的排布。他们要这样安营，也要这样行进。以色列的营阵构成一个十字。
- 营的中心是会幕：
> chis 2:2 :: !对着会幕的四围安营
同时，营的中心是利未支派：
> chis 2:17 :: !有利未营在诸营中间 :: !他们怎样安营，就怎样往前行
- 东边：犹大支派，然后以萨迦，然后西布伦：
> chis 2:3,5,7 :: !是犹大营的纛 :: !是以萨迦支派 :: !又有西布伦支派
- 南边：流便支派，然后西缅，然后迦得：
> chis 2:10,12,14 :: !是流便营的纛 :: !是西缅支派 :: !又有迦得支派
- 西边：以法莲支派（约瑟的），然后玛拿西（约瑟的），然后便雅悯：
> chis 2:18,20,22 :: !是以法莲营的纛 :: !是玛拿西支派 :: !又有便雅悯支派
- 北边：但支派，然后亚设，然后拿弗他利：
> chis 2:25,27,29 :: !是但营的纛 :: !是亚设支派 :: !又有拿弗他利支派
***注**：这样的排布需要13个营（1+3+3+3+3），而雅各的儿子只有12个。这里列举了所有的支派，但约瑟的一个支派由他两个儿子的支派代替：玛拿西和以法莲。
# 十字的每一边都按最靠近中心的支派之名计数
先列举犹大营的数目：
> chis 2:3-4 :: !共有七万四千六百名
然后列举犹大之后各支派的人数：
> chis 2:6 :: !共有五万四千四百名
> chis 2:8 :: !共有五万七千四百名
然后全部加在一起，以犹大（最靠近中心的支派）之营命名，其数目已包括所有三个营：
> chis 2:9 :: !凡属犹大营按着军队被数的，共有十八万六千四百名 :: !要作第一队往前行
其余各边也都这样重复。

@@ крест-и-крещение-переход-через-море | QO4A_十字架与洗礼——过红海 | 十字架与洗礼——过红海 | | 关于过红海之预像意义的引文 | 旧约/预表 | 十字架与洗礼——过红海 | 4
以色列民从埃及的奴役中走过红海底——是洗礼的预像（[[1kor 10:2]]），是脱离罪的奴役的出走。先知摩西命令红海的水回到原处（[[ish 14:26-27]]）。上帝指示先知摩西举杖把水分开（[[ish 14:16,21]]），而当民众走到对岸之后，摩西要用手命令水回到原处（[[ish 14:26-27]]）。按情理，这是横向的动作，与先前分开水流的纵向动作相对。这样就得到一个十字：
- 「之前」分开的纵向动作「|」。
- 「之后」连接的横向动作「—」。
这样就成了一个十字（「|」与「—」相加即「＋」）。以色列民借十字架脱离了奴役。正如我们借着基督的十字架脱离罪的奴役，受浸入洗礼之水中。

**在先知以西结的异象中，书记员要在一些人的额上画上记号**「𐤕」（腓尼基字母Tau）。
先知以西结见到关于犹太人可憎之事的异象，为此上帝差遣刑罚者前来，由书记员带领。书记员把记号画在那些人的额上——那些人对这些可憎之事同样憎恶，如同上帝一样。按上帝的指示，有这记号的人不会受刑罚触及。
> iez 9:4-6 :: !那些因城中所行可憎之事叹息哀哭的人，画记号在额上 :: !只是凡有记号的人不要挨近他 ~~ 俄文本引用处误作 Иез 1:4-6；经文实为 Иез 9:4-6。
在希伯来文中「画记号」写作「הִתְוִיתָ **תָּו**」[taw-vaw' tawv]。
直译可以译作「画上**תָּו**」（Tau字母），但先知以西结出生之时，犹太人还在使用腓尼基文字或源自腓尼基文字的古希伯来文字；按那种文字，Tau字母写作「𐤕」。这样，按字面写的是：「**画上**𐤕」。
古代基督徒也同样在自己额上画十字：[[ru:крестное-знамение|十字圣号]]
<hr>
犹太人从基督降生前约十世纪到七世纪使用腓尼基字母（源自腓尼基字母的古希伯来字母）。也就是说，它使用到巴比伦之囚为止。犹太人在16年中分几个阶段被掳往巴比伦（<a href="https://ru.wikipedia.org/wiki/Вавилонский_плен">公元前598—582年</a>）。
先知以西结生活的年代约为<a href="https://ru.wikipedia.org/wiki/Иезекииль">公元前约622年——约公元前570年</a>（共52年）。
<a href="https://azbyka.ru/days/sv-iezekiil">25岁</a>时，他与自己的民族一同被掳。
也就是说，他出生并受教育时还在使用腓尼基文字。
<a href="https://ru.wikipedia.org/wiki/Иезекииль">30岁</a>时，他的先知事奉开始（[[iez 1:1]]）。
此时以西结写他的先知书。
我们所关注的事件记载于第8-9章，发生在再过一年零两个月之后（[[iez 8:1]]）。
无论如何，我们来到公元前七至六世纪之交、巴比伦之囚的最开始，此时犹太人的新文字才开始逐渐形成。字母并不是一下子改变的，这在被掳期间经历了很长时间。
最可能的是，先知还在使用犹太民族所能明白的腓尼基文字，相应地，把Tau写作「𐤕」。如果这是正确的，那么书记员要在人的额上画上「𐤕」这个符号，使他们免受刑罚——这也把我们引向主的十字架的救赎意义。
