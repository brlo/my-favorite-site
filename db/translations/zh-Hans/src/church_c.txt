## 里昂的伊里奈乌斯（二世纪）论圣殿是天上的实体的象征
圣殿按天上实体之像的建造，由圣里昂的伊里奈乌斯（二世纪）所证实。伊里奈乌斯引用神学家约翰的启示录，说地上的事物作天上事物的像是合宜的——这些天上的事物也是由同一位上帝所造：
“所以，正如他[上帝]在这些事[祭物]上并无所缺，却愿意我们为自己而行这些事，免得我们不结果子；同样，圣言也把关于祭物的诫命赐给了（犹太）民族，虽然他并不需要它们，为要叫他们学习事奉上帝；基于同样的原因，他愿意**我们也常常、按时地把礼物带到祭坛前**。
这样，**在天上有祭坛**，因为我们的祈祷和献礼是朝那里去的；也有**圣殿**，正如约翰在启示录里所说：“天上上帝的殿开了”（启 11:19），还有帐幕：“看哪，上帝的帐幕在人中间，他要与人同住”（启 21:3）。祭物、献礼和一切祭品，（犹太）民族是按预像领受的，正如摩西在山上所受的指示——是来自同一位上帝，他的名如今在教会里、在万民中被称颂。但是，**在我们周围所安排的地上的事物，作天上事物的像是合宜的**——这些天上的事物也是由同一位上帝所造。**否则，他就无法把属灵事物的相似之物拉近到我们的悟性面前**。”
（[俄文](https://azbyka.ru/otechnik/Irinej_Lionskij/protiv-eresej/4)《驳异端》卷四，第18-19章）

# 基督命令不要称呼人为师、为父
> mf 23:2,5-9 :: 喜爱筵席上的首座，会堂里的高位 :: 称呼他拉比 :: !但你们不要受拉比的称呼 :: !也不要称呼地上的人为父
这话不能按字面理解，正如关于截去肢体的话（[[mf 5:29-30]]），以及基督说他来不是叫地上太平、乃是叫地上动刀兵的话（[[mf 10:34-35]]）不能按字面理解一样。这里教导的是谦卑：使信徒不去追求被人称呼“拉比、拉比”（[[mf 23:7]]），得到这些称呼之后也不骄傲自高，而要明白：至高的权柄、真正的父和师傅——是上帝。
重要的是从上下文出发正确理解这话的意思，否则就会得出连孩子也不能称呼自己的父亲为父的结论，尽管上帝在诫命里正是这样称呼他们的（[[vtor 5:16]]）。同样，也不能说任何教师都不可以称为教师，尽管教会里毫无疑问有教师。从圣经我们看到，使徒们并没有回避这些称呼。

# 基督徒的理想
基督徒的理想——一生只有一个婚姻。
# 对平信徒的宽免
如果妻子或丈夫死了，虽然新的婚姻不受鼓励（因为基督徒相信来生和死人普遍的复活），但作为宽免的措施是允许的——使徒说过这一点，为的是不叫人陷入某种致死的重罪而彻底灭亡：
> 1kor 7:8-9 :: 寡妇 :: !与其欲火攻心，倒不如嫁娶为妙
> 1tim 5:14 :: 我愿意年轻的寡妇嫁人
同样，救主在论到不可离婚时，也为了淫乱（变心）的情形开了例外：
> mf 5:31-32 :: 若不是为淫乱的缘故
这样，如果配偶死了或变了心，新的婚姻是可能的。但仍然不是无限制的，而只是作为宽免的措施，总共只可以有两次。
循着类似的推理，教会又为此加上了一些别的原因，例如配偶有生命危险等等（[俄文](https://azbyka.ru/otechnik/dokumenty/osnovy-sotsialnoj-kontseptsii-russkoj-pravoslavnoj-tserkvi/#0_10_3)）。
