# 正教会的理解
正教会教导：主耶稣基督是唯一的中保。是怎样的中保？是那舍自己作万人**赎价**的中保（[[1tim 2:5]]）。其余的圣人不是救赎者。同祷者却有许多：
> 2kor 1:10-11 :: !现在仍要救我们 :: !并且我们指望他将来还要救我们 :: !你们以祈祷帮助我们 :: !就是为我们因许多人所得的恩
他们是圣洁的义人、上帝的朋友：上帝之母、天使、先知、使徒、殉道者和其余的圣人。如同使徒在这里被人请求代祷，在天上也有人求他代祷。以为每个人都应当只为自己的利益向上帝祈祷的想法，与圣经格格不入。相反，圣经中多次召呼全教会彼此代祷（[[iak 5:16]]）。所有的人——甚至最伟大的义人和上帝的特选者——不放弃向上帝的祈祷，也请求信徒们为他们祈祷，自己不住地为信徒祈祷，并吩咐将来也要守这规矩。这也称为彼此代求。
我们从教会知道、并以圣经证实：义人在与身体分离之后进入与上帝同在的生活，并继续向他献上自己的祈祷。因此，如同这些义人活着、身体还在地上时我们曾求他们的祈祷，同样在他们与身体分离、进入天上与基督明显的同在后，我们也求他们的祈祷（[[evr 12:22-23]]）；因为他们不是进入更坏的境地，而是更好的境地（[[fil 1:23]]）。我们相信爱永不止息（[[1kor 13:8]]），因此整个教会——地上争战的和天上得胜的——是一个合一的、完整的、相通的教会，共同地彼此祈祷，并被爱催促关怀自己所有的肢体。我们也信、并从教会知道、且在圣经中表明：我们的护守天使与上帝有相通（[[mf 18:10]]），被差遣事奉那将要承受救恩的人（[[evr 1:14]]）；而圣洁的义人住在上帝圣光之中，也知道地上发生的事，并为教会向上帝献上祈祷（[[otkr 6:9-11]]）；永恒的爱催促众人在基督的一个身体里彼此相通、彼此关怀：在天上，也在地上。

# 对异议的回应
## 一位中保
### 简答
正教徒因向圣人祈祷而受指责，说只有基督才是唯一的中保。回答是：基督是唯一的、救赎了世人的中保，如同一节经文接着说的：
> 1tim 2:5-6 :: !只有一位中保 :: !乃是降世为人的基督耶稣 :: !他舍自己作万人的赎价
圣徒们不是救赎者，而是同祷者（[[iak 5:16]]）。一切在于意义。我们的反对者（通常是新教徒）彼此为对方的所需祈祷。如果他们彼此是中保，那圣人也是我们的中保。如果他们彼此是同祷者，那圣人也是我们的同祷者：因为我们只是求他们为我们祈祷、加入我们向上帝的祈祷。我们不把他们当作神，也不把他们当作神来祈祷——同样，新教徒请人代祷时，也不把自己的伙伴当作神。
可以有代祷的中保吗？——从圣经显然可见：可以。例如，因教会司祭的祈祷，另一个人的罪可以得赦。
> iak 5:14-15 :: !该请教会的长老来 :: !为他祷告 :: !他若犯了罪，也必蒙赦免
无可争议的代求。这样，反对向圣人祈祷的人对基督作为唯一中保之言（[[1tim 2:5-6]]）的理解是不正确的。所引的经文并不反对祈祷中的代求者。
### 更详细地论“中保”一词
还有翻译上的特点。“中保”一词译自希腊文 μεσίτης。它可以译作“和平的缔造者”——促成双方和好的人。也就是说，换言之，基督是上帝与人之间唯一的**和好者**（缔造和平者）。使徒们在别处说得更明白：
> 2kor 5:18-19 :: !他借着基督使我们与他和好 :: !又将劝人与他和好的职分赐给我们 :: !这就是上帝在基督里叫世人与自己和好 :: !并且将这和好的道理托付了我们
> 1in 2:1-2,12 :: !若有人犯罪 :: !在父那里我们有一位中保 :: !就是那义者耶稣基督 :: !他为我们的罪作了挽回祭 :: !小子们哪，我写信给你们，因为你们的罪借着主名得了赦免
把“中保”译作**和好者**或缔造和平者，也与句子的结尾相合，如前所指：“他舍自己作万人的赎价”（[[1tim 2:5-6]]）。这样一位缔造和平者，藉把自己作为祭物献上，赎了人类在上帝面前的罪。所以这节经文不是反对向圣人祈祷，而是讲到基督作为人类与上帝的**和好者**。基督也是人与人之间的**和好者**（[[ef 2:14]]）。
## 关于“拯救我们”的说法
正教徒因允许在向圣人的祈祷中用“拯救我们”的话而受指责。这里又是在于意义。拯救是基督一次成就的。在这一意义上再没有别的救主。但许多人可以促进具体个人的得救。这样的说法在圣经中也常见：
### 使徒救人
> rim 11:14 :: !或者可以激动我骨肉之亲发愤 :: !好救他们一些人
> 1kor 9:22 :: !无论如何总要救些人
### 妻子救人
> 1kor 7:16 :: !你这作妻子的，怎么知道不能救你的丈夫呢 :: !你这作丈夫的，怎么知道不能救你的妻子呢
### 使徒呼召拯救别人
> iud 1:22-23 :: !有些人你们要从火中抢出来 :: !搭救他们
> 1tim 4:16 :: !又能救自己，又能救听你的人
## 难道除了基督还有谁能救人吗？
无论使徒还是夫妻，都不是主耶稣基督意义上的救主——他是唯一的救赎者，把人类从死亡和阴间中救出、赐复活和与上帝同在的永生。但如上所见，“我要救”这样的说法是使徒们所用的。我们正确地理解这些话的意义——人可以促进得救：
> 1kor 3:9 :: !因为我们是与上帝同工的
## 关于“怜悯我们”的说法
这里情形与“拯救”相同（见上）。这样的说法不只向圣徒，也向普通人发出。怜悯，就是施以恩惠。例如，义人约伯对自己的朋友们说：
> iov 19:21 :: !我朋友啊，可怜我！可怜我
## 圣徒怎么能听见来自全世界的祈祷？
反对向圣人祈祷的人说：“上帝是无所不在、全能的；而圣人如果不具备这些属性，那他们怎么能听见地球上不同地方众多人的祈祷？”
### 圣徒们说预言、行奇迹，不是靠自己的力量，而是靠上帝的力量
圣徒们不是离开上帝单独被考察的。就是在地上身体活着的时候，上帝的能力也住在他们里面；更何况在迁往天上、与基督同活之后，他们更不会失去这一点。先知亚迦布虽不是无所不知的，却宣告了将临到天下的大饥荒（[[act 11:28]]）。使徒彼得不是全能的，却复活了多加（[[act 9:40]]）。他们作这些不是靠自己的力量，而是靠上帝的力量。
圣徒们如使徒所言，进入的不是更坏的，而是好得无比的境地（[[fil 1:23-24]]）：不是失去，而是获得（[[fil 1:21]]）。他们与上帝联合，在他的光和恩典中。他们的存在不能与我们的相比。他们知道地上发生的事（[[otkr 6:10]]）。甚至还在身体里的时候，使徒们就写道，他们灵里与基督徒同在：
### 使徒不在身体里，而在灵里知道基督徒团体的情况
> kol 2:5 :: !我身子虽与你们相离，心却与你们同在
> 1kor 5:3-5 :: !我身子虽不在你们那里，心却在你们那里 :: !就是你们聚会的时候，我的心也同在 :: !使他的灵魂在主耶稣的日子可以得救
> 1kor 8:3 :: !若有人爱上帝，这人乃是上帝所知道的
### 得救的人有护守天使
如经所记，天使被差遣事奉得救的人：
> evr 1:14 :: !天使岂不都是服役的灵 :: !奉差遣为那将要承受救恩的人效力吗
同时，天使常常见上帝的面（[[mf 18:10]]）。甚至他们就可以转达我们的祈祷。我们不只向圣人们祈祷，也向圣天使祈祷：求他们为我们代祷，为他们的劳苦和关怀感谢他们。
反对地上教会与天上教会相通的人，甚至不允许感谢被差来事奉我们的护守天使——而这天使并不需要无所不在、无所不能才能听见我们。
这样，教会相信：圣徒们因住在上帝的光和恩典中而能听见我们的祈祷。与上帝的合一赐给他们这样的可能。是上帝自己赐给他们这样的可能。所以，用最简单的话说：圣徒们能听见祈祷，不是由于自己的能力，而是由于上帝和他的能力。
## 教会怎么知道谁是圣人？难道是人替上帝作决定吗？
人不是替上帝作决定。上帝按自己的应许（[[ru:почитание-святых-в-Библии#HH-Святые-будут-в-чести|引文]]），自己荣耀自己的圣人，显明奇迹，垂听他们的祈祷。教会只是为此作见证，并把民间对圣人的敬礼理出秩序，免得混乱——正如使徒所吩咐的：
> 1kor 14:40 :: !凡事都要规规矩矩的按着次序行
*规矩——即次序
> 2sol 3:11 :: !有人不按规矩而行，什么工都不作
教会关于义人之圣洁的见证和敬礼秩序的设立（封圣），通常远在义人去世之后，那时对这一问题的研究，不但可以依据义人地上的生活，还可以依据上帝在义人迁往天上、与上帝同活之后所显明的事。
从教会的肢体们收集关于奇迹、医治——在义人坟墓旁发生的——以及义人祈祷之助的见证。仔细考察他生活和信仰的纯洁。之后教会共同地研究所收集的信息，可以批准把义人作为圣人敬礼，并为此撰写教会文本和圣像，设立纪念日。这某种意义上是把教会民间已经在发生的敬礼理出秩序，确认这敬礼的正确性，把敬礼纳入事奉圣礼。
不过，许多义人的圣洁无需作见证，因为这由圣经和教会的圣传可知。著名的圣人无疑包括童贞女马利亚上帝之母（上帝为她成就了大事，[[lk 1:49]]）、圣祖、先知、使徒、他们所立的主教、司祭和辅祭（例如首位殉道的六品执事司提反，[[act 7:55-60]]）、众多的殉道者。此外，教会不只向圣人们祈祷，也向圣天使祈祷：总领天使米迦勒、加百列，以及[[ru:ангел-хранитель|护守天使]]等。为天使的圣洁作见证是多余的，因为这是人所共知的上帝的仆人。
# 重要的说明
在为向圣人祈祷辩护之前，必须坚定地领会一个关键点：反对者没有对禁止向圣人祈祷作出正面的解释。反对者言论的基础只有一句话：“圣经里没有说”。这是他们解释的否定部分，他们会坚持它。而正面的部分——即对这一禁止的明确理解——他们没有。
基督复临安息日会的人部分地可以提出解释，因为他们不相信人死后灵魂的生活。不过，安息日会的人也无法解释为什么不能向天使祈祷——因为天使的存在他们目前并不否认。按圣经，天使被派给得救的人，关怀人的得救（[[evr 1:14]]）；为什么对他们什么都不可以说？他们无法解释。
至于其余的（新）新教徒，他们大多数相信人在与身体分离后灵魂的生活，所以他们完全无法解释：为什么不能与天上的教会相通——而我们现在已经来到她面前（[[evr 12:22-23]]）；为什么不能与圣祖们、使徒们、殉道者们、天使们交谈。当然，他们会试图说些什么，但那总是不能令人信服。例如会说，圣徒们进入了上帝的安息，所以仿佛不再挂念地上的事了。但那样就得出上帝也不挂念地上的事，因为他也在同一个安息里。他们其余的辩解也同样荒谬。
向圣人祈祷的必要性是从圣经隐含地（逐步地）推论出来的，就是说，这一必要性没有直接指明，而是被蕴含的。这是正常的，因为圣经里不是一切都说得直白。关于上帝是三位一体这一最主要的教训，就是从圣经隐含地推论出来的。我们的反对者自己也从圣经隐含地推论许多东西。例如，任何地方都没有说不能给婴儿施洗，然而他们不合理地断言不能给婴儿施洗，并且不因圣经里没有说而困扰。他们试图从圣经的别的论断隐含地推出这一禁止。所以极重要的是把他们引到这个领域，请他们对禁止向圣人祈祷给出一个有意义的理解。
还有，亲爱的朋友，也要记住：反对向圣人祈祷的人，所反对的根本不是代求性的祈祷（因为很容易证明：他们彼此祈祷时自己就是彼此的代求者，无论他们怎样争辩）。他们最反对的，是**地上教会与天上教会的相通**——反对与圣洁的灵——圣天使和圣人们、上帝的朋友们——的任何相通。仿佛地上的教会对天上的教会生了气，不愿意与她交谈；仿佛基督身体的一部分不愿与同一身体的另一部分相通。他们连一句话都不允许，甚至不允许向护守天使为他的关怀感谢一句。因为一旦承认与属灵世界中的圣人们哪怕最小的相通可能，很快留给他们的，就只剩下一步一步地承认与地上教会和天上教会的相通相关的一切了。所以，作为问题之一，值得考察与天使相通的可能——圣经中这一点展现得非常广泛。
