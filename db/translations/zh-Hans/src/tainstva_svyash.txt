# 旧约中司祭职的上帝设立
司祭——只是亚伦的后裔：
> ish 29:9 :: !给亚伦和他儿子束上腰带 :: !他们就凭永远的定例得了祭司的职任
司祭职与圣衣、膏抹一同传递：
> ish 29:29 :: !亚伦的圣衣要留给他的子孙 :: !可以穿着受膏，又穿着承接圣职
外人若近前来行事奉的礼，必须治死。司祭职的职责就是看守这事：
> chis 3:10 :: !你要嘱咐亚伦和他儿子，谨守自己祭司的职任 :: !近前来的外人必被治死
详细：
> chis 18:1-3,7 :: !耶和华对亚伦说 :: !你和你的儿子，并你本族的人 :: !你要带你弟兄利未人 :: !使他们与你联合，服事你 :: !你和你的儿子要一同在法柜的帐幕前供职 :: !只是不可挨近圣所的器具和坛 :: !你和你的儿子要为一切属坛，和幔子内的事，一同守祭司的职任 :: !我将祭司的职任给你们当作赏赐事奉我 :: !凡挨近的外人必被治死
# 新约中司祭职的更换
主耶稣基督订立新约（[[lk 22:20]]；[[evr 8:8]]），改变律法，更换司祭职（是更换，而不是废除）：
> evr 7:12 :: !祭司的职任既已更改，律法也必须更改
救主把圣灵赐给使徒，按麦基洗德的等次设立司祭的等次；他自己成为大祭司：
> evr 7:1-3; evr 6:20 :: !又是至高上帝的祭司 :: !他头一个名繙出来就是仁义王 :: !就是平安王的意思 :: !无父、无母、无族谱、无生之始、无命之终 :: !乃是与上帝的儿子相似
> evr 8:1 :: !我们有这样的大祭司，已经坐在天上至大者宝座的右边
# 教会等次的形成
在五旬节那天，圣灵被赐给使徒和整个教会聚会——赐给整个教会。但在这天之前，救主只向使徒们显现，并且只把圣灵赐给他们，把赦罪之权赐给他们如同司祭一样——就是说，设立等次：
> in 20:21-23 :: !父怎样差遣了我，我也照样差遣你们 :: !你们受圣灵 :: !你们赦免谁的罪，谁的罪就赦免了 :: !你们留下谁的罪，谁的罪就留下了
同样，在旧约的教会里，洁净罪的事正是在司祭职上：
> lev 5:5-6 :: !就要承认所犯的罪 :: !祭司要为他赎了
# 新等次的权柄
主把天国的钥匙、捆绑和释放的权柄赐给使徒：
> mf 16:19 :: !凡你在地上所捆绑的，在天上也要捆绑 :: !凡你在地上所释放的，在天上也要释放
> mf 18:18 :: !凡你们在地上所捆绑的，在天上也要捆绑 :: !凡你们在地上所释放的，在天上也要释放
司祭职由使徒们拣选并按立，但圣经宣告：立长老看守教会的正是圣灵：
> act 20:17-18,28 :: !请教会的长老来 :: !圣灵立你们作全群的监督 :: !牧养上帝的教会
这一切——是旧约预言的应验，见下文。
# 关于新约司祭职的预言
在旧约的教会里，司祭只从犹太民族中立——利未支派、亚伦的家系。而在新约的教会里，司祭将从一切民族中立，而不只是从犹太人（亚伦的家系）中：
> is 66:18-21 :: !我必将万民万族 :: !并素来没有听见我名声、没有看见我荣耀辽远的海岛 :: !我也必从他们中间取人为祭司，为利未人
# 使徒传承与按立的教训
## 主教的按立
主教提摩太藉使徒的按手、并有先前已被按立的主教们的按手，领受了特别的恩赐：
> 2tim 1:6 :: !使你将上帝藉我按手所给你的恩赐
> 1tim 4:14 :: !你不要轻忽所得的恩赐 :: !就是从前借着预言、在众长老按手的时候赐给你的
行邪术的西门看见，不是每个基督徒都能按手以赐下圣灵。字面上说：不是人人都有这权柄。他拿钱给使徒，要他们也给他这权柄（使徒们为此咒诅了他）：
> act 8:18-20 :: !西门看见使徒按手，便有圣灵赐下 :: !把这权柄也给我 :: !叫我手按着谁，谁就可以受圣灵 :: !你想上帝的恩赐是可以用钱买的

## 主教与长老——区别
主教（希腊文 ἐπίσκοπος——监督）和长老（希腊文 πρεσβύτερος——年长者、团体之首）这两个概念交叉使用，仿佛可以互换。然而，具体之人的职分和权柄看得清楚，无论他们如何被称呼。提多应当完成使徒的事业，在克里特设立长老：
> tit 1:5 :: !又照我所吩咐你的，在各城设立长老
提摩太可以审判自己的长老、责备和警戒信徒：
> 1tim 5:19 :: !控告长老的呈子，非有两三个见证就不要收
> 2tim 4:2 :: !务要传道 :: !责备人，警戒人，劝勉人
这样，提多和提摩太按今天的理解是主教，虽然被称为长老。
## 人人都是司祭吗？
### 与旧约话语的平行
使徒彼得重复旧约的话，称所有基督徒为君尊的祭司和圣洁的国民：
> 1pet 2:9 :: !惟有你们是被拣选的族类，是有君尊的祭司，是圣洁的国度
这些话在旧约里是对全以色列说的：
> ish 19:5-6 :: !你们要归我作祭司的国度，为圣洁的国民
这样，上帝称旧约的以色列为祭司的国度和圣洁的国民。然而，在事奉圣礼的意义上，并不是所有犹太人都是司祭。按律法，只有亚伦的司祭职可以进帐幕，其余的人若进帐幕就须以自己的生命付出代价，即他们必须死（[[chis 3:10]]；[[chis 3:38]]；[[chis 18:7]]）。
如果在旧约里要把这些话分开——祭司的国度（不是所有人）和圣洁的国民（所有人），那么对新约使徒的话也得同样承认：君尊的祭司（不是所有人）、圣洁的国度（所有人）（[[1pet 2:9]]）。这些话可以按字面理解，也可以按寓意理解，但无论如何，都得把这两句话联系在一起，在同一意义上理解它们。
### 旧约中建立普遍祭司职的企图
在旧约里，上帝设立的秩序是：只有亚伦的后裔可以作司祭：
> ish 29:29 :: !亚伦的圣衣要留给他的子孙
甚至亚伦的家系也不是人人都能作司祭：
> lev 21:21,23 :: !祭司亚伦的后裔，凡有残疾的，都不可近前来将火祭献给耶和华 :: !免得亵渎我的圣所
反对这神圣秩序的，是**可拉、大坍、亚比兰和安**，他们要求先知摩西从全民族中立司祭，而不只是从亚伦的家系。他们引用的正是那句话（[[ish 19:5-6]]），说人人都圣洁：
> chis 16:3 :: !全会众个个既是圣洁，耶和华也在他们中间 :: !你们为什么自高，超过耶和华的会众呢
> chis 16:10 :: !你们还要求祭司的职任吗
之后上帝的荣光显现，地开了口，吞灭了叛乱者：
> chis 16:19-21 :: !可拉招聚全会众到会幕门前 :: !你们离开这会众，我好在转眼之间把他们灭绝
上帝吩咐把叛乱者的香炉中的火倒出，用那些香炉包祭坛，作后世的记念：
> chis 16:37-38 :: !把那些犯罪自害己命之人的香炉，叫人锤成片子，用以包坛 :: !并且可以给以色列人作记号
> 1kor 10:11 :: !他们遭遇这些事都要作为鉴戒
使徒犹大也记念可拉灭亡的顽梗：
> iud 1:11 :: !并在可拉的背叛中灭亡了
还有预言说，在末后的日子这样的人要起来：
> 2tim 4:3 :: !耳朵发痒，就随从自己的情欲，增添好些师傅
### 关于新约中立司祭的预言
还在旧约里就有预言：在新约里仍要立司祭和仆人，但从一切民族中立，而不只是从亚伦的家系：
> is 66:18-21 :: !我必将万民万族 :: !我也必从他们中间取人为祭司，为利未人
新约里指明，没有人可以自己取得司祭职：
> evr 5:1-5 :: !凡从人间挑选的大祭司，是奉派替人办理属上帝的事 :: !这大祭司的尊荣，没有人自取 :: !惟要蒙上帝所召，像亚伦一样 :: !如此，基督也不是自取荣耀作大祭司
### 信了并受了洗的行邪术的西门没有传递圣灵恩赐的恩赐
行邪术的西门，如经所记，信了并受了洗：
> act 8:13 :: !西门自己也信了，既受了洗
但当他明白不是所有基督徒都能传递圣灵的恩赐时，就试图向使徒们买这恩赐。使徒们为此咒诅了他：
> act 8:18-23 :: !西门看见使徒按手，便有圣灵赐下 :: !把这权柄也给我 :: !叫我手按着谁，谁就可以受圣灵 :: !彼得说 :: !你想上帝的恩赐是可以用钱买的 :: !你在这道上无分无关 :: !你当懊悔你这罪恶 :: !我看出你正在苦胆之中
由此可见，不是所有基督徒都是有职分和上帝恩赐的司祭，能传递圣灵。给撒玛利亚人施洗的六品执事腓利也没有这恩赐（[[act 21:8]]）。而有这恩赐的人，是藉使徒的按手（[[2tim 1:6]]）和司祭职的按手（[[1tim 4:14]]）领受的。
这样：
- 不是所有人都受了教导并施洗的托付：“所以，**你们要去，使万民作我的门徒，奉父，子、圣灵的名给他们施洗**”（[[mf 28:19]]）
- 不是所有人都受了命令：“**你们应当如此行，为的是记念我**”（[[lk 22:19]]；[[1kor 11:24]]）
- 不是所有人都得了捆绑和释放的权柄：“凡你们**在地上所捆绑**的，在天上也要捆绑；凡你们**在地上所释放**的，在天上也要释放”（[[mf 18:18]]）
- 不是所有人都得了赦罪和不赦罪的权柄：“**你们赦免谁的罪**，谁的罪就赦免了；**你们留下谁的罪**，谁的罪就留下了”（[[in 20:23]]）
- 不是所有人都得了按手赐圣灵的权柄：“**西门看见使徒按手，便有圣灵赐下**”（[[act 8:18]]）
- 使徒吩咐请来的，正是长老，病人藉他们的祈祷和事奉（用油抹）可以得赦罪：“**他就该请教会的长老来**，他们可以**奉主的名用油抹他**，为他祷告。……**他若犯了罪，也必蒙赦免**”（[[iak 5:14-15]]）
# 君尊的祭司——如何理解？
无论在旧约还是新约，每个信徒都被召在自己的殿——自己的身体——里作祭司。[[ru:человек-храм-Божий|人——上帝的殿]]，而祭司就是在这殿里向上帝献祭的人。使徒彼得正是从这个思想开始，然后才讲到君尊的祭司：
> 1pet 2:5 :: !被建造成为灵宫 :: !作圣洁的祭司 :: !奉献上帝所悦纳的灵祭
讲君尊的祭司时，使徒彼得在同一封书信里也讲到牧人和必须顺服他们：
> 1pet 5:5 :: !你们年幼的也要顺服年长的 :: !因为上帝阻挡骄傲的人，赐恩给谦卑的人
还有一处关于基督徒为祭司的话：
> otkr 1:5-6 :: !又使我们成为国民，作他父上帝的祭司
> otkr 5:9-10 :: !又叫他们成为国民，作祭司，归于上帝，在地上执掌王权
> otkr 20:6 :: !他们必作上帝和基督的祭司
基督徒怎样是王，也就怎样是祭司。如果他现在不掌管外在的人，也就不是外在之人的祭司。这样的解释对上下文是诚实的，也符合常识。
基督徒被召在自己的身体里为王——使自己的理智掌管身体的私欲；而洁净了这上帝的殿（自己的身体和心）之后，应当在那里献上蒙上帝悦纳的祭：纯洁的思想、言语、行为、祈祷和颂赞。

# 对异议的回应
## “藉按手赐下圣灵——这只是西门的误解？”
正教徒在圣经里指出关于藉按手传递圣灵之特殊恩赐的引文。这些引文中有行邪术的（术士）西门的情形。
行邪术的西门看见，不是每个基督徒都能按手以赐下圣灵。字面上说：不是人人都有这权柄。他拿钱给使徒，要他们也给他这权柄（使徒们为此咒诅了他）：
> act 8:18-20 :: !西门看见使徒按手，便有圣灵赐下 :: !把这权柄也给我 :: !叫我手按着谁，谁就可以受圣灵 :: !你想上帝的恩赐是可以用钱买的
批评者说，这只是行邪术的西门的错误理解：他毕竟是术士，所以一切都理解错了。
那使徒保罗也是术士吗？
> 2tim 1:6 :: !使你将上帝藉我按手所给你的恩赐
> 1tim 4:14 :: !你不要轻忽所得的恩赐 :: !就是从前借着预言、在众长老按手的时候赐给你的
使徒直接说：上帝的恩赐是藉他的按手赐下的。
回到西门的情形。使徒行传中的这个故事是福音史家路加写的（[[lk 1:3]]；[[act 1:1]]）。他写的不是西门仿佛对事件有什么错误的理解，而是西门只是**看见**了。他看见了什么？福音史家路加写道：“西门看见使徒按手，便有圣灵赐下”——这就是他所看见的。这不是西门在说，而是福音史家路加。接着从使徒彼得的话可以清楚：这确实如此——使徒能够传递这上帝的恩赐，而他责备西门的，正是他想**用钱**得到**上帝的恩赐**。
## “使徒保罗的按立不是经过人？”
正教徒表明，使徒保罗的职分是教会按立的：
> act 13:2-3 :: !要为我分派巴拿巴和扫罗 :: !于是禁食祷告，按手在他们头上
批评者反驳说，使徒保罗不是被人按立的，并引用一节经文：
> gal 1:1 :: !不是由于人，也不是借着人
但这指控没有根据，因为这里说的是拣选的方式，而不是上帝恩赐的传递。
在按手在扫罗身上之前，确实是圣灵自己拣选了他，并吩咐教会把扫罗分别出来，担任经上所说圣灵召他去的事奉。批评者引用这节经文是为了什么——不明白，因为并没有矛盾：扫罗不是由人、也不是通过人拣选的，而是圣灵自己拣选了他，吩咐教会把他分别出来担任事奉，之后教会给扫罗按手：
> act 13:2-3 :: !圣灵说 :: !要为我分派巴拿巴和扫罗 :: !去作我召他们所作的工 :: !于是禁食祷告，按手在他们头上
这样，拣选是圣灵行的，而恩典的赐下不是不经教会，而是经由教会——经由她仆人们的按手。
批评者试图以此论证他们所建立的团体与最早的基督徒没有任何直接联系，论证他们自行选立牧师和教师。显然，自己没有从上帝来的权柄管理并教导教会的人，不能把这样的权柄给任何人。但他们要紧的是表明一种可能性：仿佛圣灵可以这样作——仿佛可以不经任何与他们之前已存在的教会的联系，立他们的牧师担任事奉。
然而，虽然圣灵愿意作什么就作什么，我们在圣经里看不到一例：上帝脱离基督所建立的合一的、看得见的教会而立人担任事奉并拯救人。
上帝拣选了扫罗；虽然他无疑可以亲自立他担任事奉，但没有不经自己的教会这样做。同样我们在最初外邦人受洗的事上也看到：埃提阿伯的太监（[[act 8:27]]）和百夫长哥尼流（[[act 10:1]]）。
1. 埃提阿伯的太监在读圣经，却不明白。**上帝本可以**亲自教导太监并赐下洗礼的救人恩典，**但没有脱离教会这样做**。上帝差教会到太监那里，教会教导他明白圣经，并在洗礼中赐下恩典。
2. 百夫长哥尼流祈祷上帝、行善事。**上帝本可以**亲自把救人的恩典赐给哥尼流，**但没有脱离教会这样做**。他反而差天使到他那里，吩咐他去找教会（以使徒彼得为代表）。当使徒来到时，圣灵才降在哥尼流身上——虽然它同样可以早些、不经使徒而降临，但它没有这样做。
3. 逼迫基督徒的扫罗（未来的使徒保罗）往大马士革去逼迫基督徒。基督以耀眼的光向他显现；扫罗问他该作什么。基督上帝**本可以**亲自把恩典赐给扫罗，**但没有脱离教会这样做**，而是吩咐他到大马士革去找教会（以使徒亚拿尼亚为代表）；只有在那里，使徒才藉着教会使他复原（[[act 9:17]]），赐下圣灵的恩典（[[act 9:17]]），并在洗礼中赐下洗净他罪的救人恩典（[[act 22:16]]）。
同样，在一切情形中，包括按立扫罗担任特殊的使徒职分：上帝自己拣选扫罗，上帝本可以亲自把他的恩赐赐给他，但没有脱离自己的教会这样做。圣灵向教会说话，教会给扫罗按手（[[act 13:2-3]]）。
所以，那些与教会分离的团体宣称他们的牧师有脱离教会的特殊蒙召，在圣经里没有任何依据。圣经里根本没有这样的例子。
## “按手是从异教借来的？”
那些自行建立教会的人，首先必须证明基督一次所建立的教会已经堕落。因为如果教会没有堕落，那他们的新团体就不需要，只要进入基督的教会即可。为证明教会的堕落，常用“贴标签”的手法——贴上尽可能可怕的标签。于是教会常被指控偏离上帝、因借用异教实践而堕入异教，被点名的有：
- 圣殿的存在；
- 圣地；
- 圣物；
- 圣像；
- 特别的神圣之人（司祭）；
- 圣规程和圣奥秘（仿佛是影响上帝的药方），其中包括按手。
这是极其荒唐的指控，因为这一切都是上帝亲自设立的，并且圣经里都有直接的经文。把异教拉到这里来，只是为了给教会贴标签。所有这些神圣的建筑、地方、物件、行动和人，在新旧约圣经里都有——详见[[ru:святыня|圣物]]一文。
### 旧约中的按手
雅各以祈祷按手祝福了自己的孙子：
> gen 48:14-16 :: !以色列伸出右手来 :: !按在以法莲的头上 :: !又剪搭过左手来按在玛拿西的头上 :: !他就给约瑟祝福说 :: !赐福与这两个童子
上帝命令先知摩西以按手立约书亚担任事奉：
> chis 27:18,22-23 :: !嫩的儿子约书亚是心中有圣灵的 :: !你将他领来，按手在他头上 :: !按手在他头上，嘱咐他
> vtor 34:9 :: !嫩的儿子约书亚，因为摩西曾按手在他头上，就被智慧的灵充满
上帝命令以按手立利未人在圣殿供职：
> chis 8:10 :: !将利未人奉到耶和华面前，以色列人要按手在他们头上
### 新约中的按手
> 2tim 1:6 :: !使你将上帝藉我按手所给你的恩赐
> 1tim 4:14 :: !你不要轻忽所得的恩赐 :: !在众长老按手的时候赐给你的
> evr 6:2 :: !各样洗礼、按手之礼
研读圣经之后，那些指责教会仿佛在使徒之后从异教借来这些实践及其态度的说法，就令人惊讶了——使徒们自己写的正是上帝的恩赐**藉着**他们手的按手而赐下，并且把这作为教导的一部分。这一切（这方式本身）不是新发明，而是在使徒之前的同一环境里已存在了几个世纪的东西——设立它的不是异教徒，而是上帝自己。
## “新约里没有称祭司？”
“祭司职”一词在新约的语境中出现。基督更换了祭司职，而不是废除它：
> evr 7:12 :: !祭司的职任既已更改
基督成为永远的大祭司，但司祭没有被废除。关于他们的拣选和设立，预言里有话：
> is 66:18-21 :: !我必将万民万族 :: !我也必从他们中间取人为祭司，为利未人
此外，实际上正是使徒们是祭司——不是随便什么人。旧约里司祭有洁净人罪的职责（[[lev 5:5-6]]）；同样在新约里，新的教会等次建立时，这权柄被赐给它——赦罪或不赦罪：
> in 20:21-23 :: !你们受圣灵 :: !你们赦免谁的罪，谁的罪就赦免了 :: !你们留下谁的罪，谁的罪就留下了
最早的基督徒证实：长老们也是祭司——见[[ru:gq8M_Новозаветные_пресвитеры__священники|引文]]。
