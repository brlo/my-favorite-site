# 魔鬼（撒但）——堕落的天使
魔鬼是上帝所造众多天使中的一位，但他不愿日后事奉上帝，也就是从上帝面前堕落了、堕落了：
> iez 28:12-19 :: !你是那受膏遮掩约柜的基路伯 :: !后来在你中间又察出不义 :: !以致犯罪 :: !你因美丽心中高傲 :: !又因荣光败坏智慧 :: !我已将你摔倒在地 :: !我使火从你中间发出烧灭你
这些从上帝面前堕落的天使，用不同的词来称呼：鬼（[[mf 8:31]]）、魔（[[tov 6:8]]）、撒但的差役（[[2kor 12:7]]）、污鬼（[[mf 10:1]]）、「黑鬼」（民间的称呼）。撒但还被称为蛇（[[gen 3:1]]；[[is 27:1]]；[[otkr 12:9]]；[[otkr 20:2]]）、龙（[[otkr 12:9]]；[[otkr 20:2]]）、明亮之星（[[is 14:12]]）、鳄鱼（利维坦）（[[is 27:1]]）、这世界的王（[[in 12:31]]）、恶者（[[mf 13:19]]）、谎言的灵（[[3ts 22:22]]）。魔鬼不是一种没有位格的感觉，不是人心中某种抽象的冲动，也不是寓意。他是真实的存有，是一个位格。魔鬼是最初犯罪的存有：
> 1in 3:8 :: !犯罪的是属魔鬼，因为魔鬼从起初就犯罪
