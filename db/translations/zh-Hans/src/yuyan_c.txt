# 启示录中各教会的评价
可以见到教会反对者的一种尝试：引用神学家约翰启示录第2-3章的内容（[[otkr 2:1]]），论证教会已离弃真信仰。在其中，主耶稣基督向七个教会说话，指出他们的长处与缺点。其实，仔细看经文，恰恰相反：教会持守着基督的信仰；即使个别教会受到指摘，也是因他们的**行为**。
## 1. 以弗所教会
✅ 因行为受称赞（远离淫乱、指摘假使徒、恨恶尼哥拉一党人的行为、忍耐、为主劳苦）。
> otkr 2:2-3,6 :: !我知道你的行为、劳碌、忍耐 :: !你也曾试验那自称为使徒却不是使徒的 :: !你也能忍耐，曾为我的名劳苦，并不乏倦 :: !你恨恶尼哥拉一党人的行为
❌ 受指摘，因为他离弃了起初的爱心；并蒙召回到它，行「起初所行的**事**」。
> otkr 2:4-5 :: !你把起初的爱心离弃了 :: !并要悔改，行起初所行的事
## 2. 士每拿教会
✅ 因行为受称赞（忍耐患难、贫穷和毁谤）。蒙召不要惧怕将要受的逼迫。应许了生命的冠冕。完全未受指摘。
> otkr 2:9-10 :: !我知道你的患难、你的贫穷 :: !你将要受的苦你不用怕 :: !你务要至死忠心，我就赐给你那生命的冠冕
## 3. 别迦摩教会
✅ 因行为受称赞（在逼迫的威胁下没有弃绝基督的信仰）。
> otkr 2:13 :: !你还坚守我的名，没有弃绝我的道
❌ 受指摘，因为他**没有赶出**吃祭偶像之物、行奸淫之事的尼哥拉一党人。同时，别迦摩教会并没有弃绝基督的信仰：「没有弃绝我的**道**」。
> otkr 2:14-15 :: !有人服从了巴兰的教训 :: !叫他们吃祭偶像之物，行奸淫的事 :: !你那里也有人照样服从了尼哥拉一党人的教训
## 4. 推雅推喇教会
✅ 因**信心**和行为（爱心、勤勉、忍耐）受称赞。
> otkr 2:19 :: !我知道你的行为、爱心、信心、勤劳、忍耐
❌ 受指摘，因为他也没有赶出「耶洗别」，容让她引诱信徒行奸淫、吃祭偶像之物（如同别迦摩的尼哥拉一党人）。受刑罚的只有那些与耶洗别行淫的人。其余的人则受称赞：「但你们已经有的，总要持守，直等到我来」。
> otkr 2:20-25 :: !就是你容让那自称是先知的妇人耶洗别教导我的仆人，引诱他们行奸淫，吃祭偶像之物 :: !那些与她行淫的人，若不悔改所行的，我也要叫他们同受大患难 :: !但你们已经有的，总要持守，直等到我来
## 5. 撒狄教会
✅ 只有几个没有玷污自己衣服的人受称赞。
> otkr 3:4 :: !然而在撒狄你还有几名是未曾污秽自己衣服的
❌ 因其余的人，他被比作死人，因为行为不完全：「因我见你的**行为**在我上帝面前没有一样是完全的」。受指摘，因为他不儆醒。
> otkr 3:1-2 :: !按名你是活的，其实是死的 :: !你要儆醒 :: !因我见你的行为在我上帝面前没有一样是完全的
## 6. 非拉铁非教会
✅ 因行为受称赞（虽然力量略小，但没有弃绝基督），因持守基督忍耐的道。蒙召：「你要持守你所有的」。完全未受指摘。
> otkr 3:8,10-11 :: !我知道你的行为，你略有一点力量 :: !没有弃绝我的名 :: !你既遵守我忍耐的道 :: !我必快来，你要持守你所有的
## 7. 老底嘉教会
不受称赞。
❌ 因行为受指摘：「我知道你的**行为**，你也不冷也不热」。蒙召向基督买金子、衣服和眼药，并要发热心、悔改：「所以你要发热心，也要悔改」。
> otkr 3:15-19 :: !我知道你的行为，你也不冷也不热 :: !所以我必从我口中把你吐出去 :: !我劝你向我买火炼的金子 :: !又买白衣穿上 :: !又买眼药擦你的眼睛 :: !所以你要发热心，也要悔改
# 总结
这样：
- 🟢 士每拿教会（2）和非拉铁非教会（6）完全未受指摘。
- 🟡 别迦摩教会（3）和推雅推喇教会（4）持守了信仰，但受指摘没有赶出引诱人的（尼哥拉一党人和耶洗别）。受刑罚的正是那些属于虚假教导的人。而教会本身则受称赞：「没有弃绝我的**道**」（别迦摩）、「但你们已经有的，总要持守，直等到我来」（推雅推喇）。
- 🟠 以弗所教会（1）因敬虔和保守信仰受称赞，因离弃起初的爱心受指摘，蒙召行起初所行的**事**。
- 🟠 撒狄教会（5）因几个保守了衣服的人受称赞，因**行为**的不完全受指摘。
- 🔴 老底嘉教会（7）完全不受称赞，因**行为**上的不冷不热受指摘，蒙召悔改。
- 因为信仰，没有人受指摘，但几乎所有的都因信仰受称赞（1, 2, 3, 4, 6）。
- 有些教会因一件事上的欠缺受指摘，但因持守信仰受称赞（3, 4）。
- 另一些教会在行为上有更严重的欠缺，但在其中信仰仍然保守着（1, 5）。
- 最后一个教会因对**行为**的冷淡（不冷不热）受指摘（7）。
或许有人以为「行为」也包括信仰。然而，那些明确持守了信仰的教会，却因行为上的欠缺受指摘（3, 4）——这几乎不给这种解释留下余地。这样，启示录中的教会受指摘不是因为信仰（作为教导），而是因为行为上的不完全。而有些教会完全未受指摘。
