# 起初的基督徒们也患病
提摩太（以弗所主教）患胃病，使徒保罗因他的病吩咐他稍微放松斋戒：
> 1tim 5:23 :: !因你胃口不清，屡次患病 :: !再不要照常喝水
使徒保罗自己也得了一种病，免得他自高：
> 2kor 12:7 :: !有一根刺加在我肉体上 :: !免得我过于自高
以巴弗提（使徒保罗的同工）患病，几乎要死：
> fil 2:25-27,30 :: !以巴弗提 :: !因为你们听见他病了 :: !他实在是病了，几乎要死 :: !几乎至死
使徒保罗把一个犯罪的基督徒交给撒但，让他受疾病的打击：
> 1kor 5:3,5 :: 要把这样的人交给撒但，败坏他的肉体，使他的灵魂在主耶稣的日子可以得救
不配地参与圣餐礼曾使许多基督徒患病、软弱、甚至死亡：
> 1kor 11:30 :: !在你们中间有好些软弱的与患病的
旧约的义人也患病
> gen 27:1 :: !以撒年老，眼睛昏花，不能看见
# 身体受苦的益处
## 有助于离弃罪
> 1pet 4:1 :: !在肉身受过苦的，就已经与罪断绝了
## 免于骄傲
> 2kor 12:7 :: !所以有一根刺加在我肉体上，就是撒但的差役要攻击我，免得我过于自高
## 管教
| 这样，因痛苦缠身，**他的狂傲，方开始止息**；因天主的惩罚，**痛苦逐渐增加，他也逐渐觉悟**。 ||| sb 2mak 9:11
# 上帝能以疾病施行惩罚
上帝能因罪孽和罪恶施行惩罚：
> ier 30:15 :: !你的痛苦无法医治 :: !我因你的罪孽甚大，罪恶众多，曾将这些加在你身上
上帝因米利暗（亚伦和摩西的姊妹）毁谤摩西而以癞病惩罚她：
> chis 12:8-10 :: !耶和华就向他们二人发怒而去 :: !米利暗长了大痲疯，有雪那样白 :: <<你们毁谤
因以色列民偏离对上帝的敬拜，瘟疫临到以色列民：
> chis 25:3,9 :: !耶和华的怒气就向以色列人发作 :: !那时遭瘟疫死的，有二万四千人
救主指出罪是疾病的原因：
> in 5:14 :: !你已经痊愈了，不要再犯罪，恐怕你遭遇的更加利害
上帝也能施怜悯，护佑人免于疾病
> ish 15:26 :: !你若留意听耶和华你上帝的话 :: !我就不将所加与埃及人的疾病加在你身上，因为我耶和华是医治你的
