# 身体与灵魂
## 逼迫者不能杀死灵魂
主耶稣基督说不要怕逼迫者，因为他们只能杀死身体，却不能杀死灵魂，不能伤害灵魂。否认灵魂死后存在的人声称，灵魂与身体一同死亡，如此则逼迫者杀死的不只是身体，也是灵魂——但这与基督的话相矛盾：
> mf 10:28 :: 那杀身体 :: !不能杀灵魂的
> lk 12:4 :: !那杀身体以后不能再作什么的，不要怕他们
## 已死的先知摩西的灵魂在大博尔山显现
救主在大博尔山显圣容的时刻，使徒们看见了已经死去的先知摩西显现，正与基督谈论他即将面临的十字架苦难。也就是说，先知虽然死了（[[vtor 34:7]]；[[nav 1:2]]）（见<a href="#HH-上帝复活了先知摩西">下文注释</a>），却没有消失，也没有失去知觉：他正**与基督交谈**：
> mf 17:3 :: !摩西 :: !同耶稣说话
> lk 9:29-31 :: !忽然有摩西、以利亚两个人同耶稣说话 :: !谈论耶稣去世的事
## 使徒论死后的生命
使徒保罗说，当地上的帐幕（身体）拆毁时，我们有天上永存的房屋：
> 2kor 5:1,4 :: !我们这地上的帐棚若拆毁了 :: !必得上帝所造，不是人手所造，在天上永存的房屋 :: !并非愿意脱下这个，乃是愿意穿上那个
<hr>
在另一处——或许是最重要的一处——使徒写道，他情愿快些死去，以便明确地进入与上帝同在的生命，他称死亡为「益处」。如果使徒死后就消失或沉睡，那他什么也没有获得，只是失去（知觉）。那样的话，急忙去死、去进入无所作为的状态就没有任何意义了。更合理的做法是：活着、传道、建立教会、与上帝相通、帮助教会（**尽可能长久地不撇下教会**——这是灵魂不朽学说的反对者们一贯忽略的主要思想），住在地上的身体里。但使徒知道自己将进入天上与上帝同在的生命，所以情愿快些脱离身体中的地上生命：
> fil 1:21-24 :: !我死了就有益处 :: !情愿离世与基督同在，因为这是好得无比的
*否认灵魂死后存在的人，通常忽略所提注释中的论据，而说：「使徒不会察觉睡梦中飞逝的时间，会立刻在复活中与基督一同醒来」。然而，如果使徒并不是立刻进入与基督同在的生命，而只是进入无知觉的无所作为，那么，当使徒紧接着明明写道住在肉身中更是要紧的时候，急忙**撇下教会**就没有任何意义了。
<hr>
使徒出离身体时，相信他会到主那里，因此再次表示宁愿离开身体。他指出，无论是住在身内还是离开身外，重要的是蒙上帝喜悦：
> 2kor 5:6,8-9 :: !我们住在身内，便与主相离 :: !更愿意离开身体
使徒住在身体里，如同住在圣殿中（[[ru:человек-храм-Божий|人——上帝的殿]]），但不久他必须离开身体：
> 2pet 1:13-14 :: !趁我还在这帐棚的时候 :: !我脱离这帐棚的时候快到了
使徒写道，他曾被提到天上——或是在身内，或是在身外：
> 2kor 12:2 :: !或在身内，我不知道，或在身外，我也不知道
使徒指出灵魂的永恒性：
> 2kor 4:16,18 :: !外体虽然毁坏，内心却一天新似一天 :: !所不见的是永远的
## 受审判的是活**在身体里**时所做的行为，而不是身体之外的行为
上帝所要审判的，只是人在身体中活着时所做的事：
> 2kor 5:10 :: !按着本身所行的
## 旧约的记述
认为人的死不仅是身体的毁灭、也是灵魂的毁灭，这种想法是不正确的：
| **恶人们胡思乱想自语说**：“我们的生命又短促，又多愁；人的死期一到，又没有办法补救，也从不见有人从阴府回来。我们原是偶然而生，过后我们又好像未曾生存过；我们鼻中的气息只是一阵烟雾，思想亦不过是心动迸出的火花；**火花一旦熄灭，身躯即变成灰土，魂魄即像轻风消散**。 ||| sb prs 2:1-3
同时：
| **邪曲的思想，使人离开天主**；愚人试探全能者，只有使自己蒙羞， ||| sb prs 1:3
| **义人的灵魂在天主手里**，痛苦不能伤害他们。**在愚人看来，他们算是死了**，认为他们去世是受了惩罚，**离我们而去，仿佛是归于泯灭**；其实，**他们是处于安宁中**； ||| sb prs 3:1-3
# 对否认死后生命的撒都该人的驳斥
在所有犹太党派（法利赛人、撒都该人、艾赛尼人等）中，只有一派——撒都该人——相信人死后归于消失（[[act 23:8]]）。主严厉地驳斥他们，指责他们的谬误和不明白圣经：
> mf 22:29 :: !你们错了，因为不明白圣经，也不晓得上帝的大能
> mk 12:27 :: !上帝不是死人的上帝，乃是活人的上帝 :: !你们是大错了
# 耶稣基督的人性灵魂
主耶稣基督死后，他的灵魂下到了阴间：
> ps 16:10; act 2:27 :: !你必不将我的灵魂撇在阴间
> act 2:31 :: !他的灵魂不撇在阴间
在阴间，基督向那些从世界洪水时代起就在那里的神魂（灵魂）宣讲：
> 1pet 3:18-20 :: !按着肉体说，他被治死；按着灵性说，他复活了 :: !他藉这灵曾去传道给那些在监狱里的灵听 :: !挪亚预备方舟、上帝容忍等待的时候
> 1pet 4:5-6 :: !就是死人也曾有福音传给他们
> ef 4:8-9 :: !既说升上，岂不是先降在地下吗
最终，基督掌管死人，也掌管活人：
> rim 14:9 :: !因此基督死了，又活了，为要作死人并活人的主
# 义人死后在天上的生命
为基督被杀的灵魂与他在天上同活，并且知道地上发生的事（他们的冤至今未伸）：
> otkr 6:9-11 :: !有为上帝的道并为作见证被杀之人的灵魂 :: !圣洁真实的主啊！你不审判住在地上的人，给我们伸流血的冤，要等到几时呢 :: !于是有白衣赐给他们各人 :: !等着一同作仆人的和他们的弟兄，也像他们被杀，满足了数目
# 为基督殉道的人住在天上

义人住在天上，而我们这些住在地上的人，如今就已走近天上凯旋的教会——走近义人的神魂：
> evr 12:22-23 :: !你们乃是来到 :: !天上的耶路撒冷 :: !诸长子之会所共聚的总会 :: !被成全之义人的灵魂
常保童身的人无论基督往哪里去都跟随他：
> otkr 14:4-5 :: !这些人未曾沾染妇女 :: !他们原是童身 :: !羔羊无论往那里去，他们都跟随他
死人受审判，阴间交出在它里面的死人：
> otkr 20:12-13 :: !我又看见死了的人 :: !死了的人都凭着这些案卷所记载的，照他们所行的受审判 :: !死亡和阴间也交出其中的死人
# 批评
## 上帝复活了先知摩西？
东正教徒为灵魂死后有知觉的存在辩护，提出这样的论据：先知摩西虽然死了（[[vtor 34:7]]；[[nav 1:2]]），却显现并**与基督交谈**：
> mf 17:3 :: !摩西 :: !同耶稣说话
反对东正教会的人（特别是基督复临安息日会信徒）回答说，这仿佛是因为上帝接升并复活了先知摩西。他们所依据的不是圣经，而是伪经《摩西升天记》（因为他们无法直接引用怀爱伦的话）。
我们（他们也同样）不认为伪经是有权威的文本。但问题在于，即便在这部伪经中——至少在保存下来的部分里——也没有关于先知摩西复活的话。相反，书中将这样的话归于摩西：他要「归到他列祖那里」（<a href="https://azbyka.ru/otechnik/Biblia2/apokrificheskie-apokalipsisy/15#sel=15:41,15:57;27:1,27:7">来源</a>）。
此外，先知的复活与圣经相矛盾，因为正是基督——死者中的初熟果子：
> 1kor 15:20 :: !成为睡了之人初熟的果子
我们也知道，没有一个人（这话是对人说的）升过天，没有一个先知升过天：
> in 3:13 :: !除了从天降下仍旧在天的人子，没有人升过天
> act 2:29,34 :: !大卫并没有升到天上
关于在基督十字架祭献和他的复活之前，所有的人死后都下到阴间的详情：
[[ru:9VFT_До_жертвы_Христовой_ветхозаветные_праведники_сходили_в_ад|在基督祭献之前，旧约的义人们下到阴间]]
## 灵魂不朽的学说就是相信魔鬼所说「不一定死」的话吗？
灵魂学说的反对者（复临信徒）这样控告东正教徒：上帝说「你们必定死」，而魔鬼说「你们不一定死」，仿佛这就意味着，相信灵魂死后存活的信仰就是相信魔鬼的话：「你们不一定死」。相应地，相信灵魂在身体死后存活的人，被他们控告为相信魔鬼的谎言。
这控告听起来响亮，但这一想法本身与上下文有严重的矛盾和问题。上帝说的不仅是「你们必定死」，而是说：你们吃的日子必定死——即在吃那禁树果子的那一天：
> gen 2:16-17 :: !你吃的日子必定死
灵魂生命学说的反对者把「必定死」这句话理解为最简单直接的意思：身体的死亡、人一切生命活动的终止、人存在的终结（至少是有知觉的存在的终结）。
人在吃果子的那一天发生了这种被理解的死吗？——没有，亚当死得晚得多，活到九百三十岁（[[gen 5:5]]）。这意味着什么？——意味着上帝所说的是另一种死。魔鬼所否认的也正是另一种死。
而如果不是这样，那就不得不承认：上帝说人在吃果子的那天必死，是撒了谎，而魔鬼反倒说了实话——「你们不一定死」——因为毕竟，那一天并没有发生粗浅意义（身体意义）上的死亡。但我们无论如何不能承认：上帝（道路、真理、生命——[[in 14:6]]）撒了谎，而魔鬼（说谎的、说谎之人的父——[[in 8:44]]）说了实话。然而，灵魂学说反对者们的解释恰恰把人引向这个结论。
为了走出这个死胡同，他们必定要把话语的一部分作比喻式的重新解释：
- 死亡本身按字面理解，
- 而死亡的日子却不按字面理解。
东正教会的解释没有这样的缺陷：
- 死亡的日子按字面理解，
- 死亡本身也按字面理解——只是针对人的属灵状态而言。不过，在身体状态上确实也发生了变化：人至少看见了自己是赤身露体的。
始祖确实在那天就死了，但这一死——不是消失，而是一种与上帝隔绝的状态，一切罪人都处在这种状态中。基督——上帝自己——也把没有上帝的生命状态称为死：
> mf 8:21-22 :: !任凭死人埋葬他们的死人
> in 5:24 :: !是已经出死入生了
> otkr 3:1 :: !按名你是活的，其实是死的
使徒们也这样说。他们曾活在死的状态中：
> ef 2:1-2 :: !死在过犯罪恶之中 :: !行事为人
> 1tim 5:5-6 :: !正活着的时候也是死的
也就是说，死的状态在亚当和夏娃犯罪堕落之后立刻就来临了——这是一种内在的、没有上帝的生命状态。在这个意义上，魔鬼说「你们不一定死」时撒了谎。他们正如上帝所说的那样死了——就在那一天。
如此，这些控告并不严重——它们本身就带有矛盾，并且脱离圣经的上下文。
