# 定义
**圣膏**（领受圣灵的恩赐）——教会七个圣奥秘之一，人在其中领受走属灵道路并长进所需的力量（圣灵的恩赐）。圣膏圣奥秘与洗礼圣奥秘一同举行，紧接着洗礼之后。
起初，这圣奥秘是藉使徒的按手并祈祷举行的。后来——但还在使徒的时代——按手就被以圣膏（特别祝圣的油）膏抹人所取代。极可能是为了使这圣奥秘不仅能由使徒和主教施行，也能由那些主教授予此权的司祭施行，正如其余的圣奥秘一样。主教调制圣膏，并把它交给举行这圣奥秘的司祭。详见[[ru:миропомазание#HH-С-I-II-века-вместо-возложения-рук-помазывают-миром|下文相应的部分]]。
# 关于赐予圣灵恩赐之圣奥秘的指示
使徒彼得的宣讲。
使徒彼得呼召人受洗使罪得赦，随后又另外讲到必须领受圣灵的恩赐：
> act 2:38 :: !奉耶稣基督的名受洗 :: !就必领受所赐的圣灵
# 圣灵的恩赐藉使徒的按手传递
福音史家路加在使徒行传中直接宣告：“藉着使徒的按手，圣灵是赐下的”（[[act 8:18]]）。这不是西门的话，而是路加福音史家——使徒行传作者——的话。此外，接着使徒彼得直接讲到圣灵恩赐的传递是上帝的恩赐，并责备西门图谋用钱来得到这恩赐：
> act 8:17-20 :: !于是使徒按手在他们头上，他们就受了圣灵 :: !因你想上帝的恩赐是可以用钱买的
使徒保罗在以弗所施洗。洗礼之后立刻按手，以传递圣灵的恩赐：
> act 19:4-6 :: !就奉主耶稣的名受洗 :: !保罗按手在他们头上，圣灵便降在他们身上
# 圣灵恩赐的传递——与洗礼分开的圣奥秘
撒玛利亚人受了洗，但圣灵是后来、在使徒按手之后才降下的。
撒玛利亚人的洗礼举行了。任何地方都没有说这洗礼有什么不对。相反，经上直接指出“他们只奉主耶稣的名受了洗”，而圣灵还没有降在他们身上。当使徒们听说撒玛利亚人的事，就清楚需要有使徒到撒玛利亚人那里去，使他们不仅受洗（这是腓利也能做的），而且领受圣灵的恩赐（这腓利已经不能做了，因为传递圣灵恩赐的只能是使徒，以及他们把这恩赐传递给他们的人——主教）：
> act 8:5,12,14-17 :: !腓利下撒玛利亚城去宣讲基督 :: !连男带女就受了洗 :: !就打发彼得，约翰往他们那里去 :: !两个人到了，就为他们祷告，要叫他们受圣灵 :: !因为圣灵还没有降在他们一个人身上，他们只奉主耶稣的名受了洗 :: !于是使徒按手在他们头上，他们就受了圣灵
# 从I-II世纪起，以圣膏的膏抹代替按手
起初这圣奥秘是藉使徒和主教的按手举行的。后来，极可能是因为归依基督教的人数增多，主教很难为所有基督徒按手，于是确立了祝圣特别的油（圣膏）并把它交给司祭（长老）的实践——司祭在圣膏圣奥秘中膏抹人，代替主教的按手。
在圣经本身和一系列最早的基督教作家那里，都有以这种方式举行圣奥秘的指示：
> 2kor 1:21-22 :: !并且膏我们的就是上帝 :: !他又用印印了我们，并赐圣灵在我们心里作凭据
> 1in 2:20 :: !你们从那圣者受了恩膏
> 1in 2:27 :: !你们从主所受的恩膏常存在你们心里 :: !自有主的恩膏在凡事上教训你们
**安提阿的圣提奥菲尔，二世纪**
“至于你对我、对我的基督徒之名的讥笑，你不知道你说的是什么。首先，凡被膏抹的，都是令人喜悦的、有益而美好的，不应被讥笑。因为什么船若不先被油膏抹，还能合用而坚固呢？什么塔或房子若不被膏抹，还能美观而适用呢？谁进入这一生、或进入竞技场而不被油膏抹呢？<…> **正因如此，我们被称为基督徒，因为我们是被上帝的油所膏抹的**。”
（[俄文](https://bibleox.com/ru/ru/w/Феофил-послание_к_Автолику)《致奥托利科斯书》）

# 对异议的回应
## “可是圣灵降在百夫长哥尼流身上，并没有使徒的按手？”
圣灵在使徒彼得宣讲时降在哥尼流一家身上——这是**唯一的**一例：圣灵不藉使徒按手、并在洗礼之前降临。在这例外的情形之前有一系列极不寻常的事件，表明上帝这样预备教会接纳外邦人（非犹太人）。在此之前，接纳外邦人的可能性完全不明显，甚至后来还引起争辩。藉这特殊的圣灵降临，上帝指明：
1. 可以接纳外邦人（非犹太人）进入教会；
2. 消除了在这事上怀疑、并指责人持错误判断的可能。上帝这样作并非不用使徒（圣灵不是立刻降下，而是先差遣天使，吩咐人去请使徒来），然而圣灵自己确实在使徒按手之前降临，清楚地表达了上帝接纳外邦人的旨意。
重要的是：圣灵的降临并没有取消洗礼圣奥秘的必要——在圣灵降在哥尼流一家身上之后，使徒立刻为他们施洗：
> act 10:1,34,44,46-48 :: !在该撒利亚有一个人，名叫哥尼流 :: !我真看出上帝是不偏待人 :: !圣灵降在一切听道的人身上 :: !这些人既受了圣灵，与我们一样，谁能禁止用水给他们施洗呢 :: !就吩咐奉耶稣基督的名给他们施洗
对想更详细了解的人，我们作详细的解释。
在教会存在的初期，接纳外邦人几乎是不可能的。宣讲只向犹太人敞开（[[act 11:19]]；[[act 11:1,18]]；[[act 14:27]]；[[act 15:4]]；[[act 15:7]]）。教会还没有形成接纳外邦人（即非犹太人）是否可行的共同认识。
甚至对最近的门徒之一——使徒彼得——也需要特殊的预备：不是一次，而是三次向他显现同一个关于不洁食物的异象，并命令他不要把上帝所洁净的当作不洁（[[act 10:15]]；[[act 11:9]]）。
这样，使徒彼得来到哥尼流那里；宣讲开始之后，圣灵降在哥尼流一家身上。降临之后，使徒立刻用水给他们施洗。为罗马百夫长哥尼流施洗之后，犹太血统的基督徒对所发生的事惊讶：
> act 10:45 :: !见圣灵的恩赐也浇在外邦人身上，就都希奇
在耶路撒冷，使徒彼得因给外邦人施洗而受到责难；但听了他讲述上帝的启示和圣灵降在哥尼流身上的事之后，人们就安静下来（[[act 11:1,18]]）。甚至在这之后，问题也没有得到彻底解决。使徒彼得到了安提阿。那里也来了耶路撒冷雅各那里的基督徒（[[gal 2:12]]），于是安提阿的犹太人连同使徒彼得开始躲开耶路撒冷来的人，免得显得与外邦人交往。
这样，不难看出，教会为接纳外邦人作特殊的预备，是何等必要。
1. 甚至使徒也需要被单独地三次教导。
2. 目击这一切的基督徒被所发生的事震惊，而在别人面前还不得不辩白。
3. 与使徒们发生争辩，为此在耶路撒冷召集了整个会议。
这一切都是在上帝超性地介入、亲自不藉使徒按手降在外邦人身上的情况下发生的。甚至尽管有这一切，仍出现强烈的抵抗。若没有这些，又会怎样呢？
这样，主只有一次以例外的样式行事，为要教导教会接纳外邦人。
这特殊的事件并没有取消洗礼。使徒立刻给哥尼流一家施了洗。
值得特别注意这一整串事件，其实质在于：上帝完全可预料地可以按自己的意愿行事，但是……不脱离教会行事。
那些自立基督教团体的人在这里宁可只看到为自己的擅自聚会开口子的机会，力图证明圣灵仿佛会因传福音而直接赐给他们。但他们完全忽略了这样的事实：能够完全独立行事、不需要使徒就能降在哥尼流和他一家身上的圣灵，并没有脱离教会这样做。
看到哥尼流的义、他的祈祷和施舍，上帝差到他那里的不是圣灵的恩赐，而是先差天使，吩咐哥尼流去找教会。只有当教会以使徒的身份来到、当被赋予传递圣灵恩赐之权柄的人来到时，圣灵才降在哥尼流身上。
这样，圣灵能够不通过教会而降临，但他不这样做。圣经里没有一次这样的例子。在其余所有情形中，圣灵都没有在洗礼之前降临。
圣灵在洗礼时降临——这正是说，在洗礼的过程中行了按手并降下圣灵。今天行的也是同样：洗礼之后立刻随之举行圣膏。
洗礼被称为属灵的诞生、进入教会、加入身体。圣灵恩赐的差遣并不这样称呼。如使徒所说，洗礼救人。那么，难道是水本身救人吗？当然是圣灵藉着水的运作。在水里受浸时属灵的诞生没有圣灵是不会发生的。而传递圣灵恩赐的圣奥秘——是单独的。使徒在这里也正是把它们作为圣灵的两个分开的行动来讲：
> 1kor 12:13 :: !都从一位圣灵受洗 :: !饮于一位圣灵
1）**受洗**也是（!）在圣灵里；
2）**饮于**圣灵。
两者都是由圣灵成就的。没有圣灵的运作，没有人从水里重生。
而如果这是两个不同的概念，那就不必把从水而生作为看见并进入天国的条件了；只要说“从圣灵生”就足够了。但救主讲到诞生时，把两者并提：从水和圣灵生，既不忽略水，也不忽略圣灵。
## “如果圣灵的恩赐只能由使徒传递，那圣灵为什么在六品执事腓利施洗之后降在埃提阿伯的太监身上？”
在腓利与太监的情形中（[[act 8:39]]）有一个非常重要的细节。
绝大多数释经者——包括最古老的，包括圣金口约翰——引用这段经文时都没有关于圣灵降下的话（αγιον επεπεϲεν επι τον ευνουχον αγγελοϲ δε）。经上只是说：
圣<s>灵降在太监身上，而天使</s>主把腓利提了去。
西奈抄本没有这些话（四世纪）：
“καὶ ἐκέλευσεν στῆναι τὸ ἅρμα,
καὶ κατέβησαν ἀμφότεροι εἰς τὸ ὕδωρ,
ὁ τε Φίλιππος καὶ ὁ εὐνοῦχος,
καὶ ἐβάπτισεν αὐτόν.
ὅτε δὲ ἀνέβησαν ἐκ τοῦ ὕδατος,
**πνεῦμα Κυρίου ἥρπασε τὸν Φίλιππον**,
καὶ οὐκ εἶδεν αὐτὸν οὐκέτι ὁ εὐνοῦχος·
ἐπορεύετο γὰρ τὴν ὁδὸν αὐτοῦ χαίρων.
Φίλιππος δὲ εὑρέθη εἰς Ἄζωτον,
καὶ διερχόμενος εὐηγγελίζετο τὰς πόλεις πάσας,
ἕως τοῦ ἐλθεῖν αὐτὸν εἰς Καισάριαν.”（使徒行传 8:39-40）
梵蒂冈抄本没有这些话（四世纪）：
“και εκελευϲε ϲτηναι το αρμα και κατεβηϲαν αμφοτεροι ειϲ το υδωρ ο τε φιλιπποϲ και ο ευνουχοϲ και εβαπτιϲεν αυτον
οτε δε ανεβηϲαν εκ του υδατοϲ **πνευμα κ̅υ̅ ηρπαϲεν το̅ φιλιππον** και ουκ ειδε̅ αυτον ουκετι ο ευνουχοϲ επορευετο γαρ αυτου την οδον χαιρων”
亚历山大抄本没有这些话（五世纪）：
“και εκελευϲεν ϲτηναι το αρμα και κατεβηϲαν αμφοτεροι ειϲ το υδωρ ο τε φιλιπποϲ και ο ευνουχοϲ και εβαπτιϲεν αυτον
οτε δε ανεβηϲαν εκ του υδατοϲ **π̅ν̅α̅ κ̅υ̅ ηρπαϲεν τον φιλιππο̅** και ουκ ειδεν αυτον ουκετι ο ευνουχοϲ επορευετο γαρ την οδο̅ αυτου χαιρων
φιλιπποϲ δε ευρεθη ειϲ αζωτον και διερχομενοϲ ταϲ πολειϲ παϲαϲ εωϲ του ελθειν αυτο̅ ειϲ καιϲαριαν”
圣金口约翰也是这样引用的（没有圣灵降临的话）：
“Ὅτε δὲ ἀνέβησαν ἀπὸ τοῦ ὕδατος, **Πνεῦμα Κυρίου ἥρπασε τὸν Φίλιππον**, καὶ οὐκ εἶδεν αὐτὸν οὐκ ἔτι ὁ εὐνοῦχος.”
