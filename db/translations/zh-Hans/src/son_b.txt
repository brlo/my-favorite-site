# 来自穆斯林的问题
## 为什么需要祭品？怜悯的上帝难道不能白白赦免吗？
基督徒所信的上帝称为爱：
> 1in 4:8,16 :: 上帝就是爱 :: 上帝就是爱！
上帝借着把自己献为祭、以拯救受造者，正是显明他对受造物的爱——因为他自己也说过：
> in 15:13 :: !人为朋友舍命，人的爱心没有比这个大的
这样，他以祭品之爱吸引他所愿意拯救的人：
> in 12:32-33 :: 我若从地上被举起来，就要吸引万人来归我 :: 指着自己将要怎样死说的
但智慧的上帝始终以智慧安排救恩。除了爱之外，我们还可以说到神圣公义的满足：上帝不仅怜悯，而且公义。他善于把智慧、怜悯、公义和爱结合在一起。
