# 酵——影响一切的小东西
新约圣经中酵的比喻，不是把它用作本身好或坏的东西，而是用来表明小小的一分可以影响其余的一切。放入面粉中的酵很少，但最终会使全团都发起来。
除了酵，主也常常用盐的比喻——盐同样影响其余的一切（防腐）：
> mf 5:13 :: !你们是世上的盐 :: !盐若失了味
> mk 9:50 :: !盐本是好的 :: !你们里头应当有盐，彼此和睦
同时，盐如同酵一样，也参与旧约的祭献：
> lev 2:13 :: !凡献为素祭的供物都要用盐调和 :: !一切的供物都要配盐而献
# 酵的正面含义
## 酵——天国
主耶稣基督把酵比作天国。又一次，小东西要影响一切：
> mf 13:33 :: !天国好像面酵 :: !直等全团都发起来
> lk 13:20-21 :: !我拿什么来比上帝的国呢 :: !好比面酵 :: !直等全团都发起来
# 酵的负面含义
## 酵——异端的教导
主耶稣基督向使徒们指出法利赛人和撒都该人教导的危害。他用酵的比喻表明小东西可以影响一切：
> mf 16:6,11-12 :: !你们要谨慎，防备法利赛人和撒都该人的酵 :: !乃是防备法利赛人和撒都该人的教训
## 酵——假冒为善
另一次，基督在数千人面前再次用酵的比喻，指出法利赛人的特点——假冒为善的危害。又一次，假冒为善成了影响一切的小东西：
> lk 12:1 :: !你们要防备法利赛人的酵，就是假冒为善
## 酵——团体中不悔改的淫乱之人
使徒保罗用酵的比喻指摘哥林多团体中有不悔改的淫乱之人。淫乱之人是团体中的小部分，却可以影响整个团体：
> 1kor 5:1,6-8 :: !风闻在你们中间有淫乱的事 :: !就是有人收了他的继母 :: !岂不知一点面酵能使全团发起来吗 :: !应当把旧酵除净，好使你们成为新团 :: !也不可用恶毒、邪恶的酵 :: !只用诚实真正的无酵饼
使徒建议除净的不是酵本身，而是恶毒邪恶的酵：也就是把不悔改的淫乱之人赶出团体（[[1kor 5:9,11]]）。这里使徒揭示的是旧约的含义，而不是在说饼：
> 1kor 5:7-8 :: !应当把旧酵除净，好使你们成为新团 :: !也不可用恶毒、邪恶的酵 :: !只用诚实真正的无酵饼
> mf 16:11 :: !这话不是指着饼说的
## 酵——团体中引人走向犹太教的人
使徒保罗用酵的比喻警告加拉太团体，他们中间有教导说为得救必须遵守摩西律法的人，这是危险的：
> gal 5:4-5,9-10,12 :: !你们这要靠律法称义的，是与基督隔绝，从恩典中坠落了 :: !一点面酵能使全团都发起来 :: !但搅扰你们的，无论是谁，必担当他的罪名 :: !恨不得那搅乱你们的人，把自己割绝了
