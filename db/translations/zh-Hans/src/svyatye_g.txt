# 预备性的共通问题
本文以上帝的教训为前提：**基督是上帝**（[[ru:Христос-Бог|引文]]）。
童贞女马利亚受敬礼，是根据敬礼圣人的教训；所以首先要证明[[ru:почитание-святых-в-Библии|敬礼圣人]]和[[ru:молитвы-святым|为圣人祈祷]]。
然而，这里将提出的依据，不只是把童贞女马利亚作为圣人之一来敬礼，而是**特别**敬礼她——作为**圣仆和上帝朋友中最大的一位**，作为耶稣基督的母亲（即上帝之母，因为耶稣基督是上帝）。
# 特别敬礼上帝之母的缘由
1. **童贞女马利亚对上帝话语特别的留意**；
2. **完全谦卑地顺服上帝**；
3. **被上帝拣选**。全宇宙中没有别的受造物蒙上帝赐予按人性生他的荣耀。她的功绩不在于生育，而在于上帝预先知道马利亚的品质（[[rim 8:29]]），因这些品质而拣选了她。上帝以这拣选指明她的伟大；
4. **上帝之子尊敬童贞女马利亚为自己的母亲**。再没有别的受造物（全宇宙中）是上帝之子的母亲；
5. **预言的应验**：“从今以后万代要称我有福”（[[lk 1:48]]）——即所有世代的人。上帝为童贞女马利亚成就了大事：“那有权能的为我成就了**大事**，他的名为圣”（[[lk 1:49]]）。
# 因谦卑被拣选
> lk 1:46-48 :: !他顾念他使女的卑微 :: !从今以后，万代要称我有福
连最大的先知（施洗约翰）的父亲撒迦利亚，也因不信——或说得更好：因不信任、疑惑——被天使责罚（[[lk 1:20]]）。而上帝之母谦卑地领受了对自己的定命，谦卑地回答：
> lk 1:38 :: !情愿照你的话成就在我身上
关于谦卑的重要引文：
| 你的力量，不在乎人多；你的威能，并不靠强力；但**你却是谦卑者的天主**，弱小者的扶助，无力者的保护，无靠者的依赖，失望者的救主。 ||| sb iudf 9:11
| **你越伟大，在一切事上越当谦下**；这样，你才能在上主面前，获得恩宠。 ||| sb prsir 3:20
关于谦卑的重要引文：[[ru:смирение|谦卑]]
# 上帝话语最留心的听者
> pr 23:26 :: !我儿，要将你的心归我 :: !你的眼目也要喜悦我的道路
> lk 2:19 :: !马利亚却把这一切的事存在心里，反复思想
> lk 2:51 :: !他母亲把这一切的事都存在心里
> lk 11:27-28 :: !是，却还不如听上帝之道而遵守的人有福
正如圣伊格纳提（布良恰尼诺夫）所说，她成了上帝教导的最留心、最恒常的听者和实行者：
“童贞女高于所有圣徒，一方面因为她成了神人的母亲，另一方面因为**她是最恒常、最留心的听者和实行神人所宣讲教导的人**。”
（[俄文](https://azbyka.ru/technik/Ignatij_Brjanchaninov/asketicheskaya_propoved/54)《正教会论上帝之母的教导》）
# 成为基督上帝的母亲
特别敬礼上帝之母的缘由之一，是她——上帝之母（按人性）：因为再没有别的受造物是上帝的母亲。上帝的诫命要求尊敬父母（[[ru:10-заповедей#HH-5|第五诫]]），所以基督上帝亲自尊敬上帝之母为自己的母亲，他信实的门徒们也跟随他。
## 童贞女马利亚生了上帝之子
正是上帝的独生子真实地由女子所生：
> gal 4:4 :: !上帝就差遣他的儿子 :: !为女子所生
上帝的独生子、上帝的道，真实地成了肉身：
> in 1:14 :: !道成了肉身，住在我们中间
天使加百列直接称童贞女马利亚所生的孩子为上帝之子：
> lk 1:35 :: !所要生的圣者必称为上帝的儿子
## 童贞女马利亚——上帝之子的母亲
义人以利沙伯——先知施洗约翰的母亲——直接称童贞女马利亚为上帝之母：
> lk 1:43 :: !我主的母
> mf 2:11 :: !看见小孩子和他母亲马利亚
> in 19:26 :: !耶稣见母亲 :: !就对他母亲说
> in 2:5 :: !他母亲对用人说
> in 2:1 :: !耶稣的母亲在那里
（[[mf 2:14]]；[[mf 2:20]]；[[mf 2:21]]；[[mf 12:46]]；[[mk 3:31]]；[[lk 2:33]]；[[lk 2:34]]；[[lk 2:43]]；[[lk 2:48]]；[[lk 2:51]]；[[lk 8:19]]；[[in 2:3]]；[[in 2:12]]；[[in 19:25]]；[[in 19:26]]；[[act 1:14]]）
如果上帝之子永远成了人（这是确实的），那么童贞女马利亚就永远是上帝之子的母亲。
## 上帝之子——童贞女马利亚之子
> mf 1:25 :: !等她生了儿子
## 童贞女马利亚——上帝之母
童贞女马利亚生了耶稣基督。
耶稣基督——上帝之子——是[[ru:Христос-Бог|我们的上帝]]。
童贞女马利亚所生的是[[ru:Христос-Бог|我们的上帝]]。就是说，她是生了上帝的那位——上帝之母。
童贞女马利亚生的不是永恒的上帝本性——它存在于时间和空间之外——而是上帝之子的人性；这人性有其开始，并且从它存在之初就完全属于上帝之子（上帝）的位格。
简言之，童贞女马利亚按人性生了上帝。
然而，上帝之母的伟大恰恰在于她被拣选作上帝的母亲。她的功绩不在于生育——生育的人很多——而在于：上帝预先知道马利亚的品质（[[rim 8:29]]），从所有存在过的人中拣选的不是别人，而正是童贞女马利亚。
# 上帝之母曾经是、并且仍是童贞女
## 耶稣基督诞生之前马利亚的童贞
童贞女马利亚与义人约瑟没有夫妻关系。她虽已许配给约瑟（[[lk 1:27]]），却不明白自己没有夫妻关系怎么能生子：
> lk 1:34 :: !我没有出嫁，怎么有这事呢
还应注意：这个问题只有在童贞女马利亚曾向上帝许愿保守童贞的情况下才有意义。否则，即使童贞女马利亚至今没有与义人约瑟有过夫妻关系，当上帝的天使宣告她将生子时，她显然应当顺服上帝、与丈夫有夫妻关系，好叫预言应验。但如果童贞女马利亚曾向上帝许愿度贞洁的生活，那就立刻产生问题：“怎么会生子呢？因为向上帝所起的愿是不可违背的（[[chis 30:3]]）？”
天使回答说，向马利亚所预言的将不经丈夫、以上帝大能的奇妙运作成就：
> lk 1:35 :: !圣灵要临到你身上 :: !至高者的能力要荫庇你
耶稣基督只是按人们的看法是约瑟的儿子：
> lk 3:23 :: !依人看来，他是约瑟的儿子
实际上，基督不是由约瑟所生，而是由圣灵的大能。
## 耶稣基督诞生之后马利亚的童贞
关于马利亚终身童贞（至今仍是童贞女）的预言：从她生的只有一个孩子——进入我们世界的上帝、基督，正如藉着童贞女马利亚、上帝之母这门一样：
> iez 44:1-2 :: !这门必须关闭，不可敞开 :: !谁也不可由其中进入，因为耶和华以色列的上帝已经由其中进入，所以必须关闭
这样，童贞女马利亚除了耶稣基督，没有生任何别的孩子。同时，马利亚的童贞没有被破坏。
还应注意：在被钉十字架的那一天，基督把自己母亲的关怀托付给所爱的门徒——神学家约翰（[[in 19:26-27]]）。这表明：除了基督——童贞女马利亚的独子——之外，她再没有丈夫，也没有别的本应照顾她的儿女。
义人约瑟在基督诞生时已经年老，所以在基督被钉时早已去世。确实，在记述耶稣基督的童年之后，经上再也没有提到约瑟。而马利亚被托付给约翰，是因为正是他将比其他使徒在地上活得更久。主自己指明，使徒彼得将为基督受难，而使徒约翰将活得久得多（[[in 21:22]]）。我们知道，约翰是使徒中最年轻的，在地上劳苦直到第一世纪末，而其余使徒都领了殉道之死。这使使徒约翰能够比所有其他人更久地照顾童贞女马利亚。
这一事实也表明：童贞女马利亚没有别的能照顾她的儿女。
# 万代都要称上帝之母有福
上帝之母将被称为有福，上帝为她成就了大事：
> lk 1:48-49 :: !从今以后，万代要称我有福 :: !那有权能的，为我成就了大事
类似的话也说及基督自己：
> ps 72:17 :: !人要因他蒙福，万国要称他有福
# 基督与母亲的特殊关系
## 上帝之子尊敬童贞女马利亚为自己的母亲
上帝之子顺服律法：
> gal 4:4 :: !且生在律法以下
上帝命令尊敬父亲和母亲：
> ish 20:12 :: !当孝敬父母
> vtor 5:16 :: !当照耶和华你上帝所吩咐的孝敬父母
> ish 21:17 :: !咒骂父母的，必要把他治死
> lev 20:9 :: !凡咒骂父母的，总要治死他
> ish 21:15 :: !打父母的，必要把他治死
> lk 18:20 :: !当孝敬父母
> mk 7:9,11-12 :: !你们诚然是废弃上帝的诫命 :: !以后你们就不容他再奉养父母
全宇宙中除童贞女马利亚外，没有别的受造物是上帝之子的母亲。在这层关系上，天使和世人中没有谁高于童贞女马利亚，因为尊敬她为自己母亲的，正是上帝之子、上帝本身。
## 基督听自己母亲的话
基督指出，宣讲和奇迹（显明他的荣耀）的时候还没有到；但因母亲所求，他行了第一个奇迹：
> in 2:3-5,7-8,11 :: !耶稣的母亲对他说 :: !我与你有什么相干 :: !我的时候还没有到 :: !他母亲对用人说 :: !这是耶稣所行的头一件神迹 :: !显出他的荣耀来
## 基督关怀自己的母亲
在十字架上残酷受苦的时候，基督关怀自己的母亲：
> in 19:26-27 :: !耶稣见母亲 :: !就对他母亲说 :: !看你的母亲 :: !从此那门徒就接她到自己家里去了
## 基督与自己母亲个人关系的性质
在最可怕的时辰——在十字架上经受极重的身体痛苦、被出卖、门徒逃散、人之常情的被弃感（第九个小时：“我的上帝！我的上帝！**为什么离弃我**？”，[[mk 15:34]]）——主关怀着自己的母亲，她跟随他直到最后一刻。
在这最艰难的时刻，他转向自己的母亲，对她显出特别的关怀，把她托付给所爱的门徒——而且不是一般的“看顾她、照顾她”，而是“接她作你的母亲”：
> in 19:26-27 :: !就对他母亲说 :: !看你的母亲 :: !从此那门徒就接她到自己家里去了
注意：所有基督指着说“看哪，我的母亲，我的弟兄”（[[mf 12:48-50]]）的人，都离开了他（[[in 16:32]]）；而他的母亲却同他在一起直到末了。
> in 16:32 :: !留下我独自一人 :: !其实我不是独自一人，因为有父与我同在
> in 8:29 :: !他没有撇下我独自在这里 :: !因为我常作他所喜悦的事
基督没有撇下自己的母亲独自一人，也是出于同样的原因。
## 上帝之母与基督同到底，这重要吗？
使徒保罗在离世前也经历了类似的被弃：
> 2tim 1:15 :: !凡在亚西亚的人都离弃我
> 2tim 4:10 :: !底马贪爱现今的世界，就离弃我
上帝之母从起初到末了在一切事上都留心、顺服、忠于上帝。她一直是、并且仍是与上帝同在的。
# 对异议的回应
## “可是圣经里没有‘上帝之母’这个词”
圣经里也没有“三位一体”这个词——那又怎样呢？圣经里所说的，正是“上帝之母”一词所说的：童贞女马利亚是耶稣基督的母亲；耶稣基督是上帝；童贞女马利亚生了耶稣基督，即生了上帝——当然，按人性。由她所生的，是上帝。童贞女马利亚——生了上帝的，简称：上帝之母。
## “怀你胎的和乳养你的有福了”
人们因亲缘关系、因生养和乳养基督而赞美上帝之母；但基督亲自更正了这一理解（重新立定重点），指明自己母亲的伟大，在于她对上帝之道的特别留心和完全谦卑的顺服：
> lk 11:27-28 :: !怀你胎的和乳养你的有福了 :: !是，却还不如听上帝之道而遵守的人有福
> lk 2:19 :: !马利亚却把这一切的事存在心里，反复思想
> lk 2:51 :: !他母亲把这一切的事都存在心里
## “谁是我的母亲？”
这里基督又一次强调：童贞女马利亚的伟大不像人们所想的那样在于亲缘关系，而在于她毫无条件地遵行上帝的旨意：
> mf 12:48-50 :: !谁是我的母亲 :: !凡遵行我天父旨意的人，就是我的弟兄、姐妹和母亲了
## “只是没有和她同房，等她生了儿子”（太 1:25）
> mf 1:25 :: !只是没有和她同房，等她生了儿子
“没有和她同房，等她生了儿子”这话，并不意味着基督生下之后“就同房了”。这是圣经中常见的表达方式，并不表示后来有了改变。
例如：
> mf 28:20 :: !我就常与你们同在，直到世界的末了
——而在世界终结之后，基督显然仍将与信他的人同在。
> in 12:35-36 :: !你们应当趁着有光，信从这光
——而在基督升天之后，也应当信光（信基督）；
> 1kor 15:25 :: !因为基督必要作王，等上帝把一切仇敌都放在他的脚下
——而在仇敌被放在脚下之后，基督显然仍要作王（[[lk 1:33]]；[[2pet 1:11]]）。
> ps 110:1 :: !你坐在我的右边 :: !等我使你仇敌作你的脚凳
——而在仇敌被放在脚下之后，基督显然仍坐在父的右边，即仍要作王。
> otkr 2:24-25 :: !但你们已经有的，总要持守，直等到我来
——而在基督再来之后，显然仍须持守美德和信仰。
> 2ts 6:23 :: !扫罗的女儿米甲，直到死日，没有生养儿女
——而在她死后，米甲显然也没有生养儿女。
还应注意圣经中的这些地方：
> mf 12:18-20 :: !压伤的芦苇，他不折断 :: !等他施行公理，叫公理得胜
## “生了头胎的儿子——就是说还有别的孩子？”
圣经称上帝之母的儿子为头胎的：
> mf 1:25 :: !等她生了儿子〔有古卷作『等他生了头胎的儿子』〕
> lk 2:7 :: !就生了头胎的儿子
（*在西奈和梵蒂冈抄本中没有“头胎”一词；不过这个词在路 2:7 中有。*）
教会教训的反对者认为这是指童贞女马利亚还有别的儿女，说：“既然有头胎的，就是说还有别的孩子。”圣经自己表明这种想法是错误的。
上帝自己在圣经中给“头胎的”一词下了定义——**凡开胎的**：
> chis 18:15 :: !凡头生的都要归给你
> ish 34:19-20 :: !凡头生的都是我的 :: !凡头生的儿子都要赎出来
一切头胎的都属于上帝，因此：
1. 人的头胎的必须被带到圣殿，从司祭手中赎出来。
2. 洁净牲畜的头胎的被带到圣殿献上，被杀，作为祭物献给上帝。
3. 不洁净牲畜的头胎的不能作祭物，所以必须赎出来。
人及牲畜一旦生下第一个孩子，就应献给上帝或赎出来。显而易见，就在这一时刻，这头生的孩子是独生的，然而上帝称之为头胎的，因为他开了胎。这意味着：**凡独生的都是头胎的，但并非凡头胎的都是独生的**。
而如果像反对教会教训的人那样想，认为只有那些有弟兄姊妹的才叫头胎的，那就得出：生了第一个孩子的人应当对司祭说：“等生了第二个，这个才能叫头胎的；现在他不是头胎的，而是独生的，所以我不必把他献给上帝、不必赎他。”然而连这种荒谬的想法也违背圣经和常识，因为独生的救主正是按这关于头胎的律法被带进圣殿的：
> lk 2:22 :: !按摩西律法满了洁净的日子 :: !他们带着孩子上耶路撒冷去，要把他献与主
显然，主耶稣基督在这里是**独生**的，但他被作为**头胎的**带进圣殿。这样，这里的“头胎的”，按上帝的话，指的是凡开胎的，并不表明母亲是否还有别的生育。详见注[2]。
## 耶稣基督的弟兄们
圣经说基督有弟兄们：
> mf 13:55 :: !他弟兄们不是叫雅各
> in 7:5 :: !因为连他的弟兄说这话，是因为不信他
> mk 3:31 :: !耶稣的母亲和弟兄来
> 1kor 9:5 :: !仿佛其余的使徒和主的弟兄，并矶法一样
这里指的是约瑟前婚的儿女，或只是亲属。弟兄们——就是一般的亲属。例如，罗得是亚伯拉罕的侄子，但在圣经里也称为弟兄：
> gen 14:12 :: !又把亚伯兰的姪儿罗得
> gen 13:8 :: !因为我们是骨肉
约瑟在马利亚被许配给他作保护者时已经年老，因为马利亚不能没有丈夫。如果基督由马利亚所生、而她没有已知的丈夫，那么按律法她应当被石头打死（[[vtor 22:20-21]]），因为所有的人都会以为她行了淫乱（婚外）之事。所以主这样安排：马利亚有丈夫，但她以奇妙的方式、不由丈夫、由圣灵的感孕而怀孕（[[mf 1:18-25]]；[[lk 1:34-35]]）。
在耶稣的童年之后，经上再也没有提到约瑟；而童贞女马利亚陪伴耶稣基督直到末了——直到十字架的苦难（[[in 19:25-26]]），并且在复活之后、五旬节那天也被提到（[[act 1:14]]）。
基督把自己的母亲托付给所爱的门徒——约翰（[[in 19:27]]）。显然，那时约瑟已经去世。
这样，耶稣基督的“弟兄们”——只是一般的亲属，而完全不是童贞女马利亚的别的儿女。
而预言清楚地说明，从童贞女马利亚所生的只有主耶稣基督：
> iez 44:1-2 :: !这门必须关闭，不可敞开 :: !谁也不可由其中进入，因为耶和华以色列的上帝已经由其中进入，所以必须关闭
## 任何地方都没有说童贞女马利亚不信基督
教会的批评者常常重复这样的想法：仿佛童贞女马利亚不信她的儿子是救主、是所应许的弥赛亚、是基督。但这不是真的。圣经里没有这样的话。说的只是弟兄们（约瑟前婚的儿女）不信基督：
> in 7:5 :: !因为连他的弟兄说这话，是因为不信他
这是相当可以预料的：他们是约瑟前婚的儿子，已经是成年人，见过少年耶稣长大。所以他们和基督的其他同乡（加利利居民）一样，难以相信（[[mf 13:54-58]]）。但后来弟兄们也信了（[[act 1:14]]；[[gal 1:19]]）。
## 王的母亲——王后
批评者责备教会称上帝之母为王后。但王的母亲正是王后。
| **列王的公主都成群结队前来欢迎你，王后佩带敖非尔金饰，在你右边侍立。** ||| sb ps 45:10 ~~ 俄文本编号为 Пс 44:10（圣咏编号相差一）。
使徒们曾被拒绝坐在基督国里他的右边和左边：
> mk 10:40 :: !只是坐在我的左右 :: !乃是为谁预备的，就赐给谁
如果不是使徒们“坐”在那里，那是谁？在正教的“最后审判”圣像中，写在基督旁边的正是上帝之母（在右边）和先知施洗约翰（在左边）——作为妇人所生中最大的（[[mf 11:11]]）。
## “上帝之母，拯救我们”这句话
这里需要正确理解意义。救主只有一位，而在拯救的事业中有许多同工者：
> 1kor 3:9 :: !因为我们是与上帝同工的
使徒打算拯救人：
> 1kor 9:22 :: !向什么样的人，我就作什么样的人 :: !无论如何总要救些人
> rim 11:14 :: !或者可以激动我骨肉之亲发愤 :: !好救他们一些人
妻子可以救丈夫，丈夫可以救妻子：
> 1kor 7:16 :: !你这作妻子的，怎么知道不能救你的丈夫呢 :: !你这作丈夫的，怎么知道不能救你的妻子呢
使徒呼召拯救人：
> iud 1:22-23 :: !有些人你们要从火中抢出来 :: !搭救他们
> 1tim 4:16 :: !你要谨慎自己和自己的教训 :: !又能救自己，又能救听你的人
## “上帝之母的仆人”这句话
这与拯救的情形相同。必须正确理解意义。
我们不把上帝之母当作上帝来事奉，但我们事奉她。如果上帝之母求我们什么事，我们会乐意为她效劳。难道可以想象基督徒会作别样的事吗？
圣经里有义人不但称自己为上帝的仆人——同时仍是独一上帝的仆人——也称自己为人的仆人的地方。
使徒们——是基督徒们的仆人：
> 2kor 4:5 :: !并且自己因耶稣作你们的仆人
亚比该——敬畏上帝的人、庇护先知脱逃逼迫的人——称自己为先知以利亚的仆人，称以利亚为主人：
> 3ts 18:3-4,7-9,12 :: !俄巴底认出他来，就俯伏在地 :: !你是我主以利亚不是 :: !仆人却是自幼敬畏耶和华的
## 上帝之母在安葬之后复活了
敬礼上帝之母的人的反对者，反对正教会关于主耶稣基督使自己的母亲复活的圣传，仿佛这是不可能的，以为只有基督复活了。然而从圣经的角度，这没有任何困难：因为基督复活之后，许多圣徒复活了（无论我们怎样理解这复活的性质）：
> mf 27:51-53 :: !坟墓也开了 :: !已睡圣徒的身体，多有起来的 :: !到耶稣复活以后，他们从坟墓里出来 :: !进了圣城，向许多人显现
如果主在自己的复活中使许多圣徒复活，那他更能使自己的亲生母亲复活——他为道成肉身而拣选了她，行奇迹时听了她，并关怀她、把她托付给所爱的门徒。
为证实上帝之母复活的圣传，还应注意：既然教会从最古老的年代起就以这样的敬畏对待圣人的圣髑（详见[[ru:почитание-мощей-цитаты-святых|敬礼圣髑的引文]]），那么教会没有上帝之母的圣髑，正如没有主耶稣基督的圣髑（因为他复活了）。
