# 前言
“唯独圣经”是一种用来建立自己教会的伎俩。如同街头猜杯戏法的把戏，用简单而灵活的手法把听众绕晕，使他们觉察不到就在眼前进行的调包。他们传授的并不是“只按圣经”的教训，而是又一种对圣经的解释——摈弃一切不符合新教师个人信仰（他的意见）的东西。教师的个人信仰被传递给听众，成为又一个人的传统。但这传统不被称为传统——伎俩就在这里：听众产生一种错觉，仿佛他们只按圣经相信。以前的异端团体就是这样建立的：摈弃教会直接从使徒们与圣经一起领受的信仰，把教师们自己的意见高举于一切之上，而这些意见彼此各不相同。无论出现多少教派，它们的教师们按圣经可以解释出任何一种信仰。

# “唯独圣经”
**“唯独圣经”**（拉丁文 Sola Scriptura，俄文——Только Писание）——十六世纪改革家们（[[ru:3SlQ_Протестантизм|新教]]运动的创始者）提出的建立教义的方法：按照这一方法，建立教义的最高权威只是圣经（按读者的主观理解）。
虽然理论上如此，但在新教徒和新新教徒中间，广泛地把“唯独圣经”理解为完全弃绝圣传。愿意在教父遗产领域论辩的新教徒并不多；而且最常见的是，在正教徒与新教徒的论辩中，只要提到圣教父的名字、更不必说他们的著作，就会遇到激烈的排斥和讥笑。“传统”一词在新教团体中被赋予负面的态度——把它与“古人的遗传”（[[mf 15:2]]）等同起来，同时完全无视使徒圣传的存在——而使徒们自己曾命令保守这传统（[[2sol 2:15]]）：这信仰是主和使徒们以种种方式栽种在教会里、并在教会中不断保存、由祖先传给后代的。
# 为“唯独圣经”辩护的尝试
“唯独圣经”的拥护者引用圣经的引文，摆出这样的姿态，仿佛其中说的是必须把圣经当作信仰的最高或唯一权威。然而实际上，所引的引文中没有一处说的是“唯独圣经”，即仿佛**只有**圣经（除它之外什么都没有）在教义中拥有某种独一的、最高的或唯一的角色。
为“唯独圣经”辩护所引用的引文有以下几类。
## 1. 上帝的道——是真理
上帝以任何方式所宣告的（口头的、书面的、异象中、经由使者：天使、先知或使徒）——都是真理：
> in 17:17 :: !你的道就是真理
对此我们不争辩。上帝的每一句话都是真理，而不只是写下的。口传的圣传也称为上帝的道：
> 1sol 2:13 :: !我们所传上帝的道 :: !乃以为是上帝的道
> 1pet 1:23-25 :: !惟有主的道是永存的 :: !所传给你们的福音就是这道
对圣经都是上帝所默示的，我们也不争辩：
> 2tim 3:16 :: !圣经都是上帝所默示的
## 2. 圣经对信徒是重要的
圣经对信徒有很高的价值：
> 2tim 3:16 :: !圣经都是上帝所默示的 :: !有益 :: !于教训
> in 5:39 :: !你们查考圣经
对此我们同样不争辩。
---
这一切都是对的。正教会不与其中任何一点争辩，而是自己肯定这一切。
然而：
- 这些引文并不表明真理**只**在圣经里，而圣传不是真理；关于圣传的同样的引文干脆被忽略（见[[ru:Против_Сола_Скриптуры#HH-Указание-хранить-Предание-и-учить-согласно-с-ним|下文]]），因为“唯独圣经”的拥护者没有维护圣传之必要性的目标。
- 这些引文并不表明**一切**上帝的启示都写在了圣经里、因此仿佛圣传可以被抛弃。抛弃圣传——是违背圣经的行为（[[2sol 2:15]]）。
所引的一切引文对于“唯独圣经”这一概念中的“唯独”一词完全没有说什么。它们只是指明上帝启示的必要性和它的真实性，无论这启示以什么形式被领受：书面的、口头的或以可见方式显示的。我们相信这一点，这里没有任何“唯独圣经”的成分。
# “唯独圣经”宣讲者的伎俩
向听众表明圣经拥有很高的权威、听圣经就是听上帝之后，接下来在听众完全不觉察的情况下发生了调包：开始讲话、按自己的意思解释圣经的，不再是上帝和圣经，而是宣讲者。于是现在被要求当作上帝的话来接受的——是宣讲者的话，是几千个在解释圣经上彼此矛盾的团体之一的创立者的话。
当然，宣讲者在自己的话语中继续引用圣经，用一套引文支持自己的话；但这里明显的问题是：新教以这种方式生出了关于上帝、他的作为和拯救方式的成千种随便什么样的教训。更有甚者，从基督教存在之初，教会之外的团体就力求歪曲信仰、恰恰藉着歪曲圣经把人引到自己那里。连魔鬼也这样做过——正是用圣经试探基督：
> mf 4:5-6 :: !可以跳下去 :: !因为经上记着说 :: !主要为你吩咐他的使者，用手托着你
魔鬼同样藉着上帝的话语使最初的人堕落：
> gen 3:1-5 :: !上帝岂是真说不许你们吃园中所有树上的果子吗 :: !你们不一定死
这样，魔鬼和与教会为敌的团体的创立者们，正是使用圣经来诱惑人。这是怎么发生的？发生的原因在于：把圣经的权威赋予了它的私人的解释。
# “唯独圣经”的根本问题——主观主义
这一建立信仰之方式的根本问题在于：**不存在对圣经的客观理解**。每个人都透过自己积累的经验、世界观、兴趣和偏好来接受它，也就是**主观地**接受。简单地说，问题在于：**谁来决定什么符合圣经、什么不符合？**“唯独圣经”不回答这个问题。恰恰是这一点使它成为只在理论上存在、无法在实践中实现的学说。这不是无根据的断言。
“唯独圣经”最早的使用者（改革家们）提出了以他们各自不同的、对圣经的理解为基础的不同教义。分歧涉及最重要的问题：
- 得救；
- 人是否被预定得救，
- 人的罪性，
- 圣奥秘在信徒生活中的角色，
- 基督在圣餐中临在的真实性，
- 能否给婴儿施洗，
- 信徒生活中有没有圣像。
不同的教义立刻产生了不同的团体。而这只是开始。随着时间推移，“唯独圣经”使用者中间的分歧和分裂迅速增多；开始于路德、加尔文和英国国教的三个方向，后来发展出成千上万个派别。
# “唯独圣经”导致出现众多圣传
按宗教改革家们所宣称的设想，“唯独圣经”应当滤去人的圣传。而实际上，每一个新的新教社团的创立者，都成了又一个人之圣传的创立者——只是把自己的信仰披上圣经引文的外衣；在宗教改革之前很久，自从出现有权威的言论和文本以来，各种异端创始者就已经在这样作了（详见[[ru:Предание|圣传]]）。
新的领袖周围形成了一个社团，这社团所接受、保存并传给自己后代的，不是别的，正是这位领袖的信仰。如果有人想加入这个社团，他就必须接受该社团领袖的信仰，并按该社团的理解去理解圣经。人到浸信会那里来——就按浸信会的圣传接受信仰；到五旬节派那里——按五旬节派的圣传；到复临派那里——按复临派的圣传，其余的团体也是如此。不然他就会被排斥为“异端”、被驱逐。
结果是，所有这些由“唯独圣经”产生的社团都走到了这一步：要相信的根本不是“只按圣经”，而是严格按他们的圣传——只按他们的领袖曾经说过的、而社团把它作为圣传保存下来的话，经由口头的传道和教师们的书籍，把知识从祖先传给后代。只不过人们不把这称为圣传，更不称为“人的圣传”——这个词作为吓人的东西，只会用来称呼教会的圣传。
# 社团领袖——信仰的源头
如果圣经是某种自足的信仰源头，那么每个主张“只按圣经”建立信仰的人，本应与其他“唯独圣经”的使用者有相同的信仰。然而他们所有人的信仰各不相同，也就是说信仰的源头各不相同。这源头就是**人**——社团的创立者。他发明了信仰，传给自己的追随者，而追随者们则保存着自己领袖的信仰。
# 实际上，在新教社团中居首位的是他们自己的圣传，而不是圣经
在所有这些社团中，居首位的正是他们的圣传，圣经只被用作补充的工具，从中挑选有利于论证圣传的引文。在这种团体中所接受的信仰实际上压过了圣经，圣经文本只被用来在听众周围制造肥皂泡——一种引人分心的幻觉，仿佛这里信的只是“只有圣经”。
如果圣经与圣传相抵触，圣经很容易被忽略。例如，圣经中任何地方都没有说婴儿不能受洗；相反，洗礼的预像（割礼）恰恰行在婴儿身上（[[gen 17:10-12]]），然而许多新教徒坚持禁止婴儿受洗，从圣经里举出间接的理由。圣经中没有说婴儿不受洗也能得救；相反，救主说，除非从水和圣灵生，就不能进上帝的国（[[in 3:3,5]]），又命令为万民施洗（[[mf 28:19]]），却不设年龄的限制；而未受割礼的人要从民中剪除（[[gen 17:14]]）——预像清楚地表明了洗礼的必要。
他们在保守只存在于自己圣传中的信仰的同时，指摘教会关于司祭职分之恩典经由按手传递的教导，却轻率地抛弃了论及上帝的恩赐**借着**按手传递的最直白的话（[[2tim 1:6]]；[[act 8:18]]）。为什么？原因很简单：他们的圣传提供的是另一种信仰；既然圣传压过圣经，圣经的直白教导就被忽略了。
# 不诚实的对立
在“唯独圣经”拥护者所建立的团体中，广泛流传着这样的对立：教会抛弃了圣经、只按传统相信；而每个新教团体相反——抛弃了传统、只按圣经相信。
实际上：
- 教会不是只按传统相信——她把圣经与传统平等地使用；
- 新教团体也不是只按圣经相信——他们只承认自己领袖的信仰为正确，并把它作为传统保存。
这样，实践中根本不存在任何“唯独圣经”。它只存在于理论中。每个具体的人对这一概念的实现，必然带来又一种新信仰、又一种对圣经的新理解、又一个团体，以及随之而来的又一个传统。
证明这一点并不难。做一个实验就够了。如果一个人进入这样的团体之一，而这团体不向他传递自己的知识、只是把一本圣经放在他手里，那么只读这一本圣经，这个人百分之百不会得出这个团体的信仰。他只有在一种情况下才会得出他们的信仰——如果这团体把自己的信仰传给他。
正教会用圣经证实自己全部的教义。然而新教团体不同意教会性的圣经理解，提出以自己的理解和信仰来代替“唯独圣经”（默不作声）。
# “唯独圣经”与圣经直接冲突
正教会反对“唯独圣经”的理由，不是针对“圣经”一词，而是针对“唯独”一词。而理由正是建立在圣经上的：
1. “唯独圣经”在圣经里没有。圣经本身没有建立“只按圣经”的信仰、或只偏爱圣经的要求。因此新教徒只能引用关于圣经之重要性的引文（对关于圣传之重要性的引文避而不谈），因为圣经里关于“唯独圣经”的引文根本没有。
2. 相反，圣经说要保守口传的圣传。多次要求保守圣传：不仅是使徒们书面的、还有口头的宣讲（[[2sol 2:15]]）。而且使徒们把口头宣讲放在第一位（[[2sol 2:15]]）。
3. 圣经要求向教会的教师们学习。上帝在教会里设立了司祭们和教师们（[[1kor 12:28]]；[[ef 4:11]]），教会的羊群（会众）被托付给他们管理并教导。“唯独圣经”的拥护者拒绝向教会学习。这些人不愿在教会里作学生，就宣布自己为教师（[[2tim 4:3]]）。
4. 圣经可能被错误地解释。圣经里有话：未经教会坚立的人强解圣经，自取沉沦（[[2pet 3:15-16]]）。“唯独圣经”的拥护者甚至不打算向教会学习。他们自己摈弃教师、只拿了教科书，随意解释圣经，这使他们成为众多分离的团体——有着不同的信仰和不同的对教科书（圣经）的理解。而圣经里说：不经教会的教导而自己解释圣经，导致歪曲圣经和灭亡（[[2pet 3:15-16]]）。
这样，“唯独圣经”的拥护者在以下各点上行事违背圣经：
1. 教导圣经里没有的东西。圣经里没有关于“唯独圣经”的教训；
2. 摈弃使徒们口传的圣传。他们说只有圣经具有首要意义，却与圣经里所记使徒的话背道而驰——使徒们要求保守圣传，把口头宣讲放在第一位，然后才是书面的（[[2sol 2:15]]）；
3. 摈弃教会的教导职分和上帝所立的教会教师们，直接违背圣经（[[1kor 12:28]]；[[ef 4:11]]）。
4. 不经教会的坚立而解释圣经。每个新教团体都有自己的圣经理解；团体的每个聚会点、乃至聚会点中的每个人，都可以随己意理解圣经，因为“唯独圣经”催促人摈弃圣经（按读者的理解）之外任何其他教义来源的最高权威。如果一个人喜欢另一种对圣经的理解，那它就被认为是正确的——毕竟圣经比宣讲者的话更大，哪怕那宣讲者是新教的。
# “唯独圣经”观念错误的最主要证明
如果发明“唯独圣经”的目的是尽可能地分裂基督教世界，那么这一观念极其有效。但如果发明它的目的是寻找使徒的信仰，那么“唯独圣经”就成了错误的观念，它使人远离目标，并生出了众多的传统和分裂。
“唯独圣经”错误的最主要证明——就是“唯独圣经”的使用者们自己：以“只按圣经”为口号建立的、无数彼此矛盾的团体及其教义。没有任何别的观念像“唯独圣经”那样在信基督的人中制造了这么多分裂。而这是直接违背圣经作的（[[in 17:20-21]]；[[1kor 1:10]]；[[1in 2:18-19]]）。
> in 17:20-21 :: !使他们都合而为一 :: !叫世人可以信你差了我来
> 1kor 1:10 :: !都说一样的话 :: !不可分党 :: !一心一意 :: !彼此相合
> 1in 2:18-19 :: !现在已经有好些敌基督的出来了 :: !他们从我们中间出去，却不是属我们的
---
十六世纪，改革家路德提出了“唯独圣经”的概念。后来每个改革家都开始建立信仰，如他们所宣称的，把最高权威赋予“只按圣经”（即对圣经的自己理解）。原本以为只按圣经建立信仰，应当使人们得出使徒的信仰。这样就宣称：正是这个方法、并且只有这个方法，使人得以达到使徒的信仰。但结果，所有改革家都与构想相违，得到了各不相同的信仰。
“唯独圣经”的进路最初产生了三个对圣经理解不同的方向：信义宗、加尔文宗和英国国教。后来，这一概念使地球上的任何人都可以建立自己的团体和自己的教义——只要拿起一本圣经。于是就出现了成千上万的所谓“宗派”，每个都有自己的信仰和自己的圣经理解。这一过程至今仍在继续。因信仰的差异，按人的习俗（[[1kor 3:3]]），他们彼此分离，各有不同的信仰、不同的洗礼和不同的上帝观。这一切都与教会中应有的样子相违背：
> ef 4:4-5 :: !身体只有一个 :: !一主，一信，一洗
有人可能就信仰上帝的不同提出异议，说大家都信耶稣。然而并非人人都有使徒们对基督作为上帝的信仰；有不少新教一位论者，否认对独一上帝——父、子、圣灵三位一体——的信仰。此外，许多团体对上帝、对他的旨意和讨他喜悦的方式有不同的观念。比如五旬节派/灵恩派认为，上帝喜悦他们无条理的喃喃、倒在地上，仿佛这一切都是圣灵——即上帝——的运作。而别的团体则拒绝五旬节派对上帝的这种观念，提出自己另外的观念。这样，他们对上帝有不同的观念，有时甚至有关于上帝的不同教训。
无数手拿圣经、彼此矛盾、宣称又建立了一种“只按圣经”之信仰的人，是反对“唯独圣经”的最鲜明论据。人们曾应许说，藉着“唯独圣经”会铺就通向唯一使徒信仰的道路，把信仰从“人的附加物”中解放出来；但实际上，这一进路生出了无数人的附加物，没有给基督教世界带来任何东西，只有无数的分裂——违背上帝关于信徒合一的旨意（[[in 17:20-21]]；[[1kor 1:10]]；[[1in 2:18-19]]）。
## 旧约中的平行
类似的分裂在旧约中也发生过——在建造巴比伦城和塔的时候（[[gen 11:1-9]]）。人们想靠自己的力量建一座城和一座通天的塔（[[gen 11:4]]），但开始说不同的话（[[gen 11:7]]），分裂并分散了（[[gen 11:8]]）。如今也是这样。
上帝建立了教会，永远赐给她圣灵（[[in 14:16]]），自己应许常与她同在（[[mf 28:20]]），口传了教训，立了司祭（[[act 20:17-18,28]]）和教师（[[1kor 12:28]]）——他们口头教导，但也进行书信往来。
十五个多世纪之后，来了些人，从教会里只取了教会所保存的部分使徒的书信（并非全部），违背这些书信，摈弃了不可战胜的教会（[[mf 16:18]]）——上帝所立的根基；摈弃了从使徒领受、保存在教会里的信仰——使徒们的圣传（[[2sol 2:15]]等）；摈弃了上帝所立的司祭（[[act 20:17-18,28]]）和教师（[[1kor 12:28]]）；决意按自己的聪明和力量（历史、考古、语言学等研究）独立地、与上帝所建立的教会分离地，建造自己的城。别的建造者也加入了他们。结果，他们开始说不同的话，分裂并分散，开始建造自己的、各有自己交流语言的居住地，而不愿住在那座“有根基的城——其设计者和建造者乃是上帝”（[[evr 11:10]]）。
# “唯独”圣经导致“唯独”式思维
新教的教训包含许多带“唯独”一词的论点，它常使拥护者陷入一种思维，可简称为“唯独”式思维。这使其中许多人只注意文本中自己喜欢的一些片段，在合适的地方想象出“唯独”一词，仿佛对自己说：“只有这些话我应当考虑”，并在这上面建立某种构造。当某文本的作者考察同一事物的不同方面——或依次、或在作品的不同地方描述它们——时，新教徒往往只选出一样，把它绝对化。
- 例如，使徒们写道，得救既需要信心，也需要行为。“唯独”式思维使人只挑选关于信心的片段，并加上“唯独”一词。
- 使徒们既写圣经，也写圣传的必要。“唯独”式思维使人只挑选关于圣经之重要性的片段，并加上“唯独”一词。
在研究古代作家的文本时，这种思维几乎处处显现。
- 例如，作者们在解释圣餐时给出两种解释（字面的和象征的）；新教徒倾向于只看见象征性的解释，试图把这些作者说成自己“唯独”式教训的拥护者。
按这一原则产生了许多异端。耶稣基督是人这一事实，难道意味着他**只是**人？不，他也是上帝。而如果他是上帝，这是否意味着他**只是**上帝？不，他也是人。如果基督是父的像，这是否意味着他**只是**像（仅是画像）？不，他还是真上帝、真人。多少人在这里跌倒，至今仍在跌倒。这里也是一样：象征性的解释不否定字面的，字面的也不否定象征的。
正教徒承认圣经和圣传、信心和行为的必要，承认圣餐的字面理解，也同时承认其象征的意义——没有任何东西妨碍这一点。许多新教徒到处坚持“唯独”一词，干脆无视同一位作者的其他话语。
# 耶路撒冷会议与圣经
教会不是按“只按圣经”的原则生活的最鲜明证据之一，是使徒们主持的第一次教会会议——耶路撒冷会议的事件。
在耶路撒冷会议上，没有圣经的指示，废除了摩西的律法、割礼、不洁食物的禁令、安息日的安息、接触死人的禁令、与外邦人交往的禁令等等。这一决定是教会聚集一起商议后作出的（[[act 15:22]]）。这作成时没有引用圣经，因为圣经的作者——圣灵——住在教会里；所以会议的决议不是用“因为经上记着”这句话确立，而是指着圣灵和教会的旨意：“因为圣灵和我们定意”（[[act 15:28-29]]）。
这样，废除摩西的律法，是圣灵和教会的决定。另一方面，反对他们的是从法利赛教门信了主的基督徒（[[act 15:5]]）。在后者一边有圣经中一些可理解的经文（[[gen 17:14]]）。在使徒们一边的，恰恰是教会的权威：如经所记，他们与全教会一同商议（[[act 15:22]]），然后宣布了共同的决定。他们没有用圣经，而只是凭自己的话，向那些按圣经要求守律法的人指明了律法的废除。
圣经里说必须受割礼，不割礼的人要从民中剪除（[[gen 17:14]]）。但使徒们并没有吩咐教导这个：
> act 15:24 :: !有几个人从我们这里出去 :: !惑乱你们的心 :: !其实我们并没有吩咐他们
但这可是圣经里说的。根据什么不需要教导这个？根据哪部圣经决定不需要受割礼？哪部圣经允许吃猪肉？——这不是按圣经作的，而是按全教会的、证实真理的会议决定（[[1tim 3:15]]）。
从那时起，耶路撒冷会议的决定成为教会的圣传：
> act 16:4 :: !把耶路撒冷使徒和长老所定的条规交给门徒遵守
---
耶路撒冷使徒会议的主席、使徒雅各，在自己的讲话中回忆先知阿摩司的话。这预言里没有受割礼的话：
> am 9:11-12 :: !我必建立大卫倒塌的帐幕 :: !使以色列人得以东所余剩的和所有称为我名下的国
如果以此为根据接受耶路撒冷会议所作的（某种对圣经的隐含引用和提及圣灵），那么按理也应当接受正教会的所有大公会议，而不只是耶路撒冷会议，因为圣灵被赐给教会，不是只在耶路撒冷会议时，而是永远：
> in 14:16 :: !叫他永远与你们同在
基督自己也应许常与教会同在：
> mf 28:20 :: !我就常与你们同在，直到世界的末了
在所有会议上——包括捍卫圣像敬礼的第七次会议——都有来自圣经的远为更有分量的依据。圣灵仍然在教会里。按这样的论据，所有会议都应当被接受。

## “当求问律法和训诲”（赛 8:20）
为“唯独圣经”辩护的人引用旧约的这段引文：
> is 8:19-20 :: !当求问那些交鬼的和行巫术的 :: !人当以训诲和法度为标准
1. 这里丝毫没有说圣经高于圣传。何况，在巫术与圣经之间当然要选择圣经。这几句话讲的是把摩西五经（妥拉）和预言（先知们的话）与巫士和灵媒的话相比较——民中根本不应当有这样的人（[[vtor 18:9-14]]）。先知以赛亚建议把妥拉和先知的话作为外在的工具，用以责备巫士，向民众指明巫士所说的与上帝所说的之间的区别。
2. 再者，在旧约时代，圣经原则上不可能与圣传分离。没有圣传，不仅不可能正确理解它，甚至不可能正确诵读它，因为它只用辅音字母写成（详见[[ru:евангелисты-обращаются-к-Септуагинте|详见]]）。不知道读音，同一个词可以读得不同。要正确诵读这些话，就必须处于诵读的传统中；而这一传统作为圣传由祖先传给后代。所以一切关于圣经的话都与圣传不可分。
3. 应当提醒对手他们自己的论题——“唯独圣经”坚持“唯独”（Sola）一词，即只有圣经是最高权威。然而在所引的引文里，没有圣经权威的这种独一性，没有“唯独”一词（或类似的话）——而这正是“唯独圣经”拥护者想看见的。如果仅以没有直接提到圣传为理由就把“唯独”加在这里，那就应当一贯地承认：在另一些类似的引文里是在提议“只按圣传”建立信仰，因为那里没有提到圣经：
> 2tim 1:13 :: !你从我听的那纯正话语的规模
> 2tim 2:2 :: !你在许多见证人面前听见我所教训的 :: !也要交托那忠心能教导别人的人
遵行所听见的圣传，不仅使人能分辨正确与错误，还能——无穷得多——使人住在上帝里面：
> 1in 2:24 :: !务要将那从起初所听见的常存在心里 :: !若将从起初所听见的存在心里，你们就必住在子里面，也必住在父里面
甚至主耶稣基督自己也召呼人保守所听见的——当时几乎全部新约圣经都已写成：
> otkr 3:3 :: !所以要回想你是怎样领受、怎样听见的 :: !又要遵守
这是否意味着主和使徒们教导“唯独圣传”？要知道，写下了圣经的他们，在这里甚至没有提到圣经，而是要求遵行圣传。
只拿这些经文，教会的反对者也可以用完全相同的方式发明相反的极端——论题“唯独圣传”。但他们没有领受使徒的圣传——他们在使徒之后十五个多世纪才出现；因为没有维护圣传的目标，他们也不引出关于圣传的这类极端。而教会从使徒们领受了圣传和圣经两者，既不摈弃这一个，也不摈弃那一个，也不摈弃使徒们关于保守口传圣传的诫命，认为圣经和圣传同是真实的。
## “不可越过圣经所写的”（林前 4:6）
> 1kor 4:6 :: !免得你们自高自大 :: !贵重这个，轻看那个
这里说的是某部写下的文本，人应当据此明白：不可彼此自高。这里说的是哪个文本？是同一封书信的前一章，其中讲授了关于对自己看法要低的功课。使徒提议从他们学习不彼此自高、不越过刚写下的内容去推想。
这封书信是因为哥林多团体中产生的分裂而写的。整个第2章使徒贬低自己和亚波罗的意义，高举基督，为要阻止哥林多教会分结成“属保罗的”和“属亚波罗的”（[[1kor 3:4-7]]），阻止教会分成党派。分裂的人不同的不是教训（否则使徒就会说教训），而是彼此的态度。他们按教会教师的名字分派系。仿佛教会中的每个人都应当只与在同一教师门下学习的人相通，而摈弃其他教会教师的学生。为改正这种错误的思维，使徒贬低了那些结成派系的名字的意义——即贬低自己和亚波罗，高举基督。
稍下一点，在总结所说的话时，使徒用别的话讲同一件事，呼召人跟随的已不是写下的，而是他自己：
> 1kor 4:16-17 :: !所以，我求你们效法我 :: !因此我已打发提摩太到你们那里去
这样，引文所说的是：基督徒不应当越过使徒所写下的榜样去推想自己，而应当听从对自己看法要低的呼召，不彼此自高、不分裂。
在这封书信里使徒夸奖哥林多人保守圣传：
> 1kor 11:2 :: !又坚守我所传给你们的
并说哥林多人若持守所传的，就得救：
> 1kor 15:1-2 :: !能以持守我所传给你们的
还有许多关于口传圣传的别的话，前文已提过。举出其中一部分：
> 2tim 1:13 :: !你从我听的那纯正话语的规模
> 2tim 2:2 :: !你在许多见证人面前听见我所教训的 :: !也要交托那忠心能教导别人的人
> 1in 2:24 :: !务要将那从起初所听见的常存在心里 :: !若将从起初所听见的存在心里
## “连使徒和天使若传别的，也不要听？”
从“唯独圣经”的拥护者那里可以听到这样的论据：使徒把自己的书信放在他自己、甚至上帝的天使之上。他们引用这行经文：
> gal 1:8 :: !与我们所传给你们的不同，他就应当被咒诅
使徒这里说的不是自己，而是指那些仿佛以使徒们的名义寄给团体的假书信：
> 2sol 2:2-3 :: !有冒我名的书信 :: !说主的日子现在到了 :: !不要轻易动心 :: !也不要惊慌 :: !并有那大罪人
他也教导不要听那些人的“启示”——他们虚假地宣称自己说天使的语言、仿佛由天使说预言。
怎么确定书信不是来自使徒、启示不是来自天使？其中传达的是另一种信仰——不是使徒们一次所传的。当然，使徒并不试图夺走上帝赐给使徒的权柄。前面的话，以及整封书信，都是针对起来教导人的教师们写的——他们把加拉太人诱向犹太教。
> gal 3:1 :: !无知的加拉太人哪 :: !谁又迷惑了你们呢
> gal 4:11 :: !我为你们害怕
> gal 5:7,12 :: !你们向来跑得好 :: !有谁拦阻你们 :: !恨不得那搅乱你们的人
使徒的意图——是保护自己的羊群脱离假教师，而不是脱离他自己，更不是脱离上帝的天使。圣天使不可能把上帝的教会——他们所事奉的上帝的教会——从真道路上诱离。使徒只是清楚地表明：应当持守那一次由他所传的信仰；而谁不这样教导，哪怕他装作使徒、或装扮成上帝的天使，也不应当接受。

# 结论
为维护“唯独圣经”的论题使用这样的手法：既然没有关于“唯独圣经”的明确引文，就展示关于圣经之重要性的引文，而对关于圣传之重要性的引文忽略并缄默。这样，听众应当觉得仿佛只有圣经才有重要性。
新教徒常责备正教徒说：
——只要在圣经里指出哪里写着要敬礼圣像、向圣人祈祷等等。
我们指出，但对他们说：
——圣传也是重要的，这连圣经也证实。
于是他们说：
——不，只有圣经重要。
这时我们就请他们：
——那就请在圣经里指出：只有圣经重要，或圣经比圣传更重要。
他们无法指出这样的话，因为圣经里没有这样的字句。要求我们出示关于圣像、关于向圣人祈祷的话，他们却拿不出完全相同的一句话来证明一切都应当只在圣经里。他们不能符合自己向别人提出的要求，表现出双重标准。
这东西是他们自己发明的；他们自己要求我们把一切都指给他看，而自己却不能在圣经里指出自己的原则。
这样，“唯独圣经”的论题自相矛盾，并没有使发明它的人达到使徒的信仰；相反，它使人远离目标，而生出了众多的传统和分裂。
