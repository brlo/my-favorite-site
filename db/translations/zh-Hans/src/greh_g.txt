# 基督和使徒对教会有形合一的旨意
> in 17:20-21 :: !我不但为这些人祈求 :: !使他们都合而为一 :: !叫世人可以信你差了我来
> 1kor 1:10-13 :: !劝你们都说一样的话 :: !你们中间也不可分党 :: !只要一心一意 :: !基督是分开的吗
> 1kor 3:4 :: !这岂不是你们和世人一样吗
上帝安排身体（教会）的肢体，使没有分裂，众人却彼此相顾，一同受苦，一同快乐：
> 1kor 12:13-14,21-26 :: !都从一位圣灵受洗，成了一个身体 :: !身子原不是一个肢体，乃是许多肢体 :: !眼不能对手说 :: !但上帝配搭这身子 :: !免得身上分门别类，总要肢体彼此相顾 :: !若一个肢体受苦，所有的肢体就一同受苦
这些不同的肢体是什么？——是教会中不同的职分和恩赐：
> 1kor 12:12,14,27-30 :: !就如身子是一个，却有许多肢体 :: !身子原不是一个肢体，乃是许多肢体 :: !你们就是基督的身子 :: !上帝在教会所设立的：第一是使徒，第二是先知，第三是教师 :: !岂都是使徒吗
这样，上帝安排这一切职分和恩赐，为使身体中没有分裂；使徒在书信开头就防止了这种分裂（[[1kor 1:10-13]]）。也就是说，上帝不但愿意合一（[[in 17:20-21]]），而且眷顾此事。看，使徒被上帝立为仆人，眷顾有形的合一，禁止哥林多人制造有形的分裂。
