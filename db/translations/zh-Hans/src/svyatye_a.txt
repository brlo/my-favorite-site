# 定义
**恩典**（古希腊文 χάρις，希伯来文 חֵ֣ן）——按主要意义，指为拯救人而运行在人身上的上帝的能力。
1. **上帝的能力，上帝的作为**（[[1kor 15:10]]——我今日成了何等人，是蒙上帝的**恩**才成的；并且他的**恩**在我里面不是徒然的；我比众使徒格外劳苦——这不是我，乃是**与我同在的上帝的恩**）；
2. **恩惠、怜悯、馈赠、恩宠、对某人的爱**（[[gen 18:3]]——我若在你眼前蒙**恩**）；（[[gr sud 6:17]]——我若在你眼前蒙**恩**）；（[[1ts 16:22]]——他在我眼中蒙了**恩**）；（[[gr 3ts 11:19]]——哈达在法老面前大蒙**恩惠**）；（[[gr act 2:47]]——**得**众民的**喜爱**）；（[[act 7:46]]——这位在大卫**蒙**上帝**恩**）；（[[gr 1kor 16:3]]——把你们的**捐资**送到耶路撒冷）；
3. **感谢上帝、讨上帝喜悦**（[[2kor 9:15]]——**感谢**上帝，因他有说不尽的恩赐）；（[[1pet 2:19]]——倘若人为叫良心对得住上帝，就忍受冤屈的苦楚，这是**可喜爱的**）；
4. **美丽**（[[pr 5:19]]——**可爱**的母鹿）；（[[gr pr 3:22]]——作你颈项的**美饰**）；
5. **珍贵**（[[pr 17:8]]——**珍宝**石头）；（[[ekl 10:12]]——智慧人的口中说出了**恩言**）；（[[ps 45:2]]——你嘴里满有**恩惠**）；
6. **恩宠、尊荣、荣耀**（[[iudf 8:23]]——奴役不会成为我们的**荣耀**）。

# 前言
圣义者和天使受敬礼，不是作为神，而是作为上帝的朋友。受敬礼的不是他们本身，而是因为他们分有上帝、因为他们里面存有上帝的恩典（见[[ru:человек-храм-Божий|人——上帝的殿]]一文）。按圣经，受敬礼的不只是上帝；叩拜不只是向上帝行；上帝亲自呼召人寻求从上帝来的荣耀；上帝应许荣耀义人，并且荣耀了他们；教会追随上帝，荣耀上帝圣洁的朋友们。
上帝在圣徒生前、也藉着他们**死后肉身**（[[4ts 13:21]]）、**遗物**（[[act 19:12]]）和**像**（[[act 5:15-16]]）赐下自己的恩典，所以这一切也都受敬礼。详见相应条目：
- [[ru:почитание-мощей-святых|敬礼圣髑]]；
- [[ru:иконы-иконопочитание-иконоборчество|敬礼圣像]]。

# 向圣人叩拜
十诫的第二诫（[[ish 20:4-5]]；[[vtor 5:8-9]]）禁止敬拜假神（偶像）。假神实际上不是神：他们的神性是虚构的，是幻想、谎言。
圣人是真实存在的，他们是上帝的朋友；向他们叩拜，不是把他们当神。向圣人叩拜，是表达对他们的敬意——作为上帝的朋友、作为上帝的仆人（天使）、作为上帝之母。这样的向天使、向人、向物件的叩拜在圣经中有，而且不是拜偶像，因为拜偶像——是敬拜**假**神，敬拜谎言。义人们经常向人如向人、向天使如向天使、向先知如向先知、向物件如向物件下拜。在一切情形中，他们都不是把他们当作神来拜。
## 向以天使形像显现的上帝叩拜
显现的是上帝，但那三位天使不是上帝的本相、不是他在创世之前所是的；就是说，这是上帝的**像**（希腊文 εἰκόνα——圣像），而亚伯拉罕拜的是上帝的圣像：
> gen 18:1-2 :: !向亚伯拉罕显现出来 :: !见有三个人在对面站着 :: !俯伏在地

> otkr 19:10 :: !千万不可 :: !你要敬拜上帝
