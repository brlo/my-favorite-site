# 对使徒而言，懂希腊语不足以向一切人宣讲
罗马的军官惊讶使徒竟然连最通用的语言——希腊语——都懂。也就是说，虽然希腊语流传很广（通用语），但这并不意味着人人都懂它。
受过高等教育的使徒保罗，曾受教于全民敬重的教法师迦玛列（[[act 22:3]]）——法利赛人、公会成员（[[act 5:34]]）——引用希腊哲学家和作家（[[act 17:28]]；[[tit 1:12]]），用希腊语向罗马的千夫长讲话。千夫长惊讶使徒保罗懂希腊语：
> act 21:33,37 :: !你懂得希利尼话吗
罗马的军官惊讶一个犹太人懂罗马帝国最通用的语言。只有在这种知识**是罕见的**时候，这才会令人惊讶。如果连希腊语的知识在如此有学问的人身上都令人惊讶，那对其他使徒而言，懂希腊语就更谈不上了——他们许多人是普通的渔夫，是没有学问的小民（[[act 4:13]]）。但问题不在于宣讲者（使徒）必须懂语言才能到处宣讲；听宣讲的人也必须懂希腊语。
所以，只有希腊语的知识是不够的，因此使徒们——作为基督生活、复活和教导的活的见证人——需要超性的恩赐，其中有明白语言恩赐，好把关于基督的见证连同自己的信仰传给万民。

# 今天的宣教士学习语言
在古代，使徒和最早的基督徒因非常的需要领受了明白外国语言的恩赐，好叫还很小的教会能够广泛传播，向万民宣讲。但今天的宣教士不得不学习语言，也就是要劳苦。为此现在一切手段都在，缺的可能只是心愿。
有一些信基督的人的团体（灵恩派和五旬节派）可以宣称自己有说别国话和解释它们的恩赐；但当他们到了别的国家，外国人并不懂他们的话，于是这样的宣教士要么继续说自己的母语，要么不得不借助教科书和教师用普通的方法学习语言。
在我们这个时代，这恩赐几乎没有了。正教会有一位二十世纪的圣人——圣山修士帕伊西——他除了母语（希腊语）之外从未学过别的语言，也从未宣称自己有说别国话的恩赐；但当外国人到他那里去时，他们竟能不用翻译就与他用法语、另一次用英语交谈。

关于哥林多前书第14章有很多问题，所以有意义把整章都分析一遍。这在[[ru:K5Ou_Иные_языки_древних_христиан_и_позднейшие_симуляции|单独的一篇文章]]里作了。
## 方言只是在未来的世代才停止吗？
正教徒向五旬节派和灵恩派指出使徒保罗关于方言必停止的话（[[1kor 13:8]]），即这恩赐将要终止。当然，它不会完全消失，因为正教中极少数的现代圣人确实有过说外国语言的恩赐；但总体上，像最早基督徒那样的大规模现象不会再有了。
对此新教五旬节派回答说，方言只是在未来的世代、基督再来之后才停止。持这种看法的一些人所依据的，是关于“等那完全的来到”之时代的话（[[1kor 13:10]]）。
我们在更宽的语境里看这段经文：
> 1kor 13:8-13 :: !爱是永不止息 :: !先知讲道之能，终必归于无有 :: !说方言之能，终必停止 :: !知识也终必归于无有 :: !我们现在所知道的有限 :: !先知所讲的也有限 :: !等那完全的来到，这有限的必归于无有了 :: !我们如今仿佛对着镜子观看，模糊不清 :: !我如今所知道的有限
使徒说，当“那完全的来到”，那“有限的”就要归于无有。什么是有限的？**知识**。在这句话里他开始解释自己那句复杂的话——“知识也终必归于无有”。他现在要表达的是：不是知识本身要归于无有（仿佛他们那时将一无所知），而是他们现在所拥有的这有限的知识要归于无有，并且将有完全的知识。他继续发展的正是这一思想。
1. 他说，如今知识**有限地**已经有了，而别的知识**有限地**藉着先知讲道显明出来。
2. 时候将到，那时赐下的将是完全的知识，而不是“有限的”。
3. 如今知识是仿佛对着镜子观看，模糊不清地得着的。
他这里说的是知识，而不是说方言的恩赐。基督徒对外国语言的知识不是有限的。否则他们就不能把福音完整地传给别的民族和万民。他们拥有完全的方言恩赐——五旬节来到耶路撒冷的人之所以惊讶，正因为他们听见使徒用自己乡谈说话（[[act 2:5-12]]）。那不是有限的。有限的是知识，而且只是知识。使徒接下去所推理的，正是知识。
那方言的恩赐什么时候停止呢？严格地说，这里没有说。只说了它要停止。而我们生活在他们之后二十个世纪，可以回顾并看到：这些话相当快就应验了——当宣讲大大传开、基督徒变得极多的时候；如今方言的恩赐已没有那样的非常需要。有非常需要的是爱，而方言的恩赐——没有。所以从那时起人们学习语言。
“爱是永不止息”这话并不表明要止息的物在永恒里止息。其余的一切什么时候止息都可以；关于永恒只说了一点：在那里爱不会止息。爱是永恒的、即使在未来的世代也不止息——这是无可争辩的。
教父们是否像五旬节派那样理解这些经文？
例如在四世纪，金口约翰认为，方言恩赐的止息说的是当今的世代，而不是未来的世代。
**圣金口约翰（约347-407）**
“他这样从各方面、以全部力量显明了爱的伟大之后，又从另一极重要的方面作同样的事，用另一个比较高举它的尊贵，说：‘先知讲道之能终必归于无有；说方言之能终必停止’。**如果这两个恩赐是为信仰而赐下的，那么随着信仰在各处的传布，它们的使用已是多余的**。而彼此相爱不会止息，反而无论在这里还是在未来的世代都要更加增长，那时更要胜过如今。在这里有许多事削弱爱——钱财、（世间的事务）、肉身的情欲、灵魂的疾病；而在那里这些都没有。至于先知讲道和方言的止息，并没有什么可奇怪的；而知识的止息却似乎奇怪，所以他正是接着说：‘知识也终必归于无有’。怎样呢？难道我们那时将生活在无知中吗？不，恰恰在那时知识更当增长，正如他说的：‘到那时就全知道，如同主知道我一样’（林前 13:12）。所以，免得你以为它也像先知讲道和方言一样要归于无有，他在说了‘知识也终必归于无有’之后没有停住，而是显明了止息的方式，随即补充说：‘我们现在所知道的有限，先知所讲的也有限；等那完全的来到，这有限的必归于无有了’（林前 13:9-10）。可见，归于无有的不是知识，而是知识的有限，因为我们将知道的不仅是这些，还要多得多的东西。”

## 人的语言和天使的语言
当人们向新教五旬节派指出“别国的话就是别的民族的外国语言”的引文时，他们同意这一点，但作为回应又拿出另一节经文，说仿佛还有一种“天使的语言”的恩赐：
> 1kor 13:1 :: !并天使的话语
但这种看法是错误的，因为天使是无形体的灵。他们没有说话的器官、没有舌头、没有肺、没有声带，也不需要空气（大气）来通过制造和接收空气的振动来交流。这样，由声带发出的任何人的声音都不可能是“天使的语言”，因为天使没有声带，也没有血肉的身体（[[lk 24:39]]）。
那使徒说“天使的语言”是什么意思呢？这不过是修辞的手法：先极度抬高一部分，再用另一部分把它贬低。使徒只是表明：没有爱的恩赐只是鸣的锣。当哥林多人还以为说别国的话已经是什么特别的东西时，使徒决定举得更高：即使能说天使的语言，若没有爱，这也毫无益处。
这只是使徒的修辞手法。关于这一点在圣金口约翰那里也可以读到。
**圣金口约翰（约347-407）**
“论到天使的语言，（使徒）并没有把语言归于天使，而是表达这样的意思：即使我能像天使彼此交谈那样说话，若没有它（爱），我还是无有，甚至是累赘、令人难堪。同样，在另一处他说‘天上、地上和地底下的一切都要屈膝拜他’（腓 2:10），他**并没有把膝盖和骨头归于天使**——绝无此事——而是藉着我们下拜的比喻来表达天使的热心敬拜。这里说语言也是一样：他指的不是肉身的器官，而是以我们熟悉的方式表达他们彼此之间的交谈。”
（[俄文](https://azbyka.ru/otechnik/Ioann_Zlatoust/besedy-na-1-e-poslanie-k-korinfjanam/32)《哥林多前书讲道集》第32篇）
**库鲁斯的真福狄奥多勒（约386-457）**
“所谓天使的语言，他指的不是感官的语言，而是某种属灵的语言，天使们用它歌颂万有的上帝并彼此交谈。以赛亚听见他们歌唱，以西结、但以理、撒迦利亚和弥迦听见他们交谈。神圣的使徒**以夸张的方式表达**这一点，为要显明爱的优越。”
（[俄文](https://azbyka.ru/otechnik/Feodorit_Kirskij/tolkovanie_na_pervoe_poslanie_k_korinfinam/13#sel=9:83,9:128)《哥林多前书注释》第13章）
基督自己也用过类似的修辞手法：极度抬高一部分，好叫另一部分把它贬低：
> mf 16:26; mk 8:36 :: !人若赚得全世界，赔上自己的生命，有什么益处呢
所以，这里讲的不是人有说天使语言的恩赐，因为人用血肉交流，而天使没有血肉。提到天使的语言只是修辞的手法。

# 对异议的回应
## “使徒们去圣殿，是因为他们不明白？”
使徒们在信仰的问题上并非一切都明白。例如，他们以为基督要去做耶路撒冷的王（[[mk 10:37-39]]），而对基督关于受难和复活的话不明白，又不敢问（[[mk 9:31-32]]；[[lk 9:45]]）。
但这一切只是在基督复活之日圣灵的恩赐被赐给他们之前（[[in 20:21-23]]），以及复活后第五十天之前（[[act 2:1-4]]）。此外，复活之后基督开他们的心窍，使他们能明白圣经（[[lk 24:45]]）。基督在复活之前就应许赐使徒无人能驳倒的智慧（[[lk 21:15]]）；使徒后来也讲到，上帝赐给他们各样智慧和知识的恩典（[[ef 1:8]]）。使徒保罗说，他在言语上（表达上）虽然是愚拙的，但在知识上却不是（[[2kor 11:6]]）。
当新教徒想表明自己在信仰问题上比使徒“更有学识”时，他们引用的是圣灵降临在使徒身上之前的种种情形。然而这不成立，因为教会是在这之后建立和设立的，那时使徒们已不再有不明白信仰的情形。
这样，在圣灵被差遣之后，使徒们明白信仰的问题，在知识上并不缺乏。即使有什么不明白的，主也没有消失——他教导使徒们。例如，他藉异象使徒彼得明白，要给百夫长哥尼流施洗——也就是给非犹太人施洗，尽管这在当时教会的一些人里引起了疑惑。
## “应当用心灵和诚实敬拜上帝，而不是在圣殿里？”
如果依着圣经，这里谈的不是圣殿，而是敬拜的地方。
> in 4:19-23 :: !我们的祖宗在这山上礼拜 :: !应当礼拜的地方是在耶路撒冷 :: !时候将到，你们拜父，也不在这山上，也不在耶路撒冷 :: !那真正拜父的，要用心灵和诚实拜他
撒玛利亚妇人用她的问题把基督框起来：在哪里敬拜？
- 在基利心山上；
- 在耶路撒冷圣殿里。
但基督说，时候将到（并且已经到了），那时人们敬拜不在山上，也不在耶路撒冷，而是在心灵和诚实里：
这里谈的并不是圣殿，可以看出。而如果有人认为这里谈的是圣殿，那就请他禁止在山上祈祷，因为基督说的也有山。那样禁止圣殿的人，也要禁止山：住在山上吗？——不要祈祷。当然，这是不合理的。
还要注意，基督说这种敬拜的时候已经到了。然而基督仍然来到耶路撒冷圣殿，称它为父的殿、祈祷的殿，关心在那里祈祷不受任何拦阻。
就是说，虽然用心灵和诚实敬拜的时候已经到了，但这并没有取消圣殿。这座殿被基督撇下成为空的，只是在以色列多数人弃绝自己的救主之后：基督把葡萄园从先前的园户（旧约的司祭职）那里夺去，交给别人——使徒们，并对那些弃绝他的人说，他们的殿要成为荒场，即上帝的恩典离开它：
> mf 23:38 :: !看哪，你们的家成为荒场留给你们
基督在十字架上死后，裂开的石头和撕开的幔子成了这事的标记：
> mf 27:51 :: !殿里的幔子从上到下裂为两半 :: !地也震动，磐石也崩裂
从那时起，基督徒在普天之下任何地方祈祷，随处献上圣餐礼的新祭：在有建筑的地方，也在没有建筑的地方。
## “既然幔子裂开了（[[mf 27:51]]），说明上帝离开了圣殿，那为什么还需要圣殿？”
为了得救，圣殿（石头的建筑）并不需要。正教会的许多圣人在旷野里得救。然而，为了得救必须参与圣奥秘，圣奥秘在事奉圣礼中举行，而按自然的原因举行它们需要建筑。当然，必要时正教会没有建筑也可以。
既然有建筑，教会就把这地方视为奉献给上帝的地方，即圣殿。在这地方人求告上帝的名，在这里圣奥秘中显出上帝的恩典，在这里基督自己在圣餐圣奥秘中亲临。所以正教徒特别敬重这些地方，作为上帝显现的地方，正如上帝亲自要求尊敬他显现的地方（[[ish 3:5]]），其中包括要求敬重圣殿（[[lev 19:30]]；[[lev 26:2]]）。
旧约圣殿被撕开的幔子表明旧约教会的废止：表明耶路撒冷的圣殿作为旧约教会（以色列）与上帝相会的地方已被上帝撇下。葡萄园从旧约教会被夺去（[[mf 21:43]]），赐给了基督所建立、改变了约和司祭职的新约教会（[[evr 7:12]]）。
新约教会不使用被撇下的旧约教会的圣殿，不在那里行事奉圣礼，也不期待上帝在那里向她显现。
## “圣殿只有一个，而且已被毁，所以不能建圣殿？”
圣殿被毁不是第一次。那已经是第二座圣殿。而在此之前有可移动的圣殿——会幕，以色列人抬着它在西奈旷野中迁徙。当第一次圣殿被尼布甲尼撒毁掉时，这是否意味着上帝拒绝了在圣殿中敬拜的可能？如果没有，那为什么后来罗马人再次毁掉它时就应该这样？
弃绝基督的犹太人以为，祈祷和敬拜上帝只能在耶路撒冷圣殿里。他们把首位殉道者、六品执事司提反召到公会受审，指控他教导说这地方要被毁灭、规矩要改变（[[act 6:13-14]]）。六品执事的辩护词在于，详细列举圣祖的历史，表明他们在哪里都祈祷、向上帝献祭：他们无论在哪里，上帝都与他们同在（[[act 7:2-53]]）。
最后他指出，这座圣殿是所罗门按圣祖大卫的意愿和祈祷建造的，尽管上帝清楚地表明，他不需要为他建造殿宇：
> act 7:46-49 :: !所罗门为上帝造成殿宇 :: !其实，至高者并不住人手所造的 :: !天是我的座位，地是我的脚凳 :: !你们要为我造何等的殿宇
这样，在旧约订立之前，义人就在各处祈祷、向上帝献祭。后来，上帝为以色列设立了集中的敬拜形式：一座圣殿、一位大祭司，因为他们在地理上总是彼此相近。这种敬拜形式应当保证上帝所愿意的合一。
但当主按预言（[[is 66:18-21]]）召万民进入教会时，他也创造了在万民中、在各处举行事奉圣礼的条件。他自己成为大祭司（作为上帝无所不在），差遣恩典，并把权柄赐给许多人——使徒们（[[mf 18:18]]），而不是只给一个人，不把圣餐的祭绑在任何地方（[[lk 22:19]]），差遣使徒往普天下去（[[mk 16:15]]）。
基督徒的事奉圣礼正是围绕圣餐而建立的。为此圣殿并不需要。那些说我们正教徒行事奉圣礼必须有圣殿的人，只是编造我们并不教导的东西。必要时，事奉圣礼在任何地方举行：在医院、在军队、在监狱、在乘船、飞机、火车的旅途中、在森林里。
我们不教导说，为了得救需要圣殿（石头的建筑）。正教会的许多圣人在旷野里得救。然而，为了得救必须参与圣奥秘，圣奥秘在事奉圣礼中举行，而按自然的原因举行它们需要建筑。必要时，正教会没有建筑也可以。
既然有建筑，教会就把这地方视为奉献给上帝的地方，即圣殿。在这地方人求告上帝的名，在这里圣奥秘中显出上帝的恩典，在这里基督自己在圣餐圣奥秘中亲临。所以正教徒特别敬重这些地方，作为上帝显现的地方：
> ish 3:5 :: !你所站之地是圣地
上帝也要求敬重他的圣殿（[[lev 19:30]]；[[lev 26:2]]）。
基督的新约教会不教导说，敬拜只能在耶路撒冷，只能在撒玛利亚山上，甚至只能在圣殿里。随处都可以敬拜上帝、向他祈祷。
---
正教徒建造圣殿，不是为了进入旧约或遵守摩西的律法。旧约已经结束，摩西的律法已被废除。
我们建造共同聚会的场所，在其中祈祷并献上祭物。这样的场所从来没有人禁止建造。
旧约的圣殿作为观念是重要的。上帝指示按天上实体的样式建造它。就是说，按上帝的构想，圣殿应当是天的像。
圣经的一切必要佐证详见[[ru:храм-образ-небесной-реальности|圣殿——天上实体的象征]]。
在旧约的时代，上帝是看不见的，而在天上的只有天使。
在新约里，基督上帝在天上有形地登基，而在天上除了天使，还有人。因此，当基督徒有了聚会的场所时，他们就按上帝先前同样的构想安排它们——使圣殿描绘天。
既然天改变了，圣殿也改变了。如今在圣殿里描绘的是成了肉身的上帝，而除了天使，还描绘天的其他居民——义的众人。
上帝从不建造空洞无意义的场所，尽管新教徒常常这样要求。他安排世界本身，使我们观看世界时能认识它的造物主。就是说，世界向我们宣讲。而圣殿的安排，为的是宣讲基督和他的天国，而不是空洞的白墙。
## 奉献给圣像的圣殿
正教圣殿只以上帝的名建造。在里面只向上帝行事奉圣礼。百分之九十五的祈祷是向上帝献上的，其余的——向他的圣人：天使和天上的义人。
每一座圣殿都有固定的神圣纪念。例如，有奉献给基督显圣容或基督升天的圣殿。这并不意味着在那里向显圣容和升天的事件祈祷。也有这样的圣殿，纪念某幅圣像（以奇妙的方式）被赐予，或纪念藉圣像使城市脱离敌人。这是神圣的纪念。当圣殿以神圣纪念之名被称呼时，这不意味着向神圣纪念祈祷。所有圣殿里的事奉圣礼都是一样的。

# 定义
**规程**（希腊文 τάξις）——某种重复性行为的既定次序。任何有秩序的东西都可以称为规程。
**礼规**——某一事奉圣礼之内容的逐项详细陈述。
圣奥秘的举行也按既定的规程进行，或者照另一说法——按礼规。
# 在教会里凡事都要按规程

> 2sol 3:6 :: !凡有弟兄不按规矩而行
> 2sol 3:11 :: !有人不按规矩而行，什么工都不作
