# 对异议的回应
## “历史教会堕落了”
那些与教会分离的社团的创立者们，把自己运动的生存模式建立在这样一个论断上：历史上基督的教会背弃了上帝而堕落，所以才需要他们那个分离的社团。可是，如果不证明教会已经堕落，那他们的分离社团就没有必要，人应该加入历史上基督的教会。
为了证明教会堕落的观念，常引用类似下面关于豺狼的经文：
> act 20:29-30 :: !我知道我去之后 :: !必有兇暴的豺狼进入你们中间，不爱惜羊群 :: !也必有人起来，说悖谬的话 :: !要引诱门徒跟从他们
然而必须承认，这些经文只是预言会出现假教师，想把人从教会里引到自己那边去，而**不是**预言教会堕落。
在此之上，使徒劝勉长老们谨慎看顾自己和羊群：
> act 20:17,28 :: 保罗从米利都打发人往以弗所去 :: !请教会的长老来 :: !圣灵立你们作全群的监督 :: !你们就当为自己谨慎，也为全群谨慎 :: !牧养上帝的教会
使徒为什么劝勉牧养羊群？他随即给出回答：因为将出现假教师，他们要像豺狼一样想把教会的羊群掳去（[[act 20:29-30]]）。但圣灵所立的长老们不应容许这事发生。
长老们能护住教会的羊群吗？能。因为圣经没有教会堕落的预言，倒有教会不可战胜的预言：
> mf 16:18 :: 阴间的权柄 :: !不能胜过他
> ef 3:21 :: !在教会中 :: 直到世世代代 :: !永永远远
> mf 28:20 :: !我就常与你们同在 :: !直到世界的末了
> in 14:16 :: !永远与你们同在
## “教会就是两三个人奉主名聚集祈祷”
基督已经建立了自己的教会之后，后来那些基督教社团的创立者首先要做的，是向人解释他们这个与基督的教会分离的新社团的出现。这样的社团由普通人不久前发起，与古代基督徒没有直接的历史联系，因此总要证明自己以某种方式属于2000年前基督所建立的教会。为此常引用圣经中关于共同祈祷之重要性的经文。他们提出：既然基督在两三个祈祷的人中间，那这些祈祷的人自己就已经是教会了：
> mf 18:19-20 :: !有两三个人奉我的名聚会，那里就有我在他们中间
然而这些经文字面上说的只是共同祈祷的能力，而不是教会。这里没有教会一词。而在几节之前，却有教会的话：
> mf 18:15-17 :: 倘若你的弟兄得罪你 :: !你就去趁着只有他和你在一处的时候 :: !另外带一两个人同去 :: !告诉教会 :: !若是不听教会
这里聚集的人是：
- 我；
- 得罪的弟兄；
- 另外一位或两位见证人。
一共是1+1+2=4。或者至少3人。
这聚在一起的三个人仍不是教会，可以看出来：因为他们要寻求审判，不是找他们自己，而是找教会。这样，教会不是两三个为祈祷而聚集的人，而是某种持续存在的、看得见的实体，可以向它寻求审判，可以听见它的回答，并且遵行或不遵行。不听教会回答的人，在教会的肢体面前就成为“像外邦人和税吏一样”。
那么谁能审判呢？使徒和他们的继任者主教（[[mf 18:18]]）。例如主教提摩太：
> 1tim 5:19-20 :: !控告长老的呈子，非有两三个见证就不要收 :: 犯罪的人，当在众人面前责备他
所以，说两三个祈祷的人就是教会的解释是不成立的——他们没有审判别人的权柄。那个与教会分离的社团的创立者自己，不听教会，就在教会面前成为“像外邦人和税吏一样”（[[mf 18:17]]）。他在自己的社团里要审判谁呢？他自己从来没有领受过的权柄，他怎么能给出呢？答案显而易见。

# 对异议的回应
## “你们这样说是因为骄傲：「只有我们得救，别人不得救」”
上帝曾藉先知摩西建立了旧约的教会，并在其中设立了上帝所喜悦的规矩。后来，旁边兴起了撒玛利亚民族，它由许多被迁移来的民族组成：这些人根据先知摩西的五卷书（妥拉），不接受当时的作者们（先知们）的书卷，自己建立了一个有自己规矩的、独立的宗教团体，按自己的方式信上帝，并等候基督。基督回答撒玛利亚妇人说：
> in 4:22 :: !你们所拜的，你们不知道 :: !救恩是从犹太人出来的
基督这样说，是因为骄傲，还是因为：在擅自建立的团体里、在按书本擅自想出来的信仰里，人确实不能得救？
当使徒说，顺着情欲行事的人——其中有异端和分裂教会之事——不能承受上帝的国，他这样说是因为骄傲，还是因为：带着这样的罪，人确实不能承受上帝的国？
> gal 5:19-21 :: 情欲的事都是显而易见的 :: !结党、纷争 :: !异端 :: !行这样事的人必不能承受上帝的国 ~~ *“结党、纷争”（διχοστασίαι）——分裂、分派。
新教徒在这里看到骄傲，是因为他们凭空虚构了“只要认基督为个人的救主就已经得救”的教义，即现在立刻得救、单凭信心得救。正教徒不持守这种教义，因此对得救有着完全不同的理解（详见[[ru:спасение#HH-Условия-спасения|得救的条件]]）。
来到[[ru:Православная-Церковь|正教会]]，我们还不是得救了，而是正在得救。来到教会的人不是都能得救，只有那些利用救恩的途径、勤恳地对付自己、根除罪的私欲、培养福音品德的人才能得救。身在正教会，只是得救的条件之一。凡寻求救恩的人都需要救恩的途径：病人需要药物，在大海中央溺水的人需要船。同样，凡被罪的私欲所缠累的人，要渡过今世的海，不在罪的深渊里沉没，并与上帝同活，就需要**救恩的途径：正确的信仰和有恩典的圣奥秘**。这些救恩的途径，上帝把它们放在他救恩的方舟——[[ru:Православная-Церковь|正教会]]——里面；而这方舟是主耶稣基督上帝亲自在2000年前来建立的。
近来由普通人擅自建立的团体，直接违背上帝关于信徒合一的旨意，不但没有救恩的途径，反而以其分离的存在本身，把人带进严重的罪的状态——异端和分裂教会这些致死的罪（[[gal 5:19-21]]）。
建立自己的“教会”、分裂信徒，直接违背基督和使徒关于信徒合一的旨意——这一切正是骄傲的表现：
> in 17:20-21 :: !祈求 :: !使他们都合而为一 :: !叫世人可以信你差了我来
> 1kor 1:10 :: !劝你们 :: !都说一样的话 :: !不可分党 :: !一心一意 :: !彼此相合
与基督为敌、建立自己的“教会”，当然不能得救。使徒说，顺着情欲行事、陷入异端和分裂的人，不能承受天国：
> gal 5:19-21 :: 情欲的事都是显而易见的 :: !结党、纷争 :: !异端 :: !行这样事的人必不能承受上帝的国 ~~ *“结党、纷争”（διχοστασίαι）——分裂、分派。
使徒直说，制造分裂的人不是服事主耶稣基督：
> rim 16:17-18 :: !离间你们、叫你们跌倒 :: !不服事我们的主基督
跟随与基督为敌的人走，怎么能得救呢？
此外，异端和分裂教会并不是仅有的罪，还有许多别的[[ru:смертный-грех|致死的罪]]。警告酒鬼说，他处在酗酒这个致死的罪里，按圣经所说不能承受上帝的国（[[1kor 6:9]]），这是骄傲的行为吗？或者对杀人犯、贼、行邪术的、淫乱的人说同样的话，也是骄傲吗？如果这不是骄傲，而且我们应当警告这些致死的罪（[[ef 5:11]]），那么老实说，也应当警告异端者和分裂教会者，因为异端和分裂与酗酒、杀人等等在同一条致死之罪的名单上——处在其中的人不能承受上帝的国。
那人怎样脱离这种罪的状态呢？离开那个由普通人近来建立的团体，放弃那个由同一个人近来想出来的信仰。然后进入主耶稣基督所建立的[[ru:Православная-Церковь|正教会]]，领受正教的信仰——基督把这信仰教导了使徒们，使徒们把它放进正教会里，圣灵把它永远保存在基督的教会里，因为圣灵被永远地差给了教会：
> in 14:16 :: !永远与你们同在
> mf 28:20 :: !我就常与你们同在 :: !直到世界的末了
