# 使徒们和最早的基督徒不按摩西律法生活

## 执事司提反被指控教导律法的改变
> act 6:13-14 :: !这个人说话不住的蹧践圣所和律法 :: !也要改变摩西所交给我们的规条
## 使徒保罗被指控教导人不按律法敬拜上帝
> act 18:13 :: !这个人，劝人不按着律法敬拜上帝
> act 21:20-21 :: !都为律法热心 :: !你教训一切在外邦的犹太人离弃摩西 :: !不要给孩子行割礼 :: !也不要遵行条规
如果使徒保罗在传犹太教，那犹太人为什么还要逼迫他呢？他们逼迫他，是因为他离弃了律法：
> gal 5:1,11 :: !所以要站立得稳，不要再被奴仆的轭挟制 :: !我若仍旧传割礼，为什么还受逼迫呢
一些基督徒在犹太人面前假装守律法，为的是不受逼迫：
> gal 6:12 :: !凡希图外貌体面的人，都勉强你们受割礼，无非是怕自己为基督的十字架受逼迫
## 基督徒不受割礼
> 1kor 7:18-19 :: !有人未受割礼蒙召呢，就不要受割礼 :: !受割礼算不得什么，不受割礼也算不得什么
> gal 5:6 :: !受割礼不受割礼全无功效
> gal 6:15 :: !受割礼不受割礼都无关紧要
> kol 3:11 :: !受割礼的、未受割礼的
## 不献牲畜为祭
> evr 10:8-9,16-18 :: !祭物和礼物，燔祭和赎罪祭，是你不愿意的 :: !可见他是除去在先的，为要立定在后的 :: !我要将我的律法写在他们心上 :: !我不再记念他们的罪愆和他们的过犯 :: !这些罪过既已赦免，就不用再为罪献祭了
## 不守安息日
> kol 2:16 :: !所以不拘在饮食上，或节期、月朔、安息日，都不可让人论断你们
> mf 12:1-2,7 :: !耶稣在安息日从麦地经过 :: !他的门徒饿了，就掐起麦穗来吃 :: !就不将无罪的当作有罪的了
## 与外邦人来往，自己成为外邦人
> act 10:27-28 :: !犹太人和别国的人亲近来往，本是不合例的 :: !但上帝已经指示我，无论什么人都不可看作俗而不洁净的
## 接触死人
主耶稣基督接触了睚鲁死去的女儿：
> mk 5:41 :: !就拉着孩子的手，对她说
按律法，基督死在十字架上之后，不能像接触已死之人那样接触他。只有上帝之母作为亲属可以这样作（[[lev 21:1-4]]）。然而，我们不但不定神学家约翰、尼哥底母、亚利马太人约瑟的罪，反而称赞他们毫无畏惧、服事我们的救主。
> mf 27:59-60 :: !约瑟取了身体，用干净细麻布裹好 :: !安放在自己的新坟墓里
> mk 6:29 :: !约翰的门徒听见了，就来把他的尸首领去，葬在坟墓里
> mk 15:45-46 :: !就把耶稣的尸首赐给约瑟 :: !安放在磐石中凿出来的坟墓里
> act 13:29 :: !就把他从木头上取下来，放在坟墓里
## 主释放了被控奸淫的妇人
律法命令用石头打死犯奸淫的（[[lev 20:10]]），但主没有定那妇人的罪，而是释放了她：
> in 8:11 :: !我也不定你的罪，去吧！从此不要再犯罪了
## 主命令喝他的血
上帝禁止喝血（[[gen 9:4]]；[[lev 3:17]]；[[lev 7:26]]；[[lev 17:14]]；[[vtor 12:16]]），但在最后的晚餐上，把杯递给门徒说：你们都喝这个，这是我的血：
> mf 26:26-28 :: !你们拿着吃，这是我的身体 :: !你们都喝这个 :: !因为这是我立约的血，为多人流出来，使罪得赦
## 主成了出自犹大支派的大祭司
律法命令祭司只能出自利未支派、亚伦的家族：
> ish 29:9 :: !他们就凭永远的定例得了祭司的职任
> ish 29:29 :: !亚伦的圣衣要留给他的子孙 :: !又穿着承接圣职
但主成了大祭司，生在犹大支派：
> evr 7:14 :: !我们的主分明是从犹大出来的 :: !但这支派，摩西并没有提到祭司
## 真正的逾越节祭牲不是在圣殿里献的
逾越节的祭牲只能在耶路撒冷圣殿里献：
> vtor 16:5-6 :: !在耶和华你上帝所赐的各城中，你不可献逾越节的祭 :: !只当在耶和华你上帝所选择要立为他名的居所
> evr 13:12 :: !所以耶稣要用自己的血叫百姓成圣，也就在城门外受苦
# 十诫也是摩西律法吗？
## 上帝藉摩西所赐的律法——利未记中的一切诫命
利未记中列举了上帝的众多诫命，包括[[ru:10-заповедей|石版上的诫命]]，称它们为**上帝藉摩西所立的律例**：
> lev 26:46 :: !这些律例、典章和法度，是耶和华与以色列人在西乃山借着摩西立的
## 上帝称他的一切诫命为律法
例如，收集吗哪的命令就是上帝的律法：
> ish 16:4,28 :: !我好试验他们遵不遵我的法度 :: !你们不肯守我的诫命和律法要到几时呢
出埃及记第16、24、31、34、35章；申命记第4、6、10章。
## 新的律法已不再写在石版上，而是写在心里
写在石版上的，被称为「律法」：
> ier 31:33 :: !我要将我的律法放在他们里面，写在他们心上
> 2kor 3:3 :: !不是写在石版上，乃是写在心版上
## 基督讲论诫命，并不特别突出十诫
> mf 5:21,27,33,38,43 :: !不可杀人 :: !不可奸淫 :: !不可背誓 :: !以眼还眼，以牙还牙 :: !当爱你的邻舍 ~~ 出 21:24；利 19:18。
## 使徒们把十诫直接称为律法
使徒雅各说，违犯「不可杀人」诫命的人，就是犯律法的：
> iak 2:10-11 :: !只在一条上跌倒，他就是犯了众条 :: !你就是不奸淫，却杀人，仍是成了犯律法的

# 基督终结了律法的时代
## 关于有一位像摩西的先知来临的预言
设立摩西律法时，立刻就说到将来要来一位像摩西的先知，即**立法者**，人应当听他。这是指着基督说的：
> vtor 18:15 :: !耶和华你的上帝要从你们弟兄中间给你兴起一位先知像我 :: !你们要听从他
> act 3:22 :: !主上帝要从你们弟兄中间给你们兴起一位先知像我 :: !凡他向你们所说的，你们都要听从
> act 7:37 :: !上帝要从你们弟兄中间给你们兴起一位先知像我
而上帝亲自以同样的话确认了这一点：
> mk 9:7 :: !这是我的爱子，你们要听他 ~~ 并见 [[mf 17:5]]；[[lk 9:35]]。
## 基督称律法为「你们的」
> in 8:17 :: !你们的律法上也记着说
> in 10:34 :: !你们的律法上岂不是写着
## 律法——直到施洗约翰
> mf 11:12-13 :: !因为众先知和律法说预言，到约翰为止
## 律法赐下，为一段时期，直到来临之时
> gal 3:19 :: !原是为过犯添上的 :: !等候那蒙应许的子孙来到
