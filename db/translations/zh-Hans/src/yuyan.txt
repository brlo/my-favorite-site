## 他将施行死人的普遍复活
所有曾经活过的人——义人和不义的人——的普遍复活：
> act 24:15 :: !无论善恶，都要复活
复活将在改变后的不朽身体中发生，义人要发光如同太阳：

在第二次降临之前死去的人，其灵魂停留在等候复活的居所。义人的灵魂与基督在天上一同喜乐（[[evr 12:22-23]]；[[otkr 6:9-11]]），而罪人的灵魂则在另一处受苦（[[lk 16:23]]）。

# 第二次降临的重要细节
## 降临——如同闪电
基督的第二次降临将立刻被全世界的人知道，如同闪过的闪电：
> lk 17:23-24 :: !你们不要出去，也不要跟随他们 :: !好像闪电从天这边一闪直照到天那边 :: !人子在他降临的日子
> mf 24:26-27 :: !你们不要出去 :: !你们不要信 :: !闪电从东边发出，直照到西边；人子降临，也要这样
## 基督将以他已有的成人身体来临
基督不会再次由人所生，而是带着他已有的身体来临——那身体是他在公元一世纪由童贞女马利亚上帝之母所生时获得的：
> act 1:9-11 :: !他就被取上升，有一朵云彩把他接去 :: !这离开你们被接升天的耶稣，你们见他怎样往天上去，他还要怎样来

主来不是为了教导，而是按他第一次来时所已经赐下的话语施行审判：

# 关于「一千年」的说法
## 一千年——是从基督第一次降临到第二次降临这一时期的象征性名称
第一次降临已经发生过。上帝之子降生成人，并未停止他所是的（上帝），而又成为了人。他教导人，受难，复活，升天，建立了教会（唯一的：地上的和天上的），并差人去传道。那些回应基督传道、进入他的教会、达到救恩并与他在天上同活的人，经上说是与他一同掌王的，虽然他们的身体还死在土里，而[[ru:жизнь-души-после-смерти-тела|他们的灵魂与基督同在]]。这样将持续到主耶稣基督的第二次降临；那时候除了上帝没有人知道（[[act 1:7]]）。从第一次降临到第二次降临的整个时期，被形象地称为一千年：
> otkr 20:1-6 :: !他捉住那龙，就是古蛇，又叫魔鬼，也叫撒但，把牠捆绑一千年 :: !等到那一千年完了 :: !与基督一同作王一千年 :: !其余的死人还没有复活，直等那一千年完了 :: !这是头一次的复活 :: !在头一次复活有分的有福了、圣洁了 :: !第二次的死在他们身上没有权柄 :: !并要与基督一同作王一千年
## 论千禧年主义（千禧年说）的异端
千禧年主义（千禧年说）——是关于基督在地上掌王一千年（1000年）的学说。东正教基督徒不能接受它，因为：
1. 无法承认**两次身体的复活**（主只教导一次身体的复活）；
1. 无法承认**两个最后审判**（主同样只教导一次审判）；
1. 无法承认在最后审判之前，为在地上统治世界而有**基督特殊的降临**；
1. 无法承认在这个世界里已经有**某种特殊的基督千年王国**，不同于天国。
详情：[[ru:хилиазм|千禧年主义]]。
# 论两次死亡与两次复活
在神学家约翰使徒的启示录一书中提到（[[otkr 20:1-6]]）两次死亡和两次复活。
第一次死——在地上肉身的死亡[1]。
第二次死——在普遍最后审判时来自上帝的永恒定罪与刑罚。
第一次复活——属灵的：归向上帝、信仰、悔改、洗礼、改正生活。
第二次复活——身体的，在主耶稣基督第二次降临时发生。
## 第一次复活——经由传道和洗礼归向上帝
主捆绑了撒但。异教的膜拜开始被基督教战胜并消失。人们获得了经由洗礼、圣餐礼和在教会中的生活而在属灵上复活、进入与上帝同在的永生的可能。这一进入永生的属灵复活，在经文中被称为头一次的复活：
> otkr 20:5-6 :: !这是头一次的复活 :: !在头一次复活有分的有福了、圣洁了 :: !第二次的死在他们身上没有权柄
归向上帝被称为从死亡进入生命：
> ef 2:5-6 :: !当我们死在过犯中的时候，便叫我们与基督一同活过来 :: !又叫我们与基督耶稣一同复活，一同坐在天上
信的人已经出死入生：
> in 5:24 :: !那听我话又信差我来者的，就有永生 :: !是已经出死入生了
而不信的人则被直接称为死人：
> lk 9:60 :: !任凭死人埋葬他们的死人
## 第二次复活——所有的人带着身体复活，为受普遍的审判
第二次复活涉及所有的人。它指一切曾经活过的人为受普遍审判而复活。所有的灵魂都回到他们复原的身体中，好叫一切趋向上帝的（灵魂与身体）得赏赐，而一切犯罪的（灵魂与身体）受刑罚。
> act 24:15 :: !无论善恶，都要复活
## 关于「两次复活」的详情
> otkr 20:1-6 :: !他捉住那龙，就是古蛇，又叫魔鬼，也叫撒但，把牠捆绑一千年 :: !等到那一千年完了 :: !与基督一同作王一千年 :: !其余的死人还没有复活，直等那一千年完了 :: !这是头一次的复活 :: !在头一次复活有分的有福了、圣洁了 :: !第二次的死在他们身上没有权柄
对这经文的注释：
> otkr 20:5 :: !其余的死人还没有复活，直等那一千年完了 :: !这是头一次的复活
上帝给所有人规定了时间，使他们可以在头一次复活的时期内复活，并且为此赐下了一切。然而，当死人应当复活的时候——即在整个一千年之内（在为这一目的所规定的、那一千年未完结之前）——有人复活了，有人却没有复活。关于「直到……完了」一词的详情：[[ru:Богородица#HH-И-не-знал-Ее-как-наконец-она-родила-Мф-125|详见]]。
头一部分的人在活于身体中时复活了，也就是归向了基督：
> otkr 20:6 :: !在头一次复活有分的有福了、圣洁了 :: !第二次的死在他们身上没有权柄
在他们身上，**第二次的死**将没有权柄。
而所有的人带着身体复活、为受普遍的审判的复活是这样的：
> otkr 20:13-15 :: !死亡和阴间也交出其中的死人 :: !他们都照各人所行的受审判 :: !这火湖就是第二次的死 :: !若有人名字没记在生命册上，他就被扔在火湖里
被扔进火湖——这就是**第二次的死**。名字记在生命册上的人，没有被扔进去。也就是说，正是那些在20:6中说到的人——在他们身上第二次的死没有权柄。
