# 可以向耶稣基督祷告吗？
当然可以。但这诫命我们不是从圣经，而是从圣传领受的。
# 只凭圣经能否断言应当向耶稣基督祷告？
圣经中没有向耶稣基督祷告的诫命。不过，[[gr in 14:14]]有一些迹象（参见希腊文文本）。
耶稣基督曾向父祷告（[[mk 14:36]]；[[lk 22:42]]），赐下了“我们在天上的父”的祷告（[[mf 6:9]]；[[lk 11:2]]），也就是说，他教导人向父祷告。
主张只靠圣经（当然是按他们对圣经的理解）建立信仰的人，不敢否认向耶稣基督的祷告。因此他们说：向耶稣基督祷告的实践既然存在，就是可以向他祷告。然而，他们常常连这种实践都难以指出，因为它十分罕见——当然，它是有的。例如：
> act 7:59 :: 呼吁 :: 求主耶稣 ~~ 希腊文 ἐπικαλούμενον（呼吁、祈求）
# 反对意见
## “奉我的名求”
新教徒反对说，诫命就在这节经文里：
> in 14:14 :: 奉我的名
然而，只要引用上下文就能看到，主耶稣基督在这里教导的也是向父求：
> in 14:13-14 :: !叫父因儿子得荣耀 ~~ 和合本此处无“向父求”的字样
