# 旧约中接触死人的禁令
接触死人使人不洁（受玷污）。但亲属可以接触自己死去的亲人而不受玷污：
> lev 21:1-4 :: !祭司不可为民中的死人沾染自己 :: !除非为他骨肉之亲的父母、儿女、弟兄 :: !和未曾出嫁作处女的姊妹，才可以沾染自己 :: !就不可从俗沾染自己
> chis 9:6 :: !有几个人因死尸而不洁净，不能在那日守逾越节
> chis 19:13 :: !凡摸了人死尸、不洁净自己的 :: !他就为不洁净，污秽还在他身上
> iez 44:25 :: !他们不可挨近死尸沾染自己 :: !只可为父亲、母亲、儿子、女儿、弟兄和未嫁人的姐妹沾染自己
> ag 2:13 :: !若有人因摸死尸染了污秽 :: !必算污秽
# 接触义人的遗骸
旧约时代，有人因接触先知以利沙的圣髑而复活：
> 4ts 13:21 :: !一碰着以利沙的骸骨，死人就复活站起来了

# 新约中接触死人
主耶稣基督接触了睚鲁死去的女儿：
> mk 5:41 :: !就拉着孩子的手，对她说
按律法，基督死在十字架上之后，不能像接触已死之人那样接触他。只有上帝之母作为亲属可以这样作（[[lev 21:1-4]]）。然而，我们不但不定神学家约翰、尼哥底母、亚利马太人约瑟的罪，反而称赞他们毫无畏惧、服事我们的救主：
> mf 27:59-60 :: !约瑟取了身体，用干净细麻布裹好 :: !安放在自己的新坟墓里
> mk 6:29 :: !约翰的门徒听见了，就来把他的尸首领去，葬在坟墓里
> mk 15:45-46 :: !就把耶稣的尸首赐给约瑟 :: !约瑟买了细麻布，把耶稣取下来 :: !安放在磐石中凿出来的坟墓里
> act 13:29 :: !就把他从木头上取下来，放在坟墓里
