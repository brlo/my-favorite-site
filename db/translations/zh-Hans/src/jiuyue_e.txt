律法主要描述女性特有的生活情境，以及两性关系中的种种情境。其中可以分出如下几个领域：
- 生育（[[lev 12:]]）
- 血漏（[[lev 15:19-30]]、[[lev 18:19]]、[[lev 20:18]]）
- 赤露（[[lev 18:]]）
- 与男人的关系、择夫（[[lev 19:20]]、[[lev 21:7-14]]、[[chis 5:12-31]]、[[chis 36:]]）
- 许愿（[[lev 27:3-8]]、[[chis 6:]]、[[chis 30:4-17]]）
- 犯罪堕落（[[lev 19:20]]、[[lev 20:10-21]]）
下面按上述次序分别讨论这些领域。
# 生育
妇女生产之后，律法规定了洁净的日子，并且按所生婴儿的性别而不同。生男婴后，妇人要不洁七天，并有33天的洁净期，在此期间她不可摸任何圣物，也不可进圣所（[[lev 12:2-4]]）。若是生女婴，这些日子相应地加倍（[[lev 12:5]]）。
# 血漏
首先应当提到，律法说人身上有任何流出，就使他成为不洁的：
> lev 15:2 :: !人若身患漏症，他因这漏症就不洁净了
尽管如此，关于妇女，出于可以理解的原因，另有单独且相当详尽的记述。
大体上，妇人患血漏的日子就为不洁，此后还有7天的洁净期。若她一直患血漏，就一直不洁。不洁的妇人不能与丈夫同房；否则丈夫也将与妻子同样不洁，加在妻子身上的条例同样加在丈夫身上。患血漏的妇人所坐所触之物都成为不洁，凡接触这些的，必不洁到晚上。洁净的日子之后，要献上两只斑鸠或两只雏鸽为祭（[[lev 15:29-30]]），此后妇人才算为洁净。
还有其他与妇女和血漏有关的律法规定，将在下面各节中论及。
# 赤露
> lev 18:6 :: !你们都不可露骨肉之亲的下体
虽然这一章也提到男人（父亲）的赤露，但按情理，主要列举的是对各种亲属关系——不仅是骨肉之亲——的妇女露体的禁令：
> lev 18:15 :: !不可露你儿妇的下体 :: !她是你儿子的妻，不可露她的下体
回到前面提到的血漏律法，再看这条丈夫对妻子的禁令：
> lev 18:19 :: !女人行经不洁净的时候，不可露她的下体，与她亲近
# 与男人的关系、择夫
若男人引诱已许配别人的婢女，他不像引诱自由人（即非婢女）那样要被处死（[[vtor 22:25]]），而只须献赎愆祭——公绵羊（[[lev 19:20-21]]）。
夫妻同房之后到晚上都算不洁（[[lev 15:18]]）。
只有童女可以作祭司的妻子（[[lev 21:13]]），不可娶寡妇、被休的、被玷污的或妓女。
若妇女因没有男嗣而承受地业，她只能嫁给自己父亲支派中的人（[[chis 36:8]]），免得产业从一个支派转到另一个支派。
甚至有一条规定，描述丈夫怀疑妻子犯奸淫时所应行的程序（[[chis 5:12-31]]）。
# 许愿（向上帝所许的愿）
有人向上帝许特别的愿，其中一些被称为拿细耳人（不要混淆：耶稣基督被称为拿撒勒人，因为他来自拿撒勒）；他们许愿不喝任何葡萄制品，不剃头发，不挨近死尸。这样的愿可以为一段时期而许，也可以许终身。提到这一点，只是为了强调一个事实：拿细耳人既有男人，也有妇女。
律法允许赎回卖出的东西（[[lev 25:25]]）；类似地，对经在圣所事奉而将自己献给上帝的人，也规定了赎价。这里可以注意：男人和女人的生命估价不同。例如，20至60岁的男子估为50舍客勒圣所银子，女子为30舍客勒（[[lev 27:3-4]]）。这一差别，洛普欣解释为：每个情形中所估的是献身圣所者的不同劳动能力，因为圣所需要他作体力劳动：砍柴、打水等等。
> chis 30:2 :: !就不可食言，必要按口中所出的一切话行 ~~ 俄文本编号为 Числ 30:3。
这样，谁许了愿，谁就必须还愿；但对妇女有附带条件。若妻子许了愿或起了誓，丈夫听见了，可以废掉她所许的愿，那愿就算没有了。父亲也可以照样废掉他女儿年幼时所许、他所听见的愿。
# 犯罪堕落
这里记述了一系列对罪施以严厉刑罚的法律，例如：
- 奸淫（[[lev 20:10-12]]），
- 兽淫（特别论到妇女：[[lev 20:16]]、[[lev 18:23]]），
- 男色（同性苟合）（[[lev 20:13]]）等等。
这类违背律法的罪行要处以死刑。
