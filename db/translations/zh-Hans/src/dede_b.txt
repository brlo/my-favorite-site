# 同心合意的诫命
上帝的恩赐不是违背人的意愿强加给人的。比如，爱是上帝的恩赐（[[1in 4:7-8]]；[[gal 5:22-23]]；[[rim 5:5]]），然而它并不强加于人，来了之后，也不会违背人的意愿留在他里面。每个人都应当努力获得爱（[[1kor 13:1-2,13]]；[[kol 3:14]]），并使自己的意志趋向爱的行为（[[in 13:34]]；[[in 15:12]]；[[in 15:17]]；[[1pet 1:22]]），而上帝则回应这些努力，赐下并保守这恩赐（[[pr 21:31]]）。
同心也是从上帝来的，因为基督和使徒们都曾为此向上帝祈祷（[[in 17:21-22]]；[[rim 15:5]]）。虽然爱与同心的恩赐已由圣灵赐给教会，但教会中的每个人都应当以努力去获得并保守这一恩赐。每个信徒都可能单独地犯罪得罪爱，也得罪同心。因此，每个人都蒙召持守爱与同心：
> rim 12:16 :: !要彼此同心
> 1kor 1:10 :: !都说一样的话 :: !只要一心一意
> 2kor 13:11 :: !要同心合意，要彼此和睦
> fil 2:2 :: !你们就要意念相同，爱心相同，有一样的心思，有一样的意念
> 1pet 3:8 :: !你们都要同心，彼此体恤，相爱如弟兄
# 批评
## 在你们中间不免有分门结党的事
> 1kor 11:19 :: !在你们中间不免有分门结党的事，好叫那些有经验的人显明出来
原文这里用的不是「分门结党」而是「异端」（希腊文 αἱρέσεις），也就是说，在你们中间免不了有异端。这只是关于异端产生的预言。按使徒的话，繁殖异端的人不能承受上帝的国：
> gal 5:19-21 :: !异端 :: !行这样事的人必不能承受上帝的国
