# 洗礼圣奥秘的实质
**洗礼**（“重生”、“属灵的诞生”）——在教会中举行的圣奥秘，人在其中：
1. 洗净罪（[[act 2:38]]；[[1kor 6:11]]；[[act 22:16]]）；
2. 属灵地重生（[[in 3:3,5-6]]；[[1kor 15:44]]；[[1kor 15:47-50]]；[[1kor 15:53]]；[[gal 3:27]]）；
3. 领受救人的恩典（[[2kor 6:1]]）；
4. 加入教会（[[1kor 12:13]]）。

# 婴儿洗礼
## 人人都必须属灵地重生
一切人都需要属灵的重生，为与上帝同享永恒的生命：
> 1kor 15:40 :: !有天上的形体，也有地上的形体
> 1kor 15:44 :: !所种的是血气的身体，复活的是灵性的身体
> in 3:6 :: !从肉身生的就是肉身 :: !从灵生的就是灵
亚当朽坏身体的继承者不能进上帝的国：
> 1kor 15:47-50 :: !头一个人是出于地 :: !血肉之体不能承受上帝的国 :: !必朽坏的不能承受不朽坏的
因此，凡从亚当承受必朽性的人都要死；而在洗礼中与基督联合的人都要复活。
> 1kor 15:22 :: !在亚当里众人都死了 :: !照样，在基督里众人也都要复活
> rim 6:3,5 :: !我们这受洗归入基督耶稣的人，是受洗归入他的死 :: !也要在他复活的形状上与他联合
一切必死的都须穿上不朽坏的：
> 1kor 15:53 :: !这必朽坏的总要变成不朽坏的，这必死的总要变成不死的
就是说，在洗礼中穿上基督：
> gal 3:27 :: !受洗归入基督的，都是披戴基督了

## 使徒给整个家庭（全家）施洗
> 1kor 1:16 :: !我也给司提反家施过洗
> act 16:15 :: !她和她一家既领了洗
> act 16:30-33 :: !当信主耶稣，你和你一家都必得救 :: !他和属乎他的人立时都受了洗
使徒呼召一切人受洗，说应许不但属于他们（成人），也属于他们的儿女：
> act 2:38-39 :: !你们各人要悔改 :: !这应许是给你们和你们的儿女
这里字面地说的正是婴儿。必须深入上下文，弄清这里所说的**应许**（应许之事）是什么。这一章讲的是五旬节那天圣灵降在教会聚会上。解释这事件时，使徒彼得指着藉先知约珥所赐的应许：
> act 2:4,14-17,37-39 :: !他们就都被圣灵充满 :: !彼得和十一个使徒站起 :: !这正是先知约珥所说的 :: !我要将我的灵浇灌凡有血气的 :: !众人听见这话，觉得扎心 :: !你们各人要悔改 :: !这应许是给你们和你们的儿女
这样，使徒彼得引用的是先知约珥。我们就到先知约珥自己那里看这一应许：
> iol 2:1,15-18,28 :: !你们要在锡安吹角 :: !分定禁食的日子，宣告严肃会 :: !聚集众民 :: !聚集孩童和吃奶的 :: !耶和华就为自己的地发热心 :: !我要将我的灵浇灌凡有血气的
这就是那应许。全民族——从老人到吃奶的婴孩——都被召参加这严肃的聚会。上帝应许把圣灵浇灌在聚集的全民族身上，如经所记：浇灌凡有血气的。这样，当使徒说应许不但属于听的人、也属于他们的儿女和一切远方的人时，按上下文，他所说的儿女，字面地指的就是婴孩。
## 上帝的恩典按他人的信心运作
婴儿受洗的时刻，可以有代父母信心的运作。圣经里有许多情形：上帝的恩典因别人的信心而在一些人身上运作。
### 救主因父母的信心医治儿女
上帝按父母的信心在儿女身上行事：
- 要求的是父亲的信心，而从鬼附中得医治的是儿子（[[mk 9:17-24]]）；
- 要求的是父亲的信心，复活的是睚鲁被医治的女儿（[[lk 8:41-42,49-55]]）；
- 相信的是母亲，从鬼附中得医治的是迦南妇人的女儿（[[mf 15:22-28]]）；
- 相信的是父亲，得医治的是大臣的儿子（[[in 4:46-50]]）。
### 因亲人信心而医治（恩典运作）的情形
- 相信的是百夫长，得医治的是他的仆人（[[mf 8:10,13]]）
- 相信的是朋友们，得医治的是瘫痪的同伴（[[mk 2:5]]）。这里重要的是：因别人的信心，这人的**罪也得了赦免**。

# 对异议的回应
## 在关于从水和圣灵而生的话里（[[in 3:5]]），水是指圣灵吗？
新教徒把救主关于得救必须从水和圣灵而生的话作寓意解释，说水指的是圣灵。他们把接下去的两节联系起来：
> in 3:5 :: !从水和圣灵生的
> in 7:38-39 :: !从他腹中要流出活水的江河来 :: !耶稣这话是指着信他之人要受圣灵说的
但如果把水理解为圣灵，那就成了同义反复（同一事物多余的重复）。那样基督说的就是：要从圣灵和圣灵生。如果在这段话里直接说圣灵是合适的，那为什么还要用寓意呢？而且即使按寓意，也得说“从水的圣灵”或“从水**或**圣灵”（这才等值），而按经文，却是要从圣灵**和**别的什么生——也就是从水。
此外，我们很好知道——包括从圣经——使徒们是真实地在水里施行重生的。就是说，洗礼中的水从来都是真实的，而“从腹中流出江河”（字面地）却从来没有人流过。
所以，既然使徒们是在水里施洗、洗礼是由圣灵成就的，我们就把救主关于从水和圣灵而生的话理解为使徒们所行的那样：从水和圣灵——这一理解客观地系于使徒在水里施洗的实践。古代的教会从不把洗礼与水分开、理解为纯然头脑中的东西，而是理解为奉父、子、圣灵之名在祝圣的水中三次浸没。
## “受洗必须悔改，可婴儿不能悔改，所以也不能受洗？”
一些与教会分离的团体指责教会允许婴儿受洗。他们引用使徒劝勉听的人先悔改、后受洗的经文：
> act 2:38-39 :: !你们各人要悔改 :: !这应许是给你们和你们的儿女
悔改的要求是对成人的；婴儿没有个人的罪，因此难以把悔改的要求加在他们身上。就是说，婴儿需要受洗，但因为他们没有个人的罪，也就不必为他们所没有的东西悔改。
总的来说，这指责听起来很奇怪。由它得出的是：婴儿为了穿上基督（受洗——[[gal 3:27]]），必须先犯罪；而他们还没有犯罪，就不能悔改，那么也就永远不能受洗。这成了某种荒谬：为获得与基督联合的可能，必须先得罪基督。当然，这是大错。受洗是人人需要的，悔改只是犯了罪的人需要的。
先知约翰的悔改的洗礼虽然不同于基督里的洗礼（[[act 19:4]]），但可以检验这些推理是否正确。先知约翰施悔改的洗，但当基督来到他那里时，他没有悔改就立刻下到水里。基督没有罪，因此他没有悔改就受了悔改的洗。婴儿也是这样。基督不需要先获得罪，才能获得受悔改之洗的可能。婴儿也是这样。受洗是人人被召的，悔改的只是有可悔之事的人。
## “受洗需要信心，可婴儿不能宣认信仰，所以也不能受洗？”
与教会分离的团体还引用另一节经文，其中主说要信而受洗：
> mk 16:16 :: !信而受洗的，必然得救 :: !不信的，必被定罪
这样，得救的必要条件之一是获得**信心**、领受**洗礼**。不履行这些条件，人不能得救。然而，难以把信心的要求加在婴儿身上；所以他们按代父母的信心受洗——对此也有圣经的依据（详见[[ru:крещение#HH-Действие-благодати-Божьей-по-вере-других-людей|上帝的恩典按他人的信心运作]]）。
还要特别注意接下去的话：不信的必被定罪。那么是不是说婴儿也要被定罪，因为他们不能信呢？
> mk 16:16 :: !不信的，必被定罪
问题在于：这一节里信心的要求只对成人。而洗礼本身，如救主在别处所说（[[in 3:3,5-6]]），是人人需要的，包括婴儿。婴儿将带着洗礼中所穿的基督（[[gal 3:27]]）长大——按代父母的信心（详见[[ru:крещение#HH-Действие-благодати-Божьей-по-вере-других-людей|上帝的恩典按他人的信心运作]]）。随着婴儿能力的增长，代父母使他在信心里坚固。如果不幸发生，婴儿因悲惨的情形死去，那么，作为受过洗的，他达到天国、与基督同享永生。
至于救主话语的次序（信而受洗），也有相反的次序：
> mk 1:4 :: !传悔改的洗礼
那么就请他们也承认这里是先施行悔改的洗、然后才有宣讲。
## “可是基督只在三十岁受洗？”
先知施洗约翰的洗礼不是基督里的洗礼。已经受过约翰之洗的人，使徒保罗重新给他们施基督的洗：
> act 19:2-6 :: !你们受的是什么洗呢 :: !是约翰的洗 :: !约翰所行的是悔改的洗 :: !他们听见这话，就奉主耶稣的名受洗 :: !保罗按手在他们头上，圣灵便降在他们身上
此外，从那些在这事上不效法基督的人——不在三十岁受洗、虽然不在婴儿期、但也不等到三十岁而是在八到十二岁给自己的孩子施洗——听到这样的指责，是很奇怪的。如果教会的指控者认为受洗的年龄应当效法基督（他受约翰的洗），那么要领洗，他看来也得等到三十岁。然而这不对，因为先知约翰悔改的洗不是基督里的洗（[[act 19:2-6]]）。基督等候三十岁不是为了受洗，而是为了出来任职事奉（[[chis 4:3]]）、出来宣讲、显明自己的荣耀。他的宣讲以先知约翰的见证开始——约翰指着来到他那里受洗的耶稣，指明他就是基督。约翰是先知。他什么时候指明救主来临之预言的应验？什么时候指着救主？当救主预备好出来任职的时候——三十岁（[[chis 4:3]]）。
## “可是那悔改的强盗没来得及受洗，却得救了？”

> act 1:1-5,8-9 :: !四十天之久向他们显现 :: !约翰是用水施洗 :: !你们要受圣灵的洗 :: !但圣灵降临在你们身上，你们就必得着能力 :: !有一朵云彩把他接去
> act 2:1,3-4 :: !五旬节到了 :: !又有舌头如火焰显现出来，分开落在他们各人头上 :: !他们就都被圣灵充满
不过，在基督复活的当天也讲到差遣圣灵，但没有讲到洗礼。这是司祭等次的设立，同时赐下赦罪和不赦罪的权柄：
> in 20:1,19,22 :: <<七日的第一日清早 :: !耶稣来站在当中 :: !就向他们吹一口气，说
## “不要禁止小孩子到基督这里来”
与教会分离的团体指责教会：教会关于不經洗礼不能得救的教训（[[in 3:3,5-6]]）仿佛妨碍婴儿得救。教会仿佛不让婴儿到基督那里去。他们引用下面这节经文：
> lk 18:15-16 :: !有人抱着自己的婴孩来见耶稣 :: !让小孩子到我这里来，不要禁止他们
实际上，这节经文所责备的，恰恰是婴儿洗礼的反对者。
圣经的这一情形里字面地发生了什么？
1. **母亲们把婴孩带到基督那里**，求主祝福他们；
2. **门徒拦在路上**，禁止他们把婴孩带到基督那里；
3. **主为母亲们开了路**，指示门徒不要拦阻把婴孩带到他那里，并祝福了婴孩（[[mk 10:16]]）。
教会的反对者在做什么？
1. 母亲们愿意让婴孩从出生就归向基督（这是我们亲自从脱离教派的母亲们那里知道的）；
2. 教会的反对者拦在母亲们的路上，字面地禁止她们给孩子施洗——圣经称洗礼为穿上基督（[[gal 3:27]]）。
教会在做什么？
1. 召母亲们带着自己的婴孩到基督那里；
2. 当母亲们把婴孩带来时，教会藉洗礼、圣餐礼和圣物使婴孩归向基督，赐给他们祝福。
教会的反对者把一切颠倒了。教会召母亲们和婴孩到基督那里，他们说这是与基督联合的障碍；而他们禁止母亲们给孩子施洗，倒说是“不阻碍”孩子到基督那里去。
教会的教训丝毫不妨碍基督拯救婴孩——如果婴孩不经洗礼就能得救的话。而教派禁止给婴儿施洗，倒是非常妨碍婴孩的得救——考虑到基督说过，不经洗礼没有人能进上帝的国（[[in 3:3,5-6]]）。
## “罪的赦免发生在获得信心的时候，而不是浸在水里？”
许多新教徒称水的洗礼只是见证（某种记号），而人的重生和罪的赦免——他们认为——发生得更早：只要人信了、为自己的罪向上帝认罪就发生了。然而，我们在圣经里看到：正是在水的洗礼中人重生、罪被洗净，正是它对人是救人的。
扫罗（未来的使徒保罗）被基督弄瞎了眼，并且立刻**信了**他；但这没有使他的罪得赦。扫罗被打发到大马士革去，为要藉领受水的洗礼洗去他的罪：
> act 22:8,10-13 :: !主啊，你是谁 :: !主啊，我当作什么 :: !兄弟扫罗，你可以看见
信了的扫罗需要藉洗礼洗去罪：
> act 22:16 :: !起来，求告他的名受洗，洗去你的罪
另一处直接说，洗礼救人（而不是见证）：
> 1pet 3:21 :: !这水所表明的洗礼，现在借着耶稣基督复活，也拯救你们
> tit 3:5 :: !借着重生的洗和圣灵的更新
## “人是因传讲基督的道而属灵地重生？”
否认上帝在圣奥秘中运作的新教徒，也否认人在洗礼的水中属灵地重生。否认这一点，他们教导人说，“从水和圣灵”的生（[[in 3:3,5]]）仿佛只在宣讲的时刻发生，其余的一切——隆重的象征性活动。为论证这一观念，他们引用这些经文：
> iak 1:18 :: !他按自己的旨意，用真道生了我们
> 1pet 1:23-25 :: !你们蒙了重生 :: !乃是由于不能坏的种子，是借着上帝活泼常存的道 :: !所传给你们的福音就是这道
教会宣讲福音有上帝的协助，他在听道人的灵魂上动工。这宣讲可以在人里面产生转变，呼召他悔改、指引他生命的道路。上帝的道是唤醒人脱离罪的沉睡、在人里面激起悔改、生发信心的手段。然而，这宣讲还没有洁净人的罪，还不是在重生的水洗中（[[ef 5:25-26]]；[[tit 3:5]]）从水和圣灵而生（[[in 3:3,5]]）。
在别处清楚地说：为使罪得赦，必须领受在水中举行的洗礼圣奥秘：
> act 22:16 :: !起来，求告他的名受洗，洗去你的罪
没有信心和悔改的人不被允许受洗。所以首先他必须听上帝的道，然后由听道而来的信心（[[rim 10:17]]），然后才是从水和圣灵而生、罪的洗净、以及在洗礼和圣膏中受圣灵的印记。
使徒先宣讲上帝的道；当听众**觉得扎心**时，他就呼召他们受洗使罪得赦：
> act 2:37-38 :: !众人听见这话，觉得扎心 :: !我们当怎样行 :: !你们各人要悔改 :: !奉耶稣基督的名受洗 :: !叫你们的罪得赦
## “洗礼不在乎除掉肉体的污秽，只求……”
> 1pet 3:21 :: !这水所表明的洗礼 :: !只求在上帝面前有无亏的良心
这一处在俄文里译得不正确。差别是根本性的：在“许诺”里没有任何圣奥秘，不从上帝领受什么；相反，是人向他许诺。而当人向上帝祈求时，从上帝那边期待的是行动（圣奥秘）：藉着罪的赦免（从上帝那边）获得无亏的、清洁的良心（[[evr 9:14]]），不被先前的罪所累。而如果浸入水里时如新教徒所想的那样什么也不举行，那还向上帝求什么呢——如果他在这里什么也不赐。
使徒彼得的书信是用希腊文写的。圣兄弟基里尔和梅福季——通晓斯拉夫语的希腊人——把 ἐπερώτημα 译作“祈求”（вопрошание），而不是“许诺”：向上帝祈求无亏的良心。
同样，古代基督徒之一——希腊人、教会的主教神学家格列高利（四世纪）——写道，这里说的是上帝的作为：按祈求赐给人无亏的良心（[俄文](https://azbyka.ru/otechnik/Grigorij_Bogoslov/slova-izd-2007-g/40)《讲道集》第40篇·论圣洗礼）。
而且，总的来说，在新约文本中这个词一次也没有被译作“许诺”，总是译作“祈求、问”。
- ἐπερωτῆσαι——问（太 22:46）
- ἐπερωτῶσιν——问（可 7:5）
- ἐπερωτῆσαι——问（可 9:32）
- Ἐπερωτήσω——我要问（可 11:29）
- ἐπερωτῆσαι——问（可 12:34）
- ἐπερωτῶντα——问的（路 2:46）
- Ἐπερωτῶ——我要问（路 6:9）
- Ἐπερωτηθεὶς——被问（路 17:20）
- ἐπερωτᾶν——问（路 20:40）
- ἐπερωτήσατε——你们问（约 9:23）
- ἐπερωτήσας——问了（徒 23:34）
- ἐπερωτῶσιν——问过的（罗 10:20）
- ἐπερωτάτωσαν——问（林前 14:35）
- ἐπερώτημα——祈求（教会斯拉夫语译法）（彼前 3:21）
就是说，不是人给上帝什么——如果那是“许诺”的话。人只是祈求，而赐下的是上帝（直接写着：“**洗净你们的心**”，[[evr 9:14]]）。
使徒指明：洗礼洗去的不是身体上的污秽（不在乎除掉肉体的污秽），而是内在地洗净罪。就是说，这是圣奥秘——重要的、肉眼看不见的、不能完全领会和说明的事。
这一切都在圣灵对水的运作中发生；所以主耶稣基督说，人从水和圣灵而生，而不只是从圣灵：
> in 3:3,5-6 :: !人若不重生 :: !从水和圣灵生的 :: !从肉身生的就是肉身 :: !从灵生的就是灵
况且，使徒最终说的话是：洗礼——**拯救**：
> 1pet 3:21 :: !这水所表明的洗礼，现在借着耶稣基督复活，也拯救你们
而新教徒（浸信会）根本不同意这一点。在他们的教导里，洗礼只是隆重的许诺，是形式，不救人。而使徒说，洗礼正是**拯救**的。
他们认为，在获得信心和悔改的时刻罪就得赦免了；而使徒保罗虽然信了，后来却被吩咐受洗以洗去罪：
> act 22:16 :: !起来，求告他的名受洗，洗去你的罪
这里也如此说：
> act 2:38 :: !你们各人要悔改，奉耶稣基督的名受洗，叫你们的罪得赦
## “洗净罪的不是洗礼，而是上帝的道？”
> ef 5:25-26 :: !要用水借着道把教会洗净
基督为教会舍了自己，为要使她成为圣洁。怎样洁净？——“用水借着道”，即圣洗礼：在三次浸入水中时，念诵奉父、子、圣灵之名的话（[[mf 28:19]]）。这里说的正是这话。而且无论哪一样（水）、哪一样（关于父、子和圣灵的话）都不能排除。作别的解释，就是断章取义。这里说的是在**水的洗**中念诵的道。
## 关于百夫长哥尼流：圣灵不经洗礼赐下吗？
灵恩派教派的拥护者为他们关于自己仿佛只凭祈祷就领受圣灵的教训辩护。他们引用圣灵唯一一次在洗礼之前降临的情形：
> act 10:44 :: !圣灵降在一切听道的人身上
这里讲的是百夫长哥尼流，他是外邦人。当时不清楚：能不能给他们施洗，能不能接纳外邦人进入教会。
所以上帝赐下特别的启示，表明外邦人可以进入教会。
1. 上帝差到外邦人哥尼流那里的不是圣灵，而是天使，叫他去找教会、请使徒来听，好得救。
2. 使徒彼得三次看见同一个异象：不洁的食物降到他面前，有声音吩咐他宰了吃；因为这声音解释说：“上帝所洁净的，你不可当作俗物”（[[act 10:15]]）
3. 当使徒来到并开始宣讲时，圣灵降在听道的外邦人身上。
之后，犹太血统的基督徒对所发生的事惊讶。怎么这样——圣灵降在外邦人身上？
> act 10:45 :: !见圣灵的恩赐也浇在外邦人身上，就都希奇
然后一切以外邦人受洗结束——如今他们无疑可以受洗了，因为上帝亲自指明了这一点：
> act 10:47-48 :: !谁能禁止用水给他们施洗呢 :: !就吩咐奉耶稣基督的名给他们施洗
这样，这是圣灵在洗礼之前降临的唯一一例。不是代替洗礼，而是在它之前——因为洗礼还是举行了。而这一特殊的圣灵降临有一个例外性的缘由——上帝以圣灵表明：可以接纳外邦人进入教会。
圣灵降临在人身上本身，是与洗礼分开的圣奥秘（详见[[ru:миропомазание|圣膏]]）。
## “太监不经使徒就领受了圣灵？”
这个问题属于圣膏的主题（见[[ru:миропомазание#HH-Если-сообщать-дары-Святого-Духа-могут-только-апостолы-то-почему-Святой-Дух-сходит-на-эфиопского-евнуха-после-крещения-от-диакона-Филиппа|圣膏]]）。在腓利与太监的情形中（[[act 8:39]]）有一个非常重要的细节。
绝大多数释经者——包括最古老的，包括圣金口约翰——引用这段经文时都没有关于圣灵降临的话（αγιον επεπεϲεν επι τον ευνουχον αγγελοϲ δε）。经上只是说：
主<s>灵降在太监身上，而天使</s>把腓利提了去。
西奈抄本没有这些话（四世纪）：
“καὶ ἐκέλευσεν στῆναι τὸ ἅρμα,
καὶ κατέβησαν ἀμφότεροι εἰς τὸ ὕδωρ,
ὁ τε Φίλιππος καὶ ὁ εὐνοῦχος,
καὶ ἐβάπτισεν αὐτόν.
ὅτε δὲ ἀνέβησαν ἐκ τοῦ ὕδατος,
**πνεῦμα Κυρίου ἥρπασε τὸν Φίλιππον**,
καὶ οὐκ εἶδεν αὐτὸν οὐκέτι ὁ εὐνοῦχος·
ἐπορεύετο γὰρ τὴν ὁδὸν αὐτοῦ χαίρων.
Φίλιππος δὲ εὑρέθη εἰς Ἄζωτον,
καὶ διερχόμενος εὐηγγελίζετο τὰς πόλεις πάσας,
ἕως τοῦ ἐλθεῖν αὐτὸν εἰς Καισάριαν.”（使徒行传 8:39-40）
梵蒂冈抄本没有这些话（四世纪）：
“και εκελευϲε ϲτηναι το αρμα και κατεβηϲαν αμφοτεροι ειϲ το υδωρ ο τε φιλιπποϲ και ο ευνουχοϲ και εβαπτιϲεν αυτον
οτε δε ανεβηϲαν εκ του υδατοϲ **πνευμα κ̅υ̅ ηρπαϲεν το̅ φιλιππον** και ουκ ειδε̅ αυτον ουκετι ο ευνουχοϲ επορευετο γαρ αυτου την οδον χαιρων”
圣金口约翰也是这样引用的（没有圣灵降临的话）：
“Ὅτε δὲ ἀνέβησαν ἀπὸ τοῦ ὕδατος, **Πνεῦμα Κυρίου ἥρπασε τὸν Φίλιππον**, καὶ οὐκ εἶδεν αὐτὸν οὐκ ἔτι ὁ εὐνοῦχος.”
（[俄文](https://bibleox.com/el/grc/w/dNiR_Ὁμιλίαι_εἰς_τὰς_Πράξεις_τῶν_Ἀποστόλων#HH-ΟΜΙΛΙΑ-ΙΘ΄)《使徒行传讲道集》第9篇）
主教米哈伊尔（卢济恩）的注释：
“‘圣灵降在太监身上，主的使者却把腓利提了去’：这一处只有少数古代希腊抄本和译本（教会斯拉夫语和俄语译本依从它们）以及少数古代释经者如此读；在大部分抄本和译本以及释经者中（其中如圣金口约翰和提奥菲拉克特）读作：主的灵把腓利提了去。这究竟是一些抄本中的增添，还是另一些抄本中的省略——难以断定；但前一种更可信，此处可以解释为：圣史缄默不言太监领受圣灵的事。”
（[俄文](https://azbyka.ru/biblia/in/?Act.8:39&r)来源）
# 若干补充
## 婴儿能够信
完全有理由认为，婴儿也能够信、并被圣灵充满，虽然他们还不能回答问题、以宣认自己的信仰。
先知大卫从婴孩时期就仰赖上帝：
> ps 22:9-10 :: !我在母怀里，你就使我有倚靠的心 :: !从我母亲生我，你就是我的上帝
先知约翰在出生之前就感到与救主相遇，并为之欢喜：
> lk 1:39-41 :: !所怀的胎就在腹里跳动 :: !以利沙伯且被圣灵充满
基督把一个孩子放在自己面前，讲到那些**信他的**“小子”：
> mf 18:2-6 :: !耶稣便叫一个小孩子来 :: !你们若不回转，变成小孩子的样式 :: !凡使这信我的一个小子跌倒的
孩子们在基督进入耶路撒冷时赞美他：
> mf 21:15-16 :: !小孩子在殿里喊着说 :: !你从婴孩和吃奶的口中完全了赞美的话
## 没有说谁可以不经洗礼而得救
圣经里没有说谁可以不经洗礼而得救的话。倒是说了：不经洗礼没有人能进上帝的国（[[in 3:3,5-6]]）。
