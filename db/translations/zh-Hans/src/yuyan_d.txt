# 假师傅的手法
## 1. 动听的学说
假师傅们将要编出动听的学说，正是因为他们的听众将寻求悦耳的学说，忍受不了纯正的教导：
> 2tim 4:3 :: !人必厌烦纯正的道理 :: !耳朵发痒，就随从自己的情欲，增添好些师傅
> 1tim 4:1-2 :: !必有人离弃真道，听从那引诱人的邪灵和鬼魔的道理
## 2. 虚假的敬虔
> 2tim 3:1-2,5,7-8 :: !末世必有危险的日子来到 :: !有敬虔的外貌，却背了敬虔的实意 :: !这等人也怎样敌挡真道
> mf 7:15 :: !你们要防备假先知。他们到你们这里来，外面披着羊皮，里面却是残暴的狼
## 3. 展示性的奇迹
使徒们和古代基督徒被赐予丰富的行异能之力，不是为了作秀，而是为了益处：
> 1kor 12:7 :: !圣灵显在各人身上，是叫人得益处
一小群渔夫需要很大的帮助，才能作为见证人，在短短一生中把传道传遍全世界。使徒们曾警告说，这些恩赐将要止息：
> 1kor 13:8 :: !先知讲道之能，终必归于无有；说方言之能，终必停止
基督自己也斥责寻求奇迹：
> mf 12:39 :: !一个邪恶、淫乱的世代求看神迹
在末后的时代，假先知将恰恰以奇迹引诱人：
> mf 24:24; mk 13:22 :: !因为假基督、假先知将要起来，显大神迹、大奇事
结果，在审判时，许多信徒将确信自己得救正是因为他们奉基督的名行异能、说预言、赶鬼。但他们受了欺骗，被教导行不法之事，基督不认识他们，把他们从自己面前赶走：
> mf 7:22-23 :: !当那日，必有许多人对我说 :: !奉你的名行许多异能吗 :: !我从来不认识你们，你们这些作恶的人，离开我去吧
# 如何认出假先知
他的预言不成就：
> vtor 18:22 :: !所说的若不成就，也无效验
如果先知或作梦的向你显个神迹、奇迹，或他的梦应验了，但他召你去事奉别的神，那就不当听他的话：

# 前言
主耶稣基督两千多年前，按古代先知的[[ru:пророчества-о-Христе|话语]]，由至洁的童贞女马利亚所生（不经男子）。他在少年时（十二岁）就已具有大智慧，令耶路撒冷圣殿中的教师们惊奇。到三十岁之前，耶稣基督顺服于约瑟，作寻常的劳动；三十岁时出来传道。关于这一时期的详情：[[ru:Христос-жизнь-в-Палестине|基督——在巴勒斯坦的生活]]。
之后，主耶稣基督传道，教导了门徒（使徒们），被出卖，在十字架上受难，第三天复活，四十天之久向自己的跟随者显现，教导他们天国的事，然后升天，坐在上帝的右边，并应许要第二次再来——正如他升天那样——为要审判全宇宙。再过十天（从复活算起的第五十天），他建立了自己的教会，并永远地把圣灵赐给了教会。
# 关于假基督
## 欺骗者
主耶稣基督亲自警告说，将有人冒充他来临，许多人会相信这些欺骗者：
> mf 24:3-5 :: !你们要谨慎，免得有人迷惑你们 :: !因为将来有好些人冒我的名来，说：『我是基督』，并且要迷惑许多人
# 关于基督的降临
## 降临——如同闪电
然而，基督的第二次降临将立刻被全世界的人知道，如同闪过的闪电：
> lk 17:23-24 :: !你们不要出去，也不要跟随他们 :: !好像闪电从天这边一闪直照到天那边 :: !人子在他降临的日子
> mf 24:26-27 :: !你们不要出去 :: !你们不要信 :: !闪电从东边发出，直照到西边；人子降临，也要这样
## 与所有天使一同降临
基督的第二次降临将带着父的荣耀，与所有圣洁的天使一同来临：
> zah 14:5 :: !耶和华我的上帝必降临，有一切圣者同来
> mf 25:31 :: !当人子在他荣耀里 :: !同着众天使降临的时候
> mk 8:38 :: !同圣天使降临的时候
> mf 16:27 :: !同着众使者降临
> iud 1:14 :: !主带着他的千万圣者降临
> 1sol 3:13 :: !当我们主耶稣同他众圣徒来的时候
> 2sol 1:7 :: !主耶稣同他有能力的天使从天上在火焰中显现
## 以已有的成人身体降临
基督不会再次由人所生，而是带着他已有的身体来临——那身体是他在公元一世纪由童贞女马利亚上帝之母所生时获得的。
> act 1:9-11 :: !他就被取上升，有一朵云彩把他接去 :: !这离开你们被接升天的耶稣，你们见他怎样往天上去，他还要怎样来
## 降临是为了审判
主来不是为了教导，而是按他第一次来时所已经赐下的话语施行审判：
> in 12:48 :: !就是我所讲的道，在末日要审判他
> mf 16:27 :: !他要照各人的行为报应各人
> mf 25:31-33,46 :: !当人子在他荣耀里 :: !要坐在他荣耀的宝座上 :: !万民都要聚集在他面前 :: !好像牧羊的分别绵羊山羊一般 :: !这些人，要往永刑里去 :: !那些义人，要往永生里去
> 2sol 1:5-8 :: !这正是上帝公义判断的明证 :: !那时，主耶稣同他有能力的天使从天上在火焰中显现 :: !要报应那不认识上帝和那不听从我主耶稣福音的人
