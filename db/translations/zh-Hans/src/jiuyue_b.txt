# 上帝在石版上赐给先知摩西的十条诫命
上帝的诫命并不限于这些，但正是这些诫命写在了石版上。
## 1
> ish 20:2-3 :: !我是耶和华你的上帝 :: !除了我以外，你不可有别的神 ~~ 并见 [[vtor 5:6-7]]；[[lev 19:2]]。
## 2
> ish 20:4-5 :: !不可为自己雕刻偶像 :: !不可跪拜那些像；也不可事奉它 ~~ 并见 [[vtor 5:8-9]]；[[lev 19:4]]。
## 3
> ish 20:7 :: !不可妄称耶和华你上帝的名 ~~ 并见 [[vtor 5:11]]；[[lev 19:12]]。
## 4
> ish 20:8-10 :: !当记念安息日，守为圣日 :: !六日要劳碌作你一切的工 :: !但第七日是向耶和华你上帝当守的安息日 ~~ 并见 [[vtor 5:12-15]]；[[lev 19:3]]；[[lev 19:30]]；[[ier 17:21]]；[[neem 13:15-18]]。
## 5
> ish 20:12 :: !当孝敬父母，使你的日子在耶和华你上帝所赐你的地上得以长久 ~~ 并见 [[vtor 5:16]]；[[lev 19:3]]。
## 6
> ish 20:13; vtor 5:17 :: !不可杀人 ~~ 并见 [[lev 19:17-18]]。
## 7
> ish 20:14; vtor 5:18 :: !不可奸淫 ~~ 并见 [[lev 19:20]]。
## 8
> ish 20:15; vtor 5:19 :: !不可偷盗 ~~ 并见 [[lev 19:11]]；[[lev 19:13]]。
## 9
> ish 20:16; vtor 5:20 :: !不可作假见证陷害人 ~~ 并见 [[lev 19:11]]。
## 10
> ish 20:17; vtor 5:21 :: !不可贪恋人的房屋 :: !也不可贪恋人的妻子、仆婢、牛驴，并他一切所有的 ~~ 并见 [[lev 19:17]]。
