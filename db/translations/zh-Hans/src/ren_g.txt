# 私审判简介
<a href="https://azbyka.ru/mytarstva">私审判</a>是东正教会的一项教导：在人死后，堕落的天使企图夺取人的灵魂。这样，灵魂要经受可怕的试炼；在试炼中，上帝的天使尽力保护义人的灵魂，把他们带到上帝面前。这一教导以象征性、形象性的方式表达为若干「关卡」，灵魂在每一关上都要就某些情欲受审问。在这里，天使是施行上帝公义的工具。
# 在邪恶的日子抵挡天空属灵气的恶魔，胜过一切
魔鬼是空中掌权者的首领：
> ef 2:1-2 :: !顺服空中掌权者的首领
需要有所准备，以便在邪恶的日子（死亡之日）胜过一切：
> ef 6:11-13 :: !要穿戴上帝所赐的全副军装，就能抵挡魔鬼的诡计 :: !天空属灵气的恶魔 :: !好在磨难的日子抵挡 :: !并且成就了一切，还能站立得住
# 若无上帝的许可，魔鬼不能触及义人；他寻求获得许可来辖制他们
魔鬼寻求如何控告或诬告人，以便辖制他：
> iov 2:4-6 :: !他在你手中，只要存留他的性命
> iud 1:9 :: !为摩西的尸首与魔鬼争辩的时候
# 魔鬼时刻寻找可吞吃的人
> 1pet 5:8 :: !你们的仇敌魔鬼，如同吼叫的狮子，遍地游行，寻找可吞吃的人
# 天使被差遣服事那将承受救恩的人
> evr 1:13-14 :: !天使岂不都是服役的灵、奉差遣为那将要承受救恩的人效力吗
# 天使在死后「接去」义人的灵魂
灵魂在与身体分离之后是会移动的。灵魂必须走完通往它将来居所的路程。
天使照管了义人拉撒路的灵魂，但对财主却没有这样的记载：
> lk 16:19-26 :: !后来那讨饭的死了，被天使带去放在亚伯拉罕的怀里 :: 财主也死了，并且埋葬了 :: !他在阴间受痛苦 :: !你该回想你生前享过福，拉撒路也受过苦；如今他在这里得安慰，你倒受痛苦
罪人的灵魂会在不知不觉中被取去：
> lk 12:19-21 :: !无知的人哪，今夜必要你的灵魂 :: !凡为自己积财，在上帝面前却不富足的，也是这样
# 在死亡的时辰魔鬼来到基督面前，但他无物可指责基督
在受难的前一天，基督说到魔鬼的临近；魔鬼在基督里面毫无所有，不能以罪指责他：
> in 14:30 :: !这世界的王将到，他在我里面是毫无所有
但对其他的人就不是这样：
> 1in 3:8 :: !犯罪的是属魔鬼
# 基督是借着云彩、经由空中升天的
> act 1:9-10 :: !他就被取上升，有一朵云彩把他接去 :: !当他往上去
# 基督也将同样再来
> fil 3:20 :: !并且等候救主
> act 1:11 :: !你们见他怎样往天上去，他还要怎样来
