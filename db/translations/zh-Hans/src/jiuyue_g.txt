# 定义
**香**——燃烧的乳香（树脂）所发的烟。
**乳香**（阿拉伯文 lādan——「芳香树脂」）——某些树木（起初是黎巴嫩雪松）的芳香树脂。燃烧的乳香发出悦人的香气。在举行圣礼和调制芬芳圣香时使用（[[ish 30:34-36]]）。
**焚香**——乳香燃烧、香上升的过程。
**香炉**——焚烧芬芳配料（加乳香）的器具（盘）。

## 专只为香（乳香）而设的坛
特别设立了烧香的坛，在其上不可焚烧任何别的东西。在其上焚香与祭献无关，自成一体。每天早晨和每天黄昏整理灯台时举行：
> ish 30:1,6-9 :: !你要用皂荚木作一座烧香的坛 :: !要把坛放在法柜前的幔子外 :: !亚伦在坛上要烧馨香料作的香 :: !每早晨他收拾灯的时候，要烧这香 :: !黄昏点灯的时候 :: !作为世世代代常烧的香 :: !不可奉上异样的香 :: !也不可浇上奠祭
