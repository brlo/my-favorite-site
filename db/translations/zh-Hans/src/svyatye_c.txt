# 为什么敬礼圣义者的圣髑
敬礼圣义者的圣髑，理由与敬礼圣义者本身相同（详见下一篇[[ru:почитание-святых-в-Библии|敬礼圣人]]）；敬礼他们，是因为他们分有上帝、因为上帝的恩典在他们里面运作（[[ru:человек-храм-Божий|人——上帝的殿]]）。敬礼的对象是义人的整体，而不是他的某一部分（[[ru:состав-человека|人性构成]]）。受敬礼的不只是**灵魂**，还有**身体**（[[4ts 13:21]]），甚至**遗物**（[[act 19:12]]）和**像**（[[act 5:15]]）——上帝藉它们施行奇迹和医治，赐下自己的恩典。
因为圣人**受敬礼是由于他们分有上帝、由于上帝的恩典在他们里面运作**，而上帝赐下自己的恩典，不但经由圣徒活着的身体，也经由他们死后的身体（[[4ts 13:21]]），所以圣徒的身体不只在生前、在死后（身体与灵魂分离之后）也因恩典而受敬礼。
上帝不厌恶自己朋友们的遗体。上帝看顾义人的遗骸（[[ps 34:19-20]]；[[in 19:33,36]]），并继续藉它们行事（[[4ts 13:21]]）。持香的妇女们对遗骸也没有厌恶——她们在救主死后第三天去开他的坟墓，要用香膏膏抹基督死去的身体（[[mk 16:1-3]]），尽管摩西的律法禁止除亲属之外的任何人接触死者的身体（[[lev 21:1-4]]）。
# 常见的问题
## 为什么圣髑在圣殿里，而不在土里
**圣殿就是**义人遗骸的**坟墓**。圣髑保存在圣殿的石棺（圣髑匣、圣髑柜）里。上帝说人是土、所以要归回土（[[gen 3:19]]），这话的意思是：人用土造成的身体[1]会重新变为土，即朽坏分解，重新成为它起初所是的——土。
许多义人并不是字面地被埋进土里。相反，义人们力求以某种特别的方式安葬义人，常常为安葬挑选专门的场所。
1. **亚伯拉罕把自己亲人的遗体安葬在专门购买的洞穴里**。他向当地的居民求葬地，而他们向他提出**最好的**葬地（[[gen 23:2-6]]）。最后，亚伯拉罕请求并买下他们所指的洞穴为业（[[gen 23:7-13,17-20]]），好在那里安葬自己的亲人。就在同一个洞穴里，后来安葬了亚伯拉罕本人（[[gen 25:9-10]]）、他的妻子撒拉（[[gen 23:19]]）、以撒和他的妻子利百加（[[gen 49:1,29-33]]）、雅各和他的妻子利亚（[[gen 49:1,29-33]]；[[gen 50:12-13]]）；
2. **主耶稣基督被安葬在岩石中凿出的专门墓穴里**——那是财主约瑟（亚利马太人）为自己凿的（[[mf 27:57,60]]；[[mk 15:46]]；[[lk 23:50-53]]；[[in 19:41]]）。这正是上帝起初藉先知以赛亚预言所定的：“人还使他与恶人同埋；谁知死的时候**与财主同葬**”（[[is 53:9]]）；
3. **最早的基督徒常常把义人安葬在地下墓穴的专门墓室里**，并在圣髑旁举行事奉圣礼（[[ru:почитание-мощей-цитаты-святых#HH-Община-Поликарпа-Смирнского-II-век|例子]]）；
4. 三百年后、四世纪基督教安全的时代来临，圣人的遗骸开始被安葬在圣殿里：或如义人约瑟那样安放在石棺中（[[gen 50:26]]；[[ru:почитание-мощей-цитаты-святых#HH-Григорий-Нисский-святитель-331-394|例子]]），或安置在圣殿主要部分（祭坛）下方专门的墓室（地窟）里，或建造专门的单独建筑（殉道者纪念堂）（[[ru:почитание-мощей-цитаты-святых#HH-Амвросий-Медиоланский-святитель-397|例子]]）。
这样，**从最古老的年代起，义人就把义人安葬在专门的场所，而不是土里**。教会在今天也是这样：义人的遗骸安放在专门场所——举行事奉圣礼的圣殿——里的石棺中。
无论我们怎么做，实质是同一个：
- 或者建一座殉道者纪念堂来安放圣髑石棺，教会聚集在其中举行事奉圣礼；
- 或者反过来，建一座举行事奉圣礼的圣殿，把圣髑石棺安放在那里。
教会从最古老的时代起就建造安放圣人棺柩的建筑，并在那里举行事奉圣礼。
## 迁移圣髑
圣经中多次发生义人遗骸的迁移，没有任何责难。例如，族长约瑟被安葬在埃及的石棺（圣髑匣）里（[[gen 50:26]]），后来先知摩西与民众四十多年抬着约瑟的遗骸走旷野，为要在约瑟自己指定的地方安葬他。详见[[ru:почитание-мощей-святых#HH-Эпизоды-об-останках-из-Библии|下文]]。
## 圣髑的分割
从最古老的年代起，圣义者的遗骸是在最残酷的酷刑（砍碎、焚烧）之后到达教会的——不是完整的，也不是一下子全部（[[mf 14:11]]；[[mk 6:28]]）。而上帝后来照样经由义人的遗骸行事，无论它们是否被收拢在一起。教会本身若保存了义人完整的遗骸，就把它们整体保存在安放于圣殿中的专门棺柩（石棺、圣髑匣）里。分割可能出于不得已的原因：在自然灾害和敌人袭击时抢救圣髑。有时为了在别处敬礼义人，只取圣髑极小的一粒碎屑。
# 上帝对人遗骸的态度
## 上帝保全义人的遗骸
> ps 34:19-20 :: !义人多有苦难 :: !又保全他一身的骨头，连一根也不折断
> in 19:33,36 :: !就不打断他的腿 :: !他的骨头一根也不可折断
由此可见上帝自己对圣人遗骸的态度。尽管如此，上帝有时容许（而不是愿意）义人受折磨，甚至被斩首，如先知施洗约翰（[[mf 14:11]]；[[mk 6:28]]）。但上帝也藉被分割的圣人遗骸赐下恩典。

> 4ts 13:21 :: !一碰着以利沙的骸骨，死人就复活站起来了

# 上帝经由义人的像行事

> act 5:15-16 :: !指望彼得过来的时候，或者得他的影儿照在什么人身上 :: !全都得了医治
# 向圣人叩拜
十诫的第一诫（[[ish 20:2-3]]；[[vtor 5:6-7]]）禁止敬拜假神（偶像）。假神不但虚假，而且根本不存在。
圣人则真实存在，他们是上帝的朋友；向他们叩拜，不是把他们当神。向圣人和他们的圣髑叩拜，是表达对他们的敬意——作为上帝的朋友。这样的向天使、向人、向物件的叩拜在圣经中有，而且不是拜偶像，因为拜偶像——是敬拜**假**神。义人们经常向人、向各种物件、向天使下拜；别人也向先知下拜。

## 迁移遗骸
### 约瑟
约瑟（雅各的儿子）请求日后把他的遗骸从埃及迁到上帝应许给他的那地：
> gen 50:24-25 :: !你们要把我的骸骨从这里搬上去
约瑟死了，人们把他安葬在埃及，收殓在棺材（圣髑匣）里：
| 约瑟死了，正一百一十岁。人用香料将他薰了，把他收殓在棺材里，停在埃及。 ||| ctb gen 50:26
先知摩西履行了约瑟的请求：
> ish 13:18-19 :: !摩西把约瑟的骸骨一同带去 :: !你们要把我的骸骨从这里一同带上去
先知摩西和以色列民**四十多年**抬着约瑟的遗骸在西奈半岛上漂泊。后来，约书亚把约瑟的遗骸安葬在示剑（[[nav 24:32]]）。
考虑到四十年的西奈旷野漂泊——即以色列从埃及的奴役到应许之地的路程——是新约教会生活的预像：教会把人从罪的奴役中领出、引领人进入上帝所应许的天国；那么在这教会的整个生命时期，上帝的民始终带着义人的圣髑。旧约教会的预像，在到达自己的国之前，始终带着义人的圣髑。
### 扫罗
扫罗被非利士人杀死；雅比的居民烧了他们的身体，把骨头葬在自己城的柳树下：
> 1ts 31:10-13 :: !将他的尸身钉在伯珊的城墙上 :: !将扫罗和他儿子的尸身从伯珊城墙上取下来 :: !用火烧了 :: !将他们骸骨葬在雅比的垂丝柳树下 :: !就禁食七日
> 1par 10:12 :: !将他们的尸骨葬在雅比的橡树下
大卫把扫罗的遗骸迁到便雅悯地，与扫罗父亲的遗骸一同安葬：
> 2ts 21:12-14 :: !将扫罗和他儿子约拿单的骸骨搬了来 :: !大卫将扫罗和他儿子约拿单的骸骨从那里搬了来 :: !将扫罗和他儿子约拿单的骸骨葬在便雅悯的洗拉 :: !在扫罗父亲基士的坟墓里 :: !此后上帝垂听国民所求的
## 延迟安葬的情形
雅各的安葬是在77天多之后举行的：
| 约瑟伏在他父亲的面上哀哭，与他亲嘴。约瑟吩咐伺候他的医生用香料薰他父亲，医生就用香料薰了以色列。薰尸的常例是**四十天**；那四十天满了，埃及人为他**哀哭了七十天**。我父亲曾叫我起誓说：**你要将我葬在迦南地，在我为自己所掘的坟墓里**。现在求你让我上去葬我父亲，以后我必回来。法老说：你可以上去，照着你父亲所说的去葬他。于是约瑟上去葬他父亲。**与他一同上去的，有法老的一切臣仆**…… ||| ctb gen 50:1-3,5-13

# 约西亚王敬礼先知的圣髑
论到约西亚说：在他以前没有王像他、在他以后也没有兴起王像他，因为他尽心、尽性、尽力归向上帝（[[4ts 23:25]]）。犹大王约西亚自幼顺服上帝，成年后开始洁净自己的国家脱离异教：他摧毁异教的像、祭坛、烧香的异教邱坛、异教的神圣树丛，禁止祭司的事奉，消灭了行邪术的和交鬼的，洁净并修理了耶路撒冷上帝的圣殿，找到了圣经的书卷，向民众宣读，民众被带入与上帝所立的约。约西亚不但摧毁异教的邱坛，还力求玷污它们——把人的骨头撒在那里：
> 4ts 23:13-14 :: !王都污秽了 :: !将人的骨头充满了那地方
约西亚毁灭了耶罗波安的旧偶像，玷污了那里的坟冢：
> 4ts 23:15-16 :: !将坟墓里的骸骨取出来，烧在坛上，污秽了坛
然而，当他遇到一座纪念碑，查明那是预言了这些事件的先知的坟墓时，他就恭敬地对待他的圣髑。此外，纪念碑本身的存在，表明先前对先知的敬礼：
> 4ts 23:17-18 :: !我所看见的是什么碑 :: !这就是他的墓碑 :: !由他吧！不要挪移他的骸骨 :: !他们就不动他的骸骨
这同一位神人先前就预言了这件事将要发生：
> 3ts 13:2 :: !坛哪！坛哪 :: !大卫家里必生一个儿子，名叫约西亚 :: !人的骨头也必烧在你上面
# 西门敬礼亲人的遗骸
大祭司约拿单（[[1mak 10:20]]；[[1mak 11:57]]）被安葬在巴斯加玛。后来，他的兄弟、大祭司西门（[[1mak 13:36,42]]）把他的遗骸迁到祖城摩丁——此前犹大也被安葬在那里（[[1mak 9:19]]）。西门修建了一座高大的建筑，以此敬礼亲人的遗骸：
| 当他临近巴斯加玛时，将约纳堂杀死，就埋葬在那里。**息孟遣人去运回他兄弟的骨骸，将他埋葬在他祖先的摩丁城里。**全以色列都举哀痛吊他，哀哭多日。之后，息孟在他父亲与他兄弟们的坟墓上，用前后光泽的石头，修了一座相当高大的纪念碑，从远处可以望见。他为父母和四个兄弟，还立了七座金字塔，彼此相对；且为塔作了一些装饰品，就是在四周，立了一些大石柱，石柱上刻了武器，**作为永久的记念**；又在武器旁，彫刻了船像，使航海的人都可以看到。息孟在摩丁修建的**这座坟墓**，至今犹存。 ||| sb 1mak 13:23,25-30
