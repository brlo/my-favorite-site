圣经中所列的一些致死的罪：
> rim 1:29-32 :: !行这样事的人是当死的
> gal 5:19-21 :: !行这样事的人必不能承受上帝的国
> 1kor 6:9 :: !不义的人不能承受上帝的国
> ef 5:5 :: !在基督和上帝的国里都是无分的
> otkr 21:8 :: !他们的分就在烧着硫磺的火湖里，这是第二次的死
> otkr 22:14-15 :: !城外有那些犬类、行邪术的、淫乱的、杀人的、拜偶像的，并一切喜好说谎言编造虚谎的
> pr 19:5,9 :: !吐出谎言的，终不能逃脱 :: !吐出谎言的，也必灭亡
只要人还活着、还能进入基督的教会而悔改，一切罪都可以得到赦免。人将要受审判的，是他在身体中活着时所做的事：
> 2kor 5:10 :: !按着本身所行的
