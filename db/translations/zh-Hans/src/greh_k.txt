@@ родовые-грехи | QS19A_祖先的罪 | 祖先的罪（没有这样的罪） | | | 人/罪 | 祖先的罪（没有这样的罪） | 500
祖先的罪并不存在。这个概念是捏造出来的，通常是所谓「民间疗法师」、特异功能者和巫师使用的概念。教会有原罪的概念，但那是另一个概念（见[[ru:7XucD5kC_Всеобщность_первородного_греха|引文]]）。使人完全脱离原罪的，只有教会的圣洗礼，而不是巫师和特异功能者——他们在主耶稣基督道成肉身之前就有，却没有行出基督所行的事。
上帝向每个人追讨的是他自己的罪。然而，父母的义的生活或败坏的生活，其后果都会落在儿女身上。这好比：如果父母毁坏自己的健康（酗酒、吸毒），也就损害了自己孩子的健康，尽管孩子对父母毁坏健康并无过错。在上帝面前，孩子不为父母的酗酒承担责任。
这一思想可以从以下的圣经话语中详细明白：
> iez 18:2-10,12-30 :: !你们在以色列地怎么用这俗语说 :: !犯罪的他必死亡 :: !人若是公义，且行正直与合理的事 :: !遵行我的律例，谨守我的典章，按诚实行事，这人是公义的，必定存活 :: !他若生一个儿子作强盗，是流人血的 :: !他行这一切可憎的事，必要死亡，他的罪 :: !他若生一个儿子，见父亲所犯的一切罪，便惧怕 :: !就不因父亲的罪孽死亡，定要存活 :: !他必因自己的罪孽死亡 :: !儿子必不担当父亲的罪孽，父亲也不担当儿子的罪孽 :: !他必定存活，不至死亡 :: !他所犯的一切罪过都不被记念，因所行的义，他必存活 :: !他所行的一切义都不被记念，他必因所犯的罪、所行的恶死亡 :: !我必按你们各人所行的审判你们。你们当回头离开所犯的一切罪过
但人们常常产生这样的想法：父母的罪责似乎还是会传给儿女。这想法是在读到以下圣经经文后产生的：
> ish 20:5-6 :: !恨我的，我必追讨他的罪，自父及子，直到三四代
这里所说的是那些一代又一代持续恨上帝的人：「直到三四代——恨我的」。这样的人要因他们对上帝的恨受罚。为什么？虽然主容忍了他父亲、祖父、曾祖父的仇恨，但这仇恨既然延续到第三四代，容忍就到了尽头，刑罚就临到他们。
叙利亚的圣埃弗雷姆：
<blockquote><p>第5-6节、13-14节、16-17节、22-26节。上帝在西奈山上赐下诫命，说：我是耶和华，必追讨恨我之人的罪，自父及子，直到三四代。<strong>上帝按自己的宽容容忍一个恶人，也容忍他的儿子和孙子；但他们若不悔改，就把刑罚加在第四代的头上，只要他在自己的恶行上与先祖相似。</strong></p></blockquote>
