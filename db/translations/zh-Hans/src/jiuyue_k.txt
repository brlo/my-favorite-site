## 上帝预先警告：他将因何把以色列从应许之地赶出
### 警告
犹太民族曾受到警告：他们得到上帝所应许的地，不是因为他们的义。先前的民族因罪恶满盈而从上帝的地土上被赶出。以色列被上帝领进这地时则受到警告：若他们也照样犯罪，上帝也必将他们从自己的地上赶出：
> vtor 7:1 :: !从你面前赶出许多国民 :: !共七国的民，都比你强大
> vtor 9:4-8 :: !你心里不可说：『耶和华将我领进来得这地，是因我的义。』 :: !乃是因这些国民的恶 :: !并不是因你的义，也不是因你心里正直 :: !你本是硬着颈项的百姓 :: !你当记念不忘，你在旷野怎样惹耶和华你上帝发怒 :: !要灭绝你们
> lev 18:3,24-28 :: !那里人的行为，你们不可效法 :: !在这一切的事上，你们都不可玷污自己 :: !故此你们要守我的律例、典章 :: !免得你们玷污那地的时候，地就把你们吐出
> vtor 28:15,58,63-64 :: !这以下的咒诅都必追随你 :: !你若不谨守遵行 :: !也要照样喜悦毁灭你们，使你们灭亡 :: !你们从所要进去得的地上必被拔除 :: !耶和华必使你们分散在万民中
### 以色列民所作的，甚至比先前因罪被赶出的那些民族更坏，因此也被赶出
> 4ts 21:9-11 :: !比耶和华在以色列人面前所灭的列国更甚 :: !比先前亚摩利人所行的更甚
> iez 16:23,34-35,45-48 :: !你行这一切恶事之后 :: !你这妓女啊，要听耶和华的话 :: !你母亲是赫人，你父亲是亚摩利人 :: !你的姐姐是撒玛利亚 :: !你的妹妹是所多玛 :: !你一切所行的倒比他们更坏 :: !你妹妹所多玛与他的众女，尚未行你和你众女所行的事
在耶稣基督被钉十字架之前，犹太民族所受的最大刑罚是约70年的期限——巴比伦之囚。而在弃绝并杀死基督之后，犹太民族被从自己的地土上赶出约2000年，圣殿至今没有归还。
