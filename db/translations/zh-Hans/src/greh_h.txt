# 骂人话的问题在哪里
骂人话（攻击性词汇）的问题在于：说话的人想显得、并自以为是恶的、有攻击性的、危险的、厉害的。恶的词汇只是达到这一目的的方式之一。人们还会加上恶的情绪、眼神、手势、衣着、纹身、习惯和其他一切自我表达的方式。但让我们回到话语本身。
话语由声音构成。声音的组合本身没有任何意义：它既不坏也不好。比如说，我们造一个词「阿木萨达尔」。「阿木萨达尔」暂时没有任何意义，因此既不算坏也不算好。但当社会中给某个词赋予了含义，人就会根据场合、根据他在这种场合想成为什么样的人，来选择带有不同含义的词。当人想显得有礼貌、有教养时，他使用有礼貌的词汇，即那些带有令人愉快的含义、表明我们和平的心态、谦卑、殷勤或类似品质的词。然而，当人想显得厉害、危险、恶毒或有攻击性时，他就转而使用攻击性的词汇，即那些带有攻击性、粗俗和其他负面含义的词，这些词立刻会表明：这样的人没有任何教养，也没有使他克制恶行的情绪——他想让周围的人觉得他是个危险、恶毒、有攻击性、狂躁、不安分的人，而这里没有任何好的东西。
此外，当人习惯于这种恶的状态时，就会对它产生依赖，如同对吸烟、饮酒的依赖，也如同对任何罪的恶习的依赖。结果，他会采取种种行动使自己进入这种恶的状态、在内心培养它：甚至独处时也骂人，听恶的音乐，用阴郁的符号填充自己和周围的空间。也就是说，这一切都是向恶的状态的运动，是在自己心里培养恶意的状态、愤怒的情欲，而主耶稣基督却教导我们：
> mf 5:22 :: !凡向弟兄动怒的 :: !凡骂弟兄是拉加的 :: !凡骂弟兄是魔利的 ~~ 「拉加」是侮辱人的称呼。
> mf 5:5 :: !温柔的人有福了，因为他们必承受地土
使徒也说：
