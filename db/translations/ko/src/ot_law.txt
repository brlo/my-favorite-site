# 구약에서 시체를 만지지 말라는 금지
시체를 만지면 사람은 부정해졌습니다(더럽혀졌습니다). 그러나 친족은 죽은 자기 살붙이를 만져도 더럽혀지지 않았습니다:
> lev 21:1-4 :: 죽은 자를 만짐으로 말미암아 스스로를 더럽히지 말려니와 :: 그의 살붙이인
> chis 9:6 :: 사람의 시체로 말미암아 부정하게 되어서
> chis 19:13 :: 죽은 사람의 시체를 만지고 자신을 정결하게 하지 아니하는 자는
> iez 44:25 :: 시체를 가까이 하여 스스로 더럽히지 못할 것이로되
> ag 2:13 :: 시체를 만져서 부정하여진 자가 :: 부정하리라
# 의인의 유해를 만지는 일

> 4ts 13:21 :: 시체가 엘리사의 뼈에 닿자 곧 회생하여 일어섰더라

# 신약에서 시체를 만지는 일
주 예수 그리스도께서는 야이로의 죽은 딸을 만지셨습니다:
> mk 5:41 :: 그 아이의 손을 잡고 이르시되
율법에 따르면 그리스도께서 십자가에서 돌아가셨을 때 이미 죽은 분으로서 아무도 그분을 만질 수 없었습니다. 친족인 하느님의 어머니만 그렇게 할 수 있었습니다([[lev 21:1-4]]). 그러나 우리는 신학자 요한과 니고데모와 아리마대 요셉을 정죄하지 않을 뿐 아니라, 아무것도 두려워하지 않고 우리 구세주를 섬긴 그들을 칭송합니다:
> mf 27:59-60 :: 요셉이
> mk 6:29 :: 요한의 제자들이

> act 20:9-10 :: 죽었는지라 :: 그 위에 엎드려 그 몸을 안고

# 누룩 — 모든 것에 영향을 주는 작은 것
신약 성경에서 누룩의 형상은 그 자체로 나쁘거나 좋은 것이 아니라, 작은 부분이 나머지 전체에 어떻게 영향을 주는지 보여 주는 데 쓰입니다. 가루에는 누룩을 조금 넣지만, 결국 온 덩어리를 부풀게 합니다.
주님께서는 누룩 말고도 소금의 형상을 자주 드시는데, 소금도 마찬가지로 다른 모든 것에 영향을 줍니다(썩지 않게 지켜 줍니다):
> mf 5:13 :: 너희는 세상의 소금이니
> mk 9:50 :: 너희 속에 소금을 두고
그런데 소금도 누룩처럼 구약의 제사에 쓰였습니다:
> lev 2:13 :: 네 모든 소제물에 소금을 치라 :: 네 모든 예물에 소금을 드릴지니라
# 누룩의 좋은 의미
## 누룩 — 하늘 나라
주 예수 그리스도께서는 누룩을 하늘 나라에 비유하십니다. 여기서도 작은 것이 모든 것에 영향을 줍니다:
> mf 13:33 :: !천국은 마치 여자가 가루 서 말 속에 갖다 넣어 전부 부풀게 한 누룩과 같으니라
> lk 13:20-21 :: !내가 하나님의 나라를 무엇으로 비교할까 :: !누룩과 같으니라
# 누룩의 나쁜 의미
## 누룩 — 이단의 가르침
주 예수 그리스도께서는 사도들에게 바리새인과 사두개인의 가르침이 해롭다는 것을 가리키십니다. 작은 것이 모든 것에 영향을 줄 수 있음을 보여 주시려고 누룩의 형상을 쓰십니다:
> mf 16:6,11-12 :: !바리새인과 사두개인들의 누룩을 주의하라 :: !바리새인과 사두개인들의 교훈을 삼가라고
## 누룩 — 외식
다른 때에 그리스도께서는 수많은 사람 앞에서 다시 누룩의 형상으로 바리새인들의 특징인 외식이 해롭다는 것을 가리키십니다. 여기서도 외식은 모든 것에 영향을 주는 작은 것입니다:
> lk 12:1 :: !바리새인들의 누룩 곧 외식을 주의하라
## 누룩 — 공동체 안의 회개하지 않는 음행자
사도 바울은 고린도 공동체에 회개하지 않는 음행자가 있다는 것을 나무라면서 누룩의 형상을 씁니다. 음행자는 공동체의 작은 부분이지만 공동체 전체에 영향을 줄 수 있습니다:
> 1kor 5:1,6-8 :: !적은 누룩이 온 덩어리에 퍼지는 것을 :: 새 덩어리가 되기 위하여 묵은 누룩을 내버리라 :: !악하고 악의에 찬 누룩으로도
사도는 누룩 일반이 아니라 악하고 악의에 찬 누룩을 없애라고, 곧 회개하지 않는 음행자를 공동체에서 내쫓으라고 합니다([[1kor 5:9,11]]). 여기서 사도는 빵에 대해 말하는 것이 아니라 구약의 의미를 풀어 줍니다:
> 1kor 5:7-8 :: !새 덩어리가 되기 위하여
> mf 16:11
## 누룩 — 공동체를 유대교로 끌어들이는 사람
사도 바울은 갈라디아 공동체에, 구원받으려면 모세 율법을 지켜야 한다고 가르치는 어떤 사람들이 그들 가운데 있는 것이 위험하다고 경고하며 누룩의 형상을 씁니다:
> gal 5:4-5,9-10,12 :: !적은 누룩이 온 덩이에 퍼지느니라 :: !너희를 요동하게 하는 자는 :: 너희를 어지럽게 하는 자들은 스스로 베어 버리기를 원하노라

> mf 12:1-2,7 :: 안식일에 :: 이삭을 잘라 먹으니 :: 무죄한 자를 정죄하지 아니하였으리라
## 이방인과 사귀며, 스스로도 이방인입니다
> act 10:27-28 :: 유대인으로서 이방인과 교제하며 가까이 하는 것이 위법인 줄은 너희도 알거니와 :: 하나님께서 내게 지시하사 아무도 속되다 하거나 깨끗하지 않다 하지 말라 하시기로
## 시체를 만집니다
주 예수 그리스도께서는 야이로의 죽은 딸을 만지셨습니다:
> mk 5:41 :: 그 아이의 손을 잡고 이르시되
율법에 따르면 그리스도께서 십자가에서 돌아가셨을 때 이미 죽은 분으로서 아무도 그분을 만질 수 없었습니다. 친족인 하느님의 어머니만 그렇게 할 수 있었습니다([[lev 21:1-4]]). 그러나 우리는 신학자 요한과 니고데모와 아리마대 요셉을 정죄하지 않을 뿐 아니라, 아무것도 두려워하지 않고 우리 구세주를 섬긴 그들을 칭송합니다.
> mf 27:59-60 :: 요셉이
> mk 6:29 :: 요한의 제자들이
> mk 15:45-46 :: 요셉이
> act 13:29 :: 나무에서 내려다가
## 주님께서는 간음하다 잡힌 여인을 놓아주십니다
율법은 간음한 자를 돌로 치라고 명하지만(레 20:10), 주님께서는 간음한 여인을 정죄하지 않으시고 놓아주셨습니다:
> in 8:11 :: !나도 너를 정죄하지 아니하노니 가서 다시는 죄를 범하지 말라
## 주님께서는 당신의 피를 마시라고 명하십니다
하느님께서는 피를 먹지 말라고 금하시지만(창 9:4; 레 3:17; 레 7:26; 레 17:14; 신 12:16), 마지막 만찬에서 제자들에게 “마시라, 이것은 내 피다”라는 말씀과 함께 잔을 주십니다:
> mf 26:26-28 :: !너희가 다 이것을 마시라 이것은 :: 나의 피
## 주님께서는 유다 지파에서 나시어 대제사장이 되셨습니다
율법은 제사장이 레위 지파, 아론의 집안에서만 나와야 한다고 명합니다:
> ish 29:9 :: 아론과 그의 아들들에게 :: 제사장의 직분을 맡겨
> ish 29:29 :: 아론의 성의는 후에 아론의 아들들에게 돌릴지니 그들이 그것을 입고 기름 부음으로 위임을 받을 것이며
그러나 주님께서는 유다 지파에서 나시어 대제사장이 되셨습니다:
> evr 7:14 :: !우리 주께서는 유다로부터 나신 것이 분명하도다 :: 이 지파에는 모세가 제사장들에 관하여 말한 것이 하나도 없고
## 참된 유월절 제물은 성전에서 바쳐지지 않습니다
유월절 제물은 예루살렘 성전에서만 바칠 수 있었습니다:
> vtor 16:5-6 :: 유월절 제사를 네 하나님 여호와께서 네게 주신 각 성에서 드리지 말고
> evr 13:12 :: !성문 밖에서 고난을 받으셨느니라
# 십계명도 모세 율법인가?
## 모세를 통해 주신 하느님의 율법 — 레위기의 모든 명령
[[en:Tc4m_The_Ten_Commandments|돌판의 계명]]을 비롯해 하느님의 많은 명령을 나열하는 레위기는 그것들을 **모세를 통해 세우신 여호와의 율법**이라고 부릅니다:
> lev 26:46 :: !여호와께서 :: !모세를 통하여 세우신 규례와 법도와 율법이니라
## 하느님께서는 당신의 모든 명령을 율법이라고 부르십니다
예를 들어 만나를 거두라는 명령도 하느님의 율법입니다:
> ish 16:4,28 :: !백성이 나가서 일용할 것을 날마다 거둘 것이라 :: !내 율법 :: !어느 때까지 너희가 내 계명과 내 율법을 지키지 아니하려느냐
출애굽기 16, 24, 31, 34, 35장; 신명기 4, 6, 10장.
## 새 율법은 더 이상 돌판이 아니라 마음에 기록됩니다
돌판에 기록된 것을 “율법”이라고 부릅니다:
> ier 31:33 :: !내가 나의 법을 그들의 속에 두며 그들의 마음에 기록하여
> 2kor 3:3 :: 그리스도의 편지니 :: !돌판에 쓴 것이 아니요 오직 육의 마음판에 쓴 것이라
## 그리스도께서는 십계명을 따로 구별하지 않고 계명들을 말씀하십니다
> mf 5:21,27,33,38,43 :: 살인하지 말라 :: 간음하지 말라 :: !헛맹세를 하지 말고 :: !눈은 눈으로, 이는 이로 갚으라 :: !네 이웃을 사랑하고 :: 네 원수를 미워하라
## 사도들은 십계명을 그냥 율법이라고 부릅니다
사도 야고보는 “살인하지 말라”는 계명을 어긴 사람이 율법을 범한 자라고 말합니다:
> iak 2:10-11 :: !간음하지 아니하여도 살인하면 율법을 범한 자가 되느니라
# 율법은 구원하지 못합니다
## 율법은 장차 올 좋은 일의 그림자이며 죄를 생각나게 하는 것입니다
> evr 10:1-3 :: !율법은 장차 올 좋은 일의 그림자일 뿐이요 참 형상이 아니므로 :: !죄를 기억하게 하는 것이 있나니
## 율법은 구원하지 못합니다. 율법을 아는 것도, 율법의 행위도
> gal 3:21 :: 만일 능히 살게 하는 율법을 주셨더라면 의가 반드시 율법으로 말미암았으리라
## 율법의 문자를 이루는 것은 구원하지 못합니다
> mf 5:20 :: 너희 의가 서기관과 바리새인보다 더 낫지 못하면 결코 천국에 들어가지 못하리라
> 1kor 13:1-3 :: 내가 :: 사랑이 없으면 소리 나는 구리와 울리는 꽹과리가 되고 :: 내가 내게 있는 모든 것으로 구제하고 또 내 몸을 불사르게 내줄지라도 사랑이 없으면 내게 아무 유익이 없느니라
## 율법을 어기면 정죄를 받습니다
> rim 2:12-13 :: 율법이 있고 범죄한 자는 율법으로 말미암아 심판을 받으리라
## 율법을 다 행하지 않는 자는 저주 아래에 있습니다
> gal 3:10-12 :: !누구든지 율법 책에 기록된 대로 모든 일을 항상 행하지 아니하는 자는 저주 아래에 있는 자라
## 율법은 아무것도 온전하게 하지 못했습니다
> evr 7:18-19 :: !연약하고 무익하므로 폐하고 :: !율법은 아무 것도 온전하게 못할지라
# 그렇다면 모세 율법은 왜 필요한가?
## 율법은 죄를 깨닫게 합니다
> rim 3:20 :: !율법으로는 죄를 깨달음이니라
> rim 5:20 :: !율법이 들어온 것은 범죄를 더하게 하려 함이라
## 율법은 죄인을 억제합니다(죄인에게 필요합니다)
> 1tim 1:9 :: 율법은 옳은 사람을 위하여 세운 것이 아니요 :: !오직 불법한 자와
## 율법은 구세주가 필요함(구세주를 기다림)을 보게 합니다
> rim 7:22-24 :: !오호라 나는 곤고한 사람이로다 이 사망의 몸에서 누가 나를 건져내랴
# 율법은 영원하지 않습니다
## 율법은 다 이루어질 때까지 있습니다
> mf 5:18 :: !다 이루리라
## 그리스도께서는 율법을 이루심으로 율법을 폐하셨습니다
> mf 5:17 :: !폐하러 온 것이 아니요 완전하게 하려 함이라
# 그리스도께서 율법의 시대를 끝내십니다
## 모세와 같은 선지자가 오리라는 예언
모세 율법이 세워지자마자, 장차 모세와 같은 선지자, 곧 **입법자**가 오리니 그의 말을 들어야 한다는 말씀이 나옵니다. 이것은 그리스도에 대한 말씀이었습니다:
> vtor 18:15 :: !나와 같은 선지자 하나를 :: !너희는 그의 말을 들을지니라
> act 3:22 :: !나 같은 선지자 하나를 세울 것이니 너희가 무엇이든지 그의 모든 말을 들을 것이라
> act 7:37 :: !하나님이 너희 형제 가운데서 나와 같은 선지자를 세우리라
하느님께서도 친히 같은 말씀으로 이것을 확인하십니다:
> mk 9:7; mf 17:5; lk 9:35 :: !너희는 그의 말을 들으라
## 그리스도께서는 율법을 “너희” 율법이라고 부르십니다
> in 8:17 :: !너희 율법에도
> in 10:34 :: !너희 율법에
## 율법은 세례 요한 때까지였습니다
> mf 11:12-13 :: !모든 선지자와 율법이 예언한 것은 요한까지니
## 율법은 그 자손이 오실 때까지 주어졌습니다
> gal 3:19 :: 율법은 :: !범법하므로 더하여진 것이라 :: !약속하신 자손이 오시기까지 있을 것이라
## 계명의 율법이 폐지되었습니다
> ef 2:14-16 :: !법조문으로 된 계명의 율법을 폐하셨으니 ~~ 러시아어 시노달 번역: “계명의 율법을 **가르침으로** 폐하셨으니”(ἐν δόγμασιν).
## 이제 율법에 대한 다툼은 쓸데없습니다
> tit 3:9 :: 분쟁과 율법에 대한 다툼은 피하라 이것은 무익한 것이요 헛된 것이니라
## 종의 멍에 — 모세 율법
> gal 5:1 :: !다시는 종의 멍에를 메지 말라
## 그리스도의 멍에는 다릅니다 — 가볍습니다
> mf 11:28-30 :: !나의 멍에를 메고 내게 배우라 :: !내 멍에는 쉽고 내 짐은 가벼움이라
## 새 율법, 그리스도의 율법은 사랑입니다
> rim 13:10 :: !사랑은 율법의 완성이니라
> gal 5:14 :: !온 율법은 네 이웃 사랑하기를 네 자신 같이 하라 하신 한 말씀에서 이루어졌나니

> gal 5:13 :: !너희가 자유를 위하여 부르심을 입었으나 :: !오직 사랑으로 서로 종 노릇 하라
## 죽음은 모세 율법을 어긴 데서가 아니라 믿음이 없는 데서 옵니다
> 1in 5:12 :: 아들이 있는 자에게는 생명이 있고 하나님의 아들이 없는 자에게는 생명이 없느니라
## 구원은 모세 율법의 행위와 상관없이 왔습니다
> rim 3:21-22 :: !이제는 율법 외에 하나님의 한 의가 나타났으니
> rim 8:1-2 :: !그러므로 이제 그리스도 예수 안에 있는 자에게는 결코 정죄함이 없나니 :: !그리스도 예수 안에 있는 생명의 성령의 법이 죄와 사망의 법에서 너를 해방하였음이라 ~~ 비잔틴 본문(다수 사본)에는 1절 끝에 “**육신을 따르지 않고 영을 따라 행하는**”이 있습니다.

> gal 3:2-3 :: !너희가 성령을 받은 것이 율법의 행위로냐 :: !성령으로 시작하였다가 이제는 육체로 마치겠느냐

> gal 5:22-23 :: !이같은 것을 금지할 법이 없느니라

# 안식일
## 하느님께서 안식일을 거룩하게 하셨습니다
세상을 창조하신 뒤 하느님께서는 일곱째 날(안식일)을 거룩하게 하셨지만 계명을 세우지는 않으셨습니다:
> gen 2:3 :: 하나님이 그 일곱째 날을 복되게 하사 :: 거룩하게 하셨으니 :: 그 날에 안식하셨음이니라
가까이에는 하느님께서 다른 명령을 주시는 곳이 많습니다:
> gen 1:28 :: 하나님이 그들에게 이르시되
> gen 1:29 :: 하나님이 이르시되
> gen 2:16-17 :: 여호와 하나님이 그 사람에게 명하여 이르시되
그러나 안식일에 대해서는 아무 명령도 주어지지 않습니다. 창조의 모든 날이 지난 뒤 안식하신 것은 사람이 아니라 하느님이라고 말합니다. 사람은 하느님께서 에덴 동산에 두어 일하게 하셨습니다:
> gen 2:5,8,15 :: 경작하며 지키게 하시고
하느님께서 머무시는 그 영원한 안식([[gen 2:3]])에 사람은 장차 들어갈 수 있을 뿐입니다. 그것도 모두가 아니라 하느님께서 친히 들이시는 이들만 들어갑니다:
> evr 4:3; ps 95:11; evr 3:11 :: 이미 믿는 우리들은 저 안식에 들어가는도다 :: 그들이 내 안식에 들어오지 못하리라
## 안식일에 일하지 말라는 계명이 생김
안식일의 쉼에 관한 계명은 선지자 모세 때 이스라엘 백성과 언약을 맺으면서 하느님께서 처음 세우셨습니다:
> ish 20:8-10; vtor 5:12-15; lev 19:3; lev 19:30 :: 엿새 동안은 힘써 네 모든 일을 행할 것이나 :: 일곱째 날은 :: 아무 일도 하지 말라
## 안식일의 쉼에 관한 계명을 세운 이유
계명을 세운 이유는 계명의 말씀 바로 뒤에 나옵니다. 그 이유는 이스라엘 백성이 애굽의 종살이에서 나온 것입니다.
> vtor 5:14-15 :: !네가 애굽 땅에서 종이 되었더니 :: !거기서 너를 인도하여 내었나니 그러므로 네 하나님 여호와가 네게 명령하여 안식일을 지키라 하느니라
그분은 그들에게 “안식일”을 주셨습니다. 곧 전에 없던 것을 주셨습니다:
> iez 20:10-12 :: !내가 그들을 애굽 땅에서 나와서 광야에 이르게 하고 :: 내 율례를 주며 :: !내 안식일을 주어
> vtor 5:2-3 :: 우리 하나님 여호와께서 호렙 산에서 우리와 언약을 세우셨나니 이 언약은 여호와께서 우리 조상들과 세우신 것이 아니요 오늘 여기 살아 있는 우리 곧 우리와 세우신 것이라
하느님께서 일곱째 날을 복되게 하신 것을 가리키는 다른 설명도 있습니다:
> ish 20:10-11; gen 2:3 :: 이는 :: !일곱째 날에 쉬었음이라 그러므로 나 여호와가 안식일을 복되게 하여
그러나 이 설명은 관련을 가리키지만, 여기서 주어지는 것은 명령의 이유가 아니라 바로 안식일에 복을 주신 이유입니다: “**그러므로 나 여호와가 안식일을 복되게 하여**”([[ish 20:10-11]]). 다른 구절에서는 바로 명령의 이유가 가장 분명하게 주어집니다: “**네가 애굽 땅에서 종이 되었더니 … 인도하여 내었나니 그러므로 … 명령하여**”([[vtor 5:14-15]]).
이처럼 안식일의 쉼은 하느님의 안식과의 관련도 가리키지만, 이스라엘 백성이 애굽의 종살이에서 풀려난 것 때문에 세워졌습니다.
## 계명의 율법은 폐지되었습니다
율법은 그리스도께서 오실 때까지 주어졌습니다:
> gal 3:19 :: !율법은 :: !범법하므로 더하여진 것이라 :: !약속하신 자손이 오시기까지 있을 것이라
계명의 율법은 그리스도의 가르침으로 폐지되었습니다:
> ef 2:14-16 :: !법조문으로 된 계명의 율법을 폐하셨으니
그리스도인들은 율법에서 벗어났습니다:
> rim 7:6 :: !우리가 얽매였던 것에 대하여 죽었으므로 율법에서 벗어났으니 :: 율법 조문의 묵은 것으로 아니할지니라
모세 율법의 폐지에 대한 자세한 설명: [[en:Ab21l_Abolition_of_the_Law_of_Moses|모세 율법의 폐지]]
## 그리스도께서는 안식일의 쉼을 어겼다는 고발에서 사도들을 변호하셨습니다
바리새인들은 주님과 사도들이 안식일의 쉼을 어겼다고 나무랍니다. 그리스도께서는 사도들을 무죄한 자라고 부르십니다:
> mf 12:2,7 :: 당신의 제자들이 안식일에 하지 못할 일을 하나이다 :: 너희가 알았더라면 :: !무죄한 자를 정죄하지 아니하였으리라
## 사도는 안식일의 쉼을 지키지 않는다고 그리스도인들을 비판하는 것을 금합니다
> kol 2:16 :: !누구든지 :: !너희를 비판하지 못하게 하라 :: !안식일을
# 주일
## 주님께서 나타나신 날
1. 주 예수 그리스도께서는 주간의 첫날, 곧 주일에 부활하시어 도마 없이 제자들에게 나타나셨습니다([[in 20:19]]).
1. 주일에 그분은 향유를 가져온 여인들에게([[mf 28:1,9]]), 막달라 마리아에게([[mk 16:9]]), 사도 베드로에게([[lk 24:34]]), 글로바와 누가에게([[lk 24:13-32]]) 나타나셨습니다.
1. 도마를 위해 구세주께서는 정확히 한 주 뒤, 다시 주님의 날에 나타나십니다([[in 20:26]]).
## 모임과 성체성혈성사를 거행하는 날
드로아에 이레 동안 머문 사도들은 일곱 날 가운데 안식일이 아니라 주일에 예배와 떡을 떼기 위해 모입니다:
> act 20:6-11 :: 드로아에 있는 그들에게 가서 이레를 머무니라 :: 그 주간의 첫날에 우리가 떡을 떼려 하여 모였더니 :: 우리가 모인 ~~ 그들은 이레 동안 드로아에 있었지만 떡을 떼려고 모인 것은 바로 주간의 첫날이었습니다.
사도는 주일(모이는 날)에 어려운 이들을 돕기 위해 돈을 조금씩 모아 두라고 합니다:
> 1kor 16:2 :: 매주 첫날에 너희 각 사람이 수입에 따라 모아 두어서
# 반론
교회에서 갈라져 나간 어떤 공동체들(주로 제칠일 안식일 예수재림교)은 계명([[kol 2:16]])을 거슬러, 교회가 안식일의 쉼을 지키지 않을 뿐 아니라 주일을 더 성대하게 기린다고 비난하며 주일을 기려서는 안 된다고 말합니다.
정교회에서는 사람이 평생 모든 날에 선한 일을 하라는 부름을 받으며, 특별한 날(토요일과 특히 주일)에는 개인의 선한 일뿐 아니라 **공동의 일**(그리스어 λειτουργία, 레이투르기아)로 기립니다. 주일은 예배를 위한 공동의 모임으로 기립니다. 다른 날에도 예배를 드리지만, 토요일과 특히 주일에는 더 성대한 특별 예배를 드립니다.
그리스도인에게 가장 중요한 사건은 그리스도의 파스카, 곧 주 예수 그리스도께서 죽은 자 가운데서 부활하신 일입니다. 이날을 축일 중의 축일, 경축 중의 경축이라 부릅니다. 왜냐하면:
> 1kor 15:14,17 :: 그리스도께서 만일 다시 살아나지 못하셨으면 :: 너희 믿음도 헛것이며
위에서 보았듯이 사도들은 바로 주일에 예배를 드렸습니다. 이날은 부활하신 주님을 만나는 기쁜 날이 되었습니다. 첫 그리스도인들도 그렇게 했습니다: [[ru:Евхаристия_в_воскресенье|주일의 성체성혈성사(러시아어)]]
또 콘스탄티누스 황제(4세기)가 쉬는 날을 토요일에서 주일로 옮겼다고 비난합니다([[act 20:6-11]]). 그러나 콘스탄티누스 황제는 토요일에 대해 아무 지시도 하지 않고, 한 주의 첫 쉬는 날, 곧 주일을 처음 정했습니다([[ru:Воскресенье_выходной_Указ_императора_Константина|자세히, 러시아어]]). 이 칙령 이전에 로마 제국에는 공통의 주간 휴일이 없었습니다.
이처럼 비판은 부드럽게 말해도 근거가 없습니다.
