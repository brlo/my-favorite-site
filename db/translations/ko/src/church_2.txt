# 머리말
먼저 짚어 둘 것은, 성경에는 자기 교회를 세우고 스스로 그 목자라고 선포한 예도 근거도 하나도 없다는 점입니다. 그리스도께서는 눈에 보이는 하나의 교회를 세우셨고 그 일치에 대한 당신의 뜻을 밝히셨습니다.
# 교회의 눈에 보이는 일치에 대한 그리스도와 사도들의 뜻
> in 17:20-21 :: !간구합니다 :: !이 사람들이 모두 하나가 되게 하여 주십시오 :: !이 사람들도 우리들 안에 있게 하여 주십시오. 그러면 아버지께서 나를 보내셨다는 것을 세상이 믿게 될 것입니다
> 1kor 1:10-13; 1kor 3:4 :: !호소합니다 :: !여러분은 모두 의견을 통일시켜 갈라지지 말고 :: !같은 생각과 같은 뜻으로 굳게 단합하십시오 :: 여러분이 서로 다투고 있다 :: 그리스도가 갈라졌다는 말입니까
하느님께서는 몸(교회)의 지체들을 분열이 없고 모두가 서로 돌보며 함께 아파하고 함께 기뻐하도록 배치하셨습니다:
> 1kor 12:13-14,21-26 :: 한 성령으로 세례를 받아 한 몸이 되었고 :: 몸은 한 지체로 된 것이 아니라 많은 지체로 되어 있습니다 :: !눈이 손더러 너는 나에게 소용이 없다고 말할 수도 없고 머리가 발더러 너는 나에게 소용이 없다고 말할 수도 없습니다 :: !하느님께서도 변변치 못한 부분을 더 귀중하게 여겨 주셔서 몸의 조화를 이루게 해 주셨습니다 :: !몸 안에 분열이 생기지 않고 :: 한 지체가 고통을 당하면 다른 모든 지체도 함께 아파하지 않겠습니까? 또 한 지체가 영광스럽게 되면 다른 모든 지체도 함께 기뻐하지 않겠습니까
몸의 이 여러 지체는 무엇입니까? 교회 안의 여러 직무와 은사입니다:
> 1kor 12:12,14,27-30 :: 몸은 하나이지만 많은 지체를 가지고 있고 :: 몸은 한 지체로 된 것이 아니라 많은 지체로 되어 있습니다 :: 여러분은 다 함께 그리스도의 몸을 이루고 있으며 :: 하느님께서는 교회 안에 다음과 같은 직책을 두셨습니다 :: 모두가 다 사도일 수는 없지 않겠습니까
이처럼 하느님께서는 이 모든 직무와 은사를 배치하셔서 몸에 분열이 없게 하셨고, 사도는 편지 첫머리에서 이 분열을 막습니다([[1kor 1:10-13]]). 곧 하느님께서는 일치를 원하실 뿐 아니라([[in 17:20-21]]) 일치를 돌보십니다. 여기서 하느님께 직무를 받은 사도는 눈에 보이는 일치를 돌보며 고린토 사람들이 눈에 보이는 분열을 만들지 못하게 합니다.
일치는 그리스도의 뜻이므로, 구원받는 사람은 하느님의 뜻을 실천하는 사람이라는 것을 이해해야 합니다([[mf 7:21]]).
# 그리스도의 적들은 그리스도의 뜻을 어기고 드러나게 교회의 경계 밖으로 나갑니다
그리스도의 적들은 사도들의 공동체에서 나갑니다:
> 1in 2:18-19 :: !벌써 그리스도의 적들이 많이 나타났습니다 :: !이런 자들은 본래 우리의 사람들이 아니었기 때문에 우리에게서 떨어져 나갔습니다. 만일 그들이 우리의 사람들이었다면 우리와 함께 그대로 남아 있었을 것입니다
그들은 그리스도를 섬기지 않습니다:
> rim 16:17-18 :: !남들을 분열시키고 죄짓게 하는 사람들을 경계하고 멀리하시기 바랍니다 :: !그런 자들은 우리 주 예수 그리스도를 섬기는 것이 아니라
# 교회의 본래의 눈에 보이는 일치
## 외부인은 따로 있었습니다
교회에는 처음부터 분명히 눈에 보이는 경계가 있었습니다:
> act 5:13 :: 다른 사람들은 신도들의 모임에 끼어 들 생각을 감히 하지 못하였다
## 공동의 재산
교회는 한 덩어리의 공동체였습니다:
> act 4:32 :: 한 마음 한 뜻이 되어 :: 모든 것을 공동으로 사용하였다
## 논란이 되는 문제의 공동 해결
교회에는 공동의 문제가 있고, 교회는 분명하고 눈에 보이는 공의회로 모여 함께 문제를 해결합니다:
> act 15:6,22 :: 사도들과 원로들은 이 문제를 검토하려고 회의를 열었다 :: 사도들과 원로들은 교회의 모든 신도들과 의논하여
## 공동의 규정
교회에는 모두에게 공통된 분명한 규정이 있습니다:
> act 16:4-5 :: 여러 도시를 두루 다니면서 :: 사도들과 원로들이 정한 규정들을 전해 주며 지키라고 하였다
## 파당으로 갈라지는 것을 금지함
교회에서는 갈라지려는 시도를 모두 막습니다:
> 1kor 1:10-13; 1kor 3:4 :: !호소합니다 :: !여러분은 모두 의견을 통일시켜 갈라지지 말고 :: !같은 생각과 같은 뜻으로 굳게 단합하십시오 :: 여러분이 서로 다투고 있다 :: 그리스도가 갈라졌다는 말입니까
## 하나의 신앙과 성사
교회에는 모두에게 공통된 분명한 신앙이 하나만 있습니다:
> ef 4:5 :: 믿음도 하나이고
> 2in 1:9 :: 그리스도의 교훈을 지키지 않고 지나치게 앞서 나가는 자는 누구든지 하느님을 모시지 않는 자입니다
구세주께서 말씀하시듯, 신앙은 사도들의 말을 따른 것입니다:
> in 17:20 :: 이 사람들의 말을 듣고 나를 믿는 사람들
교회는 장차 하나의 신앙에서 갈라져 나가려는 사람들이 나타나리라는 것을 알고 있었습니다. 이런 사람들은 교회라고 불리지 않습니다:
> iud 1:18-19 :: 분열을 일으킵니다
## 하나의 사제 품계
> act 20:17-18,28 :: 성령께서는 여러분을 감독으로 세우셔서 :: 교회를 보살피게 하셨습니다
[[ru:Таинство-Священства|신품성사]]에 관하여 자세히.
이처럼 교회는 분명하고 눈에 보이는 공동체(유기체)입니다. 교회에는 공통된 사도적 신앙이 하나 있고, 모두에게 공통된 규정이 있으며, 사도들이 세운 지도자들은 모든 면에서 일치해 있고, 지체들 사이에는 장벽이 없습니다.
# 교회의 경계와 성체성혈성사
구약의 교회는 신약의 교회와 달리 그리스도의 몸이라고 불리지 않았습니다. 신약의 교회는 신비로운 신인(神人)의 유기체, [[en:Cw7a_The_Church|그리스도의 몸]]입니다. 그러므로 교회의 경계는 몸의 경계가 있는 곳에 있습니다. 사람 몸의 경계는 어디입니까? 피가 도는 곳이 몸이고, 피가 돌지 않는 곳은 몸이 아닙니다. 피가 없으면 사람의 부분들에 생명이 없습니다. 잘린 손은 더 이상 몸의 일부가 아니며, 피가 흘러 들어오지 않아 곧 썩게 됩니다. 참된 성체성혈이 있는 곳에 몸, 곧 교회가 있습니다:
> 1kor 10:16-17 :: 그리스도의 피를 나누어 :: 그리스도의 몸을 나누어 먹는 것 :: 그 한 덩어리의 빵을 나누어 먹는 사람들이니 비록 우리가 여럿이지만 모두 한 몸인 것입니다
> 1kor 12:27 :: 여러분은 다 함께 그리스도의 몸을 이루고
> ef 2:13 :: 그리스도께서 피를 흘리심으로써 :: 하느님과 가까와졌습니다
그래서 사람들은 교회 안에서만 구원받습니다. 그리스도께서는 [[en:Cw7a_The_Church|몸, 곧 교회]]의 구세주이시기 때문입니다:
> ef 5:23 :: 당신의 몸인 교회의 구원자로서 :: 교회의 머리
[[en:Eucharist|성체성혈성사]]에 관하여 자세히.

사도들과 주교들은 서로 동등합니다. 사도들은 자기들 가운데 누가 가장 큰지 자주 다투었습니다. 그리스도께서는 서로 위에 권력을 찾지 말라고 하셨습니다:
> lk 9:46,48 :: 제자들 가운데 누가 제일 높으냐 하는 문제로 그들 사이에서 말다툼이 일어났다

> mk 9:34-35 :: 제자들은 길에서 누가 제일 높은 사람이냐 하는 문제로 서로 다투었기 때문에 :: 첫째가 되고자 하는 사람은 꼴찌가 되어 모든 사람을 섬기는 사람이 되어야 한다
사도 야고보와 요한이 그리스도의 나라에서 그분의 오른편과 왼편에 앉게 해 달라고 청했을 때 다른 사도들은 화를 냈습니다. 그리스도께서는 그들 모두에게 서로 위에 권력을 찾지 말라고 하셨습니다:
> mf 20:25-27 :: 그러나 너희는 그래서는 안 된다
여기에서도 마찬가지입니다: [[mk 10:41-44]]. 다른 모든 정교회에서 떨어져 나간 로마 교회는 사도 베드로의 특별한 권위를 내세웁니다:
> mf 16:19 :: 네가 무엇이든지 땅에서 매면 하늘에도 매여 있을 것이며
그러나 이 권위는 모든 사도에게 주어졌습니다:
> mf 18:18 :: 너희가 무엇이든지 땅에서 매면 하늘에도 매어 있을 것이며
> in 20:22-23 :: 누구의 죄든지 너희가 용서해 주면 그들의 죄는 용서받을 것이고
의미심장하게도 주님께서는 바로 사도 베드로의 발을 씻어 주시고 다른 사도들의 발도 씻어 주시며 본을 보이시고 권력욕을 경계하셨습니다:
> in 13:14-15 :: 내가 너희에게 한 일을 너희도 그대로 하라고 본을 보여 준 것이다
나중에 사도 바울로는 모임에서 사도 베드로를 책망하고([[gal 2:11]]), 예루살렘의 첫 사도 회의에서는 사도 야고보가 주재하며([[act 15:13,19]]), 사도 베드로 자신도 로마에서만이 아니라 예를 들어 안티오키아에서도 주교들을 세웠습니다.
사도들의 제자들은 주교들이 사도들의 후계자라고 씁니다. 사도들에게 해당하는 모든 것은 주교들에게도 해당합니다. 이에 관한 사도들의 제자들과 초기 그리스도인들의 글: [[ru:qeuY_Епископы__преемники_апостолов|주교는 사도들의 후계자]].

## 리옹의 이레네오(2세기): 성전은 천상 실재의 형상입니다
성전이 천상 실재의 형상대로 지어졌다는 것은 리옹의 성 이레네오(2세기)가 확인해 줍니다. 이레네오는 신학자 요한의 묵시록을 근거로, 지상의 것들이 하느님께서 창조하신 천상의 것들의 형상인 것이 합당하다고 말합니다:
<blockquote><p>“그러므로 그분께서는 이런 봉사가 필요하지 않으시지만 우리가 열매 없이 지내지 않도록 우리 자신을 위해 그것을 바치기를 바라십니다. 이처럼 말씀께서는 예물이 필요하지 않으셨지만, 백성이 하느님을 섬기는 법을 배우도록 예물을 바치라는 바로 그 계명을 주셨습니다. 그러므로 <strong>우리도 제단에 예물을</strong> 자주, 끊임없이 <strong>바치는 것</strong>이 그분의 뜻입니다. <strong><mark>그러므로 제단은 하늘에 있습니다</mark></strong>(우리의 기도와 봉헌이 그곳을 향하기 때문입니다). <strong><mark>성전도 그러합니다</mark></strong>. 요한이 묵시록에서 “하느님의 성전이 열리고”(묵시 11:19)라고 말하는 대로입니다. 장막도 그러합니다. “보라, 하느님의 장막이 사람들과 함께 있다”(묵시 21:3)고 하기 때문입니다. 예물과 봉헌과 모든 제사를 백성은 산에서 모세에게 보여 주신 대로 표상으로 받았으며, 이는 오늘날 모든 민족 가운데 교회에서 이름이 찬양받으시는 한 분 같은 하느님에게서 온 것입니다. <strong><mark>우리 둘레에 펼쳐진 지상의 것들이 천상의 것들의 표상인 것은 합당합니다</mark></strong>. 둘 다 같은 하느님께서 창조하셨기 때문입니다. <strong>달리는 그분께서 영적인 것들의 형상을 [우리가 이해하도록] 나타내실 수 없었을 것입니다</strong>.”</p></blockquote>
(<a href="https://bibleox.com/en/en/w/irenaeus-against-heresies-b4/">이단 반박 4권 18~19장</a>, 영어)
