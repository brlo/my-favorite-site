# 그리스도의 부활 뒤 하늘 실재의 변화
그리스도 이전에는 세상을 떠난 의인들의 혼이 하늘에서 하느님과 함께하는 삶에 이르지 못했다는 것을 확인하려면, 그리스도 이전과 그리스도의 부활 이후의 하늘 실재에 대한 묘사를 비교해 볼 수 있습니다.
그리스도 이전에 하늘 실재는 산 위에서 선지자 모세에게 보여졌습니다. 선지자가 본 모습대로 땅의 성전(성막, 성소)을 짓게 하려는 것이었습니다:
> ish 25:8-9,40 :: !그들이 나를 위하여 짓되 :: 성소를 :: !무릇 내가 네게 보이는 모양대로 :: 장막을 짓고 :: 지을지니라 :: 이 산에서 네게 보인 양식대로 할지니라
> evr 9:24 :: !참 것의 그림자인 손으로 만든 성소에
구약 성전의 [[ru:иерусалимский-храм|구조]]와 형상들을 살펴보면, 그리스도의 희생 이전에는 하늘에 하느님(보이지 않게)과 거룩한 천사들만 있다는 것을 알 수 있습니다([[3ts 6:29]]).
그리스도의 부활과 승천 뒤에는 인성으로 보이시는 하느님께서 하늘에 앉아 계시며([[ef 1:20-21]]; [[otkr 3:21]]), 그곳에는 여전히 천사들이 있고([[otkr 8:3]]; [[otkr 15:6]]), 의인들의 혼도 나타납니다([[otkr 6:9-11]]; [[otkr 14:1,3-5]]). 우리는 이 새 하늘 실재를 신학자 요한의 계시록에서 봅니다.
이처럼 새 하늘 실재에는 하느님과 천사들 말고도, 그리스도의 부활 이전에는 그곳에 없던 의인들의 혼이 나타납니다.
## 구약 — 성전에는 하느님과 천사들만
그리스도의 희생 이전, 구약에서 하느님께서는 산 위에서 선지자 모세에게 성전을 보여 주시며, 땅에서 모든 것을 보여 주신 모습대로 만들라고 명하십니다([[ish 25:8-9,40]]; [[evr 9:24]]). 결국 모세는 하느님을 어떤 모습으로도 나타내지 않은 성전을 짓고, 하느님께서 나타나시는 곳(궤의 덮개) 둘레에는 천사들의 상을 두며, 모든 벽과 휘장에도 천사들의 형상이 있습니다.
### 보이지 않는 하느님
하느님의 명령으로 지은 구약의 성전에는 하느님의 형상이 없었습니다. 하느님은 보이지 않으셨기 때문입니다. 가장 중요한 곳에는 거룩한 물건들이 담긴 궤(상자)만 있었고, 그 덮개 위 두 그룹 사이에서 하느님께서 나타나시고 말씀하셨습니다:
> ish 25:22 :: 거기서 내가 너와 만나고 속죄소 위 곧 증거궤 위에 있는 두 그룹 사이에서
### 거룩한 천사들
성전은 곳곳이 천사(그룹)의 형상으로 가득했습니다:
> ish 25:18-20 :: 금으로 그룹 둘을 :: 속죄소 두 끝에
> 3ts 6:23,27 :: 내소 안에 감람나무로 두 그룹을 만들었는데 :: 솔로몬이 내소 가운데에 그룹을 두었으니
> 2par 3:14; gr 1mak 1:22 :: 휘장문을 :: 그 위에 그룹의 형상을 수놓았더라
> 3ts 6:29 :: 내 외소 사방 벽에는 모두 그룹들과 종려와 핀 꽃 형상을 아로새겼고
성전의 구조에 대해 자세히: [[ru:иерусалимский-храм|예루살렘 성전]] (러시아어)
## 신약 — 성전에는 하느님과 천사들과 의인들의 혼
하느님의 아들께서 사람이 되시고 죽음을 이기신 뒤, 우리는 다른 하늘 실재를 봅니다. 신학자 요한은 계시록에서 그것을 묘사합니다. 첫째, 하느님께서 보이게 되시고 보좌에 앉으십니다. 둘째, 이제 하늘에서는 천사들만이 아니라 거룩한 의인들의 수많은 혼도 그분을 섬깁니다.

# “내 영혼을 음부에 버리지 아니하시며” — 다윗에 관한 말씀이 아닙니다
다윗 왕이 시편에서 말한 예언([[ps 16:10]]), 곧 혼이 음부에 버려지지 않고 육신이 썩음을 당하지 않으리라는 예언은 다윗이 아니라 그리스도에 관한 것입니다. 그러므로 다윗 왕의 **육신**은 썩음을 당했고, 그의 **혼**은 그리스도께서 음부에 내려가실 때까지 음부에 남아 있었습니다.
> act 2:27,29,31,34 :: 조상 다윗에 대하여 담대히 말할 수 있노니 다윗이 죽어 장사되어 :: !그리스도의 부활을 말하되 그가 음부에 버림이 되지 않고 그의 육신이 썩음을 당하지 아니하시리라 :: 다윗은 하늘에 올라가지 못하였으나 ~~ 31절, 비잔틴 본문(다수 사본): “**그의 혼이** 음부에 버림이 되지 않고”(ἡ ψυχὴ αὐτοῦ).

## 종들은 서로 다르게 상을 받습니다
> lk 19:15-19 :: !열 고을 권세를 차지하라 :: !너도 다섯 고을을 차지하라
> mf 25:14-30 :: 자기 소유를 맡김과 같으니 :: 한 사람에게는 금 다섯 달란트를, 한 사람에게는 두 달란트를, 한 사람에게는 한 달란트를 :: 각각 그 재능대로 :: 다섯 달란트 받은 자는 바로 가서 그것으로 장사하여 또 다섯 달란트를 :: 그에게서 그 한 달란트를 빼앗아 열 달란트 가진 자에게 주라
*모두가 똑같이 상을 받는 포도원 품꾼의 비유([[mf 20:1-16]])는 바리새인들이 있는 자리에서 하신 말씀입니다([[mf 19:3]]). 일찍 와서 더 많이 수고한 이들이, 늦게 돌아와 덜 수고한 이들보다 자기를 높이지 않도록 하신 말씀입니다. 늦은 짧은 시간에도 필요한 것을 얻을 수 있으니 낙심하지 말아야 합니다.
