# 머리말
의로운 성인들과 천사들은 신이 아니라 하느님의 벗으로서 공경받습니다. 그들 자체 때문이 아니라 하느님께 참여하기 때문에, 그들 안에 사는 하느님의 은총 때문에 공경받습니다(글: [[ru:человек-храм-Божий|사람은 하느님의 성전]]). 성경에 따르면 영예는 하느님께만 드리는 것이 아니고, 사람들은 하느님께만 절하는 것이 아닙니다. 하느님 자신이 하느님께서 주시는 영광을 찾으라고 우리를 부르셨고, 의인들을 영광스럽게 하겠다고 약속하시고 그렇게 하셨으며, 교회는 하느님을 따라 거룩한 하느님의 벗들을 찬양합니다.
하느님께서는 성인들을 통해 그들의 생전에도, 그들의 **죽은 몸**([[4ts 13:21]])과 **개인 소지품**([[act 19:12]])과 **형상**([[act 5:15-16]])을 통해서도 은총을 보내십니다. 그래서 이 모든 것도 공경받습니다. 자세한 내용은 해당 글에 있습니다:
- [[en:Rl6c_Veneration_of_the_Relics_of_Saints|성인 유해 공경]];
- [[ru:иконы-иконопочитание-иконоборчество|성인 이콘 공경]].
# 영예는 하느님께만 드리는 것이 아닙니다

# 성인에게 드리는 절
십계명의 둘째 계명([[ish 20:4-5]]; [[vtor 5:8-9]])은 거짓 신(우상) 숭배를 금합니다. 거짓 신은 실제로 신이 아닙니다. 그들의 신성은 지어낸 것이고 환상이며 거짓입니다.
성인들은 실제로 존재하고 하느님의 벗이며, 신으로 숭배받지 않습니다. 성인에게 드리는 절은 하느님의 벗, 하느님의 종(천사), 하느님의 어머니인 그분들에 대한 존경의 표현입니다. 천사와 사람과 사물에게 드리는 이런 절은 성경에 나오며 우상 숭배가 아닙니다. 우상 숭배는 거짓 신, 곧 거짓을 숭배하는 것이기 때문입니다. 의인들은 사람에게는 사람으로서, 천사에게는 천사로서, 예언자에게는 예언자로서, 사물에게는 사물로서 늘 절합니다. 이 모든 경우에 그들은 신에게 하듯 절하지 않습니다.
## 천사의 모습으로 나타나신 하느님께 드리는 절
하느님께서 나타나셨지만 세 천사는 하느님의 실제 모습, 세상 창조 전부터 그러하신 모습이 아닙니다. 곧 이것은 하느님의 **형상**(그리스어 εἰκόνα, 이콘)이며, 아브라함은 하느님의 이콘 앞에 절합니다:
> gen 18:1-2 :: 여호와께서 :: 아브라함에게 나타나시니라 :: 사람 셋이 :: 몸을 땅에 굽혀
## 천사에게 드리는 절
> nav 5:14 :: 얼굴을 땅에 대고 엎드려 절하고
## 예언자에게 드리는 절
> 4ts 2:15 :: 땅에 엎드려 그에게 경배하고
## 성전을 향한 절
> ps 5:7 :: 성전을 향하여 예배하리이다
## 하느님의 발판(성전)에 드리는 절
> ps 99:5 :: 그의 발등상 앞에서 경배할지어다 :: 그는 거룩하시도다
> ps 132:7 :: 그의 계신 곳으로 들어가서 그의 발등상 앞에서 엎드려 예배하리로다
## 계약궤 앞의 절
> nav 7:6 :: 여호와의 궤 앞에서 땅에 엎드려
## 지팡이에 드리는 절
> gen 47:31; evr 11:21 :: 이스라엘이 침상 머리에서 하나님께 경배하니라 ~~ 칠십인역에는 “지팡이 끝에”(προσεκύνησεν Ισραηλ ἐπὶ τὸ ἄκρον τῆς ῥάβδου αὐτοῦ)로 되어 있습니다. 히브리서 11:21도 같습니다.
더 많은 예: [[ru:поклоны|절]].
## 묵시록에서 천사가 자기가 아니라 하느님께 경배하라고 명하는 까닭
사도 요한의 환시에서 하느님께서는 가까이 눈에 보이게 계십니다. 그런 상황에서 천사를 가장 중요한 이처럼 공경하는 것은 이상할 것입니다. 그래서 천사는 하느님께 경배하라고 부릅니다:
> otkr 19:10 :: 나는 너와 및 예수의 증언을 받은 네 형제들과 같이 된 종이니 삼가 그리하지 말고 :: !오직 하나님께 경배하라
> otkr 22:9 :: 나는 너와 네 형제 선지자들과 :: !하나님께 경배하라
다른 때에 천사는 예언자 눈의 아들 여호수아의 절을 받습니다:
> nav 5:14 :: 얼굴을 땅에 대고 엎드려 절하고
# 성인들은 영예를 누릴 것입니다
> 2tim 2:20-21 :: 귀하게 쓰는 것도 있고 :: !누구든지 이런 것에서 자기를 깨끗하게 하면 귀히 쓰는 그릇이 되어
> rim 2:10 :: !선을 행하는 각 사람에게는 영광과 존귀와 평강이 있으리니
# 주님께서는 의인들을 영광스럽게 하겠다고 약속하셨습니다
> 1ts 2:30 :: !나를 존중히 여기는 자를 내가 존중히 여기고
> in 12:26 :: !사람이 나를 섬기면 내 아버지께서 그를 귀히 여기시리라
> in 17:20,22 :: !내게 주신 영광을 내가 그들에게 주었사오니
> rim 8:29-30 :: !의롭다 하신 그들을 또한 영화롭게 하셨느니라
영광스럽게 하심은 무엇보다 기도의 성취와 행실을 통해 이루어집니다:
> in 14:13-14 :: 무엇을 구하든지 :: !내가 행하리니 :: !아버지로 하여금 아들로 말미암아 영광을 받으시게 하려 함이라 :: !내가 행하리라
그래도 결국 영광을 받으시는 분은 아버지이십니다. 다만 아들 안에서이니 아들도 영광을 받으십니다.
# 하느님께서 주시는 영광을 찾습니다
> in 5:44 :: !유일하신 하나님께로부터 오는 영광은 구하지 아니하니
> rim 2:5-8 :: !하나님의 의로우신 심판 :: 각 사람에게 그 행한 대로 보응하시되 :: !참고 선을 행하여 영광과 존귀와 썩지 아니함을 구하는 자에게는 영생으로 하시고

> rim 2:9-10 :: !선을 행하는 각 사람에게는 영광과 존귀와 평강이 있으리니

# 교회는 의인들을 찬양할 것입니다
| 이제 영광스러운 사람들을 찬양하자. … **주님께서는 큰 영광을 창조하셨고** 영원부터 **당신의 위엄을 나타내셨다** ||| gr prsir 44:1-2
| … **그들의 영광은 지워지지 않을 것이다**. 그들의 몸은 평화 속에 묻혔으나 그들의 이름은 대대로 살아 있다. 백성들은 그들의 지혜를 이야기하고 **회중은 그들의 찬양을 전한다** ||| gr prsir 44:13-15

## 하느님께서는 당신의 영광을 아무에게도 주지 않으신다
> is 42:8 :: 나는 내 영광을 다른 자에게, 내 찬송을 우상에게 주지 아니하리라
이것은 우상, 곧 거짓 신들에 관한 말씀입니다. 하느님께서 친히 사람들을 영광스럽게 하신다는 많은 구절이 위에 있습니다.
