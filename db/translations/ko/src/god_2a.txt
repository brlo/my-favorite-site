# 머리말
먼저 이 견해(그리스도가 대천사 미카엘이라는 견해)는 전체주의 분파인 “여호와의 증인”에게 있다는 것을 밝혀야 합니다. 여호와의 증인은 자기네 가르침을 뒷받침하려고 심각한 왜곡이 있는 자체 성경 번역을 만들었습니다(<a href="https://azbyka.ru/otechnik/sekty/rassuzhdaja-so-svideteljami-iegovy-pri-pomoshhi-pisanija/4_7">여호와의 증인 “신세계 번역”에 대한 전문가 평가</a>, 러시아어). 재림교도들도 구약에 대천사 미카엘로 나타나는 분이 하느님의 아들 예수 그리스도라고 믿습니다.
# “천사”라는 낱말의 두 가지 뜻
성경에서 천사라는 낱말은 두 가지 뜻으로 쓰입니다. 직무와 본성입니다.
천사의 **직무**는 보냄을 받는 것입니다. 이 고대 그리스어 낱말의 뜻이 문자 그대로 그렇기 때문입니다: ἄγγελος(앙겔로스) — 사자, 전령; 히브리어 ‏מלאך‏‎ — 사자.
천사의 **본성**은 몸이 없는 영입니다. 천사는 하느님께서 창조하신 영적 존재로서 몸이 없습니다. 곧 영입니다. 이 영들은 사람보다 먼저 창조되었고 자유와 이성을 받았습니다. 그 가운데 일부는 하느님께 순종하며 살기를 원하지 않아 그분에게서 떨어져 나갔지만 여전히 천사라 불립니다([[mf 25:41]]). 곧 활동 방식과 상관없는 본성이 있습니다. 보냄을 받든 받지 않든 천사입니다. 그것이 본성입니다. 그래서 사람에게서 태어난 분명한 사람인 예언자 세례 요한도 천사라 불립니다([[mal 3:1]]; [[mf 11:10]]; [[mk 1:2]]; [[lk 7:27]]). 같은 뜻으로 같은 곳에서 그리스도께서도 친히 계약의 천사라 불리십니다([[mal 3:1]]). (공동번역은 이 낱말을 “특사”, “사자”, “일꾼”으로 옮겼지만, 그리스어 본문에는 두 곳 모두 ἄγγελος가 있습니다: τὸν ἄγγελόν μου — “나의 천사”, ὁ ἄγγελος τῆς διαθήκης — “계약의 천사”.) 이제 인용구를 봅시다.
# 모든 천사는 섬기는 영이지만 그리스도께서는 옥좌에 앉아 계십니다
사도 바울은 하느님의 아들을 천사들보다 훨씬 뛰어난 분이라고 말합니다([[evr 1:4]]). 하느님께서 천사들에게는 아들에게 하시듯 말씀하지 않으시기 때문입니다([[evr 1:5]]). 모든 천사가 하느님의 아들에게 예배드릴 것입니다([[evr 1:6]]). 그는 천사들에 관한 하느님의 말씀과 아들에 관한 말씀의 차이를 지적합니다. 천사들은 섬기는 존재이고 아들은 옥좌에 앉으신 통치자이십니다([[evr 1:7-8]], [[evr 1:13]]). 창조된 모든 것은 일시적이지만 모든 것을 창조하신 하느님의 아들은 결코 사라지지 않으십니다([[evr 1:10-12]]). 끝으로 모든 천사는 예외 없이 섬기는 영이고 아들은 성부와 함께 옥좌에 앉아 계신다고 직접 말합니다:
> evr 1:13-14 :: 하느님께서 어느 천사에게 :: 내 오른편에 앉아 있어라 :: 천사들은 모두 하느님을 섬기는 영적인 존재들로서
아들은 섬김을 받으시고, 성부와 함께 다스리십니다.
# 사람들은 하느님 앞에 무릎을 꿇고, 모든 피조물은 그리스도 앞에 무릎을 꿇습니다
하느님께서는 당신 앞에 모든 무릎이 꿇을 것이라고 말씀하시는데([[rim 14:11]]), 동시에 사람뿐 아니라 모든 피조물이 그리스도 앞에 무릎을 꿇을 것이고([[fil 2:10]]), 거기에는 천사들도 포함됩니다([[evr 1:6]]).
# 세상은 천사가 아니라 그리스도께 복종합니다
> evr 2:5 :: 장차 올 세상을 천사들의 지배 아래 두시지는 않습니다
그런데 세상은 그리스도께 복종합니다:
> 1kor 15:27 :: 모든 것을 당신 발 아래 굴복시키셨다
> ef 1:22 :: 만물을 그리스도의 발 아래 굴복시키셨으며
> evr 2:8 :: 만물을 그의 발 아래 복종시키셨습니다
# 전능하신 분, 왕 중의 왕, 주 중의 주
이처럼 모든 천사는 섬기는 영이고, 하느님의 아들 예수 그리스도께서는 하느님께서 거듭 불리시는 이름, 곧 전능하신 분, 왕 중의 왕, 주 중의 주로 불리신다는 것을 확인했습니다. 예언자들은 **하느님**을 주 중의 주라 부릅니다([[ps 136:2-3]]). 사도들은 **하느님**을 주 중의 주, 왕 중의 왕이라 부릅니다([[1tim 6:15-16]]). 사도들은 **예수 그리스도**를 주 중의 주, 왕 중의 왕이라 부르고([[otkr 17:14]]; [[otkr 19:16]]), 전능하신 분이라 부릅니다([[otkr 1:8]]). 왕 중의 왕 위에 다른 왕은 없습니다. 주 중의 주 위에 다른 주는 없습니다. 전능하신 분 위에 그분을 붙드는 이는 없습니다. 그분께서 친히 모든 것을 붙들고 계시기 때문입니다. 대천사 미카엘은 천사 군대의 지휘자입니다. 그리스도께서는 천사들과 대천사 미카엘을 포함한 세상 모든 것의 지휘자이십니다.
# 하느님(야훼)께서 친히 예언자들을 보내셨는데, 그리스도께서는 당신이 보냈다고 말씀하십니다
그리스도께서는 이스라엘에 많은 예언자를 보낸 분이 당신이라고 말씀하십니다([[mf 23:34]]). 그리고 성경은 천사들을 통해서가 아니라 하느님께서 친히 예언자들에게 말씀하시고 친히 이스라엘에 보내셨다고 말합니다([[ish 3:12]]; [[mal 4:1,5]]; [[sud 6:8]]; [[2par 25:15]]; [[1ts 15:1]]; [[2ts 12:1]]; [[2ts 12:24-25]]; <a href="https://bibleox.com/ko/en-nrsv/3ezd/1/#L32">3에스 1:32</a>). 곧 그리스도께서는 하느님, 야훼이십니다. 하느님께서 예언자들과 소통하실 때 중개자는 없었습니다.
# 성부에게서 나신 하느님의 아들께서 천사들을 창조하셨습니다
그리스도께서는 천사들을 포함하여 보이는 것과 보이지 않는 모든 것의 창조주이십니다([[kol 1:13-17]]). 곧 천사라면 자기 자신도 창조했어야 합니다.
# “미카엘”이라는 이름의 어원
미카엘은 히브리어 이름으로, ‏מי כמו אלוהים‏‎(미 크모 엘로힘, 줄여서 “미카엘”), 문자 그대로 “누가 하느님과 같은가”에서 왔습니다. 곧 아무도 하느님과 같지 않으며 아무도 그분과 비교될 수 없다는 뜻입니다. 그러나 그리스도께서는 하느님과 같음을 빼앗은 것으로 여기지 않으십니다([[fil 2:6]]).
# 옛 계약은 천사들을 통해 주어졌고, 새 계약은 주님께서 전하셨습니다
사도 바울은 옛 계약과 새 계약의 차이를 지적합니다. 옛 계약은 천사들을 통해 주어졌고([[evr 2:2]]), 새 계약은 주님께서 친히 전하셨습니다([[evr 2:3]]). 곧 적어도 천사들을 통해서가 아닙니다.
# 사람이 되신 하느님께서 천사들에게 당신을 보이셨습니다
> 1tim 3:16 :: 그분은 사람으로 이 세상에 오셨고 :: 천사들이 그분을 보았습니다 ~~ 비잔틴 본문(다수 사본)에는 θεὸς ἐφανερώθη ἐν σαρκί — “**하느님께서** 육신으로 나타나셨고”라고 되어 있습니다.
아무도 하느님을 본 적이 없습니다([[in 1:18]]). 그분은 가까이 갈 수 없는 빛 가운데 계시고 사람은 하느님을 볼 수 없습니다([[1tim 6:16]]). 그러나 참 사람으로 태어나심으로써([[in 1:14]]) 하느님께서는 그리스도 안에서 모든 이에게 보이게 되십니다. 사람은 영적 세계의 주민(천사)을 육체의 눈으로 볼 수 없지만, 그리스도께서는 사탄이 하늘에서 떨어지는 것을 보았다고 말씀하십니다([[lk 10:18]]). 또한 천사들은 여러 때 여러 곳에서 여러 사람에게 나타나지만, 성경은 그 일(천사의 나타남) 자체에 아무 의미도 두지 않습니다. 곧 “그가 천사들에게 자신을 보였다”는 식으로 말하지 않습니다. 나타났고, 그뿐입니다.
# 천사들은 창조되었고 하느님의 아들은 나셨습니다. 그것도 그저 나신 것이 아니라 외아들로 나셨습니다
하느님의 아들은 창조된 것이 아니라 하느님에게서 나셨고, 창조된 모든 것은 그 뒤에 아들을 통해 창조되었습니다([[kol 1:15-16]]). 그리고 하느님의 아들은 외아들이십니다([[in 1:18]]). 이는 외아들처럼 성부의 아들인 이는 아무도 없다는 뜻입니다. 우리는 “창조하다”와 “낳다”라는 말을 구별합니다. 무엇이든 만들 수는 있지만, 낳는 것은 자기와 같은 본성을 지닌 것뿐입니다. 물고기는 물고기를, 사람은 사람을, 하느님은 하느님을 낳습니다. 올리브 나무가 오렌지를 낳지는 않습니다.

# 해마다 예루살렘에 올라감

> lk 2:41-42 :: 해마다 과월절이 되면 예수의 부모는 명절을 지내러 예루살렘으로 가곤 하였는데 :: 예년과 마찬가지로 예루살렘으로 올라 갔다

> lk 2:41-42,46-47 :: 열 두 살이 되던 해에도 :: 성전에서 :: 학자들과 한 자리에 앉아 그들의 말을 듣기도 하고 그들에게 묻기도 하는 중이었다. 그리고 듣고 있던 사람들은 모두 그의 지능과 대답하는 품에 경탄하고 있었다

> lk 2:51 :: 나자렛으로 돌아 와 부모에게 순종하며 살았다
# 나사렛에서 가파르나움으로: 전도의 시작
서른 살이 되어 예언자 요한에게 세례를 받으신 뒤에야 그리스도께서는 전도를 시작하시려고 나사렛을 떠나 가파르나움으로 옮기십니다:
> mf 4:12-13 :: 나자렛에 머물지 않으시고 :: 가파르나움으로 가서 사셨다
예언대로: [[mf 4:14-16]]; [[is 8:23]]; [[is 9:1]]
# 중요한 세부 사항
## 갈릴리 사람들은 예수를 목수의 아들로 잘 알고 있습니다
갈릴리에서 전도하실 때 사람들은 예수 그리스도를 평범한 목수, 목수의 아들로 잘 알고 있습니다:
> mk 6:3 :: 저 사람은 그 목수가 아닌가
> mf 13:55 :: 저 사람은 그 목수의 아들이 아닌가
## 율법을 지키려고 정기적으로 성전에 가심
율법을 지키시려고 그리스도께서는 한 해에 세 번 예루살렘 성전에 가셔야 했습니다:
> ish 23:17 :: 너희 남자들은 일 년에 세번
> ish 34:23 :: 모든 남자가 한 해에 세 번씩
> vtor 16:16 :: 너희 가운데 남자는 누구든지 일 년에 세 번, 과월절과 추수절과 초막절에
## 그리스도께서는 율법을 지키셨습니다
> mf 5:17 :: 율법이나 :: 없애러 온 것이 아니라 오히려 완성하러 왔다
> mf 3:15 :: 우리가 이렇게 해야 하느님께서 원하시는 모든 일이 이루어진다
> mf 26:24; mk 14:21 :: 사람의 아들은 성서에 기록된 대로 죽음의 길로 가겠지만
> lk 24:44 :: 모세의 율법과 예언서와 시편에 나를 두고 한 말씀은 반드시 다 이루어져야 한다
> gal 4:4 :: 여자의 몸에서 나게 하시고 율법의 지배를 받게 하시어
## 전도할 나이를 기다리심
그리스도께서는 서른 살까지 전도와 기적을 삼가셨습니다. 공적 봉사는 하느님의 규정과 확립된 전통에 따라 서른 살에 시작되었기 때문입니다([[chis 4:3]]). 그러므로 율법을 없애러 오신 것이 아니라 완성하러 오신 그리스도께서는([[mf 5:17]]) 서른 살까지 기다리신 뒤 전도에 나서셨습니다:
> lk 3:23 :: 서른 살 가량 되어 전도하기 시작하셨는데
그리스도께서는 당신의 때가 오기를 기다리셨습니다:
> in 2:4 :: 아직 제 때가 오지 않았습니다
> in 7:30 :: 예수의 때가 아직 이르지 않았던 것이다
> in 8:20 :: 때가 오지 않았던 것이다
> in 7:6 :: 나의 때는 아직 오지 않았다
> in 7:8 :: 아직 나의 때가 되지 않았으니
> lk 12:50 :: 이 일을 다 겪어 낼 때까지는 내 마음이 얼마나 괴로울지 모른다
> in 17:1 :: 아버지, 때가 왔습니다
