공동번역은 “다른 언어”(ἑτέραι γλῶσσαι, γλῶσσαι)를 사도행전에서는 “외국어”로, 고린토 1서에서는 “이상한 언어”로 옮겼습니다. 그리스어로는 같은 말입니다.
# 하느님께서는 바벨에서 언어를 뒤섞으셨습니다
바벨탑 건설은 상징적으로 하느님 없이 자기 힘으로 하늘에 닿으려는 시도입니다. 이 일로 언어가 뒤섞이고 서로의 말을 알아듣지 못하게 되었습니다:
> gen 11:4-9 :: !꼭대기가 하늘에 닿게 탑을 쌓아 :: 사람들이 한 종족이라 말이 같아서 :: !사람들이 쓰는 말을 뒤섞어 놓아 서로 듣지 못하게 해야겠다 :: 야훼께서 온 세상의 말을 거기에서 뒤섞어 놓아
# 하느님께서는 교회 안에서 언어의 혼란을 극복하셨습니다
교회가 이루어지고 성령께서 내려오신 날, 하느님께서는 사도들에게 외국어의 은사를 주십니다:
> act 2:1-4 :: !그들의 마음은 성령으로 가득 차서 성령이 시키시는 대로 여러 가지 외국어로 말을 하기 시작하였다
# 다른 언어는 외국어입니다
다른 나라에서 온 사람들은 갈릴래아 사람들(사도들)이 외국어로 말하는 것을 보고 놀랐습니다:
> act 2:5-12 :: !사람들에게는 저마다 자기네 지방말로 들리므로 :: 지금 말하고 있는 저 사람들은 모두 갈릴래아 사람들이 아닌가 :: !바르티아 사람, 메대 사람, 엘람 사람 :: !메소포타미아, 유다, 갑바도기아, 본도, 아시아 :: !프리기아, 밤필리아, 에집트, 또 키레네에 가까운 리비야 :: !로마 :: !그레데 사람들과 아라비아 사람들 :: !우리는 저마다 자기네 말로 듣고 있지 않은가
# 모두에게 언어의 은사가 있는 것은 아닙니다
1. **모두가** 다른 언어를 아는 은사를 받는 것은 **아닙니다**.
1. 언어의 은사를 받은 이들은 **서로 다른** 언어를 압니다.
1. 언어의 은사를 포함한 모든 은사는 일의 **유익을 위해** 주어집니다.
> 1kor 12:4-10 :: !은총의 선물은 여러가지이지만 :: 직책은 여러가지이지만 :: !각 사람에게 각각 다른 은총의 선물을 주셨는데 :: !공동이익을 위한 것입니다 :: 지혜의 말씀 :: !이상한 언어를 말하는 능력을 ~~ 그리스어: “**여러 종류의** 언어”
> 1kor 12:28-31 :: !이상한 언어를 말하는 사람 :: !모두가 다 이상한 언어를 말할 수는 없지 않겠습니까
# 사도가 모든 사람에게 복음을 전하기에 그리스어 지식만으로는 충분하지 않았습니다
로마 군대의 지휘관은 사도가 가장 널리 쓰이는 그리스어를 아는 것에 놀랍니다. 곧 그리스어가 널리 쓰였더라도(공통어) 모두가 알아들은 것은 아닙니다.
모든 백성이 알고 존경하던 율법교사 가믈리엘([[act 22:3]])에게서 배운 사도 바울로는 학식이 높은 사람으로, 바리사이이자([[act 5:34]]) 그리스 철학자와 작가들을 인용하는 사람이었습니다([[act 17:28]] [1]; [[tit 1:12]] [2]). 그가 로마 지휘관에게 그리스어로 말을 겁니다. 지휘관은 사도 바울로가 그리스어를 아는 것에 놀랍니다:
> act 21:33,37 :: !당신은 그리이스말을 할 줄 아오
로마 지휘관은 유다인이 로마 제국에서 가장 널리 쓰이는 언어를 아는 것에 놀랍니다. 이것은 그 일이 **드물 때에만** 놀라운 일입니다. 그렇게 학식 있는 사람이 그리스어를 아는 것도 놀라운 일이라면, 대부분 평범한 어부로서 배우지 못한 소박한 사람들이었던 다른 사도들([[act 4:13]])이 그리스어를 자연스럽게 아는 일은 더 말할 것도 없습니다. 또 문제는 설교자(사도)가 언어를 알아야 한다는 것만이 아닙니다. 듣는 사람도 그리스어를 알아야 합니다.
그러므로 그리스어 지식만으로는 충분하지 않았고, 예수 그리스도의 생애와 부활과 가르침의 살아 있는 증인인 사도들에게는 그리스도에 대한 증언이 신앙과 함께 모든 민족에게 전해지도록 언어 지식을 비롯한 초자연적 은사가 필요했습니다.
# 다른 언어로 말하는 사람을 아무도 알아듣지 못하면 유익이 없습니다
> 1kor 14:6,9-13,16-17 :: !이상한 언어로 말한다고 하더라도 :: !내가 무슨 도움이 되겠습니까 :: 허공에다 대고 말하는 :: 갖가지 말 :: 뜻없는 말은 하나도 없습니다 :: !그것은 교회를 돕는 것이어야 합니다 :: 해석하는 능력 :: !남에게는 아무런 도움이 되지 못합니다
# 교회에서는 통역 없이 다른 언어로 말하지 마십시오
> 1kor 14:27-28,33 :: !해석할 사람이 없을 때에는 교회 안에는 그런 말을 쓰지 말고
예언자들이 하던 일은 설교였습니다:
> act 15:32 :: 예언자인 유다와 실라도 교우들을 여러 말로 격려하며
# 다른 언어보다 예언(설교와 해석)의 은사를 더 구하라는 권고
> 1kor 14:1-5,39 :: !성령의 선물을 간절히 구하십시오. 특히 하느님의 말씀을 받아 전하는 은혜를 간절히 구하십시오 :: 키워주고 :: 격려해 주고 :: 위로해 주려고 :: !말씀을 받아서 전하는 사람은 교회에 도움을 줍니다 :: !그보다는 하느님의 말씀을 받아 전할 수 있으면 더 좋겠습니다 :: !이상한 언어로 말하는 사람보다는 하느님의 말씀을 받아 전하는 사람이 더 위대합니다 :: !하느님의 말씀을 받아 전하는 은혜를 간절히 구하십시오
# 언어는 그칠 것입니다

> 1kor 13:1-2,13 :: !내가 인간의 여러 언어를 말하고 :: !사랑이 없으면 :: !사랑이 없으면 나는 아무것도 아닙니다 :: 가장 위대한 것은 사랑입니다
# 사도들이 주지 않은 다른 영
> 2kor 11:4 :: 다른 예수 :: !여러분이 받은 성령과는 다른 것을 주며 :: 다른 복음
# 오늘날 선교사들은 언어를 배웁니다
옛날에 사도들과 첫 그리스도인들은 아직 아주 작은 교회가 널리 퍼져 모든 민족에게 복음을 전할 수 있도록, 비상한 필요 때문에 외국어의 은사를 받았습니다. 그러나 오늘날 선교사들은 언어를 배워야, 곧 수고해야 합니다. 이를 위한 수단은 이제 다 있고, 없는 것이 있다면 열의뿐입니다.
그리스도를 믿는 사람들의 단체 가운데(은사주의자와 오순절파) 다른 언어와 그 해석의 은사가 있다고 주장하는 이들이 있지만, 그들이 외국에 가면 외국인들은 그들의 말을 알아듣지 못합니다. 그래서 그런 선교사들은 모국어로 말하거나 교재와 교사의 도움으로 평범하게 언어를 배워야 합니다.
우리 시대에는 이 은사가 거의 없습니다. 정교회에는 20세기 성인 아토스의 성 파이시오스가 있습니다. 그는 모국어(그리스어) 외에 다른 언어를 배운 적이 없고 다른 언어의 은사가 있다고 주장하지도 않았지만, 외국인들이 찾아오면 통역 없이 프랑스어로, 또 다른 때에는 영어로 그와 이야기할 수 있었습니다.
# 비판
## 고린토 1서 14장 본문에 관한 여러 질문
고린토 1서 14장에 관해서는 질문이 많으므로 장 전체를 차례로 살펴보는 것이 좋습니다. 이 일은 [[ru:K5Ou_Иные_языки_древних_христиан_и_позднейшие_симуляции|별도의 글]]에서 다룹니다.
## 언어는 오는 세상에서야 그치는가?
정교인들은 오순절파와 은사주의자들에게 언어가 그칠 것이라는 사도 바울로의 말씀([[1kor 13:8]])을 가리켜 보입니다. 곧 이 은사는 멈출 것입니다. 물론 완전히 사라지지는 않습니다. 정교회의 매우 드문 현대 성인들에게 외국어를 말하는 은사가 있었음이 알려져 있습니다. 그러나 대체로 첫 그리스도인들에게서 보는 것과 같은 대규모 현상은 더 이상 없을 것입니다.
이에 대해 신개신교 오순절파는 언어가 그리스도의 재림 뒤 오는 세상에서야 그친다고 대답합니다. 그들 가운데 일부는 이 의견의 근거를 “완전한 것이 오면”이라는 이어지는 말씀([[1kor 13:10]])에서 찾습니다.
이 본문을 더 넓은 문맥에서 살펴봅시다:
> 1kor 13:8-13 :: 사랑은 가실 줄을 모릅니다 :: !말씀을 받아 전하는 특권도 사라지고 이상한 언어를 말하는 능력도 끊어지고 :: !지식도 사라질 것입니다. 우리가 아는 것도 불완전하고 말씀을 받아 전하는 것도 불완전하지만 :: !완전한 것이 오면 불완전한 것은 사라집니다 :: 거울에 비추어 보듯이 희미하게 :: !지금은 불완전하게 알 뿐이지만
사도는 “완전한 것이 오면” “불완전한” 것이 사라진다고 말했습니다. 불완전한 것은 무엇입니까? **지식**입니다. 이 문장에서 사도는 “**지식**도 사라질 것”이라는 어려운 표현을 풀어 설명하기 시작합니다. 사라지는 것이 지식 자체(아무것도 모르게 된다는 뜻)가 아니라, 지금 가진 부분적인 지식이 사라지고 온전한 지식이 오리라는 생각을 전해야 합니다. 그는 바로 이 생각을 이어 갑니다.
1. 지금 지식은 이미 **부분적으로** 있고, 다른 지식은 예언을 통해 **부분적으로** 드러납니다.
1. “부분적”이 아닌 완전한 지식이 주어질 때가 올 것입니다.
1. 지금 지식은 흐린 거울을 들여다보듯 희미하게 얻어집니다.
여기서 사도는 언어의 은사가 아니라 지식을 말하고 있습니다. 그리스도인들은 외국어를 부분적으로 알지 않았습니다. 그랬다면 복음을 다른 종족과 민족들에게 온전히 전하지 못했을 것입니다. 그들은 언어의 은사를 완전히 지니고 있었습니다. 오순절에 예루살렘에 온 사람들이 사도들이 자기네 말로 말하는 것을 듣고 놀란 까닭이 바로 이것입니다([[act 2:5-12]]). 이것은 부분적인 것이 아니었습니다. 부분적인 것은 지식이었고, 지식뿐이었습니다. 사도가 이어서 논하는 것도 바로 지식입니다.
그러면 언어의 은사는 언제 그칩니까? 엄밀히 말해 여기에는 나오지 않습니다. 그칠 것이라고만 합니다. 20세기가 지난 지금 돌아보면 이 말씀은 꽤 일찍 이루어졌습니다. 복음이 널리 퍼지고 그리스도인이 아주 많아져 언어의 은사가 그토록 절실히 필요하지 않게 되었습니다. 절실히 필요한 것은 사랑이지 언어의 은사가 아닙니다. 그래서 그때부터 언어를 배우게 되었습니다.
사랑만이 영원 속에서 그치지 않는다는 말씀은 끝나는 것들이 영원 속에서 끝난다는 뜻이 아닙니다. 다른 모든 것은 언제든 끝날 수 있지만, 영원에 관해서는 사랑이 거기서 끝나지 않는다는 것만 말합니다. 사랑이 영원하며 오는 세상에서도 그치지 않는다는 데에는 논란의 여지가 없습니다.
사람들은 성경의 이 구절을 오순절파처럼 이해했습니까?
예를 들어 4세기에 요한 크리소스토모스는 언어의 은사가 그치는 일이 오는 세상이 아니라 지금 세상의 일이라고 보았습니다.
**성 요한 크리소스토모스(347년경~407년)**

## 사람의 언어와 천사의 언어
신개신교인들은 다른 언어가 다른 민족의 외국어라는 구절을 보면 이에 동의하면서도, 천사의 언어라는 은사도 있다며 다른 구절을 내놓습니다:
> 1kor 13:1 :: !인간의 여러 언어를 말하고 천사의 말까지 한다 하더라도
그러나 이 의견은 잘못입니다. 천사는 몸이 없는 영입니다. 그들에게는 발성 기관도, 혀도, 폐도, 성대도 없으며, 공기의 진동을 만들어 소통하기 위한 대기도 필요하지 않습니다. 그러므로 성대로 내는 어떤 사람의 소리도 천사의 언어일 수 없습니다. 천사에게는 살과 뼈로 된 몸이 없듯이 성대도 없습니다([[lk 24:39]]).
그러면 사도는 천사의 언어를 말하면서 무엇을 뜻합니까? 이것은 수사적 표현일 뿐입니다. 한쪽을 극도로 높인 다음 다른 쪽으로 낮추는 것입니다. 사도는 사랑 없는 은사가 빈 소리임을 보여 줄 뿐입니다. 고린토 사람들은 다른 민족의 언어를 말하는 것을 이미 대단하게 여겼기에, 사도는 더 높여서 천사의 언어로 말할 수 있다 해도 사랑이 없으면 아무 유익이 없다고 합니다.
이것은 사도의 수사적 표현일 뿐입니다. 성 요한 크리소스토모스의 글에서도 이를 읽을 수 있습니다.
**성 요한 크리소스토모스(347년경~407년)**
<blockquote><p>“여기서 그는 <strong>“천사의 언어”를 말하지만 천사에게 몸을 입히는 것이 아닙니다</strong>. 그의 뜻은 이렇습니다. ‘내가 천사들이 서로 말하듯이 말한다 해도, 이것이 없으면 나는 아무것도 아니고 오히려 짐이 될 뿐입니다.’ 다른 예를 하나 들면, 그가 “하늘과 땅과 땅 아래 있는 모든 것이 그분께 무릎을 꿇고”(필립 2:10)라고 말할 때 <strong>천사들에게 무릎과 뼈가 있다고 말하는 것이 아니라</strong>, 그들의 깊은 경배를 우리의 관습에 빗대어 나타내려는 것입니다. 여기서도 살로 된 기관을 뜻하여 “언어”라고 하는 것이 아니라, 우리에게 알려진 방식으로 천사들의 서로 간의 소통을 나타내려는 것입니다.”</p></blockquote>

# 하느님께서는 성전을 공경하라고 명하셨습니다
성전은 [[ru:храм-образ-небесной-реальности|천상 실재의 형상]]입니다. 하느님께서는 이 형상을 공경하라고 명하셨습니다:
> lev 19:30 :: 나의 성소를 소중하게 여겨라
> lev 26:2 :: 나의 성소를 어려워하여라
신약의 성전은 신학자 요한의 묵시록에 나오는 형상대로 지어집니다.
# 비판
## 사도들은 깨닫지 못해서 성전을 찾아갔는가?
사도들이 신앙 문제를 잘 깨닫지 못한 때도 있었습니다. 예를 들어 그들은 그리스도께서 예루살렘에서 왕이 되시리라 생각했고([[mk 10:37-39]]), 그리스도의 고난과 부활에 관한 말씀을 깨닫지 못하면서 묻기를 두려워했습니다([[mk 9:31-32]]; [[lk 9:45]]).
그러나 이 모든 일은 그리스도 부활 당일([[in 20:21-23]])과 부활 후 50일째([[act 2:1-4]])에 성령의 은사를 받기 전까지의 일입니다. 게다가 부활 뒤에 그리스도께서는 성경을 깨닫도록 그들의 마음을 열어 주셨습니다([[lk 24:45]]). 부활 전에도 그리스도께서는 반박할 수 없는 지혜를 사도들에게 주시겠다고 약속하셨고([[lk 21:15]]), 사도는 나중에 하느님께서 온갖 지혜와 총명을 넘치도록 주셨다고 전합니다([[ef 1:8]]). 사도 바울로는 자신이 말재주는 없어도 지식은 모자라지 않는다고 합니다([[2kor 11:6]]).
개신교인들은 신앙 문제에서 자기들이 사도들보다 “더 높은” 깨달음을 지녔음을 보이려고 성령이 사도들에게 내려오시기 전의 여러 일을 내세웁니다. 그러나 이는 옳지 않습니다. 교회는 그 뒤에 세워지고 갖추어졌으며, 그때 사도들에게는 더 이상 신앙을 잘못 이해하는 일이 없었습니다.
그러니 성령을 받은 뒤 사도들은 신앙 문제를 깨달았고 지식이 부족하지 않았습니다. 설령 무언가 깨닫지 못한 일이 있었더라도 주님께서 사라지신 것이 아니고 사도들을 가르쳐 주셨습니다. 예를 들어 주님께서는 환시를 통해 사도 베드로에게 백인대장 고르넬리오, 곧 유다인이 아닌 사람에게 세례를 주어야 함을 보여 주셨습니다. 이 일은 당시 교회의 일부 사람들을 당혹스럽게 했습니다.
## 하느님께는 성전이 아니라 영과 진리로 예배해야 하는가?
성경을 따르면 이 대화는 성전에 관한 것이 아니라 예배 장소에 관한 것입니다.
> in 4:19-20 :: 예배드릴 곳
사마리아 여인은 질문으로 그리스도를 어떤 틀 안에 넣습니다. 어디서 예배해야 합니까?
- 그리짐 산;
- 예루살렘 성전.
그러나 그리스도께서는 사람들이 산에서도 예루살렘에서도 아니라 영과 진리로 예배할 때가 오며 이미 왔다고 말씀하십니다:
> in 4:21-23 :: 이 산이다 또는 예루살렘이다 하고 굳이 장소를 가리지 않아도 될 때가 올 것이다 :: 진실하게 예배하는 사람들이 영적으로 참되게 아버지께 예배를 드릴 때가 올 터인데 바로 지금이 그 때이다
보시다시피 여기에는 성전 이야기가 없습니다. 성전에 관한 말씀이라고 생각하는 사람은 산에서 기도하는 것도 금해야 합니다. 그리스도께서 산도 말씀하시기 때문입니다. 그렇다면 성전을 금하는 사람들은 산도 금해야 합니다. 산에 사십니까? 기도하지 마십시오. 물론 이것은 합리적이지 않습니다.
그리스도께서 이 예배의 때가 이미 왔다고 말씀하신 점도 주목해야 합니다. 그럼에도 그리스도께서는 예루살렘 성전에 오셔서 그곳을 아버지의 집, 기도의 집이라 부르시고, 아무것도 기도를 방해하지 않도록 돌보십니다.
곧 영과 진리로 예배할 때가 이미 왔어도 성전이 폐지되지는 않았습니다. 이 집이 황폐하게 버려진 것은 이스라엘의 대다수가 구세주를 거부한 뒤의 일입니다. 그리스도께서는 포도밭을 이전 소작인들(구약의 사제직)에게서 빼앗아 다른 이들, 곧 사도들에게 주시고, 버리신 이들에게 그들의 집이 황폐해진다고, 곧 하느님의 은총이 떠난다고 말씀하십니다:
> mf 23:38 :: 너희 성전은 하느님께 버림을 받아 황폐해지리라
그리스도께서 십자가에서 돌아가신 뒤 바위가 갈라지고 휘장이 찢어진 것이 그 상징입니다:
> mf 27:51 :: 성전 휘장이 위에서 아래까지 두 폭으로 찢어지고 땅이 흔들리며 바위가 갈라지고
그때부터 그리스도인들은 온 세상 어디서나 기도했고, 건물 안에서도 밖에서도 어디서나 성체성혈성사의 새 제사를 바쳤습니다.
## 왜 성당이 필요한가? 휘장이 찢어졌으니(마태 27:51) 하느님께서 성전을 떠나신 것이 아닌가?
구원을 위해 성당(돌로 지은 건물)이 필요한 것은 아닙니다. 정교회의 많은 성인이 광야에서 구원받았습니다. 그러나 구원을 위해서는 성사에 참여해야 하고, 성사는 예배에서 거행되며, 예배에는 자연스러운 이유로 건물이 필요합니다. 필요할 때 정교회는 건물 없이도 지냅니다.
건물이 있으면 교회는 그곳을 하느님께 봉헌된 장소, 곧 성당으로 여깁니다. 이곳에서 사람들은 하느님의 이름을 부르고, 성사에서 하느님의 은총이 나타나며, 성체성혈성사 안에 그리스도께서 친히 계십니다. 그래서 정교인들은 이런 곳을 하느님께서 나타나시는 곳으로 특별히 공경합니다. 하느님 자신이 당신께서 나타나시는 곳을 공경하라고 요구하시고([[ish 3:5]]) 성전을 공경하라고 요구하시기 때문입니다([[lev 19:30]]; [[lev 26:2]]).
구약 성전의 찢어진 휘장은 구약 교회의 폐지를 가리킵니다. 곧 예루살렘 성전이 구약 교회(이스라엘)와 하느님이 만나는 곳으로서 하느님께 버림받았음을 가리킵니다. 포도밭은 구약 교회에서 거두어져([[mf 21:43]]) 그리스도께서 세우신 신약 교회에 주어졌고, 그리스도께서는 계약과 사제직을 바꾸셨습니다([[evr 7:12]]).
신약 교회는 버림받은 구약 교회의 성전을 쓰지 않고, 그곳에서 예배하지 않으며, 그곳에서 하느님께서 나타나시기를 기대하지 않습니다.
## 성전은 하나였고 파괴되었으니 성당을 지어서는 안 되는가?
성전이 파괴된 것은 처음이 아닙니다. 이미 두 번째 성전이었습니다. 그 전에는 이동식 성전인 회막이 있어서 이스라엘 사람들이 시나이 광야에서 옮기고 다녔습니다. 느부갓네살이 처음 성전을 파괴했을 때 하느님께서 성전 예배의 가능성을 거부하신 것입니까? 아니라면 나중에 로마인들이 다시 파괴했을 때 왜 그렇게 되어야 합니까?
그리스도를 거부한 유다인들은 예루살렘 성전에서만 기도하고 하느님께 예배할 수 있다고 생각했습니다. 그들은 첫 순교자 대보제 스테파노를 의회의 재판에 불러, 이곳이 파괴되고 관습이 바뀐다고 가르친다고 고발했습니다([[act 6:13-14]]). 대보제는 조상들의 역사를 자세히 이야기하며, 그들이 어디서나 기도하고 제물을 바쳤으며 어디에 있든 하느님께서 함께하셨음을 보여 주는 것으로 변론했습니다([[act 7:2-53]]).
끝으로 그는 이 성전도 조상 다윗의 바람과 기도에 따라 솔로몬이 지었지만, 하느님께서는 당신을 위해 집을 지을 필요가 없음을 분명히 하셨다고 가리킵니다:
> act 7:46-49 :: 다윗 :: 성전을 짓게 해 달라고 간구하였지만 :: 지극히 높으신 분은 사람의 손으로 지은 집에는 사시지 않습니다 :: 너희가 나를 위하여 어떤 집을 지어 줄 것이며 내가 쉴 곳이 어디냐
이처럼 옛 계약이 맺어지기 전에도 의인들은 어디서나 기도하고 제물을 바쳤습니다. 나중에 하느님께서는 이스라엘에게 성전 하나와 대사제 한 사람이 있는 중앙집중적 예배 형식을 정해 주셨습니다. 그들이 지리적으로 늘 가까이 있었기 때문입니다. 이런 형식은 하느님께서 바라시는 일치를 지키기 위한 것이었습니다.
그러나 주님께서는 예언대로([[is 66:18-21]]) 모든 민족을 교회로 부르시면서 어느 민족에게서나 어디서나 예배할 조건도 마련하십니다. 그분 자신이 대사제가 되시고(하느님으로서 어디에나 계십니다), 어느 한 사람이 아니라 많은 사도에게 은총을 보내시고 권한을 주시며([[mf 18:18]]), 성체성혈의 제사를 어떤 장소에 묶지 않으시고([[lk 22:19]]), 사도들을 온 세상에 보내십니다([[mk 16:15]]).
그리스도인의 예배는 바로 성체성혈성사를 중심으로 이루어집니다. 이를 위해 성당이 꼭 필요한 것은 아닙니다. 정교인은 예배를 드리려면 반드시 성당이 있어야 한다고 말하는 사람들은 우리가 가르치지 않는 것을 지어내는 것입니다. 필요할 때 예배는 병원, 군대, 감옥, 배와 비행기와 기차 안, 숲속 등 어디서나 드립니다.
우리는 구원을 위해 성당(돌로 지은 건물)이 필요하다고 가르치지 않습니다. 정교회의 많은 성인이 광야에서 구원받았습니다. 그러나 구원을 위해서는 성사에 참여해야 하고, 성사는 예배에서 거행되며, 예배에는 자연스러운 이유로 건물이 필요합니다. 필요할 때 정교회는 건물 없이도 지냅니다.
건물이 있으면 교회는 그곳을 하느님께 봉헌된 장소, 곧 성당으로 여깁니다. 이곳에서 사람들은 하느님의 이름을 부르고, 성사에서 하느님의 은총이 나타나며, 성체성혈성사 안에 그리스도께서 친히 계십니다. 그래서 정교인들은 이런 곳을 하느님께서 나타나시는 곳으로 특별히 공경합니다. 하느님 자신이 당신께서 나타나시는 곳을 공경하라고 요구하시기 때문입니다:
> ish 3:5 :: 네가 서 있는 것은 거룩한 땅이니
또 당신의 성전을 공경하라고 요구하십니다([[lev 19:30]]; [[lev 26:2]]).
그리스도의 신약 교회는 예루살렘에서만, 사마리아의 산에서만, 또는 성당에서만 예배할 수 있다고 가르치지 않습니다. 하느님께는 어디서나 예배하고 기도할 수 있습니다.
정교인들은 옛 계약에 들어가거나 모세의 율법을 지키려고 성당을 짓는 것이 아닙니다. 옛 계약은 끝났고 모세의 율법은 폐지되었습니다.
우리는 함께 모여 기도하고 제사를 바칠 장소를 짓습니다. 이런 장소를 짓는 것을 금한 사람은 아무도 없습니다.
구약의 성전은 개념으로서 중요합니다. 하느님께서는 천상 실재에 빗대어 그것을 지으라고 명하셨습니다. 곧 성전은 본래 하늘의 이콘이어야 했습니다.
성경의 모든 근거를 들어 자세히 다룬 글: [[ru:храм-образ-небесной-реальности|성전 — 천상 실재의 형상]].
구약 시대에 하느님께서는 보이지 않으셨고 하늘에는 천사들만 있었습니다.
신약에서 하느님이신 그리스도께서는 눈에 보이게 하늘의 왕좌에 앉으시고, 천사들 외에 사람들도 그곳에 있게 됩니다. 그래서 그리스도인들에게 모임 장소가 생기자 그들은 이전과 같은 하느님의 뜻대로, 성전이 하늘을 나타내도록 꾸몄습니다.
하늘이 달라졌으므로 성전도 달라졌습니다. 이제 성전은 사람이 되신 하느님을 나타내고, 천사들 외에 하늘의 다른 주민들, 곧 의로운 사람들도 나타냅니다.
하느님께서는 개신교인들이 자주 요구하는 것처럼 비어 있고 뜻 없는 공간을 만드신 적이 없습니다. 그분은 세상 자체를 우리가 보고 창조주에 관해 무언가를 배우도록 지으셨습니다. 곧 세상이 우리에게 설교합니다. 성전도 빈 흰 벽이 아니라 그리스도와 그분의 하늘 나라를 전하도록 꾸며집니다.
## 이콘을 기념하는 성당
정교회 성당은 오직 하느님의 이름으로 지어집니다. 안에서 드리는 예배는 오직 하느님께 드립니다. 기도의 95%는 하느님께, 나머지는 그분의 성인들, 곧 천사들과 하늘의 의인들에게 드립니다.
모든 성당은 거룩한 기념과 연결되어 있습니다. 예를 들어 그리스도의 변모나 승천을 기념하는 성당이 있습니다. 이것은 거기서 승천이나 변모라는 사건에게 기도한다는 뜻이 아닙니다. 어떤 이콘이 (기적적으로) 주어진 일이나 이콘과 관련하여 도시가 적에게서 구원받은 일을 기념하는 성당도 있습니다. 이것은 거룩한 기념입니다. 성당이 거룩한 기념의 이름을 가졌다고 해서 거기서 그 기념에게 기도한다는 뜻이 아닙니다. 모든 성당의 예배는 같습니다.
