# 십자가는 제단이며 위대한 성물입니다
주 예수 그리스도께서는 제단인 십자가에서 당신 자신을 제물로 바치셨습니다:
> evr 9:28
이를 확인해 주는 것이 그리스도의 십자가 희생의 구약적 예표, 곧 이삭의 희생입니다. 아브라함(아버지)이 이삭(외아들)을 제물로 바칩니다:
> gen 22:2 :: 네 사랑하는 독자 이삭 :: 내가 네게 일러 준 한 산 거기서 그를 번제로 드리라
> in 3:16 :: 독생자를 주셨으니
이삭은 자기가 바쳐질 제물의 나무를 지고 산에 오릅니다:
> gen 22:6 :: 그의 아들 이삭에게 지우고
> in 19:16-18 :: 자기의 십자가를 지시고
## 아브라함은 이삭을 제단에 올렸습니다
> iak 2:21 :: 그 아들 이삭을 제단에 바칠
> act 2:23 :: 못 박아 죽였으나
십자가에서, 제단에서처럼, 인류의 구원이 이루어집니다:
> ef 2:16 :: 십자가로 :: 원수 된 것을 십자가로 소멸하시고
## 제단은 지극히 거룩합니다
> ish 29:37 :: 지극히 거룩한 제단이 되리니 제단에 접촉하는 모든 것이 거룩하리라

한편 바벨론 왕 느부갓네살은 물론 우상 숭배자였습니다([[dan 3:1-6]]). 그에게 복종한다는 것은 땅과 재물 같은 외적인 것에 대한 그의 세속 권력을 인정한다는 뜻이었습니다. 느부갓네살이 유대인들에게 우상 숭배를 강요하기 시작하자, 바로 이 불경한 명령이 거부되었습니다:
> dan 3:14 :: 너희가 내 신을 섬기지 아니하며 내가 세운 금 신상에게 절하지 아니한다
그들은 그를 왕으로 인정하지만 복종하기를 거부합니다:
> dan 3:16-18 :: !느부갓네살이여 :: !왕이여 :: !우리가 왕의 신들을 섬기지도 아니하고 왕이 세우신 금 신상에게 절하지도 아니할 줄을 아옵소서
그 때문에 그들은 화덕에 던져졌습니다:
> dan 3:21-23 :: 맹렬히 타는 풀무불 가운데에 던졌더라
그리고 하느님의 천사가 그들을 해를 입지 않게 지켜 주었습니다:
| **주의 천사가** 아자리야와 그 동료들과 함께 화덕으로 내려와서 불꽃을 화덕 밖으로 몰아내고, 화덕 한가운데를 이슬 머금은 바람이 부는 것처럼 만들었다. **불은 그들에게 전혀 닿지 않았고**, 그들을 해치거나 괴롭히지도 않았다 ||| gr dan 3:49-50
젊은이들은 다른 신들을 섬기라는 이 왕명 하나만을 어겼습니다:
> dan 3:24,28-29 :: !사드락과 메삭과 아벳느고의 하나님을 찬송할지로다 :: !그가 그의 천사를 보내사 자기를 의뢰하고 그들의 몸을 바쳐 왕의 명령을 거역하고 그 하나님 밖에는 다른 신을 섬기지 아니하며 그에게 절하지 아니한 종들을 구원하셨도다
## 하느님께서는 외국 왕들에게서 구해 주셨습니다
> 4ts 19:32-36 :: 내가 나와 나의 종 다윗을 위하여 이 성을 보호하여 구원하리라 :: 여호와의 사자가 나와서 앗수르 진영에서 군사 십팔만 오천 명을 친지라
## 벌과 구원은 백성의 경건함에 달려 있었습니다
> ier 25:5-12 :: !너희는 각자의 악한 길과 악행을 버리고 돌아오라 :: !너희는 다른 신을 따라다니며 섬기거나 경배하지 말며 :: !너희가 내 말을 순종하지 아니하고 너희 손으로 만든 것으로써 나의 노여움을 일으켜 스스로 해하였느니라 :: !너희가 내 말을 듣지 아니하였느니라 :: 진멸하여 :: 칠십 년 동안 바벨론의 왕을 섬기리라 :: 칠십 년이 끝나면 내가 바벨론의 왕과 그의 나라와 갈대아인의 땅을 그 죄악으로 말미암아 벌하여
> ps 20:4 :: 네 마음의 소원대로 허락하시고

# 그리스도께서는 스승과 아버지라 불리지 말라고 명하십니다
> mf 23:2,5-9 :: 사람에게 랍비라 칭함을 받는 것을 좋아하느니라 :: !그러나 너희는 랍비라 칭함을 받지 말라 :: !땅에 있는 자를 아버지라 하지 말라
이 말씀은 지체를 잘라 내라는 말씀([[mf 5:29-30]])이나, 그리스도께서 평화가 아니라 칼을 주러 오셔서 가족을 갈라놓으신다는 말씀([[mf 10:34-35]])처럼 글자 그대로의 뜻이 아닙니다. 믿는 이들이 “스승, 스승”이라 불리기를 바라지 않고([[mf 23:7]]), 그런 호칭을 받아도 교만해져 자신을 높이지 않으며, 가장 높은 권위이자 참된 아버지와 스승은 하느님이심을 깨닫도록 겸손을 가르치시는 것입니다.
문맥에서 출발하여 뜻을 바르게 이해하는 것이 중요합니다. 그렇지 않으면 하느님께서 계명에서 부모라고 부르시는데도([[vtor 5:16]]) 자녀가 부모를 아버지라고 부를 수 없게 됩니다. 교회에 분명히 교사들이 있는데도 어떤 교사도 교사라고 부를 수 없게 됩니다. 성경을 보면 이런 말을 피하지 않았음을 알 수 있습니다.

# 하느님께서는 올바른 뜻으로(본성이 아니라 은총으로) “스승”과 “아버지”만이 아니라 “신”이라고까지 부르는 것을 허락하십니다
> ps 82:6-7 :: 너희는 신들이며
> in 10:34-35 :: 너희를 신이라 하였노라
그러나 그리스도께서는 우리 자신을 종이라 부르라는 계명을 주십니다([[lk 17:10]]).
