# 십자가는 제단이며 위대한 성물입니다
주 예수 그리스도께서는 제단인 십자가에서 당신 자신을 제물로 바치셨습니다:
> evr 9:28
이를 확인해 주는 것이 그리스도의 십자가 희생의 구약적 예표, 곧 이삭의 희생입니다. 아브라함(아버지)이 이삭(외아들)을 제물로 바칩니다:
> gen 22:2 :: 사랑하는 네 외아들 이사악 :: 내가 일러 주는 산에 올라 가 그를 번제물로 나에게 바쳐라
> in 3:16 :: 외아들을 보내 주시어
이삭은 자기가 바쳐질 제물의 나무를 지고 산에 오릅니다:
> gen 22:6 :: 아들 이사악에게 지우고
> in 19:16-18 :: 몸소 십자가를 지시고
## 아브라함은 이삭을 제단에 올렸습니다
> iak 2:21 :: 자기 아들 이사악을 제단에 바친
> act 2:23 :: 십자가에 못박아 죽였던 것입니다
십자가에서, 제단에서처럼, 인류의 구원이 이루어집니다:
> ef 2:16 :: 십자가에서 죽으심으로써 :: 원수되었던 모든 요소를 없이하셨습니다
## 제단은 지극히 거룩합니다
> ish 29:37 :: 그 제단은 가장 거룩한 것이 되어 제단에 닿는 모든 것이 거룩해지리라

> dan 3:16-18 :: !느부갓네살왕 :: !임금님 :: !임금님의 신을 섬기거나 임금님께서 세우신 금신상 앞에 절할 수 없습니다
그 때문에 그들은 화덕에 던져졌습니다:
> dan 3:21-23 :: 활활 타는 화덕 속에 집어 넣었다
그리고 하느님의 천사가 그들을 해를 입지 않게 지켜 주었습니다:

> dan 3:24,28-29 :: !사드락과 메삭과 아벳느고가 섬기는 신이야말로 찬양받으실 분이구나 :: !어명을 어기면서까지 목숨 걸고 당신만을 믿고 저희의 신 아닌 다른 신 앞에서는 절하지도, 섬기지도 않는 이 신하들을 천사를 보내시어 구해 내셨구나

# 그리스도께서는 스승과 아버지라 불리지 말라고 명하십니다
> mf 23:2,5-9 :: 사람들이 스승이라 불러 주기를 바란다 :: !그러나 너희는 스승 소리를 듣지 말아라 :: !이 세상 누구를 보고도 아버지라 부르지 말아라
이 말씀은 지체를 잘라 내라는 말씀([[mf 5:29-30]])이나, 그리스도께서 평화가 아니라 칼을 주러 오셔서 가족을 갈라놓으신다는 말씀([[mf 10:34-35]])처럼 글자 그대로의 뜻이 아닙니다. 믿는 이들이 “스승, 스승”이라 불리기를 바라지 않고([[mf 23:7]]), 그런 호칭을 받아도 교만해져 자신을 높이지 않으며, 가장 높은 권위이자 참된 아버지와 스승은 하느님이심을 깨닫도록 겸손을 가르치시는 것입니다.
문맥에서 출발하여 뜻을 바르게 이해하는 것이 중요합니다. 그렇지 않으면 하느님께서 계명에서 부모라고 부르시는데도([[vtor 5:16]]) 자녀가 부모를 아버지라고 부를 수 없게 됩니다. 교회에 분명히 교사들이 있는데도 어떤 교사도 교사라고 부를 수 없게 됩니다. 성경을 보면 이런 말을 피하지 않았음을 알 수 있습니다.
