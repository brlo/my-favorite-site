# 구원이란 무엇인가
구원은 하느님과 함께하는 영원한 생명, 죽음에서 건져짐, 새로운(변모된) 삶입니다.
## 하느님과 함께하는 영원한 생명
> mf 18:8 :: 영생에 들어가는 것이
> mf 19:17 :: 네가 생명에 들어 가려면
## 신화(神化, 테오시스)
> 2pet 1:3-4 :: 그의 신기한 능력으로 :: !신성한 성품에 참여하는 자가 되게 하려 하셨느니라
> fil 3:21 :: !우리의 낮은 몸을 자기 영광의 몸의 형체와 같이 변하게 하시리라
[[in 17:21-23]]; [[1in 3:2]]; [[ps 82:6]]; [[gal 2:20]]; [[rim 8:14,16]]

# 믿음만이 아니라 행위도 구원에 필요합니다
## 행위 없는 믿음은 구원하지 못합니다
> iak 2:1,14-20 :: !만일 사람이 믿음이 있노라 하고 행함이 없으면 무슨 유익이 있으리요 그 믿음이 능히 자기를 구원하겠느냐 :: !행함이 없는 믿음은 그 자체가 죽은 것이라 :: 귀신들도 믿고 떠느니라 :: !행함이 없는 믿음이 헛것인 줄을 ~~ 20절의 “헛것”은 비잔틴 본문(다수 사본)에서 νεκρά, 곧 “죽은 것”입니다.
## 불법을 행하는 많은 이가 멸망합니다. 그들은 믿었을 뿐 아니라 그리스도의 이름으로 기적까지 행했습니다
> mf 7:22-23 :: 많은 사람이 :: 선지자 노릇 하며 :: 귀신을 쫓아 내며 :: 많은 권능을 행하지 :: !내가 너희를 도무지 알지 못하니 :: !불법을 행하는 자들아 내게서 떠나가라
## 심판은 행위에 따라 이루어집니다
> mf 16:27 :: !각 사람이 행한 대로 갚으리라
> 2kor 5:10 :: !우리가 다 반드시 :: 그리스도의 심판대 앞에 나타나게 되어 :: !각각 선악간에 그 몸으로 행한 것을 따라 받으려 함이라
> ef 6:7-8 :: !각 사람이 무슨 선을 행하든지 종이나 자유인이나 주께로부터 그대로 받을 줄을 앎이라
> ps 62:12 :: !주께서 각 사람이 행한 대로 갚으심이니이다
> rim 2:6 :: !하나님께서 각 사람에게 그 행한 대로 보응하시되
> otkr 2:23 :: !내가 너희 각 사람의 행위대로 갚아 주리라
> otkr 22:12 :: !각 사람에게 그가 행한 대로 갚아 주리라
## 믿음으로만이 아니라 행함으로 의롭다 하심을 받습니다
> iak 2:21-26 :: 우리 조상 아브라함이 :: 행함으로 의롭다 하심을 받은 것이 아니냐 :: !사람이 행함으로 의롭다 하심을 받고 믿음으로만은 아니니라 :: 기생 라합이
## 참고 선을 행함으로 영생을 얻습니다
> rim 2:5-8 :: 하나님께서 각 사람에게 그 행한 대로 보응하시되 :: !참고 선을 행하여 영광과 존귀와 썩지 아니함을 구하는 자에게는 영생으로 하시고
## 영생을 얻으려면 선한 일에 부유해야 합니다
> 1tim 6:18-19 :: !선한 사업을 많이 하고 :: !참된 생명을 취하는 것이니라 ~~ 비잔틴 본문(다수 사본): “**영생을** 취하는”(τῆς αἰωνίου ζωῆς)
## 선한 일을 위하여 지음받았습니다
행위가 없다는 것은 자기에 대한 하느님의 뜻을 어기는 것입니다. 선한 행위가 없으면 사람은 자기의 사명, 곧 자기가 지음받은 목적을 이루지 못합니다:
> ef 2:10 :: !그리스도 예수 안에서 선한 일을 위하여 지으심을 받은 자니
## 고난을 참으며 그리스도를 따를 때 하느님 나라를 유업으로 받습니다
> rim 8:17 :: !상속자 :: !우리가 그와 함께 영광을 받기 위하여 고난도 함께 받아야 할 것이니라 ~~ 그리스어는 조건문입니다: εἴπερ συμπάσχομεν, “**만일** 우리가 그와 함께 고난을 받으면”.
## 사도는 복음 전파(행위)가 자기 구원에 도움이 되리라는 것을 압니다
> fil 1:19 :: 나를 구원에 이르게 할 줄
## 그리스도인의 의는 서기관과 바리새인의 의보다 나아야 합니다
> mf 5:20,22,28,34,39,44,48 :: !너희 의가 서기관과 바리새인보다 더 낫지 못하면 :: !결코 천국에 들어가지 못하리라
서기관과 바리새인은 말만 하고 행하지 않습니다:
> mf 23:2-3 :: !서기관들과 바리새인들이 :: !그들은 말만 하고 행하지 아니하며
*믿음은 행위가 있을 때 의로 여겨집니다. 사람은 믿음으로만이 아니라 행위로도 의롭다 하심을 받습니다([[iak 2:21-24]]).
## 의를 행하는 사람이 의롭습니다
> 1in 3:7-8 :: !의를 행하는 자는 그의 의로우심과 같이 의롭고 :: 죄를 짓는 자는 마귀에게 속하나니
## 의인도 겨우 구원받습니다
의인은 하느님의 의를 따라 행하는 사람입니다([[iez 33:13-16]]). 죄인은 하느님의 의를 거슬러 행하는 사람, 곧 죄를 짓는 사람입니다. 의인도 겨우 구원받습니다. 그렇다면 죄인은 아예 구원받지 못합니다:
> 1pet 4:18 :: !의인이 겨우 구원을 받으면
## 하느님을 안다고 말하면서 행위로는 그분을 부인할 수 있습니다
> lk 6:46 :: !내가 말하는 것을 행하지 아니하느냐
> tit 1:16 :: !하나님을 시인하나 행위로는 부인하니
하느님께서 기뻐하시지 않는 행위 가운데에는 이단([[gal 5:20]])과 믿는 이들 사이에 분열을 일으키는 일([[in 17:20-21]]; [[1kor 1:10]])이 있습니다.
## 죄인을 미혹된 길에서 돌아서게 하는 일은 허다한 죄를 덮습니다
참된 신자가 이웃을 미혹에서 돌아서게 하면, 그 일로 허다한 죄를 덮게 됩니다. 만일 구원이 믿음만으로 얻어진다면, 이웃을 돌아서게 한 일은 그 이웃에게만 도움이 될 뿐 돌아서게 한 사람에게는 아무것도 주지 못하고 그의 죄를 덮지도 못할 것입니다(이미 믿음으로 구원받았다면 무엇 하러 죄를 덮겠습니까?):
> iak 5:19-20 :: 미혹되어 진리를 떠난 자를 :: !죄인을 미혹된 길에서 돌아서게 하는 자가 그의 영혼을 사망에서 구원할 것이며 허다한 죄를 덮을 것임이라
## 하느님의 안식에 들어가기를 힘쓰라는 부르심
곧 힘쓰지 않으면 믿는 이들도 들어가지 못할 수 있습니다:
> evr 4:11 :: !저 안식에 들어가기를 힘쓸지니
## 덕과 영원한 나라에 들어감
믿는 이가 덕을 갖추면 열매 없는 사람으로 남지 않습니다. 덕에 굳게 서면 하느님 나라에 넉넉히 들어가게 됩니다. 그러나 덕이 없는 사람은 맹인입니다:
> 2pet 1:5-11 :: !너희 믿음에 덕을 :: 지식을 :: 절제를 :: 인내를 :: 경건을 :: 형제 우애를 :: 사랑을 :: !이런 것이 너희에게 있어 흡족한즉 너희로 우리 주 예수 그리스도를 알기에 게으르지 않고 열매 없는 자가 되지 않게 하려니와 :: 이런 것이 없는 자는 맹인이라 멀리 보지 못하고 그의 옛 죄가 깨끗하게 된 것을 잊었느니라 :: !더욱 힘써 너희 부르심과 택하심을 굳게 하라 :: 행한즉 :: !우리 주 곧 구주 예수 그리스도의 영원한 나라에 들어감을 넉넉히 너희에게 주시리라
이처럼 행위 없는 믿음도, 믿음 없는 행위도 구원하지 못합니다.
# 세례를 받은 뒤에도 믿는 이들은 여전히 죄를 지을 수 있으며 자기 안의 죄와 싸워야 합니다
> evr 10:26 :: 진리를 아는 지식을 받은 후 짐짓 죄를 범한즉
> 1in 1:8-9 :: 만일 우리가 죄가 없다고 말하면 스스로 속이고
> 1in 2:1 :: !너희로 죄를 범하지 않게 하려 함이라
> iak 4:1 :: !너희 중에 싸움이 어디로부터 다툼이 어디로부터 나느냐
> iak 5:14-16 :: 교회의 장로들을 청할 것이요 :: 믿음의 기도는 병든 자를 구원하리니 :: !혹시 죄를 범하였을지라도 사하심을 받으리라 :: 병이 낫기를 위하여 서로 기도하라 의인의 간구는 역사하는 힘이 큼이니라
> 1kor 15:34 :: !깨어 의를 행하고 죄를 짓지 말라 :: 하나님을 알지 못하는 자가 있기로
> ef 4:32 :: !서로 용서하기를
끝으로 주 예수 그리스도께서는 제자들에게 기도를 주시며 죄 사함을 청하라고 가르치십니다. 이것은 평생에 한 번 드리는 기도가 아닙니다. 제자들이 기도를 가르쳐 달라고 청하자 그리스도께서 이 본보기를 주셨습니다:
> lk 11:1-4; mf 6:7-13 :: !너희는 기도할 때에 이렇게 하라 :: !우리 죄도 사하여 주시옵고
# 구원은 한 번의 행위가 아니라 평생의 과정입니다
구원을 이루어야 합니다(그리스어 κατεργάζεσθε — 이루다, 행하다, 만들어 내다, 성취하다, 완수하다, 굴복시키다, 정복하다):
> fil 2:12 :: 두렵고 떨림으로 너희 구원을 이루라
사도는 세례받은 그리스도인들 속에 그리스도의 형상이 이루어지기까지 해산하는 수고를 합니다. 곧 그리스도께서는 그들 안에 저절로, 한순간에 형성되지 않았습니다:
> gal 4:19 :: 너희 속에 그리스도의 형상을 이루기까지 다시 너희를 위하여 해산하는 수고를 하노니
> 2tim 4:7 :: 나의 달려갈 길을 마치고
구원은 약속되었을 뿐 아직 받은 것이 아닙니다(“구원을 받았다”가 아니라 “구원을 얻으리라”):
> mf 10:22; mf 24:13 :: !끝까지 견디는 자는 구원을 얻으리라
> otkr 2:10 :: !네가 죽도록 충성하라 그리하면 내가 생명의 관을 네게 주리라
사도는 자기를 판단하지 않습니다. 하느님을 거스른 일을 스스로 알지 못하지만 그것으로 자기를 의롭다 하지 않고 하느님의 심판을 기다립니다:
> 1kor 4:1-5 :: 우리를 :: 하나님의 비밀을 맡은 자로 여길지어다 :: !맡은 자들에게 구할 것은 충성이니라 :: !나도 나를 판단하지 아니하노니 :: !다만 나를 심판하실 이는 주시니라 :: 때가 이르기 전 곧 주께서 오시기까지 아무 것도 판단하지 말라
## 그리스도인의 완전함에 이르는 길
사도는 모든 그리스도인과 마찬가지로 썩지 않을 관을 얻으려고 달음질하고 수고하며, 자신이 버림받지 않을까 두려워합니다:
> 1kor 9:25-27 :: 관을 얻고자 하되 :: 썩지 아니할 것을 얻고자 하노라 :: 그러므로 나는 달음질하기를 :: 내 몸을 쳐 복종하게 함은 :: !자신이 도리어 버림을 당할까 두려워함이로다
> fil 3:12-14 :: 내가 이미 얻었다 함도 아니요 온전히 이루었다 함도 아니라 :: 오직 내가 그리스도 예수께 잡힌 바 된 그것을 잡으려고 달려가노라 :: 나는 아직 내가 잡은 줄로 여기지 아니하고 :: 푯대를 향하여
## 구원받는 이들과 망하는 이들
구원받는 이들이 아직 구원받은 것이 아니듯, 망하는 이들도 아직 망한 것이 아닙니다. 둘 다 길 위에 있으며 둘 다 길을 바꿀 수 있습니다. 구원받는 이도 멸망에 이를 수 있고, 망하는 이도 구원에 이를 수 있습니다:
> 2kor 2:15 :: !구원 받는 자들에게나 :: !망하는 자들에게나
많은 이가 하늘 나라에 이르려고 애쓰지만 이르지 못할 것입니다:
> lk 13:24; mf 7:14; mf 7:13 :: 좁은 문으로 들어가기를 힘쓰라 :: !들어가기를 구하여도 못하는 자가 많으리라
믿는 이들 가운데 많은 이뿐 아니라 그리스도의 이름으로 기적을 행하는 이들조차 하늘 나라에 이르지 못합니다:
> mf 7:22-23 :: 많은 사람이 :: 선지자 노릇 하며 :: 귀신을 쫓아 내며 :: 많은 권능을 행하지 :: 내가 너희를 도무지 알지 못하니 :: 내게서 떠나가라

## 모든 이가 심판을 받습니다

> mf 7:22-23 :: 많은 사람이 :: 선지자 노릇 하며 :: 귀신을 쫓아 내며 :: 많은 권능을 행하지 :: 내가 너희를 도무지 알지 못하니 :: 내게서 떠나가라
# 비판에 대한 답변
## “믿는 자는 심판에 이르지 아니한다”
> in 5:24 :: 심판에 이르지 아니하나니
간단히 말하면, 이 말씀은 구세주의 말씀을 참으로 믿고 행하는([[lk 6:47-49]]; [[1in 2:17]]) 이들이 벌을 받는 정죄에 이르지 않는다는 뜻입니다. 그러나 누가 그렇게 믿고 행하는 사람인지는 그리스도께서 친히 심판 때에 판단하실 것입니다([[1kor 4:3-5]]). 위에서 보았듯이 모든 이에 대한 심판은 바로 교회에서 시작되며([[1pet 4:17-18]]), 모든 이가 심판을 받기 때문입니다.
좀 더 자세히 살펴보겠습니다.
이 구절은 성경 전체가 말하는 바에 비추어 이해해야 합니다. 성경은 구원을 위해 계명을 지키는 것도 필요하고([[lk 6:47-49]]; [[1in 2:17]]), 세례도 필요하며([[in 3:5]]), 성체성혈성사도([[in 6:53-54]]) 그 밖에 많은 것도 필요하다고 말합니다. 어떤 구절은 보면서 다른 구절에는 눈을 감아서는 안 됩니다.
구원에 필요한 다른 것들을 빼놓을 수 없으므로, 이 말씀은 세례를 통해 교회에 들어와 성체성혈성사에 참여하며 교회(그리스도의 몸) 안에서 살고, 계명을 지키며, 하느님의 뜻을 알고 그 뜻대로 사는 신자들에 관한 것입니다. 그들이 **그렇게 행한다면** 정죄의 심판에 이르지 않습니다. 그러나 그런 사람이 누구일까요? 심판자이신 그리스도께서 아십니다. 그러므로 우선 모든 이가 심판에 이르며, 이는 다른 곳에서 분명히 말씀하신 바입니다.
모든 이가 심판을 받습니다:
> 2kor 5:10 :: 우리가 다 반드시 그리스도의 심판대 앞에 나타나게 되어 :: 선악간에 :: 그 몸으로 행한 것을
여기서는 바로 **믿는 이들에 대해** 말합니다:
> rim 14:10 :: 형제를 비판하느냐 :: 형제를 업신여기느냐 :: 우리가 다 하나님의 심판대 앞에 서리라
> ekl 12:14 :: 하나님은 모든 행위와 모든 은밀한 일을 선악 간에 심판하시리라
모든 이가 심판받는다고만 말하는 것으로 충분하지 않습니다. 심판은 바로 교회, 곧 믿는 이들에게서 시작됩니다:
> 1pet 4:17-18 :: 하나님의 집에서 심판을 시작할 때가 되었나니 :: 만일 우리에게 먼저 하면
그러므로 믿고 행하는 사람(그가 누구인지는 심판자이신 그리스도께서 정하십니다)은 정죄의 심판에 이르지 않습니다.
이 **많은 신자들**은 분명히 자기가 구원받았으며 심판에 이르지 않으리라 생각했지만, 믿었음에도 불법을 행하는 자로 정죄받습니다:
> mf 7:22-23 :: 많은 사람이 :: 주여 주여 우리가 주의 이름으로 선지자 노릇 하며 :: 귀신을 쫓아 내며 :: 많은 권능을 행하지 :: 내가 너희를 도무지 알지 못하니 :: 내게서 떠나가라
이처럼 그리스도께서는 모든 이를 심판하시며, 심판 때에 그들을 서로 구분하실 것입니다:
> mf 25:31-32 :: 인자가 :: 자기 영광의 보좌에 앉으리니 :: !모든 민족을 그 앞에 모으고 :: !각각 구분하기를 :: !목자가 양과 염소를 구분하는 것 같이
## “사람이 의롭게 되는 것은 율법의 행위로 말미암음이 아니요”
> gal 2:16 :: !사람이 의롭게 되는 것은 율법의 행위로 말미암음이 아니요 오직 예수 그리스도를 믿음으로 말미암는 줄 :: !율법의 행위로써가 아니고 :: !율법의 행위로써는 의롭다 함을 얻을 육체가 없느니라
여기서 말하는 것은 모세 율법의 행위이며, 그것으로는 의롭게 될 수 없습니다. 갈라디아서에서는 이것이 중심 주제이며, 그 계기는 이방인에게 할례가 필요한가 하는 논쟁이었습니다. 할례는 필요하지 않습니다. 우리는 모세 율법의 행위가 아니라 그리스도를 믿는 믿음과 그리스도를 믿는 이 믿음의 행위로 구원받기 때문입니다(<a href="#HH-믿음만이-아니라-행위도-구원에-필요합니다">행위가 필요하다는 구절들</a>을 보십시오).
## “너희는 그 은혜에 의하여 믿음으로 말미암아 구원을 받았으니”
> ef 2:5,8-9 :: 은혜로 구원을 받은 것이라 :: 그 은혜에 의하여 믿음으로 말미암아 구원을 받았으니 :: 하나님의 선물이라 :: 행위에서 난 것이 아니니
여기서는 각 사람의 개인적 구원이 아니라 구원받을 **가능성**이 세상에 온 것(그 가능성이 열린 것)을 말합니다.
### 1. 구원의 가능성이 열린 것은 선물입니다
그리스도 이전에는 구원받을 가능성이 없었습니다. 그리스도 이후에 구원이 가능해졌고 구원의 방편이 마련되었습니다. 구원의 가능성이 나타나도록 사람은 무엇을 했습니까? 아무것도 하지 않았습니다. 인류의 죄는 늘어나기만 했습니다. 구원의 길은 사람들에게 주신 하느님의 **선물**로 마련되었습니다. 죄 많은 인류는 이 선물을 받을 자격이 없었습니다:
> rim 5:6-9 :: 우리가 아직 연약할 때에 기약대로 그리스도께서 경건하지 않은 자를 위하여 죽으셨도다 :: !우리가 아직 죄인 되었을 때에 그리스도께서 우리를 위하여 죽으심으로 하나님께서 우리에 대한 자기의 사랑을 확증하셨느니라
### 2. 구원의 방편은 선물입니다
또 구원의 길에 들어서서 구원의 방편을 받으려면 한 사람 한 사람에게 바로 믿음이 필요합니다. 그는 교회로 인도되고, 세례로 거듭나며, 견진성사로 성령의 은사를 받고, 성체성혈성사로 그리스도와 하나가 됩니다. 이 모든 것은 믿음으로 **값없이 주어집니다**. 사람은 이 선물을 미리 벌어들일 필요가 없습니다.
### 3. 구원의 길은 하느님의 도우심으로(고전 15:10) 사람의 행위로(롬 2:5-8) 평생에 걸쳐(계 2:10) 걸어가는 것입니다
이어서 그리스도 안에서 태어난 목적을 말합니다. 그것은 선한 일입니다:
> ef 2:10 :: !그리스도 예수 안에서 선한 일을 위하여 지으심을 받은 자니
성경의 다른 곳에서 말하듯, 이 선한 일 없이는 구원받을 수 없습니다. 행함이 없는 믿음은 죽은 것이고([[iak 2:20]]), 사람은 믿음으로만이 아니라 행함으로 의롭다 하심을 받으며([[iak 2:24]]), 모든 이가 심판을 받고([[2kor 5:10]]), 심판 자체가 행위에 따라 이루어지기 때문입니다([[2kor 5:10]]; [[ef 6:7-8]]).
이처럼 인류에게 한 번 열린 구원은 믿음으로만이 아니라 행위로도 자기 것으로 삼아야 하며, 위에서 보았듯이 이것은 과정, 그것도 힘든 과정이고 많은 이가 그 목표에 이르지 못합니다:
> lk 13:24; mf 7:14; mf 7:13 :: 좁은 문으로 들어가기를 힘쓰라 :: !들어가기를 구하여도 못하는 자가 많으리라
## 회개한 강도는 믿기만 했을 뿐 아무 행위도 하지 않았는가?
강도는 구약의 이스라엘에 속한 사람으로서, 하느님과의 옛 언약 안에 있으면서 구세주를 믿는 믿음으로 구원받았으며, 무언가를 행하기도 했습니다.
왜 옛 언약 안에서입니까? 그리스도께서 성령으로 세례를 베푸시리라고 기록되어 있고([[lk 3:16]]; [[mf 3:11]]; [[mk 1:8]]), 그리스도께서는 승천하신 뒤에, 곧 오순절에 성령을 보내 주시겠다고 약속하셨기 때문입니다([[in 16:7]]; [[in 14:16]]; [[in 14:26]]; [[in 7:38-39]]). 강도에게 회개와 세례를 전했다는 기록도 없고, 강도에게 성령이 내리셨다는 기록도 없습니다(뒷날 다른 옛 그리스도인들의 경우와 다릅니다). 그러므로 회개한 강도는 교회가 세워지기 전에, 세례와 성체성혈성사 없이, 아직 옛 언약 안에서 구원받았습니다.
그러나 강도도 행위를 했습니다. 그는 자기에게 내려진 벌을 마땅히 받을 것으로 겸손히 받아들였고, 회개에 합당한 열매를 맺었습니다([[mf 3:8]]).
> lk 23:41 :: 우리는 우리가 행한 일에 상당한 보응을 받는 것이니 이에 당연하거니와
하느님께 원망하지 않고, 탓할 다른 사람을 찾지 않고, 남을 정죄하지 않으며 고난을 겸손히 견디는 것은 그리스도인의 행위입니다([[pr 3:11]]). 우리의 첫 조상들은 타락한 뒤에 자기를 탓하지 않고 다른 이를, 어느 정도는 하느님까지 탓하기 시작했습니다:
> gen 3:12-13 :: 하나님이 주셔서 나와 함께 있게 하신 여자 그가 그 나무 열매를 내게 주므로 내가 먹었나이다 :: 뱀이 나를 꾀므로 내가 먹었나이다
그러나 강도는 자기를 탓하며 벌을 견뎠습니다. 이것은 행위이며, 그리스도인의 정신에 매우 합당한 행위입니다.
그는 강도였으므로 위대한 이들 가운데 하나로 영화롭게 되지도 않고, 구세주의 오른편이나 왼편에 예비된 자리를 받지도 않지만([[mk 10:40]]), 믿음으로, 그리고 자기가 할 수 있었던 이 작은 행위만으로도 구원받습니다. 그러니 강도에게도 믿음만이 아니라 행위가 있었습니다.
또 눈여겨볼 것은 강도가 스스로 자기가 구원받았다고 선언하지 않고, 그리스도께서 그에 대해 판결하신다는 점입니다. 강도의 말에는 구원에 대한 확신이 보이지 않습니다. 오히려 그는 자기가 하느님과 함께하는 영원한 생명에 이르지 못하리라는 것을 알기에, 자비에 대한 조심스러운 희망만 품고, 그리스도께서 당신 나라에 임하실 때(강도 자신은 그때 그곳에 있지 못하리라고 생각합니다) 자기를 기억해 달라고 청합니다.
## “누구든지 주의 이름을 부르는 자는 구원을 받으리라”
> rim 10:13
> act 2:21
이런 생각에 어려움을 느낄 수 있습니다. 구원받으려면 주님을 부르기만 하면 되고, 누구든 어떻게 부르든 무엇을 하든 어차피 구원받는가? 사실 여기서 “누구든지”라는 말은 유대인뿐 아니라 어떤 민족의 사람이든 구원받을 수 있다는 뜻입니다.
사도는 이 말씀을 인용할 뿐입니다. 이 말씀은 원래 구약에서 유대인들에게 미래에 관한 예언으로 주어졌습니다. 이제 사도는 그 말씀을 상기시키며, 그 말씀이 이루어질 때가 왔음을 가리킵니다. 구약에서 이 말씀을 한 이는 선지자 요엘입니다:
> iol 2:32 :: 누구든지 여호와의 이름을 부르는 자는 구원을 얻으리니
선지자의 말은 하느님께서 이스라엘 사람만 구원하신다고 확신하던 이스라엘 백성에게 한 것입니다. 그래서 이스라엘 백성에게, 이스라엘 사람만이 아니라 하느님을 부르는 모든 사람(모든 민족)이 구원받을 때가 오리라는 예언이 주어집니다.
그러므로 이 말씀은 하느님께서 이스라엘 백성하고만 맺으신 옛 언약에서 온 것이며, 새 언약은 하느님께서 모든 민족을 부르신 교회와 맺으신 것입니다. 교회 안에서는 더 이상 민족이 중요하지 않기 때문입니다([[kol 3:11]]). 문맥에서 곧바로 보이듯 바로 이것이 요점입니다. 구원에는 민족이 상관없습니다:
> rim 10:11-13 :: 누구든지 그를 믿는 자는 :: !유대인이나 헬라인이나 차별이 없음이라 :: !누구든지 주의 이름을 부르는 자는 구원을 받으리라
성경의 나머지 말씀도 그 필요성을 잃지 않습니다.
어떻게 구원받을 수 있습니까? 주님께서는 계명을 지키라고 말씀하십니다:
> mf 19:17 :: 계명들을 지키라
하느님을 부른다는 말씀이 이것을 폐합니까? 물론 아닙니다.
물과 성령으로 나지 않은 사람은 하늘 나라를 보지도 못하고 들어가지도 못한다고 말씀하십니다. 이것도 폐해지지 않습니다.
> in 3:3,5 :: 하나님의 나라를 볼 수 없느니라 :: 하나님의 나라에 들어갈 수 없느니라

## “대리 희생”(형벌 대속설)
믿음만으로(행위 없이) 구원받는다는 가르침을 따르는 이들 가운데 일부는 “대리 희생”이라는 구원 이론을 말하는데, 그 뜻은 이렇습니다. 이삭이 살도록 이삭 대신 어린 양이 제물로 바쳐졌듯이, 죄인이 살도록 죄 많은 사람 대신 그리스도께서 제물로 바쳐지셨다는 것입니다. 그래서 하느님 아버지께서 아들에게 진노를 쏟으셨으므로 이제 믿는 죄인들에게는 더 이상 노하지 않으시고, 믿는 죄인들에게는 하느님과 함께하는 삶을 가로막는 것이 더 이상 없다는 것입니다.
대리 희생이라는 생각은 진리와 관계가 있어 보이지 않습니다. 이 생각은 문제가 하느님께 있다는(그분이 죄인들에게 노하신다는) 그릇된 전제에서 출발합니다. 그리고 하느님을 바로잡기 위해(그 자체로 얼마나 대담한 생각입니까) 아들이 죽어야 합니다. 그리고 사람은 자기를 전혀 고칠 필요가 없습니다. 하느님께서 아들에게 노하실 것이고, 그래서 (마치 하느님께 있던) 문제가 없어지기 때문입니다. 이런 이론은 상식에 어긋나므로 진리로 받아들일 수 없습니다. 문제가 하느님께 있지 않다는 것은 분명합니다. 깨끗하지 않은 것은 하느님과 함께하는 영원한 생명에 들어갈 수 없습니다:
