## 거룩한 물건
거룩한 기름(성유)은 성물입니다. 이 기름을 바른 성전과 성전의 모든 기물은 거룩합니다. 사람 가운데에서는 아론의 후손만 사제가 되도록 이 기름을 바를 수 있습니다:
> ish 30:23-33 :: !성별하는 기름 :: 만남의 장막과 증거궤에 이 기름을 발라 :: 젯상 :: 등잔대 :: 분향단 :: 번제단 :: 물두멍 :: !너는 이렇게 이런 것들을 거룩하게 하여라. 그리하면 이것들이 가장 거룩한 것이 되어 거기 닿는 모든 것이 거룩해지리라 :: 아론과 그의 아들들에게 이 기름을 발라 주어 :: 몸치장에 써서는 안 된다 :: !그것은 거룩한 것이니 너희가 거룩하게 다루어야 한다
제단은 지극히 거룩합니다:
> ish 40:9-10 :: !이 제단은 거룩한 것 가운데서도 가장 거룩한 것이 되리라
> ish 29:37 :: !그 제단은 가장 거룩한 것이 되어 :: 제단에 닿는 모든 것이 거룩해지리라
[[ru:фимиам|향]](제단에서 사르는 향기로운 물질)은 지극히 거룩합니다:
> ish 30:34-38 :: !순수하고 거룩한 가루향 :: !이 향은 가장 거룩한 것으로 다루어야 한다 :: !야훼를 섬기는 데 쓰는 거룩한 것

# 비판
## 하느님께서는 사람의 손으로 지은 성전에 사시지 않는다
성전에 반대하는 교회 비판자들은 이 구절을 듭니다:
> act 7:46-49 :: 지극히 높으신 분은 사람의 손으로 지은 집에는 사시지 않습니다
그러나 이것은 결코 성전에 반대되는 증언이 아닙니다. 다윗이 하느님을 위해 집(성전)을 지으려 했을 때, 하느님께서는 이미 예언자 모세에게 성막을 짓고 축성하고 사제를 세우고 예식을 지키고 성물(궤)을 두라고 명하셨고, 하느님께서 세우신 질서를 어기면 사형에 처하도록 정하셨기 때문입니다. 이 구절은 하느님께서 성전에만 계시지 않고 어디에나 계심을 설명할 뿐입니다. 성전은 사람이 아니라 하느님 자신이 세우신 것이며, 이교도에게서 빌려 온 것이 결코 아닙니다.

# 정의
**은총(고대 그리스어 χάρις, 히브리어 חֵ֣ן)**은 주된 뜻으로, 사람의 구원을 위해 사람에게 작용하는 하느님의 힘입니다.[1]
1. **하느님의 힘, 하느님의 활동** ([[1kor 15:10]] — “내가 오늘의 내가 된 것은 하느님의 은총의 덕입니다” — χάριτι δὲ θεοῦ εἰμι ὅ εἰμι, καὶ ἡ χάρις αὐτοῦ ἡ εἰς ἐμὲ οὐ κενὴ ἐγενήθη, ἀλλὰ περισσότερον αὐτῶν πάντων ἐκοπίασα, οὐκ ἐγὼ δὲ ἀλλὰ ἡ χάρις τοῦ θεοῦ [ἡ] σὺν ἐμοί);
1. **자비, 호의, 선물, 어떤 이에 대한 은혜와 사랑** ([[gen 18:3]] — ἄρα εὗρον χάριν ἐναντίον σου), ([[sud 6:17]] — εἰ εὗρον χάριν ἐν ὀφθαλμοῖς σου), ([[1ts 16:22]] — εὗρεν χάριν ἐν ὀφθαλμοῖς μου), ([[3ts 11:19]] — καὶ εὗρεν Αδερ χάριν ἐναντίον Φαραω), ([[act 2:47]] — ἔχοντες χάριν πρὸς ὅλον τὸν λαόν), ([[act 7:46]] — ὃς εὗρεν χάριν ἐνώπιον τοῦ θεοῦ), ([[1kor 16:3]] — ἀπενεγκεῖν τὴν χάριν ὑμῶν εἰς Ἰερουσαλήμ);
1. **하느님께 드리는 감사, 하느님 마음에 듦** ([[2kor 9:15]] — χάρις τῷ θεῷ ἐπὶ τῇ ἀνεκδιηγήτῳ αὐτοῦ δωρεᾷ), ([[1pet 2:19]] — τοῦτο γὰρ χάρις εἰ διὰ συνείδησιν θεοῦ ὑποφέρει τις λύπας);
1. **아름다움** ([[pr 5:19]] — πῶλος σῶν χαρίτων), ([[pr 3:22]] — χάρις ᾖ περὶ σῷ τραχήλῳ);
1. **귀한 것** ([[pr 17:8]] — אֶֽבֶן ־ חֵן), ([[ekl 10:12]] — λόγοι στόματος σοφοῦ χάρις), ([[ps 45:2]] — ἐξεχύθη χάρις ἐν χείλεσίν σου);
1. **영예, 존경, 영광** ([[gr iudf 8:23]] — κατευθυνθήσεται ἡ δουλεία ἡμῶν εἰς χάριν)

> rim 8:15 :: !여러분을 하느님의 자녀로 만들어 주시는 분이십니다. 그래서 우리는 그 성령에 힘입어 하느님을 아빠, 아버지라고 부릅니다

> 1in 2:27 :: !그리스도께서 부어 주신 성령이 여러분의 마음 속에 살아 계시는 한 :: !그리스도께서 부어 주신 성령은 여러분에게 모든 것을 가르쳐 주십니다 ~~ “그리스도께서 부어 주신 성령”은 그리스어로 χρῖσμα, “기름 부음”입니다.

> 2kor 6:16 :: !나는 그들 가운데서 살며 그들 사이를 거닐 것이다
> in 14:23 :: !내 아버지와 나는 그를 찾아 가 그와 함께 살 것이다
> evr 13:9 :: !은총으로 마음을 튼튼하게 하는 것이 더 좋습니다
> evr 12:28 :: !감사를 드립시다 ~~ 그리스어: ἔχωμεν χάριν, “은총을 지니자”
> mk 10:13-14,16 :: 어린이들을 예수께 데리고 와서 :: 손을 얹어 축복해 주시기를 :: 어린이들을 안으시고 :: !머리 위에 손을 얹어 축복해 주셨다
> lk 24:50-51 :: !두 손을 들어 축복해 주셨다
# 사람을 통한 은총의 활동
> rim 15:17-19 :: !이방인들을 하느님께 복종시키신 분은 그리스도이시고 나는 다만 그분의 일꾼 노릇을 했을 따름 :: 기적과 놀라운 일 :: !성령의 힘을 ~~ “힘”: δύναμις
> 2tim 1:6 :: !내가 그대에게 안수했을 때에 :: !은총의 선물
그들은 민족들을 복종으로 이끌려고 은총을 받았습니다:
> rim 1:5 :: !은총으로 :: 사도직 :: !모든 이방인들에게 하느님을 믿고 복종할 것을 가르침으로써
> ef 4:29 :: 이로운 말 :: 듣는 사람에게 기쁨을 주도록 ~~ 그리스어: ἵνα δῷ χάριν, “듣는 이들에게 은총을 주도록”
> kol 4:6 :: 언제나 친절하게 유익한 말을 하고 ~~ 그리스어: ἐν χάριτι, “은총 안에서”
