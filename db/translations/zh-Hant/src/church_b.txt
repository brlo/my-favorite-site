# 前言
首先要指出的是：聖經裏沒有任何一個建立自己“教會”、自立爲牧人的例子，也沒有任何這樣的依據。基督建立了一個看得見的教會，並表達了關於她合一的旨意。
# 基督和使徒關於教會看得見之合一的旨意
> in 17:20-21 :: !祈求 :: !使他們都合而爲一 :: !使他們也在我們裏面 :: !叫世人可以信你差了我來
> 1kor 1:10-13 :: !勸你們 :: !都說一樣的話 :: !不可分黨 :: !一心一意 :: !彼此相合 :: 你們中間有紛爭 :: 基督是分開的嗎
> 1kor 3:4 :: !這豈不是你們和世人一樣嗎
上帝安置身體（教會）的肢體，爲使身體沒有分裂，而是彼此相顧，同受苦，同快樂：
> 1kor 12:13-14,21-26 :: 都從一位聖靈受洗，成了一個身體 :: !身子原不是一個肢體，乃是許多肢體 :: !眼不能對手說 :: !上帝配搭這身子 :: !免得身上分門別類 :: !總要肢體彼此相顧 :: !若一個肢體受苦，所有的肢體就一同受苦
這些不同的肢體是什麼？——就是教會裏各種不同的事奉和恩賜：
> 1kor 12:12,14,27-30 :: 就如身子是一個，卻有許多肢體 :: !身子原不是一個肢體，乃是許多肢體 :: !你們就是基督的身子 :: !上帝在教會所設立的 :: 使徒 :: 先知 :: 教師 :: 行異能的 :: 醫病的 :: 說方言的 :: 繙方言的
這樣，上帝安置這一切的事奉和恩賜，爲使身體沒有分裂；使徒在書信開頭就防止了分裂（[[1kor 1:10-13]]）。也就是說，上帝不但願意合一（[[in 17:20-21]]），而且親自照顧這合一。看，使徒被上帝立爲僕人，維護看得見的合一，禁止哥林多人制造看得見的分裂。
既然合一是基督的旨意，就要明白：得救的是遵行上帝旨意的人（[[mf 7:21]]）。
# 敵基督的違揹基督的旨意，明顯走出教會的邊界
敵基督的從使徒的團體中出去：

他們服事的**不是**基督：

# 教會起初看得見的合一
## 外人——另立一旁
教會在起初就有完全確定的看得見的邊界：

## 共同的財物
教會當時是一個一體的團體：
> act 4:32 :: 一心一意 :: 都是大家公用
## 共同解決有爭議的問題
教會有共同的問題，並且一同解決，聚集在完全確定的、看得見的會議上：
> act 15:6,22 :: 使徒和長老，聚會商議這事 :: 使徒和長老並全教會定意
## 共同的規矩
教會有確定的、大家共同的規矩：
> act 16:4-5 :: 經過各城 :: 把耶路撒冷使徒和長老所定的條規交給門徒遵守
## 禁止分門別類
在教會裏，任何分裂的企圖都被制止：
> 1kor 1:10-13 :: !勸你們 :: !都說一樣的話 :: !不可分黨 :: !一心一意 :: !彼此相合
## 一個信仰和聖奧祕
在教會裏只有一個確定的、大家共同的信仰：
> ef 4:5 :: 一信
> 2in 1:9 :: 越過 :: !基督的教訓 :: 不常守著的，就沒有上帝 :: 常守這教訓的
如救主所說：這信仰是按使徒的話：
> in 17:20 :: 因他們的話
教會知道，將來會出現想離開這唯一信仰的人。這些人不能被稱爲教會：

## 一個司祭的等次
> act 20:17-18,28 :: <<請教會的長老來 :: !聖靈立你們作全羣的監督 :: 牧養上帝的教會

這樣，教會是一個完全確定的看得見的團體（機體），有唯一一個共同的使徒信仰，有大家共同的規矩，有使徒所立的、在一切事上合一的帶領者；教會的肢體之間沒有任何阻隔。
# 教會的邊界與聖餐禮
舊約的教會不像新約的教會那樣被稱爲基督的身體。新約的教會是一個奧祕的神人機體，是[[ru:Церковь|基督的身體]]。所以，教會的邊界就在身體的邊界。人的身體的邊界在哪裏？血液流通的地方就是身體；不流通的地方就不是身體。人身體的部分沒有血就沒有生命。被切下來的手已經不是身體的一部分。很快，得不到血的供應，它就會腐爛。哪裏有真實的領受聖體，哪裏就有身體，也就是教會：
> 1kor 10:16-17 :: 同領基督的血 :: 同領基督的身體 :: 我們雖多，仍是一個餅、一個身體，因爲我們都是分受這一個餅
> 1kor 12:27 :: 你們就是基督的身子
> ef 2:13 :: !靠著他的血，已經得親近了
所以，救恩只在教會裏，因爲基督是[[ru:Церковь|身體的救主，也就是教會的救主]]：
> ef 5:23 :: 基督是教會的頭 :: 教會全體的救主
關於聖餐禮，詳見[[ru:Евхаристия|聖餐禮]]。
**聖殉道者、安提阿主教伊格那丟（一世紀）**，《致士每拿人書》（[俄文](https://azbyka.ru/otechnik/Ignatij_Antiohijskij/poslanie-k-smirnjanam/)）：
“第八章。凡屬於教會的事，一概不要不經主教而行。……**只有主教所舉行的聖餐，或他所准許的人所舉行的，才當視爲確實有效**。”
