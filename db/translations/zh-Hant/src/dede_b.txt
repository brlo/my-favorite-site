# 同心合意的誡命
上帝的恩賜不是違揹人的意願強加給人的。比如，愛是上帝的恩賜（[[1in 4:7-8]]；[[gal 5:22-23]]；[[rim 5:5]]），然而它並不強加於人，來了之後，也不會違揹人的意願留在他裏面。每個人都應當努力獲得愛（[[1kor 13:1-2,13]]；[[kol 3:14]]），並使自己的意志趨向愛的行爲（[[in 13:34]]；[[in 15:12]]；[[in 15:17]]；[[1pet 1:22]]），而上帝則回應這些努力，賜下並保守這恩賜（[[pr 21:31]]）。
同心也是從上帝來的，因爲基督和使徒們都曾爲此向上帝祈禱（[[in 17:21-22]]；[[rim 15:5]]）。雖然愛與同心的恩賜已由聖靈賜給教會，但教會中的每個人都應當以努力去獲得並保守這一恩賜。每個信徒都可能單獨地犯罪得罪愛，也得罪同心。因此，每個人都蒙召持守愛與同心：
> rim 12:16 :: !要彼此同心
> 1kor 1:10 :: !都說一樣的話 :: !只要一心一意
> 2kor 13:11 :: !要同心合意，要彼此和睦
> fil 2:2 :: !你們就要意念相同，愛心相同，有一樣的心思，有一樣的意念
> 1pet 3:8 :: !你們都要同心，彼此體恤，相愛如弟兄
# 批評
## 在你們中間不免有分門結黨的事
> 1kor 11:19 :: !在你們中間不免有分門結黨的事，好叫那些有經驗的人顯明出來
原文這裏用的不是「分門結黨」而是「異端」（希臘文 αἱρέσεις），也就是說，在你們中間免不了有異端。這只是關於異端產生的預言。按使徒的話，繁殖異端的人不能承受上帝的國：
> gal 5:19-21 :: !異端 :: !行這樣事的人必不能承受上帝的國
