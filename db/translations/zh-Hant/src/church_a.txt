# 對異議的回應
## “歷史教會墮落了”
那些與教會分離的社團的創立者們，把自己運動的生存模式建立在這樣一個論斷上：歷史上基督的教會背棄了上帝而墮落，所以才需要他們那個分離的社團。可是，如果不證明教會已經墮落，那他們的分離社團就沒有必要，人應該加入歷史上基督的教會。
爲了證明教會墮落的觀念，常引用類似下面關於豺狼的經文：
> act 20:29-30 :: !我知道我去之後 :: !必有兇暴的豺狼進入你們中間，不愛惜羊羣 :: !也必有人起來，說悖謬的話 :: !要引誘門徒跟從他們
然而必須承認，這些經文只是預言會出現假教師，想把人從教會裏引到自己那邊去，而**不是**預言教會墮落。
在此之上，使徒勸勉長老們謹慎看顧自己和羊羣：
> act 20:17,28 :: 保羅從米利都打發人往以弗所去 :: !請教會的長老來 :: !聖靈立你們作全羣的監督 :: !你們就當爲自己謹慎，也爲全羣謹慎 :: !牧養上帝的教會
使徒爲什麼勸勉牧養羊羣？他隨即給出回答：因爲將出現假教師，他們要像豺狼一樣想把教會的羊羣擄去（[[act 20:29-30]]）。但聖靈所立的長老們不應容許這事發生。
長老們能護住教會的羊羣嗎？能。因爲聖經沒有教會墮落的預言，倒有教會不可戰勝的預言：
> mf 16:18 :: 我的教會 :: 陰間的權柄 :: !不能勝過他 :: <<我要把我的教會建造
> ef 3:21 :: !在教會中 :: 直到世世代代 :: !永永遠遠
> mf 28:20 :: !我就常與你們同在 :: !直到世界的末了
> in 14:16 :: !永遠與你們同在
## “教會就是兩三個人奉主名聚集祈禱”
基督已經建立了自己的教會之後，後來那些基督教社團的創立者首先要做的，是向人解釋他們這個與基督的教會分離的新社團的出現。這樣的社團由普通人不久前發起，與古代基督徒沒有直接的歷史聯繫，因此總要證明自己以某種方式屬於2000年前基督所建立的教會。爲此常引用聖經中關於共同祈禱之重要性的經文。他們提出：既然基督在兩三個祈禱的人中間，那這些祈禱的人自己就已經是教會了：
> mf 18:19-20 :: !有兩三個人奉我的名聚會，那裏就有我在他們中間
然而這些經文字面上說的只是共同祈禱的能力，而不是教會。這裏沒有教會一詞。而在幾節之前，卻有教會的話：
> mf 18:15-17 :: 倘若你的弟兄得罪你 :: !你就去趁著只有他和你在一處的時候 :: !另外帶一兩個人同去 :: !告訴教會 :: !若是不聽教會
這裏聚集的人是：
- 我；
- 得罪的弟兄；
- 另外一位或兩位見證人。
一共是1+1+2=4。或者至少3人。
這聚在一起的三個人仍不是教會，可以看出來：因爲他們要尋求審判，不是找他們自己，而是找教會。這樣，教會不是兩三個爲祈禱而聚集的人，而是某種持續存在的、看得見的實體，可以向它尋求審判，可以聽見它的回答，並且遵行或不遵行。不聽教會回答的人，在教會的肢體面前就成爲“像外邦人和稅吏一樣”。
那麼誰能審判呢？使徒和他們的繼任者主教（[[mf 18:18]]）。例如主教提摩太：
> 1tim 5:19-20 :: !控告長老的呈子，非有兩三個見證就不要收
所以，說兩三個祈禱的人就是教會的解釋是不成立的——他們沒有審判別人的權柄。那個與教會分離的社團的創立者自己，不聽教會，就在教會面前成爲“像外邦人和稅吏一樣”（[[mf 18:17]]）。他在自己的社團裏要審判誰呢？他自己從來沒有領受過的權柄，他怎麼能給出呢？答案顯而易見。

# 對異議的回應
## “你們這樣說是因爲驕傲：‘只有我們得救，別人不得救’”
上帝曾藉先知摩西建立了舊約的教會，並在其中設立了上帝所喜悅的規矩。後來，旁邊興起了撒瑪利亞民族，它由許多被遷移來的民族組成：這些人根據先知摩西的五卷書（妥拉），不接受當時的作者們（先知們）的書卷，自己建立了一個有自己規矩的、獨立的宗教團體，按自己的方式信上帝，並等候基督。基督回答撒瑪利亞婦人說：
> in 4:22 :: !你們所拜的，你們不知道 :: !救恩是從猶太人出來的
基督這樣說，是因爲驕傲，還是因爲：在擅自建立的團體裏、在按書本擅自想出來的信仰裏，人確實不能得救？
當使徒說，順著情欲行事的人——其中有異端和分裂教會之事——不能承受上帝的國，他這樣說是因爲驕傲，還是因爲：帶著這樣的罪，人確實不能承受上帝的國？
> gal 5:19-21 :: 情欲的事都是顯而易見的 :: !結黨 :: !紛爭 :: !異端 :: !行這樣事的人必不能承受上帝的國 ~~ *“紛爭”（διχοστασίαι）——分裂、分派；“結黨”（ἐριθεῖαι）——結派營私。
新教徒在這裏看到驕傲，是因爲他們憑空虛構了“只要認基督爲個人的救主就已經得救”的教義，即現在立刻得救、單憑信心得救。正教徒不持守這種教義，因此對得救有著完全不同的理解（詳見[[ru:спасение#HH-Условия-спасения|得救的條件]]）。
來到[[ru:Православная-Церковь|正教會]]，我們還不是得救了，而是正在得救。來到教會的人不是都能得救，只有那些利用救恩的途徑、勤懇地對付自己、根除罪的私慾、培養福音品德的人才能得救。身在正教會，只是得救的條件之一。凡尋求救恩的人都需要救恩的途徑：病人需要藥物，在大海中央溺水的人需要船。同樣，凡被罪的私慾所纏累的人，要渡過今世的海，不在罪的深淵裏沉沒，並與上帝同活，就需要**救恩的途徑：正確的信仰和有恩典的聖奧祕**。這些救恩的途徑，上帝把它們放在他救恩的方舟——[[ru:Православная-Церковь|正教會]]——裏面；而這方舟是主耶穌基督上帝親自在2000年前來建立的。
近來由普通人擅自建立的團體，直接違揹上帝關於信徒合一的旨意，不但沒有救恩的途徑，反而以其分離的存在本身，把人帶進嚴重的罪的狀態——異端和分裂教會這些致死的罪（[[gal 5:19-21]]）。
建立自己的“教會”、分裂信徒，直接違揹基督和使徒關於信徒合一的旨意——這一切正是驕傲的表現：
> in 17:20-21 :: !祈求 :: !使他們都合而爲一 :: !使他們也在我們裏面 :: !叫世人可以信你差了我來
> 1kor 1:10 :: !勸你們 :: !都說一樣的話 :: !不可分黨 :: !一心一意 :: !彼此相合
與基督爲敵、建立自己的“教會”，當然不能得救。使徒說，順著情欲行事、陷入異端和分裂的人，不能承受天國：
> gal 5:19-21 :: 情欲的事都是顯而易見的 :: !結黨 :: !紛爭 :: !異端 :: !行這樣事的人必不能承受上帝的國 ~~ *“紛爭”（διχοστασίαι）——分裂、分派；“結黨”（ἐριθεῖαι）——結派營私。
使徒直說，製造分裂的人不是服事主耶穌基督：
> rim 16:17-18 :: !離間你們、叫你們跌倒 :: !不服事我們的主基督
跟隨與基督爲敵的人走，怎麼能得救呢？
此外，異端和分裂教會並不是僅有的罪，還有許多別的[[ru:смертный-грех|致死的罪]]。警告酒鬼說，他處在酗酒這個致死的罪裏，按聖經所說不能承受上帝的國（[[1kor 6:9]]），這是驕傲的行爲嗎？或者對殺人犯、賊、行邪術的、淫亂的人說同樣的話，也是驕傲嗎？如果這不是驕傲，而且我們應當警告這些致死的罪（[[ef 5:11]]），那麼老實說，也應當警告異端者和分裂教會者，因爲異端和分裂與酗酒、殺人等等在同一條致死之罪的名單上——處在其中的人不能承受上帝的國。
那人怎樣脫離這種罪的狀態呢？離開那個由普通人近來建立的團體，放棄那個由同一個人近來想出來的信仰。然後進入主耶穌基督所建立的[[ru:Православная-Церковь|正教會]]，領受正教的信仰——基督把這信仰教導了使徒們，使徒們把它放進正教會裏，聖靈把它永遠保存在基督的教會裏，因爲聖靈被永遠地差給了教會：
> in 14:16 :: !永遠與你們同在
> mf 28:20 :: !我就常與你們同在 :: !直到世界的末了
