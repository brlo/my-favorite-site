# 陰間刑罰的不同
## 知道而違揹的人，比不知道而違揹的人受更重的刑罰
> lk 12:47-48 :: !那僕人必多受責打 :: !必少受責打 :: !多托誰，就向誰多要
## 假善的人要受更重的定罪
> mf 23:14 :: !你們這假冒爲善的文士和法利賽人有禍了 :: <<你們這假冒爲善 :: >>要受更重的刑罰
> lk 20:46-47 :: !他們侵吞寡婦的家產，假意作很長的禱告。這些人要受更重的刑罰
## 犯罪的師傅要受更重的定罪
> iak 3:1-2 :: !不要多人作師傅，因爲曉得我們要受更重的判斷
## 在基督之前犯罪的城市，與基督行過明顯異能卻被拒絕的城市相比，在審判的日子還要容易受些
> mf 11:22-24 :: !當審判的日子，推羅、西頓所受的比你們還容易受呢 :: !當審判的日子，所多瑪所受的，比你還容易受呢
> mf 10:14-15; mk 6:11 :: !所多瑪和蛾摩拉所受的，比那城還容易受呢
> lk 10:13-15; mf 11:20-22 :: !當審判的日子，推羅、西頓所受的，比你們還容易受呢
## 藉他們而來誘惑的人有禍了
> lk 17:1-2 :: !但那絆倒人的有禍了 :: !就是把磨石拴在這人的頸項上，丟在海里，還強如他把這小子裏的一個絆倒了
## 使信徒跌倒的人有禍了
> mf 18:5-6 :: !凡使這信我的一個小子跌倒的，倒不如把大磨石拴在這人的頸項上，沉在深海里
## 出賣基督的人有禍了；那人不生在世上倒好
> mf 26:24; mk 14:21; lk 22:22 :: !但賣人子的人有禍了，那人不生在世上倒好
# 天國裏真福的不同
## 賞報按善行的多少
> ef 6:7-8 :: !因爲曉得各人所行的善事 :: !都必按所行的，得主的賞賜
> 1kor 3:6-8 :: !但將來各人要照自己的工夫得自己的賞賜
> 2kor 9:6 :: !少種的少收，多種的多收
> mf 16:27; rim 2:5-6 :: !他要照各人的行爲報應各人
> lk 6:38 :: !用十足的升斗 :: !因爲你們用什麼量器量給人，也必用什麼量器量給你們
## 使徒追求更大的
> fil 3:12-14 :: !這不是說我已經得著了 :: !我乃是竭力追求 :: !我不是以爲自己已經得著了 :: !向着標竿直跑，要得上帝在基督耶穌裏從上面召我來得的獎賞
## 誰遵行誡命又教訓人遵行——要稱爲大
> mf 5:19 :: !但無論何人遵行這誡命，又教訓人遵行，他在天國要稱爲大的
## 天國裏有許多住處
> in 14:2 :: !在我父的家裏，有許多住處
## 先知的賞賜和義人的賞賜
> mf 10:40-41 :: !必得先知所得的賞賜 :: !必得義人所得的賞賜
## 僕人們得的賞賜不同
> lk 19:15-19 :: !可以有權柄管十座城 :: !你也可以管五座城
> mf 25:14-15,20-30 :: !把他的家業交給他們 :: !按著各人的才幹，給他們銀子，一個給了五千，一個給了二千，一個給了一千 :: !那領五千銀子的又帶著那另外的五千來 :: !奪過他這一千來，給那有一萬的
*葡萄園僱工的比喻（[[mf 20:1-16]]）中，所有人得的報酬一樣；這比喻是在法利賽人面前講的（[[mf 19:3]]），講它是爲了叫人不至於彼此自高：來得早、勞苦更多的，不要自高於來得晚、勞苦較少的人——因爲在較短的晚來的時間裏，也可以獲得必要的東西，所以不應灰心。
