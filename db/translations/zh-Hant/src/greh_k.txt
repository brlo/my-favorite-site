@@ родовые-грехи | QS19A_祖先的罪 | 祖先的罪（沒有這樣的罪） | | | 人/罪 | 祖先的罪（沒有這樣的罪） | 500
祖先的罪並不存在。這個概念是捏造出來的，通常是所謂「民間療法師」、特異功能者和巫師使用的概念。教會有原罪的概念，但那是另一個概念（見[[ru:7XucD5kC_Всеобщность_первородного_греха|引文]]）。使人完全脫離原罪的，只有教會的聖洗禮，而不是巫師和特異功能者——他們在主耶穌基督道成肉身之前就有，卻沒有行出基督所行的事。
上帝向每個人追討的是他自己的罪。然而，父母的義的生活或敗壞的生活，其後果都會落在兒女身上。這好比：如果父母毀壞自己的健康（酗酒、吸毒），也就損害了自己孩子的健康，儘管孩子對父母毀壞健康並無過錯。在上帝面前，孩子不爲父母的酗酒承擔責任。
這一思想可以從以下的聖經話語中詳細明白：
> iez 18:2-10,12-30 :: !你們在以色列地怎麼用這俗語說 :: !犯罪的他必死亡 :: !人若是公義，且行正直與合理的事 :: !遵行我的律例，謹守我的典章，按誠實行事，這人是公義的，必定存活 :: !他若生一個兒子作強盜，是流人血的 :: !他行這一切可憎的事，必要死亡，他的罪 :: !他若生一個兒子，見父親所犯的一切罪，便懼怕 :: !就不因父親的罪孽死亡，定要存活 :: !他必因自己的罪孽死亡 :: !兒子必不擔當父親的罪孽，父親也不擔當兒子的罪孽 :: !他必定存活，不至死亡 :: !他所犯的一切罪過都不被記念，因所行的義，他必存活 :: !他所行的一切義都不被記念，他必因所犯的罪、所行的惡死亡 :: !我必按你們各人所行的審判你們。你們當回頭離開所犯的一切罪過
但人們常常產生這樣的想法：父母的罪責似乎還是會傳給兒女。這想法是在讀到以下聖經經文後產生的：
> ish 20:5-6 :: !恨我的，我必追討他的罪，自父及子，直到三四代
這裏所說的是那些一代又一代持續恨上帝的人：「直到三四代——恨我的」。這樣的人要因他們對上帝的恨受罰。爲什麼？雖然主容忍了他父親、祖父、曾祖父的仇恨，但這仇恨既然延續到第三四代，容忍就到了盡頭，刑罰就臨到他們。
敘利亞的聖埃弗雷姆：
<blockquote><p>第5-6節、13-14節、16-17節、22-26節。上帝在西奈山上賜下誡命，說：我是耶和華，必追討恨我之人的罪，自父及子，直到三四代。<strong>上帝按自己的寬容容忍一個惡人，也容忍他的兒子和孫子；但他們若不悔改，就把刑罰加在第四代的頭上，只要他在自己的惡行上與先祖相似。</strong></p></blockquote>
