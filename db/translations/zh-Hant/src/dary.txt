建造巴別塔形象地表達了不經上帝、靠自己達到天的企圖。這導致了口音的變亂和彼此語言的不通：

# 上帝在教會裏勝過了口音的變亂

# 不是人人都有方言的恩賜
1. **不是**人人都領受明白別國語言的恩賜。
2. 領受方言恩賜的人，明白**各種不同的**語言。
3. 一切恩賜，包括方言的恩賜，都是**爲了造就**而賜下的：

# 對使徒而言，懂希臘語不足以向一切人宣講
羅馬的軍官驚訝使徒竟然連最通用的語言——希臘語——都懂。也就是說，雖然希臘語流傳很廣（通用語），但這並不意味著人人都懂它。
受過高等教育的使徒保羅，曾受教於全民敬重的教法師迦瑪列（[[act 22:3]]）——法利賽人、公會成員（[[act 5:34]]）——引用希臘哲學家和作家（[[act 17:28]]；[[tit 1:12]]），用希臘語向羅馬的千夫長講話。千夫長驚訝使徒保羅懂希臘語：
> act 21:33,37 :: !你懂得希利尼話嗎
羅馬的軍官驚訝一個猶太人懂羅馬帝國最通用的語言。只有在這種知識**是罕見的**時候，這纔會令人驚訝。如果連希臘語的知識在如此有學問的人身上都令人驚訝，那對其他使徒而言，懂希臘語就更談不上了——他們許多人是普通的漁夫，是沒有學問的小民（[[act 4:13]]）。但問題不在於宣講者（使徒）必須懂語言才能到處宣講；聽宣講的人也必須懂希臘語。
所以，只有希臘語的知識是不夠的，因此使徒們——作爲基督生活、復活和教導的活的見證人——需要超性的恩賜，其中有明白語言恩賜，好把關於基督的見證連同自己的信仰傳給萬民。

# 今天的宣教士學習語言
在古代，使徒和最早的基督徒因非常的需要領受了明白外國語言的恩賜，好叫還很小的教會能夠廣泛傳播，向萬民宣講。但今天的宣教士不得不學習語言，也就是要勞苦。爲此現在一切手段都在，缺的可能只是心願。
有一些信基督的人的團體（靈恩派和五旬節派）可以宣稱自己有說別國話和解釋它們的恩賜；但當他們到了別的國家，外國人並不懂他們的話，於是這樣的宣教士要麼繼續說自己的母語，要麼不得不借助教科書和教師用普通的方法學習語言。
在我們這個時代，這恩賜幾乎沒有了。正教會有一位二十世紀的聖人——聖山修士帕伊西——他除了母語（希臘語）之外從未學過別的語言，也從未宣稱自己有說別國話的恩賜；但當外國人到他那裏去時，他們竟能不用翻譯就與他用法語、另一次用英語交談。

## 關於哥林多前書14章經文的各種問題
關於哥林多前書第14章有很多問題，所以有意義把整章都分析一遍。這在[[ru:K5Ou_Иные_языки_древних_христиан_и_позднейшие_симуляции|單獨的一篇文章]]裏作了。
## 方言只是在未來的世代才停止嗎？
正教徒向五旬節派和靈恩派指出使徒保羅關於方言必停止的話（[[1kor 13:8]]），即這恩賜將要終止。當然，它不會完全消失，因爲正教中極少數的現代聖人確實有過說外國語言的恩賜；但總體上，像最早基督徒那樣的大規模現象不會再有了。
對此新教五旬節派回答說，方言只是在未來的世代、基督再來之後才停止。持這種看法的一些人所依據的，是關於“等那完全的來到”之時代的話（[[1kor 13:10]]）。
我們在更寬的語境裏看這段經文：
> 1kor 13:8-13 :: !愛是永不止息 :: !先知講道之能，終必歸於無有 :: !說方言之能，終必停止 :: !知識也終必歸於無有 :: !我們現在所知道的有限 :: !先知所講的也有限 :: !等那完全的來到，這有限的必歸於無有了 :: !我們如今彷彿對著鏡子觀看，模糊不清 :: !我如今所知道的有限
使徒說，當“那完全的來到”，那“有限的”就要歸於無有。什麼是有限的？**知識**。在這句話裏他開始解釋自己那句複雜的話——“知識也終必歸於無有”。他現在要表達的是：不是知識本身要歸於無有（彷彿他們那時將一無所知），而是他們現在所擁有的這有限的知識要歸於無有，並且將有完全的知識。他繼續發展的正是這一思想。
1. 他說，如今知識**有限地**已經有了，而別的知識**有限地**藉著先知講道顯明出來。
2. 時候將到，那時賜下的將是完全的知識，而不是“有限的”。
3. 如今知識是彷彿對著鏡子觀看，模糊不清地得著的。
他這裏說的是知識，而不是說方言的恩賜。基督徒對外國語言的知識不是有限的。否則他們就不能把福音完整地傳給別的民族和萬民。他們擁有完全的方言恩賜——五旬節來到耶路撒冷的人之所以驚訝，正因爲他們聽見使徒用自己鄉談說話（[[act 2:5-12]]）。那不是有限的。有限的是知識，而且只是知識。使徒接下去所推理的，正是知識。
那方言的恩賜什麼時候停止呢？嚴格地說，這裏沒有說。只說了它要停止。而我們生活在他們之後二十個世紀，可以回顧並看到：這些話相當快就應驗了——當宣講大大傳開、基督徒變得極多的時候；如今方言的恩賜已沒有那樣的非常需要。有非常需要的是愛，而方言的恩賜——沒有。所以從那時起人們學習語言。
“愛是永不止息”這話並不表明要止息的物在永恆裏止息。其餘的一切什麼時候止息都可以；關於永恆只說了一點：在那裏愛不會止息。愛是永恆的、即使在未來的世代也不止息——這是無可爭辯的。
教父們是否像五旬節派那樣理解這些經文？
例如在四世紀，金口約翰認爲，方言恩賜的止息說的是當今的世代，而不是未來的世代。
**聖金口約翰（約347-407）**
“他這樣從各方面、以全部力量顯明了愛的偉大之後，又從另一極重要的方面作同樣的事，用另一個比較高舉它的尊貴，說：‘先知講道之能終必歸於無有；說方言之能終必停止’。**如果這兩個恩賜是爲信仰而賜下的，那麼隨著信仰在各處的傳佈，它們的使用已是多餘的。但彼此相愛不會止息，反而無論在這裏還是在未來的世代都要更加增長**，那時更要勝過如今。在這裏有許多事削弱愛——錢財、（世間的事務）、肉身的情欲、靈魂的疾病；而在那裏這些都沒有。至於先知講道和方言的止息，並沒有什麼可奇怪的；而知識的止息卻似乎奇怪，所以他正是接著說：‘知識也終必歸於無有’。怎樣呢？難道我們那時將生活在無知中嗎？不，恰恰在那時知識更當增長，正如他說的：‘到那時就全知道，如同主知道我一樣’（林前 13:12）。所以，免得你以爲它也像先知講道和方言一樣要歸於無有，他在說了‘知識也終必歸於無有’之後沒有停住，而是顯明了止息的方式，隨即補充說：‘我們現在所知道的有限，先知所講的也有限；等那完全的來到，這有限的必歸於無有了’（林前 13:9-10）。可見，歸於無有的不是知識，而是知識的有限，因爲我們將知道的不僅是這些，還要多得多的東西。”
（[俄文](https://azbyka.ru/otechnik/Ioann_Zlatoust/besedy-na-1-e-poslanie-k-korinfjanam/34)《哥林多前書講道集》第34篇）

## 人的語言和天使的語言
當人們向新教五旬節派指出“別國的話就是別的民族的外國語言”的引文時，他們同意這一點，但作爲回應又拿出另一節經文，說彷彿還有一種“天使的語言”的恩賜：
> 1kor 13:1 :: !並天使的話語
但這種看法是錯誤的，因爲天使是無形體的靈。他們沒有說話的器官、沒有舌頭、沒有肺、沒有聲帶，也不需要空氣（大氣）來通過製造和接收空氣的振動來交流。這樣，由聲帶發出的任何人的聲音都不可能是“天使的語言”，因爲天使沒有聲帶，也沒有血肉的身體（[[lk 24:39]]）。
那使徒說“天使的語言”是什麼意思呢？這不過是修辭的手法：先極度抬高一部分，再用另一部分把它貶低。使徒只是表明：沒有愛的恩賜只是鳴的鑼。當哥林多人還以爲說別國的話已經是什麼特別的東西時，使徒決定舉得更高：即使能說天使的語言，若沒有愛，這也毫無益處。
這只是使徒的修辭手法。關於這一點在聖金口約翰那裏也可以讀到。
**聖金口約翰（約347-407）**
“論到天使的語言，（使徒）並沒有把語言歸於天使，而是表達這樣的意思：即使我能像天使彼此交談那樣說話，若沒有它（愛），我還是無有，甚至是累贅、令人難堪。同樣，在另一處他說‘天上、地上和地底下的一切都要屈膝拜他’（腓 2:10），他**並沒有把膝蓋和骨頭歸於天使**——絕無此事——而是藉著我們下拜的比喻來表達天使的熱心敬拜。這裏說語言也是一樣：他指的不是肉身的器官，而是以我們熟悉的方式表達他們彼此之間的交談。”
（[俄文](https://azbyka.ru/otechnik/Ioann_Zlatoust/besedy-na-1-e-poslanie-k-korinfjanam/32)《哥林多前書講道集》第32篇）
**庫魯斯的真福狄奧多勒（約386-457）**
“所謂天使的語言，他指的不是感官的語言，而是某種屬靈的語言，天使們用它歌頌萬有的上帝並彼此交談。以賽亞聽見他們歌唱，以西結、但以理、撒迦利亞和彌迦聽見他們交談。神聖的使徒**以誇張的方式表達**這一點，爲要顯明愛的優越。”
（[俄文](https://azbyka.ru/otechnik/Feodorit_Kirskij/tolkovanie_na_pervoe_poslanie_k_korinfinam/13#sel=9:83,9:128)《哥林多前書註釋》第13章）
基督自己也用過類似的修辭手法：極度抬高一部分，好叫另一部分把它貶低：
> mf 16:26; mk 8:36 :: !人若賺得全世界，賠上自己的生命，有什麼益處呢
所以，這裏講的不是人有說天使語言的恩賜，因爲人用血肉交流，而天使沒有血肉。提到天使的語言只是修辭的手法。

# 對異議的回應
## “使徒們去聖殿，是因爲他們不明白？”
使徒們在信仰的問題上並非一切都明白。例如，他們以爲基督要去做耶路撒冷的王（[[mk 10:37-39]]），而對基督關於受難和復活的話不明白，又不敢問（[[mk 9:31-32]]；[[lk 9:45]]）。
但這一切只是在基督復活之日聖靈的恩賜被賜給他們之前（[[in 20:21-23]]），以及復活後第五十天之前（[[act 2:1-4]]）。此外，復活之後基督開他們的心竅，使他們能明白聖經（[[lk 24:45]]）。基督在復活之前就應許賜使徒無人能駁倒的智慧（[[lk 21:15]]）；使徒後來也講到，上帝賜給他們各樣智慧和知識的恩典（[[ef 1:8]]）。使徒保羅說，他在言語上（表達上）雖然是愚拙的，但在知識上卻不是（[[2kor 11:6]]）。
當新教徒想表明自己在信仰問題上比使徒“更有學識”時，他們引用的是聖靈降臨在使徒身上之前的種種情形。然而這不成立，因爲教會是在這之後建立和設立的，那時使徒們已不再有不明白信仰的情形。
這樣，在聖靈被差遣之後，使徒們明白信仰的問題，在知識上並不缺乏。即使有什麼不明白的，主也沒有消失——他教導使徒們。例如，他藉異象使徒彼得明白，要給百夫長哥尼流施洗——也就是給非猶太人施洗，儘管這在當時教會的一些人裏引起了疑惑。
## “應當用心靈和誠實敬拜上帝，而不是在聖殿裏？”
如果依著聖經，這裏談的不是聖殿，而是敬拜的地方。
> in 4:19-23 :: !我們的祖宗在這山上禮拜 :: !應當禮拜的地方是在耶路撒冷 :: !時候將到，你們拜父，也不在這山上，也不在耶路撒冷 :: !那真正拜父的，要用心靈和誠實拜他
撒瑪利亞婦人用她的問題把基督框起來：在哪裏敬拜？
- 在基利心山上；
- 在耶路撒冷聖殿裏。
但基督說，時候將到（並且已經到了），那時人們敬拜不在山上，也不在耶路撒冷，而是在心靈和誠實裏：
這裏談的並不是聖殿，可以看出。而如果有人認爲這裏談的是聖殿，那就請他禁止在山上祈禱，因爲基督說的也有山。那樣禁止聖殿的人，也要禁止山：住在山上嗎？——不要祈禱。當然，這是不合理的。
還要注意，基督說這種敬拜的時候已經到了。然而基督仍然來到耶路撒冷聖殿，稱它爲父的殿、祈禱的殿，關心在那裏祈禱不受任何攔阻。
就是說，雖然用心靈和誠實敬拜的時候已經到了，但這並沒有取消聖殿。這座殿被基督撇下成爲空的，只是在以色列多數人棄絕自己的救主之後：基督把葡萄園從先前的園戶（舊約的司祭職）那裏奪去，交給別人——使徒們，並對那些棄絕他的人說，他們的殿要成爲荒場，即上帝的恩典離開它：
> mf 23:38 :: !看哪，你們的家成爲荒場留給你們
基督在十字架上死後，裂開的石頭和撕開的幔子成了這事的標記：
> mf 27:51 :: !殿裏的幔子從上到下裂爲兩半 :: !地也震動，磐石也崩裂
從那時起，基督徒在普天之下任何地方祈禱，隨處獻上聖餐禮的新祭：在有建築的地方，也在沒有建築的地方。
## “既然幔子裂開了（[[mf 27:51]]），說明上帝離開了聖殿，那爲什麼還需要聖殿？”
爲了得救，聖殿（石頭的建築）並不需要。正教會的許多聖人在曠野裏得救。然而，爲了得救必須參與聖奧祕，聖奧祕在事奉聖禮中舉行，而按自然的原因舉行它們需要建築。當然，必要時正教會沒有建築也可以。
既然有建築，教會就把這地方視爲奉獻給上帝的地方，即聖殿。在這地方人求告上帝的名，在這裏聖奧祕中顯出上帝的恩典，在這裏基督自己在聖餐聖奧祕中親臨。所以正教徒特別敬重這些地方，作爲上帝顯現的地方，正如上帝親自要求尊敬他顯現的地方（[[ish 3:5]]），其中包括要求敬重聖殿（[[lev 19:30]]；[[lev 26:2]]）。
舊約聖殿被撕開的幔子表明舊約教會的廢止：表明耶路撒冷的聖殿作爲舊約教會（以色列）與上帝相會的地方已被上帝撇下。葡萄園從舊約教會被奪去（[[mf 21:43]]），賜給了基督所建立、改變了約和司祭職的新約教會（[[evr 7:12]]）。
新約教會不使用被撇下的舊約教會的聖殿，不在那裏行事奉聖禮，也不期待上帝在那裏向她顯現。
## “聖殿只有一個，而且已被毀，所以不能建聖殿？”
聖殿被毀不是第一次。那已經是第二座聖殿。而在此之前有可移動的聖殿——會幕，以色列人抬著它在西奈曠野中遷徙。當第一次聖殿被尼布甲尼撒毀掉時，這是否意味著上帝拒絕了在聖殿中敬拜的可能？如果沒有，那爲什麼後來羅馬人再次毀掉它時就應該這樣？
棄絕基督的猶太人以爲，祈禱和敬拜上帝只能在耶路撒冷聖殿裏。他們把首位殉道者、六品執事司提反召到公會受審，指控他教導說這地方要被毀滅、規矩要改變（[[act 6:13-14]]）。六品執事的辯護詞在於，詳細列舉聖祖的歷史，表明他們在哪裏都祈禱、向上帝獻祭：他們無論在哪裏，上帝都與他們同在（[[act 7:2-53]]）。
最後他指出，這座聖殿是所羅門按聖祖大衛的意願和祈禱建造的，儘管上帝清楚地表明，他不需要爲他建造殿宇：
> act 7:46-49 :: !所羅門爲上帝造成殿宇 :: !其實，至高者並不住人手所造的 :: !天是我的座位，地是我的腳凳 :: !你們要爲我造何等的殿宇
這樣，在舊約訂立之前，義人就在各處祈禱、向上帝獻祭。後來，上帝爲以色列設立了集中的敬拜形式：一座聖殿、一位大祭司，因爲他們在地理上總是彼此相近。這種敬拜形式應當保證上帝所願意的合一。
但當主按預言（[[is 66:18-21]]）召萬民進入教會時，他也創造了在萬民中、在各處舉行事奉聖禮的條件。他自己成爲大祭司（作爲上帝無所不在），差遣恩典，並把權柄賜給許多人——使徒們（[[mf 18:18]]），而不是隻給一個人，不把聖餐的祭綁在任何地方（[[lk 22:19]]），差遣使徒往普天下去（[[mk 16:15]]）。
基督徒的事奉聖禮正是圍繞聖餐而建立的。爲此聖殿並不需要。那些說我們正教徒行事奉聖禮必須有聖殿的人，只是編造我們並不教導的東西。必要時，事奉聖禮在任何地方舉行：在醫院、在軍隊、在監獄、在乘船、飛機、火車的旅途中、在森林裏。
我們不教導說，爲了得救需要聖殿（石頭的建築）。正教會的許多聖人在曠野裏得救。然而，爲了得救必須參與聖奧祕，聖奧祕在事奉聖禮中舉行，而按自然的原因舉行它們需要建築。必要時，正教會沒有建築也可以。
既然有建築，教會就把這地方視爲奉獻給上帝的地方，即聖殿。在這地方人求告上帝的名，在這裏聖奧祕中顯出上帝的恩典，在這裏基督自己在聖餐聖奧祕中親臨。所以正教徒特別敬重這些地方，作爲上帝顯現的地方：
> ish 3:5 :: !你所站之地是聖地
上帝也要求敬重他的聖殿（[[lev 19:30]]；[[lev 26:2]]）。
基督的新約教會不教導說，敬拜只能在耶路撒冷，只能在撒瑪利亞山上，甚至只能在聖殿裏。隨處都可以敬拜上帝、向他祈禱。
---
正教徒建造聖殿，不是爲了進入舊約或遵守摩西的律法。舊約已經結束，摩西的律法已被廢除。
我們建造共同聚會的場所，在其中祈禱並獻上祭物。這樣的場所從來沒有人禁止建造。
舊約的聖殿作爲觀念是重要的。上帝指示按天上實體的樣式建造它。就是說，按上帝的構想，聖殿應當是天的像。
聖經的一切必要佐證詳見[[ru:храм-образ-небесной-реальности|聖殿——天上實體的象徵]]。
在舊約的時代，上帝是看不見的，而在天上的只有天使。
在新約裏，基督上帝在天上有形地登基，而在天上除了天使，還有人。因此，當基督徒有了聚會的場所時，他們就按上帝先前同樣的構想安排它們——使聖殿描繪天。
既然天改變了，聖殿也改變了。如今在聖殿裏描繪的是成了肉身的上帝，而除了天使，還描繪天的其他居民——義的衆人。
上帝從不建造空洞無意義的場所，儘管新教徒常常這樣要求。他安排世界本身，使我們觀看世界時能認識它的造物主。就是說，世界向我們宣講。而聖殿的安排，爲的是宣講基督和他的天國，而不是空洞的白牆。
## 奉獻給聖像的聖殿
正教聖殿只以上帝的名建造。在裏面只向上帝行事奉聖禮。百分之九十五的祈禱是向上帝獻上的，其餘的——向他的聖人：天使和天上的義人。
每一座聖殿都有固定的神聖紀念。例如，有奉獻給基督顯聖容或基督昇天的聖殿。這並不意味著在那裏向顯聖容和昇天的事件祈禱。也有這樣的聖殿，紀念某幅聖像（以奇妙的方式）被賜予，或紀念藉聖像使城市脫離敵人。這是神聖的紀念。當聖殿以神聖紀念之名被稱呼時，這不意味著向神聖紀念祈禱。所有聖殿裏的事奉聖禮都是一樣的。

# 定義
**規程**（希臘文 τάξις）——某種重複性行爲的既定次序。任何有秩序的東西都可以稱爲規程。
**禮規**——某一事奉聖禮之內容的逐項詳細陳述。
聖奧祕的舉行也按既定的規程進行，或者照另一說法——按禮規。
