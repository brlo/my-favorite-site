# 本文論什麼
本文以新舊約聖經文本爲例，分析希臘詞「ἄρτος」與「ἄζυμα」在聖餐禮問題上的用法。
**Ἄρτος**——只是餅，不指明其性質。
**Ἄζυμα**——無酵餅。
**Ἄρτος ἄζυμος**——無酵的餅。「ἄρτος」一詞的加添，通常發生在列舉不同種類的無酵餅時（無酵的餅、無酵的薄餅）。
對這些希臘詞的引用，在歷史爭論中被用作論據。
# 爭論的對象
在關於[[ru:Евхаристия|聖餐禮]]（東正教會的主要聖奧祕）的歷史討論中，一直有爭論：主耶穌基督遞給使徒們、稱之爲自己身體時，所用的**餅**是什麼。
爭論分爲兩種意見：
- **有酵的餅**（發麵的）——東正教會；
- **無酵的餅**（無酵餅）——天主教（起初也用有酵的餅）和新教（有不同做法）。
東正教會——羅馬教會直到十一世紀也屬於其中——從一開始就在各地使用有酵的餅。當羅馬教會脫離正教時，在羅馬的諸多新做法中，也考慮到羅馬放棄以有酵之餅行聖禮、轉用無酵之餅的問題。後來這一問題在與新教各派別的論戰中再次成爲焦點。
支持在聖餐禮上使用有酵之餅的論據有一系列，其一是「ἄρτος」一詞。四位傳道者（馬太、馬可、路加、約翰）都用希臘詞「**ἄρτος**」稱呼聖餐的餅，這有理由認爲餅是有酵的，因爲逾越節晚餐的無酵餅在聖經中總是（無一例外）用希臘詞「**ἄζυμος**」稱呼。而且凡說到無酵餅，幾乎總是直接指明它是無酵的。

# 聖經中的「ἄζυμος」或「ἄρτος ἄζυμος」
在聖經中，「ἄρτος」通常指有酵的餅，而「ἄζυμος」指無酵餅。凡說到逾越節的無酵餅，聖經總是直接說明：或只說**ἄζυμος**（無酵餅），或說**ἄρτος ἄζυμος**（無酵的餅）（通常在列舉不同種類無酵餅時）。這對遵行律法是重要的：要指明餅是無酵的。
比如，我們今天稱白麵包爲「麵包」，而稱黑麵包爲「黑麵包」——這區別對我們未必重要，但對猶太人在律法方面卻原則性地重要：餅是不是無酵的。
這樣，可以只說「ἄζυμος」（無酵的），也可以說「ἄρτος ἄζυμος」（無酵的餅），但無酵餅從不被只稱爲「ἄρτος」而不提及這餅的無酵性。最常見的是用一個詞「ἄζυμος」稱呼無酵餅。
「ἄρτος ἄζυμος」（無酵的餅）這一表達出現得少得多。加添其他詞是在說到不同種類的無酵餅的時候——形狀和做法不同的無酵餅。於是，加 油 做成的餅狀無酵餅被稱爲「ἄρτος ἄζυμος」（無酵的餅），而薄餅狀、抹了油的無酵餅被稱爲「λάγανον ἄζυμον」（無酵的薄餅）。因此在少數情形下會出現這樣的組合：
- 無酵的餅；
- 無酵的薄餅。
如果沒有列舉不同種類的無酵餅，那麼幾乎總是用一個詞稱呼：**ἄζυμος**。
# 總的畫面
## 舊約
逾越節的餅總是被稱爲無酵的。使用的是：「ἄζυμα」或「ἄρτος ἄζυμα」。
## 新約
聖餐的餅從不被稱爲無酵的。傳道者們總是用「ἄρτος」一詞，完全不提及晚餐上有「ἄζυμα」。
# 那麼，ἄρτος 或許也可以是無酵餅？
東正教會的反對者想證明聖經中任何餅——包括無酵餅——都可稱爲 ἄρτος，舉出極罕見的情形（[[ish 29:2]]和[[ish 29:23]]）：那裏說的是無酵餅，卻只稱爲「ἄρτος」。這正是說到兩種不同無酵餅的情形：餅（ἄρτος）和薄餅（λάγανον）。
在詳細考察這幾節之前，可以先指出：即便在這裏，也毫不含糊地指明所說的是無酵的餅：
1. 在[[ish 29:2]]一章的開頭，這些餅（餅和薄餅）被稱爲：無酵的餅和無酵的薄餅。
1. 在[[ish 29:23]]一章的中部，較簡短地重複：一個餅和一個薄餅，並立刻指明：「從裝無酵餅的筐子中」，即無酵的。
現在詳細考察。這些詞是希臘文的，因此直接查考七十士譯本（LXX）的希臘文本——它是在耶穌基督誕生前兩個世紀由七十二位猶太譯者譯成的。取 LXX 的希臘文文本（附翻譯）：
<blockquote><p>καὶ［而］<strong>ἄρτους</strong>［餅］<strong>ἀζύμους</strong>［無酵的］πεφυραμένους［調合了］ἐν［用］ἐλαίῳ［油］καὶ［和］<strong>λάγανα</strong>［薄餅］<strong>ἄζυμα</strong>［無酵的］κεχρισμένα［抹了］ἐν - ἐλαίῳ［油］；σεμίδαλιν［細麵］ἐκ［用］πυρῶν［小麥］ποιήσεις［你要作］αὐτά［它們］。（[[ish 29:2]]）</p></blockquote>
這裏出現的是：1）**無酵的餅**（ἄρτους ἀζύμους）用油調合（πεφυραμένους ἐν ἐλαίῳ）；2）**無酵的薄餅**（λάγανα ἄζυμα）抹了油（κεχρισμένα ἐν ἐλαίῳ）。七十士譯本只提到這兩種無酵餅（馬所拉文本——三種無酵餅）。隨後上帝吩咐要用小麥的細麵作成。再看下一節：
<blockquote><p>καὶ［和］<strong>ἄρτον</strong>［餅］ἕνα［一個］ἐξ［從］ἐλαίου［油的］καὶ［和］<strong>λάγανον</strong>［薄餅］ἓν［一個］ἀπὸ［從］τοῦ - κανοῦ［筐子］τῶν - <strong>ἀζύμων</strong>［無酵的］τῶν - προτεθειμένων［擺著的］ἔναντι［在］κυρίου［主］面前。</p></blockquote>
這裏提到的仍是第二節中那兩個餅：
- 「一個調油的餅」；
- 「一個薄餅」。
並且立刻說明：它們是從裝有無酵餅的筐子中取的。況且，在這一章（第2節）已經說過這餅是無酵的。
也就是說，即便在「ἄρτος」與「ἄζυμος」連用的情形中，每次也都指明餅是無酵的。但此處給「ἄζυμος」加添其他詞也有原因：這裏描述的是不同的無酵餅（餅和薄餅）。如果不用附加的詞來描述做法，就成了「取一個無酵餅和無酵餅」，看起來相當奇怪。
由於餅彼此不同，就需要附加的詞：
- ἄρτους ἀζύμους（無酵的餅）；
- λάγανα ἄζυμα（無酵的薄餅）。
第二次：
- ἄρτον（餅）；
- λάγανον（薄餅）；
- 從裝無酵餅的筐子中（ἀζύμων）。

# 麥基洗德——聖餐禮的預像
先知和使徒們稱上帝之子爲按麥基洗德等次的祭司：
> evr 5:10; evr 5:6; evr 6:20; evr 7:11; evr 7:17; evr 7:21 :: !照著麥基洗德的等次 ~~ 並見 [[ps 110:4]]（俄文本編號爲 Пс 109:4）。
回憶麥基洗德。族長亞伯拉罕遇見了至高上帝的神祕祭司（那時祭司職分還未設立）——撒冷王麥基洗德。麥基洗德拿普通的餅（ἄρτος）和酒出來迎接亞伯拉罕，而亞伯拉罕把十分之一獻給他（那時什一奉獻還未設立）：
> gen 14:18 :: !帶著餅和酒
麥基洗德用的只是 ἄρτος。
# 嗎哪——聖餐禮的預像
舊約中在曠野裏賜給猶太人以維持生命的嗎哪，是聖餐禮的預像，主耶穌基督親自指明了這一點。在舊約中，上帝稱嗎哪爲從天降下的餅（ἄρτος）：
> ish 16:4 :: !我要將糧食從天降給你們
餅在這一章中提到7次，7次都稱爲 ἄρτος：
> ish 16:15 :: !這就是耶和華給你們喫的食物
天上的餅（嗎哪）被稱爲 ἄρτος。
# 上帝在幔利橡樹旁向亞伯拉罕顯現——聖餐禮的預像
亞伯拉罕爲上帝（以三位天使的形像顯現）預備了普通餅（ἄρτος）和宰殺的「又嫩又好」的牛犢（基督祭獻的預像）的筵席：
> gen 18:5 :: !我再拿一點餅來，你們可以加添心力
亞伯拉罕在預像聖餐禮的筵席上用的只是 ἄρτος。
# 關於聖餐禮的預言
在箴言書中，說到聖餐禮時，講的是普通的餅（ἄρτος）：

在關於聖餐禮的預言文本中，指明的是 ἄρτος。
# 五旬節——教會的誕生日
在舊約的五旬節（在新約中，五旬節是教會的誕生日），主直接命令給他獻上**新的**祭——**有酵的（ἐζυμωμένοι）餅（ἄρτοι）**和七隻無殘疾的羊羔：
> lev 23:16-17 :: !又要將新素祭獻給耶和華 :: !加酵，烤成兩個搖祭的餅 :: !當作初熟之物獻給耶和華
舊約的五旬節明確地使用有酵的 ἄρτος。
# 感恩的平安祭
舊約中有兩種平安祭：
- 讚美的祭（希伯來文 תודה）；
- 感恩的祭（或救恩的祭）（希伯來文 שלמים 或 נדר）。
平安祭包含餅的供物和牲畜的祭獻。**讚美**的平安祭用無酵的餅獻上，而若在其之外還獻**感恩**的平安祭，則用有酵的餅獻上：
> lev 7:13 :: !要用有酵的餅和爲感謝獻的平安祭
這樣，在舊約中，感恩（救恩）的祭用有酵的餅獻上。在新約中，向上帝獻上餅的聖奧祕被稱爲**「感恩禮」（源自希臘文——感恩）**，因爲基督自己在把餅遞給門徒之前，先**祝謝了**上帝並祝福了餅（[[lk 22:19]]；[[1kor 11:23-24]]）。
也就是說，在東正教會的感恩禮中，今天所做的正是：
- 取有酵的餅；
- 只是不與之同獻祭牲，因爲祭物、羔羊、逾越節——就是被釘十字架並復活的基督（[[1kor 5:7]]）。
應當注意：無酵餅被稱爲困苦餅（「ἄζυμα, ἄρτον κακώσεως」，[[vtor 16:3]]），而用有酵之餅的平安祭稱爲感恩的祭，或救恩的祭（תֹּודַ֥ת——感恩，σωτηρίου——救恩，[[lev 7:13]]）。
*注：祭肉的肉允許在當天吃掉、不留到早晨（如同逾越節），或吃兩天，但嚴格禁止留到第三天。若沒有在第三天之前吃完，剩下的就應當燒掉，否則祭物被上帝拒絕，發生玷污和罪。這把我們引向救主的復活——第三天墳墓就空了。也就是說，在這裏，有酵的餅同樣指向新約——救主的復活。

# 酵——罪的預像？
有時會遇到把舊酵的比喻用作邪惡和詭詐之酵的說法。使徒保羅正是使用**舊**酵的比喻，指出必須除掉它：
> 1kor 5:7-8 :: !應當把舊酵除淨 :: !也不可用惡毒、邪惡的酵 :: !只用誠實真正的無酵餅
然而，基督自己以另一種方式使用酵的比喻，把它比作天國：
> mf 13:33 :: !天國好像面酵 :: !直等全團都發起來 ~~ 並見 [[lk 13:21]]。
也就是說，酵是不同的。它表明小小的東西可以影響巨大的東西：酵使**全**團發起來。類似地，救主也用鹽的比喻：鹽很少，卻影響整個環境。可以注意，舊約中既獻無酵的餅爲祭，也獻有酵的餅爲祭。有酵之餅所獻上的，是把我們引向新約的東西——感恩的平安祭（[[lev 7:13]]）和五旬節的祭（[[lev 23:16-17]]）。而無酵餅則被稱爲困苦餅（[[vtor 16:3]]），是對埃及奴役的記念。無酵的、無味的、堅硬的、配苦菜的餅，應當提醒猶太民族那些主救他們脫離的苦難。而有酵的餅則相反——應當把心思轉向蒙福的時光、脫離苦難的解脫、上帝祝福的時光。
# 關於 LXX 與馬所拉文本的說明
俄文正教譯本（司祭宗教譯本）按馬所拉文本譯成（該文本在基督被釘十字架之後編成），而 LXX（在基督前兩個世紀編成）只在教義上有意義的地方加以參照。東正教會誦讀按 LXX 編成的教會斯拉夫語文本。這一切都很重要，因爲希伯來文的馬所拉文本在本主題所關注的地方與同樣是猶太人所編、但以希臘文寫成的 LXX 略有不同。例如在（[[ish 29:2]]）：馬所拉文本提到三種不同的餅（雖然都是無酵的），LXX 只提到兩種餅（也都是無酵的）。往後也是如此。
