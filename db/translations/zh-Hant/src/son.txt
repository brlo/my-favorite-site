> in 1:18 :: 獨生子
> in 3:16 :: 上帝 :: 甚至將他的獨生子賜給
> in 3:18 :: 上帝獨生子的名
> gal 4:4 :: 上帝就差遣他的兒子

# 可以向耶穌基督禱告嗎？
當然可以。但這誡命我們不是從聖經，而是從聖傳領受的。
# 只憑聖經能否斷言應當向耶穌基督禱告？
聖經中沒有向耶穌基督禱告的誡命。不過，[[gr in 14:14]]有一些蹟象（參見希臘文文本）。
耶穌基督曾向父禱告（[[mk 14:36]]；[[lk 22:42]]），賜下了“我們在天上的父”的禱告（[[mf 6:9]]；[[lk 11:2]]），也就是說，他教導人向父禱告。
主張只靠聖經（當然是按他們對聖經的理解）建立信仰的人，不敢否認向耶穌基督的禱告。因此他們說：向耶穌基督禱告的實踐既然存在，就是可以向他禱告。然而，他們常常連這種實踐都難以指出，因爲它十分罕見——當然，它是有的。例如：
> act 7:59 :: 呼籲 :: 求主耶穌 ~~ 希臘文 ἐπικαλούμενον（呼籲、祈求）
# 反對意見
## “奉我的名求”
新教徒反對說，誡命就在這節經文裏：
> in 14:14 :: 奉我的名
然而，只要引用上下文就能看到，主耶穌基督在這裏教導的也是向父求：
> in 14:13-14 :: !叫父因兒子得榮耀 ~~ 和合本此處無“向父求”的字樣
