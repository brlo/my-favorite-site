# 將有新約
舊約的預言：與猶太民族（他們違背了這約）的約將終結，將與新的民族另立新約：
> vtor 32:15-21 :: !但耶書侖漸漸肥胖、粗壯 :: !便離棄造他的上帝 :: !敬拜別神，觸動上帝的憤恨 :: !所祭祀的鬼魔，並非真神 :: !我也要以那不成子民的觸動他們的憤恨
> ier 31:31-33,36-37 :: !我要與以色列家和猶大家另立新約 :: !他們卻背了我的約 :: !我要將我的律法放在他們裏面，寫在他們心上 :: !我要作他們的上帝，他們要作我的子民 :: !以色列的後裔也就在我面前斷絕 :: !我就因以色列後裔一切所行的棄絕他們
> is 65:1 :: !沒有稱爲我名下的 :: !我在這裏！我在這裏！
> os 2:23 :: !本非我民的，我必對他說 :: !你是我的民 :: !你是我的上帝
# 論舊約的終結
> evr 8:8,13 :: !我要與以色列家和猶大家另立新約 :: !就以前約爲舊了 :: !但那漸舊漸衰的，就必快歸無有了
> 2kor 3:14-16 :: !誦讀舊約的時候，這帕子還沒有揭去 :: !這帕子在基督裏已經廢去了 :: !但他們的心幾時歸向主，帕子就幾時除去了
> 2kor 3:6 :: !他叫我們能承當這新約的執事，不是憑著字句，乃是憑著精意 :: !因爲那字句是叫人死，精意是叫人活
> rim 7:6 :: !現今就脫離了律法 :: !要按著心靈的新樣，不按著儀文的舊樣
> gal 3:23-25 :: !我們被看守在律法之下 :: !律法是我們訓蒙的師傅 :: !我們從此就不在師傅的手下了
## 警告：不要濫用基督徒的自由
> gal 5:13 :: !你們蒙召是要得自由 :: !只是不可將你們的自由當作放縱情欲的機會 :: !總要用愛心互相服事
