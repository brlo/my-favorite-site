# 與亞瑪力人的爭戰
耶穌基督在十字架上救贖性祭獻的預像，是舊約中的一件事：以色列民與亞瑪力人的爭戰。先知摩西在山上祈禱，他舉手時以色列人就得勝（[[ish 17:11]]）；他因疲乏垂手時，民衆就開始敗退。以色列民與亞瑪力人爭戰時在山上的先知摩西。亞倫與戶珥扶著他的手（[[ish 17:11-12]]）。爭戰持續了一整天，摩西不能一直舉著手，所以亞倫與戶珥幫助摩西，搬石頭來放在他以下讓他坐下，從兩邊扶著他的手：亞倫扶一隻手，戶珥扶另一隻（可以說，如同釘子固定著基督的手）。摩西就以這樣的姿勢在山上（如同基督的十字架在山上）直到日落（[[ish 17:12]]）（如同基督一樣）。情形如下：
- 約書亞（以色列民的統帥）的軍隊［如同基督軍隊——教會的元首］
- 藉着十字架戰勝了亞瑪力人［如同基督藉十字架得了勝利（[[ef 2:16]]）］，
- 十字架由摩西在山上擺出［如同基督的十字架在各各他山上］，
- 摩西被人在這樣的姿勢中扶持著［如同基督在十字架上被固定著］
- 直到一天結束［如同基督一樣］。

上帝規定了以色列各支派營陣的排布。他們要這樣安營，也要這樣行進。以色列的營陣構成一個十字。
- 營的中心是會幕：
> chis 2:2 :: !對著會幕的四圍安營
同時，營的中心是利未支派：
> chis 2:17 :: !有利未營在諸營中間 :: !他們怎樣安營，就怎樣往前行
- 東邊：猶大支派，然後以薩迦，然後西布倫：
> chis 2:3,5,7 :: !是猶大營的纛 :: !是以薩迦支派 :: !又有西布倫支派
- 南邊：流便支派，然後西緬，然後迦得：
> chis 2:10,12,14 :: !是流便營的纛 :: !是西緬支派 :: !又有迦得支派
- 西邊：以法蓮支派（約瑟的），然後瑪拿西（約瑟的），然後便雅憫：
> chis 2:18,20,22 :: !是以法蓮營的纛 :: !是瑪拿西支派 :: !又有便雅憫支派
- 北邊：但支派，然後亞設，然後拿弗他利：
> chis 2:25,27,29 :: !是但營的纛 :: !是亞設支派 :: !又有拿弗他利支派
***注**：這樣的排布需要13個營（1+3+3+3+3），而雅各的兒子只有12個。這裏列舉了所有的支派，但約瑟的一個支派由他兩個兒子的支派代替：瑪拿西和以法蓮。
# 十字的每一邊都按最靠近中心的支派之名計數
先列舉猶大營的數目：
> chis 2:3-4 :: !共有七萬四千六百名
然後列舉猶大之後各支派的人數：
> chis 2:6 :: !共有五萬四千四百名
> chis 2:8 :: !共有五萬七千四百名
然後全部加在一起，以猶大（最靠近中心的支派）之營命名，其數目已包括所有三個營：
> chis 2:9 :: !凡屬猶大營按著軍隊被數的，共有十八萬六千四百名 :: !要作第一隊往前行
其餘各邊也都這樣重複。

@@ крест-и-крещение-переход-через-море | QO4A_十字架與洗禮——過紅海 | 十字架與洗禮——過紅海 | | 關於過紅海之預像意義的引文 | 舊約/預表 | 十字架與洗禮——過紅海 | 4
以色列民從埃及的奴役中走過紅海底——是洗禮的預像（[[1kor 10:2]]），是脫離罪的奴役的出走。先知摩西命令紅海的水回到原處（[[ish 14:26-27]]）。上帝指示先知摩西舉杖把水分開（[[ish 14:16,21]]），而當民衆走到對岸之後，摩西要用手命令水回到原處（[[ish 14:26-27]]）。按情理，這是橫向的動作，與先前分開水流的縱向動作相對。這樣就得到一個十字：
- 「之前」分開的縱向動作「|」。
- 「之後」連接的橫向動作「—」。
這樣就成了一個十字（「|」與「—」相加即「＋」）。以色列民藉十字架脫離了奴役。正如我們藉著基督的十字架脫離罪的奴役，受浸入洗禮之水中。

@@ EMRx_Крест__буква_тау | QO6A_十字架——字母Tau「𐤕」 | 十字架——字母Tau「𐤕」 | | | 舊約/預表 | 十字架——字母Tau「𐤕」 | 6
**在先知以西結的異象中，書記員要在一些人的額上畫上記號**「𐤕」（腓尼基字母Tau）。
先知以西結見到關於猶太人可憎之事的異象，爲此上帝差遣刑罰者前來，由書記員帶領。書記員把記號畫在那些人的額上——那些人對這些可憎之事同樣憎惡，如同上帝一樣。按上帝的指示，有這記號的人不會受刑罰觸及。
> iez 9:4-6 :: !那些因城中所行可憎之事嘆息哀哭的人，畫記號在額上 :: !只是凡有記號的人不要挨近他 ~~ 俄文本引用處誤作 Иез 1:4-6；經文實爲 Иез 9:4-6。
在希伯來文中「畫記號」寫作「הִתְוִיתָ **תָּו**」[taw-vaw' tawv]。
直譯可以譯作「畫上**תָּו**」（Tau字母），但先知以西結出生之時，猶太人還在使用腓尼基文字或源自腓尼基文字的古希伯來文字；按那種文字，Tau字母寫作「𐤕」。這樣，按字面寫的是：「**畫上**𐤕」。
古代基督徒也同樣在自己額上畫十字：[[ru:крестное-знамение|十字聖號]]
<hr>
猶太人從基督降生前約十世紀到七世紀使用腓尼基字母（源自腓尼基字母的古希伯來字母）。也就是說，它使用到巴比倫之囚爲止。猶太人在16年中分幾個階段被擄往巴比倫（<a href="https://ru.wikipedia.org/wiki/Вавилонский_плен">公元前598—582年</a>）。
先知以西結生活的年代約爲<a href="https://ru.wikipedia.org/wiki/Иезекииль">公元前約622年——約公元前570年</a>（共52年）。
<a href="https://azbyka.ru/days/sv-iezekiil">25歲</a>時，他與自己的民族一同被擄。
也就是說，他出生並受教育時還在使用腓尼基文字。
<a href="https://ru.wikipedia.org/wiki/Иезекииль">30歲</a>時，他的先知事奉開始（[[iez 1:1]]）。
此時以西結寫他的先知書。
我們所關注的事件記載於第8-9章，發生在再過一年零兩個月之後（[[iez 8:1]]）。
無論如何，我們來到公元前七至六世紀之交、巴比倫之囚的最開始，此時猶太人的新文字纔開始逐漸形成。字母並不是一下子改變的，這在被擄期間經歷了很長時間。
最可能的是，先知還在使用猶太民族所能明白的腓尼基文字，相應地，把Tau寫作「𐤕」。如果這是正確的，那麼書記員要在人的額上畫上「𐤕」這個符號，使他們免受刑罰——這也把我們引向主的十字架的救贖意義。
