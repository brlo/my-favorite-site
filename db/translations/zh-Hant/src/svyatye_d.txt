# 正教會的理解
正教會教導：主耶穌基督是唯一的中保。是怎樣的中保？是那舍自己作萬人**贖價**的中保（[[1tim 2:5]]）。其餘的聖人不是救贖者。同禱者卻有許多：
> 2kor 1:10-11 :: !現在仍要救我們 :: !並且我們指望他將來還要救我們 :: !你們以祈禱幫助我們 :: !就是爲我們因許多人所得的恩
他們是聖潔的義人、上帝的朋友：上帝之母、天使、先知、使徒、殉道者和其餘的聖人。如同使徒在這裏被人請求代禱，在天上也有人求他代禱。以爲每個人都應當隻爲自己的利益向上帝祈禱的想法，與聖經格格不入。相反，聖經中多次召呼全教會彼此代禱（[[iak 5:16]]）。所有的人——甚至最偉大的義人和上帝的特選者——不放棄向上帝的祈禱，也請求信徒們爲他們祈禱，自己不住地爲信徒祈禱，並吩咐將來也要守這規矩。這也稱爲彼此代求。
我們從教會知道、並以聖經證實：義人在與身體分離之後進入與上帝同在的生活，並繼續向他獻上自己的祈禱。因此，如同這些義人活著、身體還在地上時我們曾求他們的祈禱，同樣在他們與身體分離、進入天上與基督明顯的同在後，我們也求他們的祈禱（[[evr 12:22-23]]）；因爲他們不是進入更壞的境地，而是更好的境地（[[fil 1:23]]）。我們相信愛永不止息（[[1kor 13:8]]），因此整個教會——地上爭戰的和天上得勝的——是一個合一的、完整的、相通的教會，共同地彼此祈禱，並被愛催促關懷自己所有的肢體。我們也信、並從教會知道、且在聖經中表明：我們的護守天使與上帝有相通（[[mf 18:10]]），被差遣事奉那將要承受救恩的人（[[evr 1:14]]）；而聖潔的義人住在上帝聖光之中，也知道地上發生的事，併爲教會向上帝獻上祈禱（[[otkr 6:9-11]]）；永恆的愛催促衆人在基督的一個身體裏彼此相通、彼此關懷：在天上，也在地上。

# 對異議的回應
## 一位中保
### 簡答
正教徒因向聖人祈禱而受指責，說只有基督纔是唯一的中保。回答是：基督是唯一的、救贖了世人的中保，如同一節經文接著說的：
> 1tim 2:5-6 :: !只有一位中保 :: !乃是降世爲人的基督耶穌 :: !他舍自己作萬人的贖價
聖徒們不是救贖者，而是同禱者（[[iak 5:16]]）。一切在於意義。我們的反對者（通常是新教徒）彼此爲對方的所需祈禱。如果他們彼此是中保，那聖人也是我們的中保。如果他們彼此是同禱者，那聖人也是我們的同禱者：因爲我們只是求他們爲我們祈禱、加入我們向上帝的祈禱。我們不把他們當作神，也不把他們當作神來祈禱——同樣，新教徒請人代禱時，也不把自己的夥伴當作神。
可以有代禱的中保嗎？——從聖經顯然可見：可以。例如，因教會司祭的祈禱，另一個人的罪可以得赦。
> iak 5:14-15 :: !該請教會的長老來 :: !爲他禱告 :: !他若犯了罪，也必蒙赦免
無可爭議的代求。這樣，反對向聖人祈禱的人對基督作爲唯一中保之言（[[1tim 2:5-6]]）的理解是不正確的。所引的經文並不反對祈禱中的代求者。
### 更詳細地論“中保”一詞
還有翻譯上的特點。“中保”一詞譯自希臘文 μεσίτης。它可以譯作“和平的締造者”——促成雙方和好的人。也就是說，換言之，基督是上帝與人之間唯一的**和好者**（締造和平者）。使徒們在別處說得更明白：
> 2kor 5:18-19 :: !他藉着基督使我們與他和好 :: !又將勸人與他和好的職分賜給我們 :: !這就是上帝在基督裏叫世人與自己和好 :: !並且將這和好的道理託付了我們
> 1in 2:1-2,12 :: !若有人犯罪 :: !在父那裏我們有一位中保 :: !就是那義者耶穌基督 :: !他爲我們的罪作了挽回祭 :: !小子們哪，我寫信給你們，因爲你們的罪藉着主名得了赦免
把“中保”譯作**和好者**或締造和平者，也與句子的結尾相合，如前所指：“他舍自己作萬人的贖價”（[[1tim 2:5-6]]）。這樣一位締造和平者，藉把自己作爲祭物獻上，贖了人類在上帝面前的罪。所以這節經文不是反對向聖人祈禱，而是講到基督作爲人類與上帝的**和好者**。基督也是人與人之間的**和好者**（[[ef 2:14]]）。
## 關於“拯救我們”的說法
正教徒因允許在向聖人的祈禱中用“拯救我們”的話而受指責。這裏又是在於意義。拯救是基督一次成就的。在這一意義上再沒有別的救主。但許多人可以促進具體個人的得救。這樣的說法在聖經中也常見：
### 使徒救人
> rim 11:14 :: !或者可以激動我骨肉之親發憤 :: !好救他們一些人
> 1kor 9:22 :: !無論如何總要救些人
### 妻子救人
> 1kor 7:16 :: !你這作妻子的，怎麼知道不能救你的丈夫呢 :: !你這作丈夫的，怎麼知道不能救你的妻子呢
### 使徒呼召拯救別人
> iud 1:22-23 :: !有些人你們要從火中搶出來 :: !搭救他們
> 1tim 4:16 :: !又能救自己，又能救聽你的人
## 難道除了基督還有誰能救人嗎？
無論使徒還是夫妻，都不是主耶穌基督意義上的救主——他是唯一的救贖者，把人類從死亡和陰間中救出、賜復活和與上帝同在的永生。但如上所見，“我要救”這樣的說法是使徒們所用的。我們正確地理解這些話的意義——人可以促進得救：
> 1kor 3:9 :: !因爲我們是與上帝同工的
## 關於“憐憫我們”的說法
這裏情形與“拯救”相同（見上）。這樣的說法不只向聖徒，也向普通人發出。憐憫，就是施以恩惠。例如，義人約伯對自己的朋友們說：
> iov 19:21 :: !我朋友啊，可憐我！可憐我
## 聖徒怎麼能聽見來自全世界的祈禱？
反對向聖人祈禱的人說：“上帝是無所不在、全能的；而聖人如果不具備這些屬性，那他們怎麼能聽見地球上不同地方衆多人的祈禱？”
### 聖徒們說預言、行奇蹟，不是靠自己的力量，而是靠上帝的力量
聖徒們不是離開上帝單獨被考察的。就是在地上身體活著的時候，上帝的能力也住在他們裏面；更何況在遷往天上、與基督同活之後，他們更不會失去這一點。先知亞迦布雖不是無所不知的，卻宣告了將臨到天下的大饑荒（[[act 11:28]]）。使徒彼得不是全能的，卻復活了多加（[[act 9:40]]）。他們作這些不是靠自己的力量，而是靠上帝的力量。
聖徒們如使徒所言，進入的不是更壞的，而是好得無比的境地（[[fil 1:23-24]]）：不是失去，而是獲得（[[fil 1:21]]）。他們與上帝聯合，在他的光和恩典中。他們的存在不能與我們的相比。他們知道地上發生的事（[[otkr 6:10]]）。甚至還在身體裏的時候，使徒們就寫道，他們靈裏與基督徒同在：
### 使徒不在身體裏，而在靈裏知道基督徒團體的情況
> kol 2:5 :: !我身子雖與你們相離，心卻與你們同在
> 1kor 5:3-5 :: !我身子雖不在你們那裏，心卻在你們那裏 :: !就是你們聚會的時候，我的心也同在 :: !使他的靈魂在主耶穌的日子可以得救
> 1kor 8:3 :: !若有人愛上帝，這人乃是上帝所知道的
### 得救的人有護守天使
如經所記，天使被差遣事奉得救的人：
> evr 1:14 :: !天使豈不都是服役的靈 :: !奉差遣爲那將要承受救恩的人效力嗎
同時，天使常常見上帝的面（[[mf 18:10]]）。甚至他們就可以轉達我們的祈禱。我們不只向聖人們祈禱，也向聖天使祈禱：求他們爲我們代禱，爲他們的勞苦和關懷感謝他們。
反對地上教會與天上教會相通的人，甚至不允許感謝被差來事奉我們的護守天使——而這天使並不需要無所不在、無所不能才能聽見我們。
這樣，教會相信：聖徒們因住在上帝的光和恩典中而能聽見我們的祈禱。與上帝的合一賜給他們這樣的可能。是上帝自己賜給他們這樣的可能。所以，用最簡單的話說：聖徒們能聽見祈禱，不是由於自己的能力，而是由於上帝和他的能力。
## 教會怎麼知道誰是聖人？難道是人替上帝作決定嗎？
人不是替上帝作決定。上帝按自己的應許（[[ru:почитание-святых-в-Библии#HH-Святые-будут-в-чести|引文]]），自己榮耀自己的聖人，顯明奇蹟，垂聽他們的祈禱。教會只是爲此作見證，並把民間對聖人的敬禮理出秩序，免得混亂——正如使徒所吩咐的：
> 1kor 14:40 :: !凡事都要規規矩矩的按著次序行
*規矩——即次序
> 2sol 3:11 :: !有人不按規矩而行，什麼工都不作
教會關於義人之聖潔的見證和敬禮秩序的設立（封聖），通常遠在義人去世之後，那時對這一問題的研究，不但可以依據義人地上的生活，還可以依據上帝在義人遷往天上、與上帝同活之後所顯明的事。
從教會的肢體們收集關於奇蹟、醫治——在義人墳墓旁發生的——以及義人祈禱之助的見證。仔細考察他生活和信仰的純潔。之後教會共同地研究所收集的信息，可以批准把義人作爲聖人敬禮，併爲此撰寫教會文本和聖像，設立紀念日。這某種意義上是把教會民間已經在發生的敬禮理出秩序，確認這敬禮的正確性，把敬禮納入事奉聖禮。
不過，許多義人的聖潔無需作見證，因爲這由聖經和教會的聖傳可知。著名的聖人無疑包括童貞女馬利亞上帝之母（上帝爲她成就了大事，[[lk 1:49]]）、聖祖、先知、使徒、他們所立的主教、司祭和輔祭（例如首位殉道的六品執事司提反，[[act 7:55-60]]）、衆多的殉道者。此外，教會不只向聖人們祈禱，也向聖天使祈禱：總領天使米迦勒、加百列，以及[[ru:ангел-хранитель|護守天使]]等。爲天使的聖潔作見證是多餘的，因爲這是人所共知的上帝的僕人。
# 重要的說明
在爲向聖人祈禱辯護之前，必須堅定地領會一個關鍵點：反對者沒有對禁止向聖人祈禱作出正面的解釋。反對者言論的基礎只有一句話：“聖經裏沒有說”。這是他們解釋的否定部分，他們會堅持它。而正面的部分——即對這一禁止的明確理解——他們沒有。
基督復臨安息日會的人部分地可以提出解釋，因爲他們不相信人死後靈魂的生活。不過，安息日會的人也無法解釋爲什麼不能向天使祈禱——因爲天使的存在他們目前並不否認。按聖經，天使被派給得救的人，關懷人的得救（[[evr 1:14]]）；爲什麼對他們什麼都不可以說？他們無法解釋。
至於其餘的（新）新教徒，他們大多數相信人在與身體分離後靈魂的生活，所以他們完全無法解釋：爲什麼不能與天上的教會相通——而我們現在已經來到她面前（[[evr 12:22-23]]）；爲什麼不能與聖祖們、使徒們、殉道者們、天使們交談。當然，他們會試圖說些什麼，但那總是不能令人信服。例如會說，聖徒們進入了上帝的安息，所以彷彿不再掛念地上的事了。但那樣就得出上帝也不掛念地上的事，因爲他也在同一個安息裏。他們其餘的辯解也同樣荒謬。
向聖人祈禱的必要性是從聖經隱含地（逐步地）推論出來的，就是說，這一必要性沒有直接指明，而是被蘊含的。這是正常的，因爲聖經裏不是一切都說得直白。關於上帝是三位一體這一最主要的教訓，就是從聖經隱含地推論出來的。我們的反對者自己也從聖經隱含地推論許多東西。例如，任何地方都沒有說不能給嬰兒施洗，然而他們不合理地斷言不能給嬰兒施洗，並且不因聖經裏沒有說而困擾。他們試圖從聖經的別的論斷隱含地推出這一禁止。所以極重要的是把他們引到這個領域，請他們對禁止向聖人祈禱給出一個有意義的理解。
還有，親愛的朋友，也要記住：反對向聖人祈禱的人，所反對的根本不是代求性的祈禱（因爲很容易證明：他們彼此祈禱時自己就是彼此的代求者，無論他們怎樣爭辯）。他們最反對的，是**地上教會與天上教會的相通**——反對與聖潔的靈——聖天使和聖人們、上帝的朋友們——的任何相通。彷彿地上的教會對天上的教會生了氣，不願意與她交談；彷彿基督身體的一部分不願與同一身體的另一部分相通。他們連一句話都不允許，甚至不允許向護守天使爲他的關懷感謝一句。因爲一旦承認與屬靈世界中的聖人們哪怕最小的相通可能，很快留給他們的，就只剩下一步一步地承認與地上教會和天上教會的相通相關的一切了。所以，作爲問題之一，值得考察與天使相通的可能——聖經中這一點展現得非常廣泛。
