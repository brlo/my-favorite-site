# 假師傅的手法
## 1. 動聽的學說
假師傅們將要編出動聽的學說，正是因爲他們的聽衆將尋求悅耳的學說，忍受不了純正的教導：
> 2tim 4:3 :: !人必厭煩純正的道理 :: !耳朵發癢，就隨從自己的情欲，增添好些師傅
> 1tim 4:1-2 :: !必有人離棄真道，聽從那引誘人的邪靈和鬼魔的道理
## 2. 虛假的敬虔
> 2tim 3:1-2,5,7-8 :: !末世必有危險的日子來到 :: !有敬虔的外貌，卻背了敬虔的實意 :: !這等人也怎樣敵擋真道
> mf 7:15 :: !你們要防備假先知。他們到你們這裏來，外面披著羊皮，裏面卻是殘暴的狼
## 3. 展示性的奇蹟
使徒們和古代基督徒被賜予豐富的行異能之力，不是爲了作秀，而是爲了益處：
> 1kor 12:7 :: !聖靈顯在各人身上，是叫人得益處
一小羣漁夫需要很大的幫助，才能作爲見證人，在短短一生中把傳道傳遍全世界。使徒們曾警告說，這些恩賜將要止息：
> 1kor 13:8 :: !先知講道之能，終必歸於無有；說方言之能，終必停止
基督自己也斥責尋求奇蹟：
> mf 12:39 :: !一個邪惡、淫亂的世代求看神蹟
在末後的時代，假先知將恰恰以奇蹟引誘人：
> mf 24:24; mk 13:22 :: !因爲假基督、假先知將要起來，顯大神蹟、大奇事
結果，在審判時，許多信徒將確信自己得救正是因爲他們奉基督的名行異能、說預言、趕鬼。但他們受了欺騙，被教導行不法之事，基督不認識他們，把他們從自己面前趕走：
> mf 7:22-23 :: !當那日，必有許多人對我說 :: !奉你的名行許多異能嗎 :: !我從來不認識你們，你們這些作惡的人，離開我去吧
# 如何認出假先知
他的預言不成就：
> vtor 18:22 :: !所說的若不成就，也無效驗
如果先知或作夢的向你顯個神蹟、奇蹟，或他的夢應驗了，但他召你去事奉別的神，那就不當聽他的話：
> vtor 13:1-4 :: !向你顯個神蹟奇事 :: !他所顯的神蹟奇事，雖有應驗 :: !我們去隨從你素來所不認識的別神 :: !你也不可聽那先知或是那作夢之人的話 :: !你們要順從耶和華你們的上帝

# 前言
主耶穌基督兩千多年前，按古代先知的[[ru:пророчества-о-Христе|話語]]，由至潔的童貞女馬利亞所生（不經男子）。他在少年時（十二歲）就已具有大智慧，令耶路撒冷聖殿中的教師們驚奇。到三十歲之前，耶穌基督順服於約瑟，作尋常的勞動；三十歲時出來傳道。關於這一時期的詳情：[[ru:Христос-жизнь-в-Палестине|基督——在巴勒斯坦的生活]]。
之後，主耶穌基督傳道，教導了門徒（使徒們），被出賣，在十字架上受難，第三天復活，四十天之久向自己的跟隨者顯現，教導他們天國的事，然後昇天，坐在上帝的右邊，並應許要第二次再來——正如他昇天那樣——爲要審判全宇宙。再過十天（從復活算起的第五十天），他建立了自己的教會，並永遠地把聖靈賜給了教會。
# 關於假基督
## 欺騙者
主耶穌基督親自警告說，將有人冒充他來臨，許多人會相信這些欺騙者：
> mf 24:3-5 :: !你們要謹慎，免得有人迷惑你們 :: !因爲將來有好些人冒我的名來，說：『我是基督』，並且要迷惑許多人
# 關於基督的降臨
## 降臨——如同閃電
然而，基督的第二次降臨將立刻被全世界的人知道，如同閃過的閃電：
> lk 17:23-24 :: !你們不要出去，也不要跟隨他們 :: !好像閃電從天這邊一閃直照到天那邊 :: !人子在他降臨的日子
> mf 24:26-27 :: !你們不要出去 :: !你們不要信 :: !閃電從東邊發出，直照到西邊；人子降臨，也要這樣
## 與所有天使一同降臨
基督的第二次降臨將帶著父的榮耀，與所有聖潔的天使一同來臨：
> zah 14:5 :: !耶和華我的上帝必降臨，有一切聖者同來
> mf 25:31 :: !當人子在他榮耀裏 :: !同著衆天使降臨的時候
> mk 8:38 :: !同聖天使降臨的時候
> mf 16:27 :: !同著衆使者降臨
> iud 1:14 :: !主帶著他的千萬聖者降臨
> 1sol 3:13 :: !當我們主耶穌同他衆聖徒來的時候
> 2sol 1:7 :: !主耶穌同他有能力的天使從天上在火焰中顯現
## 以已有的成人身體降臨
基督不會再次由人所生，而是帶著他已有的身體來臨——那身體是他在公元一世紀由童貞女馬利亞上帝之母所生時獲得的。
> act 1:9-11 :: !他就被取上升，有一朵雲彩把他接去 :: !這離開你們被接昇天的耶穌，你們見他怎樣往天上去，他還要怎樣來
## 降臨是爲了審判
主來不是爲了教導，而是按他第一次來時所已經賜下的話語施行審判：
> in 12:48 :: !就是我所講的道，在末日要審判他
> mf 16:27 :: !他要照各人的行爲報應各人
> mf 25:31-33,46 :: !當人子在他榮耀裏 :: !要坐在他榮耀的寶座上 :: !萬民都要聚集在他面前 :: !好像牧羊的分別綿羊山羊一般 :: !這些人，要往永刑裏去 :: !那些義人，要往永生裏去
> 2sol 1:5-8 :: !這正是上帝公義判斷的明證 :: !那時，主耶穌同他有能力的天使從天上在火焰中顯現 :: !要報應那不認識上帝和那不聽從我主耶穌福音的人
