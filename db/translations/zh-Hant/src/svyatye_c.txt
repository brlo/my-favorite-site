# 爲什麼敬禮聖義者的聖髑
敬禮聖義者的聖髑，理由與敬禮聖義者本身相同（詳見下一篇[[ru:почитание-святых-в-Библии|敬禮聖人]]）；敬禮他們，是因爲他們分有上帝、因爲上帝的恩典在他們裏面運作（[[ru:человек-храм-Божий|人——上帝的殿]]）。敬禮的對象是義人的整體，而不是他的某一部分（[[ru:состав-человека|人性構成]]）。受敬禮的不只是**靈魂**，還有**身體**（[[4ts 13:21]]），甚至**遺物**（[[act 19:12]]）和**像**（[[act 5:15]]）——上帝藉它們施行奇蹟和醫治，賜下自己的恩典。
因爲聖人**受敬禮是由於他們分有上帝、由於上帝的恩典在他們裏面運作**，而上帝賜下自己的恩典，不但經由聖徒活著的身體，也經由他們死後的身體（[[4ts 13:21]]），所以聖徒的身體不只在生前、在死後（身體與靈魂分離之後）也因恩典而受敬禮。
上帝不厭惡自己朋友們的遺體。上帝看顧義人的遺骸（[[ps 34:19-20]]；[[in 19:33,36]]），並繼續藉它們行事（[[4ts 13:21]]）。持香的婦女們對遺骸也沒有厭惡——她們在救主死後第三天去開他的墳墓，要用香膏膏抹基督死去的身體（[[mk 16:1-3]]），儘管摩西的律法禁止除親屬之外的任何人接觸死者的身體（[[lev 21:1-4]]）。
# 常見的問題
## 爲什麼聖髑在聖殿裏，而不在土裏
**聖殿就是**義人遺骸的**墳墓**。聖髑保存在聖殿的石棺（聖髑匣、聖髑櫃）裏。上帝說人是土、所以要歸回土（[[gen 3:19]]），這話的意思是：人用土造成的身體[1]會重新變爲土，即朽壞分解，重新成爲它起初所是的——土。
許多義人並不是字面地被埋進土裏。相反，義人們力求以某種特別的方式安葬義人，常常爲安葬挑選專門的場所。
1. **亞伯拉罕把自己親人的遺體安葬在專門購買的洞穴裏**。他向當地的居民求葬地，而他們向他提出**最好的**葬地（[[gen 23:2-6]]）。最後，亞伯拉罕請求並買下他們所指的洞穴爲業（[[gen 23:7-13,17-20]]），好在那裏安葬自己的親人。就在同一個洞穴裏，後來安葬了亞伯拉罕本人（[[gen 25:9-10]]）、他的妻子撒拉（[[gen 23:19]]）、以撒和他的妻子利百加（[[gen 49:1,29-33]]）、雅各和他的妻子利亞（[[gen 49:1,29-33]]；[[gen 50:12-13]]）；
2. **主耶穌基督被安葬在岩石中鑿出的專門墓穴裏**——那是財主約瑟（亞利馬太人）爲自己鑿的（[[mf 27:57,60]]；[[mk 15:46]]；[[lk 23:50-53]]；[[in 19:41]]）。這正是上帝起初藉先知以賽亞預言所定的：“人還使他與惡人同埋；誰知死的時候**與財主同葬**”（[[is 53:9]]）；
3. **最早的基督徒常常把義人安葬在地下墓穴的專門墓室裏**，並在聖髑旁舉行事奉聖禮（[[ru:почитание-мощей-цитаты-святых#HH-Община-Поликарпа-Смирнского-II-век|例子]]）；
4. 三百年後、四世紀基督教安全的時代來臨，聖人的遺骸開始被安葬在聖殿裏：或如義人約瑟那樣安放在石棺中（[[gen 50:26]]；[[ru:почитание-мощей-цитаты-святых#HH-Григорий-Нисский-святитель-331-394|例子]]），或安置在聖殿主要部分（祭壇）下方專門的墓室（地窟）裏，或建造專門的單獨建築（殉道者紀念堂）（[[ru:почитание-мощей-цитаты-святых#HH-Амвросий-Медиоланский-святитель-397|例子]]）。
這樣，**從最古老的年代起，義人就把義人安葬在專門的場所，而不是土裏**。教會在今天也是這樣：義人的遺骸安放在專門場所——舉行事奉聖禮的聖殿——裏的石棺中。
無論我們怎麼做，實質是同一個：
- 或者建一座殉道者紀念堂來安放聖髑石棺，教會聚集在其中舉行事奉聖禮；
- 或者反過來，建一座舉行事奉聖禮的聖殿，把聖髑石棺安放在那裏。
教會從最古老的時代起就建造安放聖人棺柩的建築，並在那裏舉行事奉聖禮。
## 遷移聖髑
聖經中多次發生義人遺骸的遷移，沒有任何責難。例如，族長約瑟被安葬在埃及的石棺（聖髑匣）裏（[[gen 50:26]]），後來先知摩西與民衆四十多年抬著約瑟的遺骸走曠野，爲要在約瑟自己指定的地方安葬他。詳見[[ru:почитание-мощей-святых#HH-Эпизоды-об-останках-из-Библии|下文]]。
## 聖髑的分割
從最古老的年代起，聖義者的遺骸是在最殘酷的酷刑（砍碎、焚燒）之後到達教會的——不是完整的，也不是一下子全部（[[mf 14:11]]；[[mk 6:28]]）。而上帝后來照樣經由義人的遺骸行事，無論它們是否被收攏在一起。教會本身若保存了義人完整的遺骸，就把它們整體保存在安放於聖殿中的專門棺柩（石棺、聖髑匣）裏。分割可能出於不得已的原因：在自然災害和敵人襲擊時搶救聖髑。有時爲了在別處敬禮義人，只取聖髑極小的一粒碎屑。
# 上帝對人遺骸的態度
## 上帝保全義人的遺骸
> ps 34:19-20 :: !義人多有苦難 :: !又保全他一身的骨頭，連一根也不折斷
> in 19:33,36 :: !就不打斷他的腿 :: !他的骨頭一根也不可折斷
由此可見上帝自己對聖人遺骸的態度。儘管如此，上帝有時容許（而不是願意）義人受折磨，甚至被斬首，如先知施洗約翰（[[mf 14:11]]；[[mk 6:28]]）。但上帝也藉被分割的聖人遺骸賜下恩典。
## 上帝使罪人的遺骸蒙羞

# 上帝繼續經由義人死去的身體行事
觸摸先知以利沙的骸骨，死人復活了——旁邊甚至看不見祈禱的舉行：
> 4ts 13:21 :: !一碰著以利沙的骸骨，死人就復活站起來了
# 上帝繼續經由義人用過的物品行事
因使徒的衣物得醫治：
> act 19:12 :: !甚至有人從保羅身上拿手巾或圍裙放在病人身上，病就退了，惡鬼也出去了
# 上帝經由義人的像行事
因使徒的像得醫治：
> act 5:15-16 :: !指望彼得過來的時候，或者得他的影兒照在什麼人身上 :: !全都得了醫治
# 向聖人叩拜
十誡的第一誡（[[ish 20:2-3]]；[[vtor 5:6-7]]）禁止敬拜假神（偶像）。假神不但虛假，而且根本不存在。
聖人則真實存在，他們是上帝的朋友；向他們叩拜，不是把他們當神。向聖人和他們的聖髑叩拜，是表達對他們的敬意——作爲上帝的朋友。這樣的向天使、向人、向物件的叩拜在聖經中有，而且不是拜偶像，因爲拜偶像——是敬拜**假**神。義人們經常向人、向各種物件、向天使下拜；別人也向先知下拜。

## 遷移遺骸
### 約瑟
約瑟（雅各的兒子）請求日後把他的遺骸從埃及遷到上帝應許給他的那地：
> gen 50:24-25 :: !你們要把我的骸骨從這裏搬上去
約瑟死了，人們把他安葬在埃及，收殮在棺材（聖髑匣）裏：
| 約瑟死了，正一百一十歲。人用香料將他薰了，把他收殮在棺材裏，停在埃及。 ||| ctb gen 50:26
先知摩西履行了約瑟的請求：
> ish 13:18-19 :: !摩西把約瑟的骸骨一同帶去 :: !你們要把我的骸骨從這裏一同帶上去
先知摩西和以色列民**四十多年**抬著約瑟的遺骸在西奈半島上漂泊。後來，約書亞把約瑟的遺骸安葬在示劍（[[nav 24:32]]）。
考慮到四十年的西奈曠野漂泊——即以色列從埃及的奴役到應許之地的路程——是新約教會生活的預像：教會把人從罪的奴役中領出、引領人進入上帝所應許的天國；那麼在這教會的整個生命時期，上帝的民始終帶著義人的聖髑。舊約教會的預像，在到達自己的國之前，始終帶著義人的聖髑。
### 掃羅
掃羅被非利士人殺死；雅比的居民燒了他們的身體，把骨頭葬在自己城的柳樹下：
> 1ts 31:10-13 :: !將他的屍身釘在伯珊的城牆上 :: !將掃羅和他兒子的屍身從伯珊城牆上取下來 :: !用火燒了 :: !將他們骸骨葬在雅比的垂絲柳樹下 :: !就禁食七日
> 1par 10:12 :: !將他們的屍骨葬在雅比的橡樹下
大衛把掃羅的遺骸遷到便雅憫地，與掃羅父親的遺骸一同安葬：
> 2ts 21:12-14 :: !將掃羅和他兒子約拿單的骸骨搬了來 :: !大衛將掃羅和他兒子約拿單的骸骨從那裏搬了來 :: !將掃羅和他兒子約拿單的骸骨葬在便雅憫的洗拉 :: !在掃羅父親基士的墳墓裏 :: !此後上帝垂聽國民所求的
## 延遲安葬的情形
雅各的安葬是在77天多之後舉行的：
| 約瑟伏在他父親的面上哀哭，與他親嘴。約瑟吩咐伺候他的醫生用香料薰他父親，醫生就用香料薰了以色列。薰屍的常例是**四十天**；那四十天滿了，埃及人爲他**哀哭了七十天**。我父親曾叫我起誓說：**你要將我葬在迦南地，在我爲自己所掘的墳墓裏**。現在求你讓我上去葬我父親，以後我必回來。法老說：你可以上去，照著你父親所說的去葬他。於是約瑟上去葬他父親。**與他一同上去的，有法老的一切臣僕**…… ||| ctb gen 50:1-3,5-13

# 約西亞王敬禮先知的聖髑
論到約西亞說：在他以前沒有王像他、在他以後也沒有興起王像他，因爲他盡心、儘性、盡力歸向上帝（[[4ts 23:25]]）。猶大王約西亞自幼順服上帝，成年後開始潔淨自己的國家脫離異教：他摧毀異教的像、祭壇、燒香的異教邱壇、異教的神聖樹叢，禁止祭司的事奉，消滅了行邪術的和交鬼的，潔淨並修理了耶路撒冷上帝的聖殿，找到了聖經的書卷，向民衆宣讀，民衆被帶入與上帝所立的約。約西亞不但摧毀異教的邱壇，還力求玷污它們——把人的骨頭撒在那裏：
> 4ts 23:13-14 :: !王都污穢了 :: !將人的骨頭充滿了那地方
約西亞毀滅了耶羅波安的舊偶像，玷污了那裏的墳冢：
> 4ts 23:15-16 :: !將墳墓裏的骸骨取出來，燒在壇上，污穢了壇
然而，當他遇到一座紀念碑，查明那是預言了這些事件的先知的墳墓時，他就恭敬地對待他的聖髑。此外，紀念碑本身的存在，表明先前對先知的敬禮：
> 4ts 23:17-18 :: !我所看見的是什麼碑 :: !這就是他的墓碑 :: !由他吧！不要挪移他的骸骨 :: !他們就不動他的骸骨
這同一位神人先前就預言了這件事將要發生：
> 3ts 13:2 :: !壇哪！壇哪 :: !大衛家裏必生一個兒子，名叫約西亞 :: !人的骨頭也必燒在你上面
# 西門敬禮親人的遺骸
大祭司約拿單（[[1mak 10:20]]；[[1mak 11:57]]）被安葬在巴斯加瑪。後來，他的兄弟、大祭司西門（[[1mak 13:36,42]]）把他的遺骸遷到祖城摩丁——此前猶大也被安葬在那裏（[[1mak 9:19]]）。西門修建了一座高大的建築，以此敬禮親人的遺骸：
| 當他臨近巴斯加瑪時，將約納堂殺死，就埋葬在那裏。**息孟遣人去運回他兄弟的骨骸，將他埋葬在他祖先的摩丁城裏。**全以色列都舉哀痛吊他，哀哭多日。之後，息孟在他父親與他兄弟們的墳墓上，用前後光澤的石頭，修了一座相當高大的紀念碑，從遠處可以望見。他爲父母和四個兄弟，還立了七座金字塔，彼此相對；且爲塔作了一些裝飾品，就是在四周，立了一些大石柱，石柱上刻了武器，**作爲永久的記念**；又在武器旁，彫刻了船像，使航海的人都可以看到。息孟在摩丁修建的**這座墳墓**，至今猶存。 ||| sb 1mak 13:23,25-30
