# 前言
“唯獨聖經”是一種用來建立自己教會的伎倆。如同街頭猜杯戲法的把戲，用簡單而靈活的手法把聽衆繞暈，使他們覺察不到就在眼前進行的調包。他們傳授的並不是“只按聖經”的教訓，而是又一種對聖經的解釋——擯棄一切不符合新教師個人信仰（他的意見）的東西。教師的個人信仰被傳遞給聽衆，成爲又一個人的傳統。但這傳統不被稱爲傳統——伎倆就在這裏：聽衆產生一種錯覺，彷彿他們只按聖經相信。以前的異端團體就是這樣建立的：擯棄教會直接從使徒們與聖經一起領受的信仰，把教師們自己的意見高舉於一切之上，而這些意見彼此各不相同。無論出現多少教派，它們的教師們按聖經可以解釋出任何一種信仰。

# “唯獨聖經”
**“唯獨聖經”**（拉丁文 Sola Scriptura，俄文——Только Писание）——十六世紀改革家們（[[ru:3SlQ_Протестантизм|新教]]運動的創始者）提出的建立教義的方法：按照這一方法，建立教義的最高權威只是聖經（按讀者的主觀理解）。
雖然理論上如此，但在新教徒和新新教徒中間，廣泛地把“唯獨聖經”理解爲完全棄絕聖傳。願意在教父遺產領域論辯的新教徒並不多；而且最常見的是，在正教徒與新教徒的論辯中，只要提到聖教父的名字、更不必說他們的著作，就會遇到激烈的排斥和譏笑。“傳統”一詞在新教團體中被賦予負面的態度——把它與“古人的遺傳”（[[mf 15:2]]）等同起來，同時完全無視使徒聖傳的存在——而使徒們自己曾命令保守這傳統（[[2sol 2:15]]）：這信仰是主和使徒們以種種方式栽種在教會裏、並在教會中不斷保存、由祖先傳給後代的。
# 爲“唯獨聖經”辯護的嘗試
“唯獨聖經”的擁護者引用聖經的引文，擺出這樣的姿態，彷彿其中說的是必須把聖經當作信仰的最高或唯一權威。然而實際上，所引的引文中沒有一處說的是“唯獨聖經”，即彷彿**只有**聖經（除它之外什麼都沒有）在教義中擁有某種獨一的、最高的或唯一的角色。
爲“唯獨聖經”辯護所引用的引文有以下幾類。
## 1. 上帝的道——是真理
上帝以任何方式所宣告的（口頭的、書面的、異象中、經由使者：天使、先知或使徒）——都是真理：
> in 17:17 :: !你的道就是真理
對此我們不爭辯。上帝的每一句話都是真理，而不只是寫下的。口傳的聖傳也稱爲上帝的道：
> 1sol 2:13 :: !我們所傳上帝的道 :: !乃以爲是上帝的道
> 1pet 1:23-25 :: !惟有主的道是永存的 :: !所傳給你們的福音就是這道
對聖經都是上帝所默示的，我們也不爭辯：
> 2tim 3:16 :: !聖經都是上帝所默示的
## 2. 聖經對信徒是重要的
聖經對信徒有很高的價值：
> 2tim 3:16 :: !聖經都是上帝所默示的 :: !有益 :: !於教訓
> in 5:39 :: !你們查考聖經
對此我們同樣不爭辯。
---
這一切都是對的。正教會不與其中任何一點爭辯，而是自己肯定這一切。
然而：
- 這些引文並不表明真理**只**在聖經裏，而聖傳不是真理；關於聖傳的同樣的引文乾脆被忽略（見[[ru:Против_Сола_Скриптуры#HH-Указание-хранить-Предание-и-учить-согласно-с-ним|下文]]），因爲“唯獨聖經”的擁護者沒有維護聖傳之必要性的目標。
- 這些引文並不表明**一切**上帝的啟示都寫在了聖經裏、因此彷彿聖傳可以被拋棄。拋棄聖傳——是違揹聖經的行爲（[[2sol 2:15]]）。
所引的一切引文對於“唯獨聖經”這一概念中的“唯獨”一詞完全沒有說什麼。它們只是指明上帝啟示的必要性和它的真實性，無論這啟示以什麼形式被領受：書面的、口頭的或以可見方式顯示的。我們相信這一點，這裏沒有任何“唯獨聖經”的成分。
# “唯獨聖經”宣講者的伎倆
向聽衆表明聖經擁有很高的權威、聽聖經就是聽上帝之後，接下來在聽衆完全不覺察的情況下發生了調包：開始講話、按自己的意思解釋聖經的，不再是上帝和聖經，而是宣講者。於是現在被要求當作上帝的話來接受的——是宣講者的話，是幾千個在解釋聖經上彼此矛盾的團體之一的創立者的話。
當然，宣講者在自己的話語中繼續引用聖經，用一套引文支持自己的話；但這裏明顯的問題是：新教以這種方式生出了關於上帝、他的作爲和拯救方式的成千種隨便什麼樣的教訓。更有甚者，從基督教存在之初，教會之外的團體就力求歪曲信仰、恰恰藉著歪曲聖經把人引到自己那裏。連魔鬼也這樣做過——正是用聖經試探基督：
> mf 4:5-6 :: !可以跳下去 :: !因爲經上記著說 :: !主要爲你吩咐他的使者，用手托著你
魔鬼同樣藉著上帝的話語使最初的人墮落：
> gen 3:1-5 :: !上帝豈是真說不許你們吃園中所有樹上的果子嗎 :: !你們不一定死
這樣，魔鬼和與教會爲敵的團體的創立者們，正是使用聖經來誘惑人。這是怎麼發生的？發生的原因在於：把聖經的權威賦予了它的私人的解釋。
# “唯獨聖經”的根本問題——主觀主義
這一建立信仰之方式的根本問題在於：**不存在對聖經的客觀理解**。每個人都透過自己積累的經驗、世界觀、興趣和偏好來接受它，也就是**主觀地**接受。簡單地說，問題在於：**誰來決定什麼符合聖經、什麼不符合？**“唯獨聖經”不回答這個問題。恰恰是這一點使它成爲只在理論上存在、無法在實踐中實現的學說。這不是無根據的斷言。
“唯獨聖經”最早的使用者（改革家們）提出了以他們各自不同的、對聖經的理解爲基礎的不同教義。分歧涉及最重要的問題：
- 得救；
- 人是否被預定得救，
- 人的罪性，
- 聖奧祕在信徒生活中的角色，
- 基督在聖餐中臨在的真實性，
- 能否給嬰兒施洗，
- 信徒生活中有沒有聖像。
不同的教義立刻產生了不同的團體。而這只是開始。隨著時間推移，“唯獨聖經”使用者中間的分歧和分裂迅速增多；開始於路德、加爾文和英國國教的三個方向，後來發展出成千上萬個派別。
# “唯獨聖經”導致出現衆多聖傳
按宗教改革家們所宣稱的設想，“唯獨聖經”應當濾去人的聖傳。而實際上，每一個新的新教社團的創立者，都成了又一個人之聖傳的創立者——只是把自己的信仰披上聖經引文的外衣；在宗教改革之前很久，自從出現有權威的言論和文本以來，各種異端創始者就已經在這樣作了（詳見[[ru:Предание|聖傳]]）。
新的領袖周圍形成了一個社團，這社團所接受、保存並傳給自己後代的，不是別的，正是這位領袖的信仰。如果有人想加入這個社團，他就必須接受該社團領袖的信仰，並按該社團的理解去理解聖經。人到浸信會那裏來——就按浸信會的聖傳接受信仰；到五旬節派那裏——按五旬節派的聖傳；到復臨派那裏——按復臨派的聖傳，其餘的團體也是如此。不然他就會被排斥爲“異端”、被驅逐。
結果是，所有這些由“唯獨聖經”產生的社團都走到了這一步：要相信的根本不是“只按聖經”，而是嚴格按他們的聖傳——只按他們的領袖曾經說過的、而社團把它作爲聖傳保存下來的話，經由口頭的傳道和教師們的書籍，把知識從祖先傳給後代。只不過人們不把這稱爲聖傳，更不稱爲“人的聖傳”——這個詞作爲嚇人的東西，只會用來稱呼教會的聖傳。
# 社團領袖——信仰的源頭
如果聖經是某種自足的信仰源頭，那麼每個主張“只按聖經”建立信仰的人，本應與其他“唯獨聖經”的使用者有相同的信仰。然而他們所有人的信仰各不相同，也就是說信仰的源頭各不相同。這源頭就是**人**——社團的創立者。他發明了信仰，傳給自己的追隨者，而追隨者們則保存著自己領袖的信仰。
# 實際上，在新教社團中居首位的是他們自己的聖傳，而不是聖經
在所有這些社團中，居首位的正是他們的聖傳，聖經只被用作補充的工具，從中挑選有利於論證聖傳的引文。在這種團體中所接受的信仰實際上壓過了聖經，聖經文本只被用來在聽衆周圍製造肥皂泡——一種引人分心的幻覺，彷彿這裏信的只是“只有聖經”。
如果聖經與聖傳相牴觸，聖經很容易被忽略。例如，聖經中任何地方都沒有說嬰兒不能受洗；相反，洗禮的預像（割禮）恰恰行在嬰兒身上（[[gen 17:10-12]]），然而許多新教徒堅持禁止嬰兒受洗，從聖經裏舉出間接的理由。聖經中沒有說嬰兒不受洗也能得救；相反，救主說，除非從水和聖靈生，就不能進上帝的國（[[in 3:3,5]]），又命令爲萬民施洗（[[mf 28:19]]），卻不設年齡的限制；而未受割禮的人要從民中剪除（[[gen 17:14]]）——預像清楚地表明了洗禮的必要。
他們在保守只存在於自己聖傳中的信仰的同時，指摘教會關於司祭職分之恩典經由按手傳遞的教導，卻輕率地拋棄了論及上帝的恩賜**藉着**按手傳遞的最直白的話（[[2tim 1:6]]；[[act 8:18]]）。爲什麼？原因很簡單：他們的聖傳提供的是另一種信仰；既然聖傳壓過聖經，聖經的直白教導就被忽略了。
# 不誠實的對立
在“唯獨聖經”擁護者所建立的團體中，廣泛流傳著這樣的對立：教會拋棄了聖經、只按傳統相信；而每個新教團體相反——拋棄了傳統、只按聖經相信。
實際上：
- 教會不是隻按傳統相信——她把聖經與傳統平等地使用；
- 新教團體也不是隻按聖經相信——他們只承認自己領袖的信仰爲正確，並把它作爲傳統保存。
這樣，實踐中根本不存在任何“唯獨聖經”。它只存在於理論中。每個具體的人對這一概念的實現，必然帶來又一種新信仰、又一種對聖經的新理解、又一個團體，以及隨之而來的又一個傳統。
證明這一點並不難。做一個實驗就夠了。如果一個人進入這樣的團體之一，而這團體不向他傳遞自己的知識、只是把一本聖經放在他手裏，那麼只讀這一本聖經，這個人百分之百不會得出這個團體的信仰。他只有在一種情況下才會得出他們的信仰——如果這團體把自己的信仰傳給他。
正教會用聖經證實自己全部的教義。然而新教團體不同意教會性的聖經理解，提出以自己的理解和信仰來代替“唯獨聖經”（默不作聲）。
# “唯獨聖經”與聖經直接衝突
正教會反對“唯獨聖經”的理由，不是針對“聖經”一詞，而是針對“唯獨”一詞。而理由正是建立在聖經上的：
1. “唯獨聖經”在聖經裏沒有。聖經本身沒有建立“只按聖經”的信仰、或只偏愛聖經的要求。因此新教徒只能引用關於聖經之重要性的引文（對關於聖傳之重要性的引文避而不談），因爲聖經裏關於“唯獨聖經”的引文根本沒有。
2. 相反，聖經說要保守口傳的聖傳。多次要求保守聖傳：不僅是使徒們書面的、還有口頭的宣講（[[2sol 2:15]]）。而且使徒們把口頭宣講放在第一位（[[2sol 2:15]]）。
3. 聖經要求向教會的教師們學習。上帝在教會裏設立了司祭們和教師們（[[1kor 12:28]]；[[ef 4:11]]），教會的羊羣（會衆）被託付給他們管理並教導。“唯獨聖經”的擁護者拒絕向教會學習。這些人不願在教會裏作學生，就宣佈自己爲教師（[[2tim 4:3]]）。
4. 聖經可能被錯誤地解釋。聖經裏有話：未經教會堅立的人強解聖經，自取沉淪（[[2pet 3:15-16]]）。“唯獨聖經”的擁護者甚至不打算向教會學習。他們自己擯棄教師、只拿了教科書，隨意解釋聖經，這使他們成爲衆多分離的團體——有著不同的信仰和不同的對教科書（聖經）的理解。而聖經裏說：不經教會的教導而自己解釋聖經，導致歪曲聖經和滅亡（[[2pet 3:15-16]]）。
這樣，“唯獨聖經”的擁護者在以下各點上行事違揹聖經：
1. 教導聖經裏沒有的東西。聖經裏沒有關於“唯獨聖經”的教訓；
2. 擯棄使徒們口傳的聖傳。他們說只有聖經具有首要意義，卻與聖經裏所記使徒的話背道而馳——使徒們要求保守聖傳，把口頭宣講放在第一位，然後纔是書面的（[[2sol 2:15]]）；
3. 擯棄教會的教導職分和上帝所立的教會教師們，直接違揹聖經（[[1kor 12:28]]；[[ef 4:11]]）。
4. 不經教會的堅立而解釋聖經。每個新教團體都有自己的聖經理解；團體的每個聚會點、乃至聚會點中的每個人，都可以隨己意理解聖經，因爲“唯獨聖經”催促人擯棄聖經（按讀者的理解）之外任何其他教義來源的最高權威。如果一個人喜歡另一種對聖經的理解，那它就被認爲是正確的——畢竟聖經比宣講者的話更大，哪怕那宣講者是新教的。
# “唯獨聖經”觀念錯誤的最主要證明
如果發明“唯獨聖經”的目的是儘可能地分裂基督教世界，那麼這一觀念極其有效。但如果發明它的目的是尋找使徒的信仰，那麼“唯獨聖經”就成了錯誤的觀念，它使人遠離目標，並生出了衆多的傳統和分裂。
“唯獨聖經”錯誤的最主要證明——就是“唯獨聖經”的使用者們自己：以“只按聖經”爲口號建立的、無數彼此矛盾的團體及其教義。沒有任何別的觀念像“唯獨聖經”那樣在信基督的人中製造了這麼多分裂。而這是直接違揹聖經作的（[[in 17:20-21]]；[[1kor 1:10]]；[[1in 2:18-19]]）。
> in 17:20-21 :: !使他們都合而爲一 :: !叫世人可以信你差了我來
> 1kor 1:10 :: !都說一樣的話 :: !不可分黨 :: !一心一意 :: !彼此相合
> 1in 2:18-19 :: !現在已經有好些敵基督的出來了 :: !他們從我們中間出去，卻不是屬我們的
---
十六世紀，改革家路德提出了“唯獨聖經”的概念。後來每個改革家都開始建立信仰，如他們所宣稱的，把最高權威賦予“只按聖經”（即對聖經的自己理解）。原本以爲只按聖經建立信仰，應當使人們得出使徒的信仰。這樣就宣稱：正是這個方法、並且只有這個方法，使人得以達到使徒的信仰。但結果，所有改革家都與構想相違，得到了各不相同的信仰。
“唯獨聖經”的進路最初產生了三個對聖經理解不同的方向：信義宗、加爾文宗和英國國教。後來，這一概念使地球上的任何人都可以建立自己的團體和自己的教義——只要拿起一本聖經。於是就出現了成千上萬的所謂“宗派”，每個都有自己的信仰和自己的聖經理解。這一過程至今仍在繼續。因信仰的差異，按人的習俗（[[1kor 3:3]]），他們彼此分離，各有不同的信仰、不同的洗禮和不同的上帝觀。這一切都與教會中應有的樣子相違揹：
> ef 4:4-5 :: !身體只有一個 :: !一主，一信，一洗
有人可能就信仰上帝的不同提出異議，說大家都信耶穌。然而並非人人都有使徒們對基督作爲上帝的信仰；有不少新教一位論者，否認對獨一上帝——父、子、聖靈三位一體——的信仰。此外，許多團體對上帝、對他的旨意和討他喜悅的方式有不同的觀念。比如五旬節派/靈恩派認爲，上帝喜悅他們無條理的喃喃、倒在地上，彷彿這一切都是聖靈——即上帝——的運作。而別的團體則拒絕五旬節派對上帝的這種觀念，提出自己另外的觀念。這樣，他們對上帝有不同的觀念，有時甚至有關於上帝的不同教訓。
無數手拿聖經、彼此矛盾、宣稱又建立了一種“只按聖經”之信仰的人，是反對“唯獨聖經”的最鮮明論據。人們曾應許說，藉著“唯獨聖經”會鋪就通向唯一使徒信仰的道路，把信仰從“人的附加物”中解放出來；但實際上，這一進路生出了無數人的附加物，沒有給基督教世界帶來任何東西，只有無數的分裂——違揹上帝關於信徒合一的旨意（[[in 17:20-21]]；[[1kor 1:10]]；[[1in 2:18-19]]）。
## 舊約中的平行
類似的分裂在舊約中也發生過——在建造巴比倫城和塔的時候（[[gen 11:1-9]]）。人們想靠自己的力量建一座城和一座通天的塔（[[gen 11:4]]），但開始說不同的話（[[gen 11:7]]），分裂並分散了（[[gen 11:8]]）。如今也是這樣。
上帝建立了教會，永遠賜給她聖靈（[[in 14:16]]），自己應許常與她同在（[[mf 28:20]]），口傳了教訓，立了司祭（[[act 20:17-18,28]]）和教師（[[1kor 12:28]]）——他們口頭教導，但也進行書信往來。
十五個多世紀之後，來了些人，從教會裏只取了教會所保存的部分使徒的書信（並非全部），違揹這些書信，擯棄了不可戰勝的教會（[[mf 16:18]]）——上帝所立的根基；擯棄了從使徒領受、保存在教會裏的信仰——使徒們的聖傳（[[2sol 2:15]]等）；擯棄了上帝所立的司祭（[[act 20:17-18,28]]）和教師（[[1kor 12:28]]）；決意按自己的聰明和力量（歷史、考古、語言學等研究）獨立地、與上帝所建立的教會分離地，建造自己的城。別的建造者也加入了他們。結果，他們開始說不同的話，分裂並分散，開始建造自己的、各有自己交流語言的居住地，而不願住在那座“有根基的城——其設計者和建造者乃是上帝”（[[evr 11:10]]）。
# “唯獨”聖經導致“唯獨”式思維
新教的教訓包含許多帶“唯獨”一詞的論點，它常使擁護者陷入一種思維，可簡稱爲“唯獨”式思維。這使其中許多人只注意文本中自己喜歡的一些片段，在合適的地方想像出“唯獨”一詞，彷彿對自己說：“只有這些話我應當考慮”，並在這上面建立某種構造。當某文本的作者考察同一事物的不同方面——或依次、或在作品的不同地方描述它們——時，新教徒往往只選出一樣，把它絕對化。
- 例如，使徒們寫道，得救既需要信心，也需要行爲。“唯獨”式思維使人只挑選關於信心的片段，並加上“唯獨”一詞。
- 使徒們既寫聖經，也寫聖傳的必要。“唯獨”式思維使人只挑選關於聖經之重要性的片段，並加上“唯獨”一詞。
在研究古代作家的文本時，這種思維幾乎處處顯現。
- 例如，作者們在解釋聖餐時給出兩種解釋（字面的和象徵的）；新教徒傾向於只看見象徵性的解釋，試圖把這些作者說成自己“唯獨”式教訓的擁護者。
按這一原則產生了許多異端。耶穌基督是人這一事實，難道意味著他**只是**人？不，他也是上帝。而如果他是上帝，這是否意味著他**只是**上帝？不，他也是人。如果基督是父的像，這是否意味著他**只是**像（僅是畫像）？不，他還是真上帝、真人。多少人在這裏跌倒，至今仍在跌倒。這裏也是一樣：象徵性的解釋不否定字面的，字面的也不否定象徵的。
正教徒承認聖經和聖傳、信心和行爲的必要，承認聖餐的字面理解，也同時承認其象徵的意義——沒有任何東西妨礙這一點。許多新教徒到處堅持“唯獨”一詞，乾脆無視同一位作者的其他話語。
# 耶路撒冷會議與聖經
教會不是按“只按聖經”的原則生活的最鮮明證據之一，是使徒們主持的第一次教會會議——耶路撒冷會議的事件。
在耶路撒冷會議上，沒有聖經的指示，廢除了摩西的律法、割禮、不潔食物的禁令、安息日的安息、接觸死人的禁令、與外邦人交往的禁令等等。這一決定是教會聚集一起商議後作出的（[[act 15:22]]）。這作成時沒有引用聖經，因爲聖經的作者——聖靈——住在教會裏；所以會議的決議不是用“因爲經上記著”這句話確立，而是指著聖靈和教會的旨意：“因爲聖靈和我們定意”（[[act 15:28-29]]）。
這樣，廢除摩西的律法，是聖靈和教會的決定。另一方面，反對他們的是從法利賽教門信了主的基督徒（[[act 15:5]]）。在後者一邊有聖經中一些可理解的經文（[[gen 17:14]]）。在使徒們一邊的，恰恰是教會的權威：如經所記，他們與全教會一同商議（[[act 15:22]]），然後宣佈了共同的決定。他們沒有用聖經，而只是憑自己的話，向那些按聖經要求守律法的人指明了律法的廢除。
聖經裏說必須受割禮，不割禮的人要從民中剪除（[[gen 17:14]]）。但使徒們並沒有吩咐教導這個：
> act 15:24 :: !有幾個人從我們這裏出去 :: !惑亂你們的心 :: !其實我們並沒有吩咐他們
但這可是聖經裏說的。根據什麼不需要教導這個？根據哪部聖經決定不需要受割禮？哪部聖經允許吃豬肉？——這不是按聖經作的，而是按全教會的、證實真理的會議決定（[[1tim 3:15]]）。
從那時起，耶路撒冷會議的決定成爲教會的聖傳：
> act 16:4 :: !把耶路撒冷使徒和長老所定的條規交給門徒遵守
---
耶路撒冷使徒會議的主席、使徒雅各，在自己的講話中回憶先知阿摩司的話。這預言裏沒有受割禮的話：
> am 9:11-12 :: !我必建立大衛倒塌的帳幕 :: !使以色列人得以東所餘剩的和所有稱爲我名下的國
如果以此爲根據接受耶路撒冷會議所作的（某種對聖經的隱含引用和提及聖靈），那麼按理也應當接受正教會的所有大公會議，而不只是耶路撒冷會議，因爲聖靈被賜給教會，不是隻在耶路撒冷會議時，而是永遠：
> in 14:16 :: !叫他永遠與你們同在
基督自己也應許常與教會同在：
> mf 28:20 :: !我就常與你們同在，直到世界的末了
在所有會議上——包括捍衛聖像敬禮的第七次會議——都有來自聖經的遠爲更有分量的依據。聖靈仍然在教會裏。按這樣的論據，所有會議都應當被接受。

# 對批評的回應
## “當求問律法和訓誨”（賽 8:20）
爲“唯獨聖經”辯護的人引用舊約的這段引文：
> is 8:19-20 :: !當求問那些交鬼的和行巫術的 :: !人當以訓誨和法度爲標準
1. 這裏絲毫沒有說聖經高於聖傳。何況，在巫術與聖經之間當然要選擇聖經。這幾句話講的是把摩西五經（妥拉）和預言（先知們的話）與巫士和靈媒的話相比較——民中根本不應當有這樣的人（[[vtor 18:9-14]]）。先知以賽亞建議把妥拉和先知的話作爲外在的工具，用以責備巫士，向民衆指明巫士所說的與上帝所說的之間的區別。
2. 再者，在舊約時代，聖經原則上不可能與聖傳分離。沒有聖傳，不僅不可能正確理解它，甚至不可能正確誦讀它，因爲它只用輔音字母寫成（詳見[[ru:евангелисты-обращаются-к-Септуагинте|詳見]]）。不知道讀音，同一個詞可以讀得不同。要正確誦讀這些話，就必須處於誦讀的傳統中；而這一傳統作爲聖傳由祖先傳給後代。所以一切關於聖經的話都與聖傳不可分。
3. 應當提醒對手他們自己的論題——“唯獨聖經”堅持“唯獨”（Sola）一詞，即只有聖經是最高權威。然而在所引的引文裏，沒有聖經權威的這種獨一性，沒有“唯獨”一詞（或類似的話）——而這正是“唯獨聖經”擁護者想看見的。如果僅以沒有直接提到聖傳爲理由就把“唯獨”加在這裏，那就應當一貫地承認：在另一些類似的引文裏是在提議“只按聖傳”建立信仰，因爲那裏沒有提到聖經：
> 2tim 1:13 :: !你從我聽的那純正話語的規模
> 2tim 2:2 :: !你在許多見證人面前聽見我所教訓的 :: !也要交托那忠心能教導別人的人
遵行所聽見的聖傳，不僅使人能分辨正確與錯誤，還能——無窮得多——使人住在上帝裏面：
> 1in 2:24 :: !務要將那從起初所聽見的常存在心裏 :: !若將從起初所聽見的存在心裏，你們就必住在子裏面，也必住在父裏面
甚至主耶穌基督自己也召呼人保守所聽見的——當時幾乎全部新約聖經都已寫成：
> otkr 3:3 :: !所以要回想你是怎樣領受、怎樣聽見的 :: !又要遵守
這是否意味著主和使徒們教導“唯獨聖傳”？要知道，寫下了聖經的他們，在這裏甚至沒有提到聖經，而是要求遵行聖傳。
只拿這些經文，教會的反對者也可以用完全相同的方式發明相反的極端——論題“唯獨聖傳”。但他們沒有領受使徒的聖傳——他們在使徒之後十五個多世紀纔出現；因爲沒有維護聖傳的目標，他們也不引出關於聖傳的這類極端。而教會從使徒們領受了聖傳和聖經兩者，既不擯棄這一個，也不擯棄那一個，也不擯棄使徒們關於保守口傳聖傳的誡命，認爲聖經和聖傳同是真實的。
## “不可越過聖經所寫的”（林前 4:6）
> 1kor 4:6 :: !免得你們自高自大 :: !貴重這個，輕看那個
這裏說的是某部寫下的文本，人應當據此明白：不可彼此自高。這裏說的是哪個文本？是同一封書信的前一章，其中講授了關於對自己看法要低的功課。使徒提議從他們學習不彼此自高、不越過剛寫下的內容去推想。
這封書信是因爲哥林多團體中產生的分裂而寫的。整個第2章使徒貶低自己和亞波羅的意義，高舉基督，爲要阻止哥林多教會分結成“屬保羅的”和“屬亞波羅的”（[[1kor 3:4-7]]），阻止教會分成黨派。分裂的人不同的不是教訓（否則使徒就會說教訓），而是彼此的態度。他們按教會教師的名字分派系。彷彿教會中的每個人都應當只與在同一教師門下學習的人相通，而擯棄其他教會教師的學生。爲改正這種錯誤的思維，使徒貶低了那些結成派系的名字的意義——即貶低自己和亞波羅，高舉基督。
稍下一點，在總結所說的話時，使徒用別的話講同一件事，呼召人跟隨的已不是寫下的，而是他自己：
> 1kor 4:16-17 :: !所以，我求你們效法我 :: !因此我已打發提摩太到你們那裏去
這樣，引文所說的是：基督徒不應當越過使徒所寫下的榜樣去推想自己，而應當聽從對自己看法要低的呼召，不彼此自高、不分裂。
在這封書信裏使徒誇獎哥林多人保守聖傳：
> 1kor 11:2 :: !又堅守我所傳給你們的
並說哥林多人若持守所傳的，就得救：
> 1kor 15:1-2 :: !能以持守我所傳給你們的
還有許多關於口傳聖傳的別的話，前文已提過。舉出其中一部分：
> 2tim 1:13 :: !你從我聽的那純正話語的規模
> 2tim 2:2 :: !你在許多見證人面前聽見我所教訓的 :: !也要交托那忠心能教導別人的人
> 1in 2:24 :: !務要將那從起初所聽見的常存在心裏 :: !若將從起初所聽見的存在心裏
## “連使徒和天使若傳別的，也不要聽？”
從“唯獨聖經”的擁護者那裏可以聽到這樣的論據：使徒把自己的書信放在他自己、甚至上帝的天使之上。他們引用這行經文：
> gal 1:8 :: !與我們所傳給你們的不同，他就應當被咒詛
使徒這裏說的不是自己，而是指那些彷彿以使徒們的名義寄給團體的假書信：
> 2sol 2:2-3 :: !有冒我名的書信 :: !說主的日子現在到了 :: !不要輕易動心 :: !也不要驚慌 :: !並有那大罪人
他也教導不要聽那些人的“啟示”——他們虛假地宣稱自己說天使的語言、彷彿由天使說預言。
怎麼確定書信不是來自使徒、啟示不是來自天使？其中傳達的是另一種信仰——不是使徒們一次所傳的。當然，使徒並不試圖奪走上帝賜給使徒的權柄。前面的話，以及整封書信，都是針對起來教導人的教師們寫的——他們把加拉太人誘向猶太教。
> gal 3:1 :: !無知的加拉太人哪 :: !誰又迷惑了你們呢
> gal 4:11 :: !我爲你們害怕
> gal 5:7,12 :: !你們向來跑得好 :: !有誰攔阻你們 :: !恨不得那攪亂你們的人
使徒的意圖——是保護自己的羊羣脫離假教師，而不是脫離他自己，更不是脫離上帝的天使。聖天使不可能把上帝的教會——他們所事奉的上帝的教會——從真道路上誘離。使徒只是清楚地表明：應當持守那一次由他所傳的信仰；而誰不這樣教導，哪怕他裝作使徒、或裝扮成上帝的天使，也不應當接受。

# 結論
爲維護“唯獨聖經”的論題使用這樣的手法：既然沒有關於“唯獨聖經”的明確引文，就展示關於聖經之重要性的引文，而對關於聖傳之重要性的引文忽略並緘默。這樣，聽衆應當覺得彷彿只有聖經纔有重要性。
新教徒常責備正教徒說：
——只要在聖經裏指出哪裏寫著要敬禮聖像、向聖人祈禱等等。
我們指出，但對他們說：
——聖傳也是重要的，這連聖經也證實。
於是他們說：
——不，只有聖經重要。
這時我們就請他們：
——那就請在聖經裏指出：只有聖經重要，或聖經比聖傳更重要。
他們無法指出這樣的話，因爲聖經裏沒有這樣的字句。要求我們出示關於聖像、關於向聖人祈禱的話，他們卻拿不出完全相同的一句話來證明一切都應當只在聖經裏。他們不能符合自己向別人提出的要求，表現出雙重標準。
這東西是他們自己發明的；他們自己要求我們把一切都指給他看，而自己卻不能在聖經裏指出自己的原則。
這樣，“唯獨聖經”的論題自相矛盾，並沒有使發明它的人達到使徒的信仰；相反，它使人遠離目標，而生出了衆多的傳統和分裂。
