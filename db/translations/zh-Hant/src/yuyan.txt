# 主耶穌基督第二次降臨時的事件
## 天上要出現十字架
> mf 24:30 :: !那時，人子的兆頭要顯在天上 :: !地上的萬族都要哀哭 :: !駕著天上的雲降臨
## 基督要與所有聖潔的天使一同來臨
基督的第二次降臨將帶著父的榮耀，與所有聖潔的天使一同來臨：
> mf 25:31 :: !同著衆天使降臨的時候
> mk 8:38 :: !同聖天使降臨的時候
> mf 16:27 :: !同著衆使者降臨
> iud 1:14 :: !主帶著他的千萬聖者降臨
> 1sol 3:13 :: !當我們主耶穌同他衆聖徒來的時候
> 2sol 1:7 :: !主耶穌同他有能力的天使從天上在火焰中顯現
> zah 14:5 :: !耶和華我的上帝必降臨，有一切聖者同來
## 他將施行死人的普遍復活
所有曾經活過的人——義人和不義的人——的普遍復活：
> act 24:15 :: !無論善惡，都要復活
復活將在改變後的不朽身體中發生，義人要發光如同太陽：
> mf 13:43 :: !那時，義人在他們父的國裏，要發出光來，像太陽一樣
在第二次降臨之前死去的人，其靈魂停留在等候復活的居所。義人的靈魂與基督在天上一同喜樂（[[evr 12:22-23]]；[[otkr 6:9-11]]），而罪人的靈魂則在另一處受苦（[[lk 16:23]]）。
那些到基督第二次降臨的時刻還沒有經歷死亡的人，他們的身體也將像從死裏復活之人的身體一樣改變：
> 1kor 15:42,44,51-53 :: !死人復活也是這樣：所種的是必朽壞的，復活的是不朽壞的 :: !所種的是血氣的身體，復活的是靈性的身體 :: !我們不是都要睡覺，乃是都要改變 :: !就在一霎時，眨眼之間，號筒末次吹響的時候 :: !死人要復活，成爲不朽壞的，我們也要改變 :: !這必朽壞的總要變成不朽壞的
> 1sol 4:13-17 :: !論到睡了的人 :: !那已經在耶穌裏睡了的人，上帝也必將他與耶穌一同帶來 :: !我們這活著還存留到主降臨的人，斷不能在那已經睡了的人之先 :: !主必親自從天降臨 :: !那在基督裏死了的人必先復活 :: !以後我們這活著還存留的人必和他們一同被提到雲裏 :: !這樣，我們就要和主永遠同在
## 基督將差遣天使聚集萬民受審
天使將聚集義人和不義的人：
> mk 13:27 :: !他要差遣天使，把他的選民
> mf 13:41 :: !人子要差遣使者，把一切叫人跌倒的和作惡的，從他國裏挑出來
## 基督將宣告判決
> mf 25:31-46 :: !當人子在他榮耀裏 :: !要坐在他榮耀的寶座上 :: !好像牧羊的分別綿羊山羊一般 :: !你們這蒙我父賜福的，可來承受那創世以來爲你們所預備的國 :: !你們這被咒詛的人，離開我 :: !這些人，要往永刑裏去 :: !那些義人，要往永生裏去
## 得救的人將被接到與基督同在的永生裏
在此之前，他們只是以靈魂與基督同在，等候身體的復活。如今，義人將在得了改變的身體（復活之後）後被接到與基督同在的永生裏：
> 1sol 4:16-17 :: !那在基督裏死了的人必先復活 :: !以後我們這活著還存留的人必和他們一同被提到雲裏，在空中與主相遇 :: !這樣，我們就要和主永遠同在
## 滅亡的人將被送去受永遠的刑罰
> mf 25:46 :: !這些人，要往永刑裏去 :: !那些義人，要往永生裏去
救恩與刑罰，如經上所記，都將是永遠的。
# 第二次降臨的重要細節
## 降臨——如同閃電
基督的第二次降臨將立刻被全世界的人知道，如同閃過的閃電：
> lk 17:23-24 :: !你們不要出去，也不要跟隨他們 :: !好像閃電從天這邊一閃直照到天那邊 :: !人子在他降臨的日子
> mf 24:26-27 :: !你們不要出去 :: !你們不要信 :: !閃電從東邊發出，直照到西邊；人子降臨，也要這樣
## 基督將以他已有的成人身體來臨
基督不會再次由人所生，而是帶著他已有的身體來臨——那身體是他在公元一世紀由童貞女馬利亞上帝之母所生時獲得的：
> act 1:9-11 :: !他就被取上升，有一朵雲彩把他接去 :: !這離開你們被接昇天的耶穌，你們見他怎樣往天上去，他還要怎樣來
## 降臨是爲了審判
主來不是爲了教導，而是按他第一次來時所已經賜下的話語施行審判：
> in 12:48 :: !就是我所講的道，在末日要審判他
> mf 16:27 :: !他要照各人的行爲報應各人
> mf 25:31-33,46 :: !當人子在他榮耀裏 :: !要坐在他榮耀的寶座上 :: !好像牧羊的分別綿羊山羊一般 :: !這些人，要往永刑裏去 :: !那些義人，要往永生裏去
> 2sol 1:5-8 :: !這正是上帝公義判斷的明證 :: !那時，主耶穌同他有能力的天使從天上在火焰中顯現 :: !要報應那不認識上帝和那不聽從我主耶穌福音的人
## 第二次降臨與審判密不可分
在基督第二次降臨時，施行審判的對象是一切的人，而不只是罪人。主要賞賜一些人，刑罰另一些人：
> mf 25:31-33,46 :: !當人子在他榮耀裏 :: !同著衆天使降臨的時候 :: !要坐在他榮耀的寶座上 :: !萬民都要聚集在他面前 :: !好像牧羊的分別綿羊山羊一般 :: !這些人，要往永刑裏去 :: !那些義人，要往永生裏去
> otkr 20:11-15 :: !我又看見一個白色的大寶座與坐在上面的 :: !死了的人都憑著這些案卷所記載的，照他們所行的受審判 :: !死亡和陰間也交出其中的死人 :: !這火湖就是第二次的死
> mf 16:27 :: !人子要在他父的榮耀裏 :: !同著衆使者降臨 :: !他要照各人的行爲報應各人
> mf 25:31-32,34,41 :: !當人子在他榮耀裏，同著衆天使降臨的時候 :: !要坐在他榮耀的寶座上 :: !萬民都要聚集在他面前 :: !好像牧羊的分別綿羊山羊一般 :: !你們這蒙我父賜福的 :: !你們這被咒詛的人
> 2sol 1:5-7 :: !這正是上帝公義判斷的明證 :: !那時，主耶穌同他有能力的天使從天上在火焰中顯現
> otkr 22:10-12 :: !不可封了這書上的預言，因爲日期近了 :: !不義的，叫他仍舊不義 :: !看哪，我必快來 :: !要照各人所行的報應他

# 關於「一千年」的說法
## 一千年——是從基督第一次降臨到第二次降臨這一時期的象徵性名稱
第一次降臨已經發生過。上帝之子降生成人，並未停止他所是的（上帝），而又成爲了人。他教導人，受難，復活，昇天，建立了教會（唯一的：地上的和天上的），並差人去傳道。那些回應基督傳道、進入他的教會、達到救恩並與他在天上同活的人，經上說是與他一同掌王的，雖然他們的身體還死在土裏，而[[ru:жизнь-души-после-смерти-тела|他們的靈魂與基督同在]]。這樣將持續到主耶穌基督的第二次降臨；那時候除了上帝沒有人知道（[[act 1:7]]）。從第一次降臨到第二次降臨的整個時期，被形象地稱爲一千年：
> otkr 20:1-6 :: !他捉住那龍，就是古蛇，又叫魔鬼，也叫撒但，把牠捆綁一千年 :: !等到那一千年完了 :: !與基督一同作王一千年 :: !其餘的死人還沒有復活，直等那一千年完了 :: !這是頭一次的復活 :: !在頭一次復活有分的有福了、聖潔了 :: !第二次的死在他們身上沒有權柄 :: !並要與基督一同作王一千年
## 論千禧年主義（千禧年說）的異端
千禧年主義（千禧年說）——是關於基督在地上掌王一千年（1000年）的學說。東正教基督徒不能接受它，因爲：
1. 無法承認**兩次身體的復活**（主只教導一次身體的復活）；
1. 無法承認**兩個最後審判**（主同樣只教導一次審判）；
1. 無法承認在最後審判之前，爲在地上統治世界而有**基督特殊的降臨**；
1. 無法承認在這個世界裏已經有**某種特殊的基督千年王國**，不同於天國。
詳情：[[ru:хилиазм|千禧年主義]]。
# 論兩次死亡與兩次復活
在神學家約翰使徒的啟示錄一書中提到（[[otkr 20:1-6]]）兩次死亡和兩次復活。
第一次死——在地上肉身的死亡[1]。
第二次死——在普遍最後審判時來自上帝的永恆定罪與刑罰。
第一次復活——屬靈的：歸向上帝、信仰、悔改、洗禮、改正生活。
第二次復活——身體的，在主耶穌基督第二次降臨時發生。
## 第一次復活——經由傳道和洗禮歸向上帝
主捆綁了撒但。異教的膜拜開始被基督教戰勝並消失。人們獲得了經由洗禮、聖餐禮和在教會中的生活而在屬靈上覆活、進入與上帝同在的永生的可能。這一進入永生的屬靈復活，在經文中被稱爲頭一次的復活：
> otkr 20:5-6 :: !這是頭一次的復活 :: !在頭一次復活有分的有福了、聖潔了 :: !第二次的死在他們身上沒有權柄
歸向上帝被稱爲從死亡進入生命：
> ef 2:5-6 :: !當我們死在過犯中的時候，便叫我們與基督一同活過來 :: !又叫我們與基督耶穌一同復活，一同坐在天上
信的人已經出死入生：
> in 5:24 :: !那聽我話又信差我來者的，就有永生 :: !是已經出死入生了
而不信的人則被直接稱爲死人：
> lk 9:60 :: !任憑死人埋葬他們的死人
## 第二次復活——所有的人帶著身體復活，爲受普遍的審判
第二次復活涉及所有的人。它指一切曾經活過的人爲受普遍審判而復活。所有的靈魂都回到他們復原的身體中，好叫一切趨向上帝的（靈魂與身體）得賞賜，而一切犯罪的（靈魂與身體）受刑罰。
> act 24:15 :: !無論善惡，都要復活
## 關於「兩次復活」的詳情
> otkr 20:1-6 :: !他捉住那龍，就是古蛇，又叫魔鬼，也叫撒但，把牠捆綁一千年 :: !等到那一千年完了 :: !與基督一同作王一千年 :: !其餘的死人還沒有復活，直等那一千年完了 :: !這是頭一次的復活 :: !在頭一次復活有分的有福了、聖潔了 :: !第二次的死在他們身上沒有權柄
對這經文的註釋：
> otkr 20:5 :: !其餘的死人還沒有復活，直等那一千年完了 :: !這是頭一次的復活
上帝給所有人規定了時間，使他們可以在頭一次復活的時期內復活，並且爲此賜下了一切。然而，當死人應當復活的時候——即在整個一千年之內（在爲這一目的所規定的、那一千年未完結之前）——有人復活了，有人卻沒有復活。關於「直到……完了」一詞的詳情：[[ru:Богородица#HH-И-не-знал-Ее-как-наконец-она-родила-Мф-125|詳見]]。
頭一部分的人在活於身體中時復活了，也就是歸向了基督：
> otkr 20:6 :: !在頭一次復活有分的有福了、聖潔了 :: !第二次的死在他們身上沒有權柄
在他們身上，**第二次的死**將沒有權柄。
而所有的人帶著身體復活、爲受普遍的審判的復活是這樣的：
> otkr 20:13-15 :: !死亡和陰間也交出其中的死人 :: !他們都照各人所行的受審判 :: !這火湖就是第二次的死 :: !若有人名字沒記在生命冊上，他就被扔在火湖裏
被扔進火湖——這就是**第二次的死**。名字記在生命冊上的人，沒有被扔進去。也就是說，正是那些在20:6中說到的人——在他們身上第二次的死沒有權柄。
