# 定義
**香**——燃燒的乳香（樹脂）所發的煙。
**乳香**（阿拉伯文 lādan——「芳香樹脂」）——某些樹木（起初是黎巴嫩雪松）的芳香樹脂。燃燒的乳香發出悅人的香氣。在舉行聖禮和調製芬芳聖香時使用（[[ish 30:34-36]]）。
**焚香**——乳香燃燒、香上升的過程。
**香爐**——焚燒芬芳配料（加乳香）的器具（盤）。
# 聖經引文
## 芬芳配料（加乳香）——大聖物
> ish 30:34-38 :: !這馨香的香料和淨乳香各樣要一般大的分量 :: !作成清淨聖潔的香 :: !放在會幕內法櫃前 :: !你們要以這香爲至聖 :: !要以這香爲聖，歸耶和華 :: !這人要從民中剪除
## 乳香（樹脂）與油一同加在素祭上，然後祭物由祭司焚燒
> lev 2:1-2 :: !要用細麵澆上油，加上乳香 :: !並取些油和所有的乳香 :: !燒在壇上
## 祭物也有不加乳香的
> chis 5:15 :: !不可澆上油，也不可加上乳香 :: !因爲這是疑恨的素祭
## 專隻爲香（乳香）而設的壇
特別設立了燒香的壇，在其上不可焚燒任何別的東西。在其上焚香與祭獻無關，自成一體。每天早晨和每天黃昏整理燈臺時舉行：
> ish 30:1,6-9 :: !你要用皂莢木作一座燒香的壇 :: !要把壇放在法櫃前的幔子外 :: !亞倫在壇上要燒馨香料作的香 :: !每早晨他收拾燈的時候，要燒這香 :: !黃昏點燈的時候 :: !作爲世世代代常燒的香 :: !不可奉上異樣的香 :: !也不可澆上奠祭
## 香象徵祈禱
> ps 141:2 :: !願我的禱告如香陳列在你面前 ~~ 俄文本編號爲 Пс 140:2（聖詠編號相差一）。
> otkr 5:8 :: !各拿著琴和盛滿了香的金爐 :: !這香就是衆聖徒的祈禱
## 香是獻給上帝的單獨祭物
香自成一體地被提及，與其他聖禮並列爲列舉（不是什麼補充，不是隻與其他事物搭配出現的）：
> 1ts 2:28 :: !我不是揀選人作我的祭司，使他燒香
| 目前我們沒有元首，沒有先知，沒有領袖，沒有全燔祭，沒有祭祀，沒有供物，**沒有馨香祭**，沒有地方可以給你薦新，好蒙受你的仁愛。 ||| sb dan 3:38
> mal 1:11 :: !在各處，人必奉我的名燒香
| 又製造了新的聖器，將燈臺、**香壇**、供桌，搬進聖殿。**在香壇上獻香**，又點著了燈臺上的燈，在殿裏放光。 ||| sb 1mak 4:49-50
| **吩咐他**爲你的名建立城池，並在其中**向你獻香**和祭物。 ||| ru 3ezd 3:24
| 約史雅的紀念，**就如精製香料的人，用各種香味配成的香料**，在衆人口裏，甜如蜂蜜，又如酒會中的音樂。 ||| sb prsir 49:1-2
| 當他從帳幕後的至聖所出來，民衆羣集他身邊時，**他是多麼有光彩**；……**他如烈火和香爐上的香料**， ||| sb prsir 50:5,9 ~~ 俄文本爲 Сир 50:5,9（論大祭司息孟）。
> ps 141:2 :: !願我的禱告如香陳列在你面前 ~~ 俄文本編號爲 Пс 140:2（聖詠編號相差一）。
> 2par 26:16 :: !進耶和華的殿，要在香壇上燒香
> pp 3:6 :: !以沒藥和乳香並商人各樣香粉薰的是誰呢
> is 43:23 :: !也沒有因乳香使你厭煩

## 以香敬奉假神是對上帝的凌辱
> ier 1:16 :: !向別神燒香，跪拜自己手所造的
> is 65:3 :: !在壇上燒香
> is 65:6 :: !就是在山上燒香、在岡上褻瀆我的罪孽 ~~ 俄文本編號爲 Ис 65:7；和合本該句在 65:6。
