# 定義
**聖膏**（領受聖靈的恩賜）——教會七個聖奧祕之一，人在其中領受走屬靈道路並長進所需的力量（聖靈的恩賜）。聖膏聖奧祕與洗禮聖奧祕一同舉行，緊接著洗禮之後。
起初，這聖奧祕是藉使徒的按手並祈禱舉行的。後來——但還在使徒的時代——按手就被以聖膏（特別祝聖的油）膏抹人所取代。極可能是爲了使這聖奧祕不僅能由使徒和主教施行，也能由那些主教授予此權的司祭施行，正如其餘的聖奧祕一樣。主教調製聖膏，並把它交給舉行這聖奧祕的司祭。詳見[[ru:миропомазание#HH-С-I-II-века-вместо-возложения-рук-помазывают-миром|下文相應的部分]]。
# 關於賜予聖靈恩賜之聖奧祕的指示
使徒彼得的宣講。
使徒彼得呼召人受洗使罪得赦，隨後又另外講到必須領受聖靈的恩賜：
> act 2:38 :: !奉耶穌基督的名受洗 :: !就必領受所賜的聖靈
# 聖靈的恩賜藉使徒的按手傳遞
福音史家路加在使徒行傳中直接宣告：“藉著使徒的按手，聖靈是賜下的”（[[act 8:18]]）。這不是西門的話，而是路加福音史家——使徒行傳作者——的話。此外，接著使徒彼得直接講到聖靈恩賜的傳遞是上帝的恩賜，並責備西門圖謀用錢來得到這恩賜：
> act 8:17-20 :: !於是使徒按手在他們頭上，他們就受了聖靈 :: !因你想上帝的恩賜是可以用錢買的
使徒保羅在以弗所施洗。洗禮之後立刻按手，以傳遞聖靈的恩賜：
> act 19:4-6 :: !就奉主耶穌的名受洗 :: !保羅按手在他們頭上，聖靈便降在他們身上
# 聖靈恩賜的傳遞——與洗禮分開的聖奧祕
撒瑪利亞人受了洗，但聖靈是後來、在使徒按手之後才降下的。
撒瑪利亞人的洗禮舉行了。任何地方都沒有說這洗禮有什麼不對。相反，經上直接指出“他們只奉主耶穌的名受了洗”，而聖靈還沒有降在他們身上。當使徒們聽說撒瑪利亞人的事，就清楚需要有使徒到撒瑪利亞人那裏去，使他們不僅受洗（這是腓利也能做的），而且領受聖靈的恩賜（這腓利已經不能做了，因爲傳遞聖靈恩賜的只能是使徒，以及他們把這恩賜傳遞給他們的人——主教）：
> act 8:5,12,14-17 :: !腓利下撒瑪利亞城去宣講基督 :: !連男帶女就受了洗 :: !就打發彼得，約翰往他們那裏去 :: !兩個人到了，就爲他們禱告，要叫他們受聖靈 :: !因爲聖靈還沒有降在他們一個人身上，他們只奉主耶穌的名受了洗 :: !於是使徒按手在他們頭上，他們就受了聖靈
# 從I-II世紀起，以聖膏的膏抹代替按手
起初這聖奧祕是藉使徒和主教的按手舉行的。後來，極可能是因爲歸依基督教的人數增多，主教很難爲所有基督徒按手，於是確立了祝聖特別的油（聖膏）並把它交給司祭（長老）的實踐——司祭在聖膏聖奧祕中膏抹人，代替主教的按手。
在聖經本身和一系列最早的基督教作家那裏，都有以這種方式舉行聖奧祕的指示：
> 2kor 1:21-22 :: !並且膏我們的就是上帝 :: !他又用印印了我們，並賜聖靈在我們心裏作憑據
> 1in 2:20 :: !你們從那聖者受了恩膏
> 1in 2:27 :: !你們從主所受的恩膏常存在你們心裏 :: !自有主的恩膏在凡事上教訓你們
**安提阿的聖提奧菲爾，二世紀**
“至於你對我、對我的基督徒之名的譏笑，你不知道你說的是什麼。首先，凡被膏抹的，都是令人喜悅的、有益而美好的，不應被譏笑。因爲什麼船若不先被油膏抹，還能合用而堅固呢？什麼塔或房子若不被膏抹，還能美觀而適用呢？誰進入這一生、或進入競技場而不被油膏抹呢？<…> **正因如此，我們被稱爲基督徒，因爲我們是被上帝的油所膏抹的**。”
（[俄文](https://bibleox.com/ru/ru/w/Феофил-послание_к_Автолику)《致奧托利科斯書》）

# 對異議的回應
## “可是聖靈降在百夫長哥尼流身上，並沒有使徒的按手？”
聖靈在使徒彼得宣講時降在哥尼流一家身上——這是**唯一的**一例：聖靈不藉使徒按手、並在洗禮之前降臨。在這例外的情形之前有一系列極不尋常的事件，表明上帝這樣預備教會接納外邦人（非猶太人）。在此之前，接納外邦人的可能性完全不明顯，甚至後來還引起爭辯。藉這特殊的聖靈降臨，上帝指明：
1. 可以接納外邦人（非猶太人）進入教會；
2. 消除了在這事上懷疑、並指責人持錯誤判斷的可能。上帝這樣作並非不用使徒（聖靈不是立刻降下，而是先差遣天使，吩咐人去請使徒來），然而聖靈自己確實在使徒按手之前降臨，清楚地表達了上帝接納外邦人的旨意。
重要的是：聖靈的降臨並沒有取消洗禮聖奧祕的必要——在聖靈降在哥尼流一家身上之後，使徒立刻爲他們施洗：
> act 10:1,34,44,46-48 :: !在該撒利亞有一個人，名叫哥尼流 :: !我真看出上帝是不偏待人 :: !聖靈降在一切聽道的人身上 :: !這些人既受了聖靈，與我們一樣，誰能禁止用水給他們施洗呢 :: !就吩咐奉耶穌基督的名給他們施洗
對想更詳細瞭解的人，我們作詳細的解釋。
在教會存在的初期，接納外邦人幾乎是不可能的。宣講只向猶太人敞開（[[act 11:19]]；[[act 11:1,18]]；[[act 14:27]]；[[act 15:4]]；[[act 15:7]]）。教會還沒有形成接納外邦人（即非猶太人）是否可行的共同認識。
甚至對最近的門徒之一——使徒彼得——也需要特殊的預備：不是一次，而是三次向他顯現同一個關於不潔食物的異象，並命令他不要把上帝所潔淨的當作不潔（[[act 10:15]]；[[act 11:9]]）。
這樣，使徒彼得來到哥尼流那裏；宣講開始之後，聖靈降在哥尼流一家身上。降臨之後，使徒立刻用水給他們施洗。爲羅馬百夫長哥尼流施洗之後，猶太血統的基督徒對所發生的事驚訝：
> act 10:45 :: !見聖靈的恩賜也澆在外邦人身上，就都希奇
在耶路撒冷，使徒彼得因給外邦人施洗而受到責難；但聽了他講述上帝的啟示和聖靈降在哥尼流身上的事之後，人們就安靜下來（[[act 11:1,18]]）。甚至在這之後，問題也沒有得到徹底解決。使徒彼得到了安提阿。那裏也來了耶路撒冷雅各那裏的基督徒（[[gal 2:12]]），於是安提阿的猶太人連同使徒彼得開始躲開耶路撒冷來的人，免得顯得與外邦人交往。
這樣，不難看出，教會爲接納外邦人作特殊的預備，是何等必要。
1. 甚至使徒也需要被單獨地三次教導。
2. 目擊這一切的基督徒被所發生的事震驚，而在別人面前還不得不辯白。
3. 與使徒們發生爭辯，爲此在耶路撒冷召集了整個會議。
這一切都是在上帝超性地介入、親自不藉使徒按手降在外邦人身上的情況下發生的。甚至儘管有這一切，仍出現強烈的抵抗。若沒有這些，又會怎樣呢？
這樣，主只有一次以例外的樣式行事，爲要教導教會接納外邦人。
這特殊的事件並沒有取消洗禮。使徒立刻給哥尼流一家施了洗。
值得特別注意這一整串事件，其實質在於：上帝完全可預料地可以按自己的意願行事，但是……不脫離教會行事。
那些自立基督教團體的人在這裏寧可只看到爲自己的擅自聚會開口子的機會，力圖證明聖靈彷彿會因傳福音而直接賜給他們。但他們完全忽略了這樣的事實：能夠完全獨立行事、不需要使徒就能降在哥尼流和他一家身上的聖靈，並沒有脫離教會這樣做。
看到哥尼流的義、他的祈禱和施捨，上帝差到他那裏的不是聖靈的恩賜，而是先差天使，吩咐哥尼流去找教會。只有當教會以使徒的身份來到、當被賦予傳遞聖靈恩賜之權柄的人來到時，聖靈才降在哥尼流身上。
這樣，聖靈能夠不通過教會而降臨，但他不這樣做。聖經裏沒有一次這樣的例子。在其餘所有情形中，聖靈都沒有在洗禮之前降臨。
聖靈在洗禮時降臨——這正是說，在洗禮的過程中行了按手並降下聖靈。今天行的也是同樣：洗禮之後立刻隨之舉行聖膏。
洗禮被稱爲屬靈的誕生、進入教會、加入身體。聖靈恩賜的差遣並不這樣稱呼。如使徒所說，洗禮救人。那麼，難道是水本身救人嗎？當然是聖靈藉著水的運作。在水裏受浸時屬靈的誕生沒有聖靈是不會發生的。而傳遞聖靈恩賜的聖奧祕——是單獨的。使徒在這裏也正是把它們作爲聖靈的兩個分開的行動來講：
> 1kor 12:13 :: !都從一位聖靈受洗 :: !飲於一位聖靈
1）**受洗**也是（!）在聖靈裏；
2）**飲於**聖靈。
兩者都是由聖靈成就的。沒有聖靈的運作，沒有人從水裏重生。
而如果這是兩個不同的概念，那就不必把從水而生作爲看見並進入天國的條件了；只要說“從聖靈生”就足夠了。但救主講到誕生時，把兩者並提：從水和聖靈生，既不忽略水，也不忽略聖靈。
## “如果聖靈的恩賜只能由使徒傳遞，那聖靈爲什麼在六品執事腓利施洗之後降在埃提阿伯的太監身上？”
在腓利與太監的情形中（[[act 8:39]]）有一個非常重要的細節。
絕大多數釋經者——包括最古老的，包括聖金口約翰——引用這段經文時都沒有關於聖靈降下的話（αγιον επεπεϲεν επι τον ευνουχον αγγελοϲ δε）。經上只是說：
聖<s>靈降在太監身上，而天使</s>主把腓利提了去。
西奈抄本沒有這些話（四世紀）：
“καὶ ἐκέλευσεν στῆναι τὸ ἅρμα,
καὶ κατέβησαν ἀμφότεροι εἰς τὸ ὕδωρ,
ὁ τε Φίλιππος καὶ ὁ εὐνοῦχος,
καὶ ἐβάπτισεν αὐτόν.
ὅτε δὲ ἀνέβησαν ἐκ τοῦ ὕδατος,
**πνεῦμα Κυρίου ἥρπασε τὸν Φίλιππον**,
καὶ οὐκ εἶδεν αὐτὸν οὐκέτι ὁ εὐνοῦχος·
ἐπορεύετο γὰρ τὴν ὁδὸν αὐτοῦ χαίρων.
Φίλιππος δὲ εὑρέθη εἰς Ἄζωτον,
καὶ διερχόμενος εὐηγγελίζετο τὰς πόλεις πάσας,
ἕως τοῦ ἐλθεῖν αὐτὸν εἰς Καισάριαν.”（使徒行傳 8:39-40）
梵蒂岡抄本沒有這些話（四世紀）：
“και εκελευϲε ϲτηναι το αρμα και κατεβηϲαν αμφοτεροι ειϲ το υδωρ ο τε φιλιπποϲ και ο ευνουχοϲ και εβαπτιϲεν αυτον
οτε δε ανεβηϲαν εκ του υδατοϲ **πνευμα κ̅υ̅ ηρπαϲεν το̅ φιλιππον** και ουκ ειδε̅ αυτον ουκετι ο ευνουχοϲ επορευετο γαρ αυτου την οδον χαιρων”
亞歷山大抄本沒有這些話（五世紀）：
“και εκελευϲεν ϲτηναι το αρμα και κατεβηϲαν αμφοτεροι ειϲ το υδωρ ο τε φιλιπποϲ και ο ευνουχοϲ και εβαπτιϲεν αυτον
οτε δε ανεβηϲαν εκ του υδατοϲ **π̅ν̅α̅ κ̅υ̅ ηρπαϲεν τον φιλιππο̅** και ουκ ειδεν αυτον ουκετι ο ευνουχοϲ επορευετο γαρ την οδο̅ αυτου χαιρων
φιλιπποϲ δε ευρεθη ειϲ αζωτον και διερχομενοϲ ταϲ πολειϲ παϲαϲ εωϲ του ελθειν αυτο̅ ειϲ καιϲαριαν”
聖金口約翰也是這樣引用的（沒有聖靈降臨的話）：
“Ὅτε δὲ ἀνέβησαν ἀπὸ τοῦ ὕδατος, **Πνεῦμα Κυρίου ἥρπασε τὸν Φίλιππον**, καὶ οὐκ εἶδεν αὐτὸν οὐκ ἔτι ὁ εὐνοῦχος.”
