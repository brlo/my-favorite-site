聖經中所列的一些致死的罪：
> rim 1:29-32 :: !行這樣事的人是當死的
> gal 5:19-21 :: !行這樣事的人必不能承受上帝的國
> 1kor 6:9 :: !不義的人不能承受上帝的國
> ef 5:5 :: !在基督和上帝的國裏都是無分的
> otkr 21:8 :: !他們的分就在燒著硫磺的火湖裏，這是第二次的死
> otkr 22:14-15 :: !城外有那些犬類、行邪術的、淫亂的、殺人的、拜偶像的，並一切喜好說謊言編造虛謊的
> pr 19:5,9 :: !吐出謊言的，終不能逃脫 :: !吐出謊言的，也必滅亡
只要人還活著、還能進入基督的教會而悔改，一切罪都可以得到赦免。人將要受審判的，是他在身體中活著時所做的事：
> 2kor 5:10 :: !按著本身所行的
