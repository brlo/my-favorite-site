# 異端的定義
**異端**（古希臘文 <a href="https://bibleox.com/ru/words/%CE%B1%CE%B9%CF%81%CE%B5%CF%83%CE%B9%CF%82">αἵρεσις</a> ——派別、學說、學派、選擇）——是後來產生的、在先前學說之觀念上形成的獨立學說，通常與之相對立。異端的追隨者認爲他們所由分出的那個學說是錯誤的，也同樣遭到對方的回敬。
在聖經的語境中，任何對信理的重大歪曲都被稱爲異端：
- **法利賽人**——關於救恩的錯誤學說。在很大程度上，他們把救恩僅僅歸結爲嚴格遵守外在的規條；
- **撒都該人**——關於屬靈現實的錯誤學說。他們否認屬靈的現實：靈魂在身體死後的生命、神靈和天使的存在、死人的復活；
- **許米乃和腓理徒的學說**——關於復活的錯誤學說。他們教導說復活已經在過去完成了；
- **尼哥拉一黨人**——關於道德生活的錯誤學說。他們容許肉體的淫亂。
這些異端都不直接涉及關於上帝的教義，而是涉及信理的某些其他方面，然而它們仍然是異端。

錯誤的教導並不把人引向上帝：

# 反對耶穌基督的人曾把他的教導視爲異端之一
控告基督使徒的人稱基督的教導爲拿撒勒異端（基督在拿撒勒長大——[[in 1:45-46]]）：
> act 24:5 :: !拿撒勒教黨
使徒們確認，法利賽人和撒都該人把他們的教導視爲異端：
> act 24:14 :: !他們所稱爲異端的道
在公會中，基督的教導被視爲衆多派別之一。法利賽人迦瑪列列舉了新派別的例子：
> act 5:34-37 :: !從前丟大起來 :: !又有加利利的猶大起來
另見：[[lk 23:2]]、[[in 7:12]]。
## 爲什麼基督的教導不是異端？
簡言之，因爲他是上帝（[[ru:Христос-Бог|引文]]）、是真理（[[in 14:6]]）、是立法者（「你們聽見有吩咐古人的話說：&lt;…&gt;只是我告訴你們」——[[mf 5:21-22]]）。
只有那些不承認耶穌是基督、是上帝，不相信他就是那位與亞伯拉罕、以撒和雅各說話的上帝和立法者（[[ish 3:15]]；[[in 8:25]]）、就是那位賜給以色列律法（[[gal 3:19]]）、差遣先知到以色列的上帝（[[mf 23:34]]）的人，才把基督的教導視爲虛假的、獨立的。由於耶穌基督是上帝，作爲立法者，他來更改了他自己所立的秩序，把他自己的葡萄園轉給別人（[[lk 20:16]]；[[mk 12:9]]）。
因此，只有不信基督的人才把基督的教導稱爲異端；信基督的人則認爲他的教導是唯一真實的（[[2in 1:9]]；[[in 3:36]]）。然而，基督和使徒們曾警告說，在他們之後會出現虛假的教導，但必須持守那一次傳給教會的：
> iud 1:3 :: !要爲從前一次交付聖徒的真道竭力的爭辯
## 凡講到耶穌基督的教導，都因爲它講到基督而是真實的嗎？
使徒們警告說，別人可能傳講另一個耶穌、另一個福音，並給人另一個靈：
> 2kor 11:3-4 :: !假如有人來另傳一個耶穌，不是我們所傳過的 :: !或者你們另受一個靈，不是你們所受過的 :: !或者另得一個福音，不是你們所得過的
# 關於異端的預言
## 基督教中將出現許多異端
> mk 13:6 :: !將來有好些人冒我的名來 :: !並且要迷惑許多人
> mf 24:11 :: !且有好些假先知起來，迷惑多人
> 1in 4:1 :: !世上有許多假先知已經出來了
《十二宗徒訓言》（一至二世紀）中也有指示：
<blockquote><p>「因爲<strong>在末後的日子裏，假先知和敗壞者將要增多</strong>，羊要變成狼，愛要變成恨。」</p></blockquote>（<a href="https://bibleox.com/ru/ru/w/Дидахе#L94">《十二宗徒訓言》94</a>）
## 異端將非常廣泛地傳播
> 2tim 2:17-18 :: !他們的話如同毒瘡，越爛越大 :: !他們偏離了真道，說復活的事已過
> 2pet 2:1-3 :: !將來在你們中間也必有假師傅，私自引進陷害人的異端 :: !將有許多人隨從他們邪淫的行爲 :: !他們因有貪心，要用捏造的言語在你們身上取利
## 異端的社羣將脫離教會及其信仰的合一
> 1in 2:18-19 :: !現在已經有好些敵基督的出來了 :: !他們從我們中間出去，卻不是屬我們的
> iud 1:18-19 :: !末世必有好譏誚的人 :: !這就是那些引人結黨、屬乎血氣、沒有聖靈的人
## 假師傅的任務——把信徒從教會中擄走並帶他們隨己而行
> act 20:29-30 :: !必有兇暴的豺狼進入你們中間 :: !就是你們中間，也必有人起來，說悖謬的話，要引誘門徒跟從他們
## 假師傅的手法
### 動聽的學說
假師傅們將要編出動聽的學說，正是因爲他們的聽衆將尋求悅耳的學說，忍受不了純正的教導：
> 2tim 4:3 :: !耳朵發癢，就隨從自己的情欲，增添好些師傅
> 1tim 4:1-2 :: !必有人離棄真道，聽從那引誘人的邪靈和鬼魔的道理
### 虛假的敬虔
> 2tim 3:1-2,5,7-8 :: !末世必有危險的日子來到 :: !有敬虔的外貌，卻背了敬虔的實意 :: !這等人也怎樣敵擋真道
> mf 7:15 :: !你們要防備假先知。他們到你們這裏來，外面披著羊皮，裏面卻是殘暴的狼
### 奇蹟
使徒們和古代基督徒被賜予豐富的行異能之力，不是爲了作秀，而是爲了益處：
> 1kor 12:7 :: !聖靈顯在各人身上，是叫人得益處
一小羣漁夫需要很大的幫助，才能在短短一生中把傳道傳遍全世界。使徒們曾警告說，這些恩賜將要止息：
> 1kor 13:8 :: !先知講道之能，終必歸於無有；說方言之能，終必停止
基督自己也斥責尋求奇蹟：
> mf 12:39 :: !一個邪惡、淫亂的世代求看神蹟
在末後的時代，假先知將恰恰以奇蹟引誘人：
> mf 24:24; mk 13:22 :: !因爲假基督、假先知將要起來，顯大神蹟、大奇事
結果，在審判時，許多信徒將確信自己得救正是因爲他們奉基督的名行異能、說預言、趕鬼。但他們受了欺騙，被教導行不法之事，基督不認識他們，把他們從自己面前趕走：
> mf 7:22-23 :: !奉你的名行許多異能嗎 :: !我從來不認識你們，你們這些作惡的人，離開我去吧
# 一世紀異端的例子
## 法利賽人
使徒們稱法利賽人的教導爲異端（獨立的、錯誤的學說）：
> act 15:5 :: !惟有幾個信徒是法利賽教門的人
從法利賽人中出來的信徒認爲，外邦人要得救，必須受割禮並遵守摩西的律法。
傳道者馬太也指出法利賽人和撒都該人教導的危險：
> mf 16:6,11-12 :: !防備法利賽人和撒都該人的酵 :: !乃是防備法利賽人和撒都該人的教訓
## 撒都該人
使徒們稱撒都該人的教導爲異端（獨立的、錯誤的學說）：
> act 5:17 :: !撒都該教門的人
撒都該人的教導否認死人復活、靈魂的死後生命、天使和神靈的存在：
> mk 12:18,24,26-27 :: !撒都該人常說沒有復活的事 :: !你們所以錯了，豈不是因爲不明白聖經，不曉得上帝的大能嗎 :: !論到死人復活，你們沒有念過摩西的書 :: !上帝不是死人的上帝，乃是活人的上帝
> act 23:8 :: !因爲撒都該人說沒有復活，也沒有天使和鬼魂
法利賽人與撒都該人相爭：
> act 23:6-8 :: !保羅看出大衆一半是撒都該人，一半是法利賽人 :: !法利賽人和撒都該人就爭論起來，會衆分爲兩黨
## 許米乃和腓理徒的學說
背離真理的許米乃和腓理徒的學說。他們既然背離了真理，就是說他們以前曾是基督徒。如今他們錯誤地教導復活，這顯然是即將傳播的異端，必須遠離：
> 2tim 2:16-19 :: !他們的話如同毒瘡，越爛越大 :: !其中有許米乃和腓理徒 :: !他們偏離了真道，說復活的事已過 :: !凡稱呼主名的人總要離開不義
## 尼哥拉一黨人
主耶穌基督憎惡尼哥拉一黨人的教導，也就是說，他們的教導顯然是異端：
> otkr 2:15 :: !你那裏也有人照樣服從了尼哥拉一黨人的教訓
> otkr 2:6 :: !你恨惡尼哥拉一黨人的行爲，這也是我所恨惡的
# 二世紀異端的例子
聖殉道者護教者查士丁（約100-165）寫道，有些人雖然自稱基督徒、承認被釘十字架的耶穌是主和基督，卻傳講謊言之靈的教導，即獨立的虛假學說（異端）：
<blockquote><p>有些人<strong>自稱是基督徒，承認被釘十字架的耶穌是主和基督，卻傳講謊言之靈的教導，而不是他的教導</strong>……我們不與他們中的任何一位相通。</p></blockquote>
（<a href="https://bibleox.com/ru/ru/w/Иустин_Философ-разговор_с_Трифоном_иудеем">《與特來弗對話錄》</a>）
里昂的聖依勒內（約130-202）也寫到無數的基督教異端。例如，他寫到護教者查士丁的門徒塔提安：在查士丁殉道之前，塔提安未曾說過異端，而在那之後卻編造了自己的學說：
<blockquote><p>1. 從上述的（假師傅們）已經分出了許多異端的許多支派，因爲<strong>許多人，甚至所有人，都願意自己做師傅，離開他們原先所持守的異端。他們從另一套意見體系編造出學說，然後又由此編出另一種，力圖教導新的東西，把自己當作所編學說的發明者</strong>。例如：所謂的克己派（Encratites），出自撒土尼努和馬吉安，<strong>宣講獨身</strong>，拒絕上帝起初的創造，間接指摘那位爲人的生育造了男性和女性的那一位；他們又<strong>戒絕食用動物</strong>，對造萬物的上帝忘恩負義。他們<strong>還否認太初之人得救</strong>；不過這意見是他們中間很晚才發明的。首先提出這一褻瀆的是塔提安：他作查士丁的門徒時，與他在一起，從未說過這樣的話；但在查士丁殉道之後，他離開了教會，因想作高人一等的師傅而受此思想激動，編造了自己獨特的學說體系。他像華倫提努派一樣杜撰某些不可見的艾翁，又像馬吉安和撒土尼努一樣宣稱婚姻是玷污和姦淫，並且憑自己否認亞當得救。</p><p>2. 另一些人相反，追隨巴西理德和卡波克拉特，引入了不法同居、多妻制和對祭偶像之物的隨意取用，聲稱上帝並不怎麼在意這些。但何必再往下說呢？<strong>無法一一列舉那些以這種或那種方式脫離真理的人</strong>。</p></blockquote>
（<a href="https://bibleox.com/ru/ru/w/Ириней_Лионский-Против_ересей#HH-Глава-XXVIII-Учение-Татиана-энкратитов-и-других">《駁異端》第28章</a>）

# 批評
## 你們不羨慕奇蹟嗎
異端的擁護者常常試圖用奇蹟、醫治和趕鬼把自己的團體拉人。爲此他們引用這樣的話：
> 1kor 14:1 :: !你們要追求愛，也要切慕屬靈的恩賜
他們也用這節經文指摘教會不羨慕，因此教會裏沒有大規模的奇蹟展示。
然而，使徒們和古代基督徒被賜予豐富的行異能之力，不是爲了作秀，而是爲了益處：
> 1kor 12:7 :: !聖靈顯在各人身上，是叫人得益處
一小羣漁夫需要很大的幫助，才能在短短一生中把傳道傳遍全世界。使徒們曾警告說，這些恩賜將要止息：
> 1kor 13:8 :: !先知講道之能，終必歸於無有；說方言之能，終必停止
基督自己也斥責尋求奇蹟：
> mf 12:39 :: !一個邪惡、淫亂的世代求看神蹟
在末後的時代，假先知將恰恰以奇蹟引誘人：
> mf 24:24; mk 13:22 :: !因爲假基督、假先知將要起來，顯大神蹟、大奇事
結果，在審判時，許多信徒將確信自己得救正是因爲他們奉基督的名行異能、說預言、趕鬼。但他們受了欺騙，被教導行不法之事，基督不認識他們，把他們從自己面前趕走：
> mf 7:22-23 :: !奉你的名行許多異能嗎 :: !我從來不認識你們，你們這些作惡的人，離開我去吧
## 你們沒有愛心
在與脫離教會的團體擁護者交談時，常常出現這樣的防衛反應：避開所討論的話題，試圖轉到討論對方的爲人及其品質。這通常發生在出現難以回答的問題之後。無論你多麼有分寸、有禮貌，你仍然可能被指控：
- 論斷人；
- 驕傲；
- 沒有愛心。
**說論斷人**——因爲你說在異端中不能得救。然而，說這話的是使徒（[[gal 5:20]]）和從一世紀起的聖教父（[[ru:7Ut6v4xr_Спасение_возможно_только_в_Церкви|引文]]）。主賜了不要定人罪的誡命（[[lk 6:37]]），但另一方面也說要按公義判斷（[[in 7:24]]）。
**說驕傲**——因爲你說[[ru:X7l9DcTY_Спасение_возможно_только_в_Церкви|只有基督的教會才能得救]]，教會是唯一的、有形的、合一的（[[ru:Церковь|引文]]）。然而聖經中也這樣說：基督是身體的（教會的）救主（[[ef 5:23]]），離了基督沒有人能得救（[[ru:Иисус_Христос-единственный-спаситель-человечества|引文]]）。聖教父們說的也是同樣的話（[[ru:7Ut6v4xr_Спасение_возможно_только_в_Церкви|引文]]）。
至於**愛心**。毫無疑問，基督徒應當溫良、謙卑、始終出於愛心行事。但愛可以而且應當是什麼樣的呢？我們不能指摘主耶穌基督和使徒們缺乏愛心。同時，我們在聖經中遇到這樣的教導：
> pr 3:11-12 :: !因爲耶和華所愛的，他必責備
> evr 12:6 :: !因爲主所愛的，他必管教
> otkr 3:19 :: !凡我所疼愛的，我就責備管教他
> iov 5:17-18 :: !上帝所懲治的人是有福的 :: !他打破，又纏裹
因此必須記得：如果我們把一切指摘都當作仇恨的表現，那就等於指摘上帝和使徒們有仇恨——他們不僅自己指摘謊言，還召人這樣做：
> ef 5:11 :: !倒要責備行這事的人
指出某種學說的虛假，可能不只是仇恨的表現（有些人確實出於驕傲和仇恨這樣做），也可以是愛心的表現、對近人的關懷、願他得救的意願：
> iak 5:19-20 :: !你們中間若有失迷真道的 :: !便是救一個靈魂不死，並且遮蓋許多的罪
應當努力永不羞辱任何人，也不要讓談話轉入對個人的討論——在那裏往往開始彼此定罪。應當談學說，而不是談人的品質。
