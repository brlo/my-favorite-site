# 摩西律法廢除的詳細解釋
關於摩西律法的廢除，見聖教父引文前的序言：[[ru:Отмена_Закона_Моисея|論摩西律法的廢除]]。
# 摩西律法已被廢除
> rim 7:6 :: !現今就脫離了律法 :: !要按著心靈的新樣，不按著儀文的舊樣
## 不再在師傅（律法）的手下
> gal 3:21-25 :: !斷乎不是 :: !但這因信得救的理還未來以先，我們被看守在律法之下 :: !律法是我們訓蒙的師傅 :: !我們從此就不在師傅的手下了
> gal 4:1-2,9-11,21,29-31 :: !乃在師傅和管家的手下，直等他父親預定的時候來到 :: !情願再給他作奴僕呢 :: !你們謹守日子、月分、節期、年分 ~~ 這裏說的正是安息日，按聖提奧凡的話。 :: !你們這願意在律法以下的人 :: !那按著血氣生的，逼迫了那按著聖靈生的，現在也是這樣 ~~ 這裏以血氣所生的與律法相比較。 :: !把使女和他兒子趕出去 :: !我們不是使女的兒女，乃是自主婦人的兒女了
# 關於廢除律法的公會議定
第一次使徒公會議決定：基督徒沒有必要遵守猶太律法的規條：
> act 15:5-6 :: !必須給外邦人行割禮 :: !吩咐他們遵守摩西的律法 :: !使徒和長老，聚會商議這事
> act 15:24 :: !用言語攪擾你們 :: !惑亂你們的心 :: !其實我們並沒有吩咐他們
> act 15:28-29 :: !因爲聖靈和我們定意不將別的重擔放在你們身上 :: !惟有幾件事是不可少
> act 21:25 :: !叫他們謹忌那祭偶像之物和血，並勒死的牲畜與姦淫
> act 16:4 :: !把耶路撒冷使徒和長老所定的條規交給門徒遵守
# 使徒們和最早的基督徒不按摩西律法生活
## 對律法以外的人，作律法以外的人（即不遵守它）
> 1kor 9:20-21 :: !向沒有律法的人，我就作沒有律法的人 :: !其實我在上帝面前，不是沒有律法 :: !在基督面前，正在律法之下
## 執事司提反被指控教導律法的改變
> act 6:13-14 :: !這個人說話不住的蹧踐聖所和律法 :: !也要改變摩西所交給我們的規條
## 使徒保羅被指控教導人不按律法敬拜上帝
> act 18:13 :: !這個人，勸人不按著律法敬拜上帝
> act 21:20-21 :: !都爲律法熱心 :: !你教訓一切在外邦的猶太人離棄摩西 :: !不要給孩子行割禮 :: !也不要遵行條規
如果使徒保羅在傳猶太教，那猶太人爲什麼還要逼迫他呢？他們逼迫他，是因爲他離棄了律法：
> gal 5:1,11 :: !所以要站立得穩，不要再被奴僕的軛挾制 :: !我若仍舊傳割禮，爲什麼還受逼迫呢
一些基督徒在猶太人面前假裝守律法，爲的是不受逼迫：
> gal 6:12 :: !凡希圖外貌體面的人，都勉強你們受割禮，無非是怕自己爲基督的十字架受逼迫
## 基督徒不受割禮
> 1kor 7:18-19 :: !有人未受割禮蒙召呢，就不要受割禮 :: !受割禮算不得什麼，不受割禮也算不得什麼
> gal 5:6 :: !受割禮不受割禮全無功效
> gal 6:15 :: !受割禮不受割禮都無關緊要
> kol 3:11 :: !受割禮的、未受割禮的
## 不獻牲畜爲祭
> evr 10:8-9,16-18 :: !祭物和禮物，燔祭和贖罪祭，是你不願意的 :: !可見他是除去在先的，爲要立定在後的 :: !我要將我的律法寫在他們心上 :: !我不再記念他們的罪愆和他們的過犯 :: !這些罪過既已赦免，就不用再爲罪獻祭了
## 不守安息日
> kol 2:16 :: !所以不拘在飲食上，或節期、月朔、安息日，都不可讓人論斷你們
> mf 12:1-2,7 :: !耶穌在安息日從麥地經過 :: !他的門徒餓了，就掐起麥穗來吃 :: !就不將無罪的當作有罪的了
## 與外邦人來往，自己成爲外邦人
> act 10:27-28 :: !猶太人和別國的人親近來往，本是不合例的 :: !但上帝已經指示我，無論什麼人都不可看作俗而不潔淨的
## 接觸死人
主耶穌基督接觸了睚魯死去的女兒：
> mk 5:41 :: !就拉著孩子的手，對她說
按律法，基督死在十字架上之後，不能像接觸已死之人那樣接觸他。只有上帝之母作爲親屬可以這樣作（[[lev 21:1-4]]）。然而，我們不但不定神學家約翰、尼哥底母、亞利馬太人約瑟的罪，反而稱讚他們毫無畏懼、服事我們的救主。
> mf 27:59-60 :: !約瑟取了身體，用乾淨細麻布裹好 :: !安放在自己的新墳墓裏
> mk 6:29 :: !約翰的門徒聽見了，就來把他的屍首領去，葬在墳墓裏
> mk 15:45-46 :: !就把耶穌的屍首賜給約瑟 :: !安放在磐石中鑿出來的墳墓裏
> act 13:29 :: !就把他從木頭上取下來，放在墳墓裏
## 主釋放了被控姦淫的婦人
律法命令用石頭打死犯奸淫的（[[lev 20:10]]），但主沒有定那婦人的罪，而是釋放了她：
> in 8:11 :: !我也不定你的罪，去吧！從此不要再犯罪了
## 主命令喝他的血
上帝禁止喝血（[[gen 9:4]]；[[lev 3:17]]；[[lev 7:26]]；[[lev 17:14]]；[[vtor 12:16]]），但在最後的晚餐上，把杯遞給門徒說：你們都喝這個，這是我的血：
> mf 26:26-28 :: !你們拿著吃，這是我的身體 :: !你們都喝這個 :: !因爲這是我立約的血，爲多人流出來，使罪得赦
## 主成了出自猶大支派的大祭司
律法命令祭司只能出自利未支派、亞倫的家族：
> ish 29:9 :: !他們就憑永遠的定例得了祭司的職任
> ish 29:29 :: !亞倫的聖衣要留給他的子孫 :: !又穿著承接聖職
但主成了大祭司，生在猶大支派：
> evr 7:14 :: !我們的主分明是從猶大出來的 :: !但這支派，摩西並沒有提到祭司
## 真正的逾越節祭牲不是在聖殿裏獻的
逾越節的祭牲只能在耶路撒冷聖殿裏獻：
> vtor 16:5-6 :: !在耶和華你上帝所賜的各城中，你不可獻逾越節的祭 :: !只當在耶和華你上帝所選擇要立爲他名的居所
> evr 13:12 :: !所以耶穌要用自己的血叫百姓成聖，也就在城門外受苦
# 十誡也是摩西律法嗎？
## 上帝藉摩西所賜的律法——利未記中的一切誡命
利未記中列舉了上帝的衆多誡命，包括[[ru:10-заповедей|石版上的誡命]]，稱它們爲**上帝藉摩西所立的律例**：
> lev 26:46 :: !這些律例、典章和法度，是耶和華與以色列人在西乃山藉着摩西立的
## 上帝稱他的一切誡命爲律法
例如，收集嗎哪的命令就是上帝的律法：
> ish 16:4,28 :: !我好試驗他們遵不遵我的法度 :: !你們不肯守我的誡命和律法要到幾時呢
出埃及記第16、24、31、34、35章；申命記第4、6、10章。
## 新的律法已不再寫在石版上，而是寫在心裏
寫在石版上的，被稱爲「律法」：
> ier 31:33 :: !我要將我的律法放在他們裏面，寫在他們心上
> 2kor 3:3 :: !不是寫在石版上，乃是寫在心版上
## 基督講論誡命，並不特別突出十誡
> mf 5:21,27,33,38,43 :: !不可殺人 :: !不可姦淫 :: !不可背誓 :: !以眼還眼，以牙還牙 :: !當愛你的鄰舍 ~~ 出 21:24；利 19:18。
## 使徒們把十誡直接稱爲律法
使徒雅各說，違犯「不可殺人」誡命的人，就是犯律法的：
> iak 2:10-11 :: !只在一條上跌倒，他就是犯了衆條 :: !你就是不姦淫，卻殺人，仍是成了犯律法的
# 律法不能拯救
## 律法——將來美事的影兒、罪的提醒
> evr 10:1-3 :: !律法既是將來美事的影兒，不是本物的真像 :: !但這些祭物是叫人每年想起罪來
## 律法不能拯救：無論律法的知識還是行爲
> gal 3:21 :: !若曾傳一個能叫人得生的律法，義就誠然本乎律法了
## 遵行律法的字句不能拯救
> mf 5:20 :: !你們的義若不勝於文士和法利賽人的義，斷不能進天國
> 1kor 13:1-3 :: !卻沒有愛 :: !我就成了鳴的鑼、響的鈸一般 :: !我就算不得什麼 :: !仍然與我無益
## 違犯律法導致定罪
> rim 2:12-13 :: !凡在律法以下犯了罪的，也必按律法受審判 :: !乃是行律法的稱義
## 誰不遵行全律法——誰就被咒詛
> gal 3:10-12 :: !凡不常照律法書上所記一切之事去行的，就被咒詛 :: !義人必因信得生 :: !行這些事的，就必因此活著
## 律法沒有使任何人達到完全
> evr 7:18-19 :: !先前的條例因軟弱無益，所以廢掉了 :: !律法原來一無所成 :: !引進了更美的指望
# 那麼摩西律法爲什麼是必要的？
## 律法使人知道罪
> rim 3:20 :: !因爲律法本是叫人知罪
> rim 5:20 :: !律法本是外添的，叫過犯顯多 :: !只是罪在那裏顯多，恩典就更顯多了
## 律法約束罪人（爲罪人而有）
> 1tim 1:9 :: !律法不是爲義人設立的 :: !乃是爲不法和不服的
## 律法使人看見救主的必要（對救主的期待）
> rim 7:22-24 :: !我是喜歡上帝的律 :: !我真是苦啊！誰能救我脫離這取死的身體呢
# 律法不是永恆的
## 律法——直到它被成全
> mf 5:18 :: !就是到天地都廢去了 :: !律法的一點一畫也不能廢去，都要成全
## 基督成全了律法，從而廢除了它
> mf 5:17 :: !莫想我來要廢掉律法和先知 :: !我來不是要廢掉，乃是要成全
# 基督終結了律法的時代
## 關於有一位像摩西的先知來臨的預言
設立摩西律法時，立刻就說到將來要來一位像摩西的先知，即**立法者**，人應當聽他。這是指著基督說的：
> vtor 18:15 :: !耶和華你的上帝要從你們弟兄中間給你興起一位先知像我 :: !你們要聽從他
> act 3:22 :: !主上帝要從你們弟兄中間給你們興起一位先知像我 :: !凡他向你們所說的，你們都要聽從
> act 7:37 :: !上帝要從你們弟兄中間給你們興起一位先知像我
而上帝親自以同樣的話確認了這一點：
> mk 9:7 :: !這是我的愛子，你們要聽他 ~~ 並見 [[mf 17:5]]；[[lk 9:35]]。
## 基督稱律法爲「你們的」
> in 8:17 :: !你們的律法上也記著說
> in 10:34 :: !你們的律法上豈不是寫著
## 律法——直到施洗約翰
> mf 11:12-13 :: !因爲衆先知和律法說預言，到約翰爲止
## 律法賜下，爲一段時期，直到來臨之時
> gal 3:19 :: !原是爲過犯添上的 :: !等候那蒙應許的子孫來到
## 誡命之律已被教導廢除
> ef 2:14-16 :: !拆毀了中間隔斷的牆 :: !以自己的身體廢掉冤仇 :: !就是那記在律法上的規條
## 關於律法的爭論已屬徒然
> tit 3:9 :: !並因律法而起的爭競，因爲這都是虛妄無益的
## 奴僕的軛——就是摩西律法
> gal 5:1 :: !不要再被奴僕的軛挾制
## 基督的軛——另一種，是容易的
> mf 11:28-30 :: !你們當負我的軛，學我的樣式 :: !因爲我的軛是容易的，我的擔子是輕省的
## 新的律法——基督的律法——就是愛
> rim 13:10 :: !所以愛就完全了律法
> gal 5:14 :: !因爲全律法都包在『愛人如己』這一句話之內了
## 在關於律法的長篇論述之後——信心與愛心
> 1in 3:22-23 :: !上帝的命令就是叫我們信他兒子耶穌基督的名 :: !且照他所賜給我們的命令彼此相愛
> gal 6:2 :: !如此，就完全了基督的律法
> gal 5:3-6 :: !他是欠著行全律法的債 :: !你們這要靠律法稱義的，是與基督隔絕，從恩典中墜落了 :: !我們靠著聖靈，憑著信心，等候所盼望的義 :: !惟獨使人生髮仁愛的信心纔有功效
> gal 5:1,11,13 :: !你們蒙召是要得自由 :: !總要用愛心互相服事
## 導致死亡的，是信心的缺乏，而不是違犯摩西律法
> 1in 5:12 :: !人有了上帝的兒子就有生命 :: !沒有上帝的兒子就沒有生命
## 救恩來到，與律法的行爲無關
> rim 3:21-22 :: !但如今，上帝的義在律法以外已經顯明出來 :: !就是上帝的義，因信耶穌基督加給一切相信的人
> rim 8:1-2 :: !如今，那些在基督耶穌裏的就不定罪了 :: !因爲賜生命聖靈的律在基督耶穌裏釋放了我 :: !使我脫離罪和死的律了
## 按律法而活——按血氣而活
> gal 3:2-3,23 :: !你們受了聖靈，是因行律法呢 :: !你們既靠聖靈入門，如今還靠肉身成全嗎 :: !我們被看守在律法之下
## 按聖靈而活——高於按律法而活
> gal 5:16,18 :: !你們當順著聖靈而行 :: !但你們若被聖靈引導，就不在律法以下
> gal 5:22-23 :: !聖靈所結的果子 :: !這樣的事，沒有律法禁止
