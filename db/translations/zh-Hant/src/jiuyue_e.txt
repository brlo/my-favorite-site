律法主要描述女性特有的生活情境，以及兩性關係中的種種情境。其中可以分出如下幾個領域：
- 生育（[[lev 12:]]）
- 血漏（[[lev 15:19-30]]、[[lev 18:19]]、[[lev 20:18]]）
- 赤露（[[lev 18:]]）
- 與男人的關係、擇夫（[[lev 19:20]]、[[lev 21:7-14]]、[[chis 5:12-31]]、[[chis 36:]]）
- 許願（[[lev 27:3-8]]、[[chis 6:]]、[[chis 30:4-17]]）
- 犯罪墮落（[[lev 19:20]]、[[lev 20:10-21]]）
下面按上述次序分別討論這些領域。
# 生育
婦女生產之後，律法規定了潔淨的日子，並且按所生嬰兒的性別而不同。生男嬰後，婦人要不潔七天，並有33天的潔淨期，在此期間她不可摸任何聖物，也不可進聖所（[[lev 12:2-4]]）。若是生女嬰，這些日子相應地加倍（[[lev 12:5]]）。
# 血漏
首先應當提到，律法說人身上有任何流出，就使他成爲不潔的：
> lev 15:2 :: !人若身患漏症，他因這漏症就不潔淨了
儘管如此，關於婦女，出於可以理解的原因，另有單獨且相當詳盡的記述。
大體上，婦人患血漏的日子就爲不潔，此後還有7天的潔淨期。若她一直患血漏，就一直不潔。不潔的婦人不能與丈夫同房；否則丈夫也將與妻子同樣不潔，加在妻子身上的條例同樣加在丈夫身上。患血漏的婦人所坐所觸之物都成爲不潔，凡接觸這些的，必不潔到晚上。潔淨的日子之後，要獻上兩隻斑鳩或兩隻雛鴿爲祭（[[lev 15:29-30]]），此後婦人才算爲潔淨。
還有其他與婦女和血漏有關的律法規定，將在下面各節中論及。
# 赤露
> lev 18:6 :: !你們都不可露骨肉之親的下體
雖然這一章也提到男人（父親）的赤露，但按情理，主要列舉的是對各種親屬關係——不僅是骨肉之親——的婦女露體的禁令：
> lev 18:15 :: !不可露你兒婦的下體 :: !她是你兒子的妻，不可露她的下體
回到前面提到的血漏律法，再看這條丈夫對妻子的禁令：
> lev 18:19 :: !女人行經不潔淨的時候，不可露她的下體，與她親近
# 與男人的關係、擇夫
若男人引誘已許配別人的婢女，他不像引誘自由人（即非婢女）那樣要被處死（[[vtor 22:25]]），而只須獻贖愆祭——公綿羊（[[lev 19:20-21]]）。
夫妻同房之後到晚上都算不潔（[[lev 15:18]]）。
只有童女可以作祭司的妻子（[[lev 21:13]]），不可娶寡婦、被休的、被玷污的或妓女。
若婦女因沒有男嗣而承受地業，她只能嫁給自己父親支派中的人（[[chis 36:8]]），免得產業從一個支派轉到另一個支派。
甚至有一條規定，描述丈夫懷疑妻子犯奸淫時所應行的程序（[[chis 5:12-31]]）。
# 許願（向上帝所許的願）
有人向上帝許特別的願，其中一些被稱爲拿細耳人（不要混淆：耶穌基督被稱爲拿撒勒人，因爲他來自拿撒勒）；他們許願不喝任何葡萄製品，不剃頭髮，不挨近死屍。這樣的願可以爲一段時期而許，也可以許終身。提到這一點，只是爲了強調一個事實：拿細耳人既有男人，也有婦女。
律法允許贖回賣出的東西（[[lev 25:25]]）；類似地，對經在聖所事奉而將自己獻給上帝的人，也規定了贖價。這裏可以注意：男人和女人的生命估價不同。例如，20至60歲的男子估爲50舍客勒聖所銀子，女子爲30舍客勒（[[lev 27:3-4]]）。這一差別，洛普欣解釋爲：每個情形中所估的是獻身聖所者的不同勞動能力，因爲聖所需要他作體力勞動：砍柴、打水等等。
> chis 30:2 :: !就不可食言，必要按口中所出的一切話行 ~~ 俄文本編號爲 Числ 30:3。
這樣，誰許了願，誰就必須還願；但對婦女有附帶條件。若妻子許了願或起了誓，丈夫聽見了，可以廢掉她所許的願，那願就算沒有了。父親也可以照樣廢掉他女兒年幼時所許、他所聽見的願。
# 犯罪墮落
這裏記述了一系列對罪施以嚴厲刑罰的法律，例如：
- 姦淫（[[lev 20:10-12]]），
- 獸淫（特別論到婦女：[[lev 20:16]]、[[lev 18:23]]），
- 男色（同性苟合）（[[lev 20:13]]）等等。
這類違揹律法的罪行要處以死刑。
