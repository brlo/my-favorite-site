# 定義
地獄——是在榮耀的第二次降臨和最後審判之後被定罪的罪人的居所。最後審判之後，這一命運已無法改變。被定罪者的痛苦與義人的真福將同樣永遠持續。

# 批評
## 地獄無盡刑罰的教導會使人遠離基督嗎？
這不是論據。罪人聽到關於罪的刑罰的話，本來就是不舒服的。難道因此就該向他應許：犯罪會有真福？同樣，對愛罪的人來說，這樣的教導是不舒服的：
- 論悔改，
- 論離棄罪，
- 論改正生活，
- 論基督是唯一的救主，別的路不通向救恩（[[act 4:12]]），
- 論愛仇敵、放棄報復、饒恕人的虧欠、善待恨我們的人（[[mf 5:44]]；[[lk 6:27]]；[[lk 6:35]]），
- 論放棄求財的意向（[[mf 19:24]]），
- 論一夫一妻（[[mf 19:10]]）。
但這當然並不意味著要放棄這一切。而爲什麼不意味著呢？因爲這是真理。如果人不聽從這些話，那麼關於刑罰的警告就真會應驗——這些話並不是徒然的。我們警告他，是爲了這些事不至於臨到他身上。永遠的刑罰也是如此：如果這是真實的教導，那爲什麼要修改真理、刪除罪人不便聽到的東西呢？
> 2tim 4:3 :: !耳朵發癢，就隨從自己的情欲，增添好些師傅
在教導中應當以真理爲出發點，而不是以人們喜歡聽什麼爲出發點：
> iud 1:3 :: !要爲從前一次交付聖徒的真道竭力的爭辯
