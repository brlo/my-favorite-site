# 定義
**恩典**（古希臘文 χάρις，希伯來文 חֵ֣ן）——按主要意義，指爲拯救人而運行在人身上的上帝的能力。
1. **上帝的能力，上帝的作爲**（[[1kor 15:10]]——我今日成了何等人，是蒙上帝的**恩**才成的；並且他的**恩**在我裏面不是徒然的；我比衆使徒格外勞苦——這不是我，乃是**與我同在的上帝的恩**）；
2. **恩惠、憐憫、饋贈、恩寵、對某人的愛**（[[gen 18:3]]——我若在你眼前蒙**恩**）；（[[gr sud 6:17]]——我若在你眼前蒙**恩**）；（[[1ts 16:22]]——他在我眼中蒙了**恩**）；（[[gr 3ts 11:19]]——哈達在法老面前大蒙**恩惠**）；（[[gr act 2:47]]——**得**衆民的**喜愛**）；（[[act 7:46]]——這位在大衛**蒙**上帝**恩**）；（[[gr 1kor 16:3]]——把你們的**捐資**送到耶路撒冷）；
3. **感謝上帝、討上帝喜悅**（[[2kor 9:15]]——**感謝**上帝，因他有說不盡的恩賜）；（[[1pet 2:19]]——倘若人爲叫良心對得住上帝，就忍受冤屈的苦楚，這是**可喜愛的**）；
4. **美麗**（[[pr 5:19]]——**可愛**的母鹿）；（[[gr pr 3:22]]——作你頸項的**美飾**）；
5. **珍貴**（[[pr 17:8]]——**珍寶**石頭）；（[[ekl 10:12]]——智慧人的口中說出了**恩言**）；（[[ps 45:2]]——你嘴裏滿有**恩惠**）；
6. **恩寵、尊榮、榮耀**（[[iudf 8:23]]——奴役不會成爲我們的**榮耀**）。

# 前言
聖義者和天使受敬禮，不是作爲神，而是作爲上帝的朋友。受敬禮的不是他們本身，而是因爲他們分有上帝、因爲他們裏面存有上帝的恩典（見[[ru:человек-храм-Божий|人——上帝的殿]]一文）。按聖經，受敬禮的不只是上帝；叩拜不只是向上帝行；上帝親自呼召人尋求從上帝來的榮耀；上帝應許榮耀義人，並且榮耀了他們；教會追隨上帝，榮耀上帝聖潔的朋友們。
上帝在聖徒生前、也藉著他們**死後肉身**（[[4ts 13:21]]）、**遺物**（[[act 19:12]]）和**像**（[[act 5:15-16]]）賜下自己的恩典，所以這一切也都受敬禮。詳見相應條目：
- [[ru:почитание-мощей-святых|敬禮聖髑]]；
- [[ru:иконы-иконопочитание-иконоборчество|敬禮聖像]]。

# 向聖人叩拜
十誡的第二誡（[[ish 20:4-5]]；[[vtor 5:8-9]]）禁止敬拜假神（偶像）。假神實際上不是神：他們的神性是虛構的，是幻想、謊言。
聖人是真實存在的，他們是上帝的朋友；向他們叩拜，不是把他們當神。向聖人叩拜，是表達對他們的敬意——作爲上帝的朋友、作爲上帝的僕人（天使）、作爲上帝之母。這樣的向天使、向人、向物件的叩拜在聖經中有，而且不是拜偶像，因爲拜偶像——是敬拜**假**神，敬拜謊言。義人們經常向人如向人、向天使如向天使、向先知如向先知、向物件如向物件下拜。在一切情形中，他們都不是把他們當作神來拜。
## 向以天使形像顯現的上帝叩拜
顯現的是上帝，但那三位天使不是上帝的本相、不是他在創世之前所是的；就是說，這是上帝的**像**（希臘文 εἰκόνα——聖像），而亞伯拉罕拜的是上帝的聖像：
> gen 18:1-2 :: !向亞伯拉罕顯現出來 :: !見有三個人在對面站著 :: !俯伏在地
