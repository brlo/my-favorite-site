# 前言
首先要說明：“基督就是天使長米迦勒”的說法存在於“耶和華見證人”這一極端教派中。耶和華見證人爲論證自己的教導，製造了自己歪曲甚多的聖經譯本（專家對該派《新世界》譯本的評述見 <a href="https://azbyka.ru/otechnik/sekty/rassuzhdaja-so-svideteljami-iegovy-pri-pomoshhi-pisanija/4_7">azbyka.ru</a>）。此外，基督復臨安息日會也有人認爲，舊約中以天使長米迦勒身份出現的那一位似乎就是上帝之子耶穌基督。
# “天使”一詞的兩個含義
在聖經中，“天使”一詞有兩種理解：職能與本性。
天使的**職能**是奉差遣，因爲這個詞在古希臘文中字面上正是這個意思：ἄγγελος（天使羅思）——使者、報信者；希伯來文 מלאך——使者。
天使的**本性**是無形體的靈。天使是被上帝所造的靈體，沒有身體（無形的），換言之就是靈。這些靈在被造之先於人類，被賦予了自由與理性。他們中有一部分不願順服上帝，從他墮落了，但仍然被稱爲天使（[[mf 25:41]]）。也就是說，本性獨立於活動：無論是否奉差遣，都是天使。本性就是如此。因此，一個由人所生的、完全具體的人——先知施洗約翰——也被稱爲天使（[[mal 3:1]]；[[mf 11:10]]；[[mk 1:2]]；[[lk 7:27]]）。同樣含義下，基督自己也被稱爲新約的使者（[[mal 3:1]]）。這個說清楚了。現在來看引文。
# 所有天使都是服役的靈，而基督坐在寶座上
使徒保羅稱上帝之子是遠比天使更尊貴的存在（[[evr 1:4]]），因爲上帝從不以對待自己兒子的方式對天使說話（[[evr 1:5]]），上帝的兒子要受所有天使的敬拜（[[evr 1:6]]）；他指出上帝論到天使和論到上帝之子的話語各不相同：前者是服役的靈，後者是坐在寶座上的主宰（[[evr 1:7-8]] 與 [[evr 1:13]]）；並指出一切受造之物的短暫，但創造了萬有的上帝之子自己永不廢去（[[evr 1:10-12]]）。最後，聖經直說：所有天使無一例外都是服役的靈，但子是與父同坐在寶座上的：
> evr 1:13-14 :: 坐在我的右邊 :: 服役的靈
兒子受服役，而子與父一同作王。
# 上帝要受人敬拜，基督受一切受造物的敬拜
上帝說，萬膝必向他跪拜（[[rim 14:11]]）；而基督受一切受造物的敬拜——不只是人（[[fil 2:10]]），包括天使（[[evr 1:6]]）。
# 世界交給了基督，不是交給天使
> evr 2:5 :: 上帝原沒有交給天使管轄
同時，世界交給了基督：
> 1kor 15:27 :: 上帝叫萬物都服在他的腳下
> ef 1:22 :: 又將萬有服在他的腳下
> evr 2:8 :: 叫萬物都服在他的腳下
# 全能者、萬王之王、萬主之主
先知稱**上帝**爲萬主之主（[[ps 136:2-3]]）。使徒稱**上帝**爲萬主之主、萬王之王（[[1tim 6:15-16]]）。使徒稱**耶穌基督**爲萬主之主、萬王之王（[[otkr 17:14]]；[[otkr 19:16]]），爲全能者（[[otkr 1:8]]）。萬王之王之上沒有別的王。萬主之主之上沒有別的主。全能者之上沒有任何存在能托住全能者，因爲他自己以自己的能力托住萬有。天使長米迦勒是天使軍團的君長。基督卻是世上一切——包括天使和天使長米迦勒本身——的元首。
# 上帝（耶和華）親自差遣先知，而基督說，正是他差遣了他們
應當指出：基督指明，他就是那位向以色列差遣了許多先知的（[[mf 23:34]]）。而聖經告訴我們，正是上帝親自（而非藉天使）向先知說話，並親自把他們差往以色列（[[ish 3:12]]；[[mal 4:1]]、[[mal 4:5]]；[[sud 6:8]]；[[2par 25:15]]；[[1ts 15:1]]；[[2ts 12:1]]；[[2ts 12:7]]）。也就是說，基督就是耶和華上帝。在上帝與先知的交往中，沒有中間人。
# 上帝之子由父所生，他創造了天使
基督是一切看得見與看不見之物的創造者，包括天使（[[kol 1:13-17]]）。也就是說，他要成爲天使，就得先造出他自己。
# “米迦勒”之名的詞源
米迦勒是希伯來名字，源自 מי כמו אלוהים（米·克莫·埃洛希姆，縮略爲“米·卡·埃爾”），字面意思是“誰能像上帝”。也就是說——沒有誰與上帝同等，沒有誰能與他相比。但基督並不認爲自己與上帝同等是強奪的（[[fil 2:6]]）。
# 舊約藉天使賜下，新約由主親自宣講
使徒保羅指出新約與舊約的區別：舊約藉天使傳的（[[evr 2:2]]），而新約由主自己親自宣講（[[evr 2:3]]）。也就是說，至少不是藉天使。
# 上帝成爲人，向天使顯現
> 1tim 3:16 :: 上帝在肉身顯現 :: 被天使看見
從來沒有人看見上帝（[[in 1:18]]），他住在人不能靠近的光裏，人不可能看見上帝（[[1tim 6:16]]）；然而，上帝一旦真正成爲人（[[in 1:14]]），就在基督裏成爲人人可見的。人不能憑肉眼看見靈界（天使）的居民，但基督卻說自己看見了從天墜落的撒但（[[lk 10:18]]）。
# 結語
基督不是天使長米迦勒，而是上帝。他多次被直接稱爲上帝。聖經對此直言不諱：[[ru:Христос-Бог|基督是上帝]]
> ps 50:7 :: 我的民哪！你們當聽我的話 :: 我是上帝，是你的上帝
