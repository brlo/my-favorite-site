正教基督徒被指控拜偶像：聖像被稱爲偶像，敬禮聖像被稱爲拜偶像。本文按聖經考察聖像敬禮的問題，回應這些指控。
先給出簡短的回答，然後較詳細地考察批評，最後給出最詳細的、逐句依據聖經的回答。
# 敬禮聖像最簡短的辯護
在上帝道成肉身之前的時代，上帝爲舊約的以色列設立律法時，沒有顯明自己的像，並禁止製造假神（偶像）的像、禁止敬拜它們（[[ish 20:4-5]]；[[vtor 5:8-9]]；[[vtor 4:15-19]]）；但他命令描繪自己的聖潔僕人（[[ish 25:1]]；[[ish 26:1]]；[[ish 25:18-20]]），而先知們在有像的聖物前叩拜（[[nav 7:6]]；[[ps 5:7]]）。正教徒對帶有像的聖物的敬禮，與先知的做法完全一樣。
此外，按上帝的構想，聖殿本身就是天的聖像（[[ish 25:8-9,40]]；[[evr 9:24]]；[[act 7:44]]）。上帝命令敬重聖殿（[[lev 19:30]]；[[lev 26:2]]）；聖殿受敬禮，人們在它面前叩拜（[[ps 5:7]]；[[ps 99:5]]；[[ps 132:7]]）。這正是正教的敬禮：敬禮像，就是敬禮原型。
任何人想用來爲先知對帶有像的聖物的敬禮辯護的理由，都適用於正教的敬禮（因爲這是同一件事）；任何人想用來指責正教敬禮的定罪，也同樣落在先知的敬禮上。
問題完全不在像及其敬禮。既然偶像是對上帝的任何虛假觀念，那麼問題在於：1）像本身、2）敬禮者賦予它的意義內容，與真理是什麼關係。如果兩者中哪怕一個在原則上虛假，那就是拜偶像——它把人從真理引開。這纔是問題所在：偶像不引人歸向上帝，對上帝的虛假觀念不引人歸向真上帝，因爲謊言不引向真理，而使人離開真理。
在與反對聖像者的對話中簡要檢驗這一論斷：
**反聖像者**：向物件叩拜——是拜偶像。
**正教徒**：那麼上帝的先知們在聖殿和有像的約櫃前叩拜，就成了拜偶像的了？
**反對者**：上帝只說了描繪，沒有說敬禮或叩拜。
**正教徒**：那麼先知們作了不該作的、沒有記載的、沒有被命令的事，就是說陷入了拜偶像？
**反對者**：先知叩拜的不是聖殿或約櫃本身，而是把這敬禮歸於上帝。
**正教徒**：正是如此。正教徒叩拜的也不是木頭和顏料，而是像中所描繪的位格——教導中正是這樣說：藉著像敬禮原型，如同先知。沒有任何差別。
如此等等。這條規則永遠有效，因爲先知的敬禮與正教的敬禮之間沒有任何差別。現在更詳細地考察這一問題。
# 反聖像者說：“上帝的話明明說：不可作像，你們卻作”
**回答**：這是摩西律法中只針對描繪上帝的舊約禁令，從上下文可見：
- 前四條誡命正是**關於上帝**的（[[ish 20:4-5]]；[[vtor 5:8-9]]）；
- 設立禁令時，上帝指出它的緣由：在律法設立時上帝沒有顯明自己的**像**（[[vtor 4:15-19]]）：既然沒有見過上帝，就不要描繪。
這樣，禁令針對的正是描繪上帝；而對自己的聖潔僕人，上帝不但沒有禁止，反而命令描繪（[[ish 25:1]]；[[ish 26:1]]），義人們向聖殿和帶這些像的聖物叩拜（[[nav 7:6]]；[[ps 5:7]]；[[ps 99:5]]；[[ps 132:7]]）。
舊約的教會裏有聖像，它們受敬禮。首先，**舊約的聖殿本身就是聖像**。作爲地上的場所，它按上帝起初的構想應當成爲天上所發生之事的描繪。上帝命令先知摩西建造聖殿，不是因爲他需要殿（上帝不需要，[[is 66:1]]；[[ps 49:13]]；[[is 1:11]]），而是命令把殿造爲天的聖像、造爲向先知所顯示的天上實體之像（[[ish 25:8-9,40]]；[[evr 9:24]]；[[act 7:44]]）。上帝命令敬禮這一聖像（[[lev 19:30]]；[[lev 26:2]]）。先知大衛向它叩拜（[[ps 5:7]]；[[ps 99:5]]；[[ps 132:7]]）。當不虔的王在聖殿裏設立異教偶像時（[[4ts 21:3-7]]）——即損壞了天上實體的像——上帝就棄絕了聖殿（[[4ts 23:27]]）。
正因爲聖殿是天的聖像，在新約裏它經歷了改變（內部構造、像），因爲天上實體也改變了。在舊約裏，天上實體中以屬靈-可見方式存在的**只有天使**。而上帝完全不可見、非物質，人也還沒有達到天上的生命（詳見[[ru:9VFT_До_жертвы_Христовой_ветхозаветные_праведники_сходили_в_ад|詳見]]）。
在新約裏——更準確地說，隨著主耶穌基督的來臨——發生了巨大的變化：
1. **上帝按人性成爲可見的**（[[in 1:18]]；[[1in 1:1-2]]）；
2. **上帝有形地在天上登基**（[[ef 1:20-21]]；[[otkr 3:21]]）；
3. **天上出現了人**——他們獲得了與主耶穌基督同活的可能（[[otkr 6:9-11]]；[[otkr 14:1,3-5]]）；
4. **上帝訂立新約**（[[ier 31:31]]；[[evr 8:8]]；[[lk 22:20]]；[[1kor 11:25]]）。**舊約與摩西的律法一同終結**（[[rim 7:6]]；[[gal 3:21-25]]；[[ef 2:14-16]]）。描繪上帝的禁令失效，因爲它曾是摩西律法的一部分，而摩西律法已隨基督的來臨被廢除（詳見[[ru:Библия-Закон-Моисея-отмена|詳見]]）。
這樣，舊約的聖殿是舊約天上實體的像，而這實體在新約裏改變了。先前的已不存在。既然聖殿按上帝起初的構想就是天上實體的像，那麼在這實體改變之後，描繪舊的就已沒有意義。因此基督徒從最古老的年代起描繪新的天上實體，把在天空明顯登基的耶穌基督（上帝）的像立在最前面，周圍——描繪他聖潔的僕人們：如今已不只是天使，還有人。
標誌性的事件是基督的祭獻之後耶路撒冷聖殿的損壞：
> mf 27:51-53 :: !殿裏的幔子從上到下裂爲兩半 :: !地也震動，磐石也崩裂 :: !墳墓也開了 :: !到耶穌復活以後 :: !進了聖城，向許多人顯現
而在70年代，聖殿被羅馬人完全毀滅，在隨後的一切千百年裏，把位置讓給了新的天上實體之像——正教聖殿。
更多古聖像見：[[ru:древние-иконы|古聖像]]
過時的不只是舊約天上實體的像，還有舊約本身——摩西的律法是它不可分的部分，如今律法已失去意義。除描繪上帝的禁令外，還有許多規定在新約裏已不再有效：
> lev 24:16 :: !那褻瀆耶和華名的，必被治死 :: !他褻瀆耶和華名的時候，必被治死
褻瀆上帝的名——是違揹**第三誡**的罪。按摩西律法的刑罰——死（[[lev 24:16]]）。據我們所知，反對聖像的人並不教導爲褻瀆上帝而殺人。他們要求遵守舊約關於不可描繪上帝的禁令，引用帶有“這是上帝的話”字樣的引文；但關於處死褻瀆者的誡命也是上帝的話，也寫得同樣明白，但他們並不這樣行。爲什麼？因爲摩西律法被廢除了。
**第四誡**設立安息日的安息——停止作工（[[ish 20:8-10]]；[[vtor 5:12-15]]；[[lev 19:3]]；[[lev 19:30]]）。按摩西律法的刑罰——死。這也是上帝的話，也寫得同樣明白；但反對聖像的人不教導爲破壞安息日的安息而殺人，他們大多數連安息日的安息自己也不守。爲什麼？因爲摩西律法被廢除了。
這樣，禁止描繪道成肉身的上帝意味著：
1. **猶太化**：繼續按摩西律法生活（順便說，什一奉獻也是按同樣的理由收取的，見[[ru:ozcY_О_десятине|什一奉獻]]）；
2. **間接否認上帝道成肉身**：或者否認基督是上帝，或者否認他是可見的。
現在我們把問題考察得更詳細。
# 摩西律法的第二誡
反對聖像的人認爲聖像違反了[[ru:10-заповедей|摩西律法]]的第二誡：
1. “**不可爲自己雕刻偶像；也不可作什麼形像**彷彿上天、下地，和地底下、水中的百物。**不可跪拜那些像**；也不可事奉它”（[[ish 20:4-5]]；[[vtor 5:8-9]]）；
摩西的十誡分爲兩部分（兩塊法版）：
- 四條關於愛上帝的誡命；
- 六條關於愛鄰人的誡命。
第二誡屬於愛上帝的表現，它並不禁止一切的像和叩拜，而是禁止製造物件、把它們當作神來敬拜以代替獨一的真上帝。換言之，**這條誡命禁止敬拜假神**。正因爲如此，我們在聖經裏既看到像、也看到不違反這條誡命的叩拜。詳見下文。
## “不可作像”
### 上帝命令在他自己的聖殿裏製作像
雖然第二誡禁止作像，但賜下這條誡命的同一上帝，如今命令在他的殿（會幕）裏製作像：在會幕的板壁上、在通入至聖所的幔子上描繪基路伯的像，並在約櫃的施恩座上製作基路伯的金像：
> ish 26:1 :: !你要用十幅幔子作帳幕 :: !並用巧匠的手工繡上基路伯
> ish 36:8 :: !並用巧匠的手工繡上基路伯
> ish 25:18-20 :: !要用金子錘出兩個基路伯來 :: !安在施恩座的兩頭
在較晚的、所羅門建造的聖殿裏，有更多的各種像和雕像：
> 2par 3:14 :: !織幔子 :: !在其上繡出基路伯來
> 2par 3:10 :: !在至聖所按造像的法子造兩個基路伯
> 3ts 6:23 :: !他用橄欖木作兩個基路伯
聖殿構造的詳情：[[ru:иерусалимский-храм|耶路撒冷聖殿]]
爲製作殿內的器皿，上帝把聖靈的恩賜賜給了工匠們：
> ish 31:1-5 :: !我已經提他的名召他 :: !我也以我的靈充滿了他 :: !能想出巧工，用金、銀、銅製造各物
### 上帝命令製作蛇的像
上帝還命令製作銅蛇，使望它的人奇妙地脫離蛇咬的死亡：
> chis 21:8-9 :: !你製造一條火蛇 :: !凡被咬的，一望這蛇，就必得活 :: !摩西便製造一條銅蛇 :: !凡被蛇咬的，一望這銅蛇，就活了
非常重要的是：這蛇是耶穌基督的像，應當指向他在十字架上將來的苦難：
> in 3:14-15 :: !摩西在曠野怎樣舉蛇 :: !人子也必照樣被舉起來 :: !叫一切信他的都得永生
這蛇後來被希西家王毀掉，因爲以色列人開始把蛇本身當作神，給它起了自己虛假的名字（尼忽士但）——這名字與真上帝沒有任何關係。他們離棄了真上帝，違反了第二誡：
> 4ts 18:4 :: !打碎摩西所造的銅蛇 :: !以色列人仍向銅蛇燒香 :: !希西家叫銅蛇爲銅塊
## “不可跪拜那些像”
雖然禁止敬拜像（聖像），但義人們經常向人、向各種物件、向天使下拜；別人也向先知下拜。沒有人因拜偶像而定他們的罪，因爲這些叩拜不是向假神（偶像）行的。
### 向以天使形像顯現的上帝叩拜
亞伯拉罕向以三個男人形像顯現的上帝叩拜：
> gen 18:1-2 :: !向亞伯拉罕顯現出來 :: !見有三個人在對面站著 :: !俯伏在地
爲什麼上帝以像顯現？——因爲上帝在本性上不可見，從來沒有人見過他（[[1tim 6:16]]；[[in 1:18]]）。
### 向天使叩拜
先要指出：天使是靈（[[evr 1:13-14]]），而靈沒有骨和肉（[[lk 24:39]]）；就是說，天使也是以人的形像向人顯現的。所以，向天使叩拜，就是向看不見的靈（天使）的看得見之像叩拜：
> nav 5:14 :: !約書亞就俯伏在地下拜
### 向先知叩拜
> 4ts 2:15 :: !在他面前俯伏於地
### 向聖殿叩拜
大衛向聖殿叩拜——這殿本身就是天的聖像（[[lev 19:30]]；[[lev 26:2]]），並且殿中佈滿聖天使的像（[[ish 25:1]]；[[ish 26:1]]）：
> ps 5:7 :: !向你的聖殿下拜
同時，上帝命令敬重聖殿（[[lev 19:30]]；[[lev 26:2]]）。
### 向上帝的腳凳（聖殿）叩拜
> ps 99:5 :: !在他腳凳前下拜
> ps 132:7 :: !我們要進他的居所，在他腳凳前下拜
### 向約櫃叩拜
> nav 7:6 :: !俯伏在地，直到晚上
### 向杖叩拜
經上記著“以色列在牀頭上敬拜”（[[gen 47:31]]），而在七十士譯本里是“在杖頭上”（[[evr 11:21]]）。

## 異教對偶像的信仰違反第二誡
對偶像的異教信仰之所以違反第二誡，是因爲它**在任何情形下**都要求叩拜**虛假的**、**並不存在的神**。摩洛、巴力、宙斯、朱庇特和佩倫並不存在——他們是虛假的神。
對偶像的異教信仰有三種，從最普遍的一種開始：
1. **偶像——就是神本身**。異教徒親手製造的物件（偶像）本身就是神。
1. **偶像——虛假之神的形像**，無論那神多麼遙遠，據說就應當長成這樣。
1. **偶像——**（被神化的）**自然元素的虛構形像**：海、風、雨、火、土。
在所有三種情形中，受敬禮的都是**虛假的**、**並不存在的神**。這是對謊言的信仰。
我們在聖經中遇到的正是第一種。聖經中所描述的最普遍的異教信仰，是**對物件本身（物質）的神化**。異教徒可以用手邊的材料爲自己造一個神，或者把已有的物件神化：
> is 44:14-15 :: !他砍伐香柏樹 :: !這樹，人可用以燒火 :: !而且作神像跪拜 :: !作雕刻的偶像向它叩拜
> gen 31:19,30 :: !拉結偷了她父親家中的神像 :: !爲什麼又偷了我的神像呢
| 再如：有個準備航海的人，行將在怒濤中航行之際，**竟向一塊比自己乘的船還易壞的木頭呼求**。……這種不虔敬的事，相沿日久，便成了習俗，以致守如法律；再加上君王的命令，**彫像遂受崇拜**。 ||| sb prs 14:1,16
| 君王對他說：「**你不以爲貝耳是生活的神嗎？你不見貝耳每天吃喝那麼多嗎？**」 ||| sb dan 14:6 ~~ 此段經文不在和合本中，引文按思高本。
| 祭祀對偶像有什麼用處？**既不能吃，又不能聞**： ||| sb prsir 30:19 ~~ 俄文本爲 Сир 30:19。
> act 19:24-27 :: !是製造亞底米神銀龕的 :: !人手所作的，不是神 :: !這保羅不但在以弗所 :: !不獨我們這事業被人藐視
聖經中其他類似的地方：[[ru:языческая-вера-в-идола|異教徒對偶像的信仰]]
古代的哲學家作爲有思想的人，在維護自己異教信仰時，已經意識到：經人手加工的材料不可能是神。他們也可能說出別的判斷，說這不過是神的形像，或某個元素的虛構形像。但第二誡仍然被違反了。
虛假的異教之神，不僅因其名字或形像而是假的。關於神的謊言，也表現在神的數目、他們的能力、本質屬性上，而最主要的——表現在上帝關於自己受造物的旨意中，這旨意啟示在誡命裏。
爲清楚起見，逐項加以比較。
### 異教的神
- 名字是虛假的（摩洛、巴力、宙斯、佩倫等等），
- 形像是虛假的（各種人形的像），
- 能力是虛假的（有限的，許多異教神各有不同的能力），
- 意志是虛假的（不是真上帝在誡命中所表達的旨意），
- 本質屬性是虛假的（不是永恆，不是無所不在，不是全知，不是無限，不是不朽，不是聖潔），
- 他召人去的是另一個（虛假的）地方，走另一條（虛假的）路。
### 正教會所信的上帝
- 聖經中真上帝的名字（自有者、父、子、聖靈、耶穌基督以及[[ru:Бог-имена|其他]]）；
- 上帝親自藉此向世界顯現自己的那些形像（亞伯拉罕面前的三位天使——[[gen 18:1-2]]，鴿子——[[lk 3:22]]，以及最後，上帝之子真實所取的人的形像）；
- 描繪的是全能的宇宙創造者；
- 呼召人遵行神聖誡命的上帝（基督被描繪爲手中拿著打開的書，其中寫著他的誡命）；
- 描繪的是召人經由十字架之路與他同活的上帝（基督被描繪在十字架上，有十字形光環）。
這樣，異教徒把像本身當作神，或當作（虛假之）神的形像，而正教會描繪的是真上帝，並不把製品（聖像）本身當作神。
此外，正教會也描繪上帝的朋友們：童貞女馬利亞上帝之母、天使、使徒、義人們。這不是謊言。他們都真實存在。同時，無論這些聖人和天使本身，還是他們的像，都不被視爲神。
正教會中的一切聖像都與福音書和十字架一樣作爲聖物受敬禮。對它們的敬禮歸向真上帝和他真實存在的朋友們。

# 隨著基督的來臨，發生了改變
## 1. 舊約與摩西的律法終結了
> rim 7:6 :: !但我們既然在捆我們的律法上死了 :: !叫我們服事主 :: !要按著心靈的新樣，不按著儀文的舊樣
> gal 3:21-25 :: !這樣，律法是與上帝的應許反對嗎 :: !律法是我們訓蒙的師傅，引我們到基督那裏 :: !但這因信得救的理既然來到，我們從此就不在師傅的手下了
> ef 2:14-16 :: !拆毀了中間隔斷的牆 :: !而且以自己的身體廢掉冤仇 :: !便藉這十字架使兩下歸爲一體
基督訂立新約，以此終結舊約和摩西的律法（[[rim 7:6]]；[[gal 3:21-25]]；[[ef 2:14-16]]）。描繪上帝的禁令曾是摩西律法的一部分，摩西律法已隨基督的來臨被廢除（詳見[[ru:Библия-Закон-Моисея-отмена|詳見]]）。上帝藉摩西所賜的誡命失去其字面的意義：我們不守安息日的安息（也不殺安息日作工的人），不獻牲畜爲祭，不受割禮，不過猶太的節日，不獻什一奉獻；摩西律法的許多別的命令我們也不遵守。舊約和摩西的律法作爲整體被廢除了，而新約的信徒被召作執事的，不是按儀文的舊樣，而是按心靈的新樣（[[2kor 3:6]]）——即理解上帝各種設立的緣由，領會其意義，遵守誡命的實質。
第二誡的字面意義禁止描繪的只是上帝，而不是他的聖潔僕人（[[ish 25:1]]；[[ish 26:1]]）。
第二誡的實質——不可敬拜假神。
相應地，正教會描繪聖人們，因爲這從來沒有被禁止，反而命令描繪他們（[[ish 25:1]]；[[ish 26:1]]），而義人們在像前叩拜（[[nav 7:6]]；[[ps 5:7]]）。至於描繪上帝，則只在舊約裏被摩西律法所禁止，因爲那時沒有人見過上帝。而既然摩西律法被廢除，那麼描繪上帝的禁令作爲摩西律法的一部分也被廢除了。
## 2. 上帝成爲可見的，取了人性（道成肉身）
> in 1:18 :: !從來沒有人看見上帝 :: !只有在父懷裏的獨生子將他表明出來
> 1in 1:1-2 :: !就是我們所聽見、所看見、親眼看過、親手摸過的
## 3. 天上實體改變了
聖殿作爲地上的建築物，按上帝的定意起初就是天上實體的像：上帝命令先知摩西建造聖殿，不是因爲上帝需要聖殿——上帝不需要它（<a href="https://bibleox.com/zh-Hans/cn-cuv/is/66/#L1">賽 66:1</a>；<a href="https://bibleox.com/zh-Hans/cn-cuv/ps/50/#L13">詩 50:13</a>；<a href="https://bibleox.com/zh-Hans/cn-cuv/is/1/#L11">賽 1:11</a>）。
然而，隨著基督的來臨，發生了改變：
1. **基督——上帝——以看得見的方式在天上登基**（[[ef 1:20-21]]；[[otkr 3:21]]）；
1. **天上出現了人**（除基督本身之外），他們獲准與基督在天上同活（[[otkr 6:9-11]]；[[otkr 14:1,3-5]]；[[evr 12:22-24]]）。
天上實體改變了。先前的已不存在。耶路撒冷的聖殿成了過去的天上實體之像，而不是現在的。因此基督徒從最古老的年代起描繪新的天上實體，把在天空明顯登基的耶穌基督（上帝）的像立在最前面，周圍——描繪他聖潔的僕人們，如今已不只是天使，還有人。
標誌性的事件是基督的祭獻之後耶路撒冷聖殿的損壞：
> mf 27:51-53 :: !殿裏的幔子從上到下裂爲兩半 :: !到耶穌復活以後 :: !進了聖城，向許多人顯現
而在70年代，聖殿被羅馬人完全毀滅，在隨後的一切千百年裏，把位置讓給了新的天上實體之像——正教聖殿。

# 關於“聖像——通向屬靈世界的窗戶”的說法
聖像是一種通向屬靈世界的窗戶。這一說法沒有任何神祕的意義，是形象化的表達。它只是說：觀看聖像時，我們彷彿透過窗戶看向看不見的屬靈世界。
屬靈的事物是不可見的，而聖像畫家把不可見的以可見的方式、藉著象徵描繪在聖像上。例如，上帝的恩典住在聖人裏面，以他們頭上的光環描繪；沒有影子意味著住在上帝的光中（這光不是尋常的光，不投下影子）；意義包含在手上所示的姿勢、衣著的顏色、衣服上的特別標記（上帝之母衣服上的三顆星）、周圍的物件、建築、空間之中。觀看這一切，我們認識到關於看不見的屬靈世界的某些事。正因爲如此，有時才使用這樣的說法：聖像彷彿是通向屬靈世界的窗戶（詳見<a href="https://monastery.ru/propovedi/okno-v-dukhovnyy-mir/" lang="ru">俄語</a>）。
爲什麼這需要特別說明？因爲經常不得不遇到：反對正教會的人爲了編造自己的指控，乾脆憑空捏造指控，灌輸給自己的追隨者，在他們心裏培植對正教會的仇恨。例如，爲把正教徒描繪成可憎的巫師，教會的反對者捏造說：正教徒彷彿經由聖像與上帝建立聯繫，如同經由某種能量門戶，因此需要聖像來與上帝相交。這一切純屬虛構。
正教會召呼信徒隨處祈禱，無論有沒有聖像。聖像只是幫助教育和祈禱的輔助手段。祈禱時，聖像幫助集中思想：不渙散、不分心。聖像也是表達對像中所描繪之位格的敬意的手段。各種物件，包括聖像，可以成爲上帝向人賜下自己恩典的途徑——詳見下一節。

# 正教會關於敬禮聖像的教訓
## 367位聖教父關於敬禮聖像的信經——第七次大公會議，尼西亞（787年）
“我們完整地保守教會的一切傳統，無論是書面的還是非書面的。其中一個傳統命令製作聖像彩繪；因爲它與福音宣講的歷史相合，證實上帝的道真實地、而非虛幻地成了肉身，並且對我們有益：因爲彼此互相說明的事物，無疑也彼此互相證實。我們循著王道、追隨我們聖教父的聖訓和公教會的聖傳行進——因爲我們知道，聖靈住在她裏面——以一切的謹慎和明察確定：可敬的聖像應被陳設（供敬禮），如同生命給予者的十字架之像一樣，無論它們由顏色、或由（馬賽克）小塊、或由任何別的材料製成，只要是以合宜的方式製成；無論它們在上帝的聖堂裏、在神聖的器皿和衣袍上、在牆壁和木板上，或在家裏和路旁；無論這是我們的主上帝救主耶穌基督的像，或我們至潔的聖母、上帝之母的像，或可敬的天使及一切聖人和義人的像。——藉聖像他們越常被我們默觀，觀看這些像的人就越被激勵記念原型，對他們獲得更多的愛，並受到更多的激勵向他們獻上親吻、敬意和叩拜；但這絕不是那按我們的信仰只歸於上帝本性的真正事奉。他們被激勵向聖像獻香、爲它們點燈，如同爲主基督之像、爲聖天使們那樣，如同古時按虔誠的心意習慣所行的那樣：因爲向聖像所獻的敬意歸於它的原型；敬拜聖像的人，敬拜的是像中所描繪者的位格。這樣的教導保存在我們的聖教父們那裏，即在公教會的傳統中，在其中福音代代相傳。”
（[俄文](https://azbyka.ru/otechnik/7_Vselenskij_Sobor)第七次大公會議，決議7）
## 君士坦丁堡牧首耶利米（1576年）
“至於第二十一篇——也是論及敬禮聖人、並說紀念聖徒有益於堅固我們的信仰——的最後一章，如果我們想到他們如何藉信心領受了上帝的恩典和幫助，我們說：呼求主要地只與上帝一位相宜，並且首先和本然地歸於他；而對聖人們所行的呼求，不是在本然的意義上，彷彿偶然地、按恩典而歸於他們。因爲聽那些呼求他們的，不是彼得或保羅，而是他們所具有的恩典——照主的話：‘我就常與你們同在，直到世界的末了’（太 28:20）。
神聖的使徒保羅寫信給羅馬人，論呼求上帝說：‘人未曾信他，怎能求他呢？’（羅 10:14）——由此表明：只應當呼求我們所信的那獨一者，即上帝。而我們把呼求本然地歸於獨一的上帝，由我們在神聖的奧蹟中呼求‘我們在天上的父’等，可以看見。在另一處：‘萬軍之主啊，求你與我們同在；除你以外，我們沒有別的患難中的幫助者。’又說：‘除你以外，我們沒有認識別的上帝。’我們使一切聖徒作中保，而首先是主之母，與她一起的還有天使和聖人的團契；我們以聖殿、奉獻、呼求、神聖的聖像相對地（而非事奉地）尊敬他們。因爲我們知道，事奉只應首先獻給獨一的上帝，除他以外不應承認別人爲上帝，不可敬拜‘別神’（詩 80:10）。我們寧可自己不願成爲聖人，也不願因相對的敬禮而陷入把聖人們神化。斷乎不可：因爲不相對地敬拜聖像，是不虔的、與基督的教會和她的兒女相違的，因爲對它們的尊敬歸於原型，如瓦西里所說：我們承認一切聖徒都是我們的中保和代求者，並且說，不但在今世，且在未來的世代裏都會有某種代求：因爲天使和聖人們將爲某些人懇求，而世界的主母也不少於他們；但絕不是爲一切人，也絕不爲人任何死在罪中的——斷然不；因爲上帝對這樣的人完全關閉了自己的憐憫，爲此他啟示了以下的事：‘他們中間雖有挪亞、但以理、約伯，也不能因他們的義救自己的兒女’（結 14:14,18）。只有爲那些——他們的懇求易於蒙垂聽的——人，即以悔改先於自己生命之終、卻還未能洗淨罪之污穢的人，教會才向上帝懇求；並且只是在審判還在進行的時候。這景象結束後，當每個人被帶到指定的刑罰之地，代求就不可能，也就沒有代求了。這代求如今也在教會中宣告：我們向聖徒們呼求，也向我們的主母，向聖天使們呼求。向我們的主母——如此：‘至聖聖母上帝之母，爲我們罪人祈禱’；向聖天使們如此：‘天上諸品聖天使總領天使們，爲我們罪人祈禱’——同樣向主的先驅施洗者先知、向光榮的使徒、先知、殉道者、修士、牧者們、普世的教師們和其餘一切聖人。我們也求聖婦們的團契爲我們罪人祈禱；我們求上帝，願他按自己的恩典和十字架不可戰勝、不可測度的神聖能力，憐憫我們這些事奉他、居於宣信和懺悔之中、求我們心靈之眼得蒙光照的人，好叫我們不至於在罪中睡著而死亡，叫仇敵不能在我們身上得逞。這樣，藉我們所說的這一切人的代求，我們求上帝憐憫我們，把我們從惡者的網羅中救出。”
（[俄文](https://azbyka.ru/otechnik/Ieremij_II_Konstantinopolskij/Otvety_liuteranam)《答路德宗徒書，第一書》）

# 對批評的回應
## “你們刪去了上帝十誡中的一誡”
你們守**第四**條關於安息日安息的誡命嗎？安息日里你們什麼工都不作嗎？你們把安息日作工的弟兄姊妹殺了嗎？你們爲褻瀆或拜偶像殺人嗎？如果你們不作這些，那是爲什麼？難道你們沒有刪去上帝的誡命？爲什麼忽略了這一點：你們自己不守第四誡，卻要求遵守第二誡？
摩西的律法被廢除了。基督徒跟隨基督。第二誡顯然不禁止像及其敬禮，因爲上帝命令在自己的殿裏製作像，命令敬重聖殿，而先知們在帶像的聖物前叩拜。誡命禁止的是描繪上帝，以及禁止拜偶像（敬禮並事奉假神）。
## “你們向聖像獻香，如以色列人向尼忽士但獻香”
以色列人的錯誤不在於獻香（獻香是上帝自己設立的），而在於他們虛構了一個假神，稱它爲尼忽士但，並且不再事奉上帝，而是事奉他們所虛構的尼忽士但——顯然是把物件本身當作神明，以色列人中一向如此（詳見[[ru:языческая-вера-в-идола#HH-Язычники-израильтяне-считали-богом-само-изделие-а-также-стихии|詳見]]）。被虛構的不只是名字，還有討尼忽士但喜悅的方式，隨之而來的是它的虛構意志（誡命）。這就是拜偶像，即事奉假神。它使人離開上帝和按他旨意的生活，把人引向按尼忽士但（其作者）意志的生活。
正教徒描繪的是真上帝，稱他的本名，遵守他的誡命，不把物件（聖像）當作神；他們叩拜和獻香不是向聖像，而是向上帝。這不是拜偶像，因爲這裏連假神都沒有，也沒有對假神的事奉——不像尼忽士但的僕役們那樣。
## “上帝說了描繪，但沒有說敬禮”
不是這樣。在聖經裏可以看到：上帝既命令製作像，也命令敬禮它們。聖經裏有敬禮像的實踐。
上帝命令敬禮聖殿——而聖殿按上帝自己的構想，就是天上實體的像（聖像）。先知大衛向帶像的聖殿叩拜；先知約書亞向帶像的約櫃叩拜。這樣，敬禮像是上帝命令的，先知們也敬禮了帶像的聖物，在它們面前叩拜。毫無疑問，先知們把這敬禮歸於上帝：就是說，敬禮像，就是敬禮原型。正教基督徒所作的正是同樣的事。
## “以防萬一，還是把聖像撤掉吧”
聽了我們的解釋之後，反對敬禮聖像的人常會同意我們的聖像敬禮是允許的；但他們說，不是我們所有人都足夠好地認識教會的教訓，仍有人把聖像當偶像對待；所以——他們說——最好把聖像撤掉，以免絆倒。
我們不同意，因爲聖像是需要的，而對它們的錯誤態度應當藉教育、藉解釋正確的信仰來消除。
有些人錯誤地理解聖經；然而這並不迫使我們爲了避免絆倒而拒絕聖經。這隻會使我們必須進行教育、正確地解釋聖經的話語。

# 結論
這樣，我們認爲，那些把敬禮聖像與敬拜假神（偶像）混爲一談的人是錯誤的；指控正教徒拜偶像，是對信徒的不公正的指控，是對正教信仰的歪曲觀念。
聖像只是關於上帝、人、事件的正確的解釋和提醒；它既不被當作上帝敬禮，也不被當作代替上帝的東西敬禮。我們對與上帝相關之物表現出基本的敬意：如同人們尊敬國旗，不是爲那特別的布料，而是爲尊敬國家本身；尊敬總統的畫像，不是爲紙張和顏料的質量，而是爲總統本人；尊敬十字架和福音書，不是爲名貴的木料和書的材料，而是因爲上帝在十字架上爲我們的得救被釘，而書裏寫著他救恩的話語。
聖像被召幫助人對上帝、他的母親和他的朋友們表達敬意。聖像可以幫助人在祈禱中集中注意力，把思想引向上帝。
有時，完全不是出於我們的意願，上帝親自藉聖像和其他物件顯明奇蹟和醫治；這自然使我們想到對這物件特別的敬意——但不是代替上帝，而是爲了上帝：如同上帝有一次對先知摩西說到必須敬重聖地那樣：
> ish 3:5 :: !你所站之地是聖地
先知大衛也對聖物心存敬畏，向聖物叩拜：
> ps 99:5 :: !在他腳凳前下拜
而對那些沒有這種敬畏的人，上帝賜下致死的刑罰：
| 反而**自高自大，抵抗上天的大主，命人將他殿宇的器皿給你拿來**，供你和你的大臣並你的妻妾用來飲酒，並且你讚美那些不能看，不能聽，不能知的金、銀、銅、鐵、木、石制的神像，卻不知尊崇那掌握你的氣息，註定你一切命途的天主。**當夜加色丁王貝耳沙匝即爲人所殺。** ||| sb dan 5:23,30
這樣，簡單地說：當敬禮的是假神或指向假神之物時，這就是拜偶像，即敬禮並叩拜假神（偶像）。對這樣的人、物件和像的宗教性敬禮，正教會不教導，並且譴責。
對真上帝的敬禮引向對一切與他相關之物的敬禮。上帝被當作上帝敬禮，而他的朋友們和忠心的僕人們——被當作他的朋友和忠心僕人敬禮，而不是被當作上帝。王被尊敬爲王，而他的近臣——被尊敬爲近臣，而不是王。在這樣的敬禮裏沒有假神。正教會教導的正是這樣的信仰。
