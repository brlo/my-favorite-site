# 七十士譯本（LXX）——是什麼？
**七十士譯本**（拉丁文 Septuaginta——“七十”，簡稱 LXX）——舊約書卷的譯本，於公元前III-II世紀由七十位（72位）猶太釋經者從希伯來文譯成古希臘文。
除這個希臘文本外，還有希伯來文的文本——馬所拉文本。
**馬所拉文本**——舊約聖經的希伯來文本，公元VII-X世紀在其上加上了元音符號。什麼是元音符號？簡單地說，就是詞上面的各種小點和勾勾，它們指出詞中缺失的元音和讀音的特點，使人能正確讀出這個詞。這些符號叫作區別符號。因爲希伯來文本只由輔音字母組成，所以只有知道誦讀傳統（聖傳）的人才能正確誦讀。加上元音符號，是爲了使文本的讀法成爲唯一的。
七十士譯本之所以重要，是因爲它是猶太人自己的文本，而且是在猶太民族拒絕耶穌爲基督、爲上帝**之前**就完成的。也就是說，那時還沒有必要把聖經解釋成讓主耶穌基督在其中越來越沒有位置。另外還要考慮到，任何翻譯都同時是一種解釋。在這裏，七十士譯本是由通曉語言和傳統的人所作的解釋-翻譯：從難以誦讀的希伯來文譯成許多人易懂的希臘文。
# 童女還是少女
福音史家馬太引用以賽亞關於基督由童女而生的預言：
> mf 1:23 :: !必有童女懷孕生子
這裏“童女”在希臘文裏是 παρθένος。
按七十士譯本，基督應當由童女而生：
> is 7:14 :: !必有童女懷孕生子
而按馬所拉文本，基督由未出嫁的少女而生：希伯來文 עַלְמָ֗ה [al-maw']。

# “使瞎眼的得看見”還是“被囚的出監牢”
福音史家路加引用先知以賽亞的預言，按七十士譯本引用：
> lk 4:18-19 :: !瞎眼的得看見
在七十士譯本里，此處有“使瞎眼的得看見”一語（希臘文 τυφλοῖς ἀνάβλεψιν）：
| Πνεῦμα κυρίου ἐπ᾿ ἐμέ, οὗ εἵνεκεν ἔχρισέν με· εὐαγγελίσασθαι πτωχοῖς ἀπέσταλκέν με, ἰάσασθαι τοὺς συντετριμμένους τῇ καρδίᾳ, κηρύξαι αἰχμαλώτοις ἄφεσιν **καὶ τυφλοῖς ἀνάβλεψιν**, καλέσαι ἐνιαυτὸν κυρίου δεκτὸν καὶ ἡμέραν ἀνταποδόσεως, παρακαλέσαι πάντας τοὺς πενθοῦντας ||| gr is 61:1-2

> is 61:1-2 :: !被囚的出監牢

# 手腳被扎了，還是被獅子撕裂？
七十士譯本里有關於基督的預言：
> ps 22:16 :: !他們扎了我的手、我的腳
晚出的馬所拉文本在[[ps 22:16]]（詩 22:16）裏沒有關於扎手扎腳的話，那裏是“獅子”一詞。文本里根本沒有“撕裂”的動詞，而且獅子的動作與手腳有什麼關係也不清楚。
然而，正確的仍然是“扎了”。庫姆蘭古卷 4Q88 證實手腳被扎（詳見[[ru:пророчества-о-Христе|關於基督的預言]]）。
此外，還有一個關於“扎”的預言。它在這裏被引用：
> in 19:37 :: !他們要仰望自己所扎的人
所引的出處：
> zah 12:10 :: !他們所扎的
希伯來原文：“וְהִבִּיטוּ אֵלַי אֵת אֲשֶׁר־**דָּקָרוּ**”（[希伯來文原典](https://bibleox.com/zh-Hans/heb-osm/zah/12/#L10)，亞 12:10）
דָּקָר——扎、刺穿；被刺穿、被扎透。
庫姆蘭卷 4Q80 也證實是“扎”。
