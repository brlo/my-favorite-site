# 罵人話的問題在哪裏
罵人話（攻擊性詞彙）的問題在於：說話的人想顯得、並自以爲是惡的、有攻擊性的、危險的、厲害的。惡的詞彙只是達到這一目的的方式之一。人們還會加上惡的情緒、眼神、手勢、衣著、紋身、習慣和其他一切自我表達的方式。但讓我們回到話語本身。
話語由聲音構成。聲音的組合本身沒有任何意義：它既不壞也不好。比如說，我們造一個詞「阿木薩達爾」。「阿木薩達爾」暫時沒有任何意義，因此既不算壞也不算好。但當社會中給某個詞賦予了含義，人就會根據場合、根據他在這種場合想成爲什麼樣的人，來選擇帶有不同含義的詞。當人想顯得有禮貌、有教養時，他使用有禮貌的詞彙，即那些帶有令人愉快的含義、表明我們和平的心態、謙卑、殷勤或類似品質的詞。然而，當人想顯得厲害、危險、惡毒或有攻擊性時，他就轉而使用攻擊性的詞彙，即那些帶有攻擊性、粗俗和其他負面含義的詞，這些詞立刻會表明：這樣的人沒有任何教養，也沒有使他剋制惡行的情緒——他想讓周圍的人覺得他是個危險、惡毒、有攻擊性、狂躁、不安分的人，而這裏沒有任何好的東西。
此外，當人習慣於這種惡的狀態時，就會對它產生依賴，如同對吸菸、飲酒的依賴，也如同對任何罪的惡習的依賴。結果，他會採取種種行動使自己進入這種惡的狀態、在內心培養它：甚至獨處時也罵人，聽惡的音樂，用陰鬱的符號填充自己和周圍的空間。也就是說，這一切都是向惡的狀態的運動，是在自己心裏培養惡意的狀態、憤怒的情欲，而主耶穌基督卻教導我們：
> mf 5:22 :: !凡向弟兄動怒的 :: !凡罵弟兄是拉加的 :: !凡罵弟兄是魔利的 ~~ 「拉加」是侮辱人的稱呼。
> mf 5:5 :: !溫柔的人有福了，因爲他們必承受地土
