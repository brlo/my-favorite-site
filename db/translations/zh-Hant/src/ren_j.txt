# 基督復活後天上現實的改變
要確信在基督之前，死去的義人靈魂並未達到與上帝在天上同活的生命，可以把基督之前的天上現實與基督復活之後的天上現實作一比較。
在基督之前，天上的現實曾被指示給先知摩西看——在山上，爲要使先知按所看見的樣式在地上建造聖殿（會幕、聖所）：
> ish 25:8-9,40 :: !又當爲我造聖所 :: !都要照我所指示你的樣式 :: !都要照著在山上指示你的樣式
> evr 9:24 :: !人手所造的聖所 :: !這不過是真聖所的影像
觀察舊約聖殿的[[ru:иерусалимский-храм|構造]]和圖像，我們看到：在基督的祭獻之前，天上只有上帝（不可見地）臨在和聖潔的天使（[[3ts 6:29]]）。
在基督復活和昇天之後，按人性可見的上帝坐在於天上（[[ef 1:20-21]]；[[otkr 3:21]]），天使仍然臨在於那裏（[[otkr 8:3]]；[[otkr 15:6]]），同時義人的靈魂也出現了（[[otkr 6:9-11]]；[[otkr 14:1,3-5]]）。我們在神學家約翰的啟示錄中看到這一新的天上現實。
這樣，在新的天上現實中，除了上帝和天使之外，還出現了義人的靈魂；在基督復活之前，那裏並沒有他們。
## 舊約——聖殿中只有上帝和天使
在基督的祭獻之前，舊約中，上帝在山上把聖殿指示給先知摩西看，吩咐他在地上照所指示的樣式製造一切（[[ish 25:8-9,40]]；[[evr 9:24]]）。最終，摩西建造了聖殿：其中上帝完全不被描繪，而在上帝顯現之處（約櫃的施恩座）周圍，安放著天使的像；同樣，所有的牆壁和幔子上都有天使的圖像。
### 不可見的上帝
在奉上帝之命建造的舊約聖殿中，沒有上帝的像，因爲上帝是不可見的。在最主要的地方隻立著約櫃（櫃子），裏面放著聖物；在櫃蓋上、兩個革魯賓之間，上帝顯現並說話：
> ish 25:22 :: !我要在那裏與你相會，又要從法櫃施恩座上，二基路伯中間
### 聖潔的天使
聖殿到處充滿了天使（革魯賓）的圖像：
> ish 25:18-20 :: !要用金子錘出兩個基路伯來，安在施恩座的兩頭
> 3ts 6:23,27 :: !他用橄欖木作兩個基路伯，各高十肘，安在內殿 :: !他將兩個基路伯安在內殿裏
> 2par 3:14 :: !幔子 :: !在其上繡出基路伯來

## 新約——聖殿中有上帝、天使和義人的靈魂
在上帝之子降生成人並戰勝死亡之後，我們看到另一種天上現實。神學家約翰在啟示錄一書中描述了它。首先，上帝成爲可見的，坐在寶座上。其次，在天上事奉他的不再只有天使，還有衆多聖義者的靈魂。
### 基督
> mk 16:19 :: !坐在上帝的右邊
> ef 1:20-21 :: !叫他在天上坐在自己的右邊
> otkr 3:21 :: !在我寶座上 :: !在我父的寶座上與他同坐
### 聖潔的天使
> otkr 8:3 :: !另有一位天使
> otkr 15:6 :: !那掌管七災的七位天使
### 聖義者的靈魂

# 「你必不將我的靈魂撇在陰間」——不是指大衛
大衛王在聖詠中說的預言（[[ps 16:10]]）——靈魂不被撇在陰間、肉身不見朽壞——不是指大衛，而是指基督。因此，大衛王的**肉身**見了朽壞，**靈魂**則被留在陰間，直到基督下到陰間。
> act 2:27,29,31,34 :: !因你必不將我的靈魂撇在陰間 :: !弟兄們，先祖大衛的事，我可以明明地對你們說，他死了，也葬埋了 :: !講論基督復活說 :: !他的靈魂不撇在陰間；他的肉身也不見朽壞 :: !大衛並沒有升到天上

> 1pet 4:5-6 :: !就是死人也曾有福音傳給他們
