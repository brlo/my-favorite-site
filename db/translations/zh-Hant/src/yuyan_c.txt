# 啟示錄中各教會的評價
可以見到教會反對者的一種嘗試：引用神學家約翰啟示錄第2-3章的內容（[[otkr 2:1]]），論證教會已離棄真信仰。在其中，主耶穌基督向七個教會說話，指出他們的長處與缺點。其實，仔細看經文，恰恰相反：教會持守著基督的信仰；即使個別教會受到指摘，也是因他們的**行爲**。
## 1. 以弗所教會
✅ 因行爲受稱讚（遠離淫亂、指摘假使徒、恨惡尼哥拉一黨人的行爲、忍耐、爲主勞苦）。
> otkr 2:2-3,6 :: !我知道你的行爲、勞碌、忍耐 :: !你也曾試驗那自稱爲使徒卻不是使徒的 :: !你也能忍耐，曾爲我的名勞苦，並不乏倦 :: !你恨惡尼哥拉一黨人的行爲
❌ 受指摘，因爲他離棄了起初的愛心；並蒙召回到它，行「起初所行的**事**」。
> otkr 2:4-5 :: !你把起初的愛心離棄了 :: !並要悔改，行起初所行的事
## 2. 士每拿教會
✅ 因行爲受稱讚（忍耐患難、貧窮和毀謗）。蒙召不要懼怕將要受的逼迫。應許了生命的冠冕。完全未受指摘。
> otkr 2:9-10 :: !我知道你的患難、你的貧窮 :: !你將要受的苦你不用怕 :: !你務要至死忠心，我就賜給你那生命的冠冕
## 3. 別迦摩教會
✅ 因行爲受稱讚（在逼迫的威脅下沒有棄絕基督的信仰）。
> otkr 2:13 :: !你還堅守我的名，沒有棄絕我的道
❌ 受指摘，因爲他**沒有趕出**吃祭偶像之物、行姦淫之事的尼哥拉一黨人。同時，別迦摩教會並沒有棄絕基督的信仰：「沒有棄絕我的**道**」。
> otkr 2:14-15 :: !有人服從了巴蘭的教訓 :: !叫他們吃祭偶像之物，行姦淫的事 :: !你那裏也有人照樣服從了尼哥拉一黨人的教訓
## 4. 推雅推喇教會
✅ 因**信心**和行爲（愛心、勤勉、忍耐）受稱讚。
> otkr 2:19 :: !我知道你的行爲、愛心、信心、勤勞、忍耐
❌ 受指摘，因爲他也沒有趕出「耶洗別」，容讓她引誘信徒行姦淫、吃祭偶像之物（如同別迦摩的尼哥拉一黨人）。受刑罰的只有那些與耶洗別行淫的人。其餘的人則受稱讚：「但你們已經有的，總要持守，直等到我來」。
> otkr 2:20-25 :: !就是你容讓那自稱是先知的婦人耶洗別教導我的僕人，引誘他們行姦淫，吃祭偶像之物 :: !那些與她行淫的人，若不悔改所行的，我也要叫他們同受大患難 :: !但你們已經有的，總要持守，直等到我來
## 5. 撒狄教會
✅ 只有幾個沒有玷污自己衣服的人受稱讚。
> otkr 3:4 :: !然而在撒狄你還有幾名是未曾污穢自己衣服的
❌ 因其餘的人，他被比作死人，因爲行爲不完全：「因我見你的**行爲**在我上帝面前沒有一樣是完全的」。受指摘，因爲他不儆醒。
> otkr 3:1-2 :: !按名你是活的，其實是死的 :: !你要儆醒 :: !因我見你的行爲在我上帝面前沒有一樣是完全的
## 6. 非拉鐵非教會
✅ 因行爲受稱讚（雖然力量略小，但沒有棄絕基督），因持守基督忍耐的道。蒙召：「你要持守你所有的」。完全未受指摘。
> otkr 3:8,10-11 :: !我知道你的行爲，你略有一點力量 :: !沒有棄絕我的名 :: !你既遵守我忍耐的道 :: !我必快來，你要持守你所有的
## 7. 老底嘉教會
不受稱讚。
❌ 因行爲受指摘：「我知道你的**行爲**，你也不冷也不熱」。蒙召向基督買金子、衣服和眼藥，並要發熱心、悔改：「所以你要發熱心，也要悔改」。
> otkr 3:15-19 :: !我知道你的行爲，你也不冷也不熱 :: !所以我必從我口中把你吐出去 :: !我勸你向我買火煉的金子 :: !又買白衣穿上 :: !又買眼藥擦你的眼睛 :: !所以你要發熱心，也要悔改
# 總結
這樣：
- 🟢 士每拿教會（2）和非拉鐵非教會（6）完全未受指摘。
- 🟡 別迦摩教會（3）和推雅推喇教會（4）持守了信仰，但受指摘沒有趕出引誘人的（尼哥拉一黨人和耶洗別）。受刑罰的正是那些屬於虛假教導的人。而教會本身則受稱讚：「沒有棄絕我的**道**」（別迦摩）、「但你們已經有的，總要持守，直等到我來」（推雅推喇）。
- 🟠 以弗所教會（1）因敬虔和保守信仰受稱讚，因離棄起初的愛心受指摘，蒙召行起初所行的**事**。
- 🟠 撒狄教會（5）因幾個保守了衣服的人受稱讚，因**行爲**的不完全受指摘。
- 🔴 老底嘉教會（7）完全不受稱讚，因**行爲**上的不冷不熱受指摘，蒙召悔改。
- 因爲信仰，沒有人受指摘，但幾乎所有的都因信仰受稱讚（1, 2, 3, 4, 6）。
- 有些教會因一件事上的欠缺受指摘，但因持守信仰受稱讚（3, 4）。
- 另一些教會在行爲上有更嚴重的欠缺，但在其中信仰仍然保守著（1, 5）。
- 最後一個教會因對**行爲**的冷淡（不冷不熱）受指摘（7）。
或許有人以爲「行爲」也包括信仰。然而，那些明確持守了信仰的教會，卻因行爲上的欠缺受指摘（3, 4）——這幾乎不給這種解釋留下餘地。這樣，啟示錄中的教會受指摘不是因爲信仰（作爲教導），而是因爲行爲上的不完全。而有些教會完全未受指摘。
