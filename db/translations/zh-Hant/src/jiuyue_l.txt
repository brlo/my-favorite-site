# 安息日
## 上帝祝聖了安息日
創造世界之後，上帝祝聖了第七日（安息日），但沒有設立誡命：
> gen 2:3 :: !上帝賜福給第七日，定爲聖日 :: !因爲在這日上帝歇了他一切創造的工，就安息了
旁邊有許多上帝賜下其他命令的地方：
> gen 1:28 :: !又對他們說
> gen 1:29 :: !上帝說
> gen 2:16-17 :: !耶和華上帝吩咐他說
然而，關於安息日沒有賜下任何命令。創造諸日之後說到安息的是上帝，而不是人。上帝把人安置在伊甸園中是爲了勞動：
> gen 2:5,8,15 :: !也沒有人耕地 :: !把所造的人安置在那裏 :: !使他修理看守
在那永恆的神聖安息中——上帝如今所處其中（[[gen 2:3]]）——人們將來才能進入。而且並非所有人，只有上帝親自放進去的人：
> evr 4:3; ps 95:11; evr 3:11 :: !但我們已經相信的人得以進入那安息 :: !他們斷不可進入我的安息
## 安息日停止勞作之誡命的出現
安息日停止勞作的誡命，是上帝在先知摩西的時代、與以色列民立約的時候首次設立的：
> ish 20:8-10 :: !當記念安息日，守爲聖日 :: !六日要勞碌作你一切的工 :: !但第七日 :: !無論何工都不可作 ~~ 並見 [[vtor 5:12-15]]；[[lev 19:3]]；[[lev 19:30]]。
## 設立安息日誡命的原因
誡命的原因就在誡命的話語之後說明了。這一原因：以色列民出埃及的出走。
> vtor 5:14-15 :: !你也要記念你在埃及地作過奴僕 :: !將你從那裏領出來 :: !因此，耶和華你的上帝吩咐你守安息日
賜給他們「安息日」，即賜給他們先前沒有的東西：
> iez 20:10-12 :: !我就使他們出埃及地 :: !將我的律例賜給他們 :: !又將我的安息日賜給他們
> vtor 5:2-3 :: !耶和華我們的上帝在何烈山與我們立約 :: !乃是與我們今日在這裏存活之人立的
也有另一種解釋，指出上帝對第七日的祝聖：
> ish 20:11; gen 2:3 :: !因爲六日之內，耶和華造天、地、海和其中的萬物 :: !所以耶和華賜福與安息日，定爲聖日
然而，這一解釋雖指出了聯繫，但這裏說明的是祝聖安息日的原因：「所以耶和華賜福」（[[ish 20:11]]），而不是誡命的原因。而在另一節經文中，則最明確地給出了誡命本身的原因：「你也要記念你在埃及地作過奴僕……將你從那裏領出來……因此，耶和華你的上帝吩咐你守安息日」（[[vtor 5:14-15]]）。
這樣，安息日的停止勞作是因以色列民脫離埃及奴役的出走而設立的，雖然也指出了它與神聖安息的聯繫。
## 誡命之律已被廢除
律法是在基督來臨之前、爲一段時期而賜下的：
> gal 3:19 :: !原是爲過犯添上的 :: !等候那蒙應許的子孫來到
誡命之律已被基督的教導廢除：
> ef 2:14-16 :: !拆毀了中間隔斷的牆 :: !以自己的身體廢掉冤仇 :: !就是那記在律法上的規條
基督徒已從律法中釋放：
> rim 7:6 :: !現今就脫離了律法 :: !要按著心靈的新樣，不按著儀文的舊樣
摩西律法廢除的詳細解釋：[[ru:Библия-Закон-Моисея-отмена|摩西律法的廢除]]。
## 基督保護使徒免受干犯安息日的指控
法利賽人指摘主和使徒們干犯安息日。基督稱使徒們無罪：
> mf 12:2,7 :: !看哪，你的門徒作安息日不可作的事了 :: !就不將無罪的當作有罪的了
## 使徒禁止因不守安息日而論斷基督徒
> kol 2:16 :: !所以不拘在飲食上，或節期、月朔、安息日，都不可讓人論斷你們
# 主日
## 主顯現的日子
1. 主耶穌基督在七日的第一日——主日——復活了，並向沒有多馬的門徒們顯現（[[in 20:19]]）。
1. 在主日，他向持香的婦女們顯現（[[mf 28:1,9]]）、向抹大拉的馬利亞顯現（[[mk 16:9]]）、向使徒彼得顯現（[[lk 24:34]]）、向使徒革流巴和路加顯現（[[lk 24:13-32]]）。
1. 爲多馬的緣故，救主恰好過了一週再次顯現，又是在主日（[[in 20:26]]）。
## 聚會與舉行聖餐禮的日子
使徒們在特羅亞住了七天，而在七天之中，他們不是在安息日、而是在主日聚會舉行事奉聖禮並擘餅：
> act 20:6-11 :: !在那裏住了七天 ~~ 在特羅亞住了整整七天。 :: !七日的第一日，我們聚會擘餅的時候 ~~ 有七天，但擘餅聚會正是在主日。 :: !我們聚會的那座樓上，有好些燈燭 ~~ 隆重的聚會。
使徒請求在主日（聚會之日）抽出錢來，幫助有缺乏的人：
> 1kor 16:2 :: !每逢七日的第一日，各人要照自己的進項抽出來留著
# 批評
某些脫離教會的團體（主要是基督復臨安息日會教派），違揹誡命（[[kol 2:16]]），不但指摘教會不守安息日，還指摘教會更隆重地慶祝主日，說主日不應當慶祝。
在東正教會中，人在一生所有的日子都蒙召行善，而在特別的日子（安息日，尤其是主日），不但以個人的善行、更以**共同的事業**（源自希臘文 λειτουργία——事奉聖禮）來慶祝，也就是以共同的聚會舉行事奉聖禮來慶祝主日。其餘的日子也舉行事奉聖禮，但在安息日、尤其是在主日舉行特別的、更隆重的事奉聖禮。
對基督徒來說，最重要的事件是基督的復活——主耶穌基督從死人中復活。這一日被稱爲諸慶節之慶節、諸凱旋之凱旋，因爲：
> 1kor 15:14,17 :: !若基督沒有復活，我們所傳的便是枉然 :: !你們的信便是徒然，你們仍在罪裏
如上所示，使徒們正是在主日舉行事奉聖禮。這一日成了與復活之主相會的喜樂之日。最早的基督徒也是如此：[[ru:Евхаристия_в_воскресенье|主日的聖餐禮]]
還有人指摘君士坦丁皇帝（四世紀），說他似乎把休息日從安息日改到了主日（[[act 20:6-11]]）。然而，君士坦丁皇帝設立了每週第一個休息日——主日，沒有對安息日作任何指示（[[ru:Воскресенье_выходной_Указ_императора_Константина|詳見]]）。在這一敕令之前，羅馬帝國沒有普遍的每週休息日。
這樣，這種批評至少可以說是不成立的。
