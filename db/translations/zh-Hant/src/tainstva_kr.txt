# 洗禮聖奧祕的實質
**洗禮**（“重生”、“屬靈的誕生”）——在教會中舉行的聖奧祕，人在其中：
1. 洗淨罪（[[act 2:38]]；[[1kor 6:11]]；[[act 22:16]]）；
2. 屬靈地重生（[[in 3:3,5-6]]；[[1kor 15:44]]；[[1kor 15:47-50]]；[[1kor 15:53]]；[[gal 3:27]]）；
3. 領受救人的恩典（[[2kor 6:1]]）；
4. 加入教會（[[1kor 12:13]]）。

> act 22:16 :: !起來，求告他的名受洗，洗去你的罪
> 1kor 6:11 :: !已經洗淨、成聖、稱義了
> act 2:38 :: !叫你們的罪得赦

# 嬰兒洗禮
## 人人都必須屬靈地重生
一切人都需要屬靈的重生，爲與上帝同享永恆的生命：
> 1kor 15:40 :: !有天上的形體，也有地上的形體
> 1kor 15:44 :: !所種的是血氣的身體，復活的是靈性的身體
> in 3:6 :: !從肉身生的就是肉身 :: !從靈生的就是靈
亞當朽壞身體的繼承者不能進上帝的國：
> 1kor 15:47-50 :: !頭一個人是出於地 :: !血肉之體不能承受上帝的國 :: !必朽壞的不能承受不朽壞的
因此，凡從亞當承受必朽性的人都要死；而在洗禮中與基督聯合的人都要復活。
> 1kor 15:22 :: !在亞當裏衆人都死了 :: !照樣，在基督裏衆人也都要復活
> rim 6:3,5 :: !我們這受洗歸入基督耶穌的人，是受洗歸入他的死 :: !也要在他復活的形狀上與他聯合
一切必死的都須穿上不朽壞的：
> 1kor 15:53 :: !這必朽壞的總要變成不朽壞的，這必死的總要變成不死的
就是說，在洗禮中穿上基督：
> gal 3:27 :: !受洗歸入基督的，都是披戴基督了
## 人人都必須洗去原罪
還有，一切人都從始祖繼承了罪性。就是說，[[ru:все-люди-грешны|嬰兒也有]]：
> iov 14:4 :: !誰能使潔淨之物出於污穢之中呢
> ps 51:5 :: !我是在罪孽裏生的
> rim 5:12 :: !罪是從一人入了世界 :: !死就臨到衆人
> rim 5:19 :: !因一人的悖逆，衆人成爲罪人 :: !因一人的順從，衆人也成爲義了
> rim 7:19-24 :: !我所願意的善，我反不作 :: !乃是住在我裏頭的罪作的 :: !但我覺得肢體中另有個律和我心中的律交戰 :: !誰能救我脫離這取死的身體呢
> rim 7:14,22-23 :: !但我是屬乎肉體的，是已經賣給罪了 :: !把我擄去，叫我附從那肢體中犯罪的律
> ef 2:3 :: !本爲可怒之子
## 使徒給整個家庭（全家）施洗
> 1kor 1:16 :: !我也給司提反家施過洗
> act 16:15 :: !她和她一家既領了洗
> act 16:30-33 :: !當信主耶穌，你和你一家都必得救 :: !他和屬乎他的人立時都受了洗
使徒呼召一切人受洗，說應許不但屬於他們（成人），也屬於他們的兒女：
> act 2:38-39 :: !你們各人要悔改 :: !這應許是給你們和你們的兒女
這裏字面地說的正是嬰兒。必須深入上下文，弄清這裏所說的**應許**（應許之事）是什麼。這一章講的是五旬節那天聖靈降在教會聚會上。解釋這事件時，使徒彼得指著藉先知約珥所賜的應許：
> act 2:4,14-17,37-39 :: !他們就都被聖靈充滿 :: !彼得和十一個使徒站起 :: !這正是先知約珥所說的 :: !我要將我的靈澆灌凡有血氣的 :: !衆人聽見這話，覺得扎心 :: !你們各人要悔改 :: !這應許是給你們和你們的兒女
這樣，使徒彼得引用的是先知約珥。我們就到先知約珥自己那裏看這一應許：
> iol 2:1,15-18,28 :: !你們要在錫安吹角 :: !分定禁食的日子，宣告嚴肅會 :: !聚集衆民 :: !聚集孩童和吃奶的 :: !耶和華就爲自己的地發熱心 :: !我要將我的靈澆灌凡有血氣的
這就是那應許。全民族——從老人到吃奶的嬰孩——都被召參加這嚴肅的聚會。上帝應許把聖靈澆灌在聚集的全民族身上，如經所記：澆灌凡有血氣的。這樣，當使徒說應許不但屬於聽的人、也屬於他們的兒女和一切遠方的人時，按上下文，他所說的兒女，字面地指的就是嬰孩。
## 上帝的恩典按他人的信心運作
嬰兒受洗的時刻，可以有代父母信心的運作。聖經裏有許多情形：上帝的恩典因別人的信心而在一些人身上運作。
### 救主因父母的信心醫治兒女
上帝按父母的信心在兒女身上行事：
- 要求的是父親的信心，而從鬼附中得醫治的是兒子（[[mk 9:17-24]]）；
- 要求的是父親的信心，復活的是睚魯被醫治的女兒（[[lk 8:41-42,49-55]]）；
- 相信的是母親，從鬼附中得醫治的是迦南婦人的女兒（[[mf 15:22-28]]）；
- 相信的是父親，得醫治的是大臣的兒子（[[in 4:46-50]]）。
### 因親人信心而醫治（恩典運作）的情形
- 相信的是百夫長，得醫治的是他的僕人（[[mf 8:10,13]]）
- 相信的是朋友們，得醫治的是癱瘓的同伴（[[mk 2:5]]）。這裏重要的是：因別人的信心，這人的**罪也得了赦免**。

> 1kor 10:1-4 :: !我們的祖宗從前都在雲下，都從海中經過 :: !都在雲裏、海里受洗歸了摩西 :: !都喫了一樣的靈食 :: !所喝的，是出於隨著他們的靈磐石
這些預像有直接的意義：

# 血的洗禮
血的洗禮——爲基督殉道的死。這裏指的不是聖戰或神風式的行爲。殉道者想活下去，不威脅任何人的生命；只是因爲他對基督的信仰，人奪去他的生命。這樣的人不經水的洗禮，不但達到得救，還在天上與基督同享特別的榮耀。

# 對異議的回應
## 在關於從水和聖靈而生的話裏（[[in 3:5]]），水是指聖靈嗎？
新教徒把救主關於得救必須從水和聖靈而生的話作寓意解釋，說水指的是聖靈。他們把接下去的兩節聯繫起來：
> in 3:5 :: !從水和聖靈生的
> in 7:38-39 :: !從他腹中要流出活水的江河來 :: !耶穌這話是指著信他之人要受聖靈說的
但如果把水理解爲聖靈，那就成了同義反復（同一事物多餘的重複）。那樣基督說的就是：要從聖靈和聖靈生。如果在這段話裏直接說聖靈是合適的，那爲什麼還要用寓意呢？而且即使按寓意，也得說“從水的聖靈”或“從水**或**聖靈”（這纔等值），而按經文，卻是要從聖靈**和**別的什麼生——也就是從水。
此外，我們很好知道——包括從聖經——使徒們是真實地在水裏施行重生的。就是說，洗禮中的水從來都是真實的，而“從腹中流出江河”（字面地）卻從來沒有人流過。
所以，既然使徒們是在水裏施洗、洗禮是由聖靈成就的，我們就把救主關於從水和聖靈而生的話理解爲使徒們所行的那樣：從水和聖靈——這一理解客觀地繫於使徒在水裏施洗的實踐。古代的教會從不把洗禮與水分開、理解爲純然頭腦中的東西，而是理解爲奉父、子、聖靈之名在祝聖的水中三次浸沒。
## “受洗必須悔改，可嬰兒不能悔改，所以也不能受洗？”
一些與教會分離的團體指責教會允許嬰兒受洗。他們引用使徒勸勉聽的人先悔改、後受洗的經文：
> act 2:38-39 :: !你們各人要悔改 :: !這應許是給你們和你們的兒女
悔改的要求是對成人的；嬰兒沒有個人的罪，因此難以把悔改的要求加在他們身上。就是說，嬰兒需要受洗，但因爲他們沒有個人的罪，也就不必爲他們所沒有的東西悔改。
總的來說，這指責聽起來很奇怪。由它得出的是：嬰兒爲了穿上基督（受洗——[[gal 3:27]]），必須先犯罪；而他們還沒有犯罪，就不能悔改，那麼也就永遠不能受洗。這成了某種荒謬：爲獲得與基督聯合的可能，必須先得罪基督。當然，這是大錯。受洗是人人需要的，悔改只是犯了罪的人需要的。
先知約翰的悔改的洗禮雖然不同於基督裏的洗禮（[[act 19:4]]），但可以檢驗這些推理是否正確。先知約翰施悔改的洗，但當基督來到他那裏時，他沒有悔改就立刻下到水裏。基督沒有罪，因此他沒有悔改就受了悔改的洗。嬰兒也是這樣。基督不需要先獲得罪，才能獲得受悔改之洗的可能。嬰兒也是這樣。受洗是人人被召的，悔改的只是有可悔之事的人。
## “受洗需要信心，可嬰兒不能宣認信仰，所以也不能受洗？”
與教會分離的團體還引用另一節經文，其中主說要信而受洗：
> mk 16:16 :: !信而受洗的，必然得救 :: !不信的，必被定罪
這樣，得救的必要條件之一是獲得**信心**、領受**洗禮**。不履行這些條件，人不能得救。然而，難以把信心的要求加在嬰兒身上；所以他們按代父母的信心受洗——對此也有聖經的依據（詳見[[ru:крещение#HH-Действие-благодати-Божьей-по-вере-других-людей|上帝的恩典按他人的信心運作]]）。
還要特別注意接下去的話：不信的必被定罪。那麼是不是說嬰兒也要被定罪，因爲他們不能信呢？
> mk 16:16 :: !不信的，必被定罪
問題在於：這一節裏信心的要求只對成人。而洗禮本身，如救主在別處所說（[[in 3:3,5-6]]），是人人需要的，包括嬰兒。嬰兒將帶著洗禮中所穿的基督（[[gal 3:27]]）長大——按代父母的信心（詳見[[ru:крещение#HH-Действие-благодати-Божьей-по-вере-других-людей|上帝的恩典按他人的信心運作]]）。隨著嬰兒能力的增長，代父母使他在信心裏堅固。如果不幸發生，嬰兒因悲慘的情形死去，那麼，作爲受過洗的，他達到天國、與基督同享永生。
至於救主話語的次序（信而受洗），也有相反的次序：
> mk 1:4 :: !傳悔改的洗禮
那麼就請他們也承認這裏是先施行悔改的洗、然後纔有宣講。
## “可是基督只在三十歲受洗？”
先知施洗約翰的洗禮不是基督裏的洗禮。已經受過約翰之洗的人，使徒保羅重新給他們施基督的洗：
> act 19:2-6 :: !你們受的是什麼洗呢 :: !是約翰的洗 :: !約翰所行的是悔改的洗 :: !他們聽見這話，就奉主耶穌的名受洗 :: !保羅按手在他們頭上，聖靈便降在他們身上
此外，從那些在這事上不效法基督的人——不在三十歲受洗、雖然不在嬰兒期、但也不等到三十歲而是在八到十二歲給自己的孩子施洗——聽到這樣的指責，是很奇怪的。如果教會的指控者認爲受洗的年齡應當效法基督（他受約翰的洗），那麼要領洗，他看來也得等到三十歲。然而這不對，因爲先知約翰悔改的洗不是基督裏的洗（[[act 19:2-6]]）。基督等候三十歲不是爲了受洗，而是爲了出來任職事奉（[[chis 4:3]]）、出來宣講、顯明自己的榮耀。他的宣講以先知約翰的見證開始——約翰指著來到他那裏受洗的耶穌，指明他就是基督。約翰是先知。他什麼時候指明救主來臨之預言的應驗？什麼時候指著救主？當救主預備好出來任職的時候——三十歲（[[chis 4:3]]）。
## “可是那悔改的強盜沒來得及受洗，卻得救了？”
那是在主還沒有設立洗禮聖奧祕的時候。信了並悔改的強盜，不經水的洗禮得了救——如同舊約的義人在新約教會建立之前的得救；這教會要在基督被釘之後52天（2+40+10）纔出現。
**洗禮——從水和聖靈而生**
> in 3:5 :: !人若不是從水和聖靈生的 :: !就不能進上帝的國
**基督將用聖靈施洗**
> lk 3:16; mf 3:11; mk 1:8 :: !他要用聖靈與火給你們施洗
**基督不去，聖靈不來**
> in 16:7; in 14:16; in 14:26; in 7:38-39 :: !我若不去，保惠師就不到你們這裏來
> in 15:26 :: !從父那裏差保惠師來 :: !就要爲我作見證
> lk 24:49 :: !你們要在城裏等候，直到你們領受從上頭來的能力
**基督復活之後還未升到父那裏去**
> in 20:17 :: !我還沒有升上去見我的父
**所應許的聖靈的洗禮，在基督復活50天后首次成就**
> act 1:1-5 :: !四十天之久向他們顯現 :: !約翰是用水施洗 :: !你們要受聖靈的洗
> act 1:1-5,8-9 :: !四十天之久向他們顯現 :: !約翰是用水施洗 :: !你們要受聖靈的洗 :: !但聖靈降臨在你們身上，你們就必得著能力 :: !有一朵雲彩把他接去
> act 2:1,3-4 :: !五旬節到了 :: !又有舌頭如火焰顯現出來，分開落在他們各人頭上 :: !他們就都被聖靈充滿
不過，在基督復活的當天也講到差遣聖靈，但沒有講到洗禮。這是司祭等次的設立，同時賜下赦罪和不赦罪的權柄：
> in 20:1,19,22 :: <<七日的第一日清早 :: !耶穌來站在當中 :: !就向他們吹一口氣，說
## “不要禁止小孩子到基督這裏來”
與教會分離的團體指責教會：教會關於不經洗禮不能得救的教訓（[[in 3:3,5-6]]）彷彿妨礙嬰兒得救。教會彷彿不讓嬰兒到基督那裏去。他們引用下面這節經文：
> lk 18:15-16 :: !有人抱著自己的嬰孩來見耶穌 :: !讓小孩子到我這裏來，不要禁止他們
實際上，這節經文所責備的，恰恰是嬰兒洗禮的反對者。
聖經的這一情形裏字面地發生了什麼？
1. **母親們把嬰孩帶到基督那裏**，求主祝福他們；
2. **門徒攔在路上**，禁止他們把嬰孩帶到基督那裏；
3. **主爲母親們開了路**，指示門徒不要攔阻把嬰孩帶到他那裏，並祝福了嬰孩（[[mk 10:16]]）。
教會的反對者在做什麼？
1. 母親們願意讓嬰孩從出生就歸向基督（這是我們親自從脫離教派的母親們那裏知道的）；
2. 教會的反對者攔在母親們的路上，字面地禁止她們給孩子施洗——聖經稱洗禮爲穿上基督（[[gal 3:27]]）。
教會在做什麼？
1. 召母親們帶著自己的嬰孩到基督那裏；
2. 當母親們把嬰孩帶來時，教會藉洗禮、聖餐禮和聖物使嬰孩歸向基督，賜給他們祝福。
教會的反對者把一切顛倒了。教會召母親們和嬰孩到基督那裏，他們說這是與基督聯合的障礙；而他們禁止母親們給孩子施洗，倒說是“不阻礙”孩子到基督那裏去。
教會的教訓絲毫不妨礙基督拯救嬰孩——如果嬰孩不經洗禮就能得救的話。而教派禁止給嬰兒施洗，倒是非常妨礙嬰孩的得救——考慮到基督說過，不經洗禮沒有人能進上帝的國（[[in 3:3,5-6]]）。
## “罪的赦免發生在獲得信心的時候，而不是浸在水裏？”
許多新教徒稱水的洗禮只是見證（某種記號），而人的重生和罪的赦免——他們認爲——發生得更早：只要人信了、爲自己的罪向上帝認罪就發生了。然而，我們在聖經裏看到：正是在水的洗禮中人重生、罪被洗淨，正是它對人是救人的。
掃羅（未來的使徒保羅）被基督弄瞎了眼，並且立刻**信了**他；但這沒有使他的罪得赦。掃羅被打發到大馬士革去，爲要藉領受水的洗禮洗去他的罪：
> act 22:8,10-13 :: !主啊，你是誰 :: !主啊，我當作什麼 :: !兄弟掃羅，你可以看見
信了的掃羅需要藉洗禮洗去罪：
> act 22:16 :: !起來，求告他的名受洗，洗去你的罪
另一處直接說，洗禮救人（而不是見證）：
> 1pet 3:21 :: !這水所表明的洗禮，現在藉着耶穌基督復活，也拯救你們
> tit 3:5 :: !藉着重生的洗和聖靈的更新
## “人是因傳講基督的道而屬靈地重生？”
否認上帝在聖奧祕中運作的新教徒，也否認人在洗禮的水中屬靈地重生。否認這一點，他們教導人說，“從水和聖靈”的生（[[in 3:3,5]]）彷彿只在宣講的時刻發生，其餘的一切——隆重的象徵性活動。爲論證這一觀念，他們引用這些經文：
> iak 1:18 :: !他按自己的旨意，用真道生了我們
> 1pet 1:23-25 :: !你們蒙了重生 :: !乃是由於不能壞的種子，是藉着上帝活潑常存的道 :: !所傳給你們的福音就是這道
教會宣講福音有上帝的協助，他在聽道人的靈魂上動工。這宣講可以在人裏面產生轉變，呼召他悔改、指引他生命的道路。上帝的道是喚醒人脫離罪的沉睡、在人裏面激起悔改、生髮信心的手段。然而，這宣講還沒有潔淨人的罪，還不是在重生的水洗中（[[ef 5:25-26]]；[[tit 3:5]]）從水和聖靈而生（[[in 3:3,5]]）。
在別處清楚地說：爲使罪得赦，必須領受在水中舉行的洗禮聖奧祕：
> act 22:16 :: !起來，求告他的名受洗，洗去你的罪
沒有信心和悔改的人不被允許受洗。所以首先他必須聽上帝的道，然後由聽道而來的信心（[[rim 10:17]]），然後纔是從水和聖靈而生、罪的洗淨、以及在洗禮和聖膏中受聖靈的印記。
使徒先宣講上帝的道；當聽衆**覺得扎心**時，他就呼召他們受洗使罪得赦：
> act 2:37-38 :: !衆人聽見這話，覺得扎心 :: !我們當怎樣行 :: !你們各人要悔改 :: !奉耶穌基督的名受洗 :: !叫你們的罪得赦
## “洗禮不在乎除掉肉體的污穢，只求……”
> 1pet 3:21 :: !這水所表明的洗禮 :: !只求在上帝面前有無虧的良心
這一處在俄文裏譯得不正確。差別是根本性的：在“許諾”裏沒有任何聖奧祕，不從上帝領受什麼；相反，是人向他許諾。而當人向上帝祈求時，從上帝那邊期待的是行動（聖奧祕）：藉著罪的赦免（從上帝那邊）獲得無虧的、清潔的良心（[[evr 9:14]]），不被先前的罪所累。而如果浸入水裏時如新教徒所想的那樣什麼也不舉行，那還向上帝求什麼呢——如果他在這裏什麼也不賜。
使徒彼得的書信是用希臘文寫的。聖兄弟基里爾和梅福季——通曉斯拉夫語的希臘人——把 ἐπερώτημα 譯作“祈求”（вопрошание），而不是“許諾”：向上帝祈求無虧的良心。
同樣，古代基督徒之一——希臘人、教會的主教神學家格列高利（四世紀）——寫道，這裏說的是上帝的作爲：按祈求賜給人無虧的良心（[俄文](https://azbyka.ru/otechnik/Grigorij_Bogoslov/slova-izd-2007-g/40)《講道集》第40篇·論聖洗禮）。
而且，總的來說，在新約文本中這個詞一次也沒有被譯作“許諾”，總是譯作“祈求、問”。
- ἐπερωτῆσαι——問（太 22:46）
- ἐπερωτῶσιν——問（可 7:5）
- ἐπερωτῆσαι——問（可 9:32）
- Ἐπερωτήσω——我要問（可 11:29）
- ἐπερωτῆσαι——問（可 12:34）
- ἐπερωτῶντα——問的（路 2:46）
- Ἐπερωτῶ——我要問（路 6:9）
- Ἐπερωτηθεὶς——被問（路 17:20）
- ἐπερωτᾶν——問（路 20:40）
- ἐπερωτήσατε——你們問（約 9:23）
- ἐπερωτήσας——問了（徒 23:34）
- ἐπερωτῶσιν——問過的（羅 10:20）
- ἐπερωτάτωσαν——問（林前 14:35）
- ἐπερώτημα——祈求（教會斯拉夫語譯法）（彼前 3:21）
就是說，不是人給上帝什麼——如果那是“許諾”的話。人只是祈求，而賜下的是上帝（直接寫著：“**洗淨你們的心**”，[[evr 9:14]]）。
使徒指明：洗禮洗去的不是身體上的污穢（不在乎除掉肉體的污穢），而是內在地洗淨罪。就是說，這是聖奧祕——重要的、肉眼看不見的、不能完全領會和說明的事。
這一切都在聖靈對水的運作中發生；所以主耶穌基督說，人從水和聖靈而生，而不只是從聖靈：
> in 3:3,5-6 :: !人若不重生 :: !從水和聖靈生的 :: !從肉身生的就是肉身 :: !從靈生的就是靈
況且，使徒最終說的話是：洗禮——**拯救**：
> 1pet 3:21 :: !這水所表明的洗禮，現在藉着耶穌基督復活，也拯救你們
而新教徒（浸信會）根本不同意這一點。在他們的教導裏，洗禮只是隆重的許諾，是形式，不救人。而使徒說，洗禮正是**拯救**的。
他們認爲，在獲得信心和悔改的時刻罪就得赦免了；而使徒保羅雖然信了，後來卻被吩咐受洗以洗去罪：
> act 22:16 :: !起來，求告他的名受洗，洗去你的罪
這裏也如此說：
> act 2:38 :: !你們各人要悔改，奉耶穌基督的名受洗，叫你們的罪得赦
## “洗淨罪的不是洗禮，而是上帝的道？”
> ef 5:25-26 :: !要用水藉着道把教會洗淨
基督爲教會舍了自己，爲要使她成爲聖潔。怎樣潔淨？——“用水藉着道”，即聖洗禮：在三次浸入水中時，唸誦奉父、子、聖靈之名的話（[[mf 28:19]]）。這裏說的正是這話。而且無論哪一樣（水）、哪一樣（關於父、子和聖靈的話）都不能排除。作別的解釋，就是斷章取義。這裏說的是在**水的洗**中唸誦的道。
## 關於百夫長哥尼流：聖靈不經洗禮賜下嗎？
靈恩派教派的擁護者爲他們關於自己彷彿只憑祈禱就領受聖靈的教訓辯護。他們引用聖靈唯一一次在洗禮之前降臨的情形：
> act 10:44 :: !聖靈降在一切聽道的人身上
這裏講的是百夫長哥尼流，他是外邦人。當時不清楚：能不能給他們施洗，能不能接納外邦人進入教會。
所以上帝賜下特別的啟示，表明外邦人可以進入教會。
1. 上帝差到外邦人哥尼流那裏的不是聖靈，而是天使，叫他去找教會、請使徒來聽，好得救。
2. 使徒彼得三次看見同一個異象：不潔的食物降到他面前，有聲音吩咐他宰了吃；因爲這聲音解釋說：“上帝所潔淨的，你不可當作俗物”（[[act 10:15]]）
3. 當使徒來到並開始宣講時，聖靈降在聽道的外邦人身上。
之後，猶太血統的基督徒對所發生的事驚訝。怎麼這樣——聖靈降在外邦人身上？
> act 10:45 :: !見聖靈的恩賜也澆在外邦人身上，就都希奇
然後一切以外邦人受洗結束——如今他們無疑可以受洗了，因爲上帝親自指明了這一點：
> act 10:47-48 :: !誰能禁止用水給他們施洗呢 :: !就吩咐奉耶穌基督的名給他們施洗
這樣，這是聖靈在洗禮之前降臨的唯一一例。不是代替洗禮，而是在它之前——因爲洗禮還是舉行了。而這一特殊的聖靈降臨有一個例外性的緣由——上帝以聖靈表明：可以接納外邦人進入教會。
聖靈降臨在人身上本身，是與洗禮分開的聖奧祕（詳見[[ru:миропомазание|聖膏]]）。
## “太監不經使徒就領受了聖靈？”
這個問題屬於聖膏的主題（見[[ru:миропомазание#HH-Если-сообщать-дары-Святого-Духа-могут-только-апостолы-то-почему-Святой-Дух-сходит-на-эфиопского-евнуха-после-крещения-от-диакона-Филиппа|聖膏]]）。在腓利與太監的情形中（[[act 8:39]]）有一個非常重要的細節。
絕大多數釋經者——包括最古老的，包括聖金口約翰——引用這段經文時都沒有關於聖靈降臨的話（αγιον επεπεϲεν επι τον ευνουχον αγγελοϲ δε）。經上只是說：
主<s>靈降在太監身上，而天使</s>把腓利提了去。
西奈抄本沒有這些話（四世紀）：
“καὶ ἐκέλευσεν στῆναι τὸ ἅρμα,
καὶ κατέβησαν ἀμφότεροι εἰς τὸ ὕδωρ,
ὁ τε Φίλιππος καὶ ὁ εὐνοῦχος,
καὶ ἐβάπτισεν αὐτόν.
ὅτε δὲ ἀνέβησαν ἐκ τοῦ ὕδατος,
**πνεῦμα Κυρίου ἥρπασε τὸν Φίλιππον**,
καὶ οὐκ εἶδεν αὐτὸν οὐκέτι ὁ εὐνοῦχος·
ἐπορεύετο γὰρ τὴν ὁδὸν αὐτοῦ χαίρων.
Φίλιππος δὲ εὑρέθη εἰς Ἄζωτον,
καὶ διερχόμενος εὐηγγελίζετο τὰς πόλεις πάσας,
ἕως τοῦ ἐλθεῖν αὐτὸν εἰς Καισάριαν.”（使徒行傳 8:39-40）
梵蒂岡抄本沒有這些話（四世紀）：
“και εκελευϲε ϲτηναι το αρμα και κατεβηϲαν αμφοτεροι ειϲ το υδωρ ο τε φιλιπποϲ και ο ευνουχοϲ και εβαπτιϲεν αυτον
οτε δε ανεβηϲαν εκ του υδατοϲ **πνευμα κ̅υ̅ ηρπαϲεν το̅ φιλιππον** και ουκ ειδε̅ αυτον ουκετι ο ευνουχοϲ επορευετο γαρ αυτου την οδον χαιρων”
聖金口約翰也是這樣引用的（沒有聖靈降臨的話）：
“Ὅτε δὲ ἀνέβησαν ἀπὸ τοῦ ὕδατος, **Πνεῦμα Κυρίου ἥρπασε τὸν Φίλιππον**, καὶ οὐκ εἶδεν αὐτὸν οὐκ ἔτι ὁ εὐνοῦχος.”
（[俄文](https://bibleox.com/el/grc/w/dNiR_Ὁμιλίαι_εἰς_τὰς_Πράξεις_τῶν_Ἀποστόλων#HH-ΟΜΙΛΙΑ-ΙΘ΄)《使徒行傳講道集》第9篇）
主教米哈伊爾（盧濟恩）的註釋：
“‘聖靈降在太監身上，主的使者卻把腓利提了去’：這一處只有少數古代希臘抄本和譯本（教會斯拉夫語和俄語譯本依從它們）以及少數古代釋經者如此讀；在大部分抄本和譯本以及釋經者中（其中如聖金口約翰和提奧菲拉克特）讀作：主的靈把腓利提了去。這究竟是一些抄本中的增添，還是另一些抄本中的省略——難以斷定；但前一種更可信，此處可以解釋爲：聖史緘默不言太監領受聖靈的事。”
（[俄文](https://azbyka.ru/biblia/in/?Act.8:39&r)來源）
# 若干補充
## 嬰兒能夠信
完全有理由認爲，嬰兒也能夠信、並被聖靈充滿，雖然他們還不能回答問題、以宣認自己的信仰。
先知大衛從嬰孩時期就仰賴上帝：
> ps 22:9-10 :: !我在母懷裏，你就使我有倚靠的心 :: !從我母親生我，你就是我的上帝
先知約翰在出生之前就感到與救主相遇，併爲之歡喜：
> lk 1:39-41 :: !所懷的胎就在腹裏跳動 :: !以利沙伯且被聖靈充滿
基督把一個孩子放在自己面前，講到那些**信他的**“小子”：
> mf 18:2-6 :: !耶穌便叫一個小孩子來 :: !你們若不迴轉，變成小孩子的樣式 :: !凡使這信我的一個小子跌倒的
孩子們在基督進入耶路撒冷時讚美他：
> mf 21:15-16 :: !小孩子在殿裏喊著說 :: !你從嬰孩和吃奶的口中完全了讚美的話
## 沒有說誰可以不經洗禮而得救
聖經裏沒有說誰可以不經洗禮而得救的話。倒是說了：不經洗禮沒有人能進上帝的國（[[in 3:3,5-6]]）。
