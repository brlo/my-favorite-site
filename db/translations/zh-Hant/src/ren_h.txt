# 定義
地獄可以有幾種理解。
1. 地獄——死者靈魂在普遍復活和最後審判之前的居所。
1. 地獄——在榮耀的第二次降臨、普遍復活和最後審判之後，被定罪的罪人復活後（即靈魂與身體一起）的居所。最後審判之後，這一命運已無法改變。被定罪者的痛苦與義人的真福將同樣永遠持續。
# 地獄、欣嫩谷、火湖、永火、外面的黑暗、監獄——受苦之處
在聖經中，「地獄」最常指某種受苦之處。這地方可以用不同的詞來稱呼，但這並不改變其實質：它始終是受苦之處。在地獄裏受苦的有：
> mf 8:12 :: !惟有本國的子民，竟被趕到外邊黑暗裏去
> mf 22:13 :: !把他丟在外邊的黑暗裏
> mf 25:30 :: !把這無用的僕人丟在外面黑暗裏
是基督自己——作爲審判者——決定誰往哪裏去：
> mf 25:41 :: !你們這被咒詛的人，離開我，進入那爲魔鬼和他的使者所預備的永火裏去
> mf 10:17,28,33-34,38 :: !你們要防備人 :: !惟有能把身體和靈魂都滅在地獄裏的，正要怕他 :: !我在我天上的父面前也必不認他 :: !乃是叫地上動刀兵 :: !不揹着他的十字架跟從我的，也不配作我的門徒
人死後要進入新的居所。這一事件值得哀哭：
> ekl 12:5 :: !因爲人歸他永遠的家
人死後有審判等待著他：
> evr 9:27 :: !人人都有一死，死後且有審判
地獄中，其中的居民有知覺地存在。巴比倫王受到地獄一切居民的迎接：
> is 14:4,9-10 :: !你下到陰間，陰間就因你震動，來迎接你 :: !你也變爲軟弱像我們一樣嗎？你也成了我們的樣子嗎
主在身體死後下到陰間，向那些從世界洪水時代起就在那裏的神魂宣講：
> 1pet 3:18-20 :: !按著肉體說，他被治死；按著靈性說，他復活了 :: !他藉這靈曾去傳道給那些在監獄裏的靈聽 :: !挪亞預備方舟、上帝容忍等待的時候
> ef 4:8-9 :: !既說升上，豈不是先降在地下嗎
基督的靈魂沒有被撇在陰間。不是**身體**沒有被撇在墳墓（土）裏，而是**靈魂**沒有被撇在陰間：
> act 2:31 :: !他的靈魂不撇在陰間
死人被看見，死人受審判，陰間交出死人：
> otkr 20:12-13 :: !我又看見死了的人 :: !死了的人都憑著這些案卷所記載的，照他們所行的受審判 :: !死亡和陰間也交出其中的死人
