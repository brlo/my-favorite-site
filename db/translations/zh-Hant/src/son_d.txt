# 耶穌基督降生在伯利恆
> mf 2:1; lk 2:4-7 :: 生在猶太的伯利恆
<em>這應驗了預言：[[mf 2:5]]；[[in 7:42]]；[[mih 5:2]]。</em>
# 逃往埃及
降生以後，約瑟和童貞女馬利亞爲躲避希律王的追殺，把嬰孩耶穌帶到埃及去了幾年（[[mf 2:16]]）：
> mf 2:14-15 :: 往埃及去 :: 住在那裏，直到希律死了
<em>這應驗了主藉先知所說的話：[[mf 2:15]]；[[os 11:1]]。</em>
# 返回拿撒勒
然後他們回到約瑟在拿撒勒的家（[[lk 2:4]]）：
> mf 2:20-23 :: 把小孩子和他母親帶到以色列地去 :: 加利利境內 :: 拿撒勒
<em>這應驗了預言：[[mf 2:23]]；可能還有 [[sud 13:5]]。</em>
# 每年上耶路撒冷
每年，耶穌基督都與父母、親屬和熟人一起上耶路撒冷的聖殿守節（[[lk 2:43-44]]）：
> lk 2:41-42 :: 每年到逾越節，他父母就上耶路撒冷去 :: 按著節期的規矩上去
到十二歲時，孩童耶穌已具有令耶路撒冷聖殿中的教師驚訝的智慧：
> lk 2:41-42,46-47 :: 當他十二歲的時候 :: 在殿裏，坐在教師中間 :: 凡聽見他的，都希奇他的聰明和他的應對
十二歲以後，基督也住在拿撒勒，順從父母：
> lk 2:51 :: 回到拿撒勒．並且順從他們
# 從拿撒勒遷往迦百農：傳道的開始
滿了三十歲、在先知約翰那裏受洗之後，基督才離開拿撒勒，遷往迦百農，開始宣講：
> mf 4:12-13 :: 後又離開拿撒勒，往迦百農去，就住在那裏
<em>這應驗了預言：[[mf 4:14-16]]；[[is 9:1-2]]。</em>
# 若干細節
## 加利利人都熟悉耶穌是木匠的兒子
在加利利傳道時，人們都熟悉耶穌基督，知道他是普通的木匠、木匠的兒子：
> mk 6:3 :: 這不是那木匠嗎
> mf 13:55 :: 這不是木匠的兒子嗎
## 爲守律法而常上聖殿
爲遵守律法，基督每年要三次上耶路撒冷的聖殿：
> ish 23:17 :: 一切的男丁，要一年三次朝見主耶和華
> ish 34:23 :: 一切男丁，要一年三次
> vtor 16:16 :: 一切的男丁 :: 除酵節、七七節、住棚節，一年三次
## 基督遵行了律法
> mf 5:17 :: 律法 :: 不是要廢掉，乃是要成全
> mf 3:15 :: 我們理當這樣盡諸般的義
> mf 26:24; mk 14:21 :: 人子必要去世，正如經上指著他所寫的
> lk 24:44 :: 摩西的律法 :: 先知的書 :: 詩篇 :: 凡指著我的話都必須應驗
> gal 4:4 :: 爲女子所生 :: 生在律法以下
## 等候滿齡纔開始傳道
基督直到三十歲才傳道行神蹟，因爲按上帝的定規和既成的傳統，公共事奉從三十歲開始（[[chis 4:3]]）。因此，來不是要廢掉律法、乃是要成全的基督（[[mf 5:17]]），等候到三十歲纔出來傳道：
> lk 3:23 :: 開頭傳道，年紀約有三十歲
基督等候他的時刻來到：
> in 2:4 :: 我的時候還沒有到
> in 7:30 :: 他的時候還沒有到
> in 8:20 :: 因爲他的時候還沒有到
> in 7:6 :: 我的時候還沒有到
> in 7:8 :: 因爲我的時候還沒有滿
> lk 12:50 :: 我是何等的迫切呢
> in 17:1 :: 父啊！時候到了
