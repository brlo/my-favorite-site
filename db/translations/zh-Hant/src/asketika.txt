# 聖經論隱修生活
## 選擇上帝所喜悅之事的太監
上帝特別舉出那些不結婚、特別關心遵守上帝誡命的人。他們彷彿被高舉在其餘的“兒女”之上：
> is 56:4-5 :: !持守我約的太監 :: !我必使他們在我殿中，在我牆內有記念、有名號，比有兒女的更美
| **不生育的男人，手若不作非法的行爲，心不思念相反上主的惡事，是有福的；天主見他忠貞，必賜給他特賞，在上主的聖殿中，賜給他更稱心的一份。** ||| sb prs 3:14
## 高於遵守誡命的成全之路
尋求救恩之道的富少年從救主得到確認：爲此必須遵守誡命。然而，因爲少年問起更多的事，主就向他指出更高的：不僅要得救，還要成爲完全的。爲此主呼召少年變賣自己的一切所有，來跟從他：
> mf 19:21 :: !你若願意作完全人 :: !可去變賣你所有的，分給窮人 :: !你還要來跟從我
## 爲天國的緣故自閹的人
隱修士捨棄一切地上的財富和依戀，一生專心尋求上帝並事奉他。隱修士——爲天國的緣故自閹、甘受剝奪的人：
> mf 19:10-12 :: !倒不如不娶 :: !這話不是人都能領受的，惟獨賜給誰，誰才能領受 :: !有爲天國的緣故自閹的 :: !這話誰能領受，就可以領受
這些關於閹人的話，是基督在使徒們聽到他禁止休妻之後說的。使徒們以爲那樣倒不如不娶。主沒有與這個結論爭辯，只指出：不是人人都能選擇這條路。誰能，誰就選擇。就是說，這是苦修者的特殊道路。
## 使徒的勸告
使徒明確地重複關於獨身的思想：
> 1kor 7:1 :: !男不近女倒好
使徒保羅沒有妻子，他勸告獨身者和寡婦（正是勸告）不要尋求新的丈夫，像他自己一樣：
> 1kor 7:8 :: !若他們常像我就好
使徒解釋這樣勸告的原因：
> 1kor 7:28-40 :: !我願你們無所掛慮 :: !沒有娶妻的，是爲主的事掛慮，想怎樣叫主喜悅 :: !娶了妻的，是爲世上的事掛慮，想怎樣叫妻子喜悅 :: !沒有出嫁的，是爲主的事掛慮，要身體、靈魂都聖潔 :: !已經出嫁的，是爲世上的事掛慮，想怎樣叫丈夫喜悅 :: !若常守節更有福氣
在自己的一生中度貞潔生活的基督徒，在天上無論羔羊往哪裏去都跟隨他：
> otkr 14:1-5 :: 羔羊 :: 十四萬四千人 :: 彷彿是新歌 :: !除了從地上買來的那十四萬四千人以外，沒有人能學這歌 :: !這些人未曾沾染婦女，他們原是童身 :: !羔羊無論往那裏去，他們都跟隨他

# 隱修生活的榜樣
## 主耶穌基督
- 沒有結婚；
- 沒有自己的房子（[[mf 8:20]]；[[lk 9:58]]；[[mf 19:21]]）；
- 沒有個人的錢袋（[[mk 12:15]]；[[mf 17:24-27]]；[[mf 19:21]]）；
- 常常獨自整夜祈禱（[[lk 6:12]]；[[mf 6:6]]；[[mf 14:23,25]]；[[mk 14:32,35,37,39-41]]）；
- 有門徒（[[lk 6:13]]；[[lk 10:1]]）；
- 教導祈禱，給門徒祈禱的範本（[[mf 6:9]]）；
- 安慰、責備、教導、訓誨來到他面前的人（[[mk 6:31]]）。
## 童貞女馬利亞——上帝之母
- 立了獨身的願，形式上處於婚姻中，沒有夫妻關係（“我不認識丈夫”——詳見[[ru:Богородица#HH-Богородица-была-и-остаётся-девой|上帝之母]]）；
- 沒有財產，自幼被送到聖殿撫養，後許配給約瑟，後被主交托給使徒約翰（[[in 19:27]]）。
## 先知施洗約翰
- 沒有結婚；
- 住在曠野，沒有自己的房子（[[lk 1:80]]）；
- 穿粗陋的自制衣服（[[mf 3:4]]）；
- 吃在曠野找到的極簡單的食物（[[mf 3:4]]）；
- 自制的衣服和找到的食物表明他沒有錢；
- 教導祈禱，給出祈禱的範本（[[lk 11:1]]）；
- 有門徒（[[mf 11:2]]；[[in 1:35]]；[[in 3:25]]）；
- 安慰、責備、教導、訓誨來到他面前的人（[[lk 3:18]]；[[lk 3:10-20]]；[[mk 6:31]]）。
## 先知以利亞
- 沒有結婚；
- 常常生活在荒野、曠野和洞穴裏（[[3ts 17:3-7]]；[[3ts 19:9]]；[[3ts 19:4]]）；
- 穿動物毛織的簡樸衣服，束皮帶（[[4ts 1:8]]）；
- 吃烏鴉叼來的簡樸食物（[[3ts 17:6]]）；
- 有門徒（[[3ts 19:19-21]]）；
- 奉上帝的命令責備人的不虔（[[3ts 18:17-40]]）。
## 先知但以理
- 沒有結婚；
- 吃簡樸的食物，拒絕王的膳食（[[dan 1:12]]）；
- 常常祈禱（[[dan 6:10]]）；
- 責備不虔（[[dan 5:17-28]]）。
## 先知耶利米
- 奉上帝的命令沒有結婚（[[ier 16:2]]）；
- 獨居，常被囚禁或流放（[[ier 37:15-16]]）；
- 教導並責備萬民（[[ier 1:9-10]]）。
