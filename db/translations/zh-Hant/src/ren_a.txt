人性構成：
1. 血肉之體；
1. 靈魂；
1. 靈（靈魂的力量）。
# 肉體
| 我在母胎中形成了肉軀，十月之久，在母血中凝結，由男精與合夢的慾樂而形成。 ||| sb prs 7:1-2
# 靈魂與靈
> 1sol 5:23 :: !全然成聖 :: !靈 :: !魂 :: !身子
> iov 14:22 :: !身上疼痛 :: !心中悲哀
> ps 63:1 :: !我的心切慕你 :: <<上帝阿
> ps 84:2 :: !我的心腸、我的肉體向永生上帝呼籲
> pr 11:17 :: !善待自己 :: !擾害己身
# 人死的時候，靈魂與身體分離
> mf 10:28; lk 12:4 :: !那殺身體不能殺靈魂的 :: !能把身體和靈魂都滅在地獄裏的
> act 20:9-10 :: !從三層樓上掉下去 :: !已經死了 :: !你們不要發慌，他的靈魂還在身上
# 人死後，肉體朽壞，但靈魂繼續存在
> act 2:31 :: !他的靈魂不撇在陰間 :: !他的肉身也不見朽壞
關於[[ru:жизнь-души-после-смерти-тела|靈魂不朽]]的引文。
# 復活時，人自己原來的肉體將復原，靈魂回來，與自己的肉體重新結合
> iov 19:25-27 :: !我這皮肉滅絕之後 :: !我必在肉體之外得見上帝 ~~ 和合本作「在肉體之外」；七十士譯本（俄文譯本所據）作「在肉體之內」，指復活時以自己的肉體得見上帝。

# 人受造原是要作上帝的形像和樣式：
> gen 1:26 :: !我們的形像 :: !我們的樣式
然而，受造時只是按形像：
> gen 1:27 :: !上帝就照著自己的形像造人 :: !乃是照著他的形像造男造女
> gen 5:1 :: !照著自己的樣式造的
> gen 9:6 :: !因爲上帝造人，是照自己的形像造的
## 人裏面的上帝形像
永遠的存在：
| 其實天主造了人，原是不死不滅的，使他成爲**自己本性的肖像**； ||| sb prs 2:23
## 人裏面的上帝樣式
人只是被召走向與上帝相似：
> mf 11:29 :: !學我的樣式 :: !得享安息
> rim 8:29 :: !效法他兒子的模樣
