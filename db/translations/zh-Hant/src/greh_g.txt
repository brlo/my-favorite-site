# 基督和使徒對教會有形合一的旨意
> in 17:20-21 :: !我不但爲這些人祈求 :: !使他們都合而爲一 :: !叫世人可以信你差了我來
> 1kor 1:10-13 :: !勸你們都說一樣的話 :: !你們中間也不可分黨 :: !只要一心一意 :: !基督是分開的嗎
> 1kor 3:4 :: !這豈不是你們和世人一樣嗎
上帝安排身體（教會）的肢體，使沒有分裂，衆人卻彼此相顧，一同受苦，一同快樂：
> 1kor 12:13-14,21-26 :: !都從一位聖靈受洗，成了一個身體 :: !身子原不是一個肢體，乃是許多肢體 :: !眼不能對手說 :: !但上帝配搭這身子 :: !免得身上分門別類，總要肢體彼此相顧 :: !若一個肢體受苦，所有的肢體就一同受苦
這些不同的肢體是什麼？——是教會中不同的職分和恩賜：
> 1kor 12:12,14,27-30 :: !就如身子是一個，卻有許多肢體 :: !身子原不是一個肢體，乃是許多肢體 :: !你們就是基督的身子 :: !上帝在教會所設立的：第一是使徒，第二是先知，第三是教師 :: !豈都是使徒嗎
這樣，上帝安排這一切職分和恩賜，爲使身體中沒有分裂；使徒在書信開頭就防止了這種分裂（[[1kor 1:10-13]]）。也就是說，上帝不但願意合一（[[in 17:20-21]]），而且眷顧此事。看，使徒被上帝立爲僕人，眷顧有形的合一，禁止哥林多人制造有形的分裂。
# 教會中的分裂——堵住人進入上帝之國之路的罪
> gal 5:19-21 :: !結黨 :: !行這樣事的人必不能承受上帝的國 ~~ 「結黨」（διχοστασίαι）——分裂、分爲兩部分。
> rim 16:17-18 :: !那些離間你們、叫你們跌倒、背乎所學之道的人 :: !因爲這樣的人不服事我們的主基督
# 關於分裂的預言
> iud 1:18-19 :: !末世必有好譏誚的人 :: !這就是那些引人結黨、屬乎血氣、沒有聖靈的人
> 1in 2:18-19 :: !現在已經有好些敵基督的出來了 :: !他們從我們中間出去，卻不是屬我們的
