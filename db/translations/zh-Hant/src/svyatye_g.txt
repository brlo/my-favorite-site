# 預備性的共通問題
本文以上帝的教訓爲前提：**基督是上帝**（[[ru:Христос-Бог|引文]]）。
童貞女馬利亞受敬禮，是根據敬禮聖人的教訓；所以首先要證明[[ru:почитание-святых-в-Библии|敬禮聖人]]和[[ru:молитвы-святым|爲聖人祈禱]]。
然而，這裏將提出的依據，不只是把童貞女馬利亞作爲聖人之一來敬禮，而是**特別**敬禮她——作爲**聖僕和上帝朋友中最大的一位**，作爲耶穌基督的母親（即上帝之母，因爲耶穌基督是上帝）。
# 特別敬禮上帝之母的緣由
1. **童貞女馬利亞對上帝話語特別的留意**；
2. **完全謙卑地順服上帝**；
3. **被上帝揀選**。全宇宙中沒有別的受造物蒙上帝賜予按人性生他的榮耀。她的功績不在於生育，而在於上帝預先知道馬利亞的品質（[[rim 8:29]]），因這些品質而揀選了她。上帝以這揀選指明她的偉大；
4. **上帝之子尊敬童貞女馬利亞爲自己的母親**。再沒有別的受造物（全宇宙中）是上帝之子的母親；
5. **預言的應驗**：“從今以後萬代要稱我有福”（[[lk 1:48]]）——即所有世代的人。上帝爲童貞女馬利亞成就了大事：“那有權能的爲我成就了**大事**，他的名爲聖”（[[lk 1:49]]）。
# 因謙卑被揀選
> lk 1:46-48 :: !他顧念他使女的卑微 :: !從今以後，萬代要稱我有福
連最大的先知（施洗約翰）的父親撒迦利亞，也因不信——或說得更好：因不信任、疑惑——被天使責罰（[[lk 1:20]]）。而上帝之母謙卑地領受了對自己的定命，謙卑地回答：
> lk 1:38 :: !情願照你的話成就在我身上
關於謙卑的重要引文：
| 你的力量，不在乎人多；你的威能，並不靠強力；但**你卻是謙卑者的天主**，弱小者的扶助，無力者的保護，無靠者的依賴，失望者的救主。 ||| sb iudf 9:11
| **你越偉大，在一切事上越當謙下**；這樣，你才能在上主面前，獲得恩寵。 ||| sb prsir 3:20
關於謙卑的重要引文：[[ru:смирение|謙卑]]
# 上帝話語最留心的聽者
> pr 23:26 :: !我兒，要將你的心歸我 :: !你的眼目也要喜悅我的道路
> lk 2:19 :: !馬利亞卻把這一切的事存在心裏，反覆思想
> lk 2:51 :: !他母親把這一切的事都存在心裏
> lk 11:27-28 :: !是，卻還不如聽上帝之道而遵守的人有福
正如聖伊格納提（布良恰尼諾夫）所說，她成了上帝教導的最留心、最恆常的聽者和實行者：
“童貞女高於所有聖徒，一方面因爲她成了神人的母親，另一方面因爲**她是最恆常、最留心的聽者和實行神人所宣講教導的人**。”
（[俄文](https://azbyka.ru/technik/Ignatij_Brjanchaninov/asketicheskaya_propoved/54)《正教會論上帝之母的教導》）
# 成爲基督上帝的母親
特別敬禮上帝之母的緣由之一，是她——上帝之母（按人性）：因爲再沒有別的受造物是上帝的母親。上帝的誡命要求尊敬父母（[[ru:10-заповедей#HH-5|第五誡]]），所以基督上帝親自尊敬上帝之母爲自己的母親，他信實的門徒們也跟隨他。
## 童貞女馬利亞生了上帝之子
正是上帝的獨生子真實地由女子所生：
> gal 4:4 :: !上帝就差遣他的兒子 :: !爲女子所生
上帝的獨生子、上帝的道，真實地成了肉身：
> in 1:14 :: !道成了肉身，住在我們中間
天使加百列直接稱童貞女馬利亞所生的孩子爲上帝之子：
> lk 1:35 :: !所要生的聖者必稱爲上帝的兒子
## 童貞女馬利亞——上帝之子的母親
義人以利沙伯——先知施洗約翰的母親——直接稱童貞女馬利亞爲上帝之母：
> lk 1:43 :: !我主的母
> mf 2:11 :: !看見小孩子和他母親馬利亞
> in 19:26 :: !耶穌見母親 :: !就對他母親說
> in 2:5 :: !他母親對用人說
> in 2:1 :: !耶穌的母親在那裏
（[[mf 2:14]]；[[mf 2:20]]；[[mf 2:21]]；[[mf 12:46]]；[[mk 3:31]]；[[lk 2:33]]；[[lk 2:34]]；[[lk 2:43]]；[[lk 2:48]]；[[lk 2:51]]；[[lk 8:19]]；[[in 2:3]]；[[in 2:12]]；[[in 19:25]]；[[in 19:26]]；[[act 1:14]]）
如果上帝之子永遠成了人（這是確實的），那麼童貞女馬利亞就永遠是上帝之子的母親。
## 上帝之子——童貞女馬利亞之子
> mf 1:25 :: !等她生了兒子
## 童貞女馬利亞——上帝之母
童貞女馬利亞生了耶穌基督。
耶穌基督——上帝之子——是[[ru:Христос-Бог|我們的上帝]]。
童貞女馬利亞所生的是[[ru:Христос-Бог|我們的上帝]]。就是說，她是生了上帝的那位——上帝之母。
童貞女馬利亞生的不是永恆的上帝本性——它存在於時間和空間之外——而是上帝之子的人性；這人性有其開始，並且從它存在之初就完全屬於上帝之子（上帝）的位格。
簡言之，童貞女馬利亞按人性生了上帝。
然而，上帝之母的偉大恰恰在於她被揀選作上帝的母親。她的功績不在於生育——生育的人很多——而在於：上帝預先知道馬利亞的品質（[[rim 8:29]]），從所有存在過的人中揀選的不是別人，而正是童貞女馬利亞。
# 上帝之母曾經是、並且仍是童貞女
## 耶穌基督誕生之前馬利亞的童貞
童貞女馬利亞與義人約瑟沒有夫妻關係。她雖已許配給約瑟（[[lk 1:27]]），卻不明白自己沒有夫妻關係怎麼能生子：
> lk 1:34 :: !我沒有出嫁，怎麼有這事呢
還應注意：這個問題只有在童貞女馬利亞曾向上帝許願保守童貞的情況下才有意義。否則，即使童貞女馬利亞至今沒有與義人約瑟有過夫妻關係，當上帝的天使宣告她將生子時，她顯然應當順服上帝、與丈夫有夫妻關係，好叫預言應驗。但如果童貞女馬利亞曾向上帝許願度貞潔的生活，那就立刻產生問題：“怎麼會生子呢？因爲向上帝所起的願是不可違揹的（[[chis 30:3]]）？”
天使回答說，向馬利亞所預言的將不經丈夫、以上帝大能的奇妙運作成就：
> lk 1:35 :: !聖靈要臨到你身上 :: !至高者的能力要廕庇你
耶穌基督只是按人們的看法是約瑟的兒子：
> lk 3:23 :: !依人看來，他是約瑟的兒子
實際上，基督不是由約瑟所生，而是由聖靈的大能。
## 耶穌基督誕生之後馬利亞的童貞
關於馬利亞終身童貞（至今仍是童貞女）的預言：從她生的只有一個孩子——進入我們世界的上帝、基督，正如藉著童貞女馬利亞、上帝之母這門一樣：
> iez 44:1-2 :: !這門必須關閉，不可敞開 :: !誰也不可由其中進入，因爲耶和華以色列的上帝已經由其中進入，所以必須關閉
這樣，童貞女馬利亞除了耶穌基督，沒有生任何別的孩子。同時，馬利亞的童貞沒有被破壞。
還應注意：在被釘十字架的那一天，基督把自己母親的關懷託付給所愛的門徒——神學家約翰（[[in 19:26-27]]）。這表明：除了基督——童貞女馬利亞的獨子——之外，她再沒有丈夫，也沒有別的本應照顧她的兒女。
義人約瑟在基督誕生時已經年老，所以在基督被釘時早已去世。確實，在記述耶穌基督的童年之後，經上再也沒有提到約瑟。而馬利亞被託付給約翰，是因爲正是他將比其他使徒在地上活得更久。主自己指明，使徒彼得將爲基督受難，而使徒約翰將活得久得多（[[in 21:22]]）。我們知道，約翰是使徒中最年輕的，在地上勞苦直到第一世紀末，而其餘使徒都領了殉道之死。這使使徒約翰能夠比所有其他人更久地照顧童貞女馬利亞。
這一事實也表明：童貞女馬利亞沒有別的能照顧她的兒女。
# 萬代都要稱上帝之母有福
上帝之母將被稱爲有福，上帝爲她成就了大事：
> lk 1:48-49 :: !從今以後，萬代要稱我有福 :: !那有權能的，爲我成就了大事
類似的話也說及基督自己：
> ps 72:17 :: !人要因他蒙福，萬國要稱他有福
# 基督與母親的特殊關係
## 上帝之子尊敬童貞女馬利亞爲自己的母親
上帝之子順服律法：
> gal 4:4 :: !且生在律法以下
上帝命令尊敬父親和母親：
> ish 20:12 :: !當孝敬父母
> vtor 5:16 :: !當照耶和華你上帝所吩咐的孝敬父母
> ish 21:17 :: !咒罵父母的，必要把他治死
> lev 20:9 :: !凡咒罵父母的，總要治死他
> ish 21:15 :: !打父母的，必要把他治死
> lk 18:20 :: !當孝敬父母
> mk 7:9,11-12 :: !你們誠然是廢棄上帝的誡命 :: !以後你們就不容他再奉養父母
全宇宙中除童貞女馬利亞外，沒有別的受造物是上帝之子的母親。在這層關係上，天使和世人中沒有誰高於童貞女馬利亞，因爲尊敬她爲自己母親的，正是上帝之子、上帝本身。
## 基督聽自己母親的話
基督指出，宣講和奇蹟（顯明他的榮耀）的時候還沒有到；但因母親所求，他行了第一個奇蹟：
> in 2:3-5,7-8,11 :: !耶穌的母親對他說 :: !我與你有什麼相幹 :: !我的時候還沒有到 :: !他母親對用人說 :: !這是耶穌所行的頭一件神蹟 :: !顯出他的榮耀來
## 基督關懷自己的母親
在十字架上殘酷受苦的時候，基督關懷自己的母親：
> in 19:26-27 :: !耶穌見母親 :: !就對他母親說 :: !看你的母親 :: !從此那門徒就接她到自己家裏去了
## 基督與自己母親個人關係的性質
在最可怕的時辰——在十字架上經受極重的身體痛苦、被出賣、門徒逃散、人之常情的被棄感（第九個小時：“我的上帝！我的上帝！**爲什麼離棄我**？”，[[mk 15:34]]）——主關懷著自己的母親，她跟隨他直到最後一刻。
在這最艱難的時刻，他轉向自己的母親，對她顯出特別的關懷，把她託付給所愛的門徒——而且不是一般的“看顧她、照顧她”，而是“接她作你的母親”：
> in 19:26-27 :: !就對他母親說 :: !看你的母親 :: !從此那門徒就接她到自己家裏去了
注意：所有基督指著說“看哪，我的母親，我的弟兄”（[[mf 12:48-50]]）的人，都離開了他（[[in 16:32]]）；而他的母親卻同他在一起直到末了。
> in 16:32 :: !留下我獨自一人 :: !其實我不是獨自一人，因爲有父與我同在
> in 8:29 :: !他沒有撇下我獨自在這裏 :: !因爲我常作他所喜悅的事
基督沒有撇下自己的母親獨自一人，也是出於同樣的原因。
## 上帝之母與基督同到底，這重要嗎？
使徒保羅在離世前也經歷了類似的被棄：
> 2tim 1:15 :: !凡在亞西亞的人都離棄我
> 2tim 4:10 :: !底馬貪愛現今的世界，就離棄我
上帝之母從起初到末了在一切事上都留心、順服、忠於上帝。她一直是、並且仍是與上帝同在的。
# 對異議的回應
## “可是聖經裏沒有‘上帝之母’這個詞”
聖經裏也沒有“三位一體”這個詞——那又怎樣呢？聖經裏所說的，正是“上帝之母”一詞所說的：童貞女馬利亞是耶穌基督的母親；耶穌基督是上帝；童貞女馬利亞生了耶穌基督，即生了上帝——當然，按人性。由她所生的，是上帝。童貞女馬利亞——生了上帝的，簡稱：上帝之母。
## “懷你胎的和乳養你的有福了”
人們因親緣關係、因生養和乳養基督而讚美上帝之母；但基督親自更正了這一理解（重新立定重點），指明自己母親的偉大，在於她對上帝之道的特別留心和完全謙卑的順服：
> lk 11:27-28 :: !懷你胎的和乳養你的有福了 :: !是，卻還不如聽上帝之道而遵守的人有福
> lk 2:19 :: !馬利亞卻把這一切的事存在心裏，反覆思想
> lk 2:51 :: !他母親把這一切的事都存在心裏
## “誰是我的母親？”
這裏基督又一次強調：童貞女馬利亞的偉大不像人們所想的那樣在於親緣關係，而在於她毫無條件地遵行上帝的旨意：
> mf 12:48-50 :: !誰是我的母親 :: !凡遵行我天父旨意的人，就是我的弟兄、姐妹和母親了
## “只是沒有和她同房，等她生了兒子”（太 1:25）
> mf 1:25 :: !只是沒有和她同房，等她生了兒子
“沒有和她同房，等她生了兒子”這話，並不意味著基督生下之後“就同房了”。這是聖經中常見的表達方式，並不表示後來有了改變。
例如：
> mf 28:20 :: !我就常與你們同在，直到世界的末了
——而在世界終結之後，基督顯然仍將與信他的人同在。
> in 12:35-36 :: !你們應當趁著有光，信從這光
——而在基督昇天之後，也應當信光（信基督）；
> 1kor 15:25 :: !因爲基督必要作王，等上帝把一切仇敵都放在他的腳下
——而在仇敵被放在腳下之後，基督顯然仍要作王（[[lk 1:33]]；[[2pet 1:11]]）。
> ps 110:1 :: !你坐在我的右邊 :: !等我使你仇敵作你的腳凳
——而在仇敵被放在腳下之後，基督顯然仍坐在父的右邊，即仍要作王。
> otkr 2:24-25 :: !但你們已經有的，總要持守，直等到我來
——而在基督再來之後，顯然仍須持守美德和信仰。
> 2ts 6:23 :: !掃羅的女兒米甲，直到死日，沒有生養兒女
——而在她死後，米甲顯然也沒有生養兒女。
還應注意聖經中的這些地方：
> mf 12:18-20 :: !壓傷的蘆葦，他不折斷 :: !等他施行公理，叫公理得勝
## “生了頭胎的兒子——就是說還有別的孩子？”
聖經稱上帝之母的兒子爲頭胎的：
> mf 1:25 :: !等她生了兒子〔有古卷作『等他生了頭胎的兒子』〕
> lk 2:7 :: !就生了頭胎的兒子
（*在西奈和梵蒂岡抄本中沒有“頭胎”一詞；不過這個詞在路 2:7 中有。*）
教會教訓的反對者認爲這是指童貞女馬利亞還有別的兒女，說：“既然有頭胎的，就是說還有別的孩子。”聖經自己表明這種想法是錯誤的。
上帝自己在聖經中給“頭胎的”一詞下了定義——**凡開胎的**：
> chis 18:15 :: !凡頭生的都要歸給你
> ish 34:19-20 :: !凡頭生的都是我的 :: !凡頭生的兒子都要贖出來
一切頭胎的都屬於上帝，因此：
1. 人的頭胎的必須被帶到聖殿，從司祭手中贖出來。
2. 潔淨牲畜的頭胎的被帶到聖殿獻上，被殺，作爲祭物獻給上帝。
3. 不潔淨牲畜的頭胎的不能作祭物，所以必須贖出來。
人及牲畜一旦生下第一個孩子，就應獻給上帝或贖出來。顯而易見，就在這一時刻，這頭生的孩子是獨生的，然而上帝稱之爲頭胎的，因爲他開了胎。這意味著：**凡獨生的都是頭胎的，但並非凡頭胎的都是獨生的**。
而如果像反對教會教訓的人那樣想，認爲只有那些有弟兄姊妹的才叫頭胎的，那就得出：生了第一個孩子的人應當對司祭說：“等生了第二個，這個才能叫頭胎的；現在他不是頭胎的，而是獨生的，所以我不必把他獻給上帝、不必贖他。”然而連這種荒謬的想法也違揹聖經和常識，因爲獨生的救主正是按這關於頭胎的律法被帶進聖殿的：
> lk 2:22 :: !按摩西律法滿了潔淨的日子 :: !他們帶著孩子上耶路撒冷去，要把他獻與主
顯然，主耶穌基督在這裏是**獨生**的，但他被作爲**頭胎的**帶進聖殿。這樣，這裏的“頭胎的”，按上帝的話，指的是凡開胎的，並不表明母親是否還有別的生育。詳見注[2]。
## 耶穌基督的弟兄們
聖經說基督有弟兄們：
> mf 13:55 :: !他弟兄們不是叫雅各
> in 7:5 :: !因爲連他的弟兄說這話，是因爲不信他
> mk 3:31 :: !耶穌的母親和弟兄來
> 1kor 9:5 :: !彷彿其餘的使徒和主的弟兄，並磯法一樣
這裏指的是約瑟前婚的兒女，或只是親屬。弟兄們——就是一般的親屬。例如，羅得是亞伯拉罕的侄子，但在聖經裏也稱爲弟兄：
> gen 14:12 :: !又把亞伯蘭的姪兒羅得
> gen 13:8 :: !因爲我們是骨肉
約瑟在馬利亞被許配給他作保護者時已經年老，因爲馬利亞不能沒有丈夫。如果基督由馬利亞所生、而她沒有已知的丈夫，那麼按律法她應當被石頭打死（[[vtor 22:20-21]]），因爲所有的人都會以爲她行了淫亂（婚外）之事。所以主這樣安排：馬利亞有丈夫，但她以奇妙的方式、不由丈夫、由聖靈的感孕而懷孕（[[mf 1:18-25]]；[[lk 1:34-35]]）。
在耶穌的童年之後，經上再也沒有提到約瑟；而童貞女馬利亞陪伴耶穌基督直到末了——直到十字架的苦難（[[in 19:25-26]]），並且在復活之後、五旬節那天也被提到（[[act 1:14]]）。
基督把自己的母親託付給所愛的門徒——約翰（[[in 19:27]]）。顯然，那時約瑟已經去世。
這樣，耶穌基督的“弟兄們”——只是一般的親屬，而完全不是童貞女馬利亞的別的兒女。
而預言清楚地說明，從童貞女馬利亞所生的只有主耶穌基督：
> iez 44:1-2 :: !這門必須關閉，不可敞開 :: !誰也不可由其中進入，因爲耶和華以色列的上帝已經由其中進入，所以必須關閉
## 任何地方都沒有說童貞女馬利亞不信基督
教會的批評者常常重複這樣的想法：彷彿童貞女馬利亞不信她的兒子是救主、是所應許的彌賽亞、是基督。但這不是真的。聖經裏沒有這樣的話。說的只是弟兄們（約瑟前婚的兒女）不信基督：
> in 7:5 :: !因爲連他的弟兄說這話，是因爲不信他
這是相當可以預料的：他們是約瑟前婚的兒子，已經是成年人，見過少年耶穌長大。所以他們和基督的其他同鄉（加利利居民）一樣，難以相信（[[mf 13:54-58]]）。但後來弟兄們也信了（[[act 1:14]]；[[gal 1:19]]）。
## 王的母親——王后
批評者責備教會稱上帝之母爲王后。但王的母親正是王后。
| **列王的公主都成羣結隊前來歡迎你，王后佩帶敖非爾金飾，在你右邊侍立。** ||| sb ps 45:10 ~~ 俄文本編號爲 Пс 44:10（聖詠編號相差一）。
使徒們曾被拒絕坐在基督國裏他的右邊和左邊：
> mk 10:40 :: !只是坐在我的左右 :: !乃是爲誰預備的，就賜給誰
如果不是使徒們“坐”在那裏，那是誰？在正教的“最後審判”聖像中，寫在基督旁邊的正是上帝之母（在右邊）和先知施洗約翰（在左邊）——作爲婦人所生中最大的（[[mf 11:11]]）。
## “上帝之母，拯救我們”這句話
這裏需要正確理解意義。救主只有一位，而在拯救的事業中有許多同工者：
> 1kor 3:9 :: !因爲我們是與上帝同工的
使徒打算拯救人：
> 1kor 9:22 :: !向什麼樣的人，我就作什麼樣的人 :: !無論如何總要救些人
> rim 11:14 :: !或者可以激動我骨肉之親發憤 :: !好救他們一些人
妻子可以救丈夫，丈夫可以救妻子：
> 1kor 7:16 :: !你這作妻子的，怎麼知道不能救你的丈夫呢 :: !你這作丈夫的，怎麼知道不能救你的妻子呢
使徒呼召拯救人：
> iud 1:22-23 :: !有些人你們要從火中搶出來 :: !搭救他們
> 1tim 4:16 :: !你要謹慎自己和自己的教訓 :: !又能救自己，又能救聽你的人
## “上帝之母的僕人”這句話
這與拯救的情形相同。必須正確理解意義。
我們不把上帝之母當作上帝來事奉，但我們事奉她。如果上帝之母求我們什麼事，我們會樂意爲她效勞。難道可以想像基督徒會作別樣的事嗎？
聖經裏有義人不但稱自己爲上帝的僕人——同時仍是獨一上帝的僕人——也稱自己爲人的僕人的地方。
使徒們——是基督徒們的僕人：
> 2kor 4:5 :: !並且自己因耶穌作你們的僕人
亞比該——敬畏上帝的人、庇護先知脫逃逼迫的人——稱自己爲先知以利亞的僕人，稱以利亞爲主人：
> 3ts 18:3-4,7-9,12 :: !俄巴底認出他來，就俯伏在地 :: !你是我主以利亞不是 :: !僕人卻是自幼敬畏耶和華的
## 上帝之母在安葬之後復活了
敬禮上帝之母的人的反對者，反對正教會關於主耶穌基督使自己的母親復活的聖傳，彷彿這是不可能的，以爲只有基督復活了。然而從聖經的角度，這沒有任何困難：因爲基督復活之後，許多聖徒復活了（無論我們怎樣理解這復活的性質）：
> mf 27:51-53 :: !墳墓也開了 :: !已睡聖徒的身體，多有起來的 :: !到耶穌復活以後，他們從墳墓裏出來 :: !進了聖城，向許多人顯現
如果主在自己的復活中使許多聖徒復活，那他更能使自己的親生母親復活——他爲道成肉身而揀選了她，行奇蹟時聽了她，並關懷她、把她託付給所愛的門徒。
爲證實上帝之母復活的聖傳，還應注意：既然教會從最古老的年代起就以這樣的敬畏對待聖人的聖髑（詳見[[ru:почитание-мощей-цитаты-святых|敬禮聖髑的引文]]），那麼教會沒有上帝之母的聖髑，正如沒有主耶穌基督的聖髑（因爲他復活了）。
