# 舊約中司祭職的上帝設立
司祭——只是亞倫的後裔：
> ish 29:9 :: !給亞倫和他兒子束上腰帶 :: !他們就憑永遠的定例得了祭司的職任
司祭職與聖衣、膏抹一同傳遞：
> ish 29:29 :: !亞倫的聖衣要留給他的子孫 :: !可以穿著受膏，又穿著承接聖職
外人若近前來行事奉的禮，必須治死。司祭職的職責就是看守這事：
> chis 3:10 :: !你要囑咐亞倫和他兒子，謹守自己祭司的職任 :: !近前來的外人必被治死
詳細：
> chis 18:1-3,7 :: !耶和華對亞倫說 :: !你和你的兒子，並你本族的人 :: !你要帶你弟兄利未人 :: !使他們與你聯合，服事你 :: !你和你的兒子要一同在法櫃的帳幕前供職 :: !只是不可挨近聖所的器具和壇 :: !你和你的兒子要爲一切屬壇，和幔子內的事，一同守祭司的職任 :: !我將祭司的職任給你們當作賞賜事奉我 :: !凡挨近的外人必被治死
# 新約中司祭職的更換
主耶穌基督訂立新約（[[lk 22:20]]；[[evr 8:8]]），改變律法，更換司祭職（是更換，而不是廢除）：
> evr 7:12 :: !祭司的職任既已更改，律法也必須更改
救主把聖靈賜給使徒，按麥基洗德的等次設立司祭的等次；他自己成爲大祭司：
> evr 7:1-3; evr 6:20 :: !又是至高上帝的祭司 :: !他頭一個名繙出來就是仁義王 :: !就是平安王的意思 :: !無父、無母、無族譜、無生之始、無命之終 :: !乃是與上帝的兒子相似
> evr 8:1 :: !我們有這樣的大祭司，已經坐在天上至大者寶座的右邊
# 教會等次的形成
在五旬節那天，聖靈被賜給使徒和整個教會聚會——賜給整個教會。但在這天之前，救主只向使徒們顯現，並且只把聖靈賜給他們，把赦罪之權賜給他們如同司祭一樣——就是說，設立等次：
> in 20:21-23 :: !父怎樣差遣了我，我也照樣差遣你們 :: !你們受聖靈 :: !你們赦免誰的罪，誰的罪就赦免了 :: !你們留下誰的罪，誰的罪就留下了
同樣，在舊約的教會裏，潔淨罪的事正是在司祭職上：
> lev 5:5-6 :: !就要承認所犯的罪 :: !祭司要爲他贖了
# 新等次的權柄
主把天國的鑰匙、捆綁和釋放的權柄賜給使徒：
> mf 16:19 :: !凡你在地上所捆綁的，在天上也要捆綁 :: !凡你在地上所釋放的，在天上也要釋放
> mf 18:18 :: !凡你們在地上所捆綁的，在天上也要捆綁 :: !凡你們在地上所釋放的，在天上也要釋放
司祭職由使徒們揀選並按立，但聖經宣告：立長老看守教會的正是聖靈：
> act 20:17-18,28 :: !請教會的長老來 :: !聖靈立你們作全羣的監督 :: !牧養上帝的教會
這一切——是舊約預言的應驗，見下文。
# 關於新約司祭職的預言
在舊約的教會裏，司祭只從猶太民族中立——利未支派、亞倫的家系。而在新約的教會裏，司祭將從一切民族中立，而不只是從猶太人（亞倫的家系）中：
> is 66:18-21 :: !我必將萬民萬族 :: !並素來沒有聽見我名聲、沒有看見我榮耀遼遠的海島 :: !我也必從他們中間取人爲祭司，爲利未人
# 使徒傳承與按立的教訓
## 主教的按立
主教提摩太藉使徒的按手、並有先前已被按立的主教們的按手，領受了特別的恩賜：
> 2tim 1:6 :: !使你將上帝藉我按手所給你的恩賜
> 1tim 4:14 :: !你不要輕忽所得的恩賜 :: !就是從前藉着預言、在衆長老按手的時候賜給你的
行邪術的西門看見，不是每個基督徒都能按手以賜下聖靈。字面上說：不是人人都有這權柄。他拿錢給使徒，要他們也給他這權柄（使徒們爲此咒詛了他）：
> act 8:18-20 :: !西門看見使徒按手，便有聖靈賜下 :: !把這權柄也給我 :: !叫我手按著誰，誰就可以受聖靈 :: !你想上帝的恩賜是可以用錢買的
## 使徒保羅的按立
> act 13:2-3 :: !要爲我分派巴拿巴和掃羅 :: !於是禁食禱告，按手在他們頭上
## 輔祭的按立
> act 6:6 :: !使徒禱告了，就按手在他們頭上
同樣見：[[act 21:8]]
## 關於按立的教訓
使徒關於按手的教訓：
> evr 6:2 :: !各樣洗禮、按手之禮
警告不要急於按立（立爲司祭）：
> 1tim 5:22 :: !給人行按手的禮，不可急促 :: !不要在別人的罪上有分
## 主教與長老——區別
主教（希臘文 ἐπίσκοπος——監督）和長老（希臘文 πρεσβύτερος——年長者、團體之首）這兩個概念交叉使用，彷彿可以互換。然而，具體之人的職分和權柄看得清楚，無論他們如何被稱呼。提多應當完成使徒的事業，在克里特設立長老：
> tit 1:5 :: !又照我所吩咐你的，在各城設立長老
提摩太可以審判自己的長老、責備和警戒信徒：
> 1tim 5:19 :: !控告長老的呈子，非有兩三個見證就不要收
> 2tim 4:2 :: !務要傳道 :: !責備人，警戒人，勸勉人
這樣，提多和提摩太按今天的理解是主教，雖然被稱爲長老。
## 人人都是司祭嗎？
### 與舊約話語的平行
使徒彼得重複舊約的話，稱所有基督徒爲君尊的祭司和聖潔的國民：
> 1pet 2:9 :: !惟有你們是被揀選的族類，是有君尊的祭司，是聖潔的國度
這些話在舊約裏是對全以色列說的：
> ish 19:5-6 :: !你們要歸我作祭司的國度，爲聖潔的國民
這樣，上帝稱舊約的以色列爲祭司的國度和聖潔的國民。然而，在事奉聖禮的意義上，並不是所有猶太人都是司祭。按律法，只有亞倫的司祭職可以進帳幕，其餘的人若進帳幕就須以自己的生命付出代價，即他們必須死（[[chis 3:10]]；[[chis 3:38]]；[[chis 18:7]]）。
如果在舊約裏要把這些話分開——祭司的國度（不是所有人）和聖潔的國民（所有人），那麼對新約使徒的話也得同樣承認：君尊的祭司（不是所有人）、聖潔的國度（所有人）（[[1pet 2:9]]）。這些話可以按字面理解，也可以按寓意理解，但無論如何，都得把這兩句話聯繫在一起，在同一意義上理解它們。
### 舊約中建立普遍祭司職的企圖
在舊約裏，上帝設立的秩序是：只有亞倫的後裔可以作司祭：
> ish 29:29 :: !亞倫的聖衣要留給他的子孫
甚至亞倫的家系也不是人人都能作司祭：
> lev 21:21,23 :: !祭司亞倫的後裔，凡有殘疾的，都不可近前來將火祭獻給耶和華 :: !免得褻瀆我的聖所
反對這神聖秩序的，是**可拉、大坍、亞比蘭和安**，他們要求先知摩西從全民族中立司祭，而不只是從亞倫的家系。他們引用的正是那句話（[[ish 19:5-6]]），說人人都聖潔：
> chis 16:3 :: !全會衆個個既是聖潔，耶和華也在他們中間 :: !你們爲什麼自高，超過耶和華的會衆呢
> chis 16:10 :: !你們還要求祭司的職任嗎
之後上帝的榮光顯現，地開了口，吞滅了叛亂者：
> chis 16:19-21 :: !可拉招聚全會衆到會幕門前 :: !你們離開這會衆，我好在轉眼之間把他們滅絕
上帝吩咐把叛亂者的香爐中的火倒出，用那些香爐包祭壇，作後世的記念：
> chis 16:37-38 :: !把那些犯罪自害己命之人的香爐，叫人錘成片子，用以包壇 :: !並且可以給以色列人作記號
> 1kor 10:11 :: !他們遭遇這些事都要作爲鑑戒
使徒猶大也記念可拉滅亡的頑梗：
> iud 1:11 :: !並在可拉的背叛中滅亡了
還有預言說，在末後的日子這樣的人要起來：
> 2tim 4:3 :: !耳朵發癢，就隨從自己的情欲，增添好些師傅
### 關於新約中立司祭的預言
還在舊約裏就有預言：在新約裏仍要立司祭和僕人，但從一切民族中立，而不只是從亞倫的家系：
> is 66:18-21 :: !我必將萬民萬族 :: !我也必從他們中間取人爲祭司，爲利未人
新約裏指明，沒有人可以自己取得司祭職：
> evr 5:1-5 :: !凡從人間挑選的大祭司，是奉派替人辦理屬上帝的事 :: !這大祭司的尊榮，沒有人自取 :: !惟要蒙上帝所召，像亞倫一樣 :: !如此，基督也不是自取榮耀作大祭司
### 信了並受了洗的行邪術的西門沒有傳遞聖靈恩賜的恩賜
行邪術的西門，如經所記，信了並受了洗：
> act 8:13 :: !西門自己也信了，既受了洗
但當他明白不是所有基督徒都能傳遞聖靈的恩賜時，就試圖向使徒們買這恩賜。使徒們爲此咒詛了他：
> act 8:18-23 :: !西門看見使徒按手，便有聖靈賜下 :: !把這權柄也給我 :: !叫我手按著誰，誰就可以受聖靈 :: !彼得說 :: !你想上帝的恩賜是可以用錢買的 :: !你在這道上無分無關 :: !你當懊悔你這罪惡 :: !我看出你正在苦膽之中
由此可見，不是所有基督徒都是有職分和上帝恩賜的司祭，能傳遞聖靈。給撒瑪利亞人施洗的六品執事腓利也沒有這恩賜（[[act 21:8]]）。而有這恩賜的人，是藉使徒的按手（[[2tim 1:6]]）和司祭職的按手（[[1tim 4:14]]）領受的。
這樣：
- 不是所有人都受了教導並施洗的託付：“所以，**你們要去，使萬民作我的門徒，奉父，子、聖靈的名給他們施洗**”（[[mf 28:19]]）
- 不是所有人都受了命令：“**你們應當如此行，爲的是記念我**”（[[lk 22:19]]；[[1kor 11:24]]）
- 不是所有人都得了捆綁和釋放的權柄：“凡你們**在地上所捆綁**的，在天上也要捆綁；凡你們**在地上所釋放**的，在天上也要釋放”（[[mf 18:18]]）
- 不是所有人都得了赦罪和不赦罪的權柄：“**你們赦免誰的罪**，誰的罪就赦免了；**你們留下誰的罪**，誰的罪就留下了”（[[in 20:23]]）
- 不是所有人都得了按手賜聖靈的權柄：“**西門看見使徒按手，便有聖靈賜下**”（[[act 8:18]]）
- 使徒吩咐請來的，正是長老，病人藉他們的祈禱和事奉（用油抹）可以得赦罪：“**他就該請教會的長老來**，他們可以**奉主的名用油抹他**，爲他禱告。……**他若犯了罪，也必蒙赦免**”（[[iak 5:14-15]]）
# 君尊的祭司——如何理解？
無論在舊約還是新約，每個信徒都被召在自己的殿——自己的身體——裏作祭司。[[ru:человек-храм-Божий|人——上帝的殿]]，而祭司就是在這殿裏向上帝獻祭的人。使徒彼得正是從這個思想開始，然後纔講到君尊的祭司：
> 1pet 2:5 :: !被建造成爲靈宮 :: !作聖潔的祭司 :: !奉獻上帝所悅納的靈祭
講君尊的祭司時，使徒彼得在同一封書信裏也講到牧人和必須順服他們：
> 1pet 5:5 :: !你們年幼的也要順服年長的 :: !因爲上帝阻擋驕傲的人，賜恩給謙卑的人
還有一處關於基督徒爲祭司的話：
> otkr 1:5-6 :: !又使我們成爲國民，作他父上帝的祭司
> otkr 5:9-10 :: !又叫他們成爲國民，作祭司，歸於上帝，在地上執掌王權
> otkr 20:6 :: !他們必作上帝和基督的祭司
基督徒怎樣是王，也就怎樣是祭司。如果他現在不掌管外在的人，也就不是外在之人的祭司。這樣的解釋對上下文是誠實的，也符合常識。
基督徒被召在自己的身體裏爲王——使自己的理智掌管身體的私慾；而潔淨了這上帝的殿（自己的身體和心）之後，應當在那裏獻上蒙上帝悅納的祭：純潔的思想、言語、行爲、祈禱和頌讚。

# 對異議的回應
## “藉按手賜下聖靈——這只是西門的誤解？”
正教徒在聖經裏指出關於藉按手傳遞聖靈之特殊恩賜的引文。這些引文中有行邪術的（術士）西門的情形。
行邪術的西門看見，不是每個基督徒都能按手以賜下聖靈。字面上說：不是人人都有這權柄。他拿錢給使徒，要他們也給他這權柄（使徒們爲此咒詛了他）：
> act 8:18-20 :: !西門看見使徒按手，便有聖靈賜下 :: !把這權柄也給我 :: !叫我手按著誰，誰就可以受聖靈 :: !你想上帝的恩賜是可以用錢買的
批評者說，這只是行邪術的西門的錯誤理解：他畢竟是術士，所以一切都理解錯了。
那使徒保羅也是術士嗎？
> 2tim 1:6 :: !使你將上帝藉我按手所給你的恩賜
> 1tim 4:14 :: !你不要輕忽所得的恩賜 :: !就是從前藉着預言、在衆長老按手的時候賜給你的
使徒直接說：上帝的恩賜是藉他的按手賜下的。
回到西門的情形。使徒行傳中的這個故事是福音史家路加寫的（[[lk 1:3]]；[[act 1:1]]）。他寫的不是西門彷彿對事件有什麼錯誤的理解，而是西門只是**看見**了。他看見了什麼？福音史家路加寫道：“西門看見使徒按手，便有聖靈賜下”——這就是他所看見的。這不是西門在說，而是福音史家路加。接著從使徒彼得的話可以清楚：這確實如此——使徒能夠傳遞這上帝的恩賜，而他責備西門的，正是他想**用錢**得到**上帝的恩賜**。
## “使徒保羅的按立不是經過人？”
正教徒表明，使徒保羅的職分是教會按立的：
> act 13:2-3 :: !要爲我分派巴拿巴和掃羅 :: !於是禁食禱告，按手在他們頭上
批評者反駁說，使徒保羅不是被人按立的，並引用一節經文：
> gal 1:1 :: !不是由於人，也不是藉着人
但這指控沒有根據，因爲這裏說的是揀選的方式，而不是上帝恩賜的傳遞。
在按手在掃羅身上之前，確實是聖靈自己揀選了他，並吩咐教會把掃羅分別出來，擔任經上所說聖靈召他去的事奉。批評者引用這節經文是爲了什麼——不明白，因爲並沒有矛盾：掃羅不是由人、也不是通過人揀選的，而是聖靈自己揀選了他，吩咐教會把他分別出來擔任事奉，之後教會給掃羅按手：
> act 13:2-3 :: !聖靈說 :: !要爲我分派巴拿巴和掃羅 :: !去作我召他們所作的工 :: !於是禁食禱告，按手在他們頭上
這樣，揀選是聖靈行的，而恩典的賜下不是不經教會，而是經由教會——經由她僕人們的按手。
批評者試圖以此論證他們所建立的團體與最早的基督徒沒有任何直接聯繫，論證他們自行選立牧師和教師。顯然，自己沒有從上帝來的權柄管理並教導教會的人，不能把這樣的權柄給任何人。但他們要緊的是表明一種可能性：彷彿聖靈可以這樣作——彷彿可以不經任何與他們之前已存在的教會的聯繫，立他們的牧師擔任事奉。
然而，雖然聖靈願意作什麼就作什麼，我們在聖經裏看不到一例：上帝脫離基督所建立的合一的、看得見的教會而立人擔任事奉並拯救人。
上帝揀選了掃羅；雖然他無疑可以親自立他擔任事奉，但沒有不經自己的教會這樣做。同樣我們在最初外邦人受洗的事上也看到：埃提阿伯的太監（[[act 8:27]]）和百夫長哥尼流（[[act 10:1]]）。
1. 埃提阿伯的太監在讀聖經，卻不明白。**上帝本可以**親自教導太監並賜下洗禮的救人恩典，**但沒有脫離教會這樣做**。上帝差教會到太監那裏，教會教導他明白聖經，並在洗禮中賜下恩典。
2. 百夫長哥尼流祈禱上帝、行善事。**上帝本可以**親自把救人的恩典賜給哥尼流，**但沒有脫離教會這樣做**。他反而差天使到他那裏，吩咐他去找教會（以使徒彼得爲代表）。當使徒來到時，聖靈才降在哥尼流身上——雖然它同樣可以早些、不經使徒而降臨，但它沒有這樣做。
3. 逼迫基督徒的掃羅（未來的使徒保羅）往大馬士革去逼迫基督徒。基督以耀眼的光向他顯現；掃羅問他該作什麼。基督上帝**本可以**親自把恩典賜給掃羅，**但沒有脫離教會這樣做**，而是吩咐他到大馬士革去找教會（以使徒亞拿尼亞爲代表）；只有在那裏，使徒才藉著教會使他復原（[[act 9:17]]），賜下聖靈的恩典（[[act 9:17]]），並在洗禮中賜下洗淨他罪的救人恩典（[[act 22:16]]）。
同樣，在一切情形中，包括按立掃羅擔任特殊的使徒職分：上帝自己揀選掃羅，上帝本可以親自把他的恩賜賜給他，但沒有脫離自己的教會這樣做。聖靈向教會說話，教會給掃羅按手（[[act 13:2-3]]）。
所以，那些與教會分離的團體宣稱他們的牧師有脫離教會的特殊蒙召，在聖經裏沒有任何依據。聖經里根本沒有這樣的例子。
## “按手是從異教借來的？”
那些自行建立教會的人，首先必須證明基督一次所建立的教會已經墮落。因爲如果教會沒有墮落，那他們的新團體就不需要，只要進入基督的教會即可。爲證明教會的墮落，常用“貼標籤”的手法——貼上儘可能可怕的標籤。於是教會常被指控偏離上帝、因借用異教實踐而墮入異教，被點名的有：
- 聖殿的存在；
- 聖地；
- 聖物；
- 聖像；
- 特別的神聖之人（司祭）；
- 聖規程和聖奧祕（彷彿是影響上帝的藥方），其中包括按手。
這是極其荒唐的指控，因爲這一切都是上帝親自設立的，並且聖經裏都有直接的經文。把異教拉到這裏來，只是爲了給教會貼標籤。所有這些神聖的建築、地方、物件、行動和人，在新舊約聖經裏都有——詳見[[ru:святыня|聖物]]一文。
### 舊約中的按手
雅各以祈禱按手祝福了自己的孫子：
> gen 48:14-16 :: !以色列伸出右手來 :: !按在以法蓮的頭上 :: !又剪搭過左手來按在瑪拿西的頭上 :: !他就給約瑟祝福說 :: !賜福與這兩個童子
上帝命令先知摩西以按手立約書亞擔任事奉：
> chis 27:18,22-23 :: !嫩的兒子約書亞是心中有聖靈的 :: !你將他領來，按手在他頭上 :: !按手在他頭上，囑咐他
> vtor 34:9 :: !嫩的兒子約書亞，因爲摩西曾按手在他頭上，就被智慧的靈充滿
上帝命令以按手立利未人在聖殿供職：
> chis 8:10 :: !將利未人奉到耶和華面前，以色列人要按手在他們頭上
### 新約中的按手
> 2tim 1:6 :: !使你將上帝藉我按手所給你的恩賜
> 1tim 4:14 :: !你不要輕忽所得的恩賜 :: !在衆長老按手的時候賜給你的
> evr 6:2 :: !各樣洗禮、按手之禮
研讀聖經之後，那些指責教會彷彿在使徒之後從異教借來這些實踐及其態度的說法，就令人驚訝了——使徒們自己寫的正是上帝的恩賜**藉著**他們手的按手而賜下，並且把這作爲教導的一部分。這一切（這方式本身）不是新發明，而是在使徒之前的同一環境裏已存在了幾個世紀的東西——設立它的不是異教徒，而是上帝自己。
## “新約裏沒有稱祭司？”
“祭司職”一詞在新約的語境中出現。基督更換了祭司職，而不是廢除它：
> evr 7:12 :: !祭司的職任既已更改
基督成爲永遠的大祭司，但司祭沒有被廢除。關於他們的揀選和設立，預言裏有話：
> is 66:18-21 :: !我必將萬民萬族 :: !我也必從他們中間取人爲祭司，爲利未人
此外，實際上正是使徒們是祭司——不是隨便什麼人。舊約裏司祭有潔淨人罪的職責（[[lev 5:5-6]]）；同樣在新約裏，新的教會等次建立時，這權柄被賜給它——赦罪或不赦罪：
> in 20:21-23 :: !你們受聖靈 :: !你們赦免誰的罪，誰的罪就赦免了 :: !你們留下誰的罪，誰的罪就留下了
