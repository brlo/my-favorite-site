# 酵——影響一切的小東西
新約聖經中酵的比喻，不是把它用作本身好或壞的東西，而是用來表明小小的一分可以影響其餘的一切。放入麵粉中的酵很少，但最終會使全團都發起來。
除了酵，主也常常用鹽的比喻——鹽同樣影響其餘的一切（防腐）：
> mf 5:13 :: !你們是世上的鹽 :: !鹽若失了味
> mk 9:50 :: !鹽本是好的 :: !你們裏頭應當有鹽，彼此和睦
同時，鹽如同酵一樣，也參與舊約的祭獻：
> lev 2:13 :: !凡獻爲素祭的供物都要用鹽調和 :: !一切的供物都要配鹽而獻
# 酵的正面含義
## 酵——天國
主耶穌基督把酵比作天國。又一次，小東西要影響一切：
> mf 13:33 :: !天國好像面酵 :: !直等全團都發起來
> lk 13:20-21 :: !我拿什麼來比上帝的國呢 :: !好比面酵 :: !直等全團都發起來
# 酵的負面含義
## 酵——異端的教導
主耶穌基督向使徒們指出法利賽人和撒都該人教導的危害。他用酵的比喻表明小東西可以影響一切：
> mf 16:6,11-12 :: !你們要謹慎，防備法利賽人和撒都該人的酵 :: !乃是防備法利賽人和撒都該人的教訓
## 酵——假冒爲善
另一次，基督在數千人面前再次用酵的比喻，指出法利賽人的特點——假冒爲善的危害。又一次，假冒爲善成了影響一切的小東西：
> lk 12:1 :: !你們要防備法利賽人的酵，就是假冒爲善
## 酵——團體中不悔改的淫亂之人
使徒保羅用酵的比喻指摘哥林多團體中有不悔改的淫亂之人。淫亂之人是團體中的小部分，卻可以影響整個團體：
> 1kor 5:1,6-8 :: !風聞在你們中間有淫亂的事 :: !就是有人收了他的繼母 :: !豈不知一點面酵能使全團發起來嗎 :: !應當把舊酵除淨，好使你們成爲新團 :: !也不可用惡毒、邪惡的酵 :: !只用誠實真正的無酵餅
使徒建議除淨的不是酵本身，而是惡毒邪惡的酵：也就是把不悔改的淫亂之人趕出團體（[[1kor 5:9,11]]）。這裏使徒揭示的是舊約的含義，而不是在說餅：
> 1kor 5:7-8 :: !應當把舊酵除淨，好使你們成爲新團 :: !也不可用惡毒、邪惡的酵 :: !只用誠實真正的無酵餅
> mf 16:11 :: !這話不是指著餅說的
## 酵——團體中引人走向猶太教的人
使徒保羅用酵的比喻警告加拉太團體，他們中間有教導說爲得救必須遵守摩西律法的人，這是危險的：
> gal 5:4-5,9-10,12 :: !你們這要靠律法稱義的，是與基督隔絕，從恩典中墜落了 :: !一點面酵能使全團都發起來 :: !但攪擾你們的，無論是誰，必擔當他的罪名 :: !恨不得那攪亂你們的人，把自己割絕了
