# 舊約中接觸死人的禁令
接觸死人使人不潔（受玷污）。但親屬可以接觸自己死去的親人而不受玷污：
> lev 21:1-4 :: !祭司不可爲民中的死人沾染自己 :: !除非爲他骨肉之親的父母、兒女、弟兄 :: !和未曾出嫁作處女的姊妹，纔可以沾染自己 :: !就不可從俗沾染自己
> chis 9:6 :: !有幾個人因死屍而不潔淨，不能在那日守逾越節
> chis 19:13 :: !凡摸了人死屍、不潔淨自己的 :: !他就爲不潔淨，污穢還在他身上
> iez 44:25 :: !他們不可挨近死屍沾染自己 :: !只可爲父親、母親、兒子、女兒、弟兄和未嫁人的姐妹沾染自己
> ag 2:13 :: !若有人因摸死屍染了污穢 :: !必算污穢
# 接觸義人的遺骸
舊約時代，有人因接觸先知以利沙的聖髑而復活：
> 4ts 13:21 :: !一碰著以利沙的骸骨，死人就復活站起來了

# 新約中接觸死人
主耶穌基督接觸了睚魯死去的女兒：
> mk 5:41 :: !就拉著孩子的手，對她說
按律法，基督死在十字架上之後，不能像接觸已死之人那樣接觸他。只有上帝之母作爲親屬可以這樣作（[[lev 21:1-4]]）。然而，我們不但不定神學家約翰、尼哥底母、亞利馬太人約瑟的罪，反而稱讚他們毫無畏懼、服事我們的救主：
> mf 27:59-60 :: !約瑟取了身體，用乾淨細麻布裹好 :: !安放在自己的新墳墓裏
> mk 6:29 :: !約翰的門徒聽見了，就來把他的屍首領去，葬在墳墓裏
> mk 15:45-46 :: !就把耶穌的屍首賜給約瑟 :: !約瑟買了細麻布，把耶穌取下來 :: !安放在磐石中鑿出來的墳墓裏
> act 13:29 :: !就把他從木頭上取下來，放在墳墓裏
