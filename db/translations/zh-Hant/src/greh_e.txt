# 殺人是罪
> ish 20:13; vtor 5:17 :: !不可殺人
> mf 19:18; mf 5:21; mk 10:19; lk 18:20; rim 13:9 :: !不可殺人
無論是尚在母腹中、還是已經出生的嬰兒，都是人。殺人是罪。
在古老的基督教文獻（《十二宗徒訓言》）中直截了當地說到這一點：
<blockquote><p>「<strong>不可墮殺胎中的嬰兒</strong>，也不可在出生後殺死他。」</p></blockquote>（<a href="https://azbyka.ru/otechnik/pravila/didahe_rus/">《十二宗徒訓言》</a>）
# 嬰兒也是人。無論在母腹內，還是在母腹外
聖經把遠早於預產期（懷孕三四個月）出生的人也稱爲嬰孩：
| 甫滿週歲的嬰孩要用聲音說話；懷孕的婦人要在三四個月時生下不足月的嬰孩，他們要存活，並且健壯。 ||| ru 3ezd 6:21
讚美那些拒絕殺死剛出生嬰兒的收生婆：
> ish 1:17,20-21 :: !收生婆敬畏上帝 :: !竟存留男孩的性命
先知施洗約翰在母腹中、在出生之前，就已被聖靈充滿。也就是說，並不是什麼「將來會成爲人的東西」，而是先知約翰自己，還在母腹中時，就成了上帝之靈的殿：
> lk 1:15 :: !從母腹裏就被聖靈充滿了
上帝在母腹中所造的，不是什麼「後來才成爲人」的東西，而是人本身；這個人後來只是從母腹中出來，也就是出生。上帝在人出生之前就使他成聖：
> ier 1:5 :: !我未將你造在腹中 :: !你未出母胎，我已分別你爲聖
忍受苦難的先知約伯也這樣說。上帝在母腹中造的是我們，而不是什麼「後來會成爲人」的東西：
> iov 31:15 :: !造我在腹中的 :: !將他與我摶在腹中的豈不是一位嗎
人在母腹中的發育過程被描述爲上帝自己的創造行動。這被描述爲：人已經存在，卻像穿衣服一樣穿上肉體，爲要出來到世界上。約伯所說的不是某種後來才成爲約伯的質料；他直接把這胚胎說成是他自己：難道不是你給我穿上肉體的嗎？
> iov 10:8-12 :: !你不是倒出我來好像奶，使我凝結如同奶餅嗎？你以皮和肉爲衣給我穿上，用骨與筋把我全體聯絡
先知大衛也描述說：
> ps 139:13,15-16 :: !我在母腹中，你已覆庇我 :: !我在暗中受造，在地的深處被聯絡 :: !我未成形的體質，你的眼早已看見了 ~~ 俄文本編號爲 Пс 138:13,15-16（聖詠編號相差一）。

# 罪
「行邪術」一節還包括其餘的一切：
- 占卜（任何形式的），
- 招魂、通靈，
- 相信法術（任何法術，黑法術、白法術），
- 相信護身符的能力（包括紅繩），
- 被咒語加持過的物件，
- 星座運勢（占星術），
- 求問特異功能者，
- 巫師、
- 法師、
- 女巫、
- 占卜者、
- 行邪術的、
- 替人「解眼」、「解咒」、「解祖咒」的老太婆，
- 等等：
> vtor 18:9-14 :: !占卜的、觀兆的、用法術的、行邪術的 :: !用迷術的、交鬼的、行巫術的、過陰的 :: !凡行這些事的，都爲耶和華所憎惡 :: !聽信觀兆的和占卜的
