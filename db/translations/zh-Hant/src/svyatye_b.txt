# 新約中的聖物
## 聖潔的聖殿
耶路撒冷聖殿是真聖所的像：
> evr 9:24 :: !基督並不是進了人手所造的聖所（這不過是真聖所的影像）
> in 2:13-16 :: !看見殿裏有賣牛、羊、鴿子的 :: !把牛羊都趕出殿去 :: !不要將我父的殿當作買賣的地方
> lk 24:53 :: !常在殿裏稱頌上帝
> act 2:46 :: !他們天天同心合意恆切的在殿裏
使徒在聖殿裏祈禱，基督在那裏於異象中向他顯現：
> act 22:17 :: !在殿裏禱告的時候 :: !魂遊象外
敵基督（大罪人）要坐在上帝的殿裏（顯然，要坐在上帝的殿裏，那殿必須是：不是宙斯的殿、不是雷神的殿，而是上帝的殿）：
> 2sol 2:3-4 :: !並有那大罪人 :: !抵擋主，高抬自己 :: !甚至坐在上帝的殿裏自稱是上帝
## 聖地

> mf 24:15 :: !那行毀壞可憎的 :: !站在聖地

## 聖物
聖膏——是聖物。聖殿和一切以聖膏膏抹的殿內器皿——是聖物。在人中間，只有亞倫的後裔可以用它膏抹，使他們成爲司祭：
> ish 30:23-33 :: !按作香之法，調和作成聖膏油 :: !要用這膏油抹會幕和法櫃 :: !要使這些物成爲聖，好成爲至聖，凡挨着的都成爲聖 :: !要膏亞倫和他的兒子 :: !這膏油是聖的，你們也要以爲聖 :: !這人要從民中剪除
祭壇——至聖的聖物：
> ish 40:9-10 :: !使壇成聖，就都成爲至聖
> ish 29:37 :: !壇就成爲至聖，凡挨着壇的都成爲聖
香的配方（在祭壇上焚燒的香料）——至聖的聖物：
> ish 30:34-38 :: !作成清淨聖潔的香 :: !你們要以這香爲至聖 :: !要以這香爲聖，歸耶和華 :: !這人要從民中剪除

# 對異議的回應
## “上帝不住人手所造的殿”
反對聖殿的教會批評者引用一節經文：
> act 7:46-49 :: !其實，至高者並不住人手所造的 :: !你們要爲我造何等的殿宇
然而這絲毫不能證明反對聖殿，因爲當大衛想爲上帝建造殿宇時，上帝早已命令先知摩西建造會幕、祝聖它、在其中設立司祭、遵守規程、擁有聖物（約櫃）、並設立了違反上帝所立秩序的死刑。這節經文只是說明：上帝無處不在，而不只在聖殿裏。同時，聖殿——是上帝自己的設立，而不是人的設立，更不是彷彿從異教借來的東西。
