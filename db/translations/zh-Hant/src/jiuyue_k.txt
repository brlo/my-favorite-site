## 上帝預先警告：他將因何把以色列從應許之地趕出
### 警告
猶太民族曾受到警告：他們得到上帝所應許的地，不是因爲他們的義。先前的民族因罪惡滿盈而從上帝的地土上被趕出。以色列被上帝領進這地時則受到警告：若他們也照樣犯罪，上帝也必將他們從自己的地上趕出：
> vtor 7:1 :: !從你面前趕出許多國民 :: !共七國的民，都比你強大
> vtor 9:4-8 :: !你心裏不可說：『耶和華將我領進來得這地，是因我的義。』 :: !乃是因這些國民的惡 :: !並不是因你的義，也不是因你心裏正直 :: !你本是硬著頸項的百姓 :: !你當記念不忘，你在曠野怎樣惹耶和華你上帝發怒 :: !要滅絕你們
> lev 18:3,24-28 :: !那裏人的行爲，你們不可效法 :: !在這一切的事上，你們都不可玷污自己 :: !故此你們要守我的律例、典章 :: !免得你們玷污那地的時候，地就把你們吐出
> vtor 28:15,58,63-64 :: !這以下的咒詛都必追隨你 :: !你若不謹守遵行 :: !也要照樣喜悅毀滅你們，使你們滅亡 :: !你們從所要進去得的地上必被拔除 :: !耶和華必使你們分散在萬民中
### 以色列民所作的，甚至比先前因罪被趕出的那些民族更壞，因此也被趕出
> 4ts 21:9-11 :: !比耶和華在以色列人面前所滅的列國更甚 :: !比先前亞摩利人所行的更甚
> iez 16:23,34-35,45-48 :: !你行這一切惡事之後 :: !你這妓女啊，要聽耶和華的話 :: !你母親是赫人，你父親是亞摩利人 :: !你的姐姐是撒瑪利亞 :: !你的妹妹是所多瑪 :: !你一切所行的倒比他們更壞 :: !你妹妹所多瑪與他的衆女，尚未行你和你衆女所行的事
在耶穌基督被釘十字架之前，猶太民族所受的最大刑罰是約70年的期限——巴比倫之囚。而在棄絕並殺死基督之後，猶太民族被從自己的地土上趕出約2000年，聖殿至今沒有歸還。
