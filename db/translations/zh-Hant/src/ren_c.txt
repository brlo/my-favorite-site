# 起初的基督徒們也患病
提摩太（以弗所主教）患胃病，使徒保羅因他的病吩咐他稍微放鬆齋戒：
> 1tim 5:23 :: !因你胃口不清，屢次患病 :: !再不要照常喝水
使徒保羅自己也得了一種病，免得他自高：
> 2kor 12:7 :: !有一根刺加在我肉體上 :: !免得我過於自高
以巴弗提（使徒保羅的同工）患病，幾乎要死：
> fil 2:25-27,30 :: !以巴弗提 :: !因爲你們聽見他病了 :: !他實在是病了，幾乎要死 :: !幾乎至死
使徒保羅把一個犯罪的基督徒交給撒但，讓他受疾病的打擊：
> 1kor 5:3,5 :: 要把這樣的人交給撒但，敗壞他的肉體，使他的靈魂在主耶穌的日子可以得救
不配地參與聖餐禮曾使許多基督徒患病、軟弱、甚至死亡：
> 1kor 11:30 :: !在你們中間有好些軟弱的與患病的
舊約的義人也患病
> gen 27:1 :: !以撒年老，眼睛昏花，不能看見
# 身體受苦的益處
## 有助於離棄罪
> 1pet 4:1 :: !在肉身受過苦的，就已經與罪斷絕了
## 免於驕傲
> 2kor 12:7 :: !所以有一根刺加在我肉體上，就是撒但的差役要攻擊我，免得我過於自高
## 管教
| 這樣，因痛苦纏身，**他的狂傲，方開始止息**；因天主的懲罰，**痛苦逐漸增加，他也逐漸覺悟**。 ||| sb 2mak 9:11
# 上帝能以疾病施行懲罰
上帝能因罪孽和罪惡施行懲罰：
> ier 30:15 :: !你的痛苦無法醫治 :: !我因你的罪孽甚大，罪惡衆多，曾將這些加在你身上
上帝因米利暗（亞倫和摩西的姊妹）毀謗摩西而以癩病懲罰她：
> chis 12:8-10 :: !耶和華就向他們二人發怒而去 :: !米利暗長了大痲瘋，有雪那樣白 :: <<你們毀謗
因以色列民偏離對上帝的敬拜，瘟疫臨到以色列民：
> chis 25:3,9 :: !耶和華的怒氣就向以色列人發作 :: !那時遭瘟疫死的，有二萬四千人
救主指出罪是疾病的原因：
> in 5:14 :: !你已經痊癒了，不要再犯罪，恐怕你遭遇的更加利害
上帝也能施憐憫，護佑人免於疾病
> ish 15:26 :: !你若留意聽耶和華你上帝的話 :: !我就不將所加與埃及人的疾病加在你身上，因爲我耶和華是醫治你的
# 並非一切疾病都出於罪
