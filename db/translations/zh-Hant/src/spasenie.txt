# 救恩是什麼
**救恩**——與上帝同在的永生（[[rim 2:5-8]]；[[mf 19:17]]），脫離死亡的救恩（[[iak 5:19-20]]），更新的、得著榮耀的生命（[[fil 3:21]]；[[2pet 1:3-4]]）。
## 與上帝同在的永生
> mf 18:8 :: 進入永生
> mf 19:17 :: 你爲什麼以善事問我呢 :: 你若要進入永生
## 成神
> 2pet 1:3-4 :: !上帝的神能已將一切關乎生命和虔敬的事賜給我們 :: 又寶貴、又極大的應許 :: !就得與上帝的性情有分
> fil 3:21 :: 將我們這卑賤的身體改變形狀，和他自己榮耀的身體相似
[[in 17:21-23]]；[[1in 3:2]]；[[ps 82:6]]；[[gal 2:20]]；[[rim 8:14,16]]

## 行義的纔是義人
> 1in 3:7-8 :: !行義的纔是義人 :: 犯罪的是屬魔鬼
## 義人僅僅得救
義人——遵行上帝公義的人（[[iez 33:13-16]]）。罪人——違揹上帝公義而行的人，即犯罪的人。就連義人也僅僅得救。照此推論，罪人就完全不能得救了：
> 1pet 4:18 :: !義人僅僅得救
## 可以口稱認識上帝，行爲卻背棄他
> lk 6:46 :: !卻不遵我的話行呢
> tit 1:16 :: 說是認識上帝 :: !行事卻和他相背
上帝所不喜悅的行爲中，有異端（[[gal 5:20]]），也有在信徒中間製造分裂（[[in 17:20-21]]；[[1kor 1:10]]）。
## 使罪人從迷路上轉回的行爲，能遮蓋許多的罪
若真實的信徒使鄰人離棄錯謬，這行爲就能遮蓋許多的罪。如果救恩單憑信心成就，那麼使鄰人離棄錯謬就只對鄰人有益，對使人迴轉的人卻毫無益處，也不會遮蓋他的罪（既然你已因信得救，還有什麼罪需要遮蓋呢？）：
> iak 5:19-20 :: !轉回 :: !救一個靈魂不死 :: !遮蓋許多的罪
## 勸勉信徒務要竭力進入上帝的安息
就是說，若不竭力，信徒也可能進不去：
> evr 4:11 :: !務必竭力進入那安息
## 品德與進入永遠的國
信徒若有這些品德，就不會沒有成效。在這幾樣上不斷長進，必得著進入國的寬闊之路；沒有品德的，就是眼瞎：
> 2pet 1:5-11 :: !有了信心，又要加上德行 :: 知識 :: 節制 :: 忍耐 :: 虔敬 :: 愛弟兄的心 :: 愛衆人的心 :: !你們若充充足足的有這幾樣，就必使你們在認識我們的主耶穌基督上，不至於閒懶不結果子了 :: 人若沒有這幾樣，就是眼瞎，只看見近處的，忘了他舊日的罪已經得了潔淨 :: !應當更加殷勤，使你們所蒙的恩召和揀選堅定不移 :: !這樣，必叫你們豐豐富富的得以進入我們主救主耶穌基督永遠的國
---
這樣，沒有行爲的信心不能救人，沒有信心的行爲同樣不能救人。

# 救恩不是一次性的事件，而是終生的過程
必須去作成救恩（希臘文 κατεργάζεσθε——行出來、作成、達成、獲得、贏取）：
> fil 2:12 :: 作成你們得救的工夫
使徒如同在受生產之苦，直到基督在受洗的基督徒裏面成形。也就是說，基督並不是自動地、在一瞬間就在他們裏面成形的：
> gal 4:19 :: 我爲你們再受生產之苦，直等到基督成形在你們心裏
> 2tim 4:7 :: 當跑的路我已經跑盡了
救恩只是應許給人，而不是已經到手（是“必得救”，而不是“已得救”）：
> mf 10:22; mf 24:13 :: !忍耐到底的
> otkr 2:10 :: !務要至死忠心，我就賜給你
使徒雖然自知沒有作過違揹上帝的事，卻不審判自己，也不以此自稱爲義，而是等候上帝的審判：
> 1kor 4:1-5 :: 執事 :: 管家 :: 所求於管家的，是要他有忠心 :: !連我自己也不論斷自己 :: !但判斷我的乃是主 :: 時候未到，什麼都不要論斷
## 論達到基督徒的完全
使徒和所有基督徒一樣，爲要得著不能壞的冠冕而奔跑、勞苦，擔心自己被棄絕：
> 1kor 9:25-27 :: 要得能壞的冠冕 :: 要得不能壞的冠冕 :: 我奔跑 :: 攻克己身，叫身服我 :: !自己反被棄絕了
> fil 3:12-14 :: 這不是說我已經得著了，已經完全了 :: 我乃是竭力追求 :: 我不是以爲自己已經得著了 :: 向着標竿直跑
## 將要得救的人和滅亡的人
正如將要得救的人還未得救，將要滅亡的人也還未滅亡。兩者都在路上，都可能改變方向：將得救的還可能走向滅亡，將滅亡的還可能走向救恩：
> 2kor 2:15 :: !得救的人 :: !滅亡的人
許多人想要進入天國，卻進不去：
> lk 13:24; mf 7:14; mf 7:13 :: <<你們要努力進窄門 :: !許多人想要進去，卻是不能
不僅許多信徒，甚至連奉基督的名行異能的人，也進不了天國：
> mf 7:22-23 :: 許多 :: 傳道 :: 趕鬼 :: 行許多異能 :: !我從來不認識你們，你們這些作惡的人，離開我去吧

# 對異議的回應
## “信徒不受審判”
> in 5:24 :: 不至於定罪
簡要地說：這裏所說的是，真實的信徒和遵行救主話語的人（[[lk 6:47-49]]；[[1in 2:17]]）不會被判罪受刑罰；但誰是這些信徒和遵行的人，要由基督自己在審判時決定（[[1kor 4:3-5]]），因爲如上所示，普世的審判正是從教會開始（[[1pet 4:17-18]]），而人人都要受審判。
我們更詳細地看這一點。
這節經文應當按照聖經全部的教導來理解。聖經裏既說到得救必須遵行誡命（[[lk 6:47-49]]；[[1in 2:17]]），也說到必須受洗（[[in 3:5]]）、領受聖餐（[[in 6:53-54]]），以及許多別的。不能只看一些經文，而對其他經文視而不見。
既然不能排除得救所需的其他條件，那麼這裏所說的是指那些藉洗禮進入教會、藉參與聖餐活在教會（基督的身體）裏、遵行誡命、認識上帝的旨意並照著生活的信徒。如果這樣行，就不會來到審判臺前被判罪。但誰是這樣行的人？唯有審判者基督知道。所以，首先所有人都要來到審判臺前，這在其他經文裏有直接的說明。
人人都要受審判：
> 2kor 5:10 :: 我們衆人必要在基督臺前顯露出來 :: 所行的 :: 或善或惡
這裏所說的正是**信徒**：
> rim 14:10 :: 論斷弟兄 :: 輕看弟兄 :: 我們都要站在上帝的臺前
> ekl 12:14 :: <<因爲人所作的事 :: 人所作的事 :: 上帝都必審問 :: 無論是善是惡
但僅僅說人人都要受審判還不夠。而且，審判正是從教會開始，也就是從信徒開始：
> 1pet 4:17-18 :: !審判要從上帝的家起首 :: !先從我們起首
總之，信徒並且遵行的人（至於是誰——由基督作爲審判者決定）不會來到審判臺前被判罪。
這些**許多信徒**顯然以爲自己已經得救、不必受審判，然而他們雖然信了，卻要被定罪爲作惡的人：
> mf 7:22-23 :: 許多 :: 奉你的名傳道 :: 奉你的名趕鬼 :: 奉你的名行許多異能 :: 我從來不認識你們，你們這些作惡的人，離開我去吧
總之，基督要審判所有人，在審判中把人彼此分開：
> mf 25:31-32 :: !萬民 :: !他要把他們分別出來 :: !綿羊山羊
## “人稱義不是因行律法”
> gal 2:16 :: 人稱義不是因行 :: !律法 :: 乃是因信耶穌基督 :: 不因行 :: !律法 :: 稱義，因爲凡有血氣的，沒有一人因行 :: !律法 :: 稱義
這裏所說的是摩西律法的行爲，人不能靠它稱義。在加拉太書中這是全書的主題，起因是關於外邦人是否需要受割禮的爭論。受割禮並不需要，因爲我們得救不是靠摩西律法的行爲，而是靠對基督的信心和這信心的行爲（參見上文“不只信心，行爲也是得救所必需的”一節）。
## “你們得救是本乎恩，也因著信”
> ef 2:5,8-9 :: 你們得救是本乎恩 :: 你們得救是本乎恩，也因著信 :: 乃是上帝所賜的 :: 也不是出於行爲
這裏所說的不是每個人個人的得救，而是得救的可能性臨到世界（即這可能性得以開啟）。
### 1. 得救可能性的開啟——是恩賜
在基督以前，人沒有得救的可能。基督以後，得救成爲可能，得救的途徑也被建立。人作了什麼，使得救成爲可能？什麼也沒有作，人類的罪反而越來越多。救恩之路的建立，是上帝賜給人的**恩賜**。這恩賜不是罪惡的人類掙來的：
> rim 5:6-9 :: 因我們還軟弱的時候，基督就按所定的日期爲罪人死 :: !惟有基督在我們還作罪人的時候爲我們死，上帝的愛就在此向我們顯明了
### 2. 救恩的途徑——是恩賜
同樣，要走上得救之路並獲得救恩的途徑，對具體的人來說，需要的正是信心。他被引入教會，在洗禮中重生，在聖膏中領受聖靈的恩賜，在聖餐禮中與基督聯合——這一切都是**因信心而白白領受的恩賜**。不要求人先掙得這個恩賜。
### 3. 走過得救之路——一生之中，靠上帝的幫助（[[1kor 15:10]]）以人的行爲（[[rim 2:5-8]]）來成就（[[otkr 2:10]]）
接下來說到在基督裏受生的目的——就是善行：
> ef 2:10 :: !行善
若沒有這些善行，如聖經其他地方所說，人就不能得救，因爲沒有行爲的信心是死的（[[iak 2:20]]），人稱義是因著行爲，不是單因著信（[[iak 2:24]]），人人都要受審判（[[2kor 5:10]]），而審判必按行爲進行（[[2kor 5:10]]；[[ef 6:7-8]]）。
因此，曾向人類開啟的救恩，不僅要以信心、也要以行爲去領受；而如上所示，這是一個過程，而且是艱難的過程，它的終點許多人達不到：
> lk 13:24; mf 7:14; mf 7:13 :: <<你們要努力進窄門 :: !許多人想要進去，卻是不能
## 悔改的強盜只來得及相信，沒有作過任何行爲嗎？
悔改的強盜得救，是作爲舊約以色列的一部分，與上帝立有舊約，憑著對救主的信心，並且來得及作了一些事。
爲什麼說在舊約裏？因爲經上記著，基督要用聖靈施洗（[[lk 3:16]]；[[mf 3:11]]；[[mk 1:8]]），而基督應許在昇天之後才差遣聖靈來（[[in 16:7]]；[[in 14:16]]；[[in 14:26]]；[[in 7:38-39]]），也就是在五旬節。經上沒有寫強盜被傳講悔改和受洗，也沒有寫聖靈降在強盜身上（不同於後來其他古代基督徒的情形）。這樣，悔改的強盜還在舊約之內、教會建立之前得救，沒有經過洗禮和聖餐禮這兩個聖奧祕。
然而，強盜也作了一件事——謙卑地領受了所加給他的刑罰，承認這是自己應得的，結出了與悔改的心相稱的果子（[[mf 3:8]]）。
> lk 23:41 :: 我們是應該的，因我們所受的與我們所作的相稱
謙卑地忍受苦難，不發怨言責怪上帝，不在別人身上尋找罪魁，也不定別人的罪——這是基督徒的行爲（[[pr 3:11]]）。我們的始祖墮落之後，不是責備自己，而是責備別人，甚至多少責怪上帝：
> gen 3:12-13 :: <<你所賜給我 :: 你所賜給我、與我同居的女人，她把那樹上的果子給我，我就喫了 :: 那蛇引誘我，我就喫了
而強盜責備的是自己，並且甘心領受刑罰。這是行爲，而且極配得上基督徒的心志。
他雖是強盜，並沒有被高舉爲偉人之一，也沒有得著救主右邊或左邊所預備的座位（[[mk 10:40]]）；但他是因信心得救的，並且還有他來得及作成的那件小行爲。所以，強盜到底還是有行爲，而不只有信心。
還要注意的是，並不是強盜自己宣稱得救，而是基督對他作出審判。強盜的話裏看不出任何對得救的確信；相反，他明白自己不會與上帝同享永生，所以只懷著對憐憫的謹慎盼望，求基督在他進入自己國的時候記念他（照強盜自己的想法，那時他不會在那個國裏）。
## “凡求告主名的，就必得救”
> rim 10:13 :: 凡求告主名的，就必得救
> act 2:21 :: 凡求告主名的，就必得救
有人可能產生疑問：難道只要求告主，無論怎樣求告、無論行什麼，就都必得救？其實，這裏的“凡”是說，能得救的不僅是猶太人，而是任何民族的人。
這些話使徒只是引用。最初是舊約中對猶太人所說的預言。使徒在此提醒這些話，並指出它們應驗的時候已經到了。舊約中說這話的是先知約珥：
> iol 2:32 :: 凡求告耶和華名的就必得救
先知的話是對以色列民說的，以色列民堅信上帝只拯救以色列人。於是給以色列民一個預言：時候將到，得救的不再只是以色列人，而是任何求告上帝的民族。
總之，這話出自舊約——上帝只與以色列民立舊約；新約則是與教會立的，教會召聚了萬民，因爲在教會裏民族已不再有意義（[[kol 3:11]]）。這裏說的正是這一點，從上下文可以直接看出：民族對得救沒有意義：
> rim 10:11-13 :: 凡信他的人，必不至於羞愧 :: !猶太人和希利尼人並沒有分別 :: !凡求告主名的，就必得救
聖經其餘的部分，並不因此失去必要性。
怎樣得救？遵守誡命——主說：
> mf 19:17 :: <<你若要進入永生 :: 當遵守誡命
求告上帝的話把這廢除了嗎？當然沒有。
經上說，不從水和聖靈生的，就不能見上帝的國，也不能進上帝的國。這同樣沒有廢除：
> in 3:3,5 :: 不能見上帝的國 :: 不能進上帝的國
關於聖餐禮的話也沒有廢除。沒有它，人就不能在自己裏面有生命，也不能在末日復活（爲與上帝同活）：
> in 6:53-54 :: <<你們若不吃 :: 你們若不吃人子的肉，不喝人子的血，就沒有生命在你們裏面 :: 在末日我要叫他復活
尼哥拉一黨人和許多異端也求告上帝，然而他們作爲異端和分裂教會者，被判失去上帝的國：
> gal 5:19-21 :: 情欲的事都是顯而易見的 :: !結黨、紛爭 :: !異端 :: !行這樣事的人必不能承受上帝的國 ~~ *“結黨、紛爭”（διχοστασίαι）——分裂、分派。
總之，“凡”是指任何民族的人，而不只是猶太人。關於教會，使徒這樣說：
> kol 3:8,10-11 :: <<但現在你們要棄絕 :: !希利尼人、猶太人 :: !化外人、西古提人
## “代贖的祭”
有些主張救恩只憑信心（不憑行爲）的人，講到一種稱爲“代贖的祭”的救贖理論，其含義如下：正如以撒被獻爲祭時有羊羔代替，使以撒得以存活；同樣，基督代替罪人被獻爲祭，使罪人得以存活。這樣，既然上帝父把他的怒氣傾倒在兒子身上，他就不再向信主的罪人發怒。於是信主的罪人與上帝同活就不再有攔阻。
代贖之祭的理論看來並不符合真理。它出自一個錯誤的前提：問題在於上帝（他向罪人發怒）。爲了“糾正”上帝（這念頭本身就何等僭妄），兒子必須死。而人自己完全不必悔改，因爲上帝將向兒子發怒，於是（彷彿在上帝那邊的）問題就解決了。這樣的理論不能被當作真理，因爲它違揹常識。顯然，問題不在於上帝。與上帝同在的永生之中，任何不潔淨的都不能進入：
> otkr 21:23,27 :: 凡不潔淨的，並那行可憎與虛謊之事的，總不得進那城
