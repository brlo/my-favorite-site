## 沒有空虛的多言
上面已經說到，需要恆常的祈禱、在祈禱中的堅持和忍耐（[[lk 18:1-7]]）。但上帝不是被話語重複的頻度安撫的。祈禱必須與上面列舉的一切結合：信心、公義、蒙上帝喜悅的行爲、遠離罪惡、清潔的心、饒恕委屈、與鄰人和睦等等。而外邦人**不改變自己**和自己的生活，指望喊叫到他們的神那裏；那些神彷彿在睡覺，所以彷彿需要更大聲、更頻繁地喊叫（見[[3ts 18:26-28]]）。
> mf 6:7-8 :: !用許多重複話 :: !你們不可效法他們
主耶穌基督自己常常整夜祈禱，有時也重複自己的祈禱：
> mk 14:39 :: !說的話還是與先前一樣

# 前言
爲亡者祈求某種憐憫，這是愛心之舉，即被對上帝和對鄰人的愛所引導之人的舉動。我們不知道主對於某一個爲亡者所發的祈求會怎樣決定，然而我們有盼望的依據，也有促使我們關懷的愛。這依據是什麼？依據——是上帝的啟示，我們從其中得知：上帝是全能的，他掌握著死亡和陰間的「鑰匙」；有些罪甚至在未來的世代也不會被赦免（由此可以明白，還有別的罪）；上帝曾呼召我們以各種不同的祈求來到他面前。我們也知道，罪人所受的刑罰不是[[ru:bib_Неодинаковая_мера_воздаяния:_мучения_и_блаженства|一樣的尺度]]，義人的福樂也不是一樣的程度；所以即使一個人不能得救，我們也盼望他的命運得到減輕。在舊約里人們就關懷亡者（見[[ru:молитвы-за-умерших#HH-Ветхий-Завет-Забота-о-прощении-грехов-умерших|下文]]），最早的基督徒也關懷他們（詳見[[ru:91USaqiJ_молитвы_за_умерших|爲亡者的祈禱]]）。
促使這一切的，是那“永不止息”的愛（[[1kor 13:8]]）。

# 罪可以藉教會的祈禱得赦免
這就是說，罪得到赦免不僅是在人自己悔改、自己求赦免的時候，也是在別人爲人求赦免的時候：
> iak 5:14-15 :: !該請教會的長老來 :: !他若犯了罪，也必蒙赦免
癱瘓者的朋友們費了很大的力氣才把朋友帶到基督面前。主因他們的信心赦免了癱瘓者的罪，並醫治了他：
> mk 2:5 :: !耶穌見他們的信心 :: !小子，你的罪赦了
# 罪甚至在死後也可以得到赦免

## 爲亡者祈禱和獻祭
猶太人爲陣亡的戰士祈禱，求他們的罪得赦免。又送銀子到耶路撒冷聖殿，爲亡者獻上贖罪祭，使他們從罪中得潔淨：
| 事後，猶大率領兵馬，到了阿杜藍城；因爲已到第七日，他們就在那裏照例自潔，過了安息日。第二天，由於事不宜遲，猶大的部隊便出去收殮陣亡的屍體，好把他們安葬在祖墳裏，與親族在一起。當時在每個死者的內衣下，發現都有雅木尼雅偶像的符籙，這原是法律禁止佩帶的；衆人便都明白這正是他們陣亡的原因。於是衆人稱讚秉公審判及揭示隱密的上主，同心哀禱，**求使所犯過惡，得以完全赦免**。隨後，英勇的猶大勸勉民衆避免犯罪，因爲人都親眼看見這些陣亡者因罪所受的罰。於是大衆募集了二千銀“達瑪”，送到耶路撒冷作贖罪祭的獻儀：**他作的是一件很美妙高超的事，因爲他想念著復活**；如果他不希望那些死過的人還要復活，**爲亡者祈禱，便是一種多餘而糊塗的事**。何況，他還想到爲那些善終的人保留下的超等報酬：這實在是一個聖善而虔誠的思想。**爲此，他爲亡者獻贖罪祭，是爲叫他們獲得罪赦**。 ||| sb 2mak 12:38-45

# 按範本祈禱
舊約裏有一部偉大的、受上帝默感的祈禱書——詩篇。它由先知兼君王大衛寫成。它曾在聖殿中使用，詩篇是人們在登上臺階時唱的。
當使徒們求主教他們祈禱時，他們所依據的是：先知施洗約翰已經教導過自己的門徒祈禱：
> lk 11:1 :: !求主教導我們禱告 :: !像約翰教導他的門徒
之後基督賜下祈禱的範本——用他自己的話：
> lk 11:2-4; mf 6:9-13 :: !你們禱告的時候，要說 :: !赦免我們的罪
就是說，給出祈禱文、按範本（規矩）祈禱——這是完全正常的，是聖經的實踐。

## 主耶穌基督的祈禱極其長久
他整夜祈禱：
> lk 6:12 :: !整夜禱告上帝
他從傍晚祈禱到幾乎清晨。夜分爲四更；第四更是夜的最後一段，幾乎已是早晨。基督祈禱了幾乎整夜：
> mf 14:23,25 :: !他就獨自上山去禱告 :: !到了晚上，只有他一人在那裏 :: !夜裏四更天
基督在自己的祈禱過一個小時之後來叫醒使徒們，這樣重複了兩次。可以推測，他祈禱了約三個小時：
> mk 14:32,35,37,39-41 :: !等我禱告 :: !俯伏在地，禱告說 :: !不能儆醒片時嗎 :: !耶穌又去禱告 :: !第三次來
## 比喻
在賜下祈禱的範本——“我們在天上的父”——之後，主隨即講了關於在祈禱中堅持和忍耐的比喻：
> lk 11:5-8 :: !但因他情詞迫切的直求，就必起來照他所需用的給他
寡婦和法官的比喻：
> lk 18:1-7 :: !要人常常禱告，不可灰心 :: !上帝的選民晝夜呼籲他
# 祈禱可以是短的
在講了關於恆常和堅持祈禱的比喻之後，主又講了那個稅吏的短禱蒙他喜悅的比喻；不過如福音史家所說明，這個比喻講的是那些自以爲義的人。最終，基督直接指出稅吏蒙上帝喜悅之處：對自己和自己的義看得很低：
> lk 18:9-14 :: !仗著自己是義人，藐視別人的 :: !那稅吏遠遠的站著，連舉目望天也不敢 :: !上帝啊，開恩可憐我這個罪人 :: !凡自高的，必降爲卑；自卑的，必升爲高
# 對異議的回應
## 不可用許多重複話
在馬太福音裏，“我們在天上的父”祈禱之前記著基督的話：祈禱中不必說多餘的話：
> mf 6:7-8 :: !用許多重複話 :: !你們不可效法他們
主耶穌基督自己常常整夜祈禱，有時也重複自己的話：
> mk 14:39 :: !說的話還是與先前一樣

# 向約櫃叩拜
先知約書亞在約櫃前叩拜——櫃的施恩座上有基路伯的像，櫃內有聖物：
> nav 7:6 :: !俯伏在地，直到晚上
# 向以三人形像顯現的上帝叩拜
亞伯拉罕向以三個人形像顯現的上帝叩拜：
> gen 18:1-2 :: !向亞伯拉罕顯現出來 :: !見有三個人在對面站著 :: !俯伏在地
上帝爲什麼以形像顯現？——因爲上帝在本性上是看不見的，從來沒有人見過他（[[1tim 6:16]]；[[in 1:18]]）。然而聖經說的是上帝顯現（希伯來文 יְהוָ֔ה——雅威）。
# 向物件叩拜
向杖：經上記著“以色列在牀頭上敬拜”（[[gen 47:31]]），而在七十士譯本里是“在杖頭上”（[[evr 11:21]]）。
# 向天使叩拜

> nav 5:14 :: !約書亞就俯伏在地下拜
> gen 19:1 :: !羅得正坐在所多瑪城門口 :: !臉伏於地下拜
