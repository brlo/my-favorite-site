# 魔鬼（撒但）——墮落的天使
魔鬼是上帝所造衆多天使中的一位，但他不願日後事奉上帝，也就是從上帝面前墮落了、墮落了：
> iez 28:12-19 :: !你是那受膏遮掩約櫃的基路伯 :: !後來在你中間又察出不義 :: !以致犯罪 :: !你因美麗心中高傲 :: !又因榮光敗壞智慧 :: !我已將你摔倒在地 :: !我使火從你中間發出燒滅你
這些從上帝面前墮落的天使，用不同的詞來稱呼：鬼（[[mf 8:31]]）、魔（[[tov 6:8]]）、撒但的差役（[[2kor 12:7]]）、污鬼（[[mf 10:1]]）、「黑鬼」（民間的稱呼）。撒但還被稱爲蛇（[[gen 3:1]]；[[is 27:1]]；[[otkr 12:9]]；[[otkr 20:2]]）、龍（[[otkr 12:9]]；[[otkr 20:2]]）、明亮之星（[[is 14:12]]）、鱷魚（利維坦）（[[is 27:1]]）、這世界的王（[[in 12:31]]）、惡者（[[mf 13:19]]）、謊言的靈（[[3ts 22:22]]）。魔鬼不是一種沒有位格的感覺，不是人心中某種抽象的衝動，也不是寓意。他是真實的存有，是一個位格。魔鬼是最初犯罪的存有：
> 1in 3:8 :: !犯罪的是屬魔鬼，因爲魔鬼從起初就犯罪
