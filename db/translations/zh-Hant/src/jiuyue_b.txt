# 上帝在石版上賜給先知摩西的十條誡命
上帝的誡命並不限於這些，但正是這些誡命寫在了石版上。
## 1
> ish 20:2-3 :: !我是耶和華你的上帝 :: !除了我以外，你不可有別的神 ~~ 並見 [[vtor 5:6-7]]；[[lev 19:2]]。
## 2
> ish 20:4-5 :: !不可爲自己雕刻偶像 :: !不可跪拜那些像；也不可事奉它 ~~ 並見 [[vtor 5:8-9]]；[[lev 19:4]]。
## 3
> ish 20:7 :: !不可妄稱耶和華你上帝的名 ~~ 並見 [[vtor 5:11]]；[[lev 19:12]]。
## 4
> ish 20:8-10 :: !當記念安息日，守爲聖日 :: !六日要勞碌作你一切的工 :: !但第七日是向耶和華你上帝當守的安息日 ~~ 並見 [[vtor 5:12-15]]；[[lev 19:3]]；[[lev 19:30]]；[[ier 17:21]]；[[neem 13:15-18]]。
## 5
> ish 20:12 :: !當孝敬父母，使你的日子在耶和華你上帝所賜你的地上得以長久 ~~ 並見 [[vtor 5:16]]；[[lev 19:3]]。
## 6
> ish 20:13; vtor 5:17 :: !不可殺人 ~~ 並見 [[lev 19:17-18]]。
## 7
> ish 20:14; vtor 5:18 :: !不可姦淫 ~~ 並見 [[lev 19:20]]。
## 8
> ish 20:15; vtor 5:19 :: !不可偷盜 ~~ 並見 [[lev 19:11]]；[[lev 19:13]]。
## 9
> ish 20:16; vtor 5:20 :: !不可作假見證陷害人 ~~ 並見 [[lev 19:11]]。
## 10
> ish 20:17; vtor 5:21 :: !不可貪戀人的房屋 :: !也不可貪戀人的妻子、僕婢、牛驢，並他一切所有的 ~~ 並見 [[lev 19:17]]。
