# 看不見者的看得見之像
## 宇宙
上帝創造世界，爲要叫人由看得見的認識看不見的：人通過觀看看得見的受造物，認識那看不見的造物主：
> rim 1:19-20 :: 上帝的事情，人所能知道的，原顯明在人心裏 :: 上帝已經給他們顯明 :: 眼不能見 :: 藉着所造之物就可以曉得
## 聖殿
看得見的地上的聖殿，是看不見的天上實體的像。先知得到命令：要照在山上所指示的樣式建造聖殿：
> ish 25:8-9,40 :: 造聖所 :: 都要照我所指示你的樣式 :: 要照著在山上指示你的樣式
使徒指出，聖殿是按真聖所的像建造的：
> evr 9:24 :: !人手所造的聖所（這不過是真聖所的影像）
> act 7:44 :: 法櫃的帳幕 :: 照所看見的樣式

## 里昂的愛任紐（二世紀）論聖殿是天上的實體的象徵
聖殿按天上實體之像的建造，由聖里昂的愛任紐（二世紀）所證實。愛任紐引用神學家約翰的啟示錄，說地上的事物作天上事物的像是合宜的——這些天上的事物也是由同一位上帝所造：
“所以，正如他[上帝]在這些事[祭物]上並無所缺，卻願意我們爲自己而行這些事，免得我們不結果子；同樣，聖言也把關於祭物的誡命賜給了（猶太）民族，雖然他並不需要它們，爲要叫他們學習事奉上帝；基於同樣的原因，他願意**我們也常常、按時地把禮物帶到祭壇前**。
這樣，**在天上有祭壇**，因爲我們的祈禱和獻禮是朝那裏去的；也有**聖殿**，正如約翰在啟示錄裏所說：‘天上上帝的殿開了’（啟 11:19），還有帳幕：‘看哪，上帝的帳幕在人中間，他要與人同住’（啟 21:3）。祭物、獻禮和一切祭品，（猶太）民族是按預像領受的，正如摩西在山上所受的指示——是來自同一位上帝，他的名如今在教會裏、在萬民中被稱頌。但是，**在我們周圍所安排的地上的事物，作天上事物的像是合宜的**——這些天上的事物也是由同一位上帝所造。**否則，他就無法把屬靈事物的相似之物拉近到我們的悟性面前**。”
（[俄文](https://azbyka.ru/otechnik/Irinej_Lionskij/protiv-eresej/4)《駁異端》卷四，第18-19章）

# 基督命令不要稱呼人爲師、爲父
> mf 23:2,5-9 :: 喜愛筵席上的首座，會堂裏的高位 :: 稱呼他拉比 :: !但你們不要受拉比的稱呼 :: !也不要稱呼地上的人爲父
這話不能按字面理解，正如關於截去肢體的話（[[mf 5:29-30]]），以及基督說他來不是叫地上太平、乃是叫地上動刀兵的話（[[mf 10:34-35]]）不能按字面理解一樣。這裏教導的是謙卑：使信徒不去追求被人稱呼“拉比、拉比”（[[mf 23:7]]），得到這些稱呼之後也不驕傲自高，而要明白：至高的權柄、真正的父和師傅——是上帝。
重要的是從上下文出發正確理解這話的意思，否則就會得出連孩子也不能稱呼自己的父親爲父的結論，儘管上帝在誡命里正是這樣稱呼他們的（[[vtor 5:16]]）。同樣，也不能說任何教師都不可以稱爲教師，儘管教會裏毫無疑問有教師。從聖經我們看到，使徒們並沒有迴避這些稱呼。

# 基督徒的理想
基督徒的理想——一生只有一個婚姻。
# 對平信徒的寬免
如果妻子或丈夫死了，雖然新的婚姻不受鼓勵（因爲基督徒相信來生和死人普遍的復活），但作爲寬免的措施是允許的——使徒說過這一點，爲的是不叫人陷入某種致死的重罪而徹底滅亡：
> 1kor 7:8-9 :: 寡婦 :: !與其慾火攻心，倒不如嫁娶爲妙
> 1tim 5:14 :: 我願意年輕的寡婦嫁人
同樣，救主在論到不可離婚時，也爲了淫亂（變心）的情形開了例外：
> mf 5:31-32 :: 若不是爲淫亂的緣故
這樣，如果配偶死了或變了心，新的婚姻是可能的。但仍然不是無限制的，而只是作爲寬免的措施，總共只可以有兩次。
循著類似的推理，教會又爲此加上了一些別的原因，例如配偶有生命危險等等（[俄文](https://azbyka.ru/otechnik/dokumenty/osnovy-sotsialnoj-kontseptsii-russkoj-pravoslavnoj-tserkvi/#0_10_3)）。
