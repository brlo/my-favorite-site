> mf 26:26-28 :: !你們拿著吃，這是我的身體 :: !因爲這是我立約的血，爲多人流出來，使罪得赦

# 聖奧祕中是救主真實的體和血
## 餅——基督將爲世人的生命而捨去的肉
在聖餐中，信徒領受耶穌基督真實的（真正的）體和真實的血——他爲世人的生命而捨棄它們，把自己作爲祭物獻在十字架上：
> in 6:48-51 :: !我所要賜的糧就是我的肉，爲世人之生命所賜的
這裏主直接宣告：這從天降下的糧就是他的肉——這肉他**現在**就有，並且**將來**要爲世人的生命而捨去。這裏只是應許。此刻他還沒有舍這肉。教導他已經賜下，而在將來，他要交付於死刑的不是教導、不是象徵、不是紀念，而是他真實的肉。正是他的肉纔是那從天降下的糧——他在聖餐聖奧祕中以餅和酒的形式分給門徒吃。

# 聖餐的舊約預表
## 逾越節的羔羊
無殘疾的（一歲的、沒有缺陷的）公羔羊應當真實地**死**，爲人的罪；然後真實地被**吃掉**，全部吃完。基督是羔羊，字面地應驗了這一預表的兩部分：
- 他真實地（不是象徵地）爲人的罪而死；
- 他真實地（不是象徵地）被吃。
> ish 12:3,5-6 :: !各人要按著父家取羊羔 :: !要無殘疾、一歲的公羊羔 :: !以色列全會衆把羊羔宰了
> ish 12:21-22,25 :: !把這逾越節的羊羔宰了 :: !打在門楣上和左右的門框上 :: !就要守這禮
> is 53:5-7 :: !哪知他爲我們的過犯受害 :: !因他受的刑罰，我們得平安 :: !耶和華使我們衆人的罪孽都歸在他身上 :: !他像羊羔被牽到宰殺之地
> act 8:32 :: !他像羊被牽到宰殺之地
> ier 11:19 :: !我卻像柔順的羊羔被牽到宰殺之地
> in 1:29,36 :: !看哪！上帝的羔羊，除去世人罪孽的 :: !看哪！這是上帝的羔羊
> 1pet 1:18-19 :: !乃是憑著基督的寶血，如同無瑕疵、無玷污的羔羊之血
> otkr 5:12 :: !曾被殺的羔羊
> otkr 7:17 :: !因爲寶座中的羔羊必牧養他們
> otkr 14:1 :: !見羔羊站在錫安山
## 嗎哪
曠野中的嗎哪，它供養以色列民從埃及的奴役走向應許之地的路上的力量。嗎哪在曠野裏是真實地被吃的。它真實地保護人不至死亡、賜人生命（曠野裏沒有別的食物）：
> ish 16:4,31 :: !我要將糧食從天降給你們 :: !每天收每天的分 :: !以色列家叫嗎哪
> chis 11:9 :: !嗎哪也隨著降下
因爲嗎哪隻是預像、是將來之事的影子，而不是實物本身，所以它沒有賜下永恆的生命，只是延長地上的生命、使人免於餓死；最終那些猶太人還是死了，正如人都死一樣。但基督說，吃他的必永遠活著：
> in 6:31-33,35,48-50 :: !我們的祖宗在曠野吃過嗎哪 :: !乃是我父將天上來的真糧賜給你們 :: !上帝的糧就是那從天上降下來賜生命給世界的 :: !我就是生命的糧 :: !你們的祖宗在曠野吃過嗎哪，還是死了 :: !叫人喫了就不死
> in 6:54-55,57-58 :: !吃我肉、喝我血的人就有永生 :: !吃我肉的人也要因我活著 :: !不像你們的祖宗吃過嗎哪還是死了
再者，如果把猶太人從埃及的奴役到應許之地的整個路程看作基督徒從罪的奴役到天國的路程，那麼嗎哪在這裏也字面地指向聖餐：
- 真實的埃及奴役——真實的罪的奴役。
- 真實地走海牀脫離奴役——真實的洗禮（[[1kor 10:2]]）。
- 真實的四十年曠野漂泊——教會中真實的今生。
- 真實的嗎哪和水——上帝所賜救主真實的體和血。
- 真實地應許給猶太人的土地——真實的國，只是如今不是地上的，而是天上的。

## 吃樹上的果子
人類真實地喫了樹上的果子而遠離上帝（[[gen 3:6]]）；人類也照樣藉吃十字架之樹的果子歸向上帝。人藉不順服之樹遠離上帝，又藉十字架順服之樹歸回（[[fil 2:8]]；[[mf 16:24]]）。那樹上的果子奪去生命，而這樹上的果子使人歸回生命。人從哪扇門出去，就從哪扇門進來。那時主說：“不可吃”（[[gen 2:17]]）——他們喫了。如今他說“拿著吃”（[[mf 26:26]]）——許多人犯著從前同樣的錯誤，只是反過來——不吃。雖然那時和現在，遵守這誡命都不難：
> gen 3:3 :: !你們不可吃，也不可摸，免得你們死
> gen 2:17 :: !你不可吃，因爲你吃的日子必定死
> mf 26:26 :: !你們拿著吃，這是我的身體
> in 6:58 :: !吃這糧的人，就永遠活著
## 感恩的平安祭
舊約裏有兩類平安祭：
- **讚美**祭（תודה，todah）；
- **感恩**祭（或救恩祭）（שלמים shelamim 或 נדר neder）。
平安祭包括獻餅和牲祭。**讚美**的平安祭用無酵餅獻上，而若另外還獻**感恩**的平安祭，則用有酵餅獻上：
> lev 7:13 :: !要用有酵的餅和爲感謝獻的平安祭
在新約裏，向上帝獻餅的聖奧祕稱爲**“聖餐禮”（感恩祭，希臘文——感恩）**，因爲基督自己在分給門徒之前**祝謝了**上帝並祝福了餅（[[lk 22:19]]；[[1kor 11:23-24]]）。
就是說，在正教會的聖餐禮中，今天字面地行的正是這些：
- 取有酵的餅；
- 獻上感恩；
- 只是不與它一同獻上祭牲，因爲祭物、羔羊、逾越節——是被釘死又復活的基督。
要注意，無酵餅稱爲困苦餅（“ἄζυμα, ἄρτον κακώσεως”，[[vtor 16:3]]），而有酵餅的平安祭稱爲感恩祭或救恩祭（תֹּודַ֥ת——感恩，σωτηρίου——救恩，[[lev 7:13]]）。
*注：* *祭牲的肉或者當天吃掉、不留到早晨（如逾越節），或者可以吃兩天，但嚴格禁止留到第三天。若沒有在第三天之前吃完，剩餘的就要用火焚燒，否則祭物就被上帝拒絕，成爲玷污和罪。這把我們引向救主的復活——第三天墳墓空了。就是說，在這裏有酵餅屬於新約——救主的復活。*

# 對餅和酒的祝福
那位非物質的上帝——他從前從無中創造了宇宙，安排了普世的洪水，使太陽停住，在任何地方奇妙地賜下不同的食物和水，分開江河和海洋，多次改變物件的本質（杖、水），他自己成爲物質的（道成肉身），以自己的祝福使餅和魚增多（[[mf 14:15-21]]；[[mf 15:32-38]]；[[mk 6:35-44]]；[[mk 8:1-9]]；[[lk 9:12-17]]；[[in 6:5-13]]），爲生來瞎眼的造了眼睛，使腐爛的肉身復原——在與門徒的逾越節晚餐上，不只是分了餅和酒，而是祈禱之後**祝福了它們**，稱它們爲自己的體和血：
> mf 26:26-28 :: !祝福，就擘開遞給門徒 :: !你們拿著吃，這是我的身體 :: !又拿起杯來，祝謝了
不能把這祝福理解爲無足輕重的空話。

# 對異議的回應
## “基督把自己比作門，是比喻？”
與民衆交談時，基督把自己比作羊圈的門：
> in 10:7 :: !我就是羊的門
既然基督在這裏比喻地稱自己爲門，那麼是否意味著聖餐中關於體和血的話也應當比喻地理解？完全不是。在與門比較之前，救主講了牧人從門進羊圈、而賊從別處爬進去的比喻。把自己比作門，救主只是結束這個比喻，向民衆解釋它。基督對民衆總是用比喻講話，而與門徒單獨在一起時則解釋一切：
> mf 13:10-11 :: !對衆人講話爲什麼用比喻呢 :: !因爲天國的奧祕，只叫你們知道，不叫他們知道
> mf 13:13 :: !所以我用比喻對他們講
> mk 4:11 :: !若是對外人講，凡事就用比喻
> mk 4:33-34 :: !若不用比喻，就不對他們講 :: !沒有人的時候，就把一切的道講給門徒聽
在錫安的樓房裏**與門徒單獨在一起**講聖餐時，基督沒有附加任何比喻，更沒有關於體和血的比喻——就是說，基督是按字面講的，而不是比喻。與民衆交談時，基督在講聖餐的話上也沒有附加任何比喻。他從關於舊約嗎哪的談話出發。這不是比喻，而是現實。猶太人真實地喫了嗎哪，爲了真實地不死。爲了向聽衆指明嗎哪隻是預像，主才說：他們雖然喫了嗎哪，嗎哪隻救他們免於飢餓，最終他們還是死了（正如人人都死），而吃他的人必不死（因爲這已經不是預像，而是預像所指之物——賜永恒生命的真正從天降下的糧）：
> in 6:57-58 :: !吃我肉的人也要因我活著 :: !不像你們的祖宗吃過嗎哪還是死了
## “我不再喝葡萄汁”
有人反對在聖餐中對體和血作實在的理解，引用基督在最後晚餐上關於葡萄汁的話。
三位福音史家——馬太、馬可和路加——都講到葡萄汁（[[mf 26:29]]；[[mk 14:25]]；[[lk 22:18]]）。路加福音史家與馬可和馬太不同，更詳細地描述了晚餐，提到喝過的幾杯：
### 第一杯
> lk 22:15-18 :: !我很願意在受害以先和你們吃這逾越節的筵席 :: !耶穌接過杯來，祝謝了 :: !你們拿這個，大家分著喝 :: !從今以後，我不再喝這葡萄汁
基督吩咐把杯中的東西分給門徒。這杯被分了。到這裏還沒有聖餐，沒有關於體和血的話；有的只是逾越節的晚餐。在這杯酒之後，基督立刻說了那句關於他不再喝葡萄汁的話：
> lk 22:18 :: !從今以後，我不再喝這葡萄汁
而只有**飯後**（[[lk 22:20]]；[[1kor 11:25]]）基督才舉行聖餐：拿起餅，又拿起杯（這已是另一杯，因爲第一杯已經喝了），遞給門徒，只是現在才說到自己的體和血：
### 第二杯
> lk 22:19-20 :: !這是我的身體，爲你們舍的 :: !飯後也照樣拿起杯來 :: !這杯是用我血所立的新約
這樣，在前一部分舉行的只是猶太人傳統的逾越節晚餐，按習俗必喝**四杯酒**（摻水的）並感謝上帝。聖經裏沒有喝這四杯酒的命令。這只是猶太人的習俗。猶太逾越節晚餐的習俗在猶太的米示拿中有詳細描述：
“米示拿第一篇
（ א ）在逾越節前夕，從晚祭之前起，人不可吃到天黑。即使在以色列中最窮的人也不可以不側身而食。並且**不可少給他四杯酒**，即使是從施濟處領的。”
（[俄文](https://toldot.com/articles/articles_30013.html)《米示拿·應戶約》第10篇）
第一次基督只是行了這習俗：拿起杯，祝謝，遞給自己的門徒，一句關於這是他的血的話也沒有說，只說叫他們彼此分著喝——他們顯然也這樣做了。杯喝了。第一次完全沒提餅。飯後才說到餅，又再說到杯，並且只是這時纔出現關於基督的體和血的話。所以關於葡萄汁的話屬於第一杯——葡萄的酒；而關於基督的血的話屬於第二杯——在其中奧祕地遞給門徒的已經不是酒，而是基督真實的血，這正是我們所信的。
## “叫人活著的乃是靈，肉體是無益的”（不帶來益處）
教會聖餐教訓的反對者宣稱，基督只是象徵性地講到吃他的肉。他們引用下面的話：
> in 6:63 :: !肉體是無益的
象徵論的擁護者這樣解釋這些話：彷彿吃基督的肉不帶來任何益處。
我們則表明，“肉體無益”的話說的是肉體式的思維——它不帶來益處。這是說那些只按地上的方式思想的人，粗糙地、按世俗的方式：只用他們在自己生活中習慣見到的方式，不能把思想提升到屬靈的奧祕。
在聖經裏我們可以遇到許多別的地方，這樣的話被用於只按地上方式思想的人：
> mf 16:17 :: !這不是屬血肉的指示你的
> gal 1:16 :: !我就沒有與屬血氣的人商量
> gal 3:3 :: !你們既靠聖靈入門，如今還靠肉身成全嗎
> ier 17:5 :: !倚靠人血肉的膀臂
這些人以爲他們面前只是一個普通人、約瑟的兒子。一個普通人怎麼能把自己的肉給他們喫？——只能像所有人那樣：從自己身上撕下來給他們喫。這樣的思維沒有帶給他們任何益處。他們大大地憂愁，說：“**這話甚難，誰能聽呢？**”（[[in 6:60]]），就離開了。
然而基督不是普通人，而是全能的上帝。他設立聖奧祕：在其中他賜生命的體和血以奧祕的方式、藉上帝的能力、以餅和酒的形式被分予。爲此需要屬靈地思想，爲那理智並不總能明白的奧祕性舉行留下位置，爲基督話語的超越地上秩序的超性成就留下位置：
> in 6:53 :: !你們若不吃人子的肉，不喝人子的血，就沒有生命在你們裏面
## 爲什麼要“吃上帝”？
這樣的問題多是穆斯林問的。新教徒也向教會提這個問題，只是形式稍有不同，實質相同。
對這個問題的回答可以很長，但這裏只給出總的想法：領聖體使人進入與上帝基督最親密的相通：不僅是屬靈的，也是身體的——因爲上帝造人不僅用靈魂，也用身體。
實際上，除了亞當和夏娃，每個人從出現在這個世界上的最初時刻起，就是以另一個人的身體——自己母親的身體——爲食的。如果他不是這樣，就不能有生命，不能成長髮育，必定滅亡——當胎兒（胚胎）不能著牀時，事情正是如此。
嬰兒出生時，他的身體是由母親的身體構成的。母親的身體交出自己，把生命給了嬰兒，這樣兩者（母親和嬰兒）處於身體的相通之中。即使出生之後，嬰兒還要長時間以母親的身體爲食，因爲嬰兒所喝的奶是在母親的身體裏由她的血造成的。所以，在這個意義上，奶——就是母親的血。
兩個過程（生育和聖餐）的設立都是上帝的。
認識了上帝所造的人性及其誕生和滋養的過程，在聖餐中承認類似的過程就不足爲奇了——在聖餐中我們喫的已不是母親的身體，而是基督上帝的身體；這樣我們與上帝進入的不僅是屬靈的，也是身體的相通——與基督完全的相通，靈與體：
> ef 5:30 :: !因我們是他身上的肢體
