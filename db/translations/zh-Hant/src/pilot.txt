聖經的經文雖然是在上帝之靈的感動下寫成的（即上帝所默示的），卻不是上帝口述的筆錄，書寫者也不是上帝手中鉛筆那樣沒有個性的工具。牧人出身的先知用樸素的語言寫作，宮廷出身的先知則以飽學之士的筆法寫作；兩人都採用與自己生活方式相稱的比喻。例如，論到使徒保羅，別的使徒寫道，他的書信中有難以理解的地方：
> 2pet 3:16 :: 有些難明白的 :: >>難明白的
而使徒保羅自己也說，他在言語上是粗俗的，在知識上卻不是：
> 2kor 11:6 :: 我的言語雖然粗俗 :: >>卻不粗俗
也就是說，他盡力而寫，但在知識上並無虧損。事實上，使徒保羅作爲受過教育的法利賽人，確實運用了複雜的意義結構。更進一步，使徒們有時明確宣告，所寫的是自己的意見：
> 1kor 7:25 :: 我沒有主的命令 :: 自己的意見告訴
更準確地說，聖經乃是上帝與人的共同工作（協作，συνεργία）：
> 1kor 3:9 :: 與上帝同工的 ~~ συνεργοί，直譯爲「與上帝同工者」
