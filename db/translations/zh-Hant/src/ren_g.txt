# 私審判簡介
<a href="https://azbyka.ru/mytarstva">私審判</a>是東正教會的一項教導：在人死後，墮落的天使企圖奪取人的靈魂。這樣，靈魂要經受可怕的試煉；在試煉中，上帝的天使盡力保護義人的靈魂，把他們帶到上帝面前。這一教導以象徵性、形象性的方式表達爲若干「關卡」，靈魂在每一關上都要就某些情欲受審問。在這裏，天使是施行上帝公義的工具。
# 在邪惡的日子抵擋天空屬靈氣的惡魔，勝過一切
魔鬼是空中掌權者的首領：
> ef 2:1-2 :: !順服空中掌權者的首領
需要有所準備，以便在邪惡的日子（死亡之日）勝過一切：
> ef 6:11-13 :: !要穿戴上帝所賜的全副軍裝，就能抵擋魔鬼的詭計 :: !天空屬靈氣的惡魔 :: !好在磨難的日子抵擋 :: !並且成就了一切，還能站立得住
# 若無上帝的許可，魔鬼不能觸及義人；他尋求獲得許可來轄制他們
魔鬼尋求如何控告或誣告人，以便轄制他：
> iov 2:4-6 :: !他在你手中，只要存留他的性命
> iud 1:9 :: !爲摩西的屍首與魔鬼爭辯的時候
# 魔鬼時刻尋找可吞吃的人
> 1pet 5:8 :: !你們的仇敵魔鬼，如同吼叫的獅子，遍地遊行，尋找可吞吃的人
# 天使被差遣服事那將承受救恩的人
> evr 1:13-14 :: !天使豈不都是服役的靈、奉差遣爲那將要承受救恩的人效力嗎
# 天使在死後「接去」義人的靈魂
靈魂在與身體分離之後是會移動的。靈魂必須走完通往它將來居所的路程。
天使照管了義人拉撒路的靈魂，但對財主卻沒有這樣的記載：
> lk 16:19-26 :: !後來那討飯的死了，被天使帶去放在亞伯拉罕的懷裏 :: 財主也死了，並且埋葬了 :: !他在陰間受痛苦 :: !你該回想你生前享過福，拉撒路也受過苦；如今他在這裏得安慰，你倒受痛苦
罪人的靈魂會在不知不覺中被取去：
> lk 12:19-21 :: !無知的人哪，今夜必要你的靈魂 :: !凡爲自己積財，在上帝面前卻不富足的，也是這樣
# 在死亡的時辰魔鬼來到基督面前，但他無物可指責基督
在受難的前一天，基督說到魔鬼的臨近；魔鬼在基督裏面毫無所有，不能以罪指責他：
> in 14:30 :: !這世界的王將到，他在我裏面是毫無所有
但對其他的人就不是這樣：
> 1in 3:8 :: !犯罪的是屬魔鬼
# 基督是藉着云彩、經由空中昇天的
> act 1:9-10 :: !他就被取上升，有一朵雲彩把他接去 :: !當他往上去
# 基督也將同樣再來
> fil 3:20 :: !並且等候救主
> act 1:11 :: !你們見他怎樣往天上去，他還要怎樣來
