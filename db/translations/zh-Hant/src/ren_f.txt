# 身體與靈魂
## 逼迫者不能殺死靈魂
主耶穌基督說不要怕逼迫者，因爲他們只能殺死身體，卻不能殺死靈魂，不能傷害靈魂。否認靈魂死後存在的人聲稱，靈魂與身體一同死亡，如此則逼迫者殺死的不只是身體，也是靈魂——但這與基督的話相矛盾：
> mf 10:28 :: 那殺身體 :: !不能殺靈魂的
> lk 12:4 :: !那殺身體以後不能再作什麼的，不要怕他們
## 已死的先知摩西的靈魂在大博爾山顯現
救主在大博爾山顯聖容的時刻，使徒們看見了已經死去的先知摩西顯現，正與基督談論他即將面臨的十字架苦難。也就是說，先知雖然死了（[[vtor 34:7]]；[[nav 1:2]]）（見<a href="#HH-上帝复活了先知摩西">下文註釋</a>），卻沒有消失，也沒有失去知覺：他正**與基督交談**：
> mf 17:3 :: !摩西 :: !同耶穌說話
> lk 9:29-31 :: !忽然有摩西、以利亞兩個人同耶穌說話 :: !談論耶穌去世的事
## 使徒論死後的生命
使徒保羅說，當地上的帳幕（身體）拆毀時，我們有天上永存的房屋：
> 2kor 5:1,4 :: !我們這地上的帳棚若拆毀了 :: !必得上帝所造，不是人手所造，在天上永存的房屋 :: !並非願意脫下這個，乃是願意穿上那個
<hr>
在另一處——或許是最重要的一處——使徒寫道，他情願快些死去，以便明確地進入與上帝同在的生命，他稱死亡爲「益處」。如果使徒死後就消失或沉睡，那他什麼也沒有獲得，只是失去（知覺）。那樣的話，急忙去死、去進入無所作爲的狀態就沒有任何意義了。更合理的做法是：活著、傳道、建立教會、與上帝相通、幫助教會（**儘可能長久地不撇下教會**——這是靈魂不朽學說的反對者們一貫忽略的主要思想），住在地上的身體裏。但使徒知道自己將進入天上與上帝同在的生命，所以情願快些脫離身體中的地上生命：
> fil 1:21-24 :: !我死了就有益處 :: !情願離世與基督同在，因爲這是好得無比的
*否認靈魂死後存在的人，通常忽略所提註釋中的論據，而說：「使徒不會察覺睡夢中飛逝的時間，會立刻在復活中與基督一同醒來」。然而，如果使徒並不是立刻進入與基督同在的生命，而只是進入無知覺的無所作爲，那麼，當使徒緊接著明明寫道住在肉身中更是要緊的時候，急忙**撇下教會**就沒有任何意義了。
<hr>
使徒出離身體時，相信他會到主那裏，因此再次表示寧願離開身體。他指出，無論是住在身內還是離開身外，重要的是蒙上帝喜悅：
> 2kor 5:6,8-9 :: !我們住在身內，便與主相離 :: !更願意離開身體
使徒住在身體裏，如同住在聖殿中（[[ru:человек-храм-Божий|人——上帝的殿]]），但不久他必須離開身體：
> 2pet 1:13-14 :: !趁我還在這帳棚的時候 :: !我脫離這帳棚的時候快到了
使徒寫道，他曾被提到天上——或是在身內，或是在身外：
> 2kor 12:2 :: !或在身內，我不知道，或在身外，我也不知道
使徒指出靈魂的永恆性：
> 2kor 4:16,18 :: !外體雖然毀壞，內心卻一天新似一天 :: !所不見的是永遠的
## 受審判的是活**在身體裏**時所做的行爲，而不是身體之外的行爲
上帝所要審判的，只是人在身體中活著時所做的事：
> 2kor 5:10 :: !按著本身所行的
## 舊約的記述
認爲人的死不僅是身體的毀滅、也是靈魂的毀滅，這種想法是不正確的：
| **惡人們胡思亂想自語說**：“我們的生命又短促，又多愁；人的死期一到，又沒有辦法補救，也從不見有人從陰府回來。我們原是偶然而生，過後我們又好像未曾生存過；我們鼻中的氣息只是一陣煙霧，思想亦不過是心動迸出的火花；**火花一旦熄滅，身軀即變成灰土，魂魄即像輕風消散**。 ||| sb prs 2:1-3
同時：
| **邪曲的思想，使人離開天主**；愚人試探全能者，只有使自己蒙羞， ||| sb prs 1:3
| **義人的靈魂在天主手裏**，痛苦不能傷害他們。**在愚人看來，他們算是死了**，認爲他們去世是受了懲罰，**離我們而去，彷彿是歸於泯滅**；其實，**他們是處於安寧中**； ||| sb prs 3:1-3
# 對否認死後生命的撒都該人的駁斥
在所有猶太黨派（法利賽人、撒都該人、艾賽尼人等）中，只有一派——撒都該人——相信人死後歸於消失（[[act 23:8]]）。主嚴厲地駁斥他們，指責他們的謬誤和不明白聖經：
> mf 22:29 :: !你們錯了，因爲不明白聖經，也不曉得上帝的大能
> mk 12:27 :: !上帝不是死人的上帝，乃是活人的上帝 :: !你們是大錯了
# 耶穌基督的人性靈魂
主耶穌基督死後，他的靈魂下到了陰間：
> ps 16:10; act 2:27 :: !你必不將我的靈魂撇在陰間
> act 2:31 :: !他的靈魂不撇在陰間
在陰間，基督向那些從世界洪水時代起就在那裏的神魂（靈魂）宣講：
> 1pet 3:18-20 :: !按著肉體說，他被治死；按著靈性說，他復活了 :: !他藉這靈曾去傳道給那些在監獄裏的靈聽 :: !挪亞預備方舟、上帝容忍等待的時候
> 1pet 4:5-6 :: !就是死人也曾有福音傳給他們
> ef 4:8-9 :: !既說升上，豈不是先降在地下嗎
最終，基督掌管死人，也掌管活人：
> rim 14:9 :: !因此基督死了，又活了，爲要作死人並活人的主
# 義人死後在天上的生命
爲基督被殺的靈魂與他在天上同活，並且知道地上發生的事（他們的冤至今未伸）：
> otkr 6:9-11 :: !有爲上帝的道併爲作見證被殺之人的靈魂 :: !聖潔真實的主啊！你不審判住在地上的人，給我們伸流血的冤，要等到幾時呢 :: !於是有白衣賜給他們各人 :: !等著一同作僕人的和他們的弟兄，也像他們被殺，滿足了數目
# 爲基督殉道的人住在天上
> otkr 12:11-12 :: !自己所見證的道 :: !他們雖至於死，也不愛惜性命 :: !諸天和住在其中的
義人住在天上，而我們這些住在地上的人，如今就已走近天上凱旋的教會——走近義人的神魂：
> evr 12:22-23 :: !你們乃是來到 :: !天上的耶路撒冷 :: !諸長子之會所共聚的總會 :: !被成全之義人的靈魂
常保童身的人無論基督往哪裏去都跟隨他：
> otkr 14:4-5 :: !這些人未曾沾染婦女 :: !他們原是童身 :: !羔羊無論往那裏去，他們都跟隨他
死人受審判，陰間交出在它裏面的死人：
> otkr 20:12-13 :: !我又看見死了的人 :: !死了的人都憑著這些案卷所記載的，照他們所行的受審判 :: !死亡和陰間也交出其中的死人
# 批評
## 上帝復活了先知摩西？
東正教徒爲靈魂死後有知覺的存在辯護，提出這樣的論據：先知摩西雖然死了（[[vtor 34:7]]；[[nav 1:2]]），卻顯現並**與基督交談**：
> mf 17:3 :: !摩西 :: !同耶穌說話
反對東正教會的人（特別是基督復臨安息日會信徒）回答說，這彷彿是因爲上帝接升並復活了先知摩西。他們所依據的不是聖經，而是僞經《摩西昇天記》（因爲他們無法直接引用懷愛倫的話）。
我們（他們也同樣）不認爲僞經是有權威的文本。但問題在於，即便在這部僞經中——至少在保存下來的部分裏——也沒有關於先知摩西復活的話。相反，書中將這樣的話歸於摩西：他要「歸到他列祖那裏」（<a href="https://azbyka.ru/otechnik/Biblia2/apokrificheskie-apokalipsisy/15#sel=15:41,15:57;27:1,27:7">來源</a>）。
此外，先知的復活與聖經相矛盾，因爲正是基督——死者中的初熟果子：
> 1kor 15:20 :: !成爲睡了之人初熟的果子
我們也知道，沒有一個人（這話是對人說的）升過天，沒有一個先知升過天：
> in 3:13 :: !除了從天降下仍舊在天的人子，沒有人升過天
> act 2:29,34 :: !大衛並沒有升到天上
關於在基督十字架祭獻和他的復活之前，所有的人死後都下到陰間的詳情：
[[ru:9VFT_До_жертвы_Христовой_ветхозаветные_праведники_сходили_в_ад|在基督祭獻之前，舊約的義人們下到陰間]]
## 靈魂不朽的學說就是相信魔鬼所說「不一定死」的話嗎？
靈魂學說的反對者（復臨信徒）這樣控告東正教徒：上帝說「你們必定死」，而魔鬼說「你們不一定死」，彷彿這就意味著，相信靈魂死後存活的信仰就是相信魔鬼的話：「你們不一定死」。相應地，相信靈魂在身體死後存活的人，被他們控告爲相信魔鬼的謊言。
這控告聽起來響亮，但這一想法本身與上下文有嚴重的矛盾和問題。上帝說的不僅是「你們必定死」，而是說：你們喫的日子必定死——即在吃那禁樹果子的那一天：
> gen 2:16-17 :: !你吃的日子必定死
靈魂生命學說的反對者把「必定死」這句話理解爲最簡單直接的意思：身體的死亡、人一切生命活動的終止、人存在的終結（至少是有知覺的存在的終結）。
人在吃果子的那一天發生了這種被理解的死嗎？——沒有，亞當死得晚得多，活到九百三十歲（[[gen 5:5]]）。這意味著什麼？——意味著上帝所說的是另一種死。魔鬼所否認的也正是另一種死。
而如果不是這樣，那就不得不承認：上帝說人在吃果子的那天必死，是撒了謊，而魔鬼反倒說了實話——「你們不一定死」——因爲畢竟，那一天並沒有發生粗淺意義（身體意義）上的死亡。但我們無論如何不能承認：上帝（道路、真理、生命——[[in 14:6]]）撒了謊，而魔鬼（說謊的、說謊之人的父——[[in 8:44]]）說了實話。然而，靈魂學說反對者們的解釋恰恰把人引向這個結論。
爲了走出這個死衚衕，他們必定要把話語的一部分作比喻式的重新解釋：
- 死亡本身按字面理解，
- 而死亡的日子卻不按字面理解。
東正教會的解釋沒有這樣的缺陷：
- 死亡的日子按字面理解，
- 死亡本身也按字面理解——只是針對人的屬靈狀態而言。不過，在身體狀態上確實也發生了變化：人至少看見了自己是赤身露體的。
始祖確實在那天就死了，但這一死——不是消失，而是一種與上帝隔絕的狀態，一切罪人都處在這種狀態中。基督——上帝自己——也把沒有上帝的生命狀態稱爲死：
> mf 8:21-22 :: !任憑死人埋葬他們的死人
> in 5:24 :: !是已經出死入生了
> otkr 3:1 :: !按名你是活的，其實是死的
使徒們也這樣說。他們曾活在死的狀態中：
> ef 2:1-2 :: !死在過犯罪惡之中 :: !行事爲人
> 1tim 5:5-6 :: !正活著的時候也是死的
也就是說，死的狀態在亞當和夏娃犯罪墮落之後立刻就來臨了——這是一種內在的、沒有上帝的生命狀態。在這個意義上，魔鬼說「你們不一定死」時撒了謊。他們正如上帝所說的那樣死了——就在那一天。
如此，這些控告並不嚴重——它們本身就帶有矛盾，並且脫離聖經的上下文。
