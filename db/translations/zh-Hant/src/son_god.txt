# 使徒在衆人面前稱基督爲上帝，基督認可了他的信仰（[[in 20:28-29]]）
這是最無可爭辯的一段。這裏具備一切必要的條件，使人確信使徒是把他當作真上帝來信的：在場沒有一個使徒反駁他，連基督自己也認可了這信仰。這裏的“θεὸς”（上帝）一詞甚至帶有冠詞“ὁ”——這就排除了反對方的一切異議。這節經文讓人看到，基督所被稱爲的，正是最高意義上的那同一位上帝：
> in 20:28-29 :: 我的主！我的上帝！ :: 你因看見了我纔信
| Ὁ κύριός μου καὶ **<u>ὁ</u> θεός** μου. λέγει αὐτῷ ὁ Ἰησοῦς, Ὅτι ἑώρακάς με πεπίστευκας; μακάριοι οἱ μὴ ἰδόντες καὶ πιστεύσαντες ||| gr in 20:28-29
對此，基督神性教導的反對者只會用一句缺乏說服力的話來搪塞，說：“使徒不過是太激動，因驚訝而喊叫”。但這與經文相矛盾，因爲經文直說，多馬是對著基督本人說的：“**對他說**”，也就是說，“我的主！我的上帝！”這句話按文本正是對基督的稱呼。
使徒這樣稱呼基督，沒有一個人糾正他，而基督自己也認可了他的信仰，說：“你因看見了我纔信”。多馬信的是什麼？他信的是他從前不肯信的事。此前他拒絕相信使徒們所說的，即基督在上個主日向他們顯現了。多馬不肯信，除非親眼看見、親手探查，確認那確實是基督，而不是別人；確認那是被釘十字架、被長槍刺透的那一位：“我非看見他手上的釘痕，用指頭探入那釘痕，又用手探入他的肋旁，我總不信”（[[in 20:25]]）。及至主日，基督再次顯現，多馬便確認，顯現的不是別人，而是誰呢？正是他曾經懷疑不肯信其顯現的那一位；如今他既已確認，就承認這顯現，彷彿在說：真的是你，**“我的主！我的上帝！”**。這裏滿足批評者的一切語法要求：話是使徒說的，是在基督與衆使徒面前說的，無人反對，基督還加以認可。
# 基督是在萬有之上、永遠可稱頌的上帝（[[rim 9:3-5]]）
使徒在最高意義上稱基督爲上帝：
> rim 9:3-5 :: 基督 :: 在萬有之上，永遠可稱頌的上帝
| **ὁ Χριστὸς** τὸ κατὰ σάρκα· **<u>ὁ</u> ὢν ἐπὶ πάντων θεὸς** εὐλογητὸς εἰς τοὺς αἰῶνας, ἀμήν ||| gr rim 9:5
基督神性教導的反對者會反駁說，這裏“θεὸς”（上帝）一詞缺少冠詞，所以基督在這裏似乎不是在最高意義上被稱爲上帝（彷彿這不是他自己的屬性），或者說“上帝”一詞根本不屬於基督。
對此有不同見解。有理由認爲，冠在這一切描述同一位人物的定語之前的共同指涉冠詞已經足夠：“ὁ ὢν ἐπὶ πάντων θεὸς”（在萬有之上、永遠可稱頌的上帝）。何況“上帝”一詞帶冠詞而屬於基督的例子，我們一開始已經舉過（[[in 20:28-29]]）。如果這裏缺少冠詞，那麼那裏還缺少什麼，才能叫人相信呢？
# 基督是真上帝（[[1in 5:20]]）
> 1in 5:20 :: 耶穌基督裏面。這是真神
| καὶ ἐσμὲν ἐν τῷ ἀληθινῷ, ἐν τῷ υἱῷ αὐτοῦ **Ἰησοῦ Χριστῷ. οὗτός ἐστιν ὁ ἀληθινὸς θεὸς** καὶ ζωὴ αἰώνιος ||| gr 1in 5:20
使徒約翰寫“這是”（οὗτός ἐστιν）的時候，這個代詞所指的是緊接在前面一句中的“耶穌基督”（Ἰησοῦ Χριστῷ）之名。這是最近的先行詞。“θεὸς”前的冠詞“ὁ”強調，這是剛剛所談論之人的確定的屬性，即耶穌基督的屬性。語法上和邏輯上，這裏說的是：“這位【耶穌基督】是真上帝，是永生。”
# 上帝用自己的血買來了教會（[[act 20:28]]）
這節經文指明基督的神性，因爲這裏被稱爲上帝的，正是用自己的血買來教會的那一位。神性沒有血；血只有成了肉身的兒子纔有。這裏被稱爲上帝、用自己的血買來教會的，正是兒子：
> act 20:28 :: 上帝的教會 :: 用自己血所買來的
| ποιμαίνειν **τὴν ἐκκλησίαν τοῦ θεοῦ**, ἣν περιεποιήσατο διὰ **τοῦ αἵματος τοῦ <u>ἰδίου</u>** ||| gr act 20:28
# 從前無人看見的上帝，在肉身顯現，將自己表明出來（[[1tim 3:15-16]]）
“上帝在肉身顯現”這句話是俄文公會譯本如此譯的，但希臘文原文這裏沒有“上帝”一詞，代替它的是一個代詞“那一位”。然而這個代詞指的是上帝，因爲緊接著前面說的是上帝：“在上帝的家中當怎樣行；這家就是永生上帝的教會”。隨後又清楚表明，在這裏被稱爲上帝的正是耶穌基督：因爲不是父，而是兒子——即耶穌基督——“在肉身顯現”，從而“被天使看見”（父作爲上帝仍然不能看見），兒子也在榮耀裏被接昇天：
> 1tim 3:15-16 :: 在上帝的家中 :: 永生上帝的教會 :: 上帝在肉身顯現 :: 被天使看見 :: 被接在榮耀裏
| **Ὃς ἐφανερώθη ἐν σαρκί**, ἐδικαιώθη ἐν πνεύματι, **ὤφθη ἀγγέλοις**, ἐκηρύχθη ἐν ἔθνεσιν, ἐπιστεύθη ἐν κόσμῳ, ἀνελήμφθη ἐν δόξῃ ||| gr 1tim 3:16
# 上帝與主耶穌基督（[[2tim 4:1]]、[[2pet 1:1]]）
在這節經文裏，耶穌被稱爲上帝，又被稱爲基督（“基督”一詞譯自希臘文，意爲“受膏者”，這是對世人所等候的救主的稱號，[[act 2:36]]）。俄文公會譯本作：“在上帝和我們的主耶穌基督面前”，但希臘文寫法略有不同，直譯是：“在上帝和基督耶穌面前”（τοῦ θεοῦ καὶ Χριστοῦ Ἰησοῦ）。
有人會反駁說，這裏說的是兩位：上帝，以及耶穌基督。這種反駁不能成立，因爲兩個詞共用一個冠詞“τοῦ”（屬格的指涉冠詞），也就是說，兩個詞都指同一個被描述的人物——耶穌。此外，下文的“τοῦ μέλλοντος”（將要審判的）是單數，這進一步表明前文所說的是一個人物：
> 2tim 4:1 :: 上帝面前，並在將來審判活人死人的基督耶穌面前
| Διαμαρτύρομαι ἐνώπιον **<u>τοῦ</u> θεοῦ καὶ Χριστοῦ Ἰησοῦ**, τοῦ μέλλοντος κρίνειν ζῶντας καὶ νεκρούς ||| gr 2tim 4:1
下面是一個使用同一共同冠詞的類似語法結構：
> 1pet 1:3 :: 父上帝
| Εὐλογητὸς **<u>ὁ</u> θεὸς καὶ πατήρ** τοῦ κυρίου ἡμῶν Ἰησοῦ Χριστοῦ ||| gr 1pet 1:3
這裏“上帝與父”兩個詞共用一個冠詞“ὁ”（主格的指涉冠詞），因此兩個詞描述的是同一位，而不是兩位。
以下這處稱基督爲上帝的結構，也服從同一條規則：
> 2pet 1:1 :: 上帝和救主耶穌基督
| ἐν δικαιοσύνῃ **<u>τοῦ</u> θεοῦ ἡμῶν καὶ σωτῆρος Ἰησοῦ Χριστοῦ** ||| gr 2pet 1:1
# 福音書作者路加稱基督爲上帝（[[lk 8:39]]）
來看福音書作者路加所記的一節。引文的前半是耶穌基督的話，後半是敘述者——福音書作者路加——自己的話。基督吩咐痊癒的人去傳講上帝爲他所作的事，而福音書作者路加記下，痊癒的人傳揚的是耶穌爲他所作的事。也就是說，在福音書作者路加的理解中，耶穌與上帝在這裏是一回事：
> lk 8:39 :: 上帝爲你作了何等大的事 :: 耶穌爲他作了何等大的事
| διηγοῦ ὅσα σοι **ἐποίησεν ὁ θεός** … κηρύσσων ὅσα **ἐποίησεν αὐτῷ ὁ Ἰησοῦς** ||| gr lk 8:39
如果基督神性的反對者反駁說，福音書作者只是描述了痊癒者的行爲，說耶穌吩咐他傳講上帝所作的事，而痊癒者誤解了，沒有傳講上帝所作的事，反倒傳講耶穌所作的事——那麼要明白：反對基督神性的人也認爲福音書作者路加是否認基督神性的，彷彿路加也不認爲基督是上帝。那樣的話，福音書作者必定會以某種方式指出痊癒者的錯誤——他做的完全不是耶穌吩咐他做的事。這至少會表現爲用“但是”“然而”之類的轉折詞：“耶穌說，要回去傳講上帝所作的事，**但是**他卻去傳揚耶穌所作的事”；更有可能的是，他會直說痊癒者誤把耶穌當作上帝，所以傳講的不是上帝，而是耶穌。這不是小事，而是信仰的根基。
但福音書作者沒有作任何對比。他使用的是同一結構的重複：“上帝爲你作了……耶穌爲他作了……”。這是福音書作者相信基督神性的有力明證。

# 上帝道成肉身（[[in 1:1-18]]）
使徒約翰稱道爲上帝，隨後指出道成了肉身。施洗約翰所指向的正是這道成了肉身的道，而他指的是耶穌基督：
> in 1:1-18 :: 道就是上帝 :: 道成了肉身
使徒在這裏稱基督不僅是父的兒子，而是獨生子，意思是：再沒有誰像基督那樣是父的兒子。他不是長子（最先出生的），而是獨生子（獨一的兒子）。沒有別的兒子。
基督神性教導的反對者會反駁說，在另外兩處，基督也被稱爲長子：
> rim 8:29 :: 在許多弟兄中作長子
> evr 1:6 :: 長子
對此應當說：他被稱爲長子，是因爲他首先從死裏復活：他的復活不是復活之後又要死（先知們從前的復活是那樣），而是以勝過死亡的改變形象的復活（[[rim 6:9]]），要活到永遠，並在榮耀裏昇天，要作王直到永遠——在他以前沒有人這樣復活過。他首先這樣復活，也就是成爲長子，或者說從死裏的首生者：
> kol 1:18 :: 從死裏首先復生的
> otkr 1:5 :: 從死裏首先復活
> act 26:23 :: 因從死裏復活

# 詩篇論及上帝的話，是論及子說的（[[evr 1:8-12]]）
使徒保羅把先知的詩篇用在基督身上。他說，那些話是論及子說的：
1. 子是上帝。
2. 子立了地的根基，造了天。
3. 子——上帝——受了上帝的膏（希臘文 Χριστός 意爲“受膏者”）。
> evr 1:8-12 :: !論到子 :: 上帝啊，你的寶座是永永遠遠的 :: 上帝，就是你的上帝，用喜樂油膏你 :: !你起初立了地的根基，天也是你手所造的 ~~ 引自詩 45:6-7
基督神性教導的反對者會反駁說，這裏稱上帝用的只是猶太人通用的詞 Elohim，這個詞既用於真上帝，也用於假神。他們將期待上帝被冠以四字聖名——四個希伯來字母 **יְהוָֽה（YHWH，音“雅威”）**。而使徒所引的詩篇（[[ps 102:25-27]]）恰好滿足他們的要求。整篇詩——是向**上帝（יְהוָֽה，YHWH）**的禱告，他在 [[ps 102:20]] 和 [[ps 102:23]] 被稱爲 **יְהוָֽה**。詩篇的標題是：“困苦人的禱告，他消沉地在**耶和華（יְהוָֽה，YHWH）**面前傾吐苦情”。也就是說，整篇詩——包括使徒所引用的詩句——都是向上帝的禱告，而上帝在其中的稱呼正如他們所期待的——耶和華。使徒卻說，這是論子說的，也就是說，耶和華——就是子，耶穌基督。

# 耶穌就是舊約裏的那同一位上帝（[[mf 23:34]]、[[ier 7:21,25]]）
當人向基督神性的反對者指出，使徒們直呼基督爲上帝時，他們反駁說：“僅被稱爲上帝還不夠”——瞧，先知摩西也曾被稱爲神：
> ish 7:1 :: 我使你在法老面前代替上帝
| Ἰδοὺ δέδωκά σε **θεὸν Φαραω**, καὶ Ααρων ὁ ἀδελφός σου ἔσται σου προφήτης ||| gr ish 7:1
首先，這裏沒有滿足批評者自己先前提出的要求：上帝一詞要帶冠詞。這裏沒有冠詞。而且從文本可以清楚看到，先知摩西得到的只是相對於法老的一種授予的職能。這裏沒有任何地方表明摩西按本性就是神，擁有神性作爲自己固有的恆常屬性。此外，批評者對我們的論證所要求的第二條，在這裏也沒有滿足：希伯來文原文中用的也是通用的“אֱלֹהִ֖ים”（Elohim），而不是四字聖名 YHWH，也就是說，這裏說的不是最高意義上的真上帝。
其次，可以完全確信：耶穌基督就是那位真上帝——創造者、耶和華、祖宗的上帝（亞伯拉罕、以撒、雅各的上帝）。例如，基督自己說他曾向以色列差遣先知，而舊約說，向以色列差遣衆先知的是上帝耶和華。由此也直接可見：基督就是道成肉身的上帝耶和華。後面還有別的例子。

# 古代抄本
1. 現今的 **[[iud 1:5]]** 作：“我想提醒你們，你們雖然知道這事，主救了他的百姓出埃及地，其後就把不信的滅絕了。”但在保存猶大書信的最古老的蒲草抄本 [[https://en.wikipedia.org/wiki/Papyrus_72|p72]]（三世紀）中，這段文字是這樣：“我想提醒你們，你們雖然萬事都知道，**上帝基督**（Theos Christos）曾一次救了他的百姓出埃及地，其後就把不信的滅絕了。”
2. 現今文本的 **[[kol 2:2]]** 結尾作：“得以知道上帝和基督的奧祕”。而在保存保羅書信的最古老蒲草抄本 [[https://en.wikipedia.org/wiki/Papyrus_46|p46]]（二世紀末）中，寫的是：“得以知道**上帝基督**的奧祕”（tou Theou Hristou）。
3. 在我們手頭的文本中，**[[2pet 1:2]]** 作：“願恩惠、平安因你們認識上帝和我們主耶穌多多地加給你們”。而該書信最古老的抄本作：“願恩惠、平安因你們認識**上帝耶穌**（tou Theou Iesou），我們的主，多多地加給你們”。
4. 現今的 **[[in 1:18]]** 作：“父懷裏的獨生子”。而在約翰福音最早的書冊——蒲草抄本 [[https://en.wikipedia.org/wiki/Papyrus_75|p75]]（三世紀中葉）和 [[https://en.wikipedia.org/wiki/Papyrus_66|p66]]（二世紀末）中，讀到的是：“父懷裏的**獨一上帝**”。里昂的愛任紐引用這處時，也是這樣。
# 基督——兩個世界的居住者：上帝與人
沒有能把一隻手放在上帝身上、另一隻手放在人身上的中保，因爲這兩個世界互不相觸，沒有任何東西、任何存在把它們連在一起：
> iov 9:33 :: 我們中間沒有聽訟的人
而耶穌基督（非受造的上帝與受造的人）自己就聯結了這兩個世界：
> 1tim 2:5 :: 在上帝和人中間，只有一位中保
# 舊約的平行經文
## 基督如同上帝：萬王之王、萬主之主
先知稱上帝爲萬主之主：
> ps 136:2-3 :: 萬主之主
使徒稱上帝爲萬王之王、萬主之主：
> 1tim 6:15-16 :: 萬王之王、萬主之主
使徒稱耶穌基督爲萬主之主、萬王之王：
> otkr 17:14 :: 萬主之主、萬王之王
> otkr 19:16 :: 萬王之王、萬主之主
## 基督如同上帝：全能者
上帝是全能者：
> iov 5:17; otkr 15:3 :: 全能者
基督是全能者：
> otkr 1:8 :: 全能者
> evr 1:3 :: 托住萬有
在同一卷書中，上帝也被稱爲全能者：
> otkr 15:3 :: 主上帝，全能者啊
## 基督是“自有的”（希伯來文：耶和華）
基督對自己的稱呼，與舊約中上帝的稱呼相同（耶和華、自有的）：
> in 8:25 :: 從起初
## 上帝將與衆聖徒一同降臨，基督也是
上帝（希伯來文 יהוה）將與衆聖徒一同降臨：
> zah 14:5 :: 耶和華我的上帝必降臨，有一切聖者同來
> iud 1:14 :: 主帶著他的千萬聖者降臨
基督將與衆聖徒一同降臨：
> 1sol 3:13 :: 我們主耶穌同他衆聖徒來
> mf 25:31 :: 人子 :: 同著衆天使
