# 來自穆斯林的問題
## 爲什麼需要祭品？憐憫的上帝難道不能白白赦免嗎？
基督徒所信的上帝稱爲愛：
> 1in 4:8,16 :: 上帝就是愛 :: 上帝就是愛！
上帝藉着把自己獻爲祭、以拯救受造者，正是顯明他對受造物的愛——因爲他自己也說過：
> in 15:13 :: !人爲朋友捨命，人的愛心沒有比這個大的
這樣，他以祭品之愛吸引他所願意拯救的人：
> in 12:32-33 :: 我若從地上被舉起來，就要吸引萬人來歸我 :: 指著自己將要怎樣死說的
但智慧的上帝始終以智慧安排救恩。除了愛之外，我們還可以說到神聖公義的滿足：上帝不僅憐憫，而且公義。他善於把智慧、憐憫、公義和愛結合在一起。
