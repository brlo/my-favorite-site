# 定義
**婚姻**——教會七個聖奧祕之一，在其中求上帝祝福自願的夫妻聯合——它建立在夫妻彼此相愛之上，按基督和他的教會之屬靈聯合的樣式。
# 聖經引文
在婚姻中舉行上帝所行做的聖奧祕：
> gen 2:18,22,24 :: !那人獨居不好 :: !耶和華上帝就用那人身上所取的肋骨造成一個女人 :: !人要離開父母，與妻子連合，二人成爲一體
> mk 10:2-9 :: !既然如此，夫妻不再是兩個人，乃是一體的了 :: !上帝配合的，人不可分開
> 1kor 6:15-16 :: !與娼妓聯合的，便是與她成爲一體嗎 :: !二人要成爲一體
> ef 5:28,31-33 :: !丈夫也當照樣愛妻子 :: !這是極大的奧祕 :: !但我是指著基督和教會說的 :: !妻子也當敬重他的丈夫
# 一世紀教會婚姻祝福
## 聖伊格那提·懷上帝者（約37-107）
“凡娶妻嫁人的，**必須與主教的同意聯合**，好叫婚姻在主裏面，而不是出於情欲”
（[[ru:ИгнАн_Пк|致波利卡普書]] 第28節）

**病人傅油**（終傅）——教會的聖奧祕，由司祭團（在極特殊情形下由一位司祭）在病人身上舉行，在於藉祈禱和以聖油膏抹病人，呼求醫治的、潔淨的恩典，醫治身體和心靈上的軟弱。
**聖經引文：**
> iak 5:14-15 :: !該請教會的長老來 :: !用油抹他 :: !出於信心的祈禱要救那病人 :: !他若犯了罪，也必蒙赦免
> mk 6:12-13 :: !用油抹了許多病人，治好他們
> mf 10:1 :: !給他們權柄，能趕逐污鬼，並醫治各樣的病症
> mf 10:8 :: !醫治病人 :: !你們白白的得來，也要白白的捨去

# 舊約中的認罪
在舊約的教會裏，上帝親自設立了在聖殿裏、在司祭面前的告解，並藉司祭潔淨罪：
> lev 5:5-6 :: !就要承認所犯的罪 :: !祭司要爲他贖了
> pr 28:13 :: !承認離棄罪過的，必蒙憐恤
# 新約中的認罪
## 司祭職有權赦罪
上帝更換了司祭職（詳見[[ru:Таинство-Священства|司祭聖奧祕]]）：
> evr 7:12 :: !祭司的職任既已更改，律法也必須更改
把赦罪之權賜給新的司祭職：
> mf 16:19 :: !凡你在地上所釋放的，在天上也要釋放
> mf 18:18 :: !凡你們在地上所釋放的，在天上也要釋放
> in 20:22-23 :: !你們赦免誰的罪，誰的罪就赦免了 :: !你們留下誰的罪，誰的罪就留下了
因司祭職的祈禱，罪得赦免：
> iak 5:14-15 :: !該請教會的長老來 :: !用油抹他 :: !他若犯了罪，也必蒙赦免
司祭職被立爲教會的守護者：
> act 20:17-18,28 :: !請教會的長老來 :: !聖靈立你們作全羣的監督 :: !牧養上帝的教會
## 告解在教會裏得以保存
在新舊約交界處，人們來到先知施洗約翰面前，也認自己的罪：
> mk 1:4-5 :: !傳悔改的洗禮，使罪得赦 :: !承認他們的罪
告解在教會裏得以保存：
> act 19:18 :: !承認訴說自己所行的事
## 信徒在得著真信仰之後，後來仍需要新的罪的赦免
真信徒能使鄰人從迷路上轉回，並以此遮蓋自己的許多罪：
> iak 5:19-20 :: !有人使他迴轉 :: !叫一個罪人從迷路上轉回 :: !遮蓋許多的罪
> iak 5:14-15 :: !該請教會的長老來 :: !用油抹他 :: !他若犯了罪，也必蒙赦免
# 主不拒絕悔改的人
上帝總是預備接納罪人的悔改，無論他犯了多重的罪
> ps 51:17 :: !憂傷痛悔的心，你必不輕看
> in 6:37 :: !到我這裏來的，我總不丟棄他
