# Bibleox — оффлайн-приложение для Android

Capacitor + Vue 3. Приложение всегда читает данные из локальной SQLite, а интернет нужен только чтобы докачать недостающее и получить обновления.

## Что и когда скачивается

| Что | Когда | Где на сервере |
|---|---|---|
| Перевод Библии (весь, ~2 МБ) | при первом открытии перевода онлайн | `GET /api/offline/bible/:tr_code` (gz-файл кэшируется в `public/s/offline/`) |
| Скелет материалов языка: заголовки, иерархия, меню | при первом открытии материалов на языке, потом дельтой | `GET /api/offline/skeleton?lang=ru&since=<unix>` |
| Текст страницы | при открытии онлайн или кнопкой «Скачать раздел» | `GET /api/offline/pages?lang=ru&ids=1,2,3` |
| Аудио главы / страницы | при прослушивании онлайн (сначала скачивается, потом играет) | статика `res.bibleox.com/s/audio/...` |
| Картинки в статьях | при просмотре онлайн | как на сайте |
| Список переводов, книг, аудио | при каждой синхронизации | `GET /api/offline/manifest?locale=ru` |

Синхронизация запускается при старте, при появлении сети и при возврате в приложение (не чаще раза в 10 минут). Можно запустить вручную в настройках. Поисковый индекс (SQLite FTS4) строится на устройстве. Текст нормализуется одной функцией и для индекса, и для запроса (`src/lib/text.js`): без регистра, ударений, титл и огласовок, а иероглифы разбиваются по одному.

## Разработка в браузере

```bash
cd mobile
npm install
npm run dev        # http://localhost:5174, API проксируется на локальный Rails (docker, порт 80)
npm test           # тесты нормализации текста и разбора ссылок
```

В браузере SQLite работает через sql.js (jeep-sqlite). Версия sql.js зафиксирована в `overrides` под jeep-sqlite.

## Сборка APK

Нужен только Docker: Android SDK лежит в образе `ghcr.io/cirruslabs/android-sdk:36`.

```bash
cd mobile
sh scripts/build-apk.sh
```

Результат: `mobile/apk/bibleox-<версия>.apk`.

При первой сборке создаётся ключ подписи `android/bibleox-release.keystore` и пароль к нему в `android/keystore.properties`. Оба файла не в git. **Их нужно сохранить в надёжном месте**: APK, подписанный другим ключом, не встанет поверх уже установленного, и пользователям придётся удалять приложение (вместе со скачанными данными).

Перед новой сборкой увеличьте `version` в `package.json`, а также `versionCode` и `versionName` в `android/app/build.gradle`.

Иконки и заставка генерируются из `resources/icon.png`:

```bash
docker exec -w /app/mobile bibleox sh scripts/gen-android-icons.sh
```

## Сервер

- `app/controllers/api/offline_controller.rb`, `app/services/offline/export.rb`. Без авторизации, только чтение.
- В `sys_config/etc/nginx/conf.d/bibleox.conf` добавлен `location ^~ /api/offline/`: без редиректа на слеш и с более мягким лимитом частоты. Его нужно выложить на сервер и перезагрузить nginx. Без этого всё тоже работает, но медленнее (лимит 1 запрос/с).
