# Bibleox — оффлайн-приложение для Android

Capacitor + Vue 3. Приложение всегда читает данные из локальной SQLite, а интернет нужен только чтобы докачать недостающее и получить обновления.

## Что и когда скачивается

| Что | Когда | Где на сервере |
|---|---|---|
| Перевод Библии (весь, ~2 МБ) | при первом открытии перевода онлайн | `GET /api/offline/bible/:tr_code` (gz-файл кэшируется в `public/s/offline/`) |
| Скелет материалов языка: заголовки, иерархия, меню, теги, цвета подложки | при первом открытии материалов на языке, потом дельтой | `GET /api/offline/skeleton?lang=ru&since=<unix>` |
| Текст страницы, lead и токен маячка | при открытии онлайн кнопкой «Скачать раздел» или при первом открытии после обновления | `GET /api/offline/pages?lang=ru&ids=1,2,3` |
| Последняя страница новостной ленты | при открытии ленты онлайн (для офлайн-показа) | `GET /api/offline/feed?lang=ru&page=1` |
| Аудио главы / страницы | при прослушивании онлайн (сначала скачивается, потом играет) | статика `res.bibleox.com/s/audio/...` |
| Картинки в статьях | при просмотре онлайн | как на сайте |
| Список переводов, книг, аудио | при каждой синхронизации | `GET /api/offline/manifest?locale=ru` |

Уже скачанные страницы, у которых есть lead, после обновления приложения один раз докачиваются: старый кэш хранил lead внутри общего текста, и его нужно вынести над оглавлением.

Синхронизация запускается при старте, при появлении сети и при возврате в приложение (не чаще раза в 10 минут). Можно запустить вручную в настройках. Поисковый индекс (SQLite FTS4) строится на устройстве. Текст нормализуется одной функцией и для индекса, и для запроса (`src/lib/text.js`): без регистра, ударений, титл и огласовок, а иероглифы разбиваются по одному.

## Лента, теги, реакции, посещения

- **Лента** открывается кнопкой «Лента» в шапке раздела «Материалы» (пятой иконки в нижнем меню нет). Она сетевая: карточки собирает сервер, приложение кэширует последний ответ и показывает его офлайн с пометкой «Обновлено». Блок «Читают сейчас» и реакции работают только онлайн.
- **Теги** приходят в скелете снимком на весь язык и открываются локальным списком статей (`/#/w/<lang>/tags/<slug>`), без обращения к сайту.
- **Реакции** отправляются на `POST /api/offline/reactions` (JSON, одна реакция на IP, как на сайте). Офлайн кнопки неактивны; последние счётчики показываются из кэша.
- **Посещение** отмечается отдельным запросом `POST /api/offline/visit` с токеном страницы, а пока статья открыта, раз в 45 секунд уходит `POST /api/offline/reading` для блока «Читают сейчас» (для главы Библии — `book` и токен книги из манифеста). Офлайн-чтение не засчитывается: статистика дневная, и отложенные запросы её бы исказили. Токен приходит вместе с текстом; для уже скачанных страниц его добирает `GET /api/offline/tokens?ids=...`.

Локальная база обновляется идемпотентно (`ensureColumns` в `src/lib/db.js`): новые колонки добавляются к уже существующим таблицам, скачанные данные не теряются. При смене формата скелета сервер отдаёт `data_version`; приложение один раз перечитывает язык целиком, иначе старые страницы не получили бы новые поля (например, цвет подложки обложки).

## Разработка в браузере

```bash
cd mobile
npm install
npm run dev        # http://localhost:5174, API проксируется на локальный Rails (docker, порт 80)
npm test           # тесты нормализации текста, ссылок и обложки
```

В браузере SQLite работает через sql.js (jeep-sqlite). Версия sql.js зафиксирована в `overrides` под jeep-sqlite.

## Сборка APK

Нужен только Docker: Android SDK лежит в образе `ghcr.io/cirruslabs/android-sdk:36`.

```bash
cd mobile
sh scripts/build-apk.sh
```

Результат: `mobile/apk/bibleox-<версия>.apk`.

При первой сборке создаётся ключ подписи `android/bibleox-release.keystore` и пароль к нему в `android/keystore.properties`. Оба файла не в git. **Их нужно сохранить в надёжном месте**: APK, подписанный другим ключом, не встанет поверх уже установленного, и пользователям придётся удалять приложение (вместе со скачанными данными).

Перед новой сборкой увеличьте `version` в `package.json`, а также `versionCode` и `versionName` в `android/app/build.gradle`.

Иконки и заставка генерируются из `resources/icon.png`:

```bash
docker exec -w /app/mobile bibleox sh scripts/gen-android-icons.sh
```

## Сервер

- `app/controllers/api/offline_controller.rb`, `app/services/offline/export.rb` — чтение: скелет, тексты, лента, токены.
- `app/controllers/api/reactions_controller.rb`, `visits_controller.rb`, `readings_controller.rb` — запись: реакции, маячок посещения, heartbeat.
- Теги в скелете отдаются снимком на язык (`tag_snapshot`), поэтому переименование и снятие тега не требуют обновлять `updated_at` статей.
- В `sys_config/etc/nginx/conf.d/bibleox.conf` добавлен `location ^~ /api/offline/`: без редиректа на слеш и с более мягким лимитом частоты. Его нужно выложить на сервер и перезагрузить nginx. Без этого всё тоже работает, но медленнее (лимит 1 запрос/с).
