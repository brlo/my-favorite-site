# Японские переводы (ja): святоотеческая библиотека

Рабочая инструкция для длительного перевода раздела отцов на японский. Общие
правила (докер, импорт YAML, прод) — в `AGENTS.md` и `docs/translations.md`;
здесь — конвенции, глоссарий и конвейер именно для ja. Методика перенята у
китайского проекта (см. `docs/chinese-translations.md` и «Уроки» ниже) и
опирается на уже сделанные ja-переводы: Игнатий, Поликарп, Дидахе.

## Статус проекта

Раздел ja: стр. 827 `chirch_writers_jp` «古代の聖父や教会の著述家の著作»,
меню по векам (1世紀…20世紀) + カテキズム + ことば集. Порядок работ как в
zh-проекте: пользователь называет автора → переводим его страницу (page_type 4)
и все труды (page_type 1); сначала I век, затем II.

Готово (не переводить заново): Игнатий (951 + 7 посланий, с греч., d2ae9a9),
Поликарп (автор + К Филиппийцам + Мученичество, с греч. и лат., 6c5f06b),
«1世紀の無名の作者による作品» (страница-список, Uk1A) + Дидахе (Dd1A, 180f05e;
страница под списком, пункт меню — в カテキズム)， Златоуст (832), Исаак Сирин
(2810), Тихон Задонский (829), Иоанн Кронштадтский (830), Иоанн Тобольский (831),
Игнатий Брянчанинов (4440), Николай Велимирович (4446), «聖師父の格言300選»
(4649); раздел цитат q (171 ст., 08e014a), статья о Православной Церкви,
Веселов (автор + 7 статей — под разделом 著者出版物 (4591), не под отцами).

zh-проект идёт параллельно и опережает ja на одного автора (Климент zh сделан
19.11). Его аналитика переиспользуется для ja бесплатно: греч. эталоны,
structure-JSON паритета, карта пересчёта #L→#HH, QUOTES-цитаты, решения по
рукописям и второканону. Сам текст переводится заново с греческого, ja-текст
из zh не конвертируется.

## Библия: 新共同訳 (jp-ni)

Единственная ja-Библия на сайте (`BibleLinker::BIBLE_BY_LANG`: ja → jp-ni;
36 609 стихов). Особенности:

- **Второканон есть** (トビ, 知恵の書 = 知， シラ, バル, マカベイ書) — ссылки на
  второканонные книги ставятся прямо на jp-ni, без сносок «нет в переводе»
  (проблемы zh с двумя Библиями здесь нет).
- **Цитаты дословно по базе** (`verses`, `tr_code='jp-ni'`), сверка пословно.
- **Псалмы** — еврейская нумерация (Пс 50 → 詩51), надписание считается стихами —
  сдвиги нелинейны, каждая псалмная ссылка сверяется по базе individually
  (состоявшееся соответствие: Пс.50:7→詩51:7). Не автоматизировать.
- **Furigana-скобки** jp-ni (вид `初[はじ]め`) в цитатах выкидывать.
- **Кириллица в ja-тексте запрещена** (славянизмы оригинала — катаканой;
  исключение — бренд «Библeокс»).
- Автолинкер для ja работает (`BibleLinker.ja_pattern`: «マタ. 10:38»
  распознаётся), но в переводах отцов ссылки пишутся ЯВНЫМИ `<a>` — контроль
  подписи и диапазонов, прецедент Игнатия/Поликарпа/Веселова.

## Ссылки (форматы)

- Библия: `<a href="https://bibleox.com/ja/jp-ni/{book}/{ch}/#L{vs}">マタ. 7:1-2</a>`.
  Коды книг транслитом (`mf`, `in`, `1kor`, `ps`, `tov`…); сокращения и полные
  названия — `config/locales/ja.yml` (`books.short/mid/full`), рабочая таблица
  ABBR — `script/translations/ign/ja_common.py`. Подпись: сокращение + `.` +
  пробел + глава:стих; диапазон ASCII-дефисом; несколько мест через 、
  (ヨシュ. 1:6-9、申. 31:6-7 参照); продолжения без книги допустимы
  (マタ. 10:38; 16:24). `参照` = «ср.».
- Внутренние ja: `https://bibleox.com/ja/ja/w/{path}#HH-{n}`; на свой труд —
  `#HH-{ch}`; подпись『タイトル』3:1-2 или …13章. Прецедент — абсолютные URL;
  сохранить (живые страницы так устроены).
- Греч. оригиналы: `/ja/grc/w/{греч. путь}` — греческий текст в href сырым,
  без %-энкода (пробы для проверки — с %-энкодом).
- Страницы, которых нет на ja: `/ja/en/w/...` + помета （英語）（и т.п.）.
- URL-схема: прод `bibleox.com/ja/ja/w/<path>`, dev `localhost/ja/ja/w/<path>`
  (префикс `/ru/` тоже работает).

**Имена** — катаканой по греческому чтению, из уже переведённых соседей, не из
заготовок меню и не калькой с русского. Состоявшиеся формы: イグナティオス
（テオフォロス）, ポリュカルポス, クレメンス（ローマの）, エイレナイオス（リヨン
の）, エウセビオス（カイサリアの）, テルトゥリアヌス, マルキオン, ヘロデ,
ピラト， トラヤヌス帝. Антропонимы ВЗ/НЗ в цитатах — как в 新共同訳.

**Славянизмы/грецизмы в тексте** — катаканой в скобках при первом употреблении:
永遠で天上の大祭司， 独り子（パイス） (прецеденты Поликарпа).

**Стиль**: вежливый です・ます (как в готовых переводах); типографика —
 полная ширина 。、; диапазоны цифр ASCII; годы через 〜（〜69-155）; вложенных
 европейских кавычек нет.

## Оформление

- Труды: `<h2>N</h2>` главы (прескрипт = глава 0; именованные главы допустимы:
  「モスクワ写本による結び」)， абзацы с номерами «1. 2. …» внутри главы —
  даёт цитирование глава:абзац (как zh).
- Сноски `[n]` по порядку следования + `<ol><li><p>…</p></li></ol>` в
  `references`; нумерует сборщик, не руками.
- Кавычки: речь и цитаты 「」, названия трудов 『』; греческие термины в сносках —
  по-гречески (παροικούσῃ, ὑπογραμμός) с японским пояснением.
- Авторская страница: вступление со ссылкой на греч. оригинал → 記憶日 → 生涯 →
  信仰 (h3-темы с цитатами) → テキストの年代について; цитаты из трудов —
  blockquote, ДОСЛОВНО из ja-переводов трудов (assert в сборщике), `<strong>`
  зеркально ru.
- `title` — чистое имя без суффиксов хлебных крошек («エフゲニー・ヴェセロフ司祭»，
  не «…／著者出版物／Библeокс»); **имя на первом месте**, прозвище вторым в
  скобках (правило пользователя для всех языков): ポリュカルポス（スミルナ
  の）、1–2世紀， クレメンス（ローマの）、1世紀. Титулы и годы — в `title_sub`
  (致命者（69年頃〜155年）、スミルナの主教). Готовые ja-страницы Игнатия и
  Поликарпа так и устроены — образец; так же называется пункт меню. Путь (URL,
  у Игнатия старый `mlNq_アンティオキアの…`) не менять.
- **Строка принципов** в конце `references` КАЖДОГО перевода (правило
  пользователя): источник, вспомогательные переводы, Библия, что сделано с
  LXX-нумерацией и латинскими главами. Образец (Поликарп):
  `翻訳：ロジオン・ヴラソフ（AIツールを併用）。底本：…（レイク版、1913年。Open Apostolic Fathers による校訂）。参照：ロシア語訳（『初期教会教父選集』ブリュッセル、1988年）…。聖書の引用は新共同訳による。`
  Помимо финальной строки, **в самих сносках сообщать читателю важное о
  принципах перевода**: какое чтение взято и почему (прецеденты Поликарпа:
  чтения レイク版, ベザ写本, モスクワ写本), LXX-цитата против 新共同訳， лат.
  главы, терминологические решения.

## Пути и меню

- Путь автора: `<Абр>1A_<ja имя>` (прецедент Pk1A; Игнатий — старый `mlNq_`),
  труды: `<Абр>1<буква>_<ja название>` (Ig1E, Pk1F, Dd1A); цифра = век автора
  (II век — 2). Проверять уникальность `path_low`.
- Импорт: автор — `list: chirch_writers_jp`, `menu: {parent: "1世紀", replace:
  "<старое название заготовки>"}`; труды — `list: <путь автора-ja>`,
  `folders:` + `menu: {parent: "<папка>", …}`. Порядок: автор → труды.
- Заготовки меню I–II веков (названия в dev; на проде искать по title, id не
  совпадают). Стиль заготовок плохой — при заполнении заменять: **имя на
  первом месте**, прозвище в скобках, 致命者 вместо 殉教者， даты без пробелов
  и †:

| век | заготовка → целевое название (replace) |
|---|---|
| 1世紀 | ローマのクレメンス、殉教者 (†~101) → クレメンス（ローマの）、致命者（〜101年頃） |
| 1世紀 | クアドラトゥス（1世紀～2世紀） |
| 2世紀 | 哲学者ユスティノス殉教者（～100-165） → ユスティノス（哲学者）、致命者（～100-165） |
| 2世紀 | アンティオキアのテオフィロス、聖人（†183） → テオフィロス（アンティオキアの）、致命者（†183） |
| 2世紀 | 聖人サルディスのメリトン（†〜180） → メリトン（サルディスの）、致命者（†〜180） |
| 2世紀 | リヨンのイレナエウス、殉教者（～130-202） → エイレナイオス（リヨンの）、致命者（～130-202） (форма из Поликарпа) |
| 2世紀 | ヒエラポリスのパピアス… → パピアス（ヒエラポリスの） / アリスティデス / タティアン / ローマのアポロニウス… → アポロニウス（ローマの） |
| 2世紀 | アレクサンドリアのクレメンス… → クレメンス（アレクサンドリアの） / テルトゥリアヌス |

Для авторов без заготовки (Варнава, Ерма, апостолы) пункт меню создаётся
импортом с приоритетом по хронологии. В поздних веках есть заведомо плохие
заготовки (ジェローム・オブ・ストリドン, アントニウス大王， イ オ ア ン（クロンウェ
シタト）… — «of Stridon» катаканой, «Великий»=大王， пробелы) — править при
выходе в тот век.

## Конвейер (на одного автора)

1. **Инвентарь**: ru-автор + труды (id, размеры), греч. эталоны. grc-страницы
   на сайте есть не для всех (см. таблицу ниже); если нет — 底本 внешнее
   критическое издание (Open Apostolic Fathers / Lightfoot / Holmes; для
   Тертуллиана лат. издание), en-тексты ANF/NPNF сайта — вспомогательно.
2. **Сборщики** `tmp/ja_fathers/<author>/` (в git не попадают; копии после
   коммита — в `script/translations/<author>/`): общий `ja_common.py`
   (ABBR + `b()/i()/here()` из ign), сборка YAML с **автонумерацией сносок**,
   assert паритета структуры с эталоном (structure JSON), assert вхождения
   QUOTES-цитат автора, кириллица=0, полнота абзацев 1:1.
3. **Черновик с греческого** (лат. главы — с латыни, оговорка в принципах);
   ru/en — вспомогательные; кальки с них просачиваются — ловит ревью.
4. **Импорт на dev**: `DRY_RUN=1` → `PUBLISH=1`; рендер curl (`/ja/ja/w/...`),
   check_links-скрипт по **body и references** (уроки Климента zh), стихи — по
   базе.
5. **Ревью вторым агентом**: греч. эталон + сборщики + этот глоссарий + формат
   отчёта P1/P2/P3; файлы во время ревью не менять; правки → пересборка →
   переимпорт (YAML `update: true`, потом флаг снять).
6. **Коммит и прод** — только по явной команде: push → `bin/bib_deploy.sh`
   (502-кверк: проверить `git log` на сервере и статус сайта), импорт на проде
   `DRY_RUN=1` → `PUBLISH=1`, живые проверки (200, меню-заготовка заменена,
   сноски, обложки при `copy_cover`).
7. Правки пользователя на сайте — свято: после них снять `update: true` из
   YAML (прецедент 808e682) и не перетирать title/названия меню, правленные
   на сайте (949d27f).

## Уроки (перенос из zh-проекта и Веселова-ja)

- **#L-якоря ru не работают**: verses-якоря (L24, L54…) пересчитывать в #HH-n
  по h2 ja-трудов; карту соответствий — в сборщик авторской страницы.
- QUOTES-цитаты автора — дословно из ja-трудов; ASCII-кавычки в фрагментах —
  главный источник багов вхождения, сразу 「」; display-строки (подписи ссылок)
  — отдельные литералы, править вместе с raw.
- Автонумерация сносок сборщиком убирает целый класс ошибок.
- Кальки с ru-вспомогательного просачиваются даже при переводе с оригинала;
  лат. главы сверять с латынью. Ревью ловит перевёрнутые действия и
  антецеденты местоимений.
- Терминологию править и в сносках, и в цитатах авторской страницы.
- Имена — из уже переведённых соседей (エイレナイオス из Поликарпа, не イレナエウス
  из заготовки).
- check_links проверяет references наравне с body (пропущенные битые ссылки
  стоили P1 Клименту zh).
- После «seed»-перевода сверять плотность вставных слов с оригиналом
  (Веселов-ja: ご存じのとおり ×212 при 58 хеджах в ru) и терминологические
  развилки пакетно по всем статьям: 比喩的 (образное) vs 象徴 (притча-vs-образ),
  соблазн=つまずき vs искушение=誘惑.
- Деплой может пройти по старому коммиту при сбое push — проверять `git log`
  на сервере (Дидахе zh).
- Импортёр не перемещает пункты меню между папками — только путь/заголовок;
  перемещение — руками по `menus.parent_id`.
