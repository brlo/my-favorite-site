# Английские переводы святых отцов: общий план долгой работы

Этот файл — точка входа для долгой последовательной работы по переводу святоотеческого
наследия на английский. Детали по двум направлениям — в отдельных документах:

- `docs/english-quotes-project.md` — раздел цитат отцов: `q-saints` → `en-saints-q`
  (статьи-подборки цитат; методика партии — `docs/quotes-quality.md`);
- `docs/english-library-project.md` — святоотеческая библиотека: труды отцов
  (страницы авторов и их произведений), по образцу `docs/japanese-translations.md`.

Общие правила репозитория — `AGENTS.md`, `docs/translations.md`. EN-глоссарий терминов и
оформление статей — `docs/disputes-translations.md` (раздел «Глоссарий EN»); у отцов лексика
традиционнее, чем в современных диспутах, — её фиксируем в конвенциях проектов ниже и по мере
партий накапливаем в отдельном EN-глоссарии отцов (пока его нет).

## Два трека и их состояние (на 2026-11-19)

| Трек | Что это | Готово | Осталось |
|---|---|---|---|
| Цитаты отцов | статьи-подборки RU `q-saints` → EN `en-saints-q` | 25 из 175 реальных статей (15 + «Церковь и спасение» + «Спасение только в Церкви» + «Крещение») | 150 статей (~1,65 МБ RU), 28 папок меню |
| Библиотека | труды отцов: авторы + произведения | у 40 из ~69 авторов есть EN-страница; 520 из 1710 трудов RU | ~29 авторов без EN-страницы; ~1190 трудов (оценка, членение трудов у языков разное) |

Инвентарь пересчитывается скриптами:

```bash
# раздел цитат
bin/rails runner script/translations/q_inventory.rb en en-saints-q --folders   # сводка по папкам
bin/rails runner script/translations/q_inventory.rb en en-saints-q --next      # следующая неполная папка
bin/rails runner script/translations/q_inventory.rb en en-saints-q --all       # всё дерево со статусами

# библиотека
bin/rails runner script/translations/library_status.rb en --folders            # по векам
bin/rails runner script/translations/library_status.rb en --authors            # авторы и покрытие
bin/rails runner script/translations/library_status.rb en --gaps               # только неполные
bin/rails runner script/translations/library_status.rb en --works "Климент"    # труды одного автора
```

## Приоритеты (по умолчанию; пользователь может поменять)

1. **Один трек на сессию.** Не смешивать цитаты и библиотеку в одной сессии: у них разные
   конвейеры, критерии приёмки и контекст. Переключение — только между сессиями/батчами.
2. **Цитаты** двигать партиями по папкам (партия = папка или её часть), пока раздел не
   закрыт: это конечный объём (160 статей) и быстрый видимый результат; после каждой
   партии обновлять таблицу статуса в `docs/english-quotes-project.md`.
3. **Библиотеку** двигать авторами по векам: I век → II → III → …; внутри автора —
   сначала страница автора, затем труды. Это основная долгая линия (сотни трудов),
   её объём заранее не обещать: оценивать по инвентарю и докладывать фактический прогресс.
4. Если пользователь не задал иное, следующая сессия — по подсказке `--next` (цитаты)
   или первый неполный автор века из `--gaps` (библиотека).

## Ритм работы

- Одна сессия = один батч (цитаты: папка/часть папки; библиотека: автор/труд).
- В конце батча: прогон проверок (`q_parity.rb` для цитат; для библиотеки — проверки
  ссылок/структуры конкретного автора), независимое ревью вторым агентом, импорт на dev,
  проверка рендера; **коммит, push и деплой — только по явной команде пользователя**
  (правило `AGENTS.md`).
- После выкладки: обновить «Статус» и «Журнал партий» в документе трека, чтобы следующая
  сессия начиналась с актуальных данных, а не с воспоминаний.
- Пользователь вычитывает страницы прямо на сайте: перед правкой уже опубликованной
  страницы сверять `md5(body)` на проде с локальной выгрузкой; его правки не перетирать.

## Качество заимствованных переводов

Если цитата берётся из готового английского перевода (библиотека сайта, Библия) и этот перевод
не передаёт мысль оригинала, ради которой цитата нужна: сверить оригинал (grc/la; греч./евр.
стиха), найти другой перевод, иначе — примечание переводчика с оригиналом вне кавычек; замена
цитаты — если иначе нельзя, отказ — только с согласия пользователя (ломает паритет с RU).
Подробно: `docs/english-quotes-project.md` («Если заимствованный перевод скрывает мысль
оригинала»), `docs/english-library-project.md` (Источники), `docs/quotes-quality.md` (п. 7).

## Долг консистентности EN (накапливается, закрывать отдельными проходами)

- В разделе цитат: «Holy Tradition» в названиях vs «Sacred Tradition» в глоссарии; регистр
  «Archbishop/archbishop»; разнобой форматов дат и титулов в h3; нумерация Псалмов
  (русская в подписях при ссылке на eng-nkjv). Список и план — в `docs/english-quotes-project.md`.
- В библиотеке: старые EN-страницы (ANF/NPNF и др.) дают библейские ссылки простым текстом,
  без явных `<a>`; часть страниц — ранние машинные переводы. Не переписывать без нужды:
  новые страницы делать по современным конвенциям, старые нормализовать постепенно.
- 3 ранние EN-страницы раздела цитат созданы вне YAML (не воспроизводимы импортом) —
  проверить и при необходимости завести для них YAML-источник.

## Как продолжить в новой сессии (чек-лист)

1. Прочитать `AGENTS.md`, этот файл и документ нужного трека; просмотреть последние
   коммиты (`git log --oneline -10`) — что уже выложено.
2. Проверить окружение: `docker ps` (bibleox, bibpostgres, bibredis), `git status`
   (не трогать чужие незакоммиченные файлы в `db/translations/`).
3. Запустить инвентарь трека (команды выше), выбрать батч по приоритету/подсказке.
4. Работать по конвейеру документа трека; вести черновики в `tmp/` (в git не попадают).
5. По завершении — проверки, ревью, dev-импорт; отчёт пользователю; коммит/деплой —
   по команде; обновить статус/журнал в документе трека.
