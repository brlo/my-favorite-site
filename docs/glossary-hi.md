# Глоссарий: хинди (hi)

Рабочий глоссарий для новых переводов на хинди: статьи «Предания»
(`db/translations/trad/hi.yml`), святоотеческая библиотека, цитаты. Составлен по
уже выложенным переводам и живым страницам; при расхождении с готовым текстом
сайта предпочитать готовый текст и дополнять глоссарий.

Общие правила перевода — `docs/translations.md`; структура меню —
`docs/menu-structure.md`.

## Библия и ссылки

- Библия сайта: **`hi-ov`** (Hindi Old Version). Текст стихов: `verses`
  (tr_code `hi-ov`).
- `BibleLinker::BIBLE_BY_LANG` содержит `hi => hi-ov`, поэтому ссылки можно
  ставить автоматически; вручную — `https://bibleox.com/hi/hi-ov/mf/25/#L1`.
- Краткие имена книг — `config/locales/hi.yml`, `books.short` (все книги).
- Цитаты Писания — **дословно по Hindi O.V.** (не перевод с русского).
  Нумерация стихов в модуле совпадает с Синодальной.
- Второканон: у O.V. протестантский канон; цитаты из Тов/Прем/Сир/Макк —
  переводить по смыслу и оговаривать в сноске, ссылку вести на греческий текст
  (`gr-lxx-byz`) либо не давать.

## Стиль и оформление

- Современный стандартный хинди (деванагари), книжный церковный стиль; без
  разговорных форм.
- Пунктуация: `।` в конце предложения, запятая `,`; кавычки `«…»` или `“…”`.
- Цифры — западные (0–9), как в существующих статьях; в URL и ссылках на стихи
  — только западные.
- Не ставить ZWJ (U+200D) внутри слов: «चिल्‍ला» портит поиск и цитаты; писать
  `चिल्ला`.
- Единая транслитерация: `बीज़ान्टियम`, `हर्मिताज़`, `थेसालोनिकी`,
  `मोलिव्दोवुल`, `5वें एवेन्यू` (не разнобой `बाइज़ेंटियम/बीज़ान्तियो` и т. п.).
- Греческие термины — по-гречески; латинские надписи — дословно.
- Ссылки на русские страницы помечать «(रूसी में)», на греческие — «(यूनानी में)».
- Названия музеев: `मेट्रोपॉलिटन संग्रहालय, पाँचवाँ एवेन्यू`, `लूव्र संग्रहालय`,
  `हर्मिताज़ संग्रहालय`.
