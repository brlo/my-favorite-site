# BKV → сайт: перенос текстов, которых у нас нет

План подтягивания текстов с <https://bkv.unifr.ch> (Bibliothek der Kirchenväter,
Фрибурский университет) в святоотеческую библиотеку сайта: если труд уже есть
хотя бы в одной из четырёх библиотек — русской, английской, латинской или
греческой, — добавляем недостающие языковые версии, которые есть в BKV.

## 0. Статус

- Каталог BKV разобран: `script/translations/bkv/catalog.py` →
  `tmp/bkv/catalog.json`. Цифры на 25.11.2026: **136 авторов, 836 трудов,
  1691 версия**.
- Метаданные версий: `script/translations/bkv/versions.py` — обходит страницы
  версий, вытаскивает «Bibliographische Angabe» (переводчик, издание, год),
  ссылки на EPUB/RTF и маркеры источника. Проверен на выборке; полный обход
  de/fr-переводов — ~800 страниц, с паузой 1.5 с это ~20 минут, кэшируется.
- **Пилот сделан (dev, 25.11)**: французский Феофил Антиохийский —
  авторская страница `Théophile_d_Antioche` и труд `Theophile_A_Autolyque`,
  в группе, где уже были ru/en/grc. Текст — Genoude 1838 с fr.wikisource
  (та же французская версия, что в BKV; у BKV-версии нет EPUB).
  Пункт-заготовка «Théophile d'Antioche, saint (†183)» в меню `IIe siècle`
  заполнен. Проверено: обе страницы 200, якоря `#HH-1…#HH-3`, переключатель
  языков en/fr/ru/grc, кириллицы нет.
- Остальное — инвентарь и инструменты; правил отбора, карты соответствий и
  загрузчика для потока пока нет.
- Немецкий пилот (Климент, Игнатий, Поликарп) — отдельный проект,
  `docs/german-library-plan.md`; он же первый пример конвейера «BKV → страница».

По типам: **1077 переводов**, **497 комментариев** (вступления, примечания

Источники внутри BKV неоднородны:

- **BKV** (Kösel, 1911–1937; 1869–1880; 1830–1850) — то, ради чего проект
  затевался: немецкие переводы, общественное достояние (с проверкой
  переводчика).
- **ANF/NPNF** (английские переводы XIX в., те же, что в CCEL) — PD, но у нас
  уже загружены в EN из CCEL (`db/ccel_map.yml`), дублировать не нужно.
- **Genoude** (французские переводы 1830–1840-х) — PD; **Moreau** и другие
  старые французские переводы — проверять по году/переводчику.
- **Edith Stein** (переводы Дионисия Ареопагита, † 1942) — PD с 2013.
- **Loeb** (греческий/латинский текст с параллельным английским) — **под
  копирайтом**, не берём.
- **«Zeugen des Wortes»** (Hugo Rahner, Herder 1954) — «Alle Rechte
  vorbehalten», не берём.
- **«(ChatGPT)»** — машинные переводы, загруженные пользователями BKV; не
  источник (качество), исключаем автоматически.

Каталог-индекс (`/de/works`) даёт только автора, труд, тип и язык версии.
**Переводчик, издание, год и ссылка на скачивание — только на странице
версии**; её надо скачать и разобрать один раз (это ~1700 страниц, по одной
на версию, ~80 КБ каждая).

## 2. Права: что можно брать

Правило сайта (см. `docs/german-library-plan.md` §2): только PD; для перевода
это смерть переводчика не позже 1955 г. (70 лет → PD в Германии/ЕС и РФ),
для США — издание до 1931 г.

Практически:

1. **Белый список источников**: `(BKV)`, `SWKV/SKV`, `Genoude`, `Moreau`,
   `Edith Stein`, `ANF/NPNF/CCEL` — с проверкой конкретного переводчика.
2. **Чёрный список**: `Loeb`, `Zeugen des Wortes`/Rahner, `Sources
   Chrétiennes`, современные единоличные переводы, `(ChatGPT)`.
3. Для каждого переводчика — одна проверка (год смерти) и запись в
   `db/bkv_translators.yml`; дальше решение принимается автоматически.
4. BKV-онлайн сам пишет, что тексты BKV «keinem Copyright mehr» подлежат, и
   просит ссылку на источник — это подстраховка, но **не замена** проверке
   переводчика: на сайте BKV есть и не-BKV тексты под копирайтом.

Атрибуция на странице: переводчик, издание, том, год, страницы, ссылка на
версию BKV (как в немецком пилоте).

`versions.py` прошёл все немецкие и французские переводы (681 из 681):

| Источник в библиографии | Версий |
|---|---|
| BKV (Kösel/Kempten, 1911–1937 и старые серии) | 349 |
| Genoude (фр., 1830–1850-е) | 32 |
| SWKV («Sämmtliche Werke der Kirchenväter», 1830-е) | 2 |
| Edith Stein († 1942) | 5 |
| ANF/NPNF (англ. XIX в.) | 2 |
| «Zeugen des Wortes» (Rahner, 1954) — **нельзя** | 10 |
| «(ChatGPT)» / машинные переводы — **нельзя** | 2 |
| без явного маркера | 277 (206 fr + 71 de) |

Сумма больше 681: маркеры пересекаются (например, BKV и Kösel); 277 — версии,
у которых нет ни одного маркера.

Важная поправка: год в библиографии — это часто **год оцифровки/переиздания**,
а не перевода. Например, у Тертуллиана стоит «Traduit par Genoude, 1852.
Proposé par Roger Pearse, 2005» — перевод PD, а год 2005 вводит в заблуждение.
Поэтому классифицировать надо **по переводчику**, а не по максимальному году.

Что уже видно:

- 41 имя переводчика в библиографиях; чаще всего Julius Baer (15), Ludwig
  Schade (15), Gerhard Rauschen (14), Remigius Storf (13), Kellner (9),
  Franz Zeller (8), Edith Stein (5), Otto Bardenhewer (4).
- Явный чёрный список: Rahner (10), ChatGPT (2), «maschinelle Übersetzung
  2026» (1), «Automatische Übersetzung» / «Arbeitsübersetzung» (2), Werner
  Steinmann 1985 (1), французский «Evangile selon Thomas» 1959 (1),
  «Discours sur les Psaumes» 2001 (1).
- 5 версий без библиографии — разобрать вручную (в т.ч. «Zwölf Briefe (BKV)»).
- 277 версий без маркера — это в основном старые французские переводы
  (abbé Joyeux, Aubert, Arnauld d’Andilly и др.) и BKV-тома без пометки;
  им нужен переводчик/год из библиографии.

Следующий шаг по правам — `db/bkv_translators.yml`: имя → год смерти, статус
(PD / проверить / нельзя). После него классификация версий автоматическая:
BKV-тома с проверенными переводчиками идут в белый список, Rahner/ChatGPT/
современные — в чёрный.

## 3. Что считать «нашим трудом»

Якорь — группа перевода (`group_lang_id`), у которой есть страница хотя бы в
одной из библиотек `ru`, `en`, `la`, `grc`. Языки, которые можем заполнить из
BKV: `de`, `fr`, `en`, `la`, `grc` (для `la`/`grc` — только PD-издания).

Две проблемы гранулярности, которые нельзя игнорировать:

- **BKV-труд ≠ наша страница.** У нас длинные труды разбиты на части
  (Августин: «De Trinitate, Liber 4», «Письма 22–29»), а в BKV один труд с
  делениями. При импорте немецкой/французской версии нужно либо резать текст
  по тем же частям (карта `parts`), либо заводить одну страницу на весь труд и
  мириться с тем, что переключатель языков на частичных страницах будет вести
  на неполный перевод.
- **Наша страница ≠ BKV-труд.** Иногда у нас одна страница на несколько
  произведений (английские «Selected Works and Letters #4»), а в BKV они
  раздельны.

Вывод: импорт «вслепую по названию» невозможен; нужна карта на уровне
**наша группа ↔ труд BKV**, с необязательным `parts` для разрезания.

## 4. Сопоставление

Порядок:

1. **Авторы.** Словарь `db/bkv_authors.yml`: автор BKV → группа автора на
   сайте (ru/en/la/grc). 136 авторов, из них реально нужны ~70 (остальные —
  апокрифы, армянские/сирийские сборники, литургии, Лютер, Фома Аквинский,
  Тереза — вне нашей библиотеки).
2. **Труды.** Внутри автора — сопоставление по названию: латинские названия
   BKV хорошо совпадают с `la`-страницами, греческие издания — с `grc`,
   английские ANF — с `en`. Черновик автоматический (нормализация,
   Jaccard/вхождение, номера книг), затем ручное подтверждение.
3. **Карта.** `db/bkv_map.yml` (по образцу `db/ccel_map.yml`):
   ```yaml
   works:
     - src: cpg-1107/an-autolykus-bkv   # труд/версия BKV
       lang: de
       group: <group_lang_id или путь нашей страницы>
       title: "An Autolykus"
       menu: { parent: "2. Jahrhundert/Theophilus von Antiochien", title: "An Autolykus" }
       parts: ...                        # если наш труд разбит
   ```
4. **Проверка.** Для каждой карты — отчёт: сколько версий, какие языки
   закрываем, какие уже есть у нас (пропуск), какие дубли (EN/CCEL).

Черновая оценка (автоматическое совпадение по именам, без ручной карты):
50 авторов и 536 трудов BKV имеют одноимённого автора на сайте; у этих трудов
1149 версий, в том числе 279 немецких, 188 французских, 277 английских, 66
латинских, 18 греческих. После ручной карты и отсева дублей/копирайта
реалистичный первый поток — **200–400 страниц** (de + fr, плюс единичные
en/la/grc, которых нет).

## 5. Конвейер импорта

Основа — `app/services/ccel/importer.rb` (карта, части, меню, ссылка-маркер,
повторный запуск, prune). Что добавить:

1. `Bkv::Importer` с параметром `LANG`; список страниц — `Kirchenvaeter` для
   de и соответствующие `q-saints-en` / `church_writers_la` / `church_writers_grc`
   / французский список для fr.
2. Скачивание: страница версии → ссылка `…/related_files/….epub` →
   `tmp/bkv/epub/<slug>.epub`. Если EPUB нет — деления (`/divisions`)
   через тот же рендер, что в немецком пилоте.
3. Рендер: главы/книги → `<h2>N</h2>`, сноски BKV — по политике (в немецком
   пилоте выброшены), атрибуция внизу; якоря `#HH-n` получаются сами.
4. Привязка к группе: `group_lang_id` из карты; если в языке уже есть страница
   этой группы — пропуск (не перезаписывать чужой перевод).
5. Метаданные: обложки — `copy_cover: true` в YAML автора или
   `script/translations/copy_covers.rb LANG`; «золотые» пункты —
   `script/translations/gold.rb LANG`; `seo_kind` —
   `script/seo/backfill_seo_kind.rb` (плюс `mark_seo_kinds_pass2.rb` для
   авторов без годов). `title_sub` и место в веке — в YAML автора.
6. Меню — как в en/ja/la: на автора два YAML, `<author>_author.yml`
   (`list: <список раздела>`, `menu.parent` — век) и `<author>_works.yml`
   (`list: <path автора>`, `folders` — категории, `menu.parent` — категория).
   Тогда труды создаются детьми автора, а пункты — в меню автора; отдельный
   «переносчик» не нужен.
7. QA: кириллица/латиница по языку, размер, число глав, якоря, ссылки,
   отсутствие машинных артефактов; первые партии — `is_published: false` до
   вычитки.

## 6. Порядок работ

1. **Каталог** — готов (`catalog.py`).
2. **Метаданные и права**: `versions.py` → `tmp/bkv/versions.json`, затем
   `db/bkv_translators.yml` (белый/чёрный список). ~1700 запросов, вежливо
   1–2 с, один раз; кэш в `tmp/bkv/versions/`.
3. **Карта авторов** (~70 строк) → **карта трудов** (пилот на 1–2 авторах).
4. **Пилот** — сделан на **Феофиле Антиохийском, «К Автолику»** (fr):
   у нас en/ru/grc по одной странице, BKV даёт французский Genoude 1838 (PD)
   и немецкий BKV Bd. 14, 1913 (пер. J. Leitl — год смерти не подтверждён,
   поэтому немецкий отложен). Для французского вместо BKV взят fr.wikisource:
   там та же версия Genoude в чистом HTML, тогда как у BKV-версии нет EPUB,
   а страницы делений отдаются медленно и без оглавления.
   Скрипт: `script/translations/fr/theophile_autolyque.py`.
  Мелкий дефект источника: в книге III у Genoude/Викитеки пропущен номер
  главы XXV (текст слит с соседними) — при вычитке сверить с печатным
  изданием.
5. **Партии по авторам**: сначала 1:1 труды (Феофил, Афинагор, Ириней,
   Игнатий, Поликарп, Мелитон, Минуций Феликс, Лактанций…), потом разбитые
   (Августин, Златоуст, Григорий Нисский) с `parts`.
   После каждой партии — `copy_covers.rb LANG`, `gold.rb LANG`,
   `backfill_seo_kind.rb`.
6. **Долгий хвост**: издания, спорные авторства, дубли с CCEL.

## 7. Что уже можно сделать без импорта

- Пересобрать каталог: `curl -sL https://bkv.unifr.ch/de/works -o
  tmp/bkv/works.html && python3 script/translations/bkv/catalog.py`.
- Собрать метаданные версий (сначала выборка, потом всё):
  `python3 script/translations/bkv/versions.py --langs de,fr --limit 20`, затем
  без `--limit`.
- Выгрузить наши группы для сопоставления:
  ```
  docker exec bibpostgres psql -U bibleox bibleox_development -t -A -F $'\t' -c \
    "select group_lang_id, lang, title, path, page_type, parent_id from pages \
     where lang in ('ru','en','la','grc') and is_deleted is not true" > tmp/bkv/site_pages.tsv
  ```

## 8. Открытые вопросы

1. Политика прав: строгая (проверять каждого переводчика) или опираться на
   заявление BKV + год издания ≤1930 с выборочной проверкой?
2. Что делать с английскими ANF/NPNF из BKV: считать дублями CCEL (пропуск)
   или сверить, чего в CCEL нет?
3. Брать ли комментарии BKV (497) — вступления и примечания редакторов? Для
   библиотеки, вероятно, нет; для страниц авторов — можно как «Einleitung».
4. Гранулярность: резать BKV-труд под наши части или заводить один труд на
   страницу?
5. Приоритет языков: de + fr в первую очередь (их у нас почти нет), или
   добивать en/la/grc, где BKV даёт недостающие тексты?
