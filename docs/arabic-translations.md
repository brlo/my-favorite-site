# Арабские переводы (ar): святоотеческая библиотека

Специфика ar-проекта; конвейер, методика и общие правила — в `AGENTS.md`,
`docs/translations.md` и `docs/japanese-translations.md` (пользователь
называет автора → страница автора + труды, I век → II век, сборщики с
автонумерацией сносок, ревью второй моделью, принципы перевода в
примечаниях, названия — имя первым). Здесь — отличия арабского и его
текущее состояние.

## Статус (пилот уже есть)

- Раздел отцов: стр. 1156 `أعمال آباء الكنيسة القديسين والكتّاب الكنسيين`
  под links-разделом التقليد (395). Меню размечено **по векам**
  (القرن الأول…العشرون + папка с ديداخي)، заготовки I–XX веков уже стоят —
  с правильными православными именами и **именем первым**:
  إغناطيوس حامل الإله، الشهيد في الكهنة (حوالي 35-107) /
  بوليكاربوس السميرني / كليمنتس الروماني / إيرينيئوس الليوني…
  Заполнен пока только Златоуст: автор 1157 `يوحنا الذهبي الفم` (имя
  первым ✓) с трудами (проповеди, толкования, «Страшный Суд» 28K).
- Молитвослов `صلاة الأرثوذكس` (992): утренние/вечерние молитвы, каноны,
  Символ веры, молитвы до/после причастия, **Божественная Литургия Иоанна
  Златоуста** (48K) — живой источник богослужебной лексики.
- Библия: `arab-avd` — **Ван Дейк (فان دايك)**, 31 102 стиха, зарегистрирована
  в константах и локали (`config/locales/ar.yml`, включая `books.short`:
  تك، خر، لا، عد، تث…). Протестантский канон, **второканона нет**.

## Библия и ссылки

- `BibleLinker::BIBLE_BY_LANG` пока **не содержит 'ar'** — автоссылок нет.
  Перед началом цитирования: добавить `'ar' => 'arab-avd'` и арабский
  паттерн по `books.short` из локали (по образцу `ja_pattern`). До того
  ссылки на Писание в текстах — простым текстом (مت 25… — как сейчас в
  «Страшном Суде»).
- Псалмы и нумерация стихов — сверять по базе; в модуле возможны
  восточноарабские цифры (٠-٩) — сверять форму в подписи ссылки с текстом
  стиха.
- Второканон: Ван Дейк его не содержит — та же проблема, что у ko/zh:
  цитаты из Тов/Прем/Сир — сноска + перевод по смыслу; вопрос о втором
  переводе (католические арабские издания) открыт.

## RTL

Страницы живут и рендерятся; при возобновлении работ — аудит направления
письма (dir=rtl в шаблонах, смешение LTR-фрагментов: HTML-теги, цифры
диапазонов, латиница/греческий в скобках, сноски). Греческие термины в
сносках — по-гречески, внутри RTL-текста обрамлять аккуратно (span dir=ltr
при необходимости).

## Названия страниц

Правило «имя первым» действует; Златоуст и заготовки ему уже соответствуют.
Строка принципов — на арабском по общей схеме (переводчик: روديون فلاسوف،
основа, вспомогательные переводы, Библия); образца ещё нет — составить при
первом переводе и занести сюда.
