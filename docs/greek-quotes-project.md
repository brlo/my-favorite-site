## Конвейер партии (отличия от EN)

Пайплайн EN (черновики → `q_apply`) сохранён, но добавлены **инструменты пересборки текста
цитат** — руками греческий полиtonic не набирается без ошибок (оксия vs тония, U+037E/U+0387,
гомоглифы кириллицы):

1. Инвентарь (`script/translations/el/inventory.rb`) → выбранная папка.
2. Дамп RU-тел + стихов: `script/translations/el/verses.rb <ru_path>` → `verses_<path>.txt`
   (RU и gr-lxx-byz построчно, для смысловой сверки нумерации).
3. Перевод: черновик тела `tmp/el_quotes/batch/<папка>/out/<el path>.html`. Тексты цитат
   можно набирать упрощённо — главное правильные БУКВЫ и выделения.
4. **Пересборка**: `bin/rails runner script/translations/el/rebuild.rb <draft>` — заменяет текст
   каждой цитаты дословным текстом модуля (выделения переносятся по посимвольному
   выравниванию: буквы строгие, пунктуация/пробелы свободные, оксия/тония и U+037E/U+0387
   не считаются различием). Поддерживает стартовые обрезки цитат (`<<` — цитата с середины
   стиха, до 160 симв. старта; эмиссия текста тоже начинается от смещения — ревью 19.11
   поймало баг, когда теги сдвигались, а текст оставался полным). Подписи ссылок
   генерируются из `books.short` (лечит гомоглифы кириллицы — в списке el-q нашлось 70).
   Ошибка = реальная опечатка/пропуск в черновике.
5. **Проверка дословности**: `bin/rails runner script/translations/el/verify_verses.rb <draft|out/>`
   — каждая цитата == тексту модуля байт-в-байт (по ссылкам цитаты). После пересборки —
   всегда зелёная.
6. YAML: `bin/rails runner tmp/el_quotes/make_yaml.rb` (собирает `db/translations/el/q_<папка>.yml`
   из черновиков; folders — отдельным `db/translations/el/q_00_folders.yml` с `pages: []`).
7. Импорт: `bin/rails pages:import_translations FILE=db/translations/el/q_00_folders.yml`
   (первый раз), затем `... FILE=...q_<папка>.yml PUBLISH=1`.
8. `bin/rails runner script/translations/q_parity.rb el db/translations/el/q_<папка>.yml`
   — счётчики/заголовки/ссылки (для el проверяет и grc-страницы библиотеки).
9. Вкладки: `bin/rails runner script/translations/el/links.rb` (`--check` — проверка).
10. Проверка на `http://localhost:3000/el/el/w/<path>` и списке `/el/el/w/el-q`.
11. Ревью второй моделью против ru-эталона (промт — `tmp/el_quotes_translation_prompt.md`),
    верификация правок, приёмка user.
12. Выкладка — только по команде (см. `docs/quotes-quality.md` «Выкладка»).

## Конвенции (решения пилота)

### Стиль и текст цитат

- Проза — monotonic dimotiki; библейские цитаты — полиtonic дословно из `gr-lxx-byz`
  (модуль хранит precomposed oxia-формы и греческие кодпоинты пунктуации — сохраняются
  как есть, «не модернизировать»).
- Скобки редактуры модуля (`[τινα]`, `[κυρίου]`, `[οἱ]`) сохраняются — читатель по ссылке
  видит тот же текст на странице Библии. Пробел/пунктуационные особенности модуля
  (em-dash в Откр 12:9 и т.п.) — тоже.
- Кавычки статьи: «…». Внутренние кавычки прямой речи, добавленные редактурой RU
  (Пс 90:2, Иуд 1:9 и т.п.), в цитаты не добавляются — текст модуля дословный.
- Разрыв цитаты (несмежные стихи) — `&lt;…&gt;` (многоточие U+2026), как в промте v0.
- Подписи-ссылки — формы `books.short` из `config/locales/el.yml` без точки:
  `Μτ 5:3-10`, `Ψλ 50:3`, `Α Κορ 13:4`, `Σ.Σολ 2:24` (это проверяет `q_parity`).
  Ссылки абсолютные, с хвостовым слэшем: `https://bibleox.com/el/gr-lxx-byz/iev/28/#L12-19`.
  Несколько мест разделяются «·» (не «;» — в греческом это вопросительный знак!),
  у каждого — полное название книги (голое «20:2» q_parity не пропустит).
- Выделения: рисунок 1:1 с RU (счётчики strong/mark/nest проверяются). При глагольном
  порядке слов LXX «strong» начинается с первого выделенного слова (глагол остаётся без
  выделения) — расхождение границ фиксируется в notes статьи.
- Века в h2, заголовки авторов, сноски — по промту v0 (`tmp/el_quotes_prompt.md`).
- Ссылки на RU-статьи в прозе, пока нет el-версии, — простым текстом (конвенция «лучше
  простым текстом» из quotes-quality); ссылку вернуть, когда появится el-страница
  (долг: «Ορθόδοξη Εκκλησία» в вступлении списка).
- Проза всегда monotonic, включая перечисления библейских терминов (ревью 19.11).

## Решения по «чтений, которых нет в модуле» (правило промта v0)

1. **Иов 33:23-24 (ангел-хранитель)**: LXX читает «χίλιοι ἄγγελοι θανατηφόροι» — мысль RU
   («ангел-наставник») в модуле отсутствует. Заменено на **Дан 3:49** («ἄγγελος δὲ κυρίου
   συγκατέβη ἅμα τοῖς περὶ τὸν Αζαριαν…») — довод раздела (вера ВЗ в ангелов) сохранён,
   счётчик strong=3 сохранён. Утверждено user 19.11. Ревью отметило: теряется мотив
   «ангела-наставника»; если он понадобится — кандидат на замену/дополнение Исх 23:20
   («ἰδοὺ ἐγὼ ἀποστέλλω τὸν ἄγγελόν μου πρὸ προσώπου σου, ἵνα φυλάσσῃ σε ἐν τῇ ὁδῷ»),
   решение за user; пока оставлено без примечания в статье.
2. **Лк 22:43-44 (ангел-хранитель)**: в модуле строки пустые (чтения нет). Заменено на
   **Мф 4:11** («ἄγγελοι προσῆλθον καὶ διηκόνουν αὐτῷ»), заголовок h3 изменён:
   «Ο Ιησούς Χριστός, ως άνθρωπος, διακονούνταν από αγγέλους» — форма согласована с чтением
   Мф 4:11 (διηκόνουν, «служили»), а не «укреплялся»; по итогам ревью 19.11.
3. **Дефекты модуля, сохранены дословно**: `πανεῦμα` (Тов 6:8, должно быть πνεῦμα),
   `σιραῖς` (2Пет 2:4, должно быть σειραῖς). Если user решит чистить модуль — отдельная
   правка БД, не в статьях.

## Известные особенности

- `q_parity.rb` дополнен: для el проверяет ссылки на grc-оригиналы (`bibleox.com/grc/grc/w/…`)
  — страницы должны существовать в библиотеке (кейсы ALL-CAPS путей типа ΔΙΔΑΧΗ проверять
  на живом сайте — известный 404-квирк).
- Вкладки: до появления `el-saints-q` статья-«библейская половина» (как ангел-хранитель)
  остаётся без таб-бара; страницы-«отцовская половина» (как Ch2c/Ik1c) получают вкладку
  «Αγία Γραφή» → `el-q`. После создания `el-saints-q` перезапустить `el_links.rb`.
- `BibleLinker` поддерживает el: `'el' => 'gr-lxx-byz'` + `el_pattern` (названия книг из
  локали, точка после сокращения допустима, цифры европейские, lookahead как в ru-паттерне).
- Пробелы/переносы: `Page#body` нормализуется при сохранении — сравнивать БД↔БД.
