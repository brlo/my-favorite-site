# Японская Библия jp-box（ビブレオックス訳）

Рабочая инструкция для продолжения собственного православного перевода Библии на
японский. Общие правила (докер, прод, коммиты) — в `AGENTS.md`; устройство переводов
Библии и импорт модулей — в `docs/bibles.md`; переводы статей — `docs/translations.md`.

## Что это

`jp-box` — не импорт готового издания, а собственный перевод проекта: современный
японский, точный к церковному тексту, с опорой на 日本正教会訳 (1901, общественное
достояние) и сверкой с 新共同訳 только по естественности языка (он под авторским
правом и источником быть не может).

Статус: **Новый Завет (27 книг), Псалтирь, Пятикнижие, Иисус Навин, Судьи, Руфь,
1–4 Царств, 1–2 Паралипоменон и Екклесиаст готовы**.
Всего 43 книги, 826 глав, 22 776 стихов (НЗ 7957, Пс 2619, Быт 1533, Исх 1181,
Лев 859, Чис 1287, Втор 958, Нав 654, Суд 619, Руфь 85, 1 Цар 806, 2 Цар 695,
3 Цар 814, 4 Цар 722, 1 Пар 943, 2 Пар 822, Еккл 222).
Всё идёт одним конвейером: Новый Завет — с византийского текста и `jp-joc`,
Ветхий — с Септуагинты и славянского контроля; проверка на дословные заимствования

## Команды (всё в контейнере `bibleox`)

```bash
# сборка модуля из YAML
docker exec bibleox bash -lc 'cd /app && bin/rails runner script/translations/bible/jp_box_build.rb'

# сборка + импорт в базу (REPLACE)
docker exec bibleox bash -lc 'cd /app && IMPORT=1 bin/rails runner script/translations/bible/jp_box_build.rb'

# проверка книги (по умолчанию mk)
docker exec bibleox bash -lc 'cd /app && BOOK=mf bin/rails runner script/translations/bible/jp_box_check.rb'

# обновить страницу «О переводе» (ru)
docker exec bibleox bash -lc 'cd /app && bin/rails runner script/translations/bible/jp_box_about.rb'
```

После импорта смотреть живую страницу: `http://localhost/ja/jp-box/mf/3/`.

## Разметка стиха в YAML

| синтаксис | что значит |
|---|---|
| `漢字[かな]` | фуригана (конвенция сайта; `text_search` её вырезает) |
| `〔…〕` | чтение, которого нет в критическом издании (в тексте стоит чтение Церкви) |

Проверка скобок — по базе, а не по памяти: если слово или целый стих в `gr-lxx-byz`
**есть** (даже если критическое издание держит его в квадратных скобках), `〔…〕` не
ставится; если на месте стиха стоит `.` — стиха в базе нет и он целиком в `〔…〕`.
Исключение — Мк 16:9–20 (по решению пользователя оставлено в скобках).
| `{A｜B}` | калька: A общепринятая, B православная (кнопка `伝統表記`) |
| `<j>…</j>` | слова Иисуса — красные |
| `<mo>…</mo>` | слова Богородицы — синие (`<m>` занят MyBible) |
| `⟨пояснение⟩` | звёздочка-сноска после предыдущего слова; сборщик кладёт текст в `data['notes']` |

Сноски ставить **только там, где слово неочевидно нехристианину** (レギオン, コルバン,
デナリオン, 大工, パン種). Очевидные слова не подписывать — в Марке 1 и 2 лишние сноски
убрали по просьбе пользователя.

## Принципы текста

- **База — текст Церкви** (византийский; контроль — Елизаветинская, русский
  Синодальный, `jp-joc`). Критический греческий на сайте (`gr-lxx-byz`) — один из
  свидетелей, не эталон. Расхождения с ним → `〔…〕`, причём маркируется добавление
  Церкви, а не «вставка».
- Там, где критическое издание расходится целым стихом (Мк 7:16, 9:44, 9:46, 15:28),
  стих целиком в `〔…〕`; для больших пассажей (Мк 16:9-20) — тоже скобки, по решению
  пользователя.
- **Не сглаживать**: не добавлять пояснений, не разрешать двусмысленности, сохранять
  порядок и структуру, если они несут смысл.
- **С греческого**. `jp-ni` — не источник (авторское право), только сверка
  естественности; `jp-joc` (1901, public domain) — опора и свидетель церковного чтения.
- Итог перевода — **общественное достояние**; на странице «О переводе» это заявлено.

## Язык

- 常体 (だ・である), как у `jp-ni`; です・ます только в статьях и словаре.
- 常用漢字, современные начертания; фуригана щедро: термины, имена, неочевидные чтения.
- Местоимения: `あなたがた` (мн. ч.), `あなた` (ед. ч.); `わたし` хираганой.
- К Христу — гонорифики (`お〜になる`, `〜された`), как в японской библейской традиции.
- Слова Христа — красным всегда, включая притчи; слова ангелов, Ирода, бесов, толпы —
  НЕ красным. Слова Богородицы — синим.
- Имена — современные формы: イエス, ダビデ, ペトロ, ヨハネ, モーセ.
- Не использовать архаизмы `jp-joc`: なんぢ, われ, 〜なり, 〜けり, 蓋, 即, 會, 體.

## Автоподстановка в режиме «伝統表記»

В `app/helpers/application_helper.rb` (`JP_BOX_ORTHODOX_NAMES`) при включённой кальке
подставляются только те слова, которые в православной традиции читаются иначе.
Формы взяты из `jp-joc` (1901) — той же традиции, что ダワィド/モイセイ/イオアン:

- Спаситель и Дух: イエス→イイスス, キリスト→ハリストス (но не 反キリスト),
  聖霊→聖神; サタン→サタナ; ユダ→イウダ (но не ユダヤ).
- Апостолы и ученики: ペトロ→ペトル, ヨハネ→イオアン, ヤコブ→イアコフ,
  アンデレ→アンドレイ, ピリポ→フィリップ, バルトロマイ→ワルフォロメイ,
  トマス→フォマ, マタイ→マトフェイ, マルタ→マルファ, ラザロ→ラザリ.
- Павел и его спутники: パウロ→パワェル, テモテ→ティモフェイ, テトス→ティト,
  ピレモン→フィリモン, ステファノ→ステファン, サウロ→サウル, バルナバ→ワルナワ,
  シラス→シラ, プリスキラ/アクラ не меняются.
- Патриархи и пророки: アブラハム→アウラアム, イサク→イサアク, ヤコブ→イアコフ,
  ヨセフ→イオシフ, モーセ→モイセイ, アロン→アアロン, ダビデ→ダワィド,
  サムエル→サムイル, サムソン→サムプソン, ダニエル→ダニイル, エレミヤ→イエレミヤ,
  イザヤ→イサイヤ, エリヤ→イリヤ, ヨナ→イオナ (но не ヨナタン), ヨブ→イオフ,
  ノア→ノイ, エノク→エノフ, アベル→アワェリ, ラハブ→ラアフ, メルキセデク→メルヒセデク,
  レビ→レワィ, コラ→コレイ, アサフ→イサフ, アナニア→アナニヤ.
- Прочие: マリア→マリヤ, ヘロデ→イロド, インマヌエル→エムマヌイル,
  エリサベト→エリサワェタ, ザカリヤ→ザハリヤ, ニコデモ→ニコディム, ゼベダイ→ゼワェデイ,
  アルファイ→アルフェイ, アポロ→アポロス (но не アポロニア).

Подстановка идёт по словарю с исключениями (`反キリスト`, `ユダヤ`, `ヨナタン`,
`アポロニア`); тесты — в `test/helpers/application_helper_test.rb`. Новые имена
добавлять туда же и проверять форму по `jp-joc` (grep по выгрузке), чтобы не выдумывать.

Остальные термины — только попарными маркерами `{A｜B}` в конкретном месте, потому что
подстановка по словарю ломает контекст. В тексте лучше писать `キリスト`, а не `メシア`,
иначе переключатель не сработает.

## Ветхий Завет (с Бытия)

- Основа — **Септуагинта** (`gr-lxx-byz`), как и обещано на странице «О переводе»:
  Церковь читает Ветхий Завет по LXX, а не по масоретскому тексту.
- Контроль церковного чтения — церковнославянский (`csl-ru`) и `jp-joc`, где он есть.
  У `jp-joc` в Ветхом Завете только фрагменты (Бытие: главы 1–9 полностью, дальше
  выборочно), поэтому для большей части книг перевод идёт с греческого и славянского.
- **`ru` (Синодальный) — не источник**: он с масоретского текста. По нему можно
  понять смысл, но его чтения не вносить; расхождения LXX/масоретского отмечать в `notes`.
- `〔…〕` — только слова церковного чтения (`csl-ru`, `jp-joc`), которых нет в `gr-lxx-byz`.
  Масоретские добавки Синодального в скобки не берутся (это другое чтение, а не Церковь).
- Красного и синего в Ветхом Завете нет: речь Бога — `「…」`, но это не прямая речь
  Христа во плоти, `<j>` не ставится.
- Родословия: числа лет по LXX (в Быт 5 и 11 они отличаются от масоретских),
  формула «…は…歳まで生き、…を生んだ».
- Выгрузка: `BOOK=gen CH=1 TRS="gr-lxx-byz jp-joc csl-ru ru" bin/rails runner tmp/dump_jp.rb`.

### Паритет LXX и церковнославянского (с 2026-11-24)

Решение пользователя: церковнославянский — не «контроль второго сорта», а второй
свидетель церковного текста, и уважать его нужно больше, но разумно.

1. Нумерация и структура книги — по `gr-lxx-byz` (на ней построен сайт).
2. Основной текст — церковное чтение. Где `csl-ru` содержит стих или фразу, которых
   в LXX нет (в том числе там, где LXX короче), они входят в **основной текст без
   `〔…〕`**; в `notes` и шапке главы отмечается «нет в LXX».
3. Где `csl-ru` и LXX дают разные чтения (имя, число, порядок, слово), по умолчанию
   предпочитаем `csl-ru` как церковное чтение, а вариант LXX — в `notes`.
   Исключение: если `csl` явно следует масоретскому тексту, а LXX хранит иное
   древнее чтение, и разница важна для смысла, берём LXX и отмечаем `csl`.
4. Масоретские чтения, которых нет ни в LXX, ни в `csl`, в текст не вносим.
5. `〔…〕` по умолчанию **не ставим**. Остаются только: (а) по прямому решению
   пользователя (Мк 16:9–20), (б) там, где сознательно держим LXX против `csl`
   и хотим это показать. Большие блоки, которые читает Церковь (например,
   1 Цар 17:12–31), идут основным текстом, а не в скобках.
6. Скобки в ранее принятых книгах (Лев, Чис, Втор, Нав, Суд) сохраняются до
   отдельной сверки; в 1 Цар и далее работаем по этому паритету.

## Процесс на главу

1. **Выгрузить источники** — по стихам. `jp-ni` в выгрузку по умолчанию не входит:
   он под авторским правом и источником быть не может (см. «Чистота текста»).

```
docker exec bibleox bash -lc 'cd /app && BOOK=mf CH=3 bin/rails runner tmp/dump_jp.rb'
```

   Выгружаются `gr-lxx-byz` и `jp-joc` (1901, public domain). Если нужно всё же
   посмотреть `jp-ni` для сверки уже написанного стиха: `TRS="gr-lxx-byz jp-ni jp-joc"`.

2. **Написать YAML** `db/translations/bible/jp-box/mf_03.yml` (шапка с `tr_code`,
   `book`, `chapter`, `draft: true`; комментарии в `notes:` — для ревью, в базу не идут).
3. **Проверить файл до сборки**: `BOOK=mf CH=3,4 ruby tmp/check_jp.rb` — разметка,
   фуригана, парность скобок, число стихов.
4. **Проверить чистоту**: `BOOK=mf CH=3 bin/rails runner tmp/sim_jp.rb` — должно быть
   «нарушений правила 0» (см. «Чистота текста»).
5. **Собрать и импортировать**: `IMPORT=1 ... jp_box_build.rb`.
6. **Проверить книгу**: `BOOK=mf ... jp_box_check.rb` — должно быть «проблем нет».
7. **Открыть страницу** и глазами посмотреть красное, скобки, сноски, фуригану.

## Чистота текста (не копировать `jp-ni`)

`jp-ni`（新共同訳）— только сверка естественности, не источник: перевод объявлен
общественным достоянием, а дословные заимствования из чужого перевода недопустимы.
Модель, видя перед собой готовый японский текст, почти неизбежно повторяет его,
поэтому:

- черновой перевод — с греческого и `jp-joc` (сверка: `TRS="gr-lxx-byz jp-ni jp-joc"`);
- **положительный образец — `jp-joc`** (Николай Японский, 1901, public domain):
  у него берём структуру фразы, порядок членов, деление на клаузы, церковные чтения
  и терминологию, где она ещё живая; **не берём язык** — 文語, 舊字體, なんぢ・なり・けり,
  〜たまへり. Язык у нас современный.
  Поэтому, например, `洗礼` в кальке остаётся `洗礼`: у jp-joc это `洗禮` — та же лексема
  в старой орфографии, а не другой термин (то же с 霊/靈, 礼/禮: калька меняет слова, не начертания).
- где `jp-ni` и `jp-joc` расходятся по структуре или чтению — идти за `jp-joc`, если
  расхождение не чисто стилистическое (регистр, старые начертания).

### Измеримое правило вместо порога сходства

Сходимость двух честных переводов одного греческого текста — норма: у независимого
Матфея средняя близость к `jp-ni` 0.66, самый длинный общий кусок 43 знака. Копирование
выглядит иначе: у старого Марка средняя 0.97, 447 стихов из 678 совпадали знак в знак,
самый длинный общий кусок 111 знаков. Поэтому проверяется не «похожесть», а
дословность:

- стих со сходством **≥0.95** при длине **≥20** знаков — переписать;
- общий с `jp-ni` кусок **длиннее 45 знаков** — переписать;
- средняя по главе — ориентир, а не догма; естественность важнее цифры.

```
docker exec bibleox bash -lc 'cd /app && BOOK=mk CH=1,2,3 ruby tmp/sim_jp.rb'
```
Скрипт считает по YAML, печатает только свой текст и метрики, текст `jp-ni` не раскрывает.

## Проверка и приёмка

- `jp_box_check.rb` проверяет: все стихи на местах (сверка с `jp-ni`), парность
  `〔〕`/`<j>`/`<mo>`, фуригану (только кана, после кандзи), отсутствие `⟨` и кириллицы,
  соответствие `{{n}}` ↔ `data['notes']`, отсутствие маркеров в `text_search`.
- Пользователь принимает главы глазами; правки вносятся в YAML и переимпортируются.
- `tmp/sim_jp.rb` — запрет дословных кусков (≥0.95 при длине ≥20; общий кусок >45),
  а не порог «похожести»: сходимость с `jp-ni` на формульных стихах нормальна.
- Раз в книгу — выборочная сверка с греческим (10–15 спорных мест) на `ἐγώ εἰμι`,
  `κατακριθήσεται` и подобные.

## Журнал решений

- Заголовок «О переводе» — пока только ru; японскую версию сделать перед выкладкой на прод.
- Статус глав на сайте не показываем (пользователь: читателю это не нужно).
- Бейдж «ИИ + человек» на странице главы ведёт на «О переводе», при наведении — тултип.
- Кнопка кальки перезагружает страницу и сбрасывает скролл — так и оставили.
