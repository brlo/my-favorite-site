# Корейские переводы (ko): святоотеческая библиотека

Специфика ko-проекта; конвейер, методика и общие правила — в `AGENTS.md`,
`docs/translations.md` и `docs/japanese-translations.md` (то же самое:
пользователь называет автора → страница автора + труды, I век → II век,
сборщики с автонумерацией сносок, ревью второй моделью, принципы перевода
в примечаниях, названия — имя первым). Здесь — только отличия корейского.

## Статус

Раздел ko: стр. 1130 `zVSU_고대_성부들과_교회_저술가들의_저작들`. Меню —
**плоское, порядок задаётся priority** (без папок-веков, в отличие от ja/zh);
заготовки авторов всех веков уже стоят. Готово: Игнатий (6006 `Ig2A` + 7
посланий `Ig2E…Ig2P`, `db/translations/ko/ign_*.yml`, скрипты
`script/translations/ign/ko_*.py` — рабочий образец), q-раздел (`ko-q`),
молитвослов 정교회 기도서, и частично: Палама, Брянчанинов, Феофан
Затворник, Ефрем Сирин, Киприан, Иоанн Кронштадтский, Антоний Великий,
Иустин, Златоуст. Поликарп, Дидахе, Климент ещё не сделаны — идут по общей
схеме с переиспользованием zh-аналитики (эталоны, structure-JSON, QUOTES).

## Библия: 개역개정 (ko-nkrv)

Единственная ko-Библия на сайте; протестантская, **второканона нет** — та же
проблема, что у zh с 思高： цитаты отцов из Тов/Прем/Сир — сноска «개역개정에
없는 차경(외경) 구절» + перевод по смыслу с указанием источника; вопрос о
второй ko-Библии открыт. `여호와` стоит в ~5900 стихах — принято сознательно
по правилу zh: свой текст — 주, цитата — как в Библии перевода. Псалмы —
еврейская нумерация, каждую ссылку сверять по базе.

## Ссылки

В отличие от ja/zh, ko-тексты Игнатия используют **простой текст +
автолинкер** (`BibleLinker`: ko → ko-nkrv): «에페 1:4-5» распознаётся и
становится ссылкой при рендере. Сокращения книг — `config/locales/ko.yml`
(`books.short`: 창/출/레/민/신/수/삼상/왕상…창世=창, 마태=마태); подпись без
точки после сокращения, диапазон дефисом. Явные `<a href="…/ko-nkrv/…">`
писать в сносках, когда нужен контроль формулировки. Внутренние ссылки:
`https://bibleox.com/ko/ko/w/{path}#HH-{n}`; свой труд — `#HH-{ch}`.

## Терминология (сверено с готовыми ko-текстами)

| по-русски | ko | примечания |
|---|---|---|
| Бог | 하느님 | свой текст; в цитатах 개역개정 — 하나님 (смешение разрешено правилом) |
| Господь | 주 | в ВЗ-цитатах 개역개정 — 여호와 |
| Церковь / храм (здание) | 교회 / 성전 | |
| епископ / пресвитер / диакон | 주교 / 사제 / 부제 | |
| таинство | 성사 | |
| Евхаристия / причастие | 성찬 / 영성체 | |
| Крещение | 세례 | не 침례 (протестантское) |
| покаяние / исповедь | 회개 / 고백(성사) | |
| благодать | 은총 | не 은혜 (протестантское) |
| Предание | 전승 | |
| мученик | 순교자 | священномученик — 순교자 사제? согласовать при случае |
| Писание | 성경 | Ветхий/Новый Завет — 구약/신약 |

Имена — греческая транскрипция, из готовых текстов: 이그나티오스 (테오포로스),
폴리카르포스, 클레멘스, 유스티노스, 에우세비오스, 이레나이오스 (заготовка
«이레네오» — заменить при переводе), 키프리아노스.

## Названия страниц (правило: имя первым)

Страница Игнатия сейчас нарушает: `안티오키아의 이그나티오스 (테오포로스), 1세기`
→ цель `이그나티오스 (테오포로스), 1세기` (Антиохия уже в title_sub:
순교자(35년경–107년), 안티오키아의 주교); меню 1705 — так же. Заготовки с
прозвищем первым (폴리카르포스 스미르나, 클레멘스 로마, 이레네오 리용,
테오필로스 안티오키아, 멜리토 사르디스…) заменять целевыми формами через
`menu: {replace: …}`: 폴리카르포스 (스미르나의), 클레멘스 (로마의)…

## Строка принципов

Образец (Игнатий ko): `번역: 로디온 블라소프 (AI 도구 활용). 저본: 그리스어 원문(…)` —
те же требования, что для остальных языков: источник, вспомогательные
переводы, Библия, LXX/лат. главы; важные детали принципов — и в сносках.
