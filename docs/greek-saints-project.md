# el-saints-проект: раздел цитат святых отцов на новогреческом (`q-saints` → `el-saints-q`)

Долгосрочный проект перевода на новогреческий (димотика) раздела **«Цитаты святых отцов
и церковных писателей»** — RU-список `q-saints` (id 140). Это второй греческий раздел цитат:
первый (`el-q`, «Βιβλικές ρήσεις») переведён полностью (191 статья, см. `docs/greek-quotes-project.md`).

Методика партии и приёмка — `docs/quotes-quality.md`; механика раздела и `q_build` —
`docs/quotes-section.md`; общий EN-аналог проекта — `docs/english-quotes-project.md`.
Решения по языку (политоника цитат, монотоника прозы) — `docs/greek-notes.md`.

## Что переводим

- RU-эталон: **`q-saints`** (id 140), дерево папок меню (Священное Писание, Церковь, Таинства,
  века и т. д.), 175 реальных статей (+ заготовки с пустым телом — не переводим).
- EL-список: **`el-saints-q`** (id 7849, «Ρήσεις Πατέρων της Εκκλησίας»), меню `links_el` —
  пункт 1913 (раньше был заготовкой без пути).
- Статья = подборка цитат с подписями авторов (h2/h3 по векам), выделениями
  (strong/mark/em/u) и ссылками на источники.

## Отличия от `el-q` (важно)

Цитаты здесь — **святоотеческие**, а не библейские, поэтому:

1. Где труд есть в **греческой библиотеке сайта** (`lang=grc`, 1201 страница), цитата берётся
   **дословно** из неё (политоника как в издании) и ссылается на страницу библиотеки:
   `https://bibleox.com/grc/grc/w/<PATH>#HH-<глава>` (главы в библиотеке — `<h2>N</h2>`).
   `q_parity.rb` для `el` проверяет существование таких страниц.
2. Где подлинника на сайте нет — цитата **переводится с русского** (политоника), без ссылки
   на библиотеку; это фиксируется в notes и, если важно, в примечании вне кавычек.
3. Библейские цитаты внутри статей — дословно из `gr-lxx-byz` (как в `el-q`), ссылки
   `/el/gr-lxx-byz/...`, нумерация LXX.
4. Проза и заголовки — монотоника; тексты цитат — политоника.
5. Ссылки на azbyka и русские библиотечные страницы не переносятся (простой текст);
   ссылки на el-страницы — по `group_lang_id`, если перевод есть.

## Конвейер партии

1. **Инвентарь:** `script/translations/q_inventory.rb el el-saints-q --folders` (`--next`).
2. **Выгрузка RU:** `script/translations/q_batch.rb export el el-saints-q "<папка>"`
   (нужна существующая страница-список; папки меню создаются из `folders:` YAML).
3. **Черновик тела** статьи: `tmp/el_saints/out/<el path>.html` — только тело, структура 1:1
   с RU (заголовки, число цитат, абзацы, рисунок выделений).
4. **Паритет:** `script/translations/q_parity.rb el db/translations/el/q_saints_<n>.yml
   --draft tmp/el_saints/out` → `Паритет с RU и ссылки: OK`.
5. **Дословность библиотечных цитат:** `tmp/el_saints/check_grc_quotes.rb <draft>` — текст
   каждой цитаты со ссылкой на `grc` должен буква в букву быть в теле этой страницы.
6. **YAML:** `script/translations/q_apply.rb el db/translations/el/q_saints_<n>.yml tmp/el_saints`
   (черновики → `body`, `update: true`), затем `q_parity` по YAML.
7. **Импорт в dev:** `bin/rails pages:import_translations FILE=db/translations/el/q_saints_<n>.yml PUBLISH=1`
   (папки — отдельным YAML с `pages: []`).
8. **Вкладки** «Γραφή / Παράδοση»: `script/translations/el/links.rb` (`--check` — проверка).
9. **Ревью второй моделью** (проза + цитаты отдельно), правки, повторный паритет.
10. **Выкладка** — только по явной команде пользователя (`docs/quotes-quality.md`, «Выкладка»).

Примечание к инвентарю: `q_inventory.rb` считает готовность по `group_lang_id`, поэтому
статьи `q-saints`, у которых уже есть греческий «двойник» из `el-q` (например «Символ веры»,
«До воскресения Христа…»), показываются готовыми, хотя в `el-saints-q` их нет. Итоговый счёт
вести по membership в меню списка (`menus.page_id = el-saints-q`), а не по инвентарю.

Инструменты проекта (в `tmp/`, не в репозитории): `BRIEF.md` (бриф исполнителю),
`count.rb` (счётчики и разбивка по цитатам), `verse.rb` (стихи `gr-lxx-byz`),
`grc_search.rb` / `grc_dump.rb` (поиск и главы греческой библиотеки),
`check_grc_quotes.rb` (дословность), `create_list.rb` (страница-список), `check_<X>.yml`
(одностатейные YAML для паритета черновика).
