# Статистика посещений

Счётчики в Redis (`app/services/page_visits.rb`), дневные ключи с TTL 7 дней, заполняются из `day_visit` в макете на каждый HTML-запрос: `vis`/`o-vis`/`s-vis`/`b-vis` (люди/одноразовые/подозрительные/боты), `uip` (уникальные IP людей), `bots` (по именам), `langs` (языки интерфейса), `zips` (топ IP), `top` (топ статей). Сводка — `/admin`.

- «Людьми» считаются только IP, сделавшие хотя бы два запроса за день; IP с единственным запросом попадают в `o-vis` («одноразовые»). Так отсеиваются распределённые скрейперы, которые качают сайт по схеме «одна страница с IP» и потому не ловятся ни по User-Agent, ни порогом. Цена — живые посетители с одним просмотром за день тоже остаются в «одноразовых».
- Ботов определяет `BotDetector`: гем `browser` + кастомный список `CUSTOM_BOTS` для тех, кого гем не знает (кандидатов искать в access-логах прода: `/var/log/nginx/access.log.1` и в блоке «Топ IP» сводки).
- «Подозрительные» — не-бот IP, сделавший за день больше `SUSPICIOUS_DAY_LIMIT` запросов (скрейперы с браузерными User-Agent по UA не отличить, ловятся только порогом).
