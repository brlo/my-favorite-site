# Статистика посещений

Счётчики в Redis (`app/services/page_visits.rb`), дневные ключи с TTL 7 дней, заполняются из `day_visit` в макете на каждый HTML-запрос: `vis`/`s-vis`/`b-vis` (люди/подозрительные/боты), `uip` (уникальные IP), `bots` (по именам), `langs` (языки интерфейса), `zips` (топ IP), `top` (топ статей). Сводка — `/admin`.

- Ботов определяет `BotDetector`: гем `browser` + кастомный список `CUSTOM_BOTS` для тех, кого гем не знает (кандидатов искать в access-логах прода: `/var/log/nginx/access.log.1` и в блоке «Топ IP» сводки).
- «Подозрительные» — не-бот IP, сделавший за день больше `SUSPICIOUS_DAY_LIMIT` запросов (скрейперы с браузерными User-Agent по UA не отличить, ловятся только порогом).
