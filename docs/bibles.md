# Переводы Библии

- Источник — модули MyBible с https://www.ph4.ru/b4_my.php (номера книг MyBible = `BOOKS[..][:id]`). Загрузка: `bin/rails bible:import_mybible FILE=... TR=код [FIX='a=b']`; убрать стихи, которых нет в модуле: `bible:prune`; перевести ссылки статей со старого перевода на новый: `bible:relink`; удалить перевод: `bible:delete`.
- Новый код перевода прописать: `config/initializers/constants.rb`, 22 файла `config/locales/*.yml` (`bib_translations` и названия в `breadcrumbs.bib_langs`), `app/views/verses/_text_bar.html.erb`, список в поиске, поисковые сервисы (CJK-языки), `BibleLinker`, `mobile/src/lib/config.js`, список переводов на `/about` (`app/views/pages/about.html.erb`), `public/llms.txt` (раздел Bible translations).
- Во французском LSG 1910 (fr-lsg) базовый текст в ряде мест расходится с православной Библией: после импорта `script/translations/bible/fix_fr_lsg.rb` возвращает в квадратных скобках чтения 1 Ин 5:7 (свидетельство Отца, Слова и Святого Духа), 1 Тим 3:16, Деян 20:28, Откр 1:11, Кол 1:14, 1 Ин 4:3, Лк 2:33, 1 Кор 15:47, Еф 3:9, Откр 22:19. Скрипт идемпотентен и должен запускаться после каждого импорта модуля. Не правились: 1 Пет 4:14 (конец стиха) и место славословия (в русской — Рим 14:24-26, в LSG — 16:25-27).
- Японская православная Библия (`jp-joc`, 日本正教会訳聖書, 1901) — источник azbyka.ru/biblia/?jp. Новый Завет и Псалтирь полные, Ветхий Завет — только богослужебные чтения (книги, главы и стихи выборочно; 1Sam, 2Sam, 1King, 2King, 2Chron в источнике отсутствуют). В HTML azbyka `<ruby>漢字<rt>かな</rt></ruby>` превращается в `漢字[かな]`; знаки U+3099–U+309C (`神[しん]゜`, `神゚識`) — артефакт оцифровки, удаляются; зелёные `<span style="color:green">` — пробный перевод самого сайта (не православный перевод), вместе с пометкой `<small>（※緑部は本サイトによる試訳）</small>` отбрасываются. Псалтирь в источнике идёт с греческой нумерацией стихов (надписание занимает 1–2 стиха), на сайте приведена к синодальной: первые 1–2 стиха сливаются в строку 0, остальные сдвигаются (скрипт `tmp/ja_orthodox/ps_align.py`, в git не входит). Дефекты источника исправлены при сборке: Исх.14:32 — дубль Исх.15:1 (удалён), Флм.1:23–24 слиты (23 → 23, благодать → 25), а также сдвинутые границы стихов: Ис.9:8–20 (+1), Ис.10:20–21, Ис.53:8–10, Ис.63:2–3, Ис.64:1–4 (+1), Иер.12:14–15, Иез.1:8–9, Чис.24:2–3, Суд.13:18–21. Клаузы переставлены к синодальным границам; отсутствующие в источнике стихи остаются пустыми. Модуль для импорта: `tmp/bibles/JP-JOC.SQLite3` (сборщик `tmp/ja_orthodox/`, в git не входит).
- Модули не всегда честные: бывают пустые заглушки, правки составителя (в корейском 공동번역 «침례» вместо «세례»; в 개역개정 NRKV лишняя «”» в Быт 1:1, импорт с `FIX='”='`); отрывки в скобках (Мк 16:9-20, Ин 5:3-4, Ин 7:53-8:11) размечены незакрытым `<n>[` … `]</n>`, до исправления `MybibleImporter.clean` конечные стихи стирались — недостающие добавляет `script/translations/bible/fix_brackets.rb`; в NRKV обрезаны после первого предложения 1 Тим 3:16 и Ис 30:6 — после импорта `fix_1tim.rb`, `fix_is30.rb` там же, стихи чужого языка на месте недостающих. Проверять текст выборочно до импорта.
- Файлы модулей (`tmp/bibles/`) в git не попадают: на прод копировать через `scp` и `docker cp` в `/app/tmp/bibles`.
- Японский перевод проекта (`jp-box`, ビブレオックス訳) — не импорт готового модуля, а собственный перевод: YAML по главам в `db/translations/bible/jp-box/*.yml` → `bin/rails runner script/translations/bible/jp_box_build.rb` (собирает `tmp/bibles/JP-BOX.SQLite3`) → `bin/rails bible:import_mybible FILE=tmp/bibles/JP-BOX.SQLite3 TR=jp-box [REPLACE=1]`. Разметка стиха: `漢字[かな]` — фуригана; `〔…〕` — расхождение с критическим изданием (в тексте стоит чтение Церкви); `{A|B}` — калька, A общепринятая, B православная, включается кукой `calque=orthodox` (кнопка `伝統表記` в text-bar); имена Христа и Святого Духа при этом подставляются автоматически (イエス→イイスス, キリスト→ハリストス, 聖霊→聖神); `<j>…</j>` — слова Иисуса (красные), `<mo>…</mo>` — слова Богородицы (синие; `<m>` в MyBible служебный, поэтому `mo`); `⟨пояснение⟩` — звёздочка-сноска после предыдущего слова, сборщик превращает её в `{{n}}` в тексте, а сам текст кладёт в `data['notes']` стиха (туда же, где подстрочник); из `text_search` маркеры вырезаются. Пока загружен только Мк 1, перевод не индексируется (`BIB_LANGS_NOT_INDEXED`).
