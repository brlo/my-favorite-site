# Конвенции ja-перевода Иустина Философа (драфт-агентам)

Проект: перевод трудов Иустина (Апология 1, Апология 2, Разговор с Трифоном) на японский для сайта bibleox.com. Эталон — русский текст сайта (он тоже перевод с греческого), en-текст сайта (ANF, 19-й век) — вспомогательный для проверки смысла. Оригинал — греческий (изд. Марковича); если ru и en расходятся в смысле, выбирай по греческой норме и помечай в примечании.

## Формат вывода

Каждый агент пишет один файл `draft/<имя>.py` (UTF-8):

```python
CH = {
  14: ["текст первого абзаца главы 14", "второй абзац"],
  15: ["…"],
}
NOTES = [
  (14, "текст примечания для главы 14"),
]
```

- Ключ `CH` — номер главы РОВНО как на строке `H2:` файла источника (если в файле `H2: 61 — о совершении Крещения`, ключ `61`). Прескрипт Диалога (`H2: О разговоре…`, файл ch01) — ключ 0.
- Список в `CH[n]` — абзацы главы, РОВНО столько же, сколько абзацев в файле источника (абзацы разделены пустой строкой). Не объединять и не дробить.
- Сноски: в тексте абзаца ставится маркер `{{N:999}}` (999 — любой уникальный id внутри файла), в `NOTES` — `(999, "текст примечания")`. Сборщик перенумерует по порядку появления. id в NOTES и в тексте должны совпасть 1:1 — ни лишних, ни отсутствующих.
- Ссылки на Библию — плейсхолдер прямо в тексте: `{{B:mih 4:1}}`, `{{B:mf 5:3-12}}`, несколько мест: `{{B:is 66:1; zah 8:23}}`. После плейсхолдера текст примечания/скобки ru («(Ис. 7:14 и Лк. 1:31)») НЕ дублируется — сборщик сам построит подпись. Если в ru место цитаты подписано, а в плейсхолдер попало несколько ссылок — одна ссылка = один плейсхолдер.
- Никакого HTML в абзацах: только текст, плейсхолдеры, маркеры сносок. Кавычки-речь и короткие цитаты — 「」, названия трудов — 『』. Названия книг Библии в тексте НЕ пишутся (они появятся в подписи ссылки), но если автор называет книгу по имени в прозе («у Исаии сказано») — пишем «イザヤ書でこのように述べています：» и т.п.

## Стиль и типографика

- Вежливый です・ます (как во всех готовых переводах сайта). Прямая речь (Трифон, Иустин в Диалоге) — тоже です・ます.
- Пунктуация: 。、 полная ширина; диапазоны цифр — ASCII дефис (10:38-42); годы: 〜100-165.
- Кавычки: речь/цитаты 「」, вложенные 『』, названия трудов 『』.
- Кириллица в ja-тексте запрещена. Славянизмы/грецизмы — катаканой: 独り子（パイス） стиль, в скобках при первом употреблении.
- Сноски (NOTES) — для читателя важное: расхождение с 新共同訳， чтение текста, терминологическое решение, объяснение реалии. НЕ переводить русские сноски ru-перевода (их в ja нет). Объём: только там, где реально нужно.
- Числа: арабскими; «второй век» → 2世紀.

## Чего не делать

- Не копировать русские сноски и подстрочные пометы ru-перевода.
- Не добавлять своих заголовков/рубрик.
- Не переводить вольнее источника; длинные рассуждения Иустина сохранять в полном составе (паритет содержания).
- Не использовать ですます-отступления в богослужебной лексике: 洗礼， 聖体， 復活， 御使い — терминология глоссария.
