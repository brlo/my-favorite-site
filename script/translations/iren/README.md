# Ириней Лионский: страницы автора en/grc из русского эталона

Сборщик страниц `Irenaeus_of_Lyon` (en, 541) и `Εἰρηναῖος Λουγδούνου` (grc, 944),
переписанных с русского эталона (ru 457). Методика — `docs/library-pipeline.md`,
`docs/english-library-project.md`, `docs/greek-notes.md` (раздел про Иринея).

## Что где

- `prep.py` — разбор ru-страницы на блоки, поиск каждой цитаты в русских трудах
  (книга/глава/абзац), чистка выделений (`blocks.json`, `quote_locs.json`);
- `make_packs.py` — карта источников (`map.json`), пакеты разделов для переводчиков
  (`packs/<lang>/C*.md`) и текстовые корпуса (`corpus/<lang>_<work>.txt`);
- `assemble.py` — сборка тела из JSON-ответов (`out/<lang>/C*.json`): цитаты дословно,
  выделения, « … » на пропусках, деление на абзацы, строки-источники с якорями;
- `build_yaml.py` — YAML для `pages:import_translations` (`refs_*.html` — тексты примечаний);
- `check_chunk.py` — проверка одного чанка (блоки, выделения, дословность, кириллица);
- `check_links.py` — все ссылки/якоря собранного тела на dev;
- `parity.py` — паритет структуры с ru-эталоном.

## Данные (в git не входят)

Выгрузки страниц — `tmp/iren/db/*.html` (psql из `bibpostgres`), ответы переводчиков —
`tmp/iren/out/<lang>/C*.json`, сборка — `tmp/iren/build/<lang>_body.html`. По умолчанию
скрипты берут данные из собственной папки; чтобы работать из репозитория:

```
IREN_TMP=tmp/iren python3 script/translations/iren/assemble.py grc
IREN_TMP=tmp/iren python3 script/translations/iren/build_yaml.py grc
```

Импорт: `bin/rails pages:import_translations FILE=db/translations/<lang>/irenaeus_author.yml
DRY_RUN=1`, затем `PUBLISH=1` (в докере `bibleox`).

## Решения

- EN: цитаты дословно из ANF на сайте; латинский довесок I.23 — с латинской страницы;
  явные опечатки электронного текста исправлены и перечислены в `refs_en.html`.
- GRC: проза — димотика/монотоника, цитаты — политоника; где греческий подлинник
  сохранился — дословно (`from: greek`), где утрачен — перевод с латинского текста сайта
  с пометой «(λατ.)» и ссылкой на латинскую страницу; «Доказательство апостольской
  проповеди» (арм. оригинал) — с русского, без ссылки.
- Пропуски русского эталона («<…>») передаются « … »; каждый кусок между ними дословен.
