# Задание переводчику: страница Иринея Лионского (en / grc)

Ты переводишь **авторскую страницу Иринея Лионского** (русский эталон — page 457) на
английский или новогреческий. Работа идёт пакетами (chunk). Координатор уже разобрал
страницу на блоки, нашёл места цитат в трудах и положил целевые тексты в пакет.

Пакет: `tmp/iren/packs/<lang>/<CHUNK>.md` — прочитай его целиком.
Корпуса для поиска: `tmp/iren/corpus/<lang>_<work>.txt` (en/grc/la), можно `grep`-ать.

## Железные правила

1. **Цитаты — не перевод.** Это дословный текст первоисточника, уже выложенный на сайте:
   - `en`: английский перевод ANF (Ante-Nicene Fathers) со страниц `en/...`;
   - `grc`: греческий оригинал со страниц `grc/...`, где он сохранился.
   Своими словами цитату пересказывать нельзя: нужен **буква в букву** кусок из
   предложенного текста (проверяется скриптом). Меняются только очевидные опечатки
   электронного текста — такие случаи перечисли в поле `notes`.
2. **Греческие цитаты, которых нет по-гречески** (в пакете нет текста grc или в нём нет
   этого места): переведи **с латинского** текста из пакета (основной свидетель),
   политоническим греческим; если латинского нет — с русского. Пометь `from`.
3. **Проза и заголовки** — твой перевод: `en` — научный английский; `grc` — новогреческий
   (димотика, **монотоника**), заголовки с прописной только в начале.
4. **Выделения** (`strong`, `mark`, `em`, `u`) переносятся: число и вид выделений в переводе
   должны соответствовать русским. `em: WHOLE` = вся цитата курсивом.
   В ответе выделение задаётся парой `[тег, "точная подстрока цитаты"]`; если подстрока
   встречается в цитате несколько раз — третьим элементом номер вхождения (с 1).
5. **Кириллицы в ответе быть не должно** (кроме поля `notes` для координатора).
   HTML валидный, теги сбалансированы.
6. Не добавлять сносок, не вставлять от себя пояснений в текст цитат. Русские
   переводческие ремарки в скобках («— прим.», «др.-греч.», «лат.») на целевой странице
   снимаются/переоформляются по смыслу.
7. Ссылки `<a>` в прозе — сохранять как есть; координатор потом поправит особые случаи.
8. Отвечай **только JSON-файлом**, без markdown-обёрток: `tmp/iren/out/<lang>/<CHUNK>.json`.
   В финальном сообщении — коротко: сколько блоков, какие цитаты `own`/`from`, замечания.

## Формат JSON

```json
{
  "lang": "en",
  "chunk": "C1",
  "blocks": [
    {"id": 47, "k": "h2", "html": "<h2>Faith</h2>"},
    {"id": 48, "k": "h3", "html": "<h3>God — the Trinity</h3>"},
    {"id": 49, "k": "quote", "work": "b1", "chapters": [10], "anchor": "HH-10",
     "text": "The Church, though dispersed throughout the whole world ...",
     "marks": [["strong", "in one God, the Father Almighty"], ["em", "WHOLE"]],
     "from": "greek"},
    {"id": 51, "k": "quote", "work": "b1", "chapters": [22], "anchor": "HH-22",
     "text": "...", "marks": [], "from": "greek"},
    {"id": 52, "k": "p", "html": "<p>(<a href=\"...\">...</a>)</p>"}
  ]
}
```

- `id` — номер блока из пакета (обязателен для каждого переводимого блока).
- `k` — как в пакете (`h2`, `h3`, `p`, `ul`, `quote`; `hr` оставить `<hr>` можно не присылать).
- Для `quote`: `work` (`b1`…`b5`, `dem`, `frag`, `justin_dial`, `justin_apol1`, `polycarp`),
  `chapters` (номера глав, где реально стоит цитата), `anchor` — id заголовка главы из пакета
  (например `HH-10-2`); для `dem` — `"anchor": null`.
- `from`: `"greek"` (дословно греч. из библиотеки), `"anf"` (дословно англ. ANF),
  `"latin"` (свой перевод с латыни), `"russian"` (свой перевод с русского), `"armenian"` —
  нет, для «Доказательства» пиши `"russian"`.
- `notes` — строка для координатора (опечатки, расхождения, сомнения), можно опустить.

**Строки-источники** (`(Против ересей, …)`) в пакете помечены «в ответ НЕ включать»:
координатор соберёт их сам из `work`/`chapters`/`anchor` цитаты. Блоки с пометкой
«ОБРАБОТАЕТ КООРДИНАТОР» тоже не переводить.

**Самопроверка (обязательно).** Записав JSON, запусти:

```
python3 tmp/iren/check_chunk.py <lang> <CHUNK>
```

(интерпретатор: `/Users/brlo/.dsh/dsh-runtimes/dsh-primary-runtime/dependencies/python/bin/python3`).
Он ловит пропуски, лишние блоки, несуществующие выделения, недеословные цитаты, кириллицу.
Доведи до «проблем 0».

## Что не переносить на целевую страницу

- `grc`: вступительный абзац «труды этого автора есть по-гречески, перейдите» — если такие
  слова есть, их опускаем/переписываем (см. пакет C0 — там координатор даст текст).
- `grc`: пояснения «в греческом оригинале…», «по-гречески это звучит…», русские
  транслитерации и глоссы в скобках: страница сама греческая.
- Латинский довесок к цитате о Симоне волхве (блоки 158–160) на grc-странице не нужен —
  в пакете помечено «ПРОПУСТИТЬ».
