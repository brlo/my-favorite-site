# Греческая (grc) страница Иустина Философа (ru 389 → grc 408)

Страница автора переписана заново с русского эталона: **проза и заголовки** — перевод на
современный греческий с монотонией (выбор пользователя), **цитаты** — не перевод, а
дословный греческий оригинал, уже выложенный на сайте: `Ἀπολογία 1` (415), `Ἀπολογία 2` (412),
`Διάλογος πρὸς Τρύφωνα` (411). Выделения (жирный/маркер/курсив) перенесены с русского.

## Что где

- `make_packs.py` — пакеты разделов для агентов-переводчиков (`chunks/*.md`) + тексты глав;
- `check_gr.py <chunk>` — приёмка ответов агентов (from/to, marks, структура, выделения);
- `my_parts.py` — переводы заголовков, подзаголовков h4, прозы и `references` (координатор);
- `review_quotes.py` — «Отзывы» (Q96–Q101): греческих/латинских изданий этих мест на сайте
  нет, поэтому перевод с русского (в `references` оговорено);
- `build_gr.py` — сборка `gr_body.html`: структура как в ru, ссылки на труды с якорем
  `#HH-<глава>`, экранирование тексто-критических `<…>`, список исправленных опечаток;
- `make_yaml.py` — `db/translations/grc/justin_author.yml`.

Исходники (дампы ru/grc из dev-БД, `works.json` без нумерации абзацев/стихов, `blocks.json`,
`out/*.json` ответов агентов) — в `tmp/justin_gr/`, в git не попадают.

## Порядок

```bash
python3 tmp/justin_gr/make_packs.py
# ответы агентов в tmp/justin_gr/out/*.json, проверка: check_gr.py <chunk>
python3 tmp/justin_gr/build_gr.py      # -> gr_body.html (в конце печатает проблемы)
python3 tmp/justin_gr/make_yaml.py     # -> db/translations/grc/justin_author.yml
bin/rails pages:import_translations FILE=db/translations/grc/justin_author.yml DRY_RUN=1
```

## Решения, которые стоит помнить

- Цитаты — греческий оригинал издания сайта (политоника); проза — монотоника. Так решил
  пользователь: страница читается как современный греческий текст, а Иустин цитируется
  дословно.
- Агент не переписывает греческий текст, а указывает `from`/`to` и `marks`: сборщик режет
  цитату из `works.json` сам, поэтому дословность гарантирована конструкцией.
- Из `works.json` снята нумерация абзацев и стихов (`<strong>N</strong>`); иначе она попадала
  бы внутрь цитат.
- Явные опечатки электронного текста исправляются списком `FIXUPS` (сейчас: «σβεςθήσεται» →
  «σβεσθήσεται» в Диалоге 44), о чём сказано в `references`; тексты трудов не меняются.
- Русские переводческие вставки в скобках (о «горячей воде» в субботу, об «Евхаристии» и т. п.)
  в цитаты не переносятся — это оговорено в `references`.
- Ссылка-источник ведёт на греческий труд с якорем главы; у главы 1 «Апологии 1» и «Диалога»
  якорь — `#HH-1-` (в исходной разметке внутри `<h2>` лишний пробел).

## Правила для греческих страниц (из docs/greek-notes.md)

- Вступление «труды автора есть на сайте по-гречески, перейдите» на греческой странице не
  нужно — блок пропускается (`SKIP = {1}` в `my_parts.py`).
- Не переносить пояснения «в греческом оригинале…» и русские переводческие глоссы в скобках:
  цитаты уже даны по-гречески.
- Имя переводчика в примечаниях — **Ροντιόν Βλάσοφ**.
