# Patrologia Latina → латинская библиотека (раздел `la`)

Конвейер наполнения латинского раздела сайта текстами Migne с azbyka.ru.
Общий план и инвентарь — `docs/latin-library-plan.md`. Пилот — Киприан Карфагенский (том 4).

## Исходники

Тома качаются по README автора (`~/Desktop/Библеокс/PL/README.txt`) и прогоняются тремя
скриптами оттуда же: `1_replace_gif2greek.py` (греческие gif → символы), `2_remove_notes.py`
(`<small>` — редакционные примечания), `3_replace_cols.py` (`[Col. 0NNN` → `[PL4.NNN`).
Результат — `greek_replaced/PL4.html`; его и читает конвейер. Скрипты 1–3 уже прогнаны для
томов 1–5, 9–10, 14–17, 22–34 (Августин 32–34), 49–50; тома 35–47 надо скачать и прогнать.

## Шаги

```bash
# 1. Извлечение трудов из тома по манифесту (границы в Migne, пути, заголовки)
python3 script/translations/pl/extract.py extract script/translations/pl/manifests/pl4.json
#    -> tmp/pl/4/<path>.html, <path>.json (статистика), report.txt

# 2. Сборка страниц: части крупных трудов, заглушки для писем без текста,
#    диапазоны столбцов для примечаний
python3 script/translations/pl/build.py script/translations/pl/authors/cyprianus.json
#    -> tmp/pl/4/plan.json

# 3. Автопроверки (перед импортом)
python3 script/translations/pl/check.py tmp/pl/4/plan.json

# 4. Импорт (в контейнере), сначала холостой прогон
docker exec bibleox bash -lc 'cd /app && DRY_RUN=1 bin/rails runner script/translations/pl/import.rb tmp/pl/4/plan.json'
docker exec bibleox bash -lc 'cd /app && PUBLISH=1 bin/rails runner script/translations/pl/import.rb tmp/pl/4/plan.json'
```

## Что делает `extract.py`

- читает прогнанный том и разбирает его на блоки (`<h4>` — заголовки, `<p>` — абзацы);
- режет диапазон труда: от заголовка труда (`works[].start`) до следующего (`works[].end`);
- выкидывает редакционный аппарат: `ARGUMENTUM` (резюме Migne — набрано курсивом,
  определяется по метрике «почти весь абзац в `<em>`»), `CAPITULA`, `MONITUM`, `NOTA`,
  `PRAEFATIO IN …`, `ADMONITIO`, сиглы `(C)`, `(C,G,S)`, ссылки на издания
  (`Erasm.`, `Pamel.`, `Oxon.` …), номера страниц, `(Vide tom. III.)`, маркеры внутри заголовков;
- строит заголовки страницы: письма/книги → `<h2>`, главы Testimonia → `<h3>`;
  у трудов без внутренних заголовков (трактаты Киприана) их и нет — как в русском эталоне;
- пишет статистику (маркеры, число абзацев, что выкинуто) в `<path>.json`, чтобы правки
  фильтров проверялись по числам, а не на глаз.

## Что делает `build.py`

- режет фрагмент на части по заголовкам (`parts[].first` — первый раздел части,
  `parts[].last` — первый раздел следующей части, то есть исключающая граница);
- вставляет пометку в письма, у которых в томе только заголовок, и перечисляет их в `references`;
- считает диапазон столбцов по маркерам (`coll. 463-492`);
- пишет `plan.json`: страница автора, папки меню, труды с `references`.

## Что делает `import.rb`

- создаёт/обновляет страницу автора в списке `church_writers_la`, заполняя пункт-заготовку
  в папке века (`menu_replace`);
- создаёт папки меню автора (`Epistolae`, `Tractatus` …) и пункты трудов;
- труды — дочерние страницы автора, `page_type 1`, `seo_kind book`, `is_past true`;
- группу языков берёт у ru-страницы, только если она свободна: у группы одна страница на
  язык (см. `pages_controller#@page_langs`), поэтому вторая и следующие части крупного труда
  получают свою группу (как `Ccel::Importer#group_for`);
- `DRY_RUN=1` — только лог, `UPDATE=1` — перезаписать существующие страницы, `PUBLISH=1` — публиковать.

## Манифесты и конфиги авторов

- `manifests/pl4.json` — какие труды берём из тома и где их границы в Migne;
- `authors/cyprianus.json` — страницы: пути, заголовки, привязка к ru-страницам (`ru`),
  папки меню, приоритеты, какие труды дробить на части и по каким заголовкам.

Новый автор = новый манифест тома (если том ещё не описан) + конфиг автора. Для второго
автора в томе же томе манифест переиспользуется.

## Подводные камни (проверено на PL 4)

- В Migne часть писем напечатана в другом томе: в PL 4 это XLI, XLII, XLIII, XLV, XLVIII,
  XLIX, LII, LVII, LIX, LXVIII, LXX, LXXII, LXXIII, LXXVI — в тексте стоят заглушки,
  номера перечислены в примечаниях. Их тексты в PL 3 (письма о крещении еретиков, соборные
  акты) — отдельная задача, манифест `pl3.json`.
- Колонцифры в маркерах иногда сбиты (`[PL4.641B]` вместо 662) — предупреждение `check.py`,
  текст при этом цел.
- Аргументы Migne бывают не только курсивом, но и с подписью редактора (`PAMELIUS.`, `EDD.`)
  вне курсива — поэтому порог «вне курсива ≤ 40 букв», а не «ноль».
- В Testimonia курсивом набраны сами цитаты Писания: правило «курсив = резюме» применяется
  только сразу после заголовка `ARGUMENTUM`.
