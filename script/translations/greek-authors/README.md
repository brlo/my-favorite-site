# Греческие страницы авторов: Игнатий Богоносец и Поликарп Смирнский

Две страницы (grc) переписаны заново с русского эталона тем же способом, что и
страница Иустина (`script/translations/justin-gr/`): **проза и заголовки** — перевод на
современный греческий с монотонией, **цитаты** — дословный греческий оригинал с сайта.
Выделения (жирный/маркер/курсив/подчёркивание) перенесены с русского.

## Что где

- `parse_ru.py <ru.html> <blocks.json>` — разбор ru-страницы на блоки (h2/h3/h4, цитаты со
  спанами, строки-источники, проза, таблица);
- `make_packs.py <ign|pol>` — пакеты разделов для агентов (`chunks/*.md`) с текстами трудов;
- `ign_parts.py`, `pol_parts.py` — заголовки, проза, свои переводы (Иероним, Ириней,
  тропарь и кондак), `references`;
- `build_page.py <ign|pol>` — сборка `ign_body.html` / `pol_body.html`: структура как в ru,
  ссылки на греческие труды с якорем `#HH-<глава>`, склейка цитат, покрывающих несколько
  глав, список опечаток;
- `make_yaml.py <ign|pol>` — `db/translations/grc/{ignatius,polycarp}_author.yml`.

Исходники (дампы ru/grc из dev-БД, `works.json` без нумерации, `blocks_*.json`,
`out/*.json` ответов агентов) — в `tmp/pages_gr/`, в git не попадают.

## Решения

- Цитаты — греческий оригинал; если ru-абзац объединяет несколько глав, агент либо даёт
  `from`/`to` по каждой главе (сборщик склеивает остаток в последний абзац), либо
  собирает дословный греческий текст в `own` с пометкой.
- Там, где греческого издания на сайте нет (Иероним «О знаменитых мужах» для Игнатия,
  Ириней «Против ересей» III 3,4 и III 4 и гимнография для Поликарпа), — свой перевод с
  русского, оговорено в `references`.
- «Церковная история» Евсевия (Γ΄ 36) в электронном тексте с обрывами слов на стыках
  абзацев: такие места либо склеены в `own`, либо не цитируются.
