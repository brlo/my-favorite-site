# Правила для переводчика греческих страниц Игнатия Богоносца и Поликарпа (цитаты)

Ты готовишь греческую версию страницы автора на bibleox.com по русскому эталону. Цитаты —
**не перевод**: это греческий оригинал, уже выложенный на сайте. Твоя работа — только
блоки-цитаты `[B<id> Q<q>]`; заголовки и прозу делает координатор.

Ключи трудов в `works.json` (глава → список абзацев; нумерация снята):

- `Ef`, `Mag`, `Tral`, `Rom`, `Phil`, `Smyr`, `Pol` — послания Игнатия (к Ефесянам,
  Магнезийцам, Траллийцам, Римлянам, Филадельфийцам, Смирнянам, Поликарпу);
- `PlkFl` — послание Поликарпа к Филиппийцам; `Mart` — Мученичество Поликарпа;
- `Eus3` — Евсевий, «Церковная история», книга 3 (глава 36 — об Игнатии и Поликарпе).

## Формат ответа

`tmp/pages_gr/out/<chunk>.json`:

```json
{"14": {"where": "Ef 19",
        "paras": [{"w": "Ef", "ch": "19", "from": "…", "to": "…",
                   "marks": [["strong", "…"]]}]}}
```

- ключ — id блока из пакета; `paras` — по одному элементу на каждый **реальный** ru-абзац
  (на заглушки `...` / `<...>` спецификации не даются);
- `w`/`ch` — труд и глава; `from`/`to` — **дословные подстроки** текста главы: кусок
  начинается с `from` и кончается на `to`; копируй из пакета, не по памяти;
- `marks` — выделения: `[tag, phrase]` (`strong` = жирный, `mark` = маркер, `em` = курсив;
  для `<bm>` — и `strong`, и `mark`), фраза должна встречаться в куске ровно один раз
  (иначе третьим элементом номер вхождения).

Если греческого соответствия нет (русский перевод вставил своё) — `"own": "перевод с ru"` и
`"text"` — свой перевод на греческий (монотонический). Таких мест должно быть минимум.

## Как искать

1. Пакет содержит тексты нужных трудов; ищи по смыслу, именам, цитатам Писания.
2. Полный `works.json` — `tmp/pages_gr/works.json` (python/json).
3. В «Церковной истории» Евсевия текст местами испорчен OCR (обрывы слов на стыках
   абзацев) — если кусок выходит нечитаемым, лучше `own`-перевод с оговоркой в отчёте.

## Чего нельзя

- пересказывать или менять греческий текст, терять выделения (число `marks` = числу
  выделений в ru-абзаце), писать кириллицей в `from`/`to`/`marks`/`text`.

В финальном сообщении: таблица «блок → where», список own-абзацев, расхождения греческого
с русским по смыслу.
